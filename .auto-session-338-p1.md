# Task: Build Multi-Iteration CoorMon Event Loop with Key Injection

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS event loop function CoorMon lives at 0x08BF22. Session 337 proved:
- **Key injection works**: writing a scan code to `mem[0x3B0033]` before calling CoorMon makes GetCSC return that scan code. The key-present branch at 0x08BF68 is TAKEN.
- **No-key path returns cleanly**: CoorMon with mem[0x3B0033]=0x00 completes in 7,350 steps across 204 unique blocks, then returns via epilogue at 0x08BF9E.

## Your Task
Create a new probe file at `TI-84_Plus_CE/probe-phase338-multi-iteration-loop.mjs` that:

1. Boots the environment (same pattern as existing probes — see reference below)
2. Installs `cxMain = 0x058241` (Home handler) at `mem[0xD007CA]` (3-byte LE write)
3. Runs CoorMon in a LOOP for N iterations (start with N=5):
   - **Iteration 1**: Inject ENTER key (scan code 0x09) via `mem[0x3B0033] = 0x09`, run CoorMon from 0x08BF22 in ADL mode
   - **Iteration 2**: Clear key (`mem[0x3B0033] = 0x00`), run CoorMon again (no-key iteration)
   - **Iteration 3**: Inject RIGHT arrow (scan code 0x03) via `mem[0x3B0033] = 0x03`, run CoorMon
   - **Iteration 4**: Clear key, run CoorMon
   - **Iteration 5**: Inject CLEAR (scan code 0x09... actually use 0x0F for CLEAR), run CoorMon
4. For each iteration, track and report:
   - Whether the key-present branch at 0x08BF68 was taken
   - Step count and unique blocks visited
   - Termination reason and last PC
   - Value of A register at the branch point 0x08BF3C
5. Print a summary table showing all iterations side by side

## Boot Pattern (copy from existing probes)
```javascript
const BOOT_ENTRY = 0x000000;
const KERNEL_INIT_ENTRY = 0x08C331;
const STACK_RESET_TOP = 0xD1A87E;
const IY_BASE = 0xD00080;
const RETURN_SENTINEL = 0xFFFFFF;
const COORMON_ENTRY = 0x08BF22;
const COORMON_BRANCH_POINT = 0x08BF3C;
const COORMON_KEY_PRESENT_TARGET = 0x08BF68;
const CXMAIN_PTR = 0xD007CA;
const HOME_HANDLER = 0x058241;
const GETCSC_ADDR = 0x3B0033;

// Phase 1: boot
const phase1 = executor.runFrom(BOOT_ENTRY, 'z80', {
  maxSteps: 20000,
  maxLoopIterations: 32,
});

// Reset CPU state
cpu.halted = false;
cpu.iff1 = 0;
cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP;
cpu.sp -= 3;
write24(mem, cpu.sp, RETURN_SENTINEL);

// Phase 2: kernel init
const phase2 = executor.runFrom(KERNEL_INIT_ENTRY, 'adl', {
  maxSteps: 100000,
  maxLoopIterations: 10000,
});

// Prepare for CoorMon
cpu.mbase = 0xD0;
cpu.iy = IY_BASE;
cpu.halted = false;
cpu.iff1 = 0;
cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP;
cpu.sp -= 3;
write24(mem, cpu.sp, RETURN_SENTINEL);

// Install home handler
write24(mem, CXMAIN_PTR, HOME_HANDLER);
```

## Important
- Use `createPeripheralBus({ timerInterrupt: false })` — timer IRQ causes infinite loops
- Between CoorMon calls, MUST reset: `cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;` and reset the stack with RETURN_SENTINEL
- Each CoorMon call: `executor.runFrom(COORMON_ENTRY, 'adl', { maxSteps: 50000, maxLoopIterations: 50000, onBlock(...) {...} })`
- The probe must be a standalone Node.js ESM file (`.mjs`) following the exact import pattern of existing probes
- DO NOT modify any existing files — only create the new probe file

## Scan Code Reference
- ENTER = 0x09
- RIGHT = 0x03
- CLEAR = 0x0F
- 2ND = 0x36
- ALPHA = 0x30
