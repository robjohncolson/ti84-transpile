# Task: Disassemble 0x0A223A (display-area clear) — first 40 bytes

## Context
This is a TI-84 Plus CE ROM transpilation project. We disassemble eZ80 machine code from the OS ROM and trace execution paths. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB binary). The runtime is in `TI-84_Plus_CE/cpu-runtime.js`.

## Background
Session 257 traced function 0x09E2EC which calls 0x0A223A. When called with uninitialized display pointers, 0x0A223A overflows into D007xx RAM, corrupting context state. We need to understand what RAM pointers it reads to determine the fill range, and what needs to be initialized for it to not overflow.

## Deliverables
Create probe file: `TI-84_Plus_CE/probe-phase258-0a223a-disassemble.mjs`

The probe should:
1. **Static disassembly**: Read ROM bytes at 0x0A223A and decode the first 40 bytes of eZ80 instructions manually (print hex bytes + mnemonic for each instruction). Use the eZ80 ADL instruction set (24-bit addresses, 3-byte immediates for LD nn).
2. **Dynamic trace**: Boot the transpiled ROM (cold boot → kernel init → mem init), then execute starting at 0x0A223A for 200 steps with `timerInterrupt: false`. Log each block visited, and watch RAM regions D005xx, D006xx, D007xx for writes.
3. **RAM pointer identification**: Before calling 0x0A223A, dump the following addresses that might contain display pointers:
   - 0xD005F0-0xD005FF (display state area)
   - 0xD00600-0xD0060F (OP register area)
   - 0xD02430-0xD02450 (edit buffer pointers area)
   - 0xD026A0-0xD026B0 (graph/display config area)
4. **Identify the fill range**: From the dynamic trace, determine what start/end addresses the function uses for its memory fill, and which RAM pointer(s) control those limits.
5. Print a summary: disassembled instructions, RAM pointers read, fill range, and what needs initialization.

For static disassembly, read bytes directly from ROM.rom at offset 0x0A223A.

Key eZ80 ADL opcodes for reference:
- `21 ll mm hh` = LD HL,nnnn (3-byte immediate in ADL)
- `11 ll mm hh` = LD DE,nnnn
- `01 ll mm hh` = LD BC,nnnn
- `CD ll mm hh` = CALL nnnn
- `C3 ll mm hh` = JP nnnn
- `ED B0` = LDIR
- `ED B8` = LDDR
- `36 nn` = LD (HL),n
- `77` = LD (HL),A
- `23` = INC HL
- `0B` = DEC BC
- `CB 46+8*bit` = BIT bit,(HL)
- `FD CB dd 46+8*bit` = BIT bit,(IY+d)
