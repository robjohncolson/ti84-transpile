# Task: Re-run 0x09EFDE VRAM fill with 150K+ steps using warm state (iiii)

## Context
Session 240 attempted a 150K-step trace of the VRAM fill loop at 0x09EFDE but failed because it used cold-boot context — only 85 steps executed before exiting at 0x08C308. Session 239's probe (`probe-phase239-09efde-vram-fill-complete.mjs`) ran 80K steps successfully by entering via 0x04EDD0 (the shared post-key-classification handler) with proper RAM seeding.

The VRAM fill at 0x09EFDE is reached via: 0x04EDD0 → 0x04ECCE → 0x07F984 → 0x08BF22 → 0x09EFDE. Session 239 showed that 80K steps fills 152,906/153,600 VRAM bytes but doesn't complete. We need 150K+ steps to see the fill complete and trace what happens AFTER the fill returns.

## What to do
Create a new probe file `TI-84_Plus_CE/probe-phase241-09efde-150k-warm.mjs` that:

1. Uses the SAME setup as `probe-phase239-09efde-vram-fill-complete.mjs` (copy its boot/init/seed approach — it enters at 0x04EDD0 with proper RAM seeds, NOT cold boot)
2. Increases STEP_BUDGET to 150000 (was 80000 in session 239)
3. Tracks:
   - When the 0x09EFDE inner loop finally exits (DJNZ falls through)
   - When the 0x09EFCB outer loop terminates (DEC A reaches 0)
   - What block executes AFTER the fill completes (the return address)
   - VRAM fill completion: count non-zero bytes in VRAM (0xD40000-0xD65400)
   - Register snapshots every 25K steps
   - Total unique blocks visited
4. Reports: step count at fill completion, first post-fill block address, VRAM byte count, final register state

## Key setup from session 239's probe
- Entry at 0x04EDD0 (not 0x09EFDE directly)
- RAM seeds: D0058E=0x00, D0058D=0x00, D0059F=0x00, D003E0=0x00, D00824=0x00, D003DA=0x00, D007E0=0x40, D00000=0x00
- SP=0xD1A87E, IX=0xD1A860, IY=0xD00080, MBASE=0xD0
- Timer interrupts DISABLED: `createPeripheralBus({ timerInterrupt: false })`
- Full z80 boot + kernelInit + memInit before entry (the standard boot path all probes use)
