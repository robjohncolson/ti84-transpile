# Auto-Session 215 P1: Disassemble 0x06004C parent function + extended trace

## Context
We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80). Session 214 found that `JP NZ,0x061290` at address 0x06004C is the **sole caller** of the edit-mode dispatcher at 0x061290. The dispatcher sets BIT 4,(IY+5) which arms the digit insertion path (ConvKeyToTok→BufInsert). But we don't know:
1. What function contains 0x06004C (need to disassemble backwards to find function entry)
2. Whether the full SET 4,(IY+5) completes in a longer trace (session 214's 50-step trace wasn't enough)

## Task
Build a probe at `TI-84_Plus_CE/probe-phase215-06004c-parent.mjs` that:

### Part A: Static disassembly backwards from 0x06004C
- Read ROM.rom (at `TI-84_Plus_CE/ROM.rom`)
- Disassemble backwards from 0x06004C, looking for a RET/JP/JR instruction or known function entry pattern
- Scan the range 0x05FF00-0x060060 for RET (0xC9), JP (0xC3), CALL patterns
- Also scan for any CALL/JP targets TO addresses in this range (i.e., who calls into this area?)
- Report the likely function entry point containing 0x06004C

### Part B: Extended trace from 0x06004C with A=0x03
- Use the same probe pattern as session 214 probes (see `TI-84_Plus_CE/probe-phase214-dispatcher-callers.mjs` for reference)
- Boot the CPU: `const { createCPU } = require('./cpu-runtime.js'); const { createPeripheralBus } = require('./peripherals.js');`
- Create peripherals with `createPeripheralBus({ timerInterrupt: false })`
- Load ROM: `require('fs').readFileSync('./ROM.rom')` into cpu memory
- Load transpiled JS: `require('./ROM.transpiled.js')` and register blocks
- Run kernelInit (0x000230) for 2000 steps, then memInit (0x08479C) for 15000 steps
- Set IY=0xD00080 (OS base), set BIT 7 at (IY+0x18) = address 0xD00098: `cpu.mem[0xD00098] |= 0x80`
- Set A=0x03, PC=0x06004C (or the function entry if found in Part A)
- Run for **500 steps** (was 50 in session 214 — need 10x more)
- Track: every block visited, check IY+5 (0xD00085) at every step to see when/if BIT 4 gets set
- Report: full block trace, step where BIT 4 set, final register state
