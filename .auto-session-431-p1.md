# Task: Decode Init Priorities 2/4/5/6 (0x008BE9, 0x008F16, 0x008FC3, 0x00904C)

## Context

The TI-84 Plus CE OS has a sequential priority init chain at 0x009118 (108 bytes, decoded in session 430). It calls 7 initializers in order, stopping at the first that returns A=1:

- P1: CALL 0x0089F8 — USB init (fully decoded, 497 bytes)
- P2: CALL 0x008BE9 — **UNDECODED** ← decode this
- P3: CALL 0x008DA0 — Link init (known, calls 0x00CC71 with 0/1/300)
- P4: CALL 0x008F16 — **UNDECODED** ← decode this
- P5: CALL 0x008FC3 — **UNDECODED** ← decode this
- P6: CALL 0x00904C — **UNDECODED** ← decode this
- P7: CALL 0x009087 — unconditional fallback (separate task)

Each priority returns A=1 for success. The init chain checks CP 0x01 + JR Z after each call.

## What to do

For each of the 4 undecoded functions (0x008BE9, 0x008F16, 0x008FC3, 0x00904C):

1. Read the ROM bytes starting at the address using the ROM file at `TI-84_Plus_CE/ROM.rom`
2. Disassemble the eZ80 ADL-mode instructions manually or via a probe
3. Determine:
   - Function size (find the RET or terminal JP)
   - What CALL targets it invokes (especially: does it call 0x00CC71 like P1 and P3 do?)
   - What ports it reads/writes
   - What RAM addresses it accesses
   - What communication protocol it initializes (USB? Link? Bluetooth? Serial?)
   - Its return value semantics (A=1 success, A=0 failure?)

4. Write a probe script at `TI-84_Plus_CE/probe-phase431-trace-init-priorities.mjs` that:
   - Reads the ROM file
   - Extracts and hex-dumps the bytes for each function
   - Identifies CALL targets (bytes CD xx xx xx pattern) and JP targets (C3 xx xx xx)
   - Reports the size and structure of each function

5. Write a report at `TI-84_Plus_CE/phase431-init-priorities-report.md` documenting findings.

## eZ80 ADL mode notes

- Default word size is 24-bit (3-byte addresses, 3-byte immediates for LD rr,nn)
- CALL nn = CD xx xx xx (4 bytes), JP nn = C3 xx xx xx (4 bytes)
- LD A,(nn) = 3A xx xx xx (4 bytes), LD (nn),A = 32 xx xx xx (4 bytes)
- IN A,(C) = ED 78 (2 bytes, port in BC)
- OUT (C),A = ED 79 (2 bytes, port in BC)
- Prefix DD = IX, FD = IY operations
- Look for RET (C9) or terminal JP (C3) to find function boundaries
