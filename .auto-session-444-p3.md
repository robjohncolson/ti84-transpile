# Task: Map D02658 and D02651 (Timer ISR Countdown Targets)

## Context
The timer ISR at 0x001ACF decrements two RAM locations:
- **D02658** — 24-bit counter (accessed via BC register pairs)
- **D02651** — 8-bit counter

These are decremented by the timer interrupt service routine each time the timer fires. Session 443 traced the ISR path: 0x000038 → 0x0006F3 → 0x001ACF → acknowledges FTINTC byte0 bit4 via port 0x5008, decrements D02658 and D02651, then EI+RETI.

The question: what do these counters gate? When they reach zero, what happens? Are they OS tick counters, key repeat timers, cursor blink timers, or something else?

## What To Do
Create a probe `TI-84_Plus_CE/probe-phase444-trace-D02658-D02651.mjs` that:

1. Scans the ROM (ROM.rom, 4MB) for ALL references to D02658 and D02651:
   - Search for byte patterns that encode these addresses (little-endian: `58 26 D0` for D02658, `51 26 D0` for D02651)
   - For each match, record the ROM offset, the surrounding 10 bytes of context, and attempt a basic decode of the instruction

2. For each reference found, classify it as:
   - **Write** (LD (D02658), A / LD (D02658), BC / etc.)
   - **Read** (LD A, (D02658) / LD BC, (D02658) / etc.)
   - **Read-modify-write** (increment, decrement patterns)

3. Report the co-accessed RAM locations at each site. For each reference to D02658/D02651, read the surrounding 30 bytes and check if other D0xxxx RAM addresses appear nearby.

4. Also scan for references to the adjacent bytes:
   - D02659, D0265A (high bytes of the D02658 24-bit word)
   - D02652, D02653 (possible high bytes of D02651)
   - D02654-D02657 (gap between the two — what's there?)

5. Generate a report with:
   - Total reference count for each address
   - Read vs write breakdown
   - The functions containing each reference (look for surrounding RET/JP boundaries)
   - Co-access patterns (what other RAM addresses appear near each reference)
   - Hypothesis for what each counter controls

```js
#!/usr/bin/env node
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const romBytes = fs.readFileSync(path.join(__dirname, 'ROM.rom'));

function hex(v, w = 6) { return '0x' + (v >>> 0).toString(16).padStart(w, '0'); }

// Scan for 3-byte address patterns in little-endian
function scanForAddress(rom, addrLow, addrMid, addrHigh) {
  const results = [];
  for (let i = 0; i < rom.length - 2; i++) {
    if (rom[i] === addrLow && rom[i + 1] === addrMid && rom[i + 2] === addrHigh) {
      // Read context: 5 bytes before, 10 bytes after
      const start = Math.max(0, i - 5);
      const end = Math.min(rom.length, i + 13);
      const context = Array.from(rom.subarray(start, end)).map(b => b.toString(16).padStart(2, '0')).join(' ');
      results.push({ offset: i, contextStart: start, context });
    }
  }
  return results;
}

// Scan for D02658 (58 26 D0) and D02651 (51 26 D0)
const d02658Refs = scanForAddress(romBytes, 0x58, 0x26, 0xD0);
const d02651Refs = scanForAddress(romBytes, 0x51, 0x26, 0xD0);

```
