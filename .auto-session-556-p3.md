# Task: Decode 0x04E640 and 0x04E645 Callers

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). Session 550 identified functions at 0x04E640 and 0x04E645 but their callers were not decoded. This priority has been carried forward from session 550.

## Target
Find and decode all callers of 0x04E640 and 0x04E645.

### Step 1: Identify the functions at 0x04E640 and 0x04E645
Hex-dump 64 bytes starting at 0x04E640. Disassemble to find what these two entry points do. They are likely related functions (5-byte offset suggests a short prefix before the main entry).

eZ80 ADL mode key opcodes:
- CD xx xx xx = CALL imm24
- C3 xx xx xx = JP imm24
- C9 = RET
- ED 6F = LD (imm24),HL
- 3A xx xx xx = LD A,(imm24)
- 32 xx xx xx = LD (imm24),A
- FD CB dd bb = IY bit ops at displacement dd

### Step 2: Find all callers
Search the entire ROM (0x000000-0x3FFFFF) for:
- CALL 0x04E640 = CD 40 E6 04
- CALL 0x04E645 = CD 45 E6 04
- JP 0x04E640 = C3 40 E6 04
- JP 0x04E645 = C3 45 E6 04

### Step 3: Decode caller context
For each caller found, hex-dump 32 bytes before and 16 bytes after the CALL/JP instruction. This shows what registers are set up before the call and what the return value is used for.

### Step 4: Cross-reference with known functions
Check if any callers are in known regions:
- 0x045xxx-0x046xxx = expression parser/evaluator
- 0x04C9xx = math utility library
- 0x052Axx-0x0554xx = BPP/LCD cluster
- 0x06Cxxx-0x07Bxxx = rendering/cursor management
- 0x0A2xxx = text renderer

## Deliverables
Create `TI-84_Plus_CE/probe-phase556-callers-04E640.mjs` that:
1. Hex-dumps and disassembles 0x04E640-0x04E67F (64B)
2. Scans ROM for all CALL/JP references to both addresses
3. For each caller, prints address + 32B context before + 16B after
4. Summarizes: total callers per entry point, which known regions they're in
