# Task: Cross-reference Internal FPU Types 0x1B/0x1D/0x1E/0x1F

## Context
The TI-84 Plus CE ROM FPU uses a type transform system at 0x07FEB6 (dual-pass pipeline, 43B). Session 538 fully dumped the transform tables:

**Forward table at 0x07FE8A→0x07FE90 (6 entries)**:
- 0x21 (String alt) → 0x1B
- 0x20 (Equation alt) → 0x0C (Complex)
- 0x1C (Matrix alt) → 0x1B
- 0x18 (String variant) → 0x1D
- 0x00 (Real) → 0x1E
- 0x19 → 0x1F

**Reverse table at 0x07FE91→0x07FE8A (5 entries)**:
- 0x0C → 0x21, 0x1B → 0x20, 0x1D → 0x1C, 0x1E → 0x18, 0x1F → 0x00

Types 0x1B, 0x1D, 0x1E, 0x1F are internal intermediate types not in standard TI-OS documentation.

## Task
Write a probe script that searches the ROM (0x000000-0x3FFFFF) for all references to these 4 internal types (0x1B, 0x1D, 0x1E, 0x1F) in known FPU regions. Specifically:

1. Read the transpiled ROM and search for CP instructions (0xFE) followed by 0x1B, 0x1D, 0x1E, or 0x1F in these FPU regions:
   - 0x07C700-0x080300 (main FPU area)
   - 0x068600-0x069F00 (secondary FPU area)
   - 0x099000-0x099600 (FP validation area)

2. For each hit, report the address, the surrounding bytes (±5 bytes), and whether it appears to be a CP/LD/AND/OR instruction referencing the type.

3. Cross-reference against known decoded functions:
   - 0x07FEB6 (dual-pass pipeline)
   - 0x07FBD9 (conditional dispatch / BCD ADD)
   - 0x07DF66 (BCD division)
   - 0x07FEF5 (valid-type dispatch)
   - 0x07CA02 (OP1 sign toggle)
   - 0x0686A8 (type sub-dispatch)

4. Print a summary table: address, instruction, type value, function name (if known), and hypothesized meaning.
