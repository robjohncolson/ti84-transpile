### How to set keyMatrix for natural scan

The keyboard controller uses ports 0xA000-0xA01E. The scan routine writes a group-select mask to port 0xA000 (selecting which row to scan), then reads the key state from port 0xA008. The peripheral bus in `TI-84_Plus_CE/peripherals.js` has a `keyMatrix` array.

To simulate pressing a key at keyMatrix[N] bit B:
```javascript
peripherals.keyMatrix[N] |= (1 << B);
```

This must be set BEFORE the scan routine reads the keyboard port.

Reference: `TI-84_Plus_CE/probe-phase377-natural-keyboard.mjs` shows how ENTER was tested via natural scan.
