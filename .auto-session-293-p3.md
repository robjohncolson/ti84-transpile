# Task: Cross-Reference CP Values Across All 14 Dispatchers

## Context
Session 292 mapped 14 KEY_DISPATCH sites that read scan codes from D0058C (0xD0058C). Each site has a CP cascade comparing the scan code against specific values. The dispatchers and their CP values are:

- 0x088657: 14 CPs (0xFF/0xFE/0xFC/0xFB/0xFA/0xEF/0x69/0xF9/0xF3)
- 0x08C4E9: 14 CPs (0xEF/0xF9/0xF3/0x69/0x5B/0x28/0x29/0xBC/0xBD/0xC0)
- 0x0258DA: 10 CPs (0x09/0x05/0x04/0x03/0x40/0x02/0x28/0x21/0x01)
- 0x02659C: 10 CPs (0x40/0x05/0x02/0x03/0x04/0x09/0x21/0x0A/0x0C/0x0D)
- 0x0B630D: 12 CPs (arrow+MODE)
- 0x0A584C: 1 CP (0x54 only)
- 0x0B3733: 1 CP (0x4A only)
- Plus 7 more dispatchers (need to find from session 292 probe output)

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase293-cp-crossref.mjs` that:

1. First, read `TI-84_Plus_CE/probe-phase292-key-dispatch-cp-values.mjs` source to find ALL 14 dispatcher addresses and their CP value sets. If the probe doesn't hardcode them, run the probe or disassemble each dispatcher address from ROM to extract the CP values.

2. Build a unified map:
   - For each unique scan code value (CP operand), list which dispatcher(s) handle it and what branch target each dispatcher jumps to for that value
   - Sort by scan code value

3. Identify:
   - **Gaps**: scan code values from 0x00-0xFF that NO dispatcher handles
   - **Overlaps**: scan code values handled by MORE THAN ONE dispatcher
   - **Coverage**: how many unique scan codes are handled across all dispatchers combined

4. Cross-reference scan code values with the keyboard matrix. The file `TI-84_Plus_CE/keyboard-matrix.md` maps physical keys to scan codes. For each handled scan code, identify which physical key it corresponds to.

5. Print:
   - A table of all handled scan codes sorted by value: `scan_code | key_name | dispatcher(s) | handler_address(es)`
   - A summary: total unique scan codes handled, total gaps, total overlaps
   - List of overlapping scan codes with their multiple dispatchers
