# Auto-Session 354 — Priority 1: Trace Cycle Boundary (Find the Backward Branch)

## Context
The TI-84 Plus CE boot is stuck in an infinite LCD init loop. After 270 unique blocks are reached, execution cycles with a period of ~2174 steps. This loop repeats 23 times in 50K steps. The loop is NOT port-gated — ports 0x0009, 0xD018, 0xD00C, 0xD00D all pass their checks immediately. The backward branch is at the CALL/RET or JP/JR level in the code.

## Task
Create a probe `TI-84_Plus_CE/probe-phase354-cycle-boundary.mjs` that records the **full block sequence** over 2 complete cycles (~4400 steps, starting from step 5000 to skip initial setup) and identifies the repeating boundary.

Specifically:
1. Boot the CPU for 5000 steps (using the standard boot setup from existing probes)
2. Then record EVERY block transition for the next 5000 steps (block address at each step)
3. Find the repeating cycle by detecting when the same block sequence starts over
4. Output:
   - The cycle length in steps
   - The LAST block address of cycle N
   - The FIRST block address of cycle N+1
   - The transition point (last few blocks → first few blocks)
   - The full unique block sequence within one cycle

## Reference Files

- `TI-84_Plus_CE/cpu-runtime.js` — CPU runtime, use `createCPU()` and `cpu.step()`

## Setup Pattern (from existing probes)
```javascript
import fs from 'fs';
import { createCPU } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const rom = new Uint8Array(fs.readFileSync('./ROM.rom'));
const cpu = createCPU(rom);
const bus = createPeripheralBus({ timerInterrupt: false });
cpu.io = bus;
// Boot from address 0x000000
cpu.pc = 0x000000;
```

The CPU's `pc` property gives the current program counter. Each `cpu.step()` executes one instruction.

A "block" is identified by `(cpu.pc >>> 0)` at the start of each step (before execution). The block address is the PC value masked to the block's entry address — but for this probe, just recording raw PC values at each step is fine. The cycle boundary can be detected by finding a repeated subsequence of PCs.
