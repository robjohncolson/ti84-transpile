# Auto-Session 300 P3: Trace 0x015930-0x015960 (Scanner Wrapper)

## Context
In the TI-84 Plus CE ROM, the ISR entry at 0x001401 does `CALL NZ,0x015930` to conditionally invoke the keyboard scanner. Address 0x015930 is a wrapper function that eventually reaches 0x01598B where it does `LD IX,0x0159BD; CALL 0x000D7E` to copy the keyboard scanner to RAM and execute it.

We need to understand what 0x015930 does BEFORE reaching the copy-execute call at 0x01598B. This wrapper likely performs setup: state saving, stack bounds checking, flag testing, etc.

## Task
Write a probe `TI-84_Plus_CE/probe-phase300-scanner-wrapper.mjs` that:

1. **Disassemble 0x015930 through 0x01598B** — the complete wrapper function from entry to the known `LD IX` instruction. Print each instruction with address and mnemonic.

2. **Identify the purpose of each section**:
   - Register saves (PUSH instructions)
   - Flag/state checks (BIT tests, CP comparisons)
   - Conditional branches (JR/JP that might skip the scanner)
   - Any writes to OS state variables
   - The setup that feeds into the scanner

3. **Also disassemble 0x01598B through 0x0159BD** — from the LD IX to the parameter block, to confirm the copy-execute sequence.

4. **Check what happens AFTER the scanner returns** — after `CALL 0x000D7E` returns (the scanner ran in RAM and returned), what does the wrapper do? Continue disassembling past the CALL to find the cleanup/return path.

## How to disassemble
Read ROM bytes from `TI-84_Plus_CE/ROM.rom`. eZ80 ADL-mode instructions. Reference existing probes like `TI-84_Plus_CE/probe-phase299-000DB6-return-path.mjs` for disassembly approach.

Key eZ80 instruction encodings:
- `PUSH rr`: BC=C5, DE=D5, HL=E5, AF=F5, IX=DD E5
- `POP rr`: BC=C1, DE=D1, HL=E1, AF=F1, IX=DD E1
- `LD IX,imm24`: DD 21 xx xx xx
- `CALL imm24`: CD xx xx xx
- `JP imm24`: C3 xx xx xx
- `JR cc,offset`: 20/28/30/38 xx
- `BIT b,(HL)`: CB 46/4E/56/5E/66/6E/76/7E
- `RET`: C9
- `DI`: F3, `EI`: FB
