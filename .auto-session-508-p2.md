# Task: Trace D02032 Write Sites (What Activates Cursor Types?)

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian).

## Background
D02032 is the master gate controlling which cursor types get descriptors populated. Its bits 0/1/2 correspond to cursor types 0/1/2. The descriptor populator at 0x07D583 checks these bits before writing to D01EB1/D01EBA/D01EDE.

Finding all ROM sites that SET bits of D02032 reveals when and how cursor types get activated during OS initialization and the event loop.

## Task
Create a probe that searches the entire 4MB ROM for all instructions that write to D02032. Look for these byte patterns:

1. **LD (D02032),A** = `32 32 20 D0` (direct byte store)
2. **LD (D02032),HL** = `22 32 20 D0` (direct word store)
3. **SET n,(IY+offset)** where IY+offset resolves to D02032: IY base is D00080, so offset = 0x1FB2... this is too large for IY+d (max ±127). So IY-relative is unlikely.
4. **.SIS LD (0x2032),A** = `40 32 32 20` (MBASE-composed, high byte from MBASE=0xD0)
5. **.SIS LD (0x2032),HL** = `40 22 32 20`
6. **Any LDIR/LDDR** that could bulk-write the region — check for DE=D02032 setups nearby

Also search for reads of D02032:
7. **LD A,(D02032)** = `3A 32 20 D0`
8. **.SIS LD A,(0x2032)** = `40 3A 32 20`
9. **BIT n,(HL)** where HL=D02032 — look for LD HL,D02032 (`21 32 20 D0`) followed by BIT instructions

For each match:
- Print the ROM address
- Print surrounding context (~20 bytes before and after)
- Decode the instruction
- Identify the enclosing function (scan backward for common function prologues: PUSH AF/BC/DE/HL/IX/IY, DI, or a RET/JP that ends the previous function)

## Deliverable
Create file `TI-84_Plus_CE/probe-phase508-trace-D02032-writes.mjs` that:
- Reads ROM.rom
- Searches for all the byte patterns listed above
- For each match, prints address, context bytes, decoded instruction, and enclosing function estimate
- Summarizes: how many write sites, how many read sites, which functions touch D02032
