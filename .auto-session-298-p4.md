## eZ80 Decoder Reference
- eZ80 ADL mode: 24-bit addresses, 3-byte immediates
- IY prefix = FD. FD 77 dd = LD (IY+d),A. FD 7E dd = LD A,(IY+d)
- FD CB dd 46 = BIT 0,(IY+d)
- LD A,(imm24) = 3A lo mid hi. LD (imm24),A = 32 lo mid hi
- CALL imm24 = CD lo mid hi. JP imm24 = C3 lo mid hi
- LDIR = ED B0 (block copy). DJNZ = 10 dd (loop with B counter)
