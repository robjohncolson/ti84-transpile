# Task: Decode 0x03E9D4 — Extended Error Detail Handler

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). You need to decode the function at address 0x03E9D4 which is the "extended error detail" handler called conditionally from the error display init at 0x03EBB0.

From session 543: At the end of `0x03EBB0`:
- POP AF → BIT 6,(IY+66) → CALL NZ,0x03E9D4 → EI → RET
So 0x03E9D4 is called only when bit 6 of IY+66 (system flags byte at D00080+66=D000C2) is set. It presumably displays additional error detail beyond the basic error message.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase544-decode-03E9D4.mjs` that:
1. Reads the ROM binary
2. Uses `decodeInstruction` from `./ez80-decoder.js` to decode instructions starting at 0x03E9D4
3. Decodes up to 60 instructions or until hitting a RET that's clearly the function end
4. Prints each instruction with address, hex bytes, and assembly mnemonic
5. For any CALL targets or memory references, note what they might be (known: D005F8=OP1, D00603=OP2, D00596=display counter, D00813=error context, D0081C=error display type, D00080=IY base, 0x0A1B5B=char output, 0x0A1C8A=text output, 0x0A2A68=cursor, 0x0A1CEC=text draw, 0x0A22B1=screen refresh)
6. Searches for xrefs to 0x03E9D4 in the ROM (scan for CD D4 E9 03, also check for C4 D4 E9 03 = CALL NZ pattern)
7. The function is likely larger — if you hit sub-calls, list them but don't recurse

## Technical Details
- Import: `import { decodeInstruction } from './ez80-decoder.js';`
- ROM read: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');`
- Decoder call: `const inst = decodeInstruction(rom, address, 'adl');` — returns object with `.tag`, `.size`, and various fields
- Use `rom.slice(addr, addr + inst.size)` for hex bytes
- Third parameter is the string `'adl'` (NOT an integer)

## Constraints
- Do NOT modify any existing files
- Do NOT import `createEz80Decoder` — use `decodeInstruction` directly
- Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase544-decode-03E9D4.mjs`
- NEVER run the probe bare — always use the watchdog wrapper

## Success Criterion
The probe runs successfully and prints a complete instruction listing for 0x03E9D4, revealing what additional error detail it displays and under what conditions.
