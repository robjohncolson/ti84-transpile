# Task: Search ROM binary for instructions that store to D3FFxx range (dispatch table registration)

## Context
In the TI-84 Plus CE ROM transpilation project, the OS event loop uses a dispatch table at D3FFFF with 9-byte entries. Sessions 269-273 investigated how this table gets populated, but all dynamic traces show the table is empty (all zeros). We need to find the actual ROM code that writes dispatch table entries.

## Task
Create a probe `TI-84_Plus_CE/probe-phase274-d3ffxx-rom-scan.mjs` that:

1. Loads `TI-84_Plus_CE/ROM.rom` (4MB binary)
2. Scans the ROM for eZ80 instructions that encode stores to the D3F000-D3FFFF address range
3. eZ80 store instructions to look for:
   - `LD (nn),A` = opcode 0x32 followed by 3-byte address (little-endian) in D3Fxxx range
   - `LD (nn),HL` = opcode 0x22 followed by 3-byte address in D3Fxxx range
   - `LD (nn),rr` (16-bit register pairs) = ED opcodes (ED 43 = LD (nn),BC, ED 53 = LD (nn),DE, ED 63 = LD (nn),HL, ED 73 = LD (nn),SP)
   - `LD (nn),IX` = DD 22 followed by 3-byte address
   - `LD (nn),IY` = FD 22 followed by 3-byte address
   - Also check for `LDIR` / `LDDR` instructions (ED B0 / ED B8) near code that loads DE with D3Fxxx addresses
   - `LD (HL),r` or `LD (IX+d),r` where HL or IX might point to D3Fxxx — these are indirect and harder to find statically, but look for `LD HL,0xD3Fxxx` (opcode 0x21 followed by 3-byte addr) near memory stores
4. For each match, report:
   - ROM offset (hex)
   - The instruction bytes
   - Decoded instruction
   - Surrounding context (16 bytes before and after)

## eZ80 Address Encoding
In eZ80 ADL mode, addresses are 3 bytes little-endian. So D3FFFF = bytes FF FF D3. D3F000 = bytes 00 F0 D3. Look for any 3-byte sequence where byte[2]=0xD3 and byte[1] >= 0xF0.

## Key Byte Patterns to Search
- `32 xx Fx D3` — LD (D3Fxxx),A
- `22 xx Fx D3` — LD (D3Fxxx),HL
- `ED 43 xx Fx D3` — LD (D3Fxxx),BC
- `ED 53 xx Fx D3` — LD (D3Fxxx),DE
- `ED 63 xx Fx D3` — LD (D3Fxxx),HL (ED prefix form)
- `ED 73 xx Fx D3` — LD (D3Fxxx),SP
- `DD 22 xx Fx D3` — LD (D3Fxxx),IX
- `FD 22 xx Fx D3` — LD (D3Fxxx),IY
- `21 xx Fx D3` — LD HL,D3Fxxx (loads pointer, may be followed by store via (HL))

Also scan for the broader D3xxxx range (byte[2]=0xD3) to catch any stores to the dispatch table region.
