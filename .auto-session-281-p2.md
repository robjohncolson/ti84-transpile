# Task: Trace 0x09E296 — STAT CALC Post-Init Function

## Context
In the TI-84 Plus CE OS ROM, the STAT dispatcher at 0x040BE4 has two main paths:
- bit 0 CLEAR → JP 0x09E0D9 (STAT EDIT menu)
- bit 0 SET + bit 1 CLEAR → JP 0x09E0A1 (STAT CALC menu)

The 0x09E0A1 (STAT CALC) path calls 0x09EDC3 (shared UI init), and AFTER that calls 0x09E296. We need to know what 0x09E296 does — it's STAT CALC-specific setup.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase281-09e296-trace.mjs` that:

1. **Static disassembly** of 0x09E296 from the ROM binary — decode eZ80 instructions until RET or unconditional JP (max 256 bytes). Use a manual disassembler (byte-by-byte opcode decode). Cover at minimum: LD, CALL, JP, JR, RET, PUSH, POP, BIT/SET/RES, CP, AND, OR, XOR, ADD, SUB, INC, DEC, DI, EI, NOP, RST, EX, LDIR, LDDR, HALT.

2. **Dynamic trace** — set up the CPU executor with:
   - Timer interrupts disabled: `createPeripheralBus({ timerInterrupt: false })`
   - PC = 0x09E296, SP = 0xD1A87E
   - IY = 0xD00080 (OS flags base)
   - Run for 500 steps max
   - Track: all RAM writes (addr >= 0xD00000), all CALL targets, all JP targets
   - Stop on RET back to initial SP level

3. **Caller scan** — search ROM for CALL/JP 0x09E296 (bytes CD 96 E2 09 and C3 96 E2 09)

4. Output: disassembly listing, dynamic trace summary, RAM writes, caller list
