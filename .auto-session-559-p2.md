# Task: Decode 0x0A2032 — Line Wrap / Column Reset Handler

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80). We're decoding OS functions to understand the text rendering pipeline.

**Call chain**: 0x0A1B5B (per-char dispatch) calls 0x0A2032 in two cases:
1. When the special char 0xD6 is detected (after 0x0A22B1)
2. When column counter D00596 reaches 26 (CALL NC,0x0A2032 — column overflow/line wrap)

This function handles either resetting the column counter and advancing to the next line, or scrolling the screen.

## Known architecture
- D00596 = column counter (incremented per char in 0x0A1B5B)
- D00595 = current column position
- D02505 = column limit
- D0231A = cursor position
- D0231D = cursor state
- D008D5 = primary Y coordinate
- D014FE = cursor Y (43 refs, 1 write, feeds into Y conversion at 0x06CBE5)
- IY base = D00080
- IY+0x2D = font size (used in scroll module 0x05AD)
- Scroll module at 0x05AD uses 7× cursor Y conversion

## Deliverable
Create `TI-84_Plus_CE/probe-phase559-decode-0A2032.mjs` that:
1. Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
2. Disassembles starting at 0x0A2032 for up to 200 bytes (or until RET found)
3. Documents each instruction with comments
4. Identifies: how it resets column counter, whether it advances Y/row, whether it calls the scroll module, what RAM it writes
5. Prints a structured summary

## Probe structure
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Disassemble from 0x0A2032, decode eZ80 instructions
// Look for: writes to D00596 (column reset), changes to D008D5/D0231A (Y advance),
// CALL to scroll-related addresses (0x05ADxx range), IY+0x2D references
```

Use eZ80 instruction set (24-bit addresses). Key opcodes: ED=extended, DD/FD=IX/IY, CB=bit ops. Addresses are 3-byte little-endian.
