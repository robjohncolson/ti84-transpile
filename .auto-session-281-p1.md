# Task: Categorize FindSym (0x0846EA) Callers by OS Subsystem

## Context
FindSym at 0x0846EA is the TI-OS Variable Allocation Table (VAT) lookup function. Session 275 discovered it has 235 ADL callers in the ROM. We need to categorize these callers by which OS subsystem they belong to, to understand which parts of the OS depend on VAT lookup.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase281-findsym-callers.mjs` that:

1. Scans the ROM binary (`TI-84_Plus_CE/ROM.rom`) for all CALL/JP instructions targeting 0x0846EA
2. For each caller address, determines which OS subsystem it belongs to by checking:
   - Is it in the STAT range (0x09DD00-0x09F000, 0x040B00-0x040D00)?
   - Is it in the graph range (0x04E000-0x055000)?
   - Is it in the home-screen/edit range (0x057000-0x05A000)?
   - Is it in the link/USB range (0x06A000-0x070000)?
   - Is it in the Y= editor range (0x09A000-0x09D000)?
   - Is it in the table range (0x096000-0x09A000)?
   - Is it in the program editor range (0x060000-0x065000)?
   - Is it near other known functions (list them)?
3. Outputs a summary table: subsystem, count, example addresses
4. Lists any callers that don't fit known ranges as "unclassified"

## Technical details
- eZ80 ADL CALL instruction: `0xCD LL MM HH` (little-endian 24-bit target) — search for bytes CD EA 46 08
- eZ80 ADL JP instruction: `0xC3 LL MM HH` — search for bytes C3 EA 46 08
- The ROM file is at `TI-84_Plus_CE/ROM.rom`, 4MB
- Use the probe pattern from existing probes (import cpu-runtime.js, peripherals.js)
- Output results with console.log
