### Reference: BCD float format
```
OP1[0]: bit 7 = sign (0=positive, 0x80=negative), bits 0-4 = type (0=real)
OP1[1]: exponent (biased by 0x80, so 0x80 = 10^0, 0x81 = 10^1, etc.)
OP1[2..8]: BCD mantissa, 2 digits per byte
Example: 5.0 = [0x00, 0x80, 0x50, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00]
Example: 12.0 = [0x00, 0x81, 0x12, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00]
```
