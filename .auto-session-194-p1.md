# Session 194 P1 — Y= Editor CALL Target Exploration

## Task
Build a probe `TI-84_Plus_CE/probe-phase194-yeq-call-targets.mjs` that traces the three CALL targets found inside the Y= editor entry at 0x09CB14:
- **0x0A2B72** — likely Y= variable display/rendering
- **0x05E27E** — likely edit buffer operation
- **0x0A1B59** — likely screen update

Also try direct entry at **0x09CB1A** (skips the JR loop to 0x09CB08).

## Context
Session 193 proved direct entry at 0x09CB14 works: 77 blocks, 3 Y= editor blocks visited (0x09CB14, 0x09CB18, 0x09CB08), returns cleanly via RET at 0x09CB27. Static disassembly:
```
0x09CB14: CALL 0x0A2B72
0x09CB17: JR -18       → jumps to 0x09CB08
0x09CB08: CALL 0x05E27E
0x09CB0B: LD HL,0xD00596
0x09CB0E: DEC (HL)
0x09CB0F: CALL 0x0A1B59
0x09CB12: RET
```

## What to build
Use `probe-phase193-yeq-extended.mjs` as the template (same boilerplate: boot, kernel init, mem init, resetCpuForOsCall, etc).

### Experiment A: Trace 0x0A2B72 standalone
- resetCpuForOsCall, set IX=0xD1A860, IY=0xD00080, MBASE=0xD0
- Push return sentinel 0x7FFFFE onto stack
- Execute from 0x0A2B72 in ADL mode, max 3000 steps
- Log: unique blocks visited, any in Y= range (0x09C000-0x09D000), final registers, RAM writes to 0xD005xx-0xD006xx area
- Sentinel watch: 0x7FFFFE (return) and 0x000000 (boot crash)

### Experiment B: Trace 0x05E27E standalone
- Same setup as A but entry at 0x05E27E
- Same logging

### Experiment C: Trace 0x0A1B59 standalone
- Same setup as A but entry at 0x0A1B59
- Same logging

### Experiment D: Direct entry at 0x09CB1A (skip JR loop)
- resetCpuForOsCall, push sentinel, enter at 0x09CB1A in ADL mode, max 3000 steps
- This should execute: CALL 0x05E27E, LD HL,0xD00596, DEC (HL), CALL 0x0A1B59, RET
- Log unique blocks, registers, any writes to VRAM (0xD40000-0xD52C00)

### Output format
Print JSON-structured results for each experiment:
```
{ experiment: "A", entry: "0x0A2B72", blocks: N, yeqBlocks: [...], steps: N, termination: "...", finalRegs: {...}, ramWrites: [...] }
```

## Files

## Constraints
- Do NOT modify any existing files. Create only `probe-phase194-yeq-call-targets.mjs`.
- Timer interrupt MUST be disabled: `createPeripheralBus({ timerInterrupt: false })`
- Use segmented execution with 2000-step segments to avoid infinite loops.
- Max loop iterations: 8192

## Success criterion
Probe runs without crash, prints structured results for all 4 experiments. We learn what each CALL target does (which blocks it visits, whether it touches VRAM, whether it returns cleanly).
