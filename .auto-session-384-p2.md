# Task: Find who calls 0x0300CB in the ROM

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). The transpiler is at `scripts/transpile-ti84-rom.mjs`.

Session 383 identified 0x0300CB as the parent function of the translation table lookup at 0x03010D. The event loop key dispatch (0x003A7D→0x001713→0x001853→0x0158DE) does NOT reach 0x0300CB. We need to find which OS context calls it.

## What to do

Write a Node.js probe script at `TI-84_Plus_CE/probe-phase384-callers-0300CB.mjs` that:

1. Reads the raw ROM file at `TI-84_Plus_CE/ROM.rom` (4,194,304 bytes)
2. Scans the ENTIRE ROM for eZ80 instructions that target 0x0300CB:
   - **CALL 0x0300CB** (ADL mode): opcode `CD CB 00 03` (little-endian 24-bit address)
   - **JP 0x0300CB** (ADL mode): opcode `C3 CB 00 03`
   - **CALL cc, 0x0300CB** variants: `C4/CC/D4/DC/E4/EC/F4/FC` followed by `CB 00 03`
   - **JP cc, 0x0300CB** variants: `C2/CA/D2/DA/E2/EA/F2/FA` followed by `CB 00 03`
   - Also search for nearby addresses: 0x0300A1, 0x0300A0, 0x0300CC, 0x0300CD (in case the call targets a slightly different entry)
3. For each match found, report:
   - The ROM offset where the instruction starts
   - The full instruction bytes
   - The instruction mnemonic
   - Context: what function region it's in (check if there's a known seed or transpiled block nearby)

4. Also search for **indirect call patterns**: the ROM uses jump tables and RST dispatches. Search for the 3-byte sequence `CB 00 03` anywhere in ROM (this could be a table entry pointing to 0x0300CB).

5. Run the script with `node TI-84_Plus_CE/probe-phase384-callers-0300CB.mjs` and capture the output.

## eZ80 encoding reference
- eZ80 is little-endian for addresses
- ADL-mode CALL nn = CD xx xx xx (3-byte address)
- ADL-mode JP nn = C3 xx xx xx (3-byte address)
- Conditional CALL cc,nn = C4/CC/D4/DC/E4/EC/F4/FC xx xx xx
- Conditional JP cc,nn = C2/CA/D2/DA/E2/EA/F2/FA xx xx xx
