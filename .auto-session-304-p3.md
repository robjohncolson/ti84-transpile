# Auto-Session 304 P3: Map Token Descriptor Table at 0xD0227E

## Context
This is a TI-84 Plus CE ROM (eZ80) reverse-engineering project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB). We use `TI-84_Plus_CE/ez80-decoder.js` to decode eZ80 instructions.

Session 303 found that 0x022331 is a token dispatch function that writes entries via 0x0236F9 (token buffer writer). The token descriptor table is at **0xD0227E** with **18 bytes per entry**, indexed by a type value.

BUT WAIT — 0xD0xxxx is RAM, not ROM. So the table at 0xD0227E is populated at runtime. We need to find what CODE populates this table.

The question: **What populates the token descriptor table at 0xD0227E, what is the entry structure (18 bytes), and how many entries exist?**

## Task
Write a probe script at `TI-84_Plus_CE/probe-phase304-token-desc-table.mjs` that:

1. Searches the ROM for instructions that reference 0xD0227E (or nearby addresses 0xD02270-0xD022A0). Use a byte-pattern scan: look for the 3-byte little-endian encoding `7E 22 D0` in the ROM.
2. For each reference found, disassemble ~20 instructions around it to understand whether it's a read or write, and what the surrounding code does.
3. Also searches for references to 0x022331 (the token dispatch function that uses this table) — byte pattern `31 23 02` — to find callers.
4. Check if 0x022331 is actually in ROM (not RAM) — if so, disassemble it (~100 instructions) to see how it indexes the table.
5. Outputs: all ROM references to the table address, the indexing arithmetic, the entry structure (which bytes mean what), and how many entries the code expects.

## Reference: How probes work
```javascript
#!/usr/bin/env node
import { readFileSync } from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { decodeInstruction } from './ez80-decoder.js';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const rom = readFileSync(path.join(__dirname, 'ROM.rom'));

// Byte-pattern scan example:
function findBytes(pattern, startAddr = 0, endAddr = 0x400000) {
  const results = [];
  for (let i = startAddr; i < endAddr - pattern.length; i++) {
    let match = true;
    for (let j = 0; j < pattern.length; j++) {
      if (rom[i + j] !== pattern[j]) { match = false; break; }
    }
    if (match) results.push(i);
  }
  return results;
}

function disasmRange(startAddr, maxInstructions) {
  let pc = startAddr;
  const results = [];
  for (let i = 0; i < maxInstructions; i++) {
    const inst = decodeInstruction(rom, pc);
    results.push({ addr: pc, ...inst });
    if (inst.mnemonic === 'RET' && !inst.condCode) break;
    if (inst.mnemonic === 'JP' && !inst.condCode && inst.operands && !inst.operands.includes('(')) break;
    pc += inst.length;
  }
  return results;
}
```

`decodeInstruction(buffer, offset)` returns `{ mnemonic, operands, length }`. ROM loaded raw, file offset = address for addresses < 0x400000.
