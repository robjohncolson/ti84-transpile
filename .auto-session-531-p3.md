# Task: Decode 0x07C9AF — Post-Normalize Dispatch

## Context
You are working on TI-84 Plus CE ROM transpilation. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). You decode functions by reading raw ROM bytes and disassembling eZ80 instructions.

## Target

- Called from 0x069CCE BCD division epilogue (session 528): `CALL 0x07C9AF` appears twice
- Called from 0x07D32A (phase 4 of 0x07D27B matrix/list handler, session 530)
- Called from 0x07C8B7 BCD multiplication epilogue (session 530): `JR 0x07C9E1` flows into this area

Session 528 partially decoded it as: "BIT 3,(IY+72); RET NZ — IY flag check, then continues." But the full function body past the initial flag check has not been decoded.

- OP2: D00603 (type), D00604 (exponent), D00605 (mantissa start)

## How to Read ROM Bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const byte = rom[addr];
// 16-bit LE: rom[addr] | (rom[addr+1] << 8)
// 24-bit LE: rom[addr] | (rom[addr+1] << 8) | (rom[addr+2] << 16)
```

## eZ80 Decoding Reference
- `3A xx xx xx` = LD A,(addr24)  [4 bytes]
- `32 xx xx xx` = LD (addr24),A  [4 bytes]
- `CD xx xx xx` = CALL addr24    [4 bytes]
- `C3 xx xx xx` = JP addr24      [4 bytes]
- `C9` = RET, `D8` = RET C, `C0` = RET NZ, `C8` = RET Z, `D0` = RET NC
- `18 dd` = JR dd, `20 dd` = JR NZ, `28 dd` = JR Z, `38 dd` = JR C, `30 dd` = JR NC
- `FE xx` = CP xx, `E6 xx` = AND xx, `F6 xx` = OR xx, `EE xx` = XOR xx
- `FD CB dd xx` = IY+dd bit operations (4 bytes)
  - BIT: xx = 0x46 + 8*bit, SET: xx = 0xC6 + 8*bit, RES: xx = 0x86 + 8*bit
- `ED 6F` = RLD, `ED 67` = RRD
- `D6 xx` = SUB xx, `C6 xx` = ADD A,xx
- `CB xx` = bit ops on registers
- `AF` = XOR A (set A=0)
- `B7` = OR A (test A for zero, clear carry)
- `21 xx xx xx` = LD HL,addr24 [4 bytes in eZ80 ADL mode]
- `11 xx xx xx` = LD DE,addr24 [4 bytes in eZ80 ADL mode]
- `01 xx xx xx` = LD BC,addr24 [4 bytes in eZ80 ADL mode]

## Probe Template

```javascript
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function hex(n, w=2) { return n.toString(16).toUpperCase().padStart(w, '0'); }
function rom8(a) { return rom[a]; }
function rom16(a) { return rom[a] | (rom[a+1] << 8); }
function rom24(a) { return rom[a] | (rom[a+1] << 8) | (rom[a+2] << 16); }

const START = 0x07C9AF;
const LEN = 200;

console.log(`=== Decoding 0x${hex(START,6)} (${LEN} bytes) ===`);
let pc = START;
while (pc < START + LEN) {
    const startPc = pc;
    const b0 = rom8(pc);
    let mnemonic = '';
    let bytes = [b0];
    pc++;
    
    // Implement decoder for each opcode pattern
    // Handle prefixes: ED, CB, DD, FD
    // Handle 24-bit addresses for CALL, JP, LD rr,nn
    
    const hexStr = bytes.map(b => hex(b)).join(' ');
    console.log(`0x${hex(startPc,6)}: ${hexStr.padEnd(24)} ${mnemonic}`);
    
    if (b0 === 0xC9 || (b0 === 0xC3 && startPc > START + 20)) {
        console.log('--- potential boundary ---');
    }
}
```
