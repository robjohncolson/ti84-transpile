## Background

- Session 600 found VRAM peaks at 3,349 px (non-white) around step 270K during key1.
- Session 606 tried VRAM peak capture but 5000-step sampling was too coarse and missed the transient peak.
- Session 604 found VRAM at D40000+ is NOT zeroed by the 0x0018F8 wipe (the wipe only covers D00000-D13FD7).
- VRAM is 16-bit 565 RGB format, 320×240 pixels, base 0xD40000, size 153,600 bytes.
- "Non-white" = pixel word != 0xFFFF.

**Sampling approach**: Since onBlock fires per-block (not per-step), use the `steps` field if available from the result, OR count onBlock invocations as an approximation. Sample by checking a counter and sampling every Nth onBlock call:

```javascript
let blockCount = 0;
let samples = [];
let peakPixels = 0;
let peakStep = 0;

onBlock(pc) {
  blockCount++;
  if (blockCount % 200 === 0) { // sample every 200 blocks ≈ every 1000-2000 steps
    const px = countVRAM(mem);
    samples.push({ block: blockCount, px });
    if (px > peakPixels) {
      peakPixels = px;
      peakStep = blockCount;
    }
  }
}
```

5. After finding peak, do a SECOND run that stops at peak and dumps VRAM:
   - Re-boot, re-init, re-paint, re-press key
   - Run with onBlock that stops (via a flag + early return or throw) at the peak block count

   - Also dump rows 0-30 (status bar) and rows 35-140 (body text area) in the same format

## VRAM counting
```javascript
function countNonWhite(mem) {
  const base = 0xD40000;
  let count = 0;
  for (let i = 0; i < 320 * 240; i++) {
    const word = mem[base + i * 2] | (mem[base + i * 2 + 1] << 8);
    if (word !== 0xFFFF) count++;
  }
  return count;
}
```

## VRAM text render
```javascript
function renderVramText(mem, startRow, endRow) {
  const base = 0xD40000;
  const lines = [];
  for (let row = startRow; row < endRow; row++) {
    let line = '';
    for (let col = 0; col < 320; col += 2) {
      const idx = (row * 320 + col) * 2;
      const word = mem[base + idx] | (mem[base + idx + 1] << 8);
      line += (word === 0xFFFF) ? '.' : '#';
    }
    lines.push(`row ${String(row).padStart(3)}: ${line}`);
  }
  return lines.join('\n');
}
```
