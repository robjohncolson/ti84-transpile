- The 3-byte value currently stored at 0xD18C22 is `00 00 00`, which decodes to 0x000000.
- Because that value is inside ROM space and the bytes do not look like a simple ROM pointer, 0xD18C22 is best classified as **zero-filled RAM slot (unlikely to be valid code or a live callback)**, not a callback slot or a function-pointer table.
