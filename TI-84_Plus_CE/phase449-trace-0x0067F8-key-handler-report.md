### Known issue: .SIL prefix in transpiler

0x0008BB uses `.SIL SBC HL, BC` to check ROM magic at 0x020100.
The transpiled code performs 24-bit SBC instead of 16-bit.
This works when boot fully initializes (value at 0x020100 loads
correctly), but is technically incorrect and may fail in some
boot sequences. The `.SIL` prefix bug should still be fixed.
