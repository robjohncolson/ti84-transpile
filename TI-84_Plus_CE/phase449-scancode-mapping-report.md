## Formula Reconstruction

1. `0x003D36: LD A, H` copies the OS group counter into `A`.
2. `0x003D37: DEC A` converts that to `A = os_group - 1`.
3. `0x003D3D-0x003D3F: RLA` three times multiplies by 8, so `A = (os_group - 1) * 8`.
4. `0x003D40-0x003D43: INC A ; RR L ; JR NC, 0x003D40` increments `A` once per rotated bit until the pressed bit reaches carry.
5. For a key at bit position `bit`, that loop contributes `bit + 1`, so the stored value is `scan_code = (os_group - 1) * 8 + bit + 1`.
6. `0x003D4B: LD (0xD00587), A` stores that OS scan code.
7. `keyboard-matrix.md` documents `keyMatrix[idx] = SDK Group(7 - idx)`, so `os_group = 7 - idx`.

Therefore the OS formula is:

```text
scan_code = ((7 - idx) - 1) * 8 + bit + 1
          = (6 - idx) * 8 + bit + 1
```

The probe formula currently used by `probe-workflow-arithmetic.mjs` is different:

```text
scan_code = (idx << 4) | bit
```

## Workflow Probe Fix

The current values in `probe-workflow-arithmetic.mjs` are wrong for `_GetCSC` / OS scan-code injection.

- `KEY_ONE` should be `0x12`, not `0x41`.
- `KEY_PLUS` should be `0x2A`, not `0x11`.
- `KEY_ENTER` should be `0x29`, not `0x10`.
