# Task: Trace 0x03FA09 (Key Processor Function)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

Session 445 discovered the key flow path: keyboard ISR scans via 0x003CC2 → raw scan code at D00587 → **key processor at 0x03FA09** → processed key at D141B5 → 0x05D58F table dispatch. The key processor 0x03FA09 has 8 callers across mode handlers. It converts raw scan codes to processed keys.

The ONLY instruction that writes a real key code to D141B5 is: `LD (D141B5),A` at 0x03FBE1.

## Task
Disassemble and decode the function at **0x03FA09** in the ROM. Create a trace report.

### How to disassemble
Read raw bytes from `TI-84_Plus_CE/ROM.rom` using Node.js:

```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
// Read bytes starting at offset 0x03FA09
// eZ80 ADL mode instructions (24-bit addresses):
//   CALL nn = 0xCD lo mid hi (4 bytes)
//   JP nn = 0xC3 lo mid hi
//   RET = 0xC9
//   LD A,(nn) = 0x3A lo mid hi (4 bytes)
//   LD (nn),A = 0x32 lo mid hi (4 bytes)
```

Also trace from 0x03FBE1 to confirm the `LD (D141B5),A` instruction.

### Deliverables
Create file `TI-84_Plus_CE/phase446-trace-03FA09-report.md` with:
1. Full disassembly of 0x03FA09 (at least 500 bytes — this function reaches at least 0x03FBE1)
2. All CALL targets
3. Where does it read D00587 (raw scan code)?
4. What transformation does it apply to convert scan code → key code?
5. Confirm the write to D141B5 at 0x03FBE1
6. What are the 8 callers? (Search the ROM for CALL 0x03FA09 patterns: bytes CD 09 FA 03)
7. Does it reference 0x05D58F (table dispatch) or D1441D (handler table pointer)?
8. Function size

### Constraints
- Do NOT modify `cpu-runtime.js`, `peripherals.js`, `browser-shell.html`, or any probe file
- Do NOT run the transpiler or any probes
- Output is a markdown report only

### Success criterion
The report maps the full transformation from D00587 (raw scan code) → D141B5 (processed key), showing what lookup tables or arithmetic the key processor uses.
