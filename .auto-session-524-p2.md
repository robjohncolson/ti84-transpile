# Task: Decode 0x08021B — Main Type-Init Operation

## Context
This is a TI-84 Plus CE OS ROM (eZ80 ADL mode) disassembly task. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, little-endian eZ80). All addresses are 24-bit. The CPU runs in ADL mode (24-bit registers, 3-byte addresses) unless `.SIS` prefix (0x40) forces 16-bit operand/address for that instruction.

## Target
Disassemble and document the function at ROM address **0x08021B**. This function is the MAIN OPERATION called by 0x0987B5/0x0987B7 (type-specific initializer). The calling code does:
```
CALL 0x0997AE  ; pre-setup
POP BC
CALL 0x08021B  ; <-- THIS FUNCTION — main operation
; carry flag = failure → secondary dispatch
; no carry = success → stack frame + further calls
```

The carry flag on return determines success/failure of the entire type initialization. This is a critical system function.

## How to read the ROM
```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');

function readBytes(addr, len) {
  return Array.from(rom.slice(addr, addr + len))
    .map(b => b.toString(16).padStart(2, '0')).join(' ');
}

// Read 512 bytes starting at the target (this may be a larger function)
console.log(readBytes(0x08021B, 512));
```

## eZ80 Decoding Notes
- Default mode is ADL (24-bit). Immediate addresses are 3 bytes little-endian.
- Prefix 0xDD = IX register variants, 0xFD = IY register variants
- Prefix 0x40 = .SIS (force 16-bit mode for next instruction)
- CALL = 0xCD + 3-byte addr (LE). JP = 0xC3 + 3-byte addr. JR = relative jump (signed byte).
- RET = 0xC9. Conditional RET: C0/C8/D0/D8/E0/E8/F0/F8.
- LD A,(addr) = 0x3A + 3-byte addr. LD (addr),A = 0x32 + 3-byte addr.
- LD HL,(addr) = 0x2A + 3-byte addr (ADL). LD (addr),HL = 0x22 + 3-byte addr.
- CP imm8 = 0xFE + byte. OR A = 0xB7. XOR A = 0xAF. SCF = 0x37. CCF = 0x3F.
- PUSH/POP: BC=C5/C1, DE=D5/D1, HL=E5/E1, AF=F5/F1, IX=DD E5/DD E1.
- BIT n,(IY+d) = FD CB dd 46+8*n. SET n,(IY+d) = FD CB dd C6+8*n. RES n,(IY+d) = FD CB dd 86+8*n.
- SBC HL,rr: ED 42(BC)/52(DE)/62(HL)/72(SP).
- ADD HL,rr: 09(BC)/19(DE)/29(HL)/39(SP).
