# Task: Map all writers of D000C6 bit 2 (LCD write-enable flag)

## Context
You are working on a TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

Session 247 discovered that function 0x02672F (LCD column/row drawing) writes ZERO VRAM bytes because all writes are gated by `BIT 2,(D000C6)` at address 0x08C308. D000C6 bit 2 is CLEAR at boot, blocking all LCD writes. We need to find what sets this bit during normal OS operation.

## Task
Write a probe script `TI-84_Plus_CE/probe-phase248-d000c6-writers.mjs` that:

1. **Static ROM scan**: Search the 4MB ROM binary (`TI-84_Plus_CE/ROM.rom`) for all instructions that reference address 0xD000C6. Look for:
   - `LD A,(0xD000C6)` = bytes `3A C6 00 D0` (3-byte address in little-endian)
   - `LD (0xD000C6),A` = bytes `32 C6 00 D0`
   - `SET n,(HL)` where HL=0xD000C6 (indirect — search for `LD HL,0xD000C6` = `21 C6 00 D0` then look for nearby SET/RES/BIT)
   - `BIT 2,(HL)` patterns near HL loads of 0xD000C6
   - Any `SET 2` or `RES 2` instruction within 20 bytes of an HL load of 0xD000C6
   
2. **Classify each reference**: For each match, output the ROM address, instruction type (READ/WRITE/BIT-TEST/SET/RES/POINTER), and surrounding context (preceding 8 bytes decoded if possible).

3. **Dynamic trace of BIT 2 SET sites**: For any site that SETs bit 2, run a short trace (200 steps) starting from 16 bytes before the SET instruction to understand the calling context.

4. **Check boot state**: Verify D000C6 = 0x00 after full boot sequence.
