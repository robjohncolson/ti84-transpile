# Task: Identify the two shared _seqcase epilogues

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

`_seqcase` is the ZDS II compiler's switch-case dispatch mechanism. Session 315 analyzed 356 unique jump targets across 563 table entries from 83 call sites. Two addresses were identified as "shared epilogues" — convergence points where multiple _seqcase tables route their cases:

- **0x049CC2** — used by 7 different _seqcase tables
- **0x008834** — used by 5 different _seqcase tables

The question is: what do these epilogues do? Are they simple function return stubs (clean up stack and RET), or do they branch to further processing?

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase316-seqcase-epilogues.mjs` and a report `TI-84_Plus_CE/phase316-seqcase-epilogues-report.md`.

The probe should:
1. Read `TI-84_Plus_CE/ROM.rom`
2. Disassemble 64 bytes starting at 0x049CC2. This should reveal the full epilogue code.
3. Disassemble 64 bytes starting at 0x008834. Same purpose.
4. For each epilogue, determine:
   - Does it end with RET (0xC9)? If so, it's a return stub.
   - Does it JP somewhere else? If so, where?
   - Does it modify any registers or RAM before returning?
   - Does it POP registers (stack cleanup)?
   - Is there a pattern like: LD A,imm / POP IX / RET (common ZDS II function epilogue)?
5. Find all references to each epilogue in the full ROM:
   - Search for JP 0x049CC2 (C3 C2 9C 04) and CALL 0x049CC2 (CD C2 9C 04)
   - Search for JP 0x008834 (C3 34 88 00) and CALL 0x008834 (CD 34 88 00)
   - Also check if either address appears in _seqcase jump tables (as 3-byte little-endian entries)
6. For the _seqcase tables that use these epilogues, identify which functions contain those tables (find the CALL _seqcase = CD xx xx 00 where _seqcase is at some known address, closest before each table).

The report should:
- Show the disassembly of both epilogues
- Classify each: return stub, branch-to-processing, error handler, default handler, etc.
- List all callers/references beyond the _seqcase tables
- Explain why 7 and 5 different switch-case blocks converge on these specific addresses

## Technical details
- eZ80 ADL mode, little-endian
- _seqcase is called via CALL 0x00224E (CD 4E 22 00) — inline table follows the CALL
- _seqcase table format: [u16 count][u24 base][count×u24 targets][u24 default]
- Jump targets in tables are 3-byte absolute addresses, little-endian
- RET = C9, JP nn = C3 lo mid hi, CALL nn = CD lo mid hi
- POP IX = DD E1, POP IY = FD E1
- LD A,imm8 = 3E nn
- Common ZDS II epilogue: POP IX / RET or LD SP,IX / POP IX / RET
