# Task: Add 20 Seeds to the Transpiler

## Context
Every auto-session adds seeds to increase ROM coverage. Current state: 145,162 transpiled blocks, 709,823 covered bytes. Coverage is ~95.92%.

## Deliverables
Add 20 new seed addresses to `scripts/transpile-ti84-rom.mjs` in the `seeds` array. Then regenerate `TI-84_Plus_CE/ROM.transpiled.js` and verify the golden regression still passes.

## How to Find Seeds
1. Run `node TI-84_Plus_CE/coverage-analyzer.mjs` to identify uncovered gaps
2. Run `node TI-84_Plus_CE/audit-true-uncovered.mjs` to get the true-uncovered byte list
3. Look at the gap analysis output for addresses that are likely code entry points (not data tables)
4. Good seed heuristics:
   - Addresses that follow a RET (C9) or JP (C3) instruction (likely new function starts)
   - Addresses aligned to even boundaries
   - Addresses in the 0x000000-0x0BFFFF range (OS code region)
   - Avoid addresses in 0x3C0000+ (certificate/data region)
   - Avoid addresses already in the seeds array

## Steps
1. Read `scripts/transpile-ti84-rom.mjs` to find the seeds array
2. Run the coverage analyzer to find gaps
3. Pick 20 addresses from uncovered gaps that look like code entry points
4. Add them to the seeds array
5. Run `node scripts/transpile-ti84-rom.mjs` to regenerate
6. Run `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs` to verify golden regression
7. Report the new block count and byte count from the transpiler output

## Constraints
- Do NOT modify cpu-runtime.js, peripherals.js, or browser-shell.html
- Do NOT modify any existing probe files
- ONLY modify `scripts/transpile-ti84-rom.mjs` (adding seeds to the array)
- The golden regression MUST still pass after adding seeds
- Do NOT add seeds that are clearly in data regions (look for patterns like repeated bytes, ASCII text, etc.)

## Success Criteria
- 20 new seeds added to the transpiler
- Transpiler runs successfully
- Golden regression passes (26/26 cells, "Normal Float Radian" decoded)
- Net positive block and byte count increase reported
