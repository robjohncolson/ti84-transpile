# Task: Entry 49 Callback Mechanism — Trace 0xD14026

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). We have a transpiler at `scripts/transpile-ti84-rom.mjs` that lifts ROM to JS.

In session 311, we discovered that vector table entry 49 (at offset 0x00063C in the low-address jump table) stores a callback pointer into RAM at address 0xD14026. The vector jumps to a ROM routine that writes the vector's target address into 0xD14026.

## Task
1. **Find all ROM references to RAM address 0xD14026**. Search the ROM binary for the byte sequence `26 40 D1` (little-endian 24-bit address) AND `26 40` (16-bit partial). Count reads vs writes.

2. **For each reference site**, disassemble 20-30 bytes of context to determine:
   - Is it reading (LD reg, (0xD14026)) or writing (LD (0xD14026), reg)?
   - What function does the caller belong to?
   - Is this a USB event callback, timer callback, or something else?

3. **Trace the callback invocation**: Who CALLS INDIRECT through 0xD14026? Look for patterns like `LD HL, (0xD14026)` / `JP (HL)` or `CALL (HL)`.

4. **Write a probe** at `TI-84_Plus_CE/probe-phase313-entry49-callback.mjs` that:
   - Searches the ROM for all references to 0xD14026
   - Disassembles context around each reference
   - Classifies each as read/write/indirect-call
   - Prints a summary

5. **Write a report** at `TI-84_Plus_CE/phase313-entry49-callback-report.md` summarizing findings.

## Key Files
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary
- `TI-84_Plus_CE/ez80-decoder.js` — instruction decoder (import and use `decodeInstruction(rom, offset)`)
- `TI-84_Plus_CE/probe-phase312-top-vectors.mjs` — reference for probe structure
- `TI-84_Plus_CE/phase312-top-vectors-report.md` — reference for report structure

## Constraints
- Do NOT modify any existing files except creating the two new files listed above
- The ROM is 4,194,304 bytes (0x400000)
- eZ80 is little-endian; 24-bit addresses are stored as 3 bytes (low, mid, high)
- Use `import { decodeInstruction } from './ez80-decoder.js'` for disassembly
- Probe must be runnable with `node TI-84_Plus_CE/probe-phase313-entry49-callback.mjs`

## Success Criteria
- All ROM references to 0xD14026 found and classified
- Callback invocation mechanism identified (who calls through the pointer)
- Probe passes without errors
- Report written with clear summary
