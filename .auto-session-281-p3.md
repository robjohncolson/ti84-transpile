# Task: Trace 0x09ED50 — Display/Menu Setup Function

## Context
In the TI-84 Plus CE OS ROM, function 0x09EDC3 (shared UI initializer, 49 bytes, 0x09EDC3-0x09EDF3) calls 0x09ED50 TWICE with different arguments via C-calling-convention (PUSH args, CALL 0x09ED50, POP cleanup):
- First call: after PUSH 1/PUSH 0x2C/CALL 0x09EE86/PUSH HL → CALL 0x09ED50
- Second call: PUSH 1/PUSH 0x40/PUSH 0x03CF72 (OS version string "5.8.2.0029") → CALL 0x09ED50

0x09ED50 appears to be a display/menu setup function. We need to understand what it does.
