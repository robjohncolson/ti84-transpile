# Task: Decode 0x0A26D6 — Line Overflow / Scroll Handler

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). We decode ROM functions by reading raw bytes and disassembling them manually (eZ80 instruction set).

0x0A26D6 is the target of `JP C,0x0A26D6` at offset 0x0A244D in the character renderer 0x0A23E5. It's reached when a character doesn't fit on the current line (carry flag set after width computation by 0x04C979). This is the line overflow / scroll / newline handler.

The character renderer 0x0A23E5 is a ~300B mega-function. When a character overflows the line width, it jumps to 0x0A26D6 instead of continuing to glyph rendering. 0x0A26D6 likely handles: newline (advance y-position), scroll (if at bottom of screen), possibly line-wrap, then either re-enters the renderer or returns.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase552-decode-0A26D6.mjs` that:

1. Reads raw bytes from ROM at 0x0A26D6 for ~150 bytes
2. Disassembles them as eZ80 instructions (ADL mode, 24-bit addresses)
3. Looks for: y-position advancement (writes to D008D5 or similar), x-position reset, scroll detection (compare y with screen height), calls to scroll routines, screen height constants (240 pixels total, or row-based)
4. Prints a clear disassembly with annotations

## eZ80 Decoding Reference
- The ROM file is a flat binary. Address 0x0A26D6 = file offset 0x0A26D6.
- eZ80 ADL mode: default 24-bit addresses and 24-bit registers.
- Common opcodes: CB = bit ops, ED = extended ops, DD = IX prefix, FD = IY prefix, 40 52 = SIS prefix
- LD instructions, CALL (CD xx xx xx = 4 bytes in ADL), JP (C3 xx xx xx), JR (18/20/28/30/38 xx), RET (C9)
- CP = compare (FE xx), BIT = test bit (CB xx), ADD/SUB for position arithmetic
- Key RAM addresses from prior sessions: D008D5 = y-position, D005A0 = saved y, D1059C = saved x, D025CE = base row height, 0x4008D2 = x-position (SIS access)
