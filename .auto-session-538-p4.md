# Task: MAP REMAINING OP COPY STUBS AT 0x07F904-0x07F91F

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary, little-endian). We're manually decoding eZ80 functions by reading raw bytes from the ROM.

**What we know:**
- 0x07F8B6-0x07F903 (session 537): 7 OP copy entry stubs, all routing to shared LDI chain at 0x07F974
- 0x07F920-0x07F98A (session 536): 12+ OP copy entry stubs, same shared LDI chain
- **Gap: 0x07F904-0x07F91F (28 bytes)** — likely contains more OP copy stubs or a transition between the two decoded regions

**OP copy stub pattern:**
Each stub loads HL (source) and DE (destination) with 3-byte OP register addresses, then JR or JP to 0x07F974 (12-byte LDI chain) or 0x07F97A (7-byte LDI chain).

**Known OP register addresses:**
- OP1: D005F8
- OP2: D00603
- OP3: D0060E
- OP4: D00619
- OP5: D00624
- OP6: D0062F
- OP7: D0063A (OP7 start, from session 536)

**eZ80 encoding (ADL mode, 3-byte addresses):**
- LD HL,nn = 21 nn nn nn (4 bytes)
- LD DE,nn = 11 nn nn nn (4 bytes)
- JP nn = C3 nn nn nn (4 bytes)
- JR e = 18 ee (2 bytes, signed offset from PC+2)
- JR cc,e = 38/30/28/20 ee (2 bytes)
- RET = C9 (1 byte)
- NOP = 00 (1 byte)
