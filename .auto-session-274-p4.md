# Task: Add 20 CODE? gap seeds from top uncovered ranges + trace 0x0846EA dispatch table scan

## Part A: 20 CODE? Gap Seeds

Add 20 new transpiler seeds for CODE?-verdict gaps in `scripts/transpile-ti84-rom.mjs`.

### How to find gaps
Run `node TI-84_Plus_CE/audit-true-uncovered.mjs` and look at the output. Alternatively, run `node TI-84_Plus_CE/coverage-analyzer.mjs` for a heatmap. The gaps are scattered throughout the ROM.

### How to add seeds
Open `scripts/transpile-ti84-rom.mjs` and find the `SEED_ADDRESSES` array (or similar — it's the large array of hex addresses near the top of the file). Add 20 new addresses from uncovered CODE? ranges. Pick addresses that:
- Are in the non-erased ROM area (< 0x100000 roughly)
- Are NOT already in the seed list
- Have a CODE? verdict (decodable as eZ80 instructions)
- Are at least 8 bytes long (skip tiny 2-3 byte gaps)

### Verification
After adding seeds, run:
```bash
node scripts/transpile-ti84-rom.mjs
node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
```
The golden regression must still pass 26/26 + status dots.

## Part B: Trace 0x0846EA dispatch table scan

Create a probe `TI-84_Plus_CE/probe-phase274-0846ea-dispatch-scan.mjs` that:

1. Sets up standard TI-84 CE execution (ROM.rom, cpu-runtime.js, peripherals.js)
2. Boots CPU (kernel init 0x000280, 5000 steps)
3. Sets up context: SP=0xD1A87E, IX=0xD1A860, IY=0xD00080, MBASE=0xD0
4. Starts execution at PC=0x0846EA
5. Runs for 5000 steps
6. Logs all unique blocks, all RAM reads/writes in D3Fxxx range
7. Tests TWO scenarios:
   - Scenario A: Dispatch table empty (all zeros at D3F000-D3FFFF) — what does 0x0846EA do? Does it fall through to a default handler?
   - Scenario B: Dispatch table has one entry at D3FFFF: 9-byte entry with handler address 0x058241
8. Reports: block path, any jumps to dispatch targets, behavior when table is empty vs populated

### Key Context
- 0x0846EA was identified as part of the dispatch table scanning mechanism in session 269
- The table at D3FFFF has 9-byte entries going backwards
- When table is empty (all zeros), we want to know if it falls through to some default path
