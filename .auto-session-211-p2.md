# Auto-Session 211 — P2: Investigate ConvKeyToTok 0x05E6A4 reachability for digit tokens

## Context
This is the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). The runtime is in `TI-84_Plus_CE/cpu-runtime.js`. The transpiled JS is generated from `scripts/transpile-ti84-rom.mjs`.

Session 210 found that the BufInsert site at `0x05E6A4` IS reachable via the ConvKeyToTok path. The path is gated by `BIT 4,(IY+5)` at `0x05E63C` — if bit 4 is SET, `JR NZ` jumps to `0x05E6A4` which does `POP DE / PUSH DE / CALL BufInsert(0x05E2A0)`. However, in session 210's traces, DE contained a return sentinel (0x7FFFFE), not a digit token.

Key addresses:
- ConvKeyToTok main entry: `0x05E630`
- BIT 4,(IY+5) gate: `0x05E63C`
- BufInsert via POP DE: `0x05E6A4`
- BufInsert routine: `0x05E2A0`
- IY typically = `0xD00080` (so IY+5 = `0xD00085`)
- Digit scan codes: 0x8E(0), 0x8F(1), 0x90(2), ..., 0x97(9)
- ConvKeyToTok primary table at 0x05BF84: maps scan code 0x8E→token 0x30, 0x8F→0x31, etc.
