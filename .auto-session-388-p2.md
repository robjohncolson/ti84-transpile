# Task: Disassemble 0x03016A (Mode Normalization Delegate)

## Context
This is TI-84 Plus CE ROM transpilation research. Session 387 found that 0x0301F6 calls 0x03016A as the "mode normalization delegate" — this is the actual 2ND translation logic. We need to understand what 0x03016A does: does it reference the 2ND sub-table at 0x09F7D3? How does it compute the 2ND-mode token?

## eZ80 reference
- eZ80 ADL mode: 24-bit addresses, little-endian
- Common opcodes: CD=CALL, C3=JP, C9=RET, 3A=LD A,(nn), 32=LD (nn),A, FD CB=BIT/SET/RES (IY+d)
- Prefix FD = IY instructions. Prefix DD = IX instructions.
- RST 38h = opcode 0xFF
