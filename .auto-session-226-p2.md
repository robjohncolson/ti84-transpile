# Auto-Session 226 — P2: Investigate 0x03FC1C (D0058D Table Reader)

## Context
In the TI-84 Plus CE ROM transpilation project, we're tracing the keyboard scan-to-keycode conversion pipeline. Session 225 found that 0x03FBFD is an 18-byte flag clearer (not a key pipeline), and noted that the ADJACENT function at 0x03FC1C reads D0058D and uses it as an index into a table at 0x03FC41. D0058D is the "real key code" variable that the key classifier loads for secondary table lookups. If 0x03FC1C maps scan codes to key codes, that's a major architectural finding.

## Task
Build a probe `TI-84_Plus_CE/probe-phase226-03fc1c-table-reader.mjs` that:

1. **Static disassembly**: Read ROM.rom bytes from 0x03FC1C to 0x03FCA0 (~132 bytes) and disassemble them as eZ80 ADL-mode instructions. Document every instruction. Key things to find:
   - How D0058D is loaded (LD A,(D0058D) or LD A,(IY+offset)?)
   - The table at 0x03FC41 — where it starts, how it's indexed
   - What the function returns or stores
   - Any CP/JR/JP branches
   - Function boundary (RET instructions)

2. **Dump the table**: Read ROM.rom at the table address 0x03FC41 and dump at least 64 bytes in hex. If the table has a clear structure (e.g., pairs of bytes, or 166 entries like the primary ConvKeyToTok table), identify the pattern.

3. **Also disassemble the complementary setter** at 0x03FC0F (found in session 225): `SET 6` → `SET 4` → `RES 5` on (IY+18). Read 0x03FC0F to 0x03FC1B.

4. **Find callers**: Scan ROM.rom for `CD 1C FC 03` (ADL CALL 0x03FC1C) and `C3 1C FC 03` (ADL JP 0x03FC1C). List all call sites with their addresses.

5. **Dynamic trace**: Using standard boot setup:
   ```javascript
   const cpu = new ez80CPU();
   const mem = new Uint8Array(0x1000000);
   const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
   mem.set(rom);
   const bus = createPeripheralBus({ timerInterrupt: false });
   cpu.bindMemory(mem, bus);
   cpu.iy = 0xD00080;
   cpu.mbase = 0xD0;
   ```
   Test the function with D0058D set to various key codes:
   - 0x8F (digit '1' key code)
   - 0x76 (LOG key code)
   - 0x5B (key code with primary=0x00, secondary table trigger)
   - 0x9A (letter 'A' key code)
   - 0x80 ('+' key code)
   
   Set PC=0x03FC1C, push sentinel 0x7FFFFE, step up to 100 steps. Record: A_return, what RAM was read/written, all blocks visited.

6. **Cross-reference with D0058D writers**: Scan ROM for references to D0058D (search for bytes `8D 05 D0` in various instruction contexts). List how many write vs read sites exist. Session 223 found that sub-function 0x02F961 writes `LD (D0058E),A` — check if D0058D is nearby (offset by 1).
