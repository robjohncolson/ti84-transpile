# Task: Decode 0x0391DC Parallel Descriptor Builder (1494 bytes)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). We have already fully decoded 0x00CD7B (1394 bytes, a linear multi-stage USB descriptor builder). There is a parallel copy at 0x0391DC in the 0x03xxxx mirror region that is 1494 bytes — 100 bytes larger than the 0x00xxxx version.

## What We Know About 0x00CD7B
- 1394 bytes (0x00CD7B-0x00D2EC)
- Linear multi-stage switch with NO LOOPS
- 5 embedded dispatch tables via CALL 0x002623 (_seqcase dense dispatcher)
- 13 unique CALL targets: 0x00CB7B (node body init), 0x00CBE9 (link init), 0x00E06D (slab alloc), 0x00E1CC (slab free), 0x0021C2 (null check), 0x002623 (switch), 0x00E583 (tree insert)
- Parses USB setup packets: stage 1 extracts type from byte 0 bits 7:5, stage 2 decodes bRequest, stage 3 allocates slab nodes, stage 4 dispatches to constructor branches
- Uses D141BE as data source buffer

## Your Task
1. Create a probe script at `TI-84_Plus_CE/probe-phase432-trace-0391DC.mjs` that:
   - Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
   - Disassembles from 0x0391DC forward (estimate ~1494 bytes based on the end of the function)
   - Lists all CALL targets and their addresses
   - Lists all absolute RAM references (0xD0xxxx range)
   - Lists all port I/O (IN/OUT instructions)
   - Compares the CALL target list against 0x00CD7B's known targets to identify differences

2. Create a report at `TI-84_Plus_CE/phase432-0391DC-report.md` documenting:
   - Total size (find the RET that ends the function)
   - How the structure differs from 0x00CD7B (extra stages? extra dispatch entries? different CALL targets?)
   - Any new RAM addresses or port references not seen in 0x00CD7B
   - Whether the extra 100 bytes are additional case handlers, longer dispatch tables, or extra logic

## Technical Notes
- eZ80 instructions are variable-length (1-6 bytes)
- CALL nn = 0xCD followed by 3-byte LE address (eZ80 ADL mode)
- RET = 0xC9
- RST 0x08 = 0xCF (debug assertion)
- The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js` — you can import and use it
- The transpiler is at `scripts/transpile-ti84-rom.mjs` — look at how it reads the ROM
