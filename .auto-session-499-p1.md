### What we know about 0x05E50C

From session 498 (probe-phase498-find-d008d2-writers.mjs):
- 0x05E50C is the **ONLY** function that writes BOTH D008D2 (LD (D008D2),HL) AND D008D5 (LD (D008D5),A)
- It reads cursor row from D00595 and cursor col from D00596
- It has 8 cursor refs (D00595/D00596) within ±200 bytes of 0x05E50C
- The pixel renderer at 0x0A23E5 reads the pre-computed address from D008D2/D008D5

### Full rendering pipeline

```
cursor position → 0x05E50C converts row/col → VRAM address
                → stores base to D008D2 (HL=24-bit) and high byte to D008D5 (A=8-bit)
                → putchar 0x061980 calls mode gate 0x061434
                → pixel renderer 0x0A23E5 reads D008D2/D008D5
                → renders glyph at VRAM address
```

### Known RAM addresses

- D008D2: VRAM base address (24-bit HL)
- D008D5: VRAM high byte
- D00595: cursor row (0-based)
- D00596: cursor col (0-based)
- D02505: cursor col duplicate
- D02575: cursor type/character code
- IY_BASE = 0xD00080

### Known subroutines to annotate

- 0x061980: putchar
- 0x061003: cursor_erase
- 0x061061: cursor_draw
- 0x060EF5: cursor_blink_orchestrator
- 0x096BEE: cursor_blink_toggle
- 0x096CCF: cursor_show_sub
- 0x0A23E5: pixel_renderer (reads D008D2/D008D5)
