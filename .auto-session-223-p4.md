# Task: Investigate 0x084EA7 as key code entry point from ISR to home-screen dispatch

## Context
You are working on a TI-84 Plus CE ROM transpilation project. Session 222 found that RAM variables D00824 and D00826 are key code storage variables with 16 writers each. 0x084EA7 was identified as a major D00824 writer with a BIT 6,(IY+54) check, making it a candidate for the key code entry point from ISR to home-screen dispatch.

**Home-screen key dispatch (from session 222)**:
- 0x0856A8: parent function that reads (D00824), does CP cascade for special keys (0x48/0x54/0x55/0x59), then CALL 0x04E9D8 for others
- Post-call dispatch at 0x0856CE: checks D00824 against 0x4A/0x49/0x54/0x55/0x59/0x48
- 0x0866E7: key code loader comparing A vs (D00828) upper bound

**Key variables**:
- D00824: key code for home-screen dispatch (16 writers)
- D00826: key code for 0x04E9D8 function (16 writers)
- D00828: upper bound for key code comparison
- D0058E: real key code for secondary table lookups in 0x05C52C

## Deliverable
Create `TI-84_Plus_CE/probe-phase223-084ea7-key-entry.mjs` that:

1. **Part A: Static disassembly of 0x084EA7 and surrounding context**
   - Read ROM.rom directly
   - Scan backward from 0x084EA7 to find function entry (look for RET boundary)
   - Disassemble the full function (~100-200 bytes forward from entry)
   - Identify: the LD (D00824),A write instruction, the BIT 6,(IY+54) check, any CALL targets, the CP/branch structure

2. **Part B: Find all 16 D00824 writers**
   - Static ROM scan for writes to D00824
   - eZ80 patterns: `32 24 08 D0` (LD (0xD00824),A in ADL mode) and `ED 43 24 08 D0` (LD (0xD00824),BC) etc.
   - Also check for `LD (HL),A` where HL = D00824 (indirect writes — look for LD HL,0xD00824 followed by LD (HL),A)
   - List all 16 with address and surrounding instruction context
   - Group by ROM region (ISR / OS core / home-screen / editor / apps)

3. **Part C: Disassemble 0x084EA7's parent function**
   - Find function entry and exit
   - Map the full control flow: what checks happen before D00824 is written
   - Identify callers (CALL/JP to this function)

4. **Part D: Dynamic trace**
   - Boot CPU, then call the function at 0x084EA7 (or its parent entry)
   - Set A to a key code value (e.g., 0x8F for digit '1')
   - Set IY+54 (which is 0xD000B6) to test BIT 6 gate both ways
   - Record: D00824 value before/after, blocks visited, other RAM writes
   - Test with BIT 6 SET and CLEAR to see which path writes D00824

## Setup pattern
Use standard probe pattern. Read `probe-phase222-0856c8-caller-chain.mjs` for context on how the home-screen dispatch works.

## Key constraints
- Use `createPeripheralBus({ timerInterrupt: false })`
- IY = 0xD00080 (so IY+54 = IY+0x36 = 0xD000B6)
- MBASE = 0xD0 (default)
- `mem.fill(val, start, END)` — third arg is END, not length
- ROM writes silently dropped (addr < 0x400000)

## Success criteria
- Function at 0x084EA7 disassembled with entry/exit boundaries
- All 16 D00824 writers listed with context
- BIT 6,(IY+54) gate behavior confirmed dynamically
- Determination of 0x084EA7's role: does it receive key codes from ISR and write to D00824 for home-screen dispatch?
