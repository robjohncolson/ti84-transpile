# Auto-Session 376 P2: Test Natural Keyboard Dispatch with Fixed Ports

## Context

Session 375 fixed two critical keyboard port bugs in peripherals.js:
1. Per-group read ports 0xA012-0xA01E were unregistered → returned 0xFF → false multi-key rejection
2. Combined read at 0xA008 used wrong polarity (active-LOW vs OS-expected active-HIGH)

Previously, we had to use "direct RAM injection" (writing scan code to 0xD00587 + setting bit 3 of 0xD00080) to get key dispatch working. Now that the ports are fixed, the scan routine at 0x003C63 should be able to detect ENTER naturally via the keyboard matrix.
