Use the eZ80 instruction set. Key opcodes:
- 0xCD = CALL nn (3-byte address follows in ADL mode)
- 0xC3 = JP nn
- 0x18 = JR e (signed byte offset)
- 0x76 = HALT
- 0xC9 = RET
- 0xDB = IN A,(n)
- 0xED 0x78 = IN A,(C)
- 0xED prefix = extended instructions
- 0xDD/0xFD = IX/IY prefix
