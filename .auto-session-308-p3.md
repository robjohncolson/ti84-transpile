5. Create a probe file `TI-84_Plus_CE/probe-phase308-jump-trampoline.mjs` that:

## eZ80 instruction reference (quick)
- `CALL nn` = 3-byte address call
- `JP nn` = 3-byte address jump  
- `RET` / `RET Z` / `RET NZ` = conditional returns
- `CP n` = compare A with immediate, sets Z if equal
- `LD A,(HL)` / `LD A,(IX+d)` = memory loads
- `BIT n,reg` = test bit, sets Z if bit is 0
- eZ80 is little-endian, 24-bit addresses (3 bytes for addresses in CALL/JP)
