# Task: Certificate Region Deep Dive (0x3B0001-0x3C0000)

## Context
Session 310 decoded `0x0421A7` as a descriptor getter that reads cert field `0x0C00` from the ROM certificate region at `0x3B0001-0x3C0000`. The region contains 6 fields before an 0xFF end marker at `0x3B003B`. Session 310 listed them:

| Field addr | Type | Payload addr | Size |
|-----------|------|-------------|------|
| 0x3B0001  | 0x0330 | 0x3B0004 | 24 |
| 0x3B001C  | 0x0340 | 0x3B001F | 1 |
| 0x3B0020  | 0x0350 | 0x3B0023 | 3 |
| 0x3B0026  | 0x0B00 | 0x3B0029 | 8 |
| 0x3B0031  | 0x0C00 | 0x3B0033 | 3 |
| 0x3B0036  | 0x0370 | 0x3B0038 | 3 |

End marker: 0x3B003B = 0xFF.

The cert helpers are at vector table entries:
- `FindFirstCertField` at 0x000310 (vector)
- `GetFieldSizeFromType` at 0x00030C (vector)

## Your Deliverables

1. **Create `TI-84_Plus_CE/probe-phase311-cert-region.mjs`**: A Node.js probe that:
   - Dumps the entire certificate region 0x3B0001-0x3C0000 as hex, identifying all field headers, payloads, and gaps
   - Parses the field structure: each field appears to be [type_hi, type_lo, size, payload...] or similar — reverse-engineer the exact format from the 6 known fields
   - Determines what the payload bytes actually contain for each field (hex dump + ASCII where printable)
   - Searches the ROM for all CALL sites to `FindFirstCertField` (0x000310) — what field IDs do callers request? (Look at the LD DE, xxxx instruction before the CALL)
   - Searches for all CALL sites to `GetFieldSizeFromType` (0x00030C)
   - Cross-references field type IDs against `TI-84_Plus_CE/references/ti84pceg.inc` for SDK names
   - Prints a complete field catalog and caller analysis

2. **Create `TI-84_Plus_CE/phase311-cert-region-report.md`**: A markdown report documenting:
   - The certificate region structure (header format, field encoding)
   - Each field's type, payload, and likely purpose
   - All ROM code that reads certificate fields and which fields they request
   - Whether field 0x0C00 (payload 00 00 00) controls any features relevant to the browser shell

## Technical Details

- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, read with `readFileSync`)
- Decoder: `import { decodeInstruction } from './ez80-decoder.js'` — `decodeInstruction(romBuffer, address, 'adl')` returns `{tag, length, target?, ...}`
- FindFirstCertField vector: 0x000310. Search for CALL 0x000310 pattern: bytes CD 10 03 00
- GetFieldSizeFromType vector: 0x00030C. Search for CALL 0x00030C pattern: bytes CD 0C 03 00
- The descriptor getter at 0x0421A7 hardcodes DE=0x0C00 before calling FindFirstCertField
- For each caller of FindFirstCertField, look backwards for LD DE instructions to find which field type they request
