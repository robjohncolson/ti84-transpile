# Auto-Session 517 — P4: Decode Type Remapping Tables at 0x07FE8A and 0x07FE91

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 516 decoded the dual-buffer type normalizer at 0x07F7FA. It calls two sub-functions:
- 0x07FE5E→0x07FE65: Reads byte at (HL), masks low 6 bits (AND 0x3F), CPIR search in 5-entry table at 0x07FE91. If found, replaces low 6 bits with value from a companion table (preserves top 2 bits via AND 0xC0 | OR B).
- 0x07FE28→0x07FE2F: Same pattern, 6-entry CPIR search in table at 0x07FE8A. Default B=0x0C if not found.

The normalizer processes both D005F8 (active descriptor) and D00603 (second buffer). It rewrites BCD display type codes using these ROM lookup tables.
