# Auto-Session 511 P3: Decode 0x0B95AC (Cursor Setup Helper)

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 CPU in ADL mode = 24-bit addresses).

**0x0B95AC** is called conditionally from cursor_setup (0x0B95E0) based on cursor type bits:
- bit 0 set → CALL 0x0B95AC with A=0x10
- bit 1 set → CALL 0x0B95AC with A=0x11

It likely configures cursor appearance mode. The cursor_setup function checks cursor type via 0x0B9644, then conditionally calls 0x0B95AC with different A values to set up appearance parameters.

Other known cursor ops for context:
- D0069F = cursor table pointer
- D005F9 = active glyph descriptor
- D00083 = IY+3 (cursor flags)
- cursor_draw (0x0B968E) reads glyph from D0069F+0x1F, adds 0x41, writes to D005F9
- 0x06868A = shared rendering dispatch
- 0x0B067E = called at end of cursor_setup with A=0x10 or 0x11

## Task

Create a probe file `TI-84_Plus_CE/probe-phase511-decode-0B95AC.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom`
2. Disassembles **0x0B95AC** — dump at least 60 bytes. Decode eZ80 instructions.
3. Also disassemble **0x0B067E** (called at end of cursor_setup, 60 bytes) — this may be related to cursor appearance config.
4. For each function identify all CALL targets, memory references, and control flow.
5. Print a functional summary of what these helpers do.

## Reference: eZ80 instruction encoding

Same as other probes:
- CALL nn = 0xCD + 3B LE addr. Conditional: NZ=0xC4, Z=0xCC, NC=0xD4, C=0xDC
- JP nn = 0xC3 + 3B. JR e = 0x18 + signed 8-bit offset
- LD A,(nn) = 0x3A + 3B. LD (nn),A = 0x32 + 3B. LD HL,(nn) = 0x2A + 3B.
- RET = 0xC9. Prefix 0x40 = .SIS. FD = IY prefix. CB = bit ops.
