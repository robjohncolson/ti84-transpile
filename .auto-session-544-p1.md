# Task: Decode 0x03EC8F — Error Context Formatter

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). You need to decode the function at address 0x03EC8F which is the "error context formatter" called from the error display init at 0x03EBB0.

From session 543: `0x03EBB0` calls `0x03EC8F` as part of the error display pipeline. The call sequence is:
- LD A,0x0E → LD (D00596),A → LD A,(D00813) → CALL 0x03EC8F → CALL 0x07FA07 → LD HL,D00603 → CALL 0x0A1C8A

So 0x03EC8F receives the error context byte (from D00813) in A, and presumably formats it for display.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase544-decode-03EC8F.mjs` that:
1. Reads the ROM binary
2. Uses `decodeInstruction` from `./ez80-decoder.js` to decode instructions starting at 0x03EC8F
3. Decodes up to 40 instructions or until hitting a RET/JP that's clearly a function end
4. Prints each instruction with address, hex bytes, and assembly mnemonic
5. For any CALL targets or memory references, note what they might be (use known addresses: D005F8=OP1, D00603=OP2, D0060E=OP3, D00596=display counter, D00813=error context, D0081C=error display type, D008DF=error code, D00080=IY system flags base)
6. Searches for xrefs to 0x03EC8F in the ROM (scan for CD 8F EC 03 pattern in the full ROM)

## Technical Details
- Import: `import { decodeInstruction } from './ez80-decoder.js';`
- ROM read: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');`
- Decoder call: `const inst = decodeInstruction(rom, address, 'adl');` — returns object with `.tag`, `.size`, and various fields depending on tag
- The decoder returns objects like `{tag: 'ld-reg-imm', dest: 'a', value: 0x0E, size: 2}` etc.
- Use `rom.slice(addr, addr + inst.size)` for hex bytes (NOT `.bytes` property — that doesn't exist)
- The third parameter to decodeInstruction is the string `'adl'` (ADL mode), NOT an integer

## Format instruction output like:
```
0x03EC8F [CD 8F EC 03] CALL 0x03EC8F    ; <comment>
```

## Constraints
- Do NOT modify any existing files
- Do NOT import `createEz80Decoder` — use `decodeInstruction` directly
- Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase544-decode-03EC8F.mjs`
- NEVER run the probe bare (`node TI-84_Plus_CE/probe-...`) — always use the watchdog wrapper

## Success Criterion
The probe runs successfully via the watchdog and prints a complete instruction listing for the function at 0x03EC8F, including all branches and call targets.
