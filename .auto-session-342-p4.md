# Task: Identify the 15 unknown handler addresses from cxMain write registry

## Context
Session 341 mapped all 19 sites in the TI-84 Plus CE ROM that write to `cxMain` (address 0xD007CA). These writes install context handlers — each handler is a different app/screen/mode. There are 15 unique handler addresses. We need to disassemble the first 20-30 bytes of each to identify what screen/app they represent.

## The 15 unique handler addresses
```
0x05CD71, 0x05FFEF, 0x06B4E8, 0x080FB7, 0x0810E8, 0x08149F,
0x09D32D, 0x09D22C, 0x0AB83D, 0x0ABA44, 0x0AC035, 0x0ACCDD,
0x0B1D3B, 0x0B4DAE, 0x0B62D8
```

Plus the known HOME_HANDLER at 0x058241 (installed via context switch, not direct write).

## What to do

1. Write a probe at `TI-84_Plus_CE/probe-phase342-handler-identify.mjs` that:
   - Reads `TI-84_Plus_CE/ROM.rom`
   - For each of the 15 addresses above (plus 0x058241):
     - Reads 40 bytes of ROM at that address
     - Prints the hex dump
     - Attempts to decode eZ80 instructions (ADL mode) using `TI-84_Plus_CE/ez80-decoder.js`
     - Prints the first 8-10 decoded instructions

2. For identification, look for these patterns in the disassembly:
   - String references: `LD HL, 0x0xxxxx` followed by calls to string print routines (hint: look for addresses in the 0x0Bxxxx range which is often string data)
   - LCD/VRAM operations: writes to 0xD40000+ range
   - Menu setup patterns: table loads, loop counters
   - Known subroutine calls: 0x021A3C (ClrLCDFull), 0x0210AC (PutS), 0x020F38 (PutC)

3. Try to assign likely names based on what you find. TI-84 CE contexts include:
   - HOME (0x058241 — already known)
   - GRAPH, TABLE, MATRIX, LIST, STAT, PRGM, Y=, WINDOW, ZOOM, CALC, FORMAT, DRAW, DIST, TEST, CATALOG, MATH, MEMORY, APPS, LINK, FINANCE

4. Output format:
```
=== Handler 0x05CD71 ===
Hex: xx xx xx ...
Disassembly:
  0x05CD71: instruction
  0x05CD74: instruction
  ...
Likely identity: <guess based on patterns>
---
```
