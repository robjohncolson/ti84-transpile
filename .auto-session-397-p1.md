## eZ80 Reference

The ROM uses eZ80 (24-bit address space). Key opcodes:
- `ED 78` = IN A,(C) — read port from BC
- `ED 79` = OUT (C),A — write port
- `CD xx xx xx` = CALL addr (3-byte addr in little-endian)
- `C3 xx xx xx` = JP addr
- `FD CB dd bb` = BIT/SET/RES on (IY+dd)
- `3E xx` = LD A,xx
- `FE xx` = CP xx
- `21 xx xx xx` = LD HL,addr
- `11 xx xx xx` = LD DE,addr
- IY base = 0xD00080
