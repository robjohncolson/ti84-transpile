# Task: Decode 0x096C03 — Token/Expression State Checker

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). You need to create a probe that statically disassembles a ROM function.

## Background
0x0935BF is a thin 11-byte wrapper: `CALL 0x096C03, BIT 0,(IY-0x04), RET Z, EX DE,HL, RET`. The REAL logic is inside 0x096C03. The caller at 0x096BD3 (inside the cursor display formatter 0x096B65) does `LD A,(HL); CP 0x0E` after calling 0x0935BF — so 0x096C03 returns a pointer in HL to some token data, and 0x0E is a token type code that determines blink-toggle vs alternate display path.

0x096C03 is called from 0x0935BF which is called from 0x096BC3 (sub-function of 0x096B65, the status bar formatter). Understanding what 0x096C03 computes reveals what token type 0x0E represents and completes the blink branching logic.

## eZ80 Instruction Reference
- eZ80 is a Z80 superset with 24-bit addressing
- Standard Z80 opcodes apply, plus:
  - `ED 27` = `LD HL,(HL)` (load 24-bit value from address in HL)
  - `.SIS` prefix (0x40) = 16-bit operand override, high byte from MBASE register (0xD0)
  - `MLT rr` = multiply L×H→HL (8×8→16 multiply)
  - `TST A,n` = test A AND n without storing
  - 24-bit LD/ADD/SBC for HL,DE,BC,IX,IY
- IY base = 0xD00080 (so IY+0x11 = D00091, IY-0x04 = D0007C, etc.)
- RST 28h (0xE7) = BCALL, followed by 2-byte index into system call table

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase505-decode-096C03.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom`
2. Statically disassembles starting at 0x096C03, decoding at least 80 bytes (or until a clear RET/JP is found)
3. For each instruction, prints: address, hex bytes, mnemonic, operands
4. Handles eZ80 prefixes (0x40 .SIS, 0x49 .LIS, 0x52 .SIL, 0x5B .LIL, CB/DD/ED/FD prefix groups)
5. Identifies all CALL/JP targets and RAM references (D0xxxx addresses)
6. Prints a summary of what the function appears to do

The probe must be runnable via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase505-decode-096C03.mjs`

## Constraints

- Do NOT touch `cpu-runtime.js`, `peripherals.js`, `browser-shell.html`, `ez80-decoder.js`, or any transpiler files
- The probe is a standalone Node.js script that reads ROM.rom directly with `fs.readFileSync`
- Use `process.exit(0)` at the end for clean exit
- Do NOT use dynamic execution (no cpu.step(), no loadOsIntoExecutor) — static disassembly ONLY
- The ROM file path is `TI-84_Plus_CE/ROM.rom` (NOT `TI84PCE.rom` or any other name)

## Success Criterion
