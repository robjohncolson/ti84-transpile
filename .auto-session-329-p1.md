## What we know
Both text renderers (fixed-width at 0x054E21 and variable-width at 0x054FC6) call subroutine **0x0553F0** for every pixel write. From session 328:
- 0x0553F0 takes A=alpha (opacity), BC=RGB565 color, HL=VRAM address
- Fast path when A=0xFF: direct 2-byte write (no blending)
- When 0<A<0xFF: full RGB565 alpha blend using MLT instruction
- Called from both renderers' inner pixel loops

## Your task

2. **Trace all code paths**: fast path (A=0xFF), transparent path (A=0x00), and the alpha blending path (0<A<0xFF).
3. **Decode the RGB565 channel decomposition**: How does it split BC into R5:G6:B5 channels? How does it read the existing VRAM pixel for blending? How does it recombine after per-channel alpha multiply?
4. **Document the MLT usage**: MLT multiplies 8×8→16 in a register pair. Which register pairs? How is the alpha value applied to each channel?
5. **Dynamic verification**: Run the function with test inputs (e.g., A=0xFF/BC=0x1234/HL=D40000, A=0x80/BC=0xFFFF/HL=D40000 with pre-set VRAM value) and confirm VRAM writes match the expected blend formula.
