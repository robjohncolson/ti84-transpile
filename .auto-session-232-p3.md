Add AP Statistics inference test commands to the direct-eval template system in `TI-84_Plus_CE/browser-shell.html`. These are the most-used inference procedures for AP Stats students.

## What to add

### 1. 1-PropZTest `[0xBB, 0x55]`
One-proportion z-test. Syntax: `1-PropZTest(p0, x, n, direction)`
- p0 = hypothesized proportion
- x = number of successes
- n = sample size  
- direction: -1 (left tail), 0 (two-tail), 1 (right tail)
- Returns: z-stat, p-value
- Formula: p-hat = x/n, z = (p-hat - p0) / sqrt(p0*(1-p0)/n)
- p-value: use existing _normalCdf helper

### 2. 1-PropZInt `[0xBB, 0x56]`
One-proportion z-interval. Syntax: `1-PropZInt(x, n, C-level)`
- x = number of successes, n = sample size, C-level = confidence level (e.g. 0.95)
- Returns: (lower, upper)
- Formula: p-hat = x/n, z* = invNorm((1+C)/2), ME = z* * sqrt(p-hat*(1-p-hat)/n)
- Use existing _invNorm helper

### 3. 2-SampZTest `[0xBB, 0x57]`
Two-sample z-test. Syntax: `2-SampZTest(σ1, σ2, x̄1, n1, x̄2, n2, direction)`
- Returns: z-stat, p-value
- Formula: z = (x̄1 - x̄2) / sqrt(σ1²/n1 + σ2²/n2)

### 4. 2-SampTTest `[0xBB, 0x5C]`
Two-sample t-test (Welch's). Syntax: `2-SampTTest(x̄1, s1, n1, x̄2, s2, n2, direction)`
- Returns: t-stat, p-value, df
- Formula: t = (x̄1 - x̄2) / sqrt(s1²/n1 + s2²/n2)
- df = Welch-Satterthwaite: (s1²/n1 + s2²/n2)² / ((s1²/n1)²/(n1-1) + (s2²/n2)²/(n2-1))
- p-value: use existing _tCdf helper

### 5. ZTest `[0xBB, 0x53]`
One-sample z-test. Syntax: `ZTest(μ0, σ, x̄, n, direction)`
- Returns: z-stat, p-value
- Formula: z = (x̄ - μ0) / (σ / sqrt(n))

### 6. TTest `[0xBB, 0x5A]`
One-sample t-test. Syntax: `TTest(μ0, x̄, s, n, direction)`
- Returns: t-stat, p-value, df
- Formula: t = (x̄ - μ0) / (s / sqrt(n)), df = n-1
