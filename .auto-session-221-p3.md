# Auto-Session 221 P3: Test 2-byte token insertion with 2nd-mode and ALPHA flags armed

## Context

We are reverse-engineering the TI-84 Plus CE OS ROM (eZ80, 4MB at `TI-84_Plus_CE/ROM.rom`). Session 220 found that 2-byte token insertion writes 0x00 because the secondary ConvKeyToTok tables need mode/context flags set. Specifically:

- Primary table at 0x05BF84: 166 entries indexed by key code. 16 entries are 0x00 (trigger secondary lookup).
- Secondary tables: 0x05C01D (400 entries, function tokens), 0x05C1B0 (400 entries, 2nd-mode with prefix 0x61/0x5E), 0x05C3AA (264 entries, Alpha-mode with prefix 0xBB/0xEF), 0x05C4A0 (18 entries, Alpha-Lock).
- Scan codes tested that returned 0x00: 0x5B (abs/transpose), 0x69 (cos⁻¹/tan⁻¹), 0x76 (log/sin⁻¹), 0x7B (Y1/Y2).

The ConvKeyToTok function at 0x05E630 likely checks IY flag bits for 2nd-mode or ALPHA-mode before selecting which table to use.

## Task

Build a probe `TI-84_Plus_CE/probe-phase221-2byte-token-mode-flags.mjs` that:

1. **Identify the mode flag bits**: Disassemble ConvKeyToTok starting at 0x05E630 for 128 bytes. Look for BIT/SET/RES instructions that test IY+offset flags, especially early in the function (before the table lookup). Common TI-OS mode flags:
   - 2nd mode: often BIT n,(IY+offset) where n and offset need discovery
   - ALPHA mode: similar pattern
   - The IY base is 0xD00080, so IY+5 = 0xD00085, IY+12 = 0xD0008C, etc.

2. **Dynamic trace with default flags**: Run ConvKeyToTok with scan code 0x76 (log key, primary=0x00) and trace all IY reads in the first 100 steps. Record which (IY+offset) addresses are tested and which bits.

3. **Test with 2nd-mode flag armed**: Once you identify the flag bit from step 1/2, set it before calling ConvKeyToTok with the same scan code. Check if the secondary table is now used and a non-zero token is returned.

4. **Test with ALPHA flag armed**: Same pattern — set the ALPHA flag bit, call ConvKeyToTok, check for non-zero token.

5. **Cross-reference with known tables**: If a non-zero token is returned, verify it matches the secondary table data at 0x05C01D/0x05C1B0/0x05C3AA. The table dump is in `TI-84_Plus_CE/phase186-keytok-tables.json`.
