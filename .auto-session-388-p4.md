## eZ80 reference
- eZ80 ADL mode: 24-bit addresses, little-endian
- Common opcodes: CD=CALL, C3=JP, C9=RET, 3A=LD A,(nn), 32=LD (nn),A, FD CB=BIT/SET/RES (IY+d)
- Prefix FD = IY instructions. Prefix DD = IX instructions.
- CP n = 0xFE n (compare A with immediate)
- JR Z,offset = 0x28 offset
- JR NZ,offset = 0x20 offset
