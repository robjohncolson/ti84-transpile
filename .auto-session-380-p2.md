# Task: Update browser-shell.html for DI+HALT Bypass Continuous Operation

## Context
You are working on a TI-84 Plus CE ROM transpilation project. Session 379 implemented a DI+HALT bypass in `cpu-runtime.js`: when the CPU reaches DI+HALT at 0x0019B5 (OS sleep mode) with iff1=0, the runtime restarts the event loop at 0x003A73 instead of dead-stopping. This is configured via `opts.diHaltBypass` and `opts.diHaltBypassEntry`.

The browser shell (`TI-84_Plus_CE/browser-shell.html`) has a "coldboot" mode that boots the ROM and runs the event loop. However, it may use a fixed step count that stops execution before or at the DI+HALT point, never taking advantage of the bypass to run continuously and accept multiple keypresses.

## What to do
1. Read `TI-84_Plus_CE/browser-shell.html` and understand the current coldboot mode implementation
2. Modify it so that:
   - When coldboot mode is active, the runtime is configured with `diHaltBypass: true` and `diHaltBypassEntry: 0x003A73`
   - The event loop runs continuously (not limited to a fixed step count) — use a chunked execution model (e.g., run 50K steps, yield to browser via requestAnimationFrame or setTimeout, repeat)
   - Keypresses are processed: when a key is pressed, inject the scan code via the existing `peripherals.setKeyPressed(cpu.memory, scanCode)` API, and the DI+HALT bypass will restart the event loop to process it
   - After each DI+HALT bypass restart, the LCD should be re-rendered so the user sees the effect of their keypress
   - The calculator doesn't freeze after processing a single key — it keeps running, accepting more keys

3. Also read `TI-84_Plus_CE/cpu-runtime.js` to understand the diHaltBypass API:
   - Look for `diHaltBypass` in the `createCPU` or `runFrom` function
   - The bypass auto-activates when `runFrom` starts at the event loop entry in ADL mode

## Reference files
- `TI-84_Plus_CE/browser-shell.html` — THE file to modify
- `TI-84_Plus_CE/cpu-runtime.js` — contains the DI+HALT bypass implementation
- `TI-84_Plus_CE/peripherals.js` — contains `setKeyPressed`, `clearKeyPressed`, `createPeripheralBus`
- `TI-84_Plus_CE/ti84-keyboard.js` — keyboard mapping for the browser UI
