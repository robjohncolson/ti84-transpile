## Reference: eZ80 instruction encoding

- Standard Z80 opcodes apply. ADL mode means default 24-bit addresses/register sizes.
- CALL nn = 0xCD followed by 3-byte little-endian address
- JP nn = 0xC3 followed by 3-byte address  
- JR e = 0x18 followed by signed 8-bit offset (relative to PC after the JR)
- Conditional variants: CALL NZ = 0xC4, CALL Z = 0xCC, CALL NC = 0xD4, CALL C = 0xDC
- JP NZ = 0xC2, JP Z = 0xCA, JP NC = 0xD2, JP C = 0xDA
- LD A,(nn) = 0x3A + 3-byte addr. LD (nn),A = 0x32 + 3-byte addr
- LD HL,(nn) = 0x2A + 3-byte addr. LD (nn),HL = 0x22 + 3-byte addr
- RET = 0xC9. RET NZ = 0xC0, RET Z = 0xC8, RET NC = 0xD0, RET C = 0xD8
- Prefix 0xDD = IX ops, 0xFD = IY ops
- Prefix 0x40 = .SIS suffix (use 16-bit operand in ADL mode)
- BIT/SET/RES via 0xCB prefix: BIT b,(HL) = CB 46+8*b, SET = CB C6+8*b, RES = CB 86+8*b
- With IY: FD CB offset opcode
