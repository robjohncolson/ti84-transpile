# Task: Trace Graph Key Handler Pair (0x0092B7 / 0x042782)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 binary). We have decoded D177B9 as the OS screen-state register (0x01=Home, 0x13=Graph, etc.). Two functions at 0x0092B7 and 0x042782 test D177B9 for value 0x13 (graph mode) and dispatch different key codes depending on whether the calculator is in graph mode or not.

## What to do
1. Read the ROM file at offsets 0x0092B7-0x009350 and 0x042782-0x042850 (read ~200 bytes from each).
2. Disassemble each function as eZ80 ADL-mode code. The eZ80 is a Z80 superset with 24-bit addresses. Key opcodes:
   - `LD A,(addr24)` = 3A xx xx xx
   - `CP imm8` = FE xx
   - `JP Z,addr24` / `JP NZ,addr24` = CA/C2 xx xx xx
   - `CALL addr24` = CD xx xx xx
   - `JP addr24` = C3 xx xx xx
   - `RET` = C9
3. For each function, determine:
   - What it loads from D177B9 and compares against (should be 0x13 for graph mode)
   - What key codes it passes to the dispatch function when state==0x13 vs state!=0x13
   - Session 319 found: if state==0x13: dispatch_key(0x97, 0x13), else dispatch_key(0x06, 0x03). VERIFY this.
   - What calls these two functions? Use grep on the ROM bytes for the 3-byte little-endian target addresses.
4. What do key codes 0x97 and 0x06 mean? Cross-reference with the _seqcase tables if possible. Key code 0x06 may be "Trace" or "Graph" based on session 319's mapping (0x01=Home, 0x02=Y=, 0x03=Window, 0x04=Zoom, 0x05=Trace/Graph).
