## eZ80 opcode reference for classification

- 0x3A + addr = LD A,(addr) → READ
- 0x32 + addr = LD (addr),A → WRITE
- 0x21 + addr = LD HL,addr → ADDR-LOAD
- 0x2A + addr = LD HL,(addr) → READ
- 0x22 + addr = LD (addr),HL → WRITE
- 0x01 + addr = LD BC,addr → ADDR-LOAD
- 0x11 + addr = LD DE,addr → ADDR-LOAD
- 0xAF before 0x32 = XOR A; LD (addr),A → writing 0
- 0x3E 0x01 before 0x32 = LD A,1; LD (addr),A → writing 1
