# Auto-Session 349 — P2: Trace 0x001AFA-0x005998 Boot Region (Find Loop Jump)

## Context
After session 348's port 0x3D fix, boot visits 35 unique blocks in a loop. The blocks are:
0x001AFA, 0x0058A6, 0x0058A9, 0x0058E9, 0x005929, 0x005969, 0x001713, 0x005973, 0x005998, 0x001AFD, 0x000810, 0x000043, 0x0006F3, 0x000704, 0x00070F, 0x00080B

The boot loops through these blocks repeatedly without terminating. We need to find which block contains the backward jump that creates the loop, and what condition controls it.

## Task
Create a probe `TI-84_Plus_CE/probe-phase349-boot-loop-disasm.mjs` that:

1. Boots from PC=0x000000 with `timerInterrupt: false`
2. Runs for 2000 steps, logging every PC transition (block entry)
3. For each of the 16 blocks listed above, disassembles 32 bytes from the ROM starting at that address (raw hex dump + instruction decode if possible, otherwise just hex)
4. Identifies the BACKWARD jump: which block ends with a JP/JR/CALL that targets an earlier address in the sequence?
5. Reports the exact instruction creating the loop and what condition register/flag controls it

## Key Files
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary, read with fs.readFileSync
- `TI-84_Plus_CE/cpu-runtime.js` — CPU with step() method
- `TI-84_Plus_CE/peripherals.js` — peripheral bus
- `TI-84_Plus_CE/probe-phase348-boot-nmi-wake.mjs` — reference probe (copy setup pattern)
- `TI-84_Plus_CE/ez80-decoder.js` — instruction decoder (may help with disassembly)

## Approach
- Read the ROM file directly with `fs.readFileSync('TI-84_Plus_CE/ROM.rom')`
- For each target address, slice 32 bytes and print as hex
- Run the boot and log block transitions to show the loop pattern
- Look for JP/JR opcodes: JP nn = 0xC3 (3-byte addr), JR e = 0x18 (signed offset), JR cc,e = 0x20/0x28/0x30/0x38
- Also check conditional JP: JP Z/NZ/C/NC = 0xCA/0xC2/0xDA/0xD2

## Deliverables
- `TI-84_Plus_CE/probe-phase349-boot-loop-disasm.mjs` — the probe
- Console output showing: hex dump of each block, the loop pattern (sequence of PCs visited), and identification of the backward jump instruction
