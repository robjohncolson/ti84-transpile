# Auto-Session 462 — P3: Full Key Processing Chain Verification

## Task
Create a probe `TI-84_Plus_CE/probe-phase462-key-chain.mjs` that verifies the complete key processing chain:

```
inject key → event loop → HALT → timer IRQ → 0x0019BE (reduced handler) → 0x001ACF (timer service) → RETI → resume event loop → _GetCSC (0x021A5C) → key processor (0x03FA09) → D141B5 gets key code → VRAM changes
```

## Architecture

This probe tests the FULL chain end-to-end with a reasonably spaced timer (10000 blocks between ticks). It traces more addresses than the P1 probe, specifically:

### Addresses to track
- `0x000038` — ISR entry (RST 38h)
- `0x001713` — ISR guard (checks D177BA)
- `0x0019BE` — Reduced ISR handler
- `0x001ACF` — Timer service
- `0x001942` — HALT instruction in event loop
- `0x003A73` — Event loop entry
- `0x03FA09` — Key processor
- `0x021A5C` — _GetCSC (scan code retrieval)
- `0xD141B5` — Memory: key code destination (read after run)
- `0xD00587` — Memory: scan code injection point

### Key injection
```js
mem[0xD00587] = 0x29;  // key '1' scan code
mem[0xD00085] |= 0x08; // bit 3 = key available
```

### Run parameters
- Boot with `timerInterrupt: false`, then after boot call `peripherals.setTimerEnabled(true)` 
- Pass `timerInterval: 10000` to `createPeripheralBus()`
- Run from `EVENT_LOOP_ENTRY = 0x003A73` with:
  - `maxSteps: 1000000` (1M steps — give it plenty of room)
  - `maxLoopIterations: 5000`
  - `diHaltBypass: false` (we want real HALT/wake via timer IRQ)

### Additional tracking
- Track the first 20 unique PCs visited (for event loop structure mapping)
- After the run, dump:
  - `mem[0xD141B5]` — if this changed from 0 to a key code, the full chain worked
  - `mem[0xD00587]` — if this was consumed (cleared to 0), _GetCSC processed it
  - `mem[0xD177B7]` — display dirty flag state
  - VRAM region `0xD40000-0xD52C00` — count nonzero bytes (if VRAM changed, display was updated)

### Cold boot pattern (same as all probes)
```js
const BOOT_ENTRY = 0x000000;
const BOOT_MODE = 'z80';
const BOOT_MAX_STEPS = 20000;
const BOOT_MAX_LOOP_ITERATIONS = 32;
const STACK_RESET_TOP = 0xD1A87E;
const KERNEL_INIT_ENTRY = 0x08C331;
const POST_INIT_ENTRY = 0x0802B2;

executor.runFrom(BOOT_ENTRY, BOOT_MODE, { maxSteps: 20000, maxLoopIterations: 32 });
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
executor.runFrom(KERNEL_INIT_ENTRY, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 });
cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0;
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
executor.runFrom(POST_INIT_ENTRY, 'adl', { maxSteps: 100, maxLoopIterations: 32 });
```
