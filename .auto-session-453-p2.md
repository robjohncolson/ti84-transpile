# Task: Decode Rendered Text from VRAM Diff

## Context
In the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, session 452 found that after injecting key "1", the OS renders a full home screen repaint to VRAM spanning 4 text bands:
- Rows 119-132 (status bar, 14px tall characters) 
- Rows 159-172 (text line 1)
- Rows 183-192 (text line 2)  
- Rows 199-212 (text line 3)

All 3,039 pixel changes are 0x0000→0xFFFF (black→white) in columns 14-287 (274px wide). The VRAM is 16-bit RGB565 at 0xD40000, 320 pixels wide, 240 rows.

The TI-84 CE uses a bitmap font stored in ROM. The font appears to be ~12px wide x 16px tall for large characters or 7x12 for small. The font table is likely in the ROM between 0x03xxxx-0x09xxxx.

## Deliverable
Create `TI-84_Plus_CE/probe-phase453-decode-vram-text.mjs` — a probe that:

1. **Boots to home screen** using the same boot sequence as `probe-phase451-enhanced-workflow.mjs` (BOOT_ENTRY→KERNEL_INIT→POST_INIT→4 stages→flash pre-copy).

2. **Takes a VRAM snapshot** before key injection (the 0xAA-filled baseline).

3. **Injects key "1"** (scan code 0x12) and runs 500,000 steps through the event loop (same as phase 451). Set D14091=1, D177B7=0x55, D177BA=0 before injection.

4. **Takes a VRAM snapshot** after key processing.

5. **Computes the VRAM diff** and for each changed row, produces a 1-bit bitmap (changed=1, unchanged=0) across all 320 pixel columns.

6. **Prints an ASCII art visualization** of each text band, showing the bitmap pattern. Use '#' for changed pixels (0→white) and '.' for unchanged. Group output by the 4 known text bands (rows 119-132, 159-172, 183-192, 199-212). Scale horizontally if needed (e.g., every 2 pixels → 1 character).

7. **Attempts basic glyph recognition**: For each text band, divide the bitmap into candidate glyph columns (look for vertical gaps of all-unchanged pixels to segment characters). Report the number of candidate glyphs found per band and their approximate widths.

8. **Searches for the font table in ROM**: Scan ROM bytes 0x030000-0x0A0000 looking for patterns that match the bitmap data from the first recognizable glyph. Report any candidate font table addresses found.

## Key addresses
- VRAM_BASE = 0xD40000, 320x240 pixels, 16-bit RGB565 (VRAM_BYTE_SIZE = 320*240*2 = 153600)
- Pixel at (x, y) = mem[VRAM_BASE + (y * 320 + x) * 2] (little-endian 16-bit)
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, mapped at address 0x000000-0x3FFFFF)
