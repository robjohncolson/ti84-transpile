# Task: Decode _fppack at 0x0034EE (IEEE-754 Single-Precision Pack Routine)

## Context
The TI-84 Plus CE ROM's soft-float library has been partially decoded. Session 313 fully decoded `_fpunpack` at 0x0034A7 (unpacks IEEE-754 single-precision into sign/exponent/mantissa components) and identified `_fppack` at 0x0034EE as the reverse operation (reassembles components into packed IEEE-754 format). `_fppack` is called by `_ultof` (0x00380D) and likely by `_fadd` (0x003569), `_fmul` (0x00372B), and `_fdiv`. We need the full disassembly.

## What to do

1. **Disassemble _fppack starting at 0x0034EE** from the raw ROM (`TI-84_Plus_CE/ROM.rom`). Read bytes starting at offset 0x0034EE. The function likely ends before the next known function `_fadd` at 0x003569, but check for RET instructions. The function is probably 50-130 bytes.

2. **Decode each instruction** in eZ80 ADL mode (24-bit). Key eZ80 patterns:
   - SLA/SRL/RR/RL for bit manipulation
   - ADD/ADC for mantissa assembly
   - LD operations for component placement
   - OR/AND for sign bit insertion

3. **Document the algorithm**: How does _fppack take sign (in what register?), exponent, and mantissa and produce a 32-bit IEEE-754 float? Document register conventions (input and output).

4. **Cross-reference with _fpunpack** (0x0034A7-0x0034ED range) to confirm the pack is the exact inverse of unpack. Do they use the same register conventions?

5. **Also disassemble _ultof at 0x00380D** briefly — session 313 says it "tail-calls _fppack with D=0/E=0x96". Confirm this and document the calling convention (what register holds the unsigned long input?).

6. **Write results** to `TI-84_Plus_CE/phase314-fppack-report.md`:
   - Full instruction-by-instruction disassembly of _fppack
   - Algorithm description in pseudocode
   - Register conventions (input/output)
   - Comparison with _fpunpack
   - _ultof calling convention confirmation

7. **Write a probe** at `TI-84_Plus_CE/probe-phase314-fppack.mjs` that:
   - Loads ROM, extracts bytes at 0x0034EE
   - Decodes and prints the instruction sequence
   - Verifies the function ends with RET
