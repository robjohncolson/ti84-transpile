# Auto-Session 370 — P2: Enable Timer Interrupt in Event Loop

## Context
The TI-84 CE OS event loop reaches HALT at 0x001942 after ~100 _GetCSC scans with no key. The HALT instruction waits for a hardware interrupt. With `timerInterrupt: true`, the timer ISR at 0x000080 fires periodically and would wake the CPU from HALT. We want to see what happens when the timer wakes the CPU — does it trigger cursor blink, screen refresh, status bar updates, etc.?

Session 369 used `timerInterrupt: false`. The timer ISR at 0x000080 dispatches through 0x001713 → 0x0067F8 → 0x001C33 which can create an infinite loop if not managed. However, the event loop probe uses `maxLoopIterations` to cap loops.

## Task
Create `TI-84_Plus_CE/probe-phase370-timer-interrupt.mjs` that:

1. Does the standard 3-phase boot (timerInterrupt: FALSE for boot):
   - Phase 1: Z80 cold boot from 0x000000, maxSteps=20000, maxLoopIterations=32, timerInterrupt=false
   - Reset: cpu.halted=false, cpu.iff1=0, cpu.iff2=0, cpu.sp=0xD1A87B, mem.fill(0xFF, cpu.sp, cpu.sp+3)
   - Phase 2: ADL from 0x08C331, maxSteps=100000, maxLoopIterations=10000, timerInterrupt=false
   - Reset: cpu.mbase=0xD0, cpu._iy=0xD00080, cpu._hl=0, cpu.halted=false, cpu.iff1=0, cpu.iff2=0, cpu.sp=0xD1A87B, mem.fill(0xFF, cpu.sp, cpu.sp+3)
   - Phase 3: ADL from 0x0802B2, maxSteps=100, maxLoopIterations=32, timerInterrupt=false

2. Record cold boot block set.

3. Phase 4: Event loop WITH timer interrupt enabled:
   - Create a NEW peripherals bus: `createPeripheralBus({ pllDelay: 2, timerInterrupt: true })`
   - Create a NEW executor with the same mem and BLOCKS but the new peripherals
   - Set cpu state: cpu.halted=false, cpu.iff1=1, cpu.iff2=1, cpu.f=0x40, cpu._ix=0xD1A860, cpu._iy=0xD00080, cpu.sp=0xD1A872, mem.fill(0xFF, cpu.sp, cpu.sp+12)
   - Run from 0x003A73 in ADL mode, maxSteps=200000, maxLoopIterations=10

   IMPORTANT: The executor needs `cpu.iff1=1` for interrupts to fire. EI (enable interrupts) must have been run, or set iff1=1 manually.

4. Report:
   - Steps, termination, lastPc
   - Total unique blocks (cold boot + event loop)
   - NEW blocks discovered in Phase 4 (not in cold boot)
   - Top 30 hottest blocks
   - Whether 0x000080 (timer ISR entry) was visited and how many times
   - Whether 0x001713, 0x001933, 0x001853, 0x000721 were visited
   - Whether the HALT at 0x001942 was reached and whether execution continued past it
   - List any blocks with addresses in LCD buffer range (0xD40000-0xD53F00) that were visited
