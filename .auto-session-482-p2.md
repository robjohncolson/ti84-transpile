# Task: Decode 0x0A23C0 and 0x0A239E — cursor blink pixel rendering functions

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM (TI-84_Plus_CE/ROM.rom) is a 4MB eZ80 binary.

Session 481 discovered that the cursor blink path uses 0x0A23C0 and 0x0A239E (NOT 0x0059C6) for pixel rendering. These are called from 0x030173:
- 0x030173 calls 0x030202 (glyph select)
- Then saves display state (D00085, D0008D, D00082, D000B2, D026AC, D026AA, D02AC0 all PUSHed)
- Sets LCD window registers (D008D2=0x0121, D008D5=0x02)
- Zeroes D026AC, sets D026AA=0xFFFF, copies D02ACC→D02AC0
- SETs D000B2 bit 6, RESes D0008D bit 1
- Calls 0x030202 again
- CALL 0x0A23C0 (cursor character render)
- CALL 0x0A239E with B=0x0E (14 = char width)
- Finally restores all PUSHed state

## eZ80 instruction reference (common opcodes)
- 0xED 0x6C = MLT HL
- 0xDD 0x49 = .SIL prefix  
- 0x40 = .SIS prefix
- 0xCD = CALL nn (3-byte address in ADL mode)
- 0xC3 = JP nn
- 0xCB xx = bit operations (SET/RES/BIT)
- 0xFD 0xCB offset opcode = BIT/SET/RES (IY+offset)
- 0x3A = LD A,(nn)
- 0x32 = LD (nn),A
- 0x2A = LD HL,(nn)
- 0x22 = LD (nn),HL
- 0xC5/D5/E5/F5 = PUSH BC/DE/HL/AF
