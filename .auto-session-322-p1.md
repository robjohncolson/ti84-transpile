# Task: Register LCD DMA and USB Ports in peripherals.js

## Context
The TI-84 Plus CE ROM transpilation project lifts eZ80 ROM machine code into runnable JavaScript. The file `TI-84_Plus_CE/peripherals.js` handles I/O port emulation. Unregistered ports return 0xFF by default, which causes infinite loops in the ROM code.

## Problem
Session 321 discovered two critical issues:

1. **LCD DMA status port 0x8040** is unregistered. The ROM function at 0x010A3C busy-loops reading port 0x8040 via wrapper 0x007B05, AND-masks with a caller-supplied byte, and loops while non-zero. Since unregistered ports return 0xFF, ALL 12 display callers hang forever. **Fix: register port 0x8040 to return 0x00 (idle/DMA complete).**

2. **USB controller ports** are unregistered. The USB error checker at 0x006EDA performs a 4-stage health check:
   - Stage 1: port 0x0F bit 7 (USB power) — needs to return 0x80
   - Stage 2a: port 0x3082 bit 4 (PLL lock) — needs to return 0x30
   - Stage 2b: port 0x3030 bit 0 (VBUS detect) — needs to return 0x01
   - Stage 3: port 0x3082 bit 5 (port status) — already covered by 0x30
   - Stage 4: port 0x3031 bits 3:2 (D+/D- line state) — needs to return 0x0C
   **Fix: register these USB ports with the values above for shortest success path.**

`TI-84_Plus_CE/peripherals.js`
