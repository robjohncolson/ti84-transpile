## Context
You are working on TI-84 Plus CE ROM transpilation. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Sessions 388-389 traced 0x03016A→0x04E950→0x09EF44. Neither 0x03016A nor 0x04E950 contains the 2ND translation table lookup (reference: 0x09F7D3 is the 2ND sub-table, 0x09F79B is the main translation table). 0x09EF44 is the next candidate — it's called by 0x04E950 with BC=0x020F, HL=0x0121, DE=0x012A.

## Deliverable
Create `TI-84_Plus_CE/probe-phase390-disasm-09EF44.mjs` — a Node.js probe that:

1. Reads the ROM from `TI-84_Plus_CE/ROM.rom`

3. Decodes eZ80 ADL-mode instructions (24-bit addresses, 3-byte pointers)
4. Reports:

   - All port I/O instructions
   - Function size (start to last RET)

## eZ80 Encoding Reference
- ADL mode: all addresses are 24-bit (3 bytes, little-endian)
- LD r,n = 1-byte opcode + 1-byte immediate
- LD r,nn = 1-byte opcode + 3-byte immediate (ADL mode)
- LD (nn),A = 0x32 + 3-byte address
- LD A,(nn) = 0x3A + 3-byte address
- CALL nn = 0xCD + 3-byte address
- JP nn = 0xC3 + 3-byte address
- JP cc,nn = 0xC2/CA/D2/DA/E2/EA/F2/FA + 3-byte address
- JR e = 0x18 + signed 1-byte offset (relative to next instruction)
- JR cc,e = 0x20/28/30/38 + signed 1-byte offset
- RET = 0xC9
- CALL cc,nn = 0xC4/CC/D4/DC/E4/EC/F4/FC + 3-byte address
- RST n = 0xC7/CF/D7/DF/E7/EF/F7/FF (call to n*8, but RST 38h = 0xFF often acts as trampoline)
- BIT b,(IY+d) = 0xFD 0xCB d 0x46|b*8
- SET b,(IY+d) = 0xFD 0xCB d 0xC6|b*8
- RES b,(IY+d) = 0xFD 0xCB d 0x86|b*8
- IN A,(C) = 0xED 0x78
- OUT (C),A = 0xED 0x79
- CP n = 0xFE + 1-byte immediate
- ADD A,n = 0xC6 + 1-byte immediate
- PUSH/POP AF/BC/DE/HL = 0xF5/C5/D5/E5 / 0xF1/C1/D1/E1
- IX prefix = 0xDD, IY prefix = 0xFD
- ED prefix for extended instructions (block ops, 16-bit I/O, etc.)
