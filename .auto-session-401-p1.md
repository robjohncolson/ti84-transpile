# Task: TRACE 0x0027E8 INDIRECT TABLE DISPATCHER

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We've been tracing the OS key dispatch pipeline.

In session 400, we decoded the key action dispatcher at 0x05D58F. Its prologue does a 4-BYTE-ENTRY TABLE LOOKUP: loads (IX+6) into A, multiplies HL by 4 (add hl,hl x2), adds base from (0xD1441D), then calls 0x0000A4 which is a trampoline to 0x0027E8. This 0x0027E8 function is the INDIRECT CALL dispatcher — it reads a 4-byte table entry and calls the handler.

## Task
Write a probe script `TI-84_Plus_CE/probe-phase401-trace-0027E8.mjs` that:

1. Reads the ROM file at `TI-84_Plus_CE/ROM.rom`
2. Disassembles the function at 0x0027E8 (read ~64 bytes from the ROM starting at offset 0x0027E8)
3. Decode the eZ80 instructions manually (hex dump + manual decode). Key eZ80 opcodes:
   - 0xE5 = PUSH HL, 0xE1 = POP HL, 0xC9 = RET
   - 0x6E = LD L,(HL), 0x66 = LD H,(HL) — but with offset these change
   - 0x7E = LD A,(HL), 0x23 = INC HL
   - 0x5E = LD E,(HL), 0x56 = LD D,(HL)
   - 0xE9 = JP (HL), 0xCD = CALL nn (3-byte address follows in little-endian)
   - 0xC3 = JP nn, 0x18 = JR d, 0x20 = JR NZ,d, 0x28 = JR Z,d
   - Prefix 0x40 = SIS (short mode), 0x52 = SIL, 0x49 = LIS, 0x5B = LIL
   - 0xDD prefix = IX instructions, 0xFD prefix = IY instructions
   - 0xED prefix = extended ops (e.g., ED 5B nn = LD DE,(nn))
4. Document what 0x0027E8 does with the table entry. Does it:
   - Read a 3-byte address and JP/CALL to it?
   - Read a 3-byte address + 1-byte parameter?
   - Read two 2-byte values?
   - Something else?
5. Also check what's at the trampoline 0x0000A4 (read ~6 bytes) to confirm it jumps to 0x0027E8.
6. Search the ROM for ALL callers of 0x0027E8 (search for bytes `CD E8 27 00` for CALL 0x0027E8 and `C3 E8 27 00` for JP 0x0027E8). Report the count and first 10 addresses.
7. Print all findings clearly.

## Reference
- ROM is little-endian eZ80 (24-bit addresses in ADL mode)
- CALL nn = CD xx xx xx (3 bytes little-endian)
- JP nn = C3 xx xx xx
- The table base pointer is stored at RAM 0xD1441D (not in ROM)
- 4-byte entries indexed by key code from IX+6
