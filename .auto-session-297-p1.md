# P1: Keyboard MMIO Hunt — Find all IN A,(C) instructions reading keyboard matrix ports 0xE009xx

## Context
The TI-84 Plus CE keyboard matrix is accessed via I/O ports in the 0xE009xx range (specifically port group starting at 0xE00900). The eZ80 reads these using `IN A,(C)` (or `IN r,(C)`) with BC set to a value like 0xE009xx. Sessions 292-296 chased a 6-level delegation chain (0x02FCB3→0x02FD8F→0x03013A→0x04E966→0x09EF44) that turned out to be VRAM fill (_RectFill), NOT keyboard hardware reads. The real keyboard scanner must be elsewhere.

## Task
Build a probe `TI-84_Plus_CE/probe-phase297-keyboard-mmio-scan.mjs` that:

1. **Scans the raw ROM binary** (`TI-84_Plus_CE/ROM.rom`, 4MB) for the eZ80 `IN A,(C)` opcode pattern. In eZ80 ADL mode:
   - `IN A,(C)` = `ED 78` (2 bytes)
   - Also check `IN r,(C)` variants: `ED 40` (IN B,(C)), `ED 48` (IN C,(C)), `ED 50` (IN D,(C)), `ED 58` (IN E,(C)), `ED 60` (IN H,(C)), `ED 68` (IN L,(C)), `ED 78` (IN A,(C))
   
2. For each `IN r,(C)` found, look backward up to 20 bytes for `LD BC,imm24` (`01 xx xx xx` in ADL mode) that loads a value matching `0x__E9xx` or `0xE009xx` (the keyboard matrix port range). Note: eZ80 is little-endian, so `LD BC,0xE00900` would encode as `01 00 09 E0`.

3. Report: ROM offset, the BC value being loaded, and the register being read into. Also report the surrounding bytes (±10 bytes) as hex dump for manual verification.

4. Additionally, search for `OUT (C),A` patterns (`ED 79`) near `LD BC,0xE009xx` — the keyboard scan typically involves writing a group select byte to the keyboard port before reading.

## File structure
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Search for ED 40/48/50/58/60/68/78 (IN r,(C) variants)

// The keyboard port range: BC high byte = 0xE0, middle byte = 0x09, low byte varies
// In memory (LE): 01 <low> 09 E0
```

## Constraints
- Read-only probe — do NOT modify any source files
- Do NOT touch cpu-runtime.js, peripherals.js, ez80-decoder.js, or transpile-ti84-rom.mjs
- Report ALL hits, not just the first one — we need the complete map

## Success criterion
A list of all ROM addresses where `IN r,(C)` reads keyboard matrix ports (0xE009xx), with the BC setup instruction identified. This tells us where the REAL keyboard scanner lives in the OS.
