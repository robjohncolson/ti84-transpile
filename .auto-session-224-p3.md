# Task: Comprehensive secondary token map — test ConvKeyToTok with magic A values across all common keys

## Context
In the TI-84 Plus CE ROM transpilation project, session 223 verified that the key classifier at 0x05C52C uses magic A values (0xFA/0xFB/0xFC/0xFE) to select secondary token tables. Session 223 tested only 2 scan codes (0x76=LOG and 0x33). We need a comprehensive map of ALL common keys across all 4 secondary tables.

The architecture:
- 0x05C52C is the key classifier. A = magic value, real key code in (0xD0058E)
- A=0xFE → Fn table at 0x05C01D (400 entries)
- A=0xFC → 2nd table at 0x05C1B0 (400 entries)
- A=0xFB → Alpha table at 0x05C3AA (264 entries)
- A=0xFA → AlphaLock table at 0x05C4A0 (18 entries)
- Primary table at 0x05BF84 (166 entries), indexed by key_code - 0x5A

Key codes of interest (from keyboard-matrix.md and session 220 scan code map):
- Digits: 0x8E-0x97 (0-9)
- Math ops: 0x80(+), 0x81(-), 0x82(*), 0x83(/), 0x84(^)
- Letters: 0x9A-0xB3 (A-Z)
- Function keys: 0x60-0x67 (Y=, WINDOW, ZOOM, TRACE, GRAPH, 2ND, MODE, DEL)
- Navigation: 0x5A-0x5F range
- Trig/math: 0x68-0x7F range (SIN, COS, TAN, LOG, LN, etc.)

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase224-secondary-token-map.mjs` that:

1. **Read ROM tables directly**: Read ROM.rom with fs.readFileSync. Dump the 4 secondary tables by reading the ROM bytes at the table addresses. Each entry in the secondary tables is 2 bytes (token pair). Build the complete map from ROM data.

2. **Dynamic verification**: For a sample of 10 key codes spread across the range (e.g., 0x60, 0x68, 0x70, 0x76, 0x7B, 0x80, 0x8F, 0x97, 0x9A, 0xB3), run ConvKeyToTok at 0x05E630 with each of the 4 magic A values (set in A register) and the key code in D0058E. Use the runtime:
   ```js
   import { createCPU } from './cpu-runtime.js';
   import { createPeripheralBus } from './peripherals.js';
   ```
   Boot with timerInterrupt:false. For each test: set A=magic, (D0058E)=keycode, PC=0x05E630 (or call 0x05C52C directly), IX=0xD1A860, IY=0xD00080, set BIT 4 on IY+5. Run 100 steps. Read DE after return for the token pair. Also check edit buffer at 0xD00A00 for what was written.

3. **Output format**: Print a table like:
   ```
   KeyCode | Primary | Fn(0xFE) | 2nd(0xFC) | Alpha(0xFB) | AlphaLock(0xFA)
   0x60    | 0xXX    | 0xXXYY   | 0xXXYY    | 0xXXYY      | 0xXXYY
   ```
