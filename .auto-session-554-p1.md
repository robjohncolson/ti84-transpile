# Task: Decode 0x07B75F — 4bpp Row Calculation Helper

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by reading raw bytes and disassembling them.

Session 553 decoded 0x0A1A9D (framebuffer address computation, 119B). In the 4bpp rendering path, 0x0A1A9D calls 0x07B75F at address 0x0A1B1C. We need to decode what 0x07B75F does.

## Known context from session 553
- 0x0A1A9D computes framebuffer addresses from (x,y) coordinates
- Three rendering modes: 16bpp (stride 640B, base D40000), 8bpp (stride 320B), 1bpp (stride 40B, base D031CE/D0529E)
- 4bpp mode (IY+0x4A bit 6 set) calls 0x07B75F for row calculation with base D09466
- The eZ80 is in ADL mode (24-bit addresses, 24-bit registers by default)
- `SIS` prefix forces 16-bit operation in ADL mode
- `MLT` multiplies H×L → HL (8-bit × 8-bit → 16-bit)

## Your task
1. Read raw bytes from ROM at offset 0x07B75F (read ~128 bytes to capture the full function)
2. Manually disassemble the eZ80 instructions
3. Identify the function's purpose, inputs, outputs, and any RAM addresses referenced
4. Check for sub-calls and what they do
5. Document the algorithm

## How to read ROM bytes
```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
// Read bytes at offset 0x07B75F
const start = 0x07B75F;
const bytes = rom.slice(start, start + 128);
console.log('Bytes at 0x' + start.toString(16) + ':');
for (let i = 0; i < bytes.length; i += 16) {
  const addr = start + i;
  const hex = Array.from(bytes.slice(i, i + 16)).map(b => b.toString(16).padStart(2, '0')).join(' ');
  console.log('  0x' + addr.toString(16).padStart(6, '0') + ': ' + hex);
}
```

## eZ80 opcode reference (ADL mode)
- 0xC9 = RET
- 0xCD = CALL imm24
- 0x21 = LD HL,imm24 (3-byte immediate in ADL mode)
- 0x11 = LD DE,imm24
- 0x01 = LD BC,imm24
- 0x3E = LD A,imm8
- 0xE5 = PUSH HL, 0xE1 = POP HL
- 0xD5 = PUSH DE, 0xD1 = POP DE
- 0xC5 = PUSH BC, 0xC1 = POP BC
- 0xF5 = PUSH AF, 0xF1 = POP AF
- 0x09 = ADD HL,BC, 0x19 = ADD HL,DE, 0x29 = ADD HL,HL
- 0xED 0x42 = SBC HL,BC, 0xED 0x52 = SBC HL,DE
- 0xED 0x6C = MLT HL (H×L → HL)
- 0x40 prefix (SIS) forces next instruction to 16-bit mode
- 0xCB = bit operations prefix
- 0xFD = IY prefix, 0xDD = IX prefix
- 0xFD 0xCB offset op = BIT/SET/RES on (IY+offset)
- 0x18 = JR offset, 0x20 = JR NZ, 0x28 = JR Z, 0x30 = JR NC, 0x38 = JR C
- 0xC3 = JP imm24, 0xCA = JP Z, 0xC2 = JP NZ, 0xDA = JP C, 0xD2 = JP NC
- 0x7E = LD A,(HL), 0x77 = LD (HL),A
- 0x23 = INC HL, 0x2B = DEC HL
- 0x13 = INC DE, 0x1B = DEC DE
- 0x03 = INC BC, 0x0B = DEC BC
- 0x3C = INC A, 0x3D = DEC A
- 0xB7 = OR A (clear carry)
- 0xAF = XOR A (A=0)
