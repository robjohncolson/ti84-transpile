# Task: Fix EI+HALT in cpu-runtime.js

## Problem
In `TI-84_Plus_CE/cpu-runtime.js`, when the CPU executes HALT with interrupts enabled (cpu.iff1=1), the executor only calls `tick()` ONCE and checks `hasPendingIRQ()`. If the timer hasn't reached its interval yet, no IRQ fires and execution terminates with `termination='halt'`. The real eZ80 CPU would stay in HALT state with the hardware timer ticking until an IRQ fires.

## Current Code (lines 1282-1319)
The relevant section is at approximately line 1282 in the `executeBlock` function:
```js
// HALT: check for peripheral-driven interrupt wake
if (result === -1 && options.peripherals && options.peripherals.tick) {
    options.peripherals.tick();
    // ... checks hasPendingIRQ() once ...
}
```

It calls `tick()` once, checks for NMI, then checks for IRQ. If neither is pending, falls through to termination.

## Required Fix
After the single tick() + hasPendingIRQ() check fails, add a loop that keeps calling tick() until hasPendingIRQ() returns true, but ONLY when cpu.iff1 is set (EI+HALT, not DI+HALT). Use a safety cap of `timerInterval * 2` iterations to prevent infinite loops.

The fix should be inserted AFTER the existing NMI check and existing single-IRQ check (lines ~1287-1319), but BEFORE the DI+HALT bypass block (line ~1322). Specifically, when the single tick didn't produce an IRQ and cpu.iff1 is set:

```js
// EI+HALT: loop tick() until timer fires (real CPU stays in HALT state)
if (cpu.iff1) {
    const maxTicks = (options.peripherals.getTimerInterval ? options.peripherals.getTimerInterval() : 200) * 2;
    for (let t = 0; t < maxTicks; t++) {
        options.peripherals.tick();
        if (options.peripherals.hasPendingNMI()) {
            cpu.halted = false;
            const haltReturnPc = pc + 1;
            cpu.push(haltReturnPc);
            cpu.iff2 = cpu.iff1;
            cpu.iff1 = 0;
            pc = 0x000066;
            options.peripherals.acknowledgeNMI();
            if (opts.onInterrupt) {
                opts.onInterrupt('nmi', haltReturnPc, 0x000066, steps);
            }
            break;
        }
        if (options.peripherals.hasPendingIRQ()) {
            cpu.halted = false;
            const haltReturnPc = pc + 1;
            cpu.push(haltReturnPc);
            cpu.iff1 = 0;
            cpu.iff2 = 0;
            const vector = cpu.im === 2
                ? cpu.read16((cpu.i << 8) | 0xff)
                : 0x000038;
            pc = vector;
            options.peripherals.acknowledgeIRQ();
            if (opts.onInterrupt) {
                opts.onInterrupt('irq', haltReturnPc, vector, steps);
            }
            break;
        }
    }
    if (!cpu.halted) {
        steps++;
        continue;
    }
}
```

Also add a `getTimerInterval()` function to the peripheral bus return object. In `peripherals.js`, in the return object (around line 912), add:
