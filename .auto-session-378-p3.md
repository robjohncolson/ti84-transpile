## eZ80 ADL-mode decoding reference
- 3-byte addresses (24-bit), 3-byte immediates for LD rr,nn
- Prefix bytes: 0xDD=IX, 0xFD=IY, 0xCB=bit ops, 0xED=extended
- CALL nn = 0xCD nn_lo nn_mid nn_hi (4 bytes in ADL)
- JP nn = 0xC3 nn_lo nn_mid nn_hi (4 bytes in ADL)
- RET = 0xC9 (pops 3 bytes in ADL)
- LD A,(nn) = 0x3A nn_lo nn_mid nn_hi
- LD (nn),A = 0x32 nn_lo nn_mid nn_hi
