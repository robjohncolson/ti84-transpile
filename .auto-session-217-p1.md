# Auto-Session 217 P1: Which A value reaches SET 4,(IY+5) at 0x0612B0?

## Context
The edit-mode dispatcher at ROM address 0x061290 branches on the A register value. Session 213 claimed A=0x03 reaches SET 4,(IY+5) at 0x0612B0, but session 216's dynamic trace DISPROVED this — A=0x03 jumps 0x061294→0x0612B6, SKIPPING 0x0612B0 entirely.

The dispatcher structure (from static disassembly, session 213):
- Entry: 0x061290
- CP 0x03 → branch to 0x0612B0 region (calls 0x06121E, 0x0605A4, 0x06C737, then SET 4,(IY+5), JR 0x061287)
- CP 0x04 → branch to 0x0612E4 region (calls 0x06121E, 0x060056, 0x06C737, then SET 4,(IY+5), JR 0x061287)
- Also handles A=0x05 and A=0x1E

But the DYNAMIC trace for A=0x03 goes to 0x0612B6 instead. So we need to test other A values.

## Task
Build a probe `TI-84_Plus_CE/probe-phase217-dispatcher-a-values.mjs` that:

1. Tests A values 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x1E at dispatcher entry 0x061290
2. For each A value:
   - Set up: full boot (z80 boot → kernelInit → memInit), BIT 7,(IY+0x18) forced SET, editCursor 0xD0243A = 0xD00A00, editTail 0xD0243D = 0xD00B00
   - Entry at the parent function 0x06003C (or 0x060048 directly after the BIT 7 test), with A set to the test value
   - Run up to 200 steps
   - Check: did IY+5 change? Specifically, did BIT 4 get SET? Read mem at IY+0x05 (IY=0xD00080, so 0xD00085)
   - Record: steps taken, unique blocks visited, final IY+5 value, whether 0x0612B0 or 0x0612E4 was visited

3. Report which A value(s) actually reach SET 4,(IY+5)
