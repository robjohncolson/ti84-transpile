# Auto-session 598 P2: Command key dispatch — verify 0x099921 is reached

## Context
The TI-84 Plus CE ROM transpilation project lifts eZ80 machine code to JavaScript. Session 597 found that character keys (digits '0'-'9') take a character-insertion path through cxMain → 0x05877A → 0x058EDA, bypassing the 38-entry command dispatcher at 0x099921. The command dispatcher 0x099921 handles function/menu keys (GRAPH, ZOOM, MATH, etc.). We need to verify that a command key DOES reach 0x099921 through the outer event loop.

## Task
Create a probe `TI-84_Plus_CE/probe-phase598-command-key.mjs` that:

1. Determines the correct internal key code for a COMMAND key (GRAPH recommended) by looking up the scan code translation table at ROM address 0x09F79B. 

   **GRAPH key**: SDK group 1, bit 0. Raw scan code = `((7-1)<<4) | 0 = 0x60`. Table index = `((0x60>>4)*8) + (0x60&0x0F) + 1 = (6*8) + 0 + 1 = 49 = 0x31`. Read the byte at `romBytes[0x09F79B + 0x31]` — that's the internal translated code for GRAPH.

   Print the translated code so we know what it is.

2. Boots the OS, runs launch-init (0x09DD62), paints the home screen (0x058241), then seeds the GRAPH key code into D0058C and D0058E, sets D0009F bit 5, and runs the OUTER event loop at 0x08C331 with 500K steps.

3. Tracks whether these addresses are hit:
   - 0x08C331 (outer loop entry)
   - 0x08C3C3 (key cascade start)
   - 0x08C745 (JP (HL) trampoline)
   - 0x0585E9 (cxMain handler)
   - 0x05877A (general key handler)
   - 0x058EDA (key classifier)
   - 0x099921 (38-entry command dispatcher) ← THIS IS THE KEY TARGET
   - 0x07BF19 (quit handler — should NOT be hit for GRAPH)

4. Reports which addresses were hit/missed, the termination state, and post-run values of D0058C, D0058E, D0009F, D007CA, D007E0.

5. **If GRAPH's translated code turns out to be one of the cascade-intercepted codes** (0xB4=QUIT, 0x3F, 0x28, 0x29, 0x7F, 0xFE, 0xFC, 0xFA), then also try a SECOND key: **MATH key** (SDK group 5, bit 2 → raw = `((7-5)<<4)|2 = 0x22`, index = `(2*8)+2+1 = 19 = 0x13`, look up `romBytes[0x09F79B + 0x13]`). Run the same test with that key code.
