# Task: Trace the 0x0302CA Error Recovery Path

## Context
TI-84 Plus CE ROM transpilation project. ROM file at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 395 identified that 0x0302CA is a "panic reset" error recovery path in the key dispatch region:
- Clears edit mode (RES 2,(IY+0x12))
- Restores SP from 0xD007FA
- Sets mode byte to 0x40
- JP 0x08C5D7

0x08C5D7 was decoded in session 388 as an "action dispatch" function but its full behavior from the error recovery entry needs tracing.

## Deliverable
Create `TI-84_Plus_CE/probe-phase396-error-recovery-0302CA.mjs` — a Node.js probe that:
1. Reads ROM.rom directly with `readFileSync`
2. Disassembles from 0x0302CA through at least 0x60 bytes to capture the full error recovery sequence
3. Then disassembles from 0x08C5D7 through at least 0x80 bytes to understand the dispatch target
4. For each function, report:
   - Exact instruction sequence with addresses and hex bytes
   - RAM addresses read/written (especially SP restore from 0xD007FA, mode byte location)
   - IY+offset flags cleared/set
   - Where execution ultimately goes (does 0x08C5D7 eventually return? Loop? JP elsewhere?)
5. Search ROM for all JP/CALL references to 0x0302CA — who triggers the error recovery?
6. Search ROM for all JP/CALL references to 0x08C5D7 — is it only reached from error recovery or also normal dispatch?

## Technical: eZ80 instruction encoding
- eZ80 is Z80-compatible with 24-bit extensions
- Standard Z80 opcodes apply. Key patterns:
  - CB xx = bit operations (BIT/SET/RES)
  - FD CB dd xx = IY+d bit operations (dd=displacement, xx=operation)
  - ED xx = extended ops
  - CD xx xx xx = CALL addr24 (3-byte address, little-endian)
  - C3 xx xx xx = JP addr24
  - 18 xx = JR offset (signed 8-bit relative)
  - 20/28/30/38 xx = JR NZ/Z/NC/C offset
  - 3E xx = LD A,imm8
  - 21 xx xx xx = LD HL,imm24
  - DD = IX prefix, FD = IY prefix
  - F3 = DI, FB = EI, 76 = HALT
  - ED 73 xx xx xx = LD (addr24),SP
  - ED 7B xx xx xx = LD SP,(addr24)
  - In ADL mode (default), addresses are 3 bytes
