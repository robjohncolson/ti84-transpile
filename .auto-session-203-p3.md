### Tokens to Add

1. **Σ( (summation)** — Token: `[0xBB, 0x35]` (2-byte token, BB prefix)
   - Syntax: `Σ(expr, var, start, end)` e.g. `Σ(X, X, 1, 10)` = 55
   - Implementation: iterate var from start to end, sum expr values
   - Use the existing variable substitution pattern

2. **seq(** — Token: `[0xBB, 0x31]` (2-byte token, BB prefix)
   - Syntax: `seq(expr, var, start, end[, step])` e.g. `seq(X², X, 1, 5)` = {1, 4, 9, 16, 25}
   - Implementation: return array of expr values as var goes from start to end
   - Display as comma-separated in braces

3. **solve(** — Token: `[0xBB, 0x36]` (2-byte token, BB prefix)
   - Syntax: `solve(expr, var, guess)` — find zero of expr near guess
   - Implementation: Newton's method or bisection, simple numerical solver
   - Return the x value where expr ≈ 0

4. **piecewise(** — Token: `[0xBB, 0x2E]` (2-byte token, BB prefix)
   - Syntax: `piecewise(expr1, cond1, expr2, cond2, ..., default)`
   - Implementation: evaluate conditions in order, return first matching expr
