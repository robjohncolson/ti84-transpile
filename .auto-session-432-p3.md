# Task: Trace 0x01579B (Timer ARM Function)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

0x01579B is called by 0x00B8BC (DI-protected bzero + timer arm, 87 bytes). The 0x00B8BC function:
- Zeros 3 USB recovery blocks: D176A8 (98 bytes), D1770A (96 bytes), D1776A (77 bytes)
- Writes tick count to D17792 and D176CB (timer latches)
- Calls 0x01579B to arm the timer
- Saves/restores IFF1 (interrupt flag state) around the operation

## Your Task
1. Create a probe script at `TI-84_Plus_CE/probe-phase432-trace-01579B.mjs` that:
   - Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
   - Disassembles from 0x01579B forward until a clear RET boundary
   - Lists all CALL targets
   - Lists all port I/O operations (timer ports are typically in 0xF0xx range on eZ80, but TI-84 CE uses memory-mapped timer at 0xF20000-0xF200FF)
   - Lists all absolute RAM references (0xD0xxxx range)
   - Identifies what timer hardware it configures

2. Create a report at `TI-84_Plus_CE/phase432-01579B-report.md` documenting:
   - Total size in bytes
   - What timer it arms (Timer 1/2/3? Which interrupt?)
   - Configuration values written (count, prescaler, mode)
   - RAM variables accessed (especially D17792/D176CB timer latches)
   - How the timer relates to USB recovery (what happens when it fires?)
   - Any conditional paths (does it check if already armed?)

## Technical Notes
- eZ80 instructions are variable-length (1-6 bytes)
- CALL nn = 0xCD followed by 3-byte LE address (eZ80 ADL mode)
- RET = 0xC9
- TI-84 CE timer hardware is memory-mapped at 0xF20000-0xF200FF:
  - Timer 1: 0xF20000 (count), 0xF20004 (reload), 0xF20008 (match1), 0xF2000C (match2)
  - Timer 2: 0xF20010 (count), 0xF20014 (reload), etc.
  - Timer 3: 0xF20020 (count), etc.
  - Timer control: 0xF20030
  - Timer interrupt status: 0xF20034
  - Timer interrupt enable: 0xF20038
- The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js`
- Look at existing probes for patterns (e.g., `probe-phase431-*.mjs`)
