# Auto-Session 345 — Priority 3: Cross-Reference Syscall Trampolines (0x000080-0x0000FF)

## Context

During TI-84 Plus CE boot, the RST 0x38 instruction vectors to address 0x000038, which dispatches to a table at 0x000080-0x0000FF. The boot path reaches 0x001768 through this mechanism. This table maps to OS services (syscall trampolines).

The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB, raw binary, eZ80 little-endian).

## Task

Create a probe at `TI-84_Plus_CE/probe-phase345-syscall-trampolines.mjs` that:

1. **Statically disassembles the RST handler at 0x000038**. Read ROM bytes starting at 0x000038 and decode the first ~20 instructions to understand how it dispatches. The handler likely reads a return address or table index to determine which syscall to execute.

2. **Dumps the trampoline table at 0x000080-0x0000FF**. Read all 128 bytes. Interpret as 3-byte little-endian addresses (eZ80 uses 24-bit addresses). That gives up to 42 entries (128/3). Print each entry's target address.

3. **For each non-zero target address**, read the first 8 bytes at that target and print them as hex. This gives a fingerprint of what each trampoline jumps to.

4. **Identify 0x001768 in the table** — which entry index maps to 0x001768? This is the one reached during boot.
