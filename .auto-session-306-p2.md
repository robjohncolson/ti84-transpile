# Auto-Session 306 P2: Decode Soft-Key Label Table at 0x02912B

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80).

Session 305 discovered that 0x029024/0x02903C are dialog strings (not F-key labels). The REAL soft-key labels were found at 0x02912B in a length-prefixed format: `0x03 "ESC" 0x02 "OK"` then `"DEGREE"`, `"RAD"`, etc.

## Task
Decode the complete soft-key label table starting at 0x02912B.

### Method
1. Read ROM bytes starting at 0x02912B and parse the length-prefixed entries:
   - Format appears to be: 1-byte length, then that many ASCII characters
   - Continue until you hit a terminator (0x00 or 0xFF) or the format breaks
2. Map ALL entries with their offset from table start
3. Find what code READS this table — search for references to 0x02912B or nearby addresses in the transpiled JS
4. Determine how the soft-key system indexes into this table (by menu ID? by sequential index?)
5. Cross-reference with the dialog string caller pattern: `HL=string_addr + A=menu_code + CALL 0x028F02`

### Deliverables
1. Create `TI-84_Plus_CE/probe-phase306-softkey-labels.mjs` — a probe that:
   - Reads ROM bytes at 0x02912B and parses all length-prefixed entries
   - Prints each entry with its offset and decoded ASCII text
   - Reports total table size and entry count
   - Searches for ROM references to addresses in the table range
2. Write complete table contents as comments at top of probe file

### Constraints
- Do NOT modify `cpu-runtime.js`, `peripherals.js`, `browser-shell.html`, or `scripts/transpile-ti84-rom.mjs`
- Use the same probe pattern as existing probes (see `TI-84_Plus_CE/probe-phase305-softmenu-strings.mjs`)
- Timer interrupts disabled: `createPeripheralBus({ timerInterrupt: false })`

### Reference files
- `TI-84_Plus_CE/probe-phase305-softmenu-strings.mjs` — prior session's string probe (pattern reference AND contains the initial discovery of 0x02912B)
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary

### Success criterion
Complete listing of all soft-key label entries in the table with their offsets, decoded text, and identification of how the OS indexes into them.
