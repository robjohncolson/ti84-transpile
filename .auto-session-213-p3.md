### BCD decode helper
To decode a TI-OS BCD real number from 9 bytes:
```
byte[0] = sign (0x00=positive, 0x80=negative)
byte[1] = exponent (biased: actual = byte[1] - 0x80)
byte[2..8] = mantissa BCD digits (each byte = 2 decimal digits, e.g. 0x31 = "31")
Value = sign × mantissa × 10^(exponent - 13)
Example: [0x00, 0x80, 0x10, 0x00, ...] = +1.0 × 10^(0-0) = 1.0
Example: [0x00, 0x80, 0x20, 0x00, ...] = +2.0
```
