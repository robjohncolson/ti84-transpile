# Task: Decode 0x0A23C0 — Pre-render Setup

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We have decoded 0x0A23E5 (the character renderer) and found it calls 0x0A23C0 early in its execution as a "pre-render setup" step.

## What we know
- 0x0A23E5 is the CHARACTER RENDERER (84B first segment). It calls 0x0A23C0 near the end of its first segment.
- 0x0A23E5's job: RES 0,(IY+35), saves display coords (D008D5→D005A0, 0x4008D2→D1059C), configures char dimensions via IY+20/IY+17 flags, then calls 0x0801B9 and 0x0A23C0.
- 0x061986 wraps 0x0A23E5 (it's the 30-caller "character output wrapper").
- The display pipeline: 0x088F6B → 0x061986 → 0x0A23E5 → 0x0A23C0 → glyph rendering.

2. Determine the function boundaries (look for RET/JP instructions or fall-through patterns).
3. Document: entry conditions, what registers/RAM it reads and writes, what it calls, and its likely purpose.
4. Find how many callers reference 0x0A23C0 across the ROM.

## eZ80 ADL mode reference
- Most instructions are standard Z80 but with 24-bit addresses/registers
- CALL nn = CD xx xx xx (3-byte LE address)
- JP nn = C3 xx xx xx
- RET = C9
- LD r,(IX+d) / LD r,(IY+d) = DD/FD prefix + opcode + displacement
- BIT/SET/RES via CB prefix
- ED prefix for extended ops (ED 17 = LD DE,(HL) in eZ80 long mode)
- SIS prefix (40) = short (16-bit) instruction in ADL mode
