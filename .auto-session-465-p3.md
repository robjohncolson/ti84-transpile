# Task: Decode ROM function at 0x001296

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by reading raw bytes and disassembling eZ80 instructions.

## What to Decode
Function at address **0x001296** in the ROM. This function is called from the OS event handler at 0x00179A:
```
0x00179A: CALL 0x001296
          JR Z 0x0017BC (cleanup — if Z, skip rest of event handler)
```

The event handler at 0x001794 runs a loop (248 iterations via DJNZ). Each iteration:
1. CALL 0x001778 (EI+HALT+countdown via D02658)
2. CALL 0x001296 ← THIS FUNCTION
3. JR Z → cleanup if Z flag set
4. CALL 0x001652 (loop body)
5. IN0 port 0x0F → BIT 7 → BIT 6
6. CALL 0x001783 (another EI+HALT+countdown)
7. JR NZ → loop back

The return value (Z/NZ) gates the event handler loop vs cleanup. Understanding this function explains what the event handler is actually checking each iteration.

Known context: BC=0x500C before the call (from the event handler's port reads). Port 0x500C = FTINTC010 interrupt status register.

## How to Decode
1. Read ROM bytes starting at offset 0x001296 in `TI-84_Plus_CE/ROM.rom`
2. Read 64-128 bytes to capture the function
3. Disassemble the eZ80 instructions manually or use the decoder

Create a probe file `TI-84_Plus_CE/probe-phase465-decode-001296.mjs` that:
1. Loads the ROM file
2. Reads bytes at offset 0x001296 (read ~128 bytes)
3. Prints them as hex dump
4. Uses the eZ80 decoder (`ez80-decoder.js`) to disassemble the instructions
5. Prints the disassembly with addresses

Example pattern (adapt from existing probes):
```js
import { readFileSync } from 'fs';
import { decode } from './ez80-decoder.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const startAddr = 0x001296;
const length = 128;

console.log(`\n=== Decoding function at 0x${startAddr.toString(16).padStart(6, '0')} ===\n`);

// Hex dump
let hexLine = '';
for (let i = 0; i < length; i++) {
    if (i % 16 === 0) {
        if (hexLine) console.log(hexLine);
        hexLine = `0x${(startAddr + i).toString(16).padStart(6, '0')}: `;
    }
    hexLine += rom[startAddr + i].toString(16).padStart(2, '0') + ' ';
}
if (hexLine) console.log(hexLine);

// Disassemble
console.log('\n--- Disassembly ---');
let offset = 0;
while (offset < length) {
    const addr = startAddr + offset;
    try {
        const instr = decode(rom, addr);
        if (!instr || instr.length === 0) {
            console.log(`0x${addr.toString(16).padStart(6, '0')}: DB 0x${rom[addr].toString(16).padStart(2, '0')}`);
            offset++;
        } else {
            const bytes = Array.from(rom.slice(addr, addr + instr.length)).map(b => b.toString(16).padStart(2, '0')).join(' ');
            console.log(`0x${addr.toString(16).padStart(6, '0')}: ${bytes.padEnd(20)} ${instr.mnemonic} ${instr.operands || ''}`);
            offset += instr.length;
        }
    } catch (e) {
        console.log(`0x${addr.toString(16).padStart(6, '0')}: DB 0x${rom[addr].toString(16).padStart(2, '0')} (decode error: ${e.message})`);
        offset++;
    }
    // Stop at RET/JP/JR that looks like function end
    const byte = rom[addr];
    if (byte === 0xC9 && offset > 4) break; // RET
}
```

Also decode functions 0x001778 and 0x001783 (each ~16-32 bytes) for completeness since they're called in the same event handler loop.
