# Auto-Session 361 P2: Investigate 0xA86301 (Archive Flash Terminator)

## Context
TI-84 Plus CE ROM transpilation project. Boot reaches 323 unique blocks (session 360). The final terminator is a missing_block at 0xA86301:adl. This address is in the 0xA00000-0xAFFFFF range — the archive flash region on the TI-84 CE. The execution path to it is: 0x0000FA→0x0000FC→0x002588→0xA86301.

The ROM file is 4MB (0x000000-0x3FFFFF). Address 0xA86301 is OUTSIDE the ROM — it's either unmapped memory, a flash bank that needs switching, or a pointer that was computed incorrectly.

## Task
1. Create a probe `TI-84_Plus_CE/probe-phase361-investigate-A86301.mjs` that:
   a. **Static disassembly**: Read and decode 64 bytes of eZ80 instructions at addresses 0x0000F8-0x000130 (near reset vector area where 0x0000FA lives) and 0x002580-0x0025C0 (around 0x002588 which jumps to 0xA86301)
   b. **Dynamic trace**: Boot from 0x000000 in z80 mode with 50000 max steps, using RAM trampoline (built into cpu-runtime.js). Record the last 30 blocks before the 0xA86301 terminator. Also record any blocks that CALL or JP to addresses >= 0xA00000.
   c. **Memory inspection**: After boot reaches 0xA86301 terminator, dump the 24 bytes at memory addresses 0xA86300-0xA86318 to see what's there (likely zeros since it's outside ROM)
   d. **Analysis**: Is the jump target 0xA86301 coming from a computed address (e.g., loaded from a table in RAM)? Or is it a literal in the code at 0x002588? Check block 0x002588 disassembly for JP/CALL instructions with immediate operands.
2. Run the probe and report findings
