# Auto-Session 214 P1 — Find callers of dispatcher 0x061290

## Context

In the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, session 213 decoded a dispatcher function at ROM address **0x061290**. This dispatcher:
- Takes A register as input
- A=0x03 → branch sets BIT 4,(IY+5) via 0x0612B0
- A=0x04 → branch sets BIT 4,(IY+5) via 0x0612E4
- A=0x05 → calls 0x05CB42
- A=0x1E → another handler

BIT 4,(IY+5) is the **edit-mode flag** that gates digit insertion into the edit buffer. Finding who calls 0x061290 will reveal how the OS enters edit mode on the home screen.

## Task

Create a probe script `TI-84_Plus_CE/probe-phase214-dispatcher-callers.mjs` that:

1. **Static ROM binary scan**: Read `TI-84_Plus_CE/ROM.rom` and scan for all occurrences of:
   - `CD 90 12 06` (CALL.LIL 0x061290, 4-byte ADL CALL)
   - `C3 90 12 06` (JP.LIL 0x061290, 4-byte ADL JP)
   - `CD 90 12` (CALL.SIS 0x061290, 3-byte short CALL — less likely but check)
   - `C3 90 12` (JP.SIS 0x061290, 3-byte short JP)
   Also scan for indirect references:
   - The 3-byte little-endian address `90 12 06` appearing in potential pointer tables (LD HL,0x061290 = `21 90 12 06`)

2. **For each call site found**, report:
   - The ROM address of the CALL/JP instruction
   - The 16 bytes before and 16 bytes after (hex dump) for context
   - Which region it's in (OS core 0x000000-0x050000, editor 0x050000-0x070000, FP/math 0x070000-0x0A0000, apps 0x0A0000+)

3. **Dynamic trace** (if call sites found): For each CALL site, set up cpu-runtime to execute from that site with A=0x03, trace 50 steps, and confirm it reaches 0x061290 and then 0x0612B0 (the SET 4 path).
