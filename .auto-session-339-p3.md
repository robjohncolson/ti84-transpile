# Task: Explore 0x08BFD1 post-VRAM check — BIT 3,(IY+9) gate analysis

## Context

In the TI-84 Plus CE ROM CoorMon event loop (0x08BF22), after the VRAM fill returns, execution reaches 0x08BFD1 which does `BIT 3,(IY+9)`. This might be the gate that decides whether to proceed to cxMain dispatch at 0x08BF82 or return via the epilogue at 0x08BF9E.

Key facts from session 338:
- IY is set to 0xD00080 (IY_BASE), so IY+9 = 0xD00089
- After the VRAM fill, the return chain is: 0x09EFE8→0x09EFEC→0x09F001→0x09F736→0x08C11A→0x0A2E05→0x08BFD1→0x08BF9E (epilogue)
- CoorMon dispatch at 0x08BF82 is NEVER reached with current setup
- cxMain dispatch area at 0x08BF82 is supposed to call the handler at [0xD007CA]

## Your task

Create a probe `TI-84_Plus_CE/probe-phase339-iy9-gate.mjs` that:

1. **Disassembles 0x08BFC5 through 0x08BFF0** (at least 20 instructions around the post-VRAM check area). Show raw bytes + disassembly for every instruction.

2. **Disassembles 0x08BF78 through 0x08BF9E** (the area between key-present target and epilogue, including 0x08BF82 dispatch area). This shows what connects to the dispatch.

3. **Traces the IY+9 byte (0xD00089) throughout a CoorMon call with ENTER key (0x09)**:
   - Value at CoorMon entry
   - Value at GetCSC return
   - Value at key-present branch (0x08BF68)
   - Value at 0x08BFD1 (the BIT 3 check point)
   - Value at epilogue (0x08BF9E)
   - Track ALL writes to 0xD00089 during the CoorMon call (who writes it, when, what value)

4. **Tests what happens if bit 3 of (IY+9) is SET before CoorMon**:
   - Run CoorMon normally first (record trace)
   - Then manually set `mem[0xD00089] |= 0x08` (bit 3) before a second CoorMon call
   - Compare: does the second call reach 0x08BF82?

5. **Surveys all IY+offset references in the 0x08BF22-0x08C000 range**:
   - Disassemble the entire range
   - List every instruction that references (IY+N) with the offset N and the operation (BIT, SET, RES, LD, etc.)
   - This maps out which IY flags CoorMon checks

6. **Checks the broader IY flag state**: read mem[0xD00080] through mem[0xD000A0] (IY+0 through IY+32) after boot+kernel init but before CoorMon. Report all non-zero bytes — these are the initial OS flag state.
