# Auto-Session 456 — P4: Trace 0x03F26D (Called from 0x048AC4 Display State Prologue)

## Context

This is a TI-84 Plus CE ROM transpilation project. The ROM at `TI-84_Plus_CE/ROM.rom` is a 4MB eZ80 binary.

Session 455 found that 0x048AC4 (display state machine driver) has this prologue pattern:
1. Port 0x5005 handshake (LCD controller sync)
2. CALL 0x03F26D
3. Check bit 4 of result
4. If bit 4 set AND D177B7 nonzero → clear D177B7/D1408B/D00896 to 0x00

The function 0x03F26D is the display state check function whose return value (bit 4) gates the D177B7 clearing path. We need to understand what it does.

## Task

Create a probe `TI-84_Plus_CE/probe-phase456-03f26d-trace.mjs` that:

### Part A: Static disassembly
1. Read the ROM file directly
2. Disassemble bytes at 0x03F26D through 0x03F2FF (up to 147 bytes, stop at RET). This is eZ80 ADL mode.
3. Key eZ80 opcodes for reference:
   - `LD A,(nnnnnn)` = 0x3A nn nn nn (24-bit addr, little-endian)
   - `LD (nnnnnn),A` = 0x32 nn nn nn
   - `IN A,(nn)` = 0xDB nn (8-bit port)
   - `IN0 A,(nn)` = 0xED 38 nn (legacy Z80 port, 8-bit)
   - `OUT (nn),A` = 0xD3 nn
   - `OUT0 (nn),A` = 0xED 39 nn
   - `BIT n,A` = 0xCB 47/4F/57/5F/67/6F/77/7F (bit 0-7)
   - `CALL nnnnnn` = 0xCD nn nn nn
   - `JP nnnnnn` = 0xC3 nn nn nn
   - `JP cc,nnnnnn` = 0xC2/0xCA/0xD2/0xDA/0xE2/0xEA/0xF2/0xFA nn nn nn
   - `JR e` = 0x18 ee (signed offset)
   - `JR cc,e` = 0x20/0x28/0x30/0x38 ee
   - `RET` = 0xC9
   - `CP n` = 0xFE nn
   - `AND n` = 0xE6 nn
   - `OR n` = 0xF6 nn
   - `XOR A` = 0xAF
   - `PUSH/POP` AF=0xF5/0xF1, BC=0xC5/0xC1, DE=0xD5/0xD1, HL=0xE5/0xE1, IX=0xDD E5/E1, IY=0xFD E5/E1

### Part B: Dynamic trace
4. Boot to home screen (copy boot sequence from `probe-phase455-timer-irq-exit.mjs`)
5. Set D14091=1, D177B7=0x55, inject key "1" (scan code 0x12)
6. Run with onStep callback tracking when PC enters 0x03F26D-0x03F2FF
7. Record: how many times 0x03F26D is called, what A register value is on entry and exit (check cpu._a), which sub-calls it makes (track CALL targets), and which ports it reads

### Part C: Analysis
8. Identify what 0x03F26D returns (which register, what values)
9. Determine what "bit 4" refers to — is it bit 4 of register A? Of a port value?
10. What does bit 4 being set mean for the display state machine?

## Deliverables

- Console output: disassembly, dynamic trace results, analysis
