# Task: Trace 0x085D3B-0x085D51 parent function (priority 8bbb)

## Context
In the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, session 248 found that 0x088586 (the D02661 latch armer) has a SINGLE CALLER: `JP Z,0x088586` at 0x085D4B. This JP is gated by `LD HL,0xD02661 / BIT 7,(HL)` — when bit 7 is CLEAR, it jumps to arm the latch.

The call at 0x085D4B is preceded by `CALL 0x086C45` at 0x085D3F. We need to understand the parent function containing 0x085D3B-0x085D51 to know what context triggers the D02661 latch armer.

## Task
Create a probe `TI-84_Plus_CE/probe-phase265-085d3b-parent.mjs` that:

1. **Static analysis**: Read the ROM binary and disassemble the region around 0x085D3B:
   - Scan backwards from 0x085D3B looking for a RET/JP/JR boundary (function entry)
   - Scan forwards past 0x085D51 looking for the function end
   - Decode at least 0x085D00-0x085D80 (128 bytes) as eZ80 ADL instructions
   - Identify the function boundary and all CALL/JP/JR targets

2. **Find callers**: Scan the ROM for all CALL/JP instructions targeting the identified function entry. Search patterns:
   - `CD xx xx xx` (CALL addr) where addr matches the function entry
   - `C3 xx xx xx` (JP addr)
   - `C2/CA/D2/DA/E2/EA/F2/FA xx xx xx` (conditional JP)
   - `CC/C4/D4/DC/E4/EC/F4/FC xx xx xx` (conditional CALL)

3. **Dynamic trace**: Run the function with standard home-screen state:
   - PC = function entry, IX=0xD1A860, SP=0xD1A860
   - Seed D02661 = 0x00 (bit 7 clear, so JP Z should fire to arm latch)
   - Run for 500 steps
   - Track: blocks visited, whether 0x088586 is reached, D02661 before/after
   - Also test with D02661 = 0x80 (bit 7 SET, should skip JP Z)

4. **Trace 0x086C45**: This is called just before the D02661 test. What does it do?
   - PC = 0x086C45, run for 200 steps
   - Track blocks and return value

## eZ80 ADL instruction reference (for static decode)
- RET = C9, RET cc = C0/C8/D0/D8/E0/E8/F0/F8
- CALL = CD + 3-byte addr, JP = C3 + 3-byte addr
- JR = 18 + signed byte, JR cc = 20/28/30/38 + signed byte  
- LD r,(addr) = various, LD (addr),r = various
- BIT n,(HL) = CB 46/4E/56/5E/66/6E/76/7E
- JP Z = CA + 3-byte addr
