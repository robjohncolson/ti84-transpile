## Background

- In session 474's bit 4 fix probe: 0x040D11 hit 4 times but VRAM 0 bytes changed
- 0x030300 is the cursor/display prep function gated by D0009D bit 0
- The function likely reads D00591 (cursor address) and D00092 (cursor glyph flags)
- After boot: D00591=0, D00092=0 — both may need to be set for actual pixel writes
