# Auto-Session 511 P2: Decode 0x06868A (Shared Cursor Rendering Call)

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 CPU in ADL mode = 24-bit addresses).

**0x06868A** is a critical shared function called by:
- cursor_draw (0x0B968E)
- cursor_render (0x0B96B3) 
- cursor_erase (0x0B96E3)
- cursor init main loop (0x0B9473)

It is the common rendering dispatch point for ALL cursor operations. Understanding it reveals how cursor glyphs reach the LCD. Previous sessions established that cursor ops are glyph-based (not pixel-based) — cursor_draw writes a glyph index to D005F9 via .SIS, then calls 0x06868A. The actual text rendering pipeline uses 0x0A1799 (674B glyph-to-VRAM rasterizer).

## Task

Create a probe file `TI-84_Plus_CE/probe-phase511-decode-06868A.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom`
2. Disassembles **0x06868A** — dump at least 150 bytes starting there. The function may be large. Decode eZ80 instructions with address, hex bytes, and mnemonic.
3. Follow any CALL targets within the first few levels — if 0x06868A is a thin wrapper (few instructions before a CALL), decode the target too (up to 100 bytes).
4. Specifically look for:
   - Calls to 0x0A1799 (glyph-to-VRAM rasterizer) or 0x0A1B5B (column-tracking wrapper)
   - Calls to 0x07D583 (populator) — this would solve the transitive path question
   - References to D005F9 (active glyph), D008D2/D008D5 (VRAM position), D0069F (cursor table pointer)
   - Any LCD/VRAM-related addresses (D40000+ is VRAM)
5. Print all CALL targets, memory references, and a functional summary.

## Reference: eZ80 instruction encoding

- CALL nn = 0xCD + 3-byte LE address. Conditional: NZ=0xC4, Z=0xCC, NC=0xD4, C=0xDC
- JP nn = 0xC3 + 3-byte addr. JR e = 0x18 + signed 8-bit offset
- LD A,(nn) = 0x3A + 3B. LD (nn),A = 0x32 + 3B
- LD HL,(nn) = 0x2A + 3B. LD (nn),HL = 0x22 + 3B
- ED 5B nn = LD DE,(nn). ED 4B nn = LD BC,(nn)
- RET = 0xC9. Prefix 0x40 = .SIS (16-bit operand in ADL mode)
- FD = IY prefix. FD CB offset opcode = IY bit operations
- CB prefix for bit ops on registers/memory
