# Task: Set cpu.mbase default to 0xD0 in cpu-runtime.js

## Context
The TI-84 Plus CE eZ80 CPU has an MBASE register that provides the upper 8 bits for Z80-mode 16-bit addresses. The real TI-84 CE OS sets MBASE to 0xD0 during boot (at ROM address 0x0013C9 via `LD MB, A`) so that short addresses like 0x059C resolve to RAM at 0xD0059C instead of ROM.

Currently `cpu-runtime.js` line 58 sets `this.mbase = 0;`. This causes the ISR dispatch gate at block 0x000704 to fail — it does `LD A, MB; CP 0xD0; JP NZ, 0x0019B5`, so with MBASE=0 the ISR always exits without dispatching callbacks.

Every consumer already works around this: browser-shell.html sets `cpu.mbase = 0xD0` in 13 places, direct-eval.js sets it at line 77, and most probes set it manually.
