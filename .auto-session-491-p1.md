# Auto-Session 491 — P1: Full Decode of 0x061000 (Text Cursor Erase Function)

## Context

Session 490 confirmed that 0x061000 is the TI-84 CE text cursor erase function. It writes a 12×16 white rectangle (0xFF pixels) directly to VRAM at cursor-computed position. Key findings from session 490:

- Case A (row=0, col=0): VRAM writes at pixels x=2-13, y=37-52
- Case B (row=5, col=13): VRAM writes at pixels x=158-169, y=137-152
- Write positions MOVE with D00595 (row) and D00596 (col)
- Does NOT call 0x0A23C0/0x0A239E — uses direct VRAM writes
- 384 byte diffs = 192 pixels = exactly 12×16 = one character cell
- Writes 0xFF (white) = cursor erase operation

## Task

Create a probe `TI-84_Plus_CE/probe-phase491-decode-061000.mjs` that fully decodes the 0x061000 function:

1. **Static disassembly**: Read raw bytes from ROM.rom starting at 0x061000. Decode each eZ80 instruction manually (using the ROM bytes and ez80 instruction encoding knowledge). Map out the full function until a RET instruction. Show every instruction with address, hex bytes, and mnemonic.

2. **Dynamic trace**: Set up the CPU with `createCPU()` and `createPeripheralBus({ timerInterrupt: false })`. Boot the CPU to idle state (run ~120,000 steps). Then for two test cases (row=0/col=0 and row=5/col=13):
   - Set D00595 (row) and D00596 (col) in memory
   - Snapshot VRAM (0xD40000-0xD52BFF) before
   - Set PC=0x061000, SP to a valid stack area (e.g., 0xD1A87E), push a return address
   - Single-step through the function, logging each PC value, key register values (A, HL, DE, BC, IX, IY), and any memory reads/writes
   - Stop when we return to the pushed return address
   - Diff VRAM after vs before

3. **Analysis**: From the trace, determine:
   - How does 0x061000 compute the VRAM address from D00595/D00596?
   - What formula converts (row, col) → (pixel_x, pixel_y) → VRAM_offset?
   - Does it read any other state variables besides D00595/D00596?
   - What are the entry register requirements (what must be set before calling)?
   - Who calls 0x061000? Search ROM.rom for CALL 0x061000 (bytes CD 00 10 06) and JP 0x061000 (bytes C3 00 10 06)

## Key addresses and constants

- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, load with `fs.readFileSync`)
- D00595 = cursor row (0-9)
- D00596 = cursor column (0-25)
- D0059C = VRAM address variable (3-byte LE pointer into VRAM)
- D008D2 = LCD window X start register
- D008D5 = LCD window Y start register
- VRAM: 0xD40000-0xD52BFF (76,800 bytes, 320×240 at 8bpp)
- Glyph size: 12 pixels wide × 16 pixels tall
- Screen: 26 columns × 10 rows of text
