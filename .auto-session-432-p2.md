# Task: Decode 0x008527 (Deeper USB/Controller Helper)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

0x008527 is called by:
- P7 fallback init (0x009087) — which handles D177B8==0x21 (USB controller power/arm)
- P2 HID/alt-setting init (0x008BE9) — which handles HID device initialization

Both callers are part of the sequential priority init chain at 0x009118 that initializes communication subsystems on the TI-84 CE.

## What We Know About the Callers
- 0x009087 (P7, 145 bytes): Returns A=1 only when D177B8==0x21, checks port 0x3082 bit 4 early-ready, optionally pulses port 0x3080 bit 2 around CALL 0x008527, delays via 0x014FA0 with 2+7 ticks
- 0x008BE9 (P2, 439 bytes): HID/alt-setting init, dispatches on D177B8 via 0x002623, reads D1408D/D1408E interface indices, manipulates ports 0x3114/0x3080, calls 0x006EB6 link-ready + 0x014FA0 packet handler + 0x00883C status

## Your Task
1. Create a probe script at `TI-84_Plus_CE/probe-phase432-trace-008527.mjs` that:
   - Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
   - Disassembles from 0x008527 forward until a clear RET boundary
   - Lists all CALL targets
   - Lists all port I/O operations (IN/OUT with port numbers)
   - Lists all absolute RAM references (0xD0xxxx range)
   - Identifies the function's purpose based on its operations

2. Create a report at `TI-84_Plus_CE/phase432-008527-report.md` documenting:
   - Total size in bytes
   - Function purpose/behavior
   - All CALL targets with brief role descriptions where known
   - Port I/O summary (which ports, which bits, read/write)
   - RAM variables accessed
   - How it relates to P2 and P7 init — what does this helper set up for them?

## Technical Notes
- eZ80 instructions are variable-length (1-6 bytes)
- CALL nn = 0xCD followed by 3-byte LE address (eZ80 ADL mode)
- RET = 0xC9
- IN A,(port) = 0xDB followed by 1-byte port (short form) OR IN r,(C) for register-indirect
- OUT (port),A = 0xD3 followed by 1-byte port (short form) OR OUT (C),r for register-indirect
- Port 0x3080 = USB OTG control/status register
- Port 0x3082 = USB status (bit 4 = early-ready, bits 7:6 = speed/mode)
- Port 0x3114 = USB endpoint register
- The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js`
- Look at existing probes like `probe-phase431-*.mjs` for patterns
