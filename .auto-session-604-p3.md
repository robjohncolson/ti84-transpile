## eZ80 instruction reference (ADL mode)

Key encodings:
- `CD xx xx xx` = CALL addr24; `C3 xx xx xx` = JP addr24
- `18 xx` = JR offset8; `20 xx` = JR NZ; `28 xx` = JR Z
- `10 xx` = DJNZ offset8 (loop with B counter)
- `FE xx` = CP A, imm8
- `3E xx` = LD A, imm8; `06 xx` = LD B, imm8
- `21 xx xx xx` = LD HL, imm24; `11 xx xx xx` = LD DE, imm24; `01 xx xx xx` = LD BC, imm24
- `ED B0` = LDIR; `ED B8` = LDDR
- `C9` = RET; `C0` = RET NZ; `C8` = RET Z
- Addresses are 24-bit little-endian
