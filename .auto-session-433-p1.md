# Task: Trace 0x00E91E (Pre-Enumerate Setup)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 machine code). We have a transpiler that lifts ROM to JavaScript, plus probes that trace ROM functions by disassembling bytes and following CALL/JP targets.

## What to do
Trace and decode the function at ROM address **0x00E91E**. This function is called by:
- P4 (CDC init at ~0x008C8x)
- P5 (Audio init at ~0x008Dxx)
- 0x008527's special 0x98 re-enumeration branch

It appears to be a **pre-enumerate setup** function — preparing state before USB re-enumeration.

## How to trace
1. Read `TI-84_Plus_CE/ROM.rom` starting at offset 0x00E91E
2. Disassemble eZ80 instructions (ADL mode, 24-bit addresses, 3-byte pointers)
3. Follow all CALL targets to identify what they do
4. Document RAM variables read/written (D1xxxx range = USB/Link state)
5. Document port I/O (0x30xx = USB controller ports)
6. Determine the function's size (find the RET instruction)

## eZ80 reference
- CALL nn = 0xCD followed by 3-byte LE address
- JP nn = 0xC3 followed by 3-byte LE address
- RET = 0xC9
- LD A,(nn) = 0x3A + 3-byte LE address
- LD (nn),A = 0x32 + 3-byte LE address
- IN A,(C) = 0xED 0x78 (reads port in BC)
- OUT (C),A = 0xED 0x79 (writes port in BC)
- RST 08h = 0xCF (BC integrity assertion in this ROM)
- Prefix 0xDD = IX, 0xFD = IY, 0xED = extended ops
- __frameset at 0x00218A, _bzero at 0x00285F, _seqcase at 0x002623
