# Task: Map D01EB1-D01EF9 Token Descriptor Block Contents at Boot

## Context

Session 505 decoded 0x096C03 (35-byte cursor-type-indexed table selector). It selects one of three (HL, DE) pointer pairs based on cursor type from D02575:
- **Type 0**: HL=D01EB1, DE=D01ECC
- **Type 1**: HL=D01EBA, DE=D01ED5
- **Type ≥2**: HL=D01EDE, DE=D01EF9

The caller at 0x096BD3 reads the first byte of the selected block: `LD A,(HL); CP 0x0E`. If the byte equals 0x0E, it takes an alternate path; otherwise it enters the blink toggle.

These D01Exx addresses are RAM, not ROM. We need to know what the OS writes there during boot to understand the token descriptor format and what 0x0E means.
