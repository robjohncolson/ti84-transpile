# Task: Trace 0x01322D (Indirect Callback Dispatcher)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 machine code). We trace ROM functions by disassembling bytes and following CALL/JP targets.

## What to do
Trace and decode the function at ROM address **0x01322D**. This function is called by 0x008527 (USB follow-up helper) with argument **0x0800**. It appears to be an **indirect callback dispatcher** that routes through a slot at RAM address **D14026**.

Key questions:
1. How does 0x01322D use the 0x0800 argument?
2. How does it read/use D14026 as a callback slot?
3. What other callers exist? (Search the ROM for bytes 0xCD 0x2D 0x32 0x01 which encode CALL 0x01322D in eZ80)
4. What callbacks could D14026 point to?

## How to trace
1. Read `TI-84_Plus_CE/ROM.rom` starting at offset 0x01322D
2. Disassemble eZ80 instructions (ADL mode, 24-bit addresses)
3. Follow all CALL targets to identify subroutines
4. Document RAM variables read/written
5. Document port I/O (0x30xx = USB controller ports)
6. Search the entire ROM for the CALL encoding to find all callers
7. Search the entire ROM for writes to D14026 (bytes 0x26 0x40 0xD1 in LD (nn),A or LD (nn),HL patterns)

## eZ80 reference
- CALL nn = 0xCD followed by 3-byte LE address (little-endian)
- JP nn = 0xC3 followed by 3-byte LE address
- RET = 0xC9
- LD A,(nn) = 0x3A + 3-byte LE address
- LD (nn),A = 0x32 + 3-byte LE address
- LD HL,(nn) = 0x2A + 3-byte LE address
- IN A,(C) = 0xED 0x78
- OUT (C),A = 0xED 0x79
- RST 08h = 0xCF (BC integrity assertion)
- __frameset at 0x00218A, _bzero at 0x00285F
