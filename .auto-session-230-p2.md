# Task: Trace 0x02FE84 — the special path for key codes ≥0xE2 and <0xFC

## Context
Session 229 decoded the key lookup function at 0x0300F1-0x030172. After looking up the key code from the 09F79B table:
- If key code < 0xE2: normal write to D0058E (JR C)
- If key code ≥ 0xFC: special path (JR NC)  
- If 0xE2 ≤ key code < 0xFC: `LD (D0058E),A / LD A,0xFC / JP 0x02FE84`

We need to understand what 0x02FE84 does with these key codes (0xE2-0xFB range). These are likely modifier keys or special function codes.

## Steps

1. Build a probe `TI-84_Plus_CE/probe-phase230-02fe84-special-path.mjs` that:

   a. Uses the standard probe pattern from this repo. Look at `TI-84_Plus_CE/probe-phase229-03011c-key-lookup.mjs` for the import/boot pattern (createCPU, createMemory, loadROM from cpu-runtime.js, createPeripheralBus from peripherals.js with timerInterrupt:false).

   b. For each key code in the 0xE2-0xFB range that appears in the 09F79B table (test at least 4-5 representative values like 0xE2, 0xE5, 0xEA, 0xF0, 0xF5, 0xFB), do a dynamic trace:
      - Set PC = 0x02FE84
      - Set A = 0xFC (as the function at 0x030100 sets before JP 0x02FE84)
      - Set D = 0x01 (the D=0x01 flag set by the key lookup function)
      - Pre-seed D0058E with the actual key code value
      - Run for 200 steps
      - Log: blocks visited, any RAM writes (especially to D0058E, D0058D, D0059F, IY flag area 0xD00080-0xD000FF), final register state
      - Check if it returns (hits RET) or falls into another handler

   c. Also trace what happens when key code ≥ 0xFC (the JR NC path from the lookup function). Pick 0xFC and 0xFE as test values.

   d. Print a summary table: key_code → behavior (what RAM gets written, what path is taken, how many steps to RET).

2. Run the probe:
   ```bash
   node TI-84_Plus_CE/probe-phase230-02fe84-special-path.mjs
   ```

3. Report findings.

## Key addresses
- 0x02FE84: target of JP from key lookup function
- 0x09F79B: key code lookup table (4 sections × 56 entries)
- D0058E: key code output variable
- D0058D: secondary key state
- D0059F: magic A / key state variable
- IY base: 0xD00080
