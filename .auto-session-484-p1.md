## Key addresses and conventions

- 0x0059C6 = character output function, takes A = character code
- D00595 = cursor row (0-9, wraps at 10)
- D00596 = cursor column (0-25, wraps at 26 = 0x1A)
- D0059C = VRAM address (3 bytes, computed by renderer)
- VRAM base = 0xD40000
- VRAM formula: 0xD40000 + (row×20+37)×640 + (col×12+2)×2
- Sentinel address: 0x500000 (between ROM and RAM)
- Stack: use cpu.sp value after boot, push 3-byte sentinel return
