# Task: Decode ROM function at 0x0994D7

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by writing probe scripts that read ROM bytes and trace execution.

## Target
**0x0994D7** — Token renderer. This function is part of the TI-OS display/edit system. It handles rendering token representations on screen. Carried forward from session 524 as a priority.

## What we know
- eZ80 CPU in ADL mode (24-bit addresses, 3-byte pointer loads)
- Display system: VRAM at D3FD80, font base at 0x003D6E, glyph size 28 bytes (char*28)
- 0x0A1B5B = char render wrapper (delegates to 0x0A1799 with char in A, handles substitutions, wraps at 26 cols)
- 0x0A1799 = font lookup + rasterizer (MLT HL char*28, VRAM=D3FD80+row*640, 16/18-row glyph loop)
- 0x09BAFF = extended token classifier (34 CP comparisons, 23 targets, B-register type codes)
- 0x09BAB8 = token reader (reads from curPC at D0231A)
- 0x09BF58 = token-type range dispatcher
- 0x097757 = post-allocation handler with token metadata + inline string rendering loop
- IY+0x4C, IY+0x53, IY+12, IY+72, IY+73 = various OS flags
- D0231A = curPC (current program counter for token stream)
- D00335 = display buffer pointer
- D00596 = curCol (current column, wraps at 26)

## Deliverable
Create a probe script at `TI-84_Plus_CE/probe-phase529-decode-0994D7-token-renderer.mjs` that:

1. Reads ROM bytes from 0x0994D7 for ~120 bytes and does hex dump
2. Identifies all CALL/JP/JR/RET instructions and their targets
3. Reads ROM bytes at each unique sub-target for ~24 bytes
4. Documents findings

### eZ80 ADL-mode decoding reference
- 3-byte addresses for JP/CALL: opcode + addr_low + addr_mid + addr_high
- CALL nn = CD + 3-byte addr, JP nn = C3 + 3-byte addr
- JR e = 18 + signed offset, JR Z = 28, JR NZ = 20, JR C = 38, JR NC = 30
- Conditional CALL: CALL Z = CC, CALL NZ = C4, CALL C = DC, CALL NC = D4
- Conditional JP: JP Z = CA, JP NZ = C2, JP C = DA, JP NC = D2
- RET = C9, RET Z = C8, RET NZ = C0, RET C = D8, RET NC = D0
- LD A,(nn) = 3A + 3-byte addr, LD (nn),A = 32 + 3-byte addr
- LD A,n = 3E + byte, CP n = FE + byte, AND n = E6 + byte
- PUSH/POP: AF=F5/F1, BC=C5/C1, DE=D5/D1, HL=E5/E1
- IX prefix = DD, IY prefix = FD
- BIT b,(IY+d) = FD CB dd bb
- RST nn = C7/CF/D7/DF/E7/EF/F7/FF (restart to fixed addresses)

### Template
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function readROM(addr, len) {
  return Array.from(rom.slice(addr, addr + len));
}

function hex(b) { return b.toString(16).padStart(2, '0'); }
function hex6(a) { return '0x' + a.toString(16).padStart(6, '0'); }
function addr24(bytes, off) { return bytes[off] | (bytes[off+1] << 8) | (bytes[off+2] << 16); }

// Read main function
const mainBytes = readROM(0x0994D7, 120);
console.log('=== 0x0994D7 ROM bytes (120) ===');
for (let i = 0; i < mainBytes.length; i += 16) {
  const chunk = mainBytes.slice(i, i + 16);
  console.log(hex6(0x0994D7 + i) + ': ' + chunk.map(hex).join(' '));
}

// Find control flow
const targets = [];
let retAddrs = [];
for (let pc = 0; pc < mainBytes.length; pc++) {
  const op = mainBytes[pc];
  
  // Handle IX/IY prefixed instructions (skip 4-byte BIT/SET/RES)
  if (op === 0xDD || op === 0xFD) {
    if (mainBytes[pc + 1] === 0xCB) {
      pc += 3; // 4-byte IX/IY CB prefix instruction
      continue;
    }
    pc++; // skip prefix, process next byte normally
    continue;
  }
  
  // CALL nn or conditional CALL nn
  if ([0xCD, 0xCC, 0xC4, 0xDC, 0xD4].includes(op)) {
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      targets.push({ from: 0x0994D7 + pc, target, op: hex(op) });
      pc += 3;
    }
  }
  // JP nn or conditional JP nn
  else if ([0xC3, 0xCA, 0xC2, 0xDA, 0xD2].includes(op)) {
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      targets.push({ from: 0x0994D7 + pc, target, op: hex(op) });
      pc += 3;
    }
  }
  // JR variants
  else if ([0x18, 0x20, 0x28, 0x30, 0x38].includes(op)) {
    const offset = mainBytes[pc + 1];
    const signed = offset > 127 ? offset - 256 : offset;
    const target = 0x0994D7 + pc + 2 + signed;
    targets.push({ from: 0x0994D7 + pc, target, op: hex(op) + ' (JR)' });
    pc += 1;
  }
  // RET variants
  else if ([0xC9, 0xC8, 0xC0, 0xD8, 0xD0].includes(op)) {
    retAddrs.push(0x0994D7 + pc);
    if (op === 0xC9) {
      console.log(`\nUnconditional RET at ${hex6(0x0994D7 + pc)}`);
      break;
    }
  }
}

console.log('\n=== Branch targets ===');
for (const t of targets) {
  console.log(`${hex6(t.from)} [${t.op}] → ${hex6(t.target)}`);
}

console.log('\n=== RET locations ===');
retAddrs.forEach(a => console.log(hex6(a)));

// Read sub-targets
const uniqueTargets = [...new Set(targets.map(t => t.target))];
for (const t of uniqueTargets) {
  if (t >= 0 && t < rom.length) {
    const bytes = readROM(t, 24);
    console.log(`\n=== ${hex6(t)} (24 bytes) ===`);
    console.log(bytes.map(hex).join(' '));
  }
}
```
