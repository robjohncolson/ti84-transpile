# Auto-Session 206, Priority 3: Test JP (HL) at 0x0585D3 with different context table entries

## Context

In the TI-84 Plus CE ROM transpilation project, session 204 decoded the pointer table at 0x0585D4:
- [0] = 0x058585 (unknown)
- [1] = 0x058B19 (cxPPutaway)
- [2] = 0x058B7E (unknown)
- [3] = 0x0582BC (home body!)
- [4] = 0x058BA9 (cxErrorEP — STAT entry)
- [5] = 0x058C01 (unknown)

The JP (HL) at 0x0585D3 selects which context function runs. Session 205 confirmed cxMain (entry [3] = 0x0582BC via 0x0585E9) is the default home-screen digit path. But we haven't explored what entries [0], [2], and [5] do.

## Technical Setup

Same pattern as `probe-phase205-cxmain-digit-trace.mjs`:

```javascript
import { createCPU } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';
import fs from 'fs';

const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
const transpiled = fs.readFileSync('TI-84_Plus_CE/ROM.transpiled.js', 'utf-8');

const bus = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(bus);

for (let i = 0; i < rom.length; i++) cpu.mem[i] = rom[i];

const fn = new Function('cpu', 'mem', 'read8', 'read16', 'read24', 'write8', 'write16', 'write24', transpiled + '\nreturn blockMap;');
const blockMap = fn(cpu, cpu.mem, cpu.read8.bind(cpu), cpu.read16.bind(cpu), cpu.read24.bind(cpu), cpu.write8.bind(cpu), cpu.write16.bind(cpu), cpu.write24.bind(cpu));
```

- IY = 0xD00080 (standard)
