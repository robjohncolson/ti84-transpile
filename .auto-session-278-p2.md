# Task: Trace 0x04C885 — dispatch table match handler

## Context
In the TI-84 Plus CE ROM, the dispatch table polling loop at 0x084711 does a linear search through 9-byte entries in the D3Fxxx region. When a match is found (CP (HL) succeeds against D005F9, then D005FA and D005FB also match), execution jumps to 0x04C885.

Session 271 identified this: "on match checks D005FA/D005FB → dispatch via 0x04C885". But nobody has traced what 0x04C885 actually DOES with the matched entry.

The dispatch table entries are 9 bytes. After the 3-byte key match (D005F9/FA/FB), the remaining 6 bytes likely contain a handler address or data pointer. 0x04C885 presumably extracts this and either calls or jumps to it.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase278-04c885-handler.mjs` that:

1. **Static disassembly of 0x04C885**: Read ROM bytes starting at 0x04C885 and decode eZ80 ADL instructions for ~50 bytes (or until a RET/JP terminates the block). Log each instruction with address, opcode bytes, and mnemonic. Key things to look for:
   - Does it load from (HL) or offset from HL to get a handler address?
   - Does it do JP (HL), CALL (HL), or JP to an absolute address?
   - Does it store anything to D005F8 (the post-dispatch result byte)?
   - Does it modify the D0259x pointer cluster?

2. **Dynamic trace from 0x04C885**: Set up a simulated match scenario:
   - Cold boot with timer IRQ disabled
   - Seed a fake 9-byte entry at D3FFF6 (= D3FFFF - 9):
     - Bytes 0-2: key bytes (e.g., 0x49, 0x00, 0x00 for key D005F9=0x49)
     - Bytes 3-5: a handler address (e.g., 0x058322 = home screen redraw, little-endian: 0x22, 0x83, 0x05)
     - Bytes 6-8: padding zeros
   - Set D0259A = 0xD3FFF6 (table-top pointer)
   - Set HL to point at the matched entry's position within the 9-byte record where 0x04C885 expects it
   - Set PC = 0x04C885
   - Trace 100 steps, logging blocks visited and any CALL/JP targets

3. **Report**: What does 0x04C885 do? Is it a direct JP (HL) to a handler address from the entry, or does it do further processing?
