# Auto-Session 226 — P3: Trace 0x051CF3 Callers and HL Table Source

## Context
This is a companion to P1. Session 225 found that D0059F (the key modifier state variable) has ONLY 1 WRITE SITE in the entire ROM — at 0x051D4D inside function 0x051CF3. The instruction is `LD A,(HL); LD (D0059F),A`. The magic values 0xFA-0xFE that control secondary token tables come from whatever table HL points to.

Session 225 also found 6 READ SITES for D0059F:
- 0x04EA11 (ConvKeyToTok caller, BIT 7,A gate)
- 0x04ECAD (CP (HL) comparison)  
- 0x051B7C (CP 0x80 check)
- 0x051D63 (BIT 7 — internal to writer function)
- 0x051D7A (BIT 6+5 — internal)
- 0x051DC1 (BIT 6 — internal)

## Task
Build a probe `TI-84_Plus_CE/probe-phase226-051cf3-callers-hl.mjs` that:

1. **Find ALL callers of 0x051CF3**: Scan ROM.rom (0x000000-0x0BFFFF) for:
   - `CD F3 1C 05` (ADL CALL 0x051CF3)
   - `C3 F3 1C 05` (ADL JP 0x051CF3)
   - Also scan for calls to nearby addresses 0x051CF0-0x051D00 in case there are alternate entry points

2. **For each caller found**, read 32 bytes BEFORE the call instruction and disassemble them. The goal is to find what sets HL before calling 0x051CF3. Look for patterns like:
   - `LD HL,<table_addr>` (direct table pointer)
   - `LD HL,(mem_addr)` (indirect table pointer from RAM)
   - `ADD HL,<offset>` (computed table pointer)

3. **Trace the 3 internal BIT test sites** (0x051D63, 0x051D7A, 0x051DC1):
   - Read ROM bytes at each address and disassemble the surrounding 20 bytes
   - Determine what branches the BIT tests control
   - These test bits 7, 6, 5 of A (the value just loaded from the table) — document what each bit-pattern means

4. **Check for pointer table references**: Search ROM for bytes `F3 1C 05` that might appear in a pointer table (not as part of a CALL/JP instruction). This catches indirect calls via `CALL (HL)` or `JP (HL)` patterns.

5. **Map the function's behavior tree**: Based on static disassembly (read 0x051CF3 to 0x051E20), create a control flow summary:
   - Entry conditions (what registers must be set)
   - All branches (what BIT tests gate which paths)
   - All side effects (what RAM is written besides D0059F)
   - Return conditions
