# Task: Add transpiler seed at 0x022264 (LCD write-enable missing block)

## Goal
Add 0x022264 as a new transpiler seed so the block at that address gets lifted to JavaScript. This is a missing block on the LCD write-enable path identified in session 251.

## Background
Session 251 found that 0x022264 is a **missing block** (not transpiled). It's on the LCD write-enable path:
- 0x022264(missing) → 0x02226C(JP 0x05529B) → 0x05529B(LD A,(D000C6); BIT 2,A; JR Z,0x0552B1) → 0x0552B1(RET)
- The SET at 0x05527B (SET 2,(IY+0x46) = SET 2 of D000C6) is reached via JP from 0x022264's successor.

## Deliverables

1. Add `0x022264` to the seed file `TI-84_Plus_CE/phase200-seeds.txt` (append it to the end of the file with a comment).
2. Run the transpiler: `node scripts/transpile-ti84-rom.mjs` and verify it completes without errors.
3. Run the golden regression: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs` and verify 26/26 cells pass.
4. Report: the new total seed count, block count, and whether 0x022264 now appears in the transpiled output.

## How to add a seed
Open `TI-84_Plus_CE/phase200-seeds.txt` and append:
