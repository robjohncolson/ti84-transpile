# Task: Search for Alternative Text Cursor Blink Path

## Context
We are reverse-engineering the TI-84 Plus CE OS ROM (eZ80) to find the TEXT CURSOR BLINK function. The ROM is lifted to JavaScript. Sessions 483-488 identified the rendering pipeline: 0x0A23C0 (character render) and 0x0A239E (pixel renderer). The cursor blink at 0x030173 was confirmed as a STATUS BAR indicator only (fixed position row=2, col=289). Session 487 found 6 candidates that reference both D00595/D00596 (cursor position) and 0x0A23C0/0x0A239E. Session 488 eliminated the top 2 (0x05C780 and 0x0817C0). Remaining candidates: 0x05E400, 0x061BC0, 0x08B3C0, 0x0A2300.

**NEW HYPOTHESIS**: The text cursor blink may NOT use 0x0A23C0/0x0A239E at all. It might write VRAM directly, or use a completely different rendering mechanism (e.g., LCD window registers to XOR a rectangular region).

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase489-alt-cursor-search.mjs` that:

1. **Search remaining candidates**: For each of 0x061BC0, 0x08B3C0, 0x0A2300:
   - Boot to idle state
   - Set D00595=3, D00596=10, D00092=0x16
   - Call the function directly
   - Record VRAM writes (count, position range)
   - Reset and call with D00595=7, D00596=20
   - Compare — do VRAM positions change?
   - Print conclusion for each

2. **Search for DIRECT VRAM writers that read cursor position**: Scan the ROM for code patterns where:
   - A function reads D00595 or D00596 (bytes: `3A 95 05 D0` for `LD A,(D00595)` or `2A 95 05 D0` for `LD HL,(D00595)`)
   - AND within 100 bytes, writes to VRAM range 0xD40000-0xD65800 (look for instructions that compute addresses in this range)
   - This is a byte-pattern search of the ROM file, not a dynamic test

3. **Search for LCD window register XOR blink**: The LCD controller has window registers that can define a rectangular region for XOR drawing. Search ROM for code that:
   - Reads D00595/D00596
   - AND writes to port addresses in the 0x4000-0x4020 range (LCD controller ports)
   - This would indicate a hardware-accelerated cursor blink

4. **Report summary**: List all functions found, with their relationship to D00595/D00596 and rendering mechanism.
