# Task: Map the D17731-D1773A buffer consumers

## Context
We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80, 4MB at `TI-84_Plus_CE/ROM.rom`). Session 287 identified that the full keyboard matrix scanner at 0x046500 writes 10 scan results to RAM addresses D17731-D1773A (via a DJNZ loop). The next question is: who READS from this buffer? The consumer of this buffer is likely the function that converts raw scan codes into the OS-level key code stored at D0058C (the GetCSC result byte).

## Deliverable
Create a probe file: `TI-84_Plus_CE/probe-phase288-d17731-consumers.mjs`

## What to do
1. Search the ROM for all instructions that reference addresses in the range D17731-D1773A. Look for:
   - LD A,(D17731) patterns: 0x3A followed by 3-byte LE address
   - LD HL,D17731 patterns: 0x21 followed by 3-byte LE address (used as pointer)
   - LD reg,(addr) variants for other registers
   - Also search for the base address D17731 as a 3-byte little-endian pattern anywhere (31 77 D1) — may be loaded as a pointer
2. For each reference found, determine if it's a READ or WRITE:
   - READ: LD A,(addr), LD r,(addr), LD rr,(addr) — these consume the buffer
   - WRITE: LD (addr),A, LD (addr),rr — these produce into the buffer (already known: 0x046500)
3. For each READ site, decode the surrounding function context to understand what it does with the buffer data.
4. Also check D0058C and D0058E (GetCSC result bytes) — search for WRITE sites to these addresses. Cross-reference: do any of the D17731 readers also write to D0058C?

## Technical details
- Import the decoder: `import { decodeInstruction } from './ez80-decoder.js';`
- ROM file: `ROM.rom` in the same directory
- eZ80 ADL mode (24-bit addressing)
- RAM addresses in the ROM appear as 3-byte little-endian operands
- D17731 in LE = 0x31 0x77 0xD1; D0058C in LE = 0x8C 0x05 0xD0; D0058E in LE = 0x8E 0x05 0xD0
- Known context: 0x046500 WRITES to D17731-D1773A. We want to find who READS from it.
- Session 287 noted that neither the 0x040Fxx cluster nor the 0x0465xx cluster writes to D0058C/D0058E

## Success criterion
The probe identifies all ROM locations that READ from the D17731-D1773A buffer, and determines whether any of them also write to D0058C (connecting the hardware scan buffer to the GetCSC result).
