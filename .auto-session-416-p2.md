## Technical Details
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, little-endian eZ80)
- eZ80 instructions: variable length 1-6 bytes
- Common patterns:
  - CALL nn: CD <low> <mid> <high> (4 bytes in .LIL mode)
  - JP nn: C3 <low> <mid> <high>
  - RET: C9
  - LD A,(nn): 3A <low> <mid> <high>
  - LD (nn),A: 32 <low> <mid> <high>
  - XOR A: AF (sets A=0)
  - CP n: FE <n>
  - JR Z,offset: 28 <offset>
  - JR NZ,offset: 20 <offset>
- D176FC and D1772D are single-byte RAM flags used in the 0x0150C2 dispatcher
