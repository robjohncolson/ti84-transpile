# Auto-Session 253 — P1: Find RAM pointer that dispatches to 0x062055

## Context
We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80). The function at 0x062055 contains the sole CALL to cxMain (0x058241) at address 0x0620C4. Session 252 confirmed that 0x062055 and 0x0620C4 have ZERO static callers — no CALL/JP to either address in the entire ROM. The function is reached entirely via computed dispatch (function pointer / JP (HL) / CALL (HL)).

Session 252 also found a **context handler table at 0x08C958** (20 3-byte entries). The table lookup function at 0x08C94B does: `LD E,A / LD D,3 / MLT DE / LD HL,0x08C958 / ADD HL,DE / LD HL,(HL) / RET` — returns handler[A] in HL. Entry [0] = 0x058241 (cxMain). The sole caller of 0x08C94B is CALL at 0x08C831 in context dispatcher at ~0x08C808.

## Task
Write a probe that searches the ROM for references to 0x062055 as a DATA value (not as a CALL/JP target — those were already checked). Specifically:

1. **Search ROM bytes for the 3-byte little-endian encoding of 0x062055** (bytes: 0x55, 0x20, 0x06). Scan the entire ROM (0x000000-0x3FFFFF) from `TI-84_Plus_CE/ROM.rom`. Report ALL hit addresses.

2. **Search ROM bytes for the 3-byte LE encoding of 0x08C808** (bytes: 0x08, 0xC8, 0x08) — this is the context dispatcher. Report ALL hit addresses.

3. **Search for any JP (HL) instructions** (opcode 0xE9) within ±64 bytes of any hits from steps 1-2. Disassemble the surrounding context (±16 bytes) using the ROM hex dump.

4. **Check RAM region D00000-D0FFFF documentation**: search the ROM for LD instructions that store 0x062055 into any RAM address. Pattern: look for `LD (nnnnnn),HL` (opcode ED 23 nn nn nn in eZ80 ADL mode, or 22 nn nn in Z80 mode) preceded by `LD HL,0x062055` (opcode 21 55 20 06 in ADL mode).
