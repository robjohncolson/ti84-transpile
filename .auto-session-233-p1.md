# Task: Trace 0x02FDE7/0x02FDFE caller context (eee)

## Context
In the TI-84 Plus CE ROM transpilation project, session 232 fully decoded function 0x02FE89 which is the SET 0,(IY+29) key-repeat armer. That function has exactly 2 callers:
- JP NZ at 0x02FDE7 jumping to 0x02FE89
- JP NZ at 0x02FDFE jumping to 0x02FE89

We need to trace what function contains these JP NZ instructions, and specifically what sets register A before the jump (since 0x02FE89 uses CP 0xFF to decide whether to arm the timer gate).

The probe should:
1. **Disassemble the region around 0x02FDE7 and 0x02FDFE** — find the function boundary (look for a RET instruction before the function start). Scan backwards from 0x02FDE0 looking for RET (0xC9) or other function-terminator patterns. Read ROM bytes from `TI-84_Plus_CE/ROM.rom` directly (4MB binary, flat address space).

3. **Trace what loads A before each JP NZ** — disassemble the 20-30 bytes preceding 0x02FDE7 and 0x02FDFE to see what instructions set A. Likely candidates: LD A,(memory), LD A,register, or A is passed from a CALL return.

cpu.memory[cpu.sp] = SENTINEL & 0xFF;
cpu.memory[cpu.sp + 1] = (SENTINEL >> 8) & 0xFF;
cpu.memory[cpu.sp + 2] = (SENTINEL >> 16) & 0xFF;
