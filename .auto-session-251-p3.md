## Task

Edit `TI-84_Plus_CE/browser-shell.html` to add the following direct-eval token handlers. Follow the EXACT pattern of existing token registrations in `runDirectEvalTemplate`.

### Tokens to add (check each doesn't already exist before adding):

1. **1-PropZTest** [0xBB, 0x57] — One-proportion z-test. Args: p0, x, n. Returns: z = (x/n - p0) / sqrt(p0*(1-p0)/n), p-value from normalcdf.

2. **2-PropZTest** [0xBB, 0x58] — Two-proportion z-test. Args: x1, n1, x2, n2. Returns: z, p-value.

3. **1-PropZInt** [0xBB, 0x55] — One-proportion z-interval. Args: x, n, C-level. Returns: (p̂ - E, p̂ + E) where E = z* × sqrt(p̂(1-p̂)/n).

4. **2-PropZInt** [0xBB, 0x56] — Two-proportion z-interval. Args: x1, n1, x2, n2, C-level. Returns interval.

5. **ZTest** [0xBB, 0x59] — One-sample z-test. Args: μ0, σ, x̄, n. Returns: z = (x̄ - μ0)/(σ/√n), p-value.

6. **TTest** [0xBB, 0x5A] — One-sample t-test. Args: μ0, x̄, Sx, n. Returns: t = (x̄ - μ0)/(Sx/√n), p-value, df=n-1.

7. **ZInterval** [0xBB, 0x53] — One-sample z-interval. Args: σ, x̄, n, C-level. Returns: (x̄ - E, x̄ + E).

8. **TInterval** [0xBB, 0x54] — One-sample t-interval. Args: x̄, Sx, n, C-level. Returns: (x̄ - E, x̄ + E) using invT.
