# Task: Map D177BD-D177C9 Display Callback Cluster

## Context
You are working on a TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian).

Session 314 discovered 5 callback slots in RAM at addresses 0xD177BD, 0xD177C0, 0xD177C3, 0xD177C6, 0xD177C9 — a 3-byte stride cluster. These are used by the _indcall infrastructure (indirect call trampolines at 0x00015C and 0x002288). They appear to be display-layer event hooks.

Each slot holds a 24-bit address (3 bytes little-endian) that gets loaded into IY and then called via JP (IY).

## Your Task
1. Create a probe `TI-84_Plus_CE/probe-phase315-display-callbacks.mjs` that:
   a. For each of the 5 slot addresses (0xD177BD, 0xD177C0, 0xD177C3, 0xD177C6, 0xD177C9), scan the entire ROM for any instruction that WRITES to that address. Write patterns to look for:
      - `LD (addr),HL` = opcode 0x22 followed by 3-byte addr (little-endian: BD 77 D1, C0 77 D1, etc.)
      - `LD (addr),BC` = ED 43 followed by addr
      - `LD (addr),DE` = ED 53 followed by addr
      - `LD (addr),IX` = DD 22 followed by addr
      - `LD (addr),IY` = FD 22 followed by addr
      - `LD (addr),A` = 0x32 followed by addr (single byte write, less likely for 24-bit slot)
   b. For each write site found, look at surrounding context (bytes before and after) to determine what value is being stored. If HL is being loaded with an immediate before the store (LD HL,imm24 = 0x21 followed by 3 bytes), extract that immediate — it's the callback target.
   c. For each slot, also find all READ sites (instructions that load FROM the slot address):
      - `LD HL,(addr)` = 0x2A followed by addr
      - `LD IY,(addr)` = FD 2A followed by addr
      - etc.
   d. For any callback target addresses found in (b), disassemble the first 10-20 bytes at that ROM address to understand what the callback does.
   e. Print a per-slot summary: slot address, write sites (ROM addresses + what they store), read sites, callback target if determinable, first few disassembled bytes of target.

2. Run the probe and capture output.
3. Create a report `TI-84_Plus_CE/phase315-display-callbacks-report.md`.
