# Task: Map D177DB/D177D8/D177DE/D177CC/D177CF (Frame Pacing State Variables)

## Context
You are working on a TI-84 Plus CE ROM reverse-engineering project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The instruction decoder is at `TI-84_Plus_CE/ez80-decoder.js`.

Session 419 decoded 0x010090, a frame-pacing state machine (400 bytes, 0x010090-0x01021F) that coordinates LCD DMA boundaries for slot 3 callback. It uses these RAM variables:
- D177DB — stage counter
- D177D8 — sub-step
- D177DE — iteration counter (wraps at 99)
- D177CC — circular buffer pointer (advances by 100 bytes)
- D177CF — second circular buffer pointer

We need to map who ELSE reads/writes these variables across the full ROM, and whether they are initialized during boot.

## Deliverables

### 1. Probe file: `TI-84_Plus_CE/probe-phase420-frame-pacing-refs.mjs`

Write a probe that:
1. Reads ROM.rom (4MB = 0x400000 bytes)
2. Scans the entire ROM for references to each of the 5 addresses (D177DB, D177D8, D177DE, D177CC, D177CF)
3. For each address, search for the 3-byte little-endian encoding in the ROM (e.g., D177DB = bytes DB 77 D1, D177D8 = D8 77 D1, etc.)
4. For each match location, decode the instruction at that location (or a few bytes before if mid-instruction) using `decodeInstruction(romBuffer, pc, 'adl')`
5. Report: match address, containing function estimate, read/write direction (LD vs ST), and any surrounding context

The decoder function signature: `decodeInstruction(romBuffer, pc, 'adl')` returns `{tag, length, nextPc, ...fields}`.

Use `process.emitWarning = () => {};` and `await import('./ez80-decoder.js')` for the decoder import.

### 2. Report file: `TI-84_Plus_CE/phase420-frame-pacing-refs-report.md`

After running the probe, write a report with:
- For each variable: total reference count, read count, write count
- Which functions (ROM address ranges) reference each variable
- Whether any boot-time initialization is found (addresses < 0x010000 often indicate init code)
- Cross-reference with 0x010090 (the known frame pacer) — are there OTHER frame-pacing functions?
- Any interesting patterns (e.g., are certain variables always read/written together?)
