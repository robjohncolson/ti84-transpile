# Task: Re-examine 0x096CCF Full Flow — Where Are the Draw/Erase Calls?

## Context

You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

The TI-84 CE uses a **display invalidation model** for cursor blink:
- Cursor pixels are written to VRAM by putchar (0x061980 with glyph 0xE1) or erased by 0x061003
- 0x097955 marks the cursor's screen region dirty and triggers LCD refresh via 0x026789
- The blink chain is: 0x096BEE (toggle) → 0x096CCF (gate) → 0x096F56 (visibility check) → 0x097955 (invalidate region)

**THE QUESTION**: Where do the actual cursor pixel writes (calls to 0x061061 for draw and 0x061003 for erase) happen? Session 501 concluded that 0x097955 does NOT call them — it only invalidates the LCD region. The draw/erase calls must happen BEFORE the JP NZ,0x097955 in 0x096CCF's flow, or in a separate path.

Session 498 decoded 0x096CCF as 70 bytes (0x096CCF-0x096D14). Session 497 decoded 0x096BEE as the blink toggle. Session 500 decoded 0x096F56 as visibility check only (17 bytes). Session 499 decoded 0x096F67 as 13-byte gate wrapper.

**But none of these contain CALL 0x061061 or CALL 0x061003.** So where ARE the draw/erase calls?

## Task

Create `TI-84_Plus_CE/probe-phase502-096CCF-full-trace.mjs` that does ROM byte scanning:

1. Hex dump 0x096B65 to 0x096D20 (entire blink region)
2. Search for CALL 0x061061 pattern (CD 61 10 06) in 0x096B00-0x096E00
3. Search for CALL 0x061003 (CD 03 10 06) in 0x096B00-0x096E00
4. Search for JP 0x061061 (C3 61 10 06) in 0x096B00-0x096E00
5. Search for JP 0x061003 (C3 03 10 06) in 0x096B00-0x096E00
6. Broader: CALL/JP 0x061061 and 0x061003 in 0x096000-0x09A000
7. Search for CALL 0x061980 (putchar, CD 80 19 06) in 0x096B00-0x096E00 and 0x096000-0x09A000
8. Search entire ROM for callers of 0x096BEE (CD EE 6B 09) and 0x096B65 (CD 65 6B 09)

```javascript
import { readFileSync } from 'fs';
import { join, dirname } from 'path';
import { fileURLToPath } from 'url';

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);
const rom = readFileSync(join(__dirname, 'ROM.rom'));

function hexDump(offset, length) {
    for (let addr = offset; addr < offset + length; addr += 16) {
        const len = Math.min(16, offset + length - addr);
        const bytes = [];
        for (let i = 0; i < len; i++) bytes.push(rom[addr + i].toString(16).padStart(2, '0'));
        console.log('0x' + addr.toString(16).padStart(6, '0') + ': ' + bytes.join(' '));
    }
}

function searchPattern(startAddr, endAddr, pattern, label) {
    const results = [];
    for (let addr = startAddr; addr <= endAddr - pattern.length; addr++) {
        let match = true;
        for (let i = 0; i < pattern.length; i++) {
            if (rom[addr + i] !== pattern[i]) { match = false; break; }
        }
        if (match) results.push(addr);
    }
    console.log('\n=== ' + label + ' ===');
    if (!results.length) console.log('NO MATCHES');
    else results.forEach(a => console.log('  0x' + a.toString(16).padStart(6, '0')));
    return results;
}

console.log('=== PROBE: 0x096CCF Full Trace ===\n');
console.log('=== HEX DUMP: 0x096B65 - 0x096D20 ===');
hexDump(0x096B65, 0x096D20 - 0x096B65);

searchPattern(0x096B00, 0x096E00, [0xCD, 0x61, 0x10, 0x06], 'CALL 0x061061 in 0x096B00-0x096E00');
searchPattern(0x096B00, 0x096E00, [0xCD, 0x03, 0x10, 0x06], 'CALL 0x061003 in 0x096B00-0x096E00');
searchPattern(0x096B00, 0x096E00, [0xC3, 0x61, 0x10, 0x06], 'JP 0x061061 in 0x096B00-0x096E00');
searchPattern(0x096B00, 0x096E00, [0xC3, 0x03, 0x10, 0x06], 'JP 0x061003 in 0x096B00-0x096E00');
searchPattern(0x096000, 0x09A000, [0xCD, 0x61, 0x10, 0x06], 'CALL 0x061061 in 0x096000-0x09A000');
searchPattern(0x096000, 0x09A000, [0xC3, 0x61, 0x10, 0x06], 'JP 0x061061 in 0x096000-0x09A000');
searchPattern(0x096000, 0x09A000, [0xCD, 0x03, 0x10, 0x06], 'CALL 0x061003 in 0x096000-0x09A000');
searchPattern(0x096000, 0x09A000, [0xC3, 0x03, 0x10, 0x06], 'JP 0x061003 in 0x096000-0x09A000');
searchPattern(0x096B00, 0x096E00, [0xCD, 0x80, 0x19, 0x06], 'CALL 0x061980 in 0x096B00-0x096E00');
searchPattern(0x096000, 0x09A000, [0xCD, 0x80, 0x19, 0x06], 'CALL 0x061980 in 0x096000-0x09A000');
searchPattern(0x000000, 0x400000, [0xCD, 0xEE, 0x6B, 0x09], 'CALL 0x096BEE entire ROM');
```
