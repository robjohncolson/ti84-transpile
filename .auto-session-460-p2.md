# Task: Trace 0x03FA09 key processor internal flow (531 bytes)

## Context

0x03FA09 is the OS key processor function. It reads the scan code from D00587, and when nonzero, branches to 0x03FB9A which eventually writes D141B5 at 0x03FBE1. The function is 531 bytes (0x03FA09 to ~0x03FC2B). Session 459 identified this as a critical function to map, but it hasn't been fully traced yet.

Key facts from prior sessions:
- 0x03FA09 reads D00587 (scan code deposited by ISR's KbdScan at 0x03F994)
- Nonzero scan code → branches to 0x03FB9A
- 0x03FBE1 writes A to D141B5 (the "committed key code" that OS components read)
- D14091 gate at 0x03FBC3 — unknown purpose
- D141B2 is a secondary key buffer
- The function has multiple IY flag checks (IY+0 bits)

## Deliverables

Write a probe `TI-84_Plus_CE/probe-phase460-trace-03FA09.mjs` that:

1. **Disassembles** the ROM bytes from 0x03FA09 to 0x03FC2B (531 bytes) using the eZ80 decoder
2. **Traces execution** through this function by:
   - Setting up a boot with D00587 pre-loaded with a known scan code (e.g., 0x09 = key "1")
   - Setting IY = 0xD00080 (standard OS value)
   - Setting appropriate IY flags (bit 3 of (IY+0) should be set to indicate scan code available)
   - Calling 0x03FA09 directly (or letting the ISR dispatcher reach it)
   - Logging every instruction executed within the 0x03FA09-0x03FC2B range
3. **Maps all branch targets** within the function — every JR, JP, CALL, RET, conditional jump
4. **Reports**:
   - The complete control flow graph (which addresses lead to which)
   - What D141B5 ends up containing after the function runs
   - What D14091 controls (gate condition and effect)
   - What D141B2 is used for
   - All IY flag bits checked and their effect on branching
