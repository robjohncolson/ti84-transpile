# Task: MAP 0x0AEB45 STRING TABLE LOOKUP CODE — find ROM functions that index the 76-string table

## Context

Session 573 mapped a string table at 0x0AEB45-0x0AECFC (439 bytes, 76 strings) containing token/parameter names like "List", "RegEQ", "df", "Iterations", "Period", "Store EQ", "lower", "upper", etc. This is the primary token name string table for the stats/parameter dialogs.

We need to find which ROM functions ACCESS this table — i.e., which code loads the address 0x0AEB45 or indexes into the table region.

## Deliverable

Create a probe at `TI-84_Plus_CE/probe-phase574-map-0AEB45-lookup.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom` (4MB, load with `fs.readFileSync`)
2. Scans the entire ROM for references to the table base address 0x0AEB45:
   - Look for bytes `45 EB 0A` (little-endian 24-bit) anywhere in ROM
   - For each hit, print the offset and surrounding context (what opcode precedes it — is it LD HL,nn / LD DE,nn / LD BC,nn / CALL nn / JP nn?)
3. Also scan for references to addresses within the table range 0x0AEB45-0x0AECFC:
   - Scan for any 3-byte sequence where byte[2]=0x0A, byte[1] is 0xEB-0xEC, and byte[0] spans the table
   - Group results by the referenced address
4. Scan for references to the first string table at 0x0AB3BE as well (bytes `BE B3 0A`)
5. For each reference found, identify the instruction that contains it by checking the preceding opcode byte:
   - 0x21 = LD HL,nn
   - 0x11 = LD DE,nn  
   - 0x01 = LD BC,nn
   - 0xCD = CALL nn
   - 0xC3 = JP nn
   - 0x3E preceding 2 bytes back could be LD A,n (different pattern)
6. Print results grouped by: (a) direct table base references, (b) intra-table references, (c) first table references

## File references

- ROM binary: `TI-84_Plus_CE/ROM.rom` (4,194,304 bytes)
- Session 573 findings: 0x0AEB45-0x0AECFC = 76 strings, 439 bytes

## Constraints

- Do NOT modify any existing files
- This is a pure ROM binary scan — no CPU boot required
- Output must be human-readable with hex addresses
- Run via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase574-map-0AEB45-lookup.mjs`

## Success criterion

The probe runs (exit 0) and prints all ROM locations that reference the string table at 0x0AEB45 (and 0x0AB3BE), identifying the instruction type at each reference site and grouping results clearly.
