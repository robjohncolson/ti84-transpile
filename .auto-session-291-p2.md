## Task
Create a probe file `TI-84_Plus_CE/probe-phase291-d0058c-read-sites.mjs` that:

1. Reads `ROM.rom` and `ez80-decoder.js` from the same directory
2. For each of the 19 read sites above:
   - Disassemble 10 instructions before and 20 instructions after the read
   - After loading A from D0058C, trace what happens to A:
     - Is it compared (CP)? Against what value?
     - Is it used as an index (ADD/SLA + table lookup)?
     - Is it stored somewhere else?
     - Is it passed to a CALL?
   - Look for patterns like:
     - `LD A,(D0058C) / CP xx / JR Z/NZ` = key-specific dispatch
     - `LD A,(D0058C) / CALL xxxx` = passing scan code to handler
     - `LD A,(D0058C) / LD (other_addr),A` = copying scan code

3. For each read site, classify the consumer pattern:
   - `KEY_DISPATCH`: compares scan code against specific values (list which)
   - `KEY_FORWARD`: passes scan code to another function via CALL
   - `KEY_COPY`: copies scan code to another RAM location (note destination)
   - `KEY_TEST`: tests scan code for zero/non-zero only
   - `UNKNOWN`: can't determine

4. Print a structured report showing each read site, its classification, the specific key values it checks (if KEY_DISPATCH), and the function it forwards to (if KEY_FORWARD).
