# Task: Decode 0x060B7A — Shared Cursor State Setup

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). You need to create a probe that statically disassembles a ROM function.

## Background
0x060B7A is called by BOTH functions sharing BCALL entry 826 (0x060B8D):
- **Function A (0x060B8D-0x060BA1)**: CALL 0x060B7A, CALL 0x0846EA, LD (D0244E),HL, CALL 0x05E86A, CALL 0x022BCF, RET. This is the BCALL entry point — some kind of cursor state initializer.
- **Function B (0x060BA2-0x060BC5)**: CALL 0x060B7A, CALL 0x0846EA, then does cursor type checking (returns A=0x3D '=' or A=0x7F block character). Function B is the one called from 0x096B65 (status bar formatter) at 0x096B9C.

Both functions call 0x060B7A FIRST, then 0x0846EA. 0x060B7A is likely a cursor state/position reader that sets up HL (or other registers) for the subsequent 0x0846EA call. Understanding it reveals what shared setup both cursor functions need.

0x060B7A must be between 0x060B50 and 0x060B8C (since 0x060B8D is Function A's start). It's likely a short helper (≤20 bytes).

Also decode 0x0846EA since both functions call it immediately after 0x060B7A. It likely processes whatever 0x060B7A set up.

## eZ80 Instruction Reference
- eZ80 is a Z80 superset with 24-bit addressing
- Standard Z80 opcodes apply, plus:
  - `ED 27` = `LD HL,(HL)` (load 24-bit value from address in HL)
  - `.SIS` prefix (0x40) = 16-bit operand override, high byte from MBASE register (0xD0)
  - `MLT rr` = multiply L×H→HL (8×8→16 multiply)
  - `TST A,n` = test A AND n without storing
  - 24-bit LD/ADD/SBC for HL,DE,BC,IX,IY
- IY base = 0xD00080 (so IY+0x11 = D00091, IY-0x04 = D0007C, etc.)
- RST 28h (0xE7) = BCALL, followed by 2-byte index into system call table
