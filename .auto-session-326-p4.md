## eZ80 decoding

Do manual byte-level decoding. Key opcodes:
- 0xCD = CALL nn (3-byte LE, 4 bytes total)
- 0xC9 = RET
- 0xC3 = JP nn
- 0x3E = LD A,n (2 bytes)
- 0xDB = IN A,(n) (2 bytes)
- 0xD3 = OUT (n),A (2 bytes)
- 0x21 = LD HL,nn (4 bytes)
- 0x11 = LD DE,nn (4 bytes)
- 0x01 = LD BC,nn (4 bytes)
- 0xDD prefix = IX instructions
- 0xFD prefix = IY instructions
- 0xED prefix = extended (ED 79 = OUT (C),A, ED 78 = IN A,(C))

Watch for port writes — these functions likely interact with LCD SPI hardware.
