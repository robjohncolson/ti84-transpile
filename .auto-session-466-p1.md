# Task: TEST COMBINED EI+HALT + PORT 0x0F FIX — End-to-End Event Handler Probe

## Context
Session 465 fixed TWO critical blockers in the TI-84 CE ROM transpilation:
1. **EI+HALT fix** in `cpu-runtime.js` (line ~1321-1327): After HALT with `cpu.iff1=1`, the executor now loops calling `tick()` up to `timerInterval*2` iterations until `hasPendingIRQ()` or `hasPendingNMI()` returns true.
2. **Port 0x0F fix** in `peripherals.js` (line ~885-892): Returns 0x40 (bit 6 = keyboard event pending) when any key in keyboard matrix is pressed, 0x00 otherwise. Bit 7 never set.

These fixes should allow: key injection → scheduler routes to event handler → EI+HALT countdown loop → timer ISR fires → event processing.

## Deliverable
Create `TI-84_Plus_CE/probe-phase466-combined-fix-test.mjs` — a probe that tests both fixes working together.
