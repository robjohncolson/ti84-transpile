# Task: Decode D02661/D02662 Mode-State Semantics

## Context
In the TI-84 Plus CE OS, function 0x0AF877 is a 2-state predicate that checks:
- Load (D02661), compare with 0x83
- If equal, load (D02662), compare with 0x03
- Returns Z (zero flag set) if BOTH match, else NZ

This predicate gates behavior in the token dispatcher 0x0AF408. We need to understand what D02661 and D02662 represent by finding all ROM locations that WRITE to these addresses.

## Deliverable
Create a probe file: `TI-84_Plus_CE/probe-phase296-d02661-mode-state.mjs`

The probe must:
1. Read `TI-84_Plus_CE/ROM.rom` (4MB binary)
2. Search the entire ROM (0x000000 through 0x3FFFFF) for all writes to D02661 and D02662
3. Write patterns to search for:
   - `LD (0xD02661),A` = opcode 0x32 followed by 0x61 0x26 0xD0 (little-endian)
   - `LD (0xD02662),A` = opcode 0x32 followed by 0x62 0x26 0xD0
   - Also check for 16-bit writes: `LD (0xD02661),HL` = 0x22 0x61 0x26 0xD0
   - And block writes/LDIR that might target this range
4. For each write site found:
   - Report the address
   - Disassemble a few instructions before and after to understand context
   - Try to determine what value is being written (is it a constant? loaded from where?)
5. Also search for reads: `LD A,(0xD02661)` = 0x3A 0x61 0x26 0xD0 and same for D02662
6. Summarize: what do D02661/D02662 represent? When does the 0x83/0x03 combination get set?
