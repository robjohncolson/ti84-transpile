# Task: Disassemble 0x0A223A (display-area clear) — Static ROM Decode

## Context
This is a TI-84 Plus CE ROM transpilation project. ROM file: `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian, ADL mode = 24-bit addresses).

Session 258 proved 0x0A223A is NOT the overflow source (that was originally suspected in session 257). The function reads D02504/D02505/D02684 and fills VRAM via 0x09EF20→0x09EFDE. With zero pointers, it fills D44Bxx-D44Dxx (correct VRAM range).

## Task
Create a probe `TI-84_Plus_CE/probe-phase263-0a223a-static-decode.mjs` that:

1. **Statically disassembles** 0x0A223A from ROM bytes (read `TI-84_Plus_CE/ROM.rom`, decode eZ80 ADL instructions starting at offset 0x0A223A). Use the ez80 instruction encoding — all addresses are 24-bit in ADL mode. Decode at least 80 bytes (until you hit a RET or unconditional JP that exits the function).

2. **Identifies ALL RAM pointer reads** — any `LD reg,(address)` where address is in D0xxxx or D4xxxx range. Document exactly which RAM addresses the function reads to determine its fill range (start address, row count, column range, fill color).

3. **Cross-references with 0x0A22B1** (the display setup function that calls 0x0A223A). Session 241 decoded 0x0A22B1 as: row computation + VRAM base + color staging. How does 0x0A223A receive its parameters — via registers from 0x0A22B1, or from RAM?

4. **Outputs a clean disassembly listing** with annotations for each instruction.

## Reference: eZ80 Instruction Decoding
- ADL mode: all addresses 24-bit, all LD (nn),reg and LD reg,(nn) use 3-byte addresses
- Common patterns: `ED 39 xx yy zz` = LD (xxyyzz),rr (16-bit store), `3A xx yy zz` = LD A,(xxyyzz)
- `2A xx yy zz` = LD HL,(xxyyzz), `ED 4B xx yy zz` = LD BC,(xxyyzz), `ED 5B xx yy zz` = LD DE,(xxyyzz)
- RET = 0xC9, JP nn = 0xC3 xx yy zz, CALL nn = 0xCD xx yy zz
- DJNZ = 0x10 offset, JR = 0x18 offset, JR Z = 0x28, JR NZ = 0x20, JR C = 0x38, JR NC = 0x30

## How to read ROM bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Read byte at address: rom[address]
// Read 24-bit LE: rom[addr] | (rom[addr+1] << 8) | (rom[addr+2] << 16)
```
