## Key technical constraints (from CLAUDE.md)

- Disable the timer IRQ for OS init probes: `createPeripheralBus({ timerInterrupt: false })`. The default 200-tick IRQ hijacks init via 0x1713 → 0x67F8 → 0x1c33 infinite loop.

- ROM write-protect: `cpu-runtime.js` silently drops writes below 0x400000. That is intentional.

- Boot recipe, wipe traps (0x0019be vs 0x0019b5), and all current addresses are in the handoff file's recent UPDATE blocks — trust those over anything older.
