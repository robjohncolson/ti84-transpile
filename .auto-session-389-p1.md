## eZ80 ADL-mode instruction reference
- 3-byte addresses (LD HL,imm24 = 0x21 XX XX XX)
- CALL imm24 = 0xCD XX XX XX (4 bytes)
- JP imm24 = 0xC3 XX XX XX (4 bytes)
- RET = 0xC9
- LD A,(imm24) = 0x3A XX XX XX
- LD (imm24),A = 0x32 XX XX XX
- IN A,(port) = 0xDB XX (2 bytes, port is 8-bit)
- IY-relative: 0xFD prefix, e.g. BIT n,(IY+d) = 0xFD 0xCB dd 0x46+8*n
- IX-relative: 0xDD prefix
