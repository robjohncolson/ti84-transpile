## Your Task
1. Create a probe `TI-84_Plus_CE/probe-phase315-fpunpack2.mjs` that:
   a. Scans ROM for all CALL instructions targeting 0x0034CC. CALL in eZ80 ADL mode is opcode 0xCD followed by 3-byte address (little-endian: CC 34 00).
   b. For each caller, extracts the caller's ROM address and disassembles ~30 bytes around the CALL site to understand the calling context (what registers are set up before, what's done with the result after).
   c. Determines which soft-float function each caller belongs to by looking at the broader function context (check for function prologues like PUSH IX / LD IX,SP = DD E5 DD F5, or known function addresses from the list above).
   d. Also checks: does _fpunpack (the original) have any callers at the same function addresses? This would tell us whether both variants are used in the same function (suggesting the two operands come in different formats).
   e. Prints: total caller count, each caller's address and parent function, whether both _fpunpack and _fpunpack2 are called in the same function, and the register setup pattern before each call.

2. Run the probe and capture output.
3. Create a report `TI-84_Plus_CE/phase315-fpunpack2-report.md`.
