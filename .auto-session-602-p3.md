# Auto-Session 602 — Priority 3: INVESTIGATE THE '8' GLYPH AT ENTRY LINE

## Context

This is a TI-84 Plus CE ROM transpilation project. The lifted OS runs real eZ80 code as JavaScript.

Session 601 confirmed the digit '2' renders to VRAM at the entry line (rows 219-232, cols 14-23). But there's ALSO an '8' glyph at cols 26-35 on the same row. We only pressed '2' — why does '8' appear?

Possibilities:
1. MathPrint rendering artifact (MathPrint uses large fonts and may render extra characters)
2. The cursor character (some calculators show a block cursor that looks like '8')
3. An OS artifact from uninitialized VRAM/edit buffer
4. The '2' key's token representation includes a second character somehow

## Task

Write a probe that:
1. Boots the OS using the standard recipe (see below)
2. Runs the first keypress ('2') through the full outer-loop path
3. At VRAM peak (~step 271K), dumps the ENTRY LINE region in detail:
   - Rows 219-240, all 320 columns
   - For each row, output which columns have non-white pixels
   - Also dump the EDIT BUFFER at D0231A (editCursor) region — read 64 bytes from the address stored at D0231A to see what tokens are in the edit buffer
4. Also read D0243A (edit cursor address) and dump 64 bytes from that address
5. Check D0058E (translated key code) at the peak to confirm only '2' was processed

## Standard Boot Recipe

```javascript
import { createCPU } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const fs = await import('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');

const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(peripherals);
cpu.loadROM(rom);

// Boot
cpu.regs.sp = 0xD1A87E - 24;
cpu.pushWord(0x0019b5); // halt block, NOT 0x0019be (wipe trap)
cpu.write24(0xD008E0, cpu.regs.sp);
cpu.regs.adl = 1;
cpu.runFrom(0x09DD62, { maxSteps: 300000, maxLoopIterations: 30000 });

// Paint status bar
cpu.pushWord(0x0019b5);
cpu.write24(0xD008E0, cpu.regs.sp);
peripherals.setTimerEnabled(true);
cpu.runFrom(0x058241, { maxSteps: 400000, maxLoopIterations: 50000 });

// Press '2' key
peripherals.setMatrixKey(3, 1); // SDK group 4 bit 1 = '2'
cpu.write8(0xD00587, 0x1A);    // raw scan code
cpu.write8(0xD0058E, 0x90);    // translated internal code
cpu.write8(0xD0058C, 0x90);    // pending key for outer loop
cpu.write8(0xD0058D, 0x90);    // backup
cpu.mem[0xD00080] |= 0x08;    // key-available flag
cpu.mem[0xD0009F] |= 0x20;    // bit 5 = pending key for outer loop

// Run outer loop with VRAM sampling
cpu.pushWord(0x0019b5);
cpu.write24(0xD008E0, cpu.regs.sp);
// Run with step-by-step VRAM monitoring around the peak
```
