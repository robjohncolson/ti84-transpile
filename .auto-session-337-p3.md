# Task: Trace FillRect callers at 0x09F008

## Context
This is a TI-84 Plus CE ROM transpilation project. We've decoded the OS FillRect primitive:
- Entry: 0x09F008 — sets up registers from the stack (row range B/C, column range DE, VRAM address computation)
- Inner loop: 0x09EFDE — DJNZ-based rectangular pixel fill, writes DE (16-bit color) to (HL)
- Epilogue: 0x09EFEC — odd-pixel epilogue
- Both exit to 0x09F736

We need to know who calls FillRect and with what parameters during the OS event loop / home screen rendering.

## Deliverable
Create `TI-84_Plus_CE/probe-phase337-fillrect-callers.mjs` that:

1. **TEST A — Static caller scan**: Search ROM bytes for CALL instructions targeting 0x09F008.
   - In eZ80 ADL mode, `CALL nn` = opcode 0xCD followed by 3-byte little-endian address
   - So search ROM for bytes: `CD 08 F0 09` (0xCD, then 0x09F008 in little-endian: 0x08, 0xF0, 0x09)
   - Also check for `JP nn` = 0xC3 followed by same 3 bytes
   - Also check for conditional calls: `CALL cc,nn` opcodes 0xC4/0xCC/0xD4/0xDC/0xE4/0xEC/0xF4/0xFC followed by the 3 address bytes
   - Print each caller address and surrounding context (decode 5 instructions before it)

2. **TEST B — Dynamic trace during home screen boot**: Boot the OS, install cxMain=0x058241, run CoorMon from 0x08BF22 (max 100000 steps). Track:
   - Every time PC hits 0x09F008 or 0x09EFDE
   - When 0x09F008 is hit: dump the stack top 12 bytes (the parameters), and registers A, BC, DE, HL, SP
   - Count how many times FillRect is called during the event loop

3. **TEST C — Extended boot trace**: Run the golden regression boot sequence (same as probe-phase99d-home-verify.mjs, if you can find it — check the file for how it boots) with onBlock tracking for 0x09F008 hits. This traces FillRect calls during the full home-screen render, not just CoorMon.

For each FillRect call found dynamically, decode the parameters:
- Stack layout at 0x09F008 entry: the function reads from (SP+offset) to get row start (B), row end (C), col start, col end
- Color value in DE
- Compute the rectangle: rows = C - B, cols = colEnd - colStart
- Compute VRAM address from `row*0xA0*4 + 0xD40000 + col*2`

## Boot sequence
Standard 2-phase:
- Phase 1: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
- Phase 2: `executor.runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })`
- Post-boot: `cpu.mbase = 0xD0; cpu.iy = 0xD00080; cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;`
- Stack reset: `cpu.sp = 0xD1A87E; cpu.sp -= 3; write24(mem, cpu.sp, 0xFFFFFF);`
