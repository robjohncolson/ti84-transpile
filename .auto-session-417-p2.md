# Session 417 P2: Decode 0x0106A0 Registrar Internals — Map All Callers

## Background
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 machine code).

Session 416 discovered a callback registrar at 0x0106A0-0x0106F2. It's a switch-like structure that writes BC (a callback address) to exactly one of 5 D177BD slots based on an index parameter. The 5 slots are:
- Slot 0: D177BD (3 bytes)
- Slot 1: D177C0 (3 bytes)
- Slot 2: D177C3 (3 bytes)
- Slot 3: D177C6 (3 bytes)
- Slot 4: D177C9 (3 bytes)

The epilogue is at 0x0106EE: LD SP,IX / POP IX / RET.

The teardown at 0x010F00-0x010F2C bulk-clears all 5 slots to 0x000000.

D177D6 is a bitmask that gates dispatch: bit 1→slot 1, bit 2→slot 2, bit 3→slot 3, bit 4→slot 4. Slot 0 dispatches unconditionally.

## Task
1. Read the ROM bytes at 0x0106A0-0x0106F2 and fully decode the switch structure. How does the registrar determine which slot to write? Is the index in A, BC, or on the stack?
2. Find ALL callers of 0x0106A0 in the ROM. Search for CALL 0x0106A0 (pattern: CD A0 06 01) and JP 0x0106A0 (pattern: C3 A0 06 01).
3. For each caller, read ~30 bytes before the CALL to determine what BC value (callback address) is being registered and what slot index is being passed.
4. Cross-reference the callback addresses with known OS functions.
