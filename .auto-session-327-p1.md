# Task: Trace 0x055191 (LCD Sync Gate)

## Context
You are working on a TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80). The transpiler is at `scripts/transpile-ti84-rom.mjs`. The runtime is `TI-84_Plus_CE/cpu-runtime.js`. Peripherals are in `TI-84_Plus_CE/peripherals.js`.

## What we know
- 0x055191 is called by BOTH LCD refresh functions:
  - 0x0551FE (lighter LCD refresh, 18 instr, 63 bytes)
  - 0x05523D (heavier LCD initializer, 22 instr, 67 bytes)
- Both call 0x055191 as their FIRST action before filling VRAM
- 0x055191 is likely an LCD "sync gate" — it probably checks/waits for some LCD busy condition
- This may be the LCD busy-wait that needs MMIO support in the emulator

## Your task
Build a probe script `TI-84_Plus_CE/probe-phase327-lcd-sync-gate.mjs` that:

1. **Disassembles 0x055191** by reading raw bytes from the ROM and decoding eZ80 instructions manually (read ROM bytes, decode opcodes by hand — do NOT use the transpiler's decoder). Trace from 0x055191 until you hit a RET or unconditional JP outside the function. Document every instruction with address and mnemonic.

2. **Runs a dynamic trace** using the transpiled runtime:
   - Load the transpiled JS via: `const fs = require('fs'); const zlib = require('zlib'); eval(zlib.gunzipSync(fs.readFileSync('TI-84_Plus_CE/ROM.transpiled.js.gz')).toString());`
   - Create CPU + peripherals: `const {createCPU} = require('./TI-84_Plus_CE/cpu-runtime.js'); const {createPeripheralBus} = require('./TI-84_Plus_CE/peripherals.js'); const periph = createPeripheralBus({timerInterrupt: false}); const cpu = createCPU(periph);`
   - Set PC = 0x055191, run up to 200 steps, log each block PC
   - Record what MMIO ports (if any) it reads/writes
   - Record what RAM addresses it reads/writes

3. **Determine**: What condition does 0x055191 check? Does it read any MMIO port (0xE3xxxx, 0x8xxx, 0x31xx)? Does it spin/wait on anything? Does it just set a flag and return?

## Output format
The probe should `console.log()` all findings. Structure:
- Part A: Static disassembly (address, hex bytes, mnemonic for each instruction)
- Part B: Dynamic trace (block PCs, step count, MMIO accesses)
- Part C: Conclusion — what the function does and whether it needs MMIO support
