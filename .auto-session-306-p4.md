# Auto-Session 306 P4: Trace 0x07CFA7 / 0x07CF1A (Graph/Matrix and List Handlers)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80).

Session 305 decoded the LCD refresh pipeline at 0x06868A. It dispatches based on OP1 type:
- 0x20/0x21 → 0x07CFA7 (graph/matrix handler)
- 0x1C → 0x07CF1A (list handler)
- else → RET

We need to trace what these two handlers actually do during LCD refresh.

## Task
1. **Disassemble 0x07CFA7** (graph/matrix handler):
   - Read ROM bytes starting at 0x07CFA7
   - Trace the instruction flow — what does it read? What VRAM does it write?
   - How far does the function extend? Where does it RET?
   - What sub-calls does it make?

2. **Disassemble 0x07CF1A** (list handler):
   - Same analysis as above
   - How does list display differ from graph/matrix display?

3. **Compare the two handlers**: what's shared, what's different?

### Method
- Read ROM bytes at both addresses and disassemble eZ80 instructions
- For each handler, trace until RET or JP to another function
- Log any sub-calls (CALL instructions) and their targets
- Identify VRAM write patterns (writes to 0xD40000+ range or via lcd_* functions)

### Deliverables
1. Create `TI-84_Plus_CE/probe-phase306-lcd-type-handlers.mjs` — a probe that:
   - Disassembles the code at 0x07CFA7 and 0x07CF1A
   - For each handler: lists all instructions, sub-calls, memory reads/writes
   - Identifies the function boundaries (entry point to RET)
   - Reports any VRAM write patterns
2. Write disassembly and analysis as comments at top of probe file
