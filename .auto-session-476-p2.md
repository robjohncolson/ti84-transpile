# Task: Find ROM sites that write D00824, D007E0, D14091, D00000, D00092

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 binary). You need to search the ROM binary for instructions that write to specific RAM addresses.

## Background
Session 475 proved that the home screen init function at 0x08BF22 does NOT set D00824, D007E0, D14091, D00000, or D00092. These variables control mode state, display updates, and cursor rendering. They must be initialized SOMEWHERE else — possibly by the OS scheduler (0x0015F7), boot stages (0x08C331, 0x0802B2), or another init function.

## Deliverable
Create `TI-84_Plus_CE/probe-phase476-ram-write-search.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Searches the ENTIRE 4MB ROM for byte patterns that represent eZ80 instructions writing to these addresses:

### Target byte patterns (eZ80 ADL mode, little-endian addresses):

**LD (addr),A = opcode 0x32 + 3-byte LE address:**
- D00824: `32 24 08 D0`
- D007E0: `32 E0 07 D0`
- D14091: `32 91 40 D1`
- D00000: `32 00 00 D0`
- D00092: `32 92 00 D0`

**LD (addr),HL = opcode 0x22 + 3-byte LE address:**
- D00824: `22 24 08 D0`
- D007E0: `22 E0 07 D0`
- D14091: `22 91 40 D1`
- D00000: `22 00 00 D0`
- D00092: `22 92 00 D0`

**IY-relative writes (SET/RES/LD via IY+offset where IY=D00080):**
- D00092 = IY+0x12: Check for `FD CB 12 C6` (SET 0,(IY+0x12)) through `FD CB 12 FE` (SET 7,(IY+0x12)), and LD (IY+0x12),n = `FD 36 12 nn`
- D00000 is NOT IY-relative (IY=D00080, offset would be -0x80 = negative, not valid)

**Also check for indexed writes via IX if IX is set to a known base:**
- This is lower priority; focus on the LD (addr),A and LD (addr),HL patterns first

3. For each match found, report:
   - ROM address of the instruction
   - Target variable being written
   - Instruction type (LD (addr),A, LD (addr),HL, SET bit, etc.)
   - Context: 8 bytes before and 8 bytes after the match (as hex)

4. Also specifically check these known code regions for writes to any of the 5 variables:
   - 0x0015F7-0x001A00 (OS scheduler)
   - 0x0802B2-0x080400 (post-init boot stage)
   - 0x08C331-0x08C400 (kernel init)
   - 0x08BF22-0x08C000 (home screen init — session 475 says it doesn't write them, verify)
