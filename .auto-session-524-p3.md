# Task: Decode 0x0989E9 — Type-Init Success Handler

## Context
This is a TI-84 Plus CE OS ROM (eZ80 ADL mode) disassembly task. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, little-endian eZ80). All addresses are 24-bit. The CPU runs in ADL mode (24-bit registers, 3-byte addresses) unless `.SIS` prefix (0x40) forces 16-bit operand/address for that instruction.

## Target
Disassemble and document the function at ROM address **0x0989E9**. This function is called on the SUCCESS path of 0x0987B5/0x0987B7 (type-specific initializer). The calling sequence after success:
```
; After 15-byte stack frame setup (PUSH IX, LD IX,0, ADD IX,SP, PUSH HL, LD HL,-15, ADD HL,SP, LD SP,HL)
CALL 0x0989E9   ; <-- THIS FUNCTION
; then CALL 0x09953F (conditional test)
; if carry: CALL 0x098A13, cleanup, JR to secondary dispatch
; if no carry: POP AF, CALL 0x099574, CALL 0x098A13, cleanup, RET
```

So 0x0989E9 is the first thing called after a successful type init with a 15-byte local frame on the stack.

## How to read the ROM
```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');

function readBytes(addr, len) {
  return Array.from(rom.slice(addr, addr + len))
    .map(b => b.toString(16).padStart(2, '0')).join(' ');
}

// Read 256 bytes starting at the target
console.log(readBytes(0x0989E9, 256));
```

## eZ80 Decoding Notes
- Default mode is ADL (24-bit). Immediate addresses are 3 bytes little-endian.
- Prefix 0xDD = IX register variants, 0xFD = IY register variants
- Prefix 0x40 = .SIS (force 16-bit mode for next instruction)
- CALL = 0xCD + 3-byte addr (LE). JP = 0xC3 + 3-byte addr. JR = relative jump (signed byte).
- RET = 0xC9. Conditional RET: C0/C8/D0/D8/E0/E8/F0/F8.
- LD A,(addr) = 0x3A + 3-byte addr. LD (addr),A = 0x32 + 3-byte addr.
- LD HL,(addr) = 0x2A + 3-byte addr (ADL). LD (addr),HL = 0x22 + 3-byte addr.
- CP imm8 = 0xFE + byte. OR A = 0xB7. XOR A = 0xAF.
- PUSH/POP: BC=C5/C1, DE=D5/D1, HL=E5/E1, AF=F5/F1, IX=DD E5/DD E1.
- IX+d addressing: DD 7E dd = LD A,(IX+d), DD 77 dd = LD (IX+d),A, DD 46 dd = LD B,(IX+d), etc.
- BIT n,(IY+d) = FD CB dd 46+8*n. SET/RES similar.
