## What We Know
- 0x0098D2 is called by 0x009B35 (USB/link masked-status service helper, decoded session 418)
- 0x009B35 is called by the USB ISR (0x0019B5) when port 0x5015 bit 5 is set
- 0x0098D2 is called when the masked USB status result is nonzero — this is the escalation path from status sampling to actual USB service
- 0x009B35 reads ports 0x3084/0x3085, applies masks from D14042/D14046, and calls 0x0098D2 if the masked result is nonzero
- The alternate path (when D177B7 != 0x55, USB not initialized) calls 0x0094C0 or 0x0096CB instead

## eZ80 Reference
- eZ80 is Z80 superset, 24-bit addresses, ADL mode
- IN A,(C) = ED 78 (reads port from BC register)
- OUT (C),A = ED 79
- IN0 A,(port) = ED 38 pp (reads from 8-bit port address)
- OUT0 (port),A = ED 39 pp
- CALL addr = CD ll mm hh (4 bytes in ADL mode)
- LD A,(addr) = 3A ll mm hh
- LD (addr),A = 32 ll mm hh
- JP cc,addr = C2/CA/D2/DA ll mm hh (conditional jump)
- JR cc,offset = 20/28/30/38 dd (relative jump)
- RET = C9, RET cc = C0/C8/D0/D8/E0/E8/F0/F8
- BIT n,A = CB 47/4F/57/5F/67/6F/77/7F
- SET/RES n,(addr) uses CB prefix
- 0x40 byte can be .SIS prefix — be careful!
- PUSH/POP IX = DD E5/DD E1, PUSH/POP IY = FD E5/FD E1
