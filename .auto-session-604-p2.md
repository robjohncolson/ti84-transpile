## eZ80 instruction reference (ADL mode)

Key encodings:
- `CD xx xx xx` = CALL addr24
- `C3 xx xx xx` = JP addr24
- `18 xx` = JR offset8
- `20 xx` = JR NZ, offset8; `28 xx` = JR Z, offset8
- `FE xx` = CP A, imm8
- `CB 46+8*bit` = BIT bit,(HL)
- `FD CB dd 46+8*bit` = BIT bit,(IY+dd)
- `3E xx` = LD A, imm8
- `C9` = RET; `C0` = RET NZ; `C8` = RET Z
- `E5` = PUSH HL; `E1` = POP HL
- `D5` = PUSH DE; `D1` = POP DE
- `C5` = PUSH BC; `C1` = POP BC
- `F5` = PUSH AF; `F1` = POP AF
- Addresses are 24-bit little-endian in ADL mode
