## eZ80 Decoding Reference
- The ROM file is a flat binary. Address 0x0A24C8 = file offset 0x0A24C8.
- eZ80 ADL mode: default 24-bit addresses and 24-bit registers.
- Common opcodes: CB = bit ops, ED = extended ops, DD = IX prefix, FD = IY prefix, 40 52 = SIS prefix
- LD instructions, CALL (CD xx xx xx = 4 bytes in ADL), JP (C3 xx xx xx), JR (18/20/28/30/38 xx), RET (C9)
- DJNZ (10 xx) = decrement B, jump if not zero (loop construct)
- IX access: DD 7E xx = LD A,(IX+d), DD 46 xx = LD B,(IX+d), etc.
- LCD framebuffer: 0xD40000-0xD52BFF (320×240×2 bytes, 16-bit color, row-major)
- LDIR (ED B0) = block copy, common for framebuffer writes
