## Context

This subcall determines the fill parameters (likely VRAM cursor setup, row/column bounds). Understanding 0x08C308 completes the _RectFill documentation.

The transpiled ROM is at `TI-84_Plus_CE/ROM.transpiled.js` (generate first with `node scripts/transpile-ti84-rom.mjs` if it doesn't exist). The raw ROM is `TI-84_Plus_CE/ROM.rom`.
