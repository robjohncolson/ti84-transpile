# Task: Decode the 6-Entry Dispatch Table Inside 0x0120AA (Notification Sub-Handlers)

## Context

The TI-84 Plus CE ROM at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary) has a notification cascade system. Session 408 decoded the PRIMARY CASCADE at 0x01204A:

- 10-entry CP chain tests RAM byte D177B8 against payload values: 0x0B, 0x0D, 0x99, 0x9A, 0x9B, 0x01, 0x98, 0x96, 0x97, 0xFF
- ALL 10 branch to the SAME handler at 0x0120AA
- Handler at 0x0120AA calls:
  - 0x00238F (param conversion)
  - Reads D1778E/D1778B
  - Calls 0x0023AD (bounds check)
  - On no-carry: dispatches to 6 sub-handlers
  - On carry: calls 0x0136BF (error handler)
- Fallthrough (no match): calls 0x00883C with type=0x03, payload=0x06

The 6-ENTRY SUB-DISPATCH TABLE has NOT been decoded. We know it exists inside the handler at 0x0120AA but we don't know what the 6 entries do.

## Your task

Write a probe script at `TI-84_Plus_CE/probe-phase409-notification-dispatch.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Disassembles starting at 0x0120AA and follows control flow deeply (at least 300 bytes)
3. Finds the 6-entry dispatch mechanism — it could be:
   - A JP table (6 consecutive JP instructions)
   - A CALL table
   - A pointer table (6 addresses loaded then JP (HL))
   - An indexed jump (ADD HL,HL / LD HL,(HL+offset) / JP (HL))
4. For each of the 6 sub-handlers:
   - What address does it start at?
   - What does it do? (Read 20-30 bytes of each handler to classify)
   - What RAM addresses does it access?
   - Does it call known functions (0x00238F, 0x0023AD, 0x00883C, etc.)?
5. Write a report at `TI-84_Plus_CE/phase409-notification-dispatch-report.md`

## eZ80 reference

eZ80 is a Z80 superset with 24-bit addresses. Key opcodes:
- `CD xx xx xx` = CALL addr (4 bytes in ADL mode)
- `C3 xx xx xx` = JP addr (4 bytes)
- `FE xx` = CP n (compare A with immediate)
- `28 xx` = JR Z,offset / `20 xx` = JR NZ,offset
- `CA xx xx xx` = JP Z,addr / `C2 xx xx xx` = JP NZ,addr
- `E9` = JP (HL)
- `C9` = RET
- `3A xx xx xx` = LD A,(addr) reads RAM
- `32 xx xx xx` = LD (addr),A writes RAM
- `21 xx xx xx` = LD HL,addr
- `ED B1` = CPIR
- `19` = ADD HL,DE
- `09` = ADD HL,BC
- `7E` = LD A,(HL)
- `23` = INC HL

Little-endian for all multi-byte values. 3-byte addresses in ADL mode.
