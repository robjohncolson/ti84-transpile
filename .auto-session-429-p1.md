## What We Know
- 0x00DCB6 is called by 0x00CC71 (the descriptor init wrapper, 266 bytes at 0x00CC71-0x00CD7A) when param2 (IX+9) == 1.
- If 0x00DCB6 returns 0, the bootstrap at 0x00E2EB is SKIPPED and 0x00CC71 returns A=2 (partial init).
- This function gates whether Link/serial and USB-alt init modes proceed to full bootstrap.
- It likely checks whether the Link controller is ready/present.
- The call site is inside 0x00CC71. Two of the three callers pass param2=1: 0x008EB5 (Link/serial, pushes 0/1/300) and 0x0126F5 (USB alt-mode, pushes 0/1/1000).
- Port 0x3010 is the link control register (bit 0: link active, bit 4: RX ready, bit 5: TX ready).
- Port 0x3015 is the link status register.
- Port 0x3030 is checked for bit 0 (controller readiness) elsewhere in the init path.
