# Task: Trace Key Code Processing at 0x02FFAE

## Goal
Create a probe `TI-84_Plus_CE/probe-phase471-keycode-processing.mjs` that enters at 0x02FFAE with a translated key code in A and traces what happens. This is the key COMMAND DISPATCH after scan→key translation.

## Context
Session 470 discovered:
- After scan→key translation at 0x02FF09, CALL 0x022346 reads the translation table at 0x09F79B
- 0x0302EB translates scan→key code
- 0x02FFAE receives the translated key code and dispatches
- ROM bytes at 0x02FFAE: 3A 24 08 D0 FE 00 7E 20 36 3A E0 07 D0 FE 54 28 02 FE 53 7E 28 08 FE 06 20 04 3E 05 18 21 ...
- This decodes as: LD A,(D00824); CP 0x00; ... checks D007E0 for values 0x43, 0x49, 0x40, etc.
- ENTER key: scan code 0x09 → key code 0x05 (k_Enter) from translation table

## What to build
A probe that:
1. Runs the standard 3-stage cold boot (same as probe-phase469-keywait-v2.mjs)
2. After boot, sets up state:
   - cpu.a = 0x05 (k_Enter, the translated ENTER key code)
   - cpu.f with Z flag clear (NZ condition — key present)
   - IY = 0xD00080
   - Set SP with return sentinel (mem[sp]=0xFF, mem[sp+1]=0xFF, mem[sp+2]=0xFF)
3. Enters at 0x02FFAE in ADL mode
4. Runs with maxSteps=50000, maxLoopIterations=5000, diHaltBypass:true
5. Tracks with onBlock:
   - 0x02FFAE (entry)
   - 0x030300 (cursor/display prep - called from key handler)
   - 0x040D11 (cursor timing)
   - 0x02FE84 (near final RET)
   - 0x02FE88 (final RET)
   - 0x02FD99 (potential branch target)
   - 0x0059C6 (display output)
   - 0x022346 (table lookup if any further lookups)
6. Logs EVERY block hit for the first 200 steps (capture the full execution trace)
7. After run, reports:
   - Full execution trace (first 200 blocks with PC, A register, flags)
   - D00824, D007E0, D0009D, D00088, D00080 final values
   - Any CALLs made (log target addresses)
   - VRAM checksum before/after
   - Final PC and termination

Also try with A=0x06 (one key code above ENTER) to see the CP 0x06/0x05 comparison paths.

## File patterns (same as P1)
- Import: `import { createExecutor } from './cpu-runtime.js'; import { createPeripheralBus } from './peripherals.js';`
- ROM: `fs.readFileSync(path.join(__dirname, 'ROM.rom'))`
- Blocks: `const romModule = await import(pathToFileURL(path.join(__dirname, 'ROM.transpiled.js')).href); const BLOCKS = romModule.PRELIFTED_BLOCKS;`
- Peripherals: `createPeripheralBus({ timerInterrupt: false })`
- Executor: `createExecutor(BLOCKS, mem, { peripherals })`

## Boot sequence (copy from probe-phase469-keywait-v2.mjs)
```js
const STACK_RESET_TOP = 0xD1A87E;
// 1a. Boot entry
const bootResult = executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 });
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
// 1b. Kernel init  
cpu.mbase = 0xD0; cpu._iy = 0xD00080;
const kernelResult = executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0;
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
// 1c. Post-init
const postInitResult = executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
```
