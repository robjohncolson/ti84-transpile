## eZ80 instruction encoding
- CALL nn = CD xx xx xx (4 bytes in ADL mode), JP nn = C3 xx xx xx
- JR e = 18/20/28/30/38 + signed offset
- RST 28h = E7, followed by 2-byte LE BCALL index
- BIT n,(IY+d) = FD CB dd 46+8*n
- LD A,(nn) = 3A xx xx xx, LD (nn),A = 32 xx xx xx
- LD HL,(nn) = 2A xx xx xx (or ED 6B in some encodings)
