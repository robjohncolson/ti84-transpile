# Task: Looping Event Loop Probe at 0x02FDBE

## Goal
Create a probe `TI-84_Plus_CE/probe-phase471-looping-eventloop.mjs` that enters at 0x02FDBE (the real event loop head) with a LOOPING STACK — the return address on the stack points back to 0x02FDBE so the RET at 0x02FE88 returns to the loop head.

## Context
Session 470 discovered:
- 0x02FDBE = real event loop head. ROM bytes: CD 09 FA 03 = CALL 0x03FA09
- After 0x03FA09 returns, code checks D000A8 bits 5/3, falls through to 0x02FDD8
- 0x02FDD8 tests D000B4 bit 0. If A!=0 → JP 0x02FE89 (key handler). If A==0 → display update path
- The display update path: test D000D7 bits, CALL 0x03D1BE, BIT 0,(IY+0x46)=D000C6, CALL NZ 0x030078, LD HL,(D00591), CALL 0x040D11, XOR A, RET
- The RET at 0x02FE88 currently returns to 0xFFFFFF (stack sentinel from probes). We need it to return to 0x02FDBE.
- 0x02FE89 key handler: CP 0xFF, SET D0009D bit 0, check D00080 bit 4, → 0x02FEB7 → key translation at 0x02FF09 → CALL 0x022346 (table lookup) → 0x0302EB → 0x02FFAE → CALL 0x030300 → RET at 0x02FE88

## What to build
A probe that:
1. Runs the standard 3-stage cold boot (same pattern as probe-phase469-keywait-v2.mjs — see that file for exact boot sequence)
2. After boot, injects ENTER key: mem[0xD00587]=0x09, mem[0xD00080] |= 0x08 (bit 3), mem[0xD00088] |= 0x08
3. Sets mem[0xD177BA]=0x7F, mem[0xD177B7]=0x00
4. Sets SP to STACK_RESET_TOP-3 (0xD1A87E - 3 = 0xD1A87B)
5. **CRITICAL**: Writes the return address 0x02FDBE onto the stack in little-endian 3-byte format:
   ```js
   mem[cpu.sp] = 0xBE;     // low byte
   mem[cpu.sp + 1] = 0xFD; // mid byte  
   mem[cpu.sp + 2] = 0x02; // high byte
   ```
6. Runs from 0x02FDBE in ADL mode with maxSteps=500000, maxLoopIterations=50000, diHaltBypass:true
7. Tracks with onBlock:
   - 0x02FDBE (event loop head)
   - 0x03FA09 (key processor)
   - 0x02FDD8 (main handler entry)
   - 0x02FE89 (key handler chain)
   - 0x030078 (port/LCD setup)
   - 0x040D11 (cursor timing)
   - 0x0059C6 (display output)
   - 0x030300 (cursor/display prep)
8. Logs first 10 hits of each tracked PC with step count and A register
9. After run, reports:
   - Hit counts for all tracked PCs
   - D00587, D00080, D141B5, D000B4 final values
   - VRAM checksum before vs after (use FNV-1a over 0xD40000-0xD65800)
   - Number of VRAM bytes that changed
   - Final PC and termination reason
   - How many times execution returned to 0x02FDBE (proves the loop works)

## File patterns

## Boot sequence (copy from probe-phase469-keywait-v2.mjs)
```js
// 1a. Boot entry
const bootResult = executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 });
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);

// 1b. Kernel init  
cpu.mbase = 0xD0; cpu._iy = 0xD00080;
const kernelResult = executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0;
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);

// 1c. Post-init
const postInitResult = executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
```
