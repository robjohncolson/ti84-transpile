# Task: Map D01D0C — Find All References to This Shared Variable

## Context
D01D0C is a RAM address read by two adjacent functions decoded in session 586:
- 0x092F87 (14B): LD A,(D01D0C) → INC A → CALL 0x092FC7 → LD HL,D008F0 → RET
- 0x092F95 (11B): LD A,(D01D0C) → OR A → JP Z,0x092FC1 → JR 0x092FB1

Both functions are called by type-0x09 event callers (0x022896 calls 0x092F87, 0x0228E3 calls 0x092F95). D01D0C is NOT yet mapped — we don't know what it represents.

## Deliverable
Create `TI-84_Plus_CE/probe-phase588-map-D01D0C.mjs` that:
1. Reads `TI-84_Plus_CE/ROM.rom` (path relative to repo root)
2. Scans the ENTIRE ROM (0x000000-0x3FFFFF, 4MB) for all references to address 0xD01D0C
3. For each reference found, identify:
   - The ROM address where the reference occurs
   - Whether it's a READ (LD A,(D01D0C), LD HL,(D01D0C), etc.), WRITE (LD (D01D0C),A, etc.), or ADDRESS (LD HL,D01D0C, LEA, etc.)
   - The instruction context (disassemble the instruction)
   - The surrounding function context (a few instructions before/after)
4. Print a summary: total refs, reads vs writes vs address-loads, which ROM regions reference it, hypothesis about what D01D0C represents

## Scanning approach
Scan for the 3-byte little-endian encoding of 0xD01D0C = bytes [0x0C, 0x1D, 0xD0] at every position. For each match, check if the preceding byte(s) form a valid instruction that takes a 24-bit address operand:
- 0x3A = LD A,(nn) — READ
- 0x2A = LD HL,(nn) — READ
- 0x32 = LD (nn),A — WRITE
- 0x22 = LD (nn),HL — WRITE
- 0xED 0x4B = LD BC,(nn) — READ (check byte at offset-2)
- 0xED 0x5B = LD DE,(nn) — READ
- 0xED 0x6B = LD HL,(nn) — READ (ED-prefixed variant)
- 0xED 0x43 = LD (nn),BC — WRITE
- 0xED 0x53 = LD (nn),DE — WRITE
- 0xED 0x63 = LD (nn),HL — WRITE
- 0x21 = LD HL,nn — ADDRESS load
- 0x01 = LD BC,nn — ADDRESS load
- 0x11 = LD DE,nn — ADDRESS load
- With DD/FD prefixes for IX/IY variants
- Also check for CALL/JP to this address (unlikely for RAM but be thorough)

Also scan nearby D01D0x addresses (D01D0A-D01D0F) to see if D01D0C is part of a larger structure.

## Constraints
- Do NOT modify any existing files
- Do NOT import from ez80-decoder.js
- ROM path is 'TI-84_Plus_CE/ROM.rom' (relative to repo root)
- Run via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase588-map-D01D0C.mjs`
- NEVER run bare `node TI-84_Plus_CE/probe-*.mjs`

## Success criterion
Probe runs via watchdog (exit 0), finds ALL references to D01D0C in the ROM, categorizes them as read/write/address, identifies the ROM regions that use this variable, and provides a hypothesis about its purpose (counter? index? flag?).
