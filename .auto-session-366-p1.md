You are working on a TI-84 Plus CE ROM transpilation project. The OS ROM is lifted to JavaScript and executed block-by-block in Node.js. The peripheral bus (`TI-84_Plus_CE/peripherals.js`) emulates hardware I/O ports.

## Problem
Port 0x2001 is the flash/NAND controller status register. Bit 3 = busy flag. The OS code at ROM address 0x006D57 polls this port in a tight loop:
```
IN A,(C)       ; read port 0x2001
BIT 3,A        ; test busy flag
JR NZ, loop    ; loop while busy
```

Currently, unregistered ports return 0xFF (see `read()` function at line 205-217 of peripherals.js). This means bit 3 is always set (busy), causing an infinite loop at higher step counts.

## Task
Add a flash controller handler to `TI-84_Plus_CE/peripherals.js`. Requirements:

1. Register a handler for port 0x2001 (and possibly 0x2000-0x200F if the flash controller uses a range)
2. The handler should return bit 3 = 0 (ready) on reads. Simplest approach: always return 0x00 for port 0x2001.
3. Optionally track writes to the flash controller port range for debugging (log them but don't need complex state machine)
4. Add the registration in the `createPeripheralBus()` function alongside the existing PLL handler, INTC handler, etc.
