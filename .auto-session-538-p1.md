# Task: READ TYPE TABLES AT 0x07FE8A-0x07FE96

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). We've decoded a forward type transform at 0x07FE2F and a reverse type transform at 0x07FE65 that use lookup tables in ROM:

- **0x07FE8A**: 6-entry "forward input" table (searched by CPIR with BC=6)
- **0x07FE90**: 6-entry "forward output" table (indexed by BC remainder after CPIR match)
- **0x07FE91**: 5-entry "reverse input" table (searched by CPIR with BC=5, overlaps forward output)

The forward transform at 0x07FE2F does: strip sign bits (AND 0x3F), search 0x07FE8A for the type, if found index into 0x07FE90 for the output type, else default to 0x0C (complex).

The reverse transform at 0x07FE65 does the inverse: search 0x07FE91 for the type, if found index into 0x07FE8A for the output type.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase538-read-type-tables.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Dumps the raw bytes at these addresses:
   - 0x07FE8A through 0x07FE96 (13 bytes total — covers all 3 tables)
3. Formats the output as:
   - Forward input table (6 bytes at 0x07FE8A): hex values
   - Forward output table (6 bytes at 0x07FE90): hex values
   - Reverse input table (5 bytes at 0x07FE91): hex values (note: overlaps forward output starting at byte 1)
4. For each entry, annotate with the known TI-OS type names:
   - 0x00 = Real, 0x01 = List, 0x02 = Matrix, 0x04 = Equation/Y-Var, 0x05 = String, 0x06 = Program, 0x07 = Protected Program, 0x08 = Picture, 0x0C = Complex, 0x0D = Complex List, 0x15 = AppVar, 0x17 = Group, 0x18 = String variant (seen in session 533), 0x1C = Matrix (alt), 0x20 = Equation (alt), 0x21 = String (alt)
5. Print the forward mapping table: "input_type → output_type" for each of the 6 entries
6. Print the reverse mapping table: "input_type → output_type" for each of the 5 entries
7. Verify the tables are inverses where they overlap

## How to read the ROM
```javascript

// ROM is memory-mapped at 0x000000, so rom[0x07FE8A] is the byte at address 0x07FE8A

```
