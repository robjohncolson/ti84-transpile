# Task: Trace 0x055316 — Display-Driver Config Table Setup

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM binary is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

Session 324 found:
- 0x055191 = RAM-only config table copier (returns in 11 steps, zero I/O)
- 0x055191 calls 0x055316
- 0x055316 sets up a display-driver config table pointer at RAM address D005E9, pointing to ROM data at 0x0525D4
- Question: What config does it load? What is the structure at 0x0525D4?

## What to do
Create a probe `TI-84_Plus_CE/probe-phase325-trace-055316.mjs` that:

### Part 1: Disassemble 0x055316
Start disassembling at 0x055316 and continue until RET (0xC9). This function should be relatively short since it's a config table setup routine. Decode all instructions.

### Part 2: Dump the config table at ROM 0x0525D4
Read bytes from ROM offset 0x0525D4. The table structure is unknown — dump the first 128 bytes in hex and look for patterns:
- Repeating structures (fixed-size records)
- Zero terminators
- Pointer values (3-byte LE addresses pointing into ROM or RAM)
- Common display config values (pixel counts, timing values)

The TI-84 CE LCD is 320×240 pixels, 16bpp (RGB565). Look for values like:
- 320 = 0x0140
- 240 = 0x00F0
- 153600 = 0x25800 (total pixels)
- Common SPI panel init command sequences (datasheet values)

### Part 3: Find all callers of 0x055316
Search the ROM for CALL/JP to 0x055316:
- CALL: bytes `CD 16 53 05`
- JP: bytes `C3 16 53 05`

### Part 4: Cross-reference with the LCD function family
Check if 0x055316 is called by or calls any of:
- 0x055280 (LCD DMA transfer trigger)
- 0x055191 (config table copier)
- 0x0557xx range (LCD panel init functions from session 323)
- 0x010A3C (LCD sync)

Search for CALL instructions within 0x055316's body targeting these addresses.

### Part 5: Decode the config table structure
Based on the hex dump and the way 0x055316 accesses it, propose a structure definition. If the table contains SPI panel init commands, they typically follow patterns like:
- Command byte + parameter count + parameter bytes
- Or fixed-size (command, param1, param2) tuples
