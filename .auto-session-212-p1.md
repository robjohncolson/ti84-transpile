1. z80 boot at 0x000000 (max 20000 steps)
2. kernelInit at 0x08C331 (max 100000 steps)
3. postInit at 0x0802B2 (max 100 steps)
4. memInit at 0x09DEE0 with return sentinel at 0x7FFFF6 (max 100000 steps)

After boot, for EACH digit test:
- Create a fresh mem copy or reset the edit buffer region (0xD00A00-0xD00B00 = 0x00)
- Set edit pointers: TOP=0xD00A00, CURSOR=0xD00A00, TAIL=0xD00A00, BTM=0xD00B00

- Set A = scan code
- Push RETURN_SENTINEL (0x7FFFFE) onto stack
- Set PC = 0x05E630
- Run up to 500 steps, stop when PC hits RETURN_SENTINEL or BufInsert
