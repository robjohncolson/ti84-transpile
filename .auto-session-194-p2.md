# Session 194 P2 — STAT with Seeded List Data in RAM

## Task
Build a probe `TI-84_Plus_CE/probe-phase194-stat-seeded-lists.mjs` that seeds dummy list data into RAM before running the STAT handler trace from 0x058BA9 (cxErrorEP). Session 193 proved that the LDDR at 0x092263 crashes because BC=0x2FEAF5 (3M bytes — garbage from uninitialized RAM). The STAT path expects populated list/variable tables.

## Context
From session 193 findings:
- Entry at 0x058BA9 reaches LDDR block at 0x092263 after 87 unique blocks
- BC = 0x2FEAF5 at LDDR entry = garbage from uninitialized RAM
- LDDR attempts 3M-byte copy → corrupts memory → falls to boot vector
- Root cause: STAT handler expects list data/variable tables that aren't present in cold-boot

TI-84 CE list data locations (from OS symbol table research):
- **List pointer table**: starts around 0xD01508 (contains 3-byte pointers to list data)
- **Number of lists**: stored at 0xD0150B area
- **VAT (Variable Allocation Table)**: starts at top of RAM and grows downward. The VAT bottom pointer is at 0xD0258E (pTemp) / 0xD02591 (progPtr)
- **List data format**: Each list entry is: 2-byte size (little-endian element count), then 9 bytes per element (TI-OS real number format: type byte + 8 BCD bytes)

## What to build
Use `probe-phase193-stat-lddr-inspect.mjs` as the template.

### Pre-seeding: Create a minimal L1 list with 3 elements {1.0, 2.0, 3.0}
After boot + kernel init + mem init, seed RAM:

1. **Create L1 data** at a safe RAM location (e.g., 0xD10000):
   - Write element count: 0x03, 0x00 (3 elements, little-endian)
   - Write element 1: `00 80 10 00 00 00 00 00 00` (1.0 in TI BCD)
   - Write element 2: `00 80 20 00 00 00 00 00 00` (2.0)
   - Write element 3: `00 80 30 00 00 00 00 00 00` (3.0)

2. **Create a VAT entry for L1** near the top of available RAM (e.g., 0xD1A800):
   - VAT entry format: type=0x01 (real list), then 3-byte data pointer (little-endian to 0xD10000), then name
   - Name for L1: length=1, bytes=0x00 (list index 0 = L1)

3. **Set VAT pointers**:
   - Write progPtr (0xD02591) = address of VAT entry
   - Write pTemp (0xD0258E) = address past VAT entry

4. **Set stat list selection RAM**: Write the list number (0x01 for L1) to 0xD01508 and related stat mode bytes

### Experiments
**Experiment A**: Run from 0x058BA9 with seeded lists, 5000-step limit
- Track: unique blocks, whether LDDR at 0x092263 fires, what BC value is at LDDR, whether execution proceeds past LDDR
- Sentinel watch: 0x092265 (LDDR successor), 0x000000 (boot crash), 0x7FFFFE (return)

**Experiment B**: Same as A but also snapshot BC register at block 0x092263 (use onBlock callback)
- Compare BC value with seeded vs unseeded

**Experiment C**: Bypass approach — set BC=3 directly before LDDR
- After boot, resetCpuForOsCall, enter at 0x092263 directly with BC=3, DE and HL set to safe RAM locations
- See if LDDR with small BC value completes and reaches successor 0x092265

### Output
Print JSON results for each experiment showing blocks visited, BC at LDDR, whether successor reached, final state.
