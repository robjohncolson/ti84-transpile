# Task: Seed RAM 0x020100 with 0x00A55A and test normal key dispatch path

## Context
The TI-84 Plus CE OS event loop dispatches keys via CALL 0x001713, which calls 0x0008BB (flash self-test). The test does:
```
LD HL,(0x020100)
LD BC,0x00A55A
SBC HL,BC
RET
```
If HL ≠ BC (NZ), dispatch takes error path → DI+HALT at 0x001937.
If HL == BC (Z), dispatch takes NORMAL path → 0x001853 → 0x000721.

We have NEVER reached 0x001853 or 0x000721 because RAM 0x020100 was never seeded.

## Deliverable
Create `TI-84_Plus_CE/probe-phase375-flash-seed-test.mjs` that:

1. Boots through phases 1→2→3 (standard boot sequence), then enters event loop at 0x003A73
2. Before entering the event loop, seeds:
   - `mem[0x020100] = 0x5A` (little-endian low byte of 0x00A55A)
   - `mem[0x020101] = 0xA5` (middle byte)
   - `mem[0x020102] = 0x00` (high byte)
   - `mem[0xD00587] = 0x09` (ENTER scan code)
   - `mem[0xD00080] |= 0x08` (set bit 3 = key available flag)
3. Runs the event loop for up to 500,000 steps
4. Tracks which blocks are visited, specifically checking for:
   - 0x001853 (normal key handler — NEVER reached before)
   - 0x000721 (post-key-process jump — NEVER reached before)
   - 0x001937 (DI+HALT error path — should NOT be reached with seed)
   - 0x003A7D (dispatch entry — should be reached)
5. Also runs a CONTROL test WITHOUT the 0x020100 seed (but WITH key injection) to confirm 0x001937 IS still reached without the fix
6. Prints clear PASS/FAIL results:
   - PASS if 0x001853 reached AND 0x001937 NOT reached
   - FAIL if 0x001937 still reached or 0x001853 not reached
7. Reports total unique blocks reached, new blocks (not in control), and the first 20 block transitions after dispatch at 0x003A7D
