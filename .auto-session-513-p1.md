## How to decode
Use Node.js to read the ROM binary and decode eZ80 instructions. The ROM file is at `TI-84_Plus_CE/ROM.rom`. eZ80 instructions are variable-length (1-6 bytes). Key opcodes:
- `0xCD` = CALL.LIL (4 bytes: CD + 3-byte LE addr)
- `0xC9` = RET
- `0xC3` = JP.LIL (4 bytes)
- `0x21` = LD HL,imm24 (4 bytes in ADL mode)
- `0x3E` = LD A,imm8 (2 bytes)
- `0xCB` prefix = bit operations
- `0xDD`/`0xFD` = IX/IY prefix
- `0xED` prefix = extended ops
- `0x40` prefix (.SIS) = short mode override

For each call site, read ~300 bytes around it (150 before, 150 after) and decode the instruction stream. Look for function boundaries (RET, JP to far address, or alignment patterns).
