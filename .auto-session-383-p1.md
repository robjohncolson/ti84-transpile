# Session 383 P1: Find the parent function of 0x03010D and add as transpiler seed

## Context
Session 382 discovered that the translation table lookup code at ROM address 0x03010D has 0 CALL sites — it is reached by FALL-THROUGH from a parent function that starts BEFORE 0x03010D. This parent function converts the reversed _GetCSC scan code (e.g., ENTER=0x29) to a forward table index for the lookup table at 0x09F79B.

The translation table at 0x09F79B uses forward formula indices (group*8+bit+1), but _GetCSC stores reversed codes ((6-group)*8+bit+1). The parent function of 0x03010D performs this conversion. Adding the parent function's entry point as a transpiler seed will enable key-code translation (populating 0xD0058C with the TI-BASIC key code).

## Task
1. Read `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Disassemble BACKWARDS from 0x03010D to find the function entry point. Look for:
   - A RET or JP instruction (marks the end of the previous function)
   - Standard function prologues: PUSH IX/IY, LD IX,0, etc.
   - The first instruction after a RET/JP before 0x03010D is likely the parent function entry
3. Scan roughly 0x030080-0x03010D for the entry point
4. Also check: does the code between the entry point and 0x03010D contain the reversed→forward scan code conversion? (XOR, SUB, complement, table lookup)
5. Create a probe file `TI-84_Plus_CE/probe-phase383-parent-03010D.mjs` that:
   - Reads ROM.rom
   - Disassembles from the identified entry point through 0x03010D+
   - Documents the function boundary and the scan code conversion logic
   - Lists the entry point address clearly in output
