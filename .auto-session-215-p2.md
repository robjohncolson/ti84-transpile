# Auto-Session 215 P2: BIT 7,(IY+0x18) setter map — what arms the 0x06004C gate?

## Context
We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80). Session 214 found that the sole caller of the edit-mode dispatcher (0x061290) is at 0x06004C, gated by `BIT 7,(IY+0x18)`. IY base = 0xD00080, so IY+0x18 = address 0xD00098. When BIT 7 is SET, the JP NZ fires and reaches the dispatcher which sets BIT 4,(IY+5) (arming digit insertion). We need to find what sets/clears/tests BIT 7 at (IY+0x18).

- Scan for all IY-indexed bit manipulation instructions targeting offset 0x18:
