# Task: Extend Boot to 50,000 Steps (Multi-Phase Probe)

## Context
The TI-84 CE ROM transpilation project has confirmed the OS reaches the main event loop (_GetCSC keyboard scan) by 10k steps. Session 366 attempted a 50k boot probe but failed because it used a single-phase Z80 boot (only reaching 274 blocks at the RAM trampoline). The golden probe (`probe-phase99d-home-verify.mjs`) uses a multi-phase pattern that MUST be followed.

## Golden probe boot pattern (from probe-phase99d-home-verify.mjs)
The `coldBoot()` function does:
1. `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })` — Z80 cold boot
2. Reset halted/iff/sp, set sp = 0xD1A87E - 3
3. `executor.runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })` — kernel init
4. Set mbase=0xD0, iy=0xD00080, hl=0, reset halted/iff/sp
5. `executor.runFrom(0x0802B2, 'adl', { maxSteps: 100, maxLoopIterations: 32 })` — post-init

## Your task
Create `TI-84_Plus_CE/probe-phase367-boot-50k.mjs` that:

1. Copies the full `coldBoot()` pattern above (all 3 phases with exact parameters)
2. After coldBoot completes, continues execution for 50,000 additional steps from the event loop entry point. After `coldBoot()`, the OS should be near 0x003A73 (event loop). Use `executor.runFrom(cpu.lastPc || 0x003A73, 'adl', { maxSteps: 50000, maxLoopIterations: 500 })` — or better, capture the `lastPc` from the post-init run and continue from there.
3. Reports:
   - Total unique blocks visited across ALL phases
   - The milestone block count at each phase boundary
   - New blocks discovered during the 50k extension (not seen in earlier phases)
   - Top 10 most-visited blocks during the 50k extension
   - Any `missing_block` terminations (address + mode)
   - Whether the OS is still scanning keys or has progressed to new functionality
   - The final PC, SP, and key register states
