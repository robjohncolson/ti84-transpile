## eZ80 Disassembly Notes
- eZ80 is little-endian, variable-length instructions
- CALL addr24: CD + 3-byte LE address
- IN A,(port): DB port (or IN0 A,(port): ED 38 port for 8-bit port)
- OUT (port),A: D3 port (or OUT0 (port),A: ED 39 port)
- IN A,(C): ED 78 (reads port from BC register)
- OUT (C),A: ED 79 (writes port from BC register)
- LD A,(addr24): 3A + 3-byte LE address
- LD (addr24),A: 32 + 3-byte LE address
- RET: C9, RETI: ED 4D
- DI: F3, EI: FB, HALT: 76
