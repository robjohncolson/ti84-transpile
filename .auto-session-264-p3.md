### Step 2: Add the handlers

**expr(string)**: Parse the string argument, recursively evaluate it through the same direct-eval engine. If the string contains a valid expression, return its numeric result.

**sub(string, start, length)**: Return substring. TI-84 uses 1-indexed positions. `sub("HELLO",2,3)` returns "ELL".

**inString(string, search[, start])**: Find first occurrence of search in string, starting at optional start position (1-indexed, default 1). Returns 0 if not found.

**Matr>list(matrix, col, listVar)**: Extract column `col` from matrix into a list. Since direct-eval uses JS arrays, extract `matrix.map(row => row[col-1])`.

**List>matr(list1, list2, ..., matVar)**: Combine lists as columns into a matrix. Each list becomes a column.

**\*row(scalar, matrix, row)**: Multiply all elements in `row` (1-indexed) of matrix by scalar. Return new matrix.

**\*row+(scalar, matrix, rowSrc, rowDest)**: Multiply rowSrc by scalar, add to rowDest. Return new matrix.

**rowSwap(matrix, row1, row2)**: Swap two rows. Return new matrix.
