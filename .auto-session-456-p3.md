# Auto-Session 456 — P3: Re-arm D177B7=0x55 Between Keys in VRAM Probe

## Context

This is a TI-84 Plus CE ROM transpilation project. Session 455 found that only the FIRST key ("1") produces VRAM changes in the snapshot-diff probe because D177B7 goes from 0x55 → 0x00 after key 1's display refresh. Without re-arming D177B7=0x55 before each subsequent key, the display refresh path at 0x048AC4 is skipped.

**D177B7 protocol**: 
- 0x55 = dirty/needs-refresh (triggers display refresh in key processor)
- 0xAA = consumed/refresh-in-progress  
- 0x00 = clean (no refresh needed)

## Task

Create a probe `TI-84_Plus_CE/probe-phase456-vram-rearm.mjs` based on `probe-phase455-vram-changed-map.mjs` that:

1. Uses the same boot sequence and key injection as the phase 455 VRAM probe
2. **Re-arms D177B7=0x55** before EACH key injection (not just the first)
3. Injects 4 keys in sequence: "1", "+", "1", ENTER (scan codes 0x12, 0x11, 0x12, 0x10)
4. For each key, snapshots VRAM (0xD40000-0xD65400) before and after processing
5. Reports per-key: number of changed bytes, row ranges affected, column ranges affected
6. Compares all 4 keys' change maps to identify common vs unique VRAM regions

**Key constants** (from existing probes):
- VRAM_BASE = 0xD40000
- VRAM size = 320 * 240 * 2 = 153,600 bytes (16-bit RGB565)
- D177B7 = display dirty flag address (0xD177B7)
- D00587 = key scan code address
- D00080 bit 3 = key available flag
- D141B5 = key buffer
- D14091 = key processing enable (must be nonzero)
- EVENT_LOOP_ENTRY = 0x003A73
- Boot sequence: same as probe-phase455-vram-changed-map.mjs

**Critical**: After boot, set mem[0xD14091]=1 and mem[0xD177B7]=0x55. Before EACH key injection, re-arm mem[0xD177B7]=0x55. Also clear D141B5=0 between keys (it's a single-entry buffer that must be empty for new keys).

The boot sequence and processInjectedKey function should be copied from `probe-phase455-vram-changed-map.mjs`. Read that file for the exact boot stages, flash trampoline copy, and key processing loop pattern.

## Deliverables
- `TI-84_Plus_CE/probe-phase456-vram-rearm.mjs`
- Console output: per-key VRAM diff stats, row/col ranges, cross-key comparison
