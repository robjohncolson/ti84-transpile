# Task: Test 0x05C52C key classifier with magic A values for secondary table lookup

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM has been lifted to JavaScript. Session 222 decoded the key classifier function at 0x05C52C — it uses "magic A values" (0xFA/0xFB/0xFC/0xFE) to select secondary token tables, with the real key code stored in RAM at 0xD0058E.

**Key classifier architecture (from session 222)**:
- Normal keys: A < 0xFA → SUB 0x5A → index primary table at 0x05BF84 → RET
- A=0xFE → Fn table: reads (0xD0058E), splits at CP 0x69 → below=0x05C01D, above=SUB 0x69→0x05C086
- A=0xFC → 2nd table at 0x05C1B0, reads (0xD0058E)
- A=0xFB → Alpha table at 0x05C3AA, reads (0xD0058E), CP 0x8C adjust
- A=0xFA → AlphaLock table at 0x05C4A0, reads (0xD0058E), CP 0x44 bounds

## Deliverable
Create `TI-84_Plus_CE/probe-phase223-05c52c-secondary-tables.mjs` that:

1. **Part A: Fn table (A=0xFE)**
   - Set A=0xFE, mem[0xD0058E]=0x76 (LOG key code, which is < 0x69)
   - Call ConvKeyToTok entry at 0x05E630 (which calls 0x05C52C internally)
   - OR call 0x05C52C directly if ConvKeyToTok adds unwanted overhead
   - Record what token value is returned in DE or A after the call
   - Expected: should index Fn table (0x05C01D) and return a non-zero token (LOG = [0xBB,something])
   
2. **Part B: Fn table high range (A=0xFE, key ≥ 0x69)**
   - Set A=0xFE, mem[0xD0058E]=0x76 is already < 0x69, so also try 0xD0058E=0x69 or 0x6A
   - Record the returned token

3. **Part C: 2nd table (A=0xFC)**
   - Set A=0xFC, mem[0xD0058E]=0x76
   - Record returned token — should be a 2-byte token from 0x05C1B0

4. **Part D: Alpha table (A=0xFB)**
   - Set A=0xFB, mem[0xD0058E]=0x76
   - Record returned token

5. **Part E: AlphaLock table (A=0xFA)**
   - Set A=0xFA, mem[0xD0058E]=0x76
   - Record returned token

Also seed the gap buffer for ConvKeyToTok if needed:
- editTop (0xD02437) = 0xD00A00
- editCursor (0xD0243A) = 0xD00A00  
- editTail (0xD0243D) = 0xD00B00
- editBtm (0xD02440) = 0xD00B00
- BIT 4,(IY+5) should be SET for BufInsert path

## Key constraints
- Use `createPeripheralBus({ timerInterrupt: false })` — timer IRQ causes infinite loop
- ROM write-protect: writes where addr < 0x400000 are silently dropped
- `mem.fill(val, start, END)` not `(val, start, length)` — the third arg is END position
- IY base = 0xD00080 (set by boot or manually: `cpu.registers.IY = 0xD00080`)
- MBASE = 0xD0 (default in cpu-runtime.js)

## Success criteria
- Probe runs without crash
- At least one magic A value produces a non-zero token from a secondary table
- Output clearly shows which table was consulted and what token was returned
- Print results as structured console output
