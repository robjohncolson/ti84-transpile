# Auto-Session 394 P3: Model LCD Palette Register 0xE30200 in peripherals.js

## Context
The TI-84 Plus CE LCD controller has a 512-byte color palette at memory-mapped address 0xE30200. Session 393 decoded the 8bpp setter function at 0x05523D-0x05527F, which copies 512 bytes from ROM address 0x055777 to 0xE30200 (the LCD palette registers).

Architecture:
- 256 entries × 2 bytes each = 512 bytes (RGB565 format, likely)
- Written by the 8bpp mode setter when switching to 8bpp color depth
- Used by the LCD controller to map 8-bit pixel values to 16-bit RGB565 colors
- The LCD controller is memory-mapped starting at 0xE30000

Known LCD registers from prior sessions:
- 0xE30018 = LCD timing control register (written by mode setter helper at 0x055280)
- 0xE30020 = LCD status register (busy-wait bit 2)
- 0xE30028 = LCD control register (bit 2 set during mode change)
- 0xE30200-0xE303FF = palette (512 bytes, this task)

Also relevant:
- 0xD000C6 bit 2 = system LCD mode flag (0=16bpp, 1=8bpp), checked by 12 callers
- Jump table: 0x022264 → 8bpp setter, 0x022268 → 16bpp setter
