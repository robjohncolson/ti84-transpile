# Task: Investigate JP 0x000DB6 — Primary Scanner's Return Path

## Context
The TI-84 Plus CE primary keyboard scanner at 0x0159C0 ends with a tail-call `JP 0x000DB6` instead of a normal `RET`. This is unusual — normal functions just RET. We need to understand what 0x000DB6 does. Possibilities:
- Interrupt re-enable (EI + RETI)
- Context restore (POP registers + RET)
- OS dispatch (jump to event loop)
- Something else entirely

## What to do
Create a probe at `TI-84_Plus_CE/probe-phase299-000DB6-return-path.mjs` that:

1. **Static disassembly of 0x000DB6**:
   - Read `TI-84_Plus_CE/ROM.rom` binary
   - Decode instructions starting at 0x000DB6, continuing until you hit a RET, RETI, JP, or unconditional branch that exits the routine
   - For each instruction: print address, hex bytes, mnemonic, operands
   - Continue past any conditional branches to get the full picture of both paths
   - Decode at least 64 bytes from 0x000DB6

2. **Check if 0x000DB6 is in the OS jump table**:
   - The OS jump table starts at 0x000000 and has entries every 3 bytes (JP addr24)
   - Calculate: 0x000DB6 / 3 = entry 0x492 = entry 1170
   - Check if 0x000DB6 is exactly aligned to a 3-byte boundary (0xDB6 % 3 = 0? → 0xDB6 = 3510, 3510/3 = 1170 → yes, it's entry 1170)
   - What OS API call is entry 1170? Check if the transpiler's seed list or any spec file names it

3. **Search for other callers of 0x000DB6**:
   - Scan ROM for `CD B6 0D 00` (CALL 0x000DB6) and `C3 B6 0D 00` (JP 0x000DB6)
   - List all callers with their addresses

4. **Dynamic trace**:
   - Boot OS through home screen (reference: probe-phase99d-home-verify.mjs boot sequence)
   - Count how many times PC enters 0x000DB6 during boot
   - For each entry, log the return address (from stack) to see who called/jumped here

5. **Cross-reference with known OS API names**:
   - Check `TI-84_Plus_CE/cpu-runtime.js` for any comments or labels near 0x000DB6
   - Check if the CE SDK headers name jump table entry 1170
   - Search for "0x000DB6" or "000DB6" in all .md and .mjs files in the project

## eZ80 instruction reference
- `C9` = RET
- `ED 4D` = RETI  
- `FB` = EI (enable interrupts)
- `F3` = DI (disable interrupts)
- `E1` = POP HL
- `D1` = POP DE
- `C1` = POP BC
- `F1` = POP AF
- `DD E1` = POP IX
- `FD E1` = POP IY
