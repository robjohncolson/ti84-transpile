## eZ80 Decoding Reference
- `3A xx xx xx` = LD A,(addr24)  [4 bytes]
- `32 xx xx xx` = LD (addr24),A  [4 bytes]
- `CD xx xx xx` = CALL addr24    [4 bytes]
- `C3 xx xx xx` = JP addr24      [4 bytes]
- `C9` = RET, `D8` = RET C, `C0` = RET NZ, `C8` = RET Z, `D0` = RET NC
- `18 dd` = JR dd, `20 dd` = JR NZ, `28 dd` = JR Z, `38 dd` = JR C, `30 dd` = JR NC
- `FE xx` = CP xx, `E6 xx` = AND xx, `F6 xx` = OR xx, `EE xx` = XOR xx
- `FD CB dd xx` = IY+dd bit operations (4 bytes)
- `ED 6F` = RLD, `ED 67` = RRD
- `D6 xx` = SUB xx, `C6 xx` = ADD A,xx
- `CB xx` = bit ops on registers
- `AF` = XOR A, `B7` = OR A
- `21 xx xx xx` = LD HL,addr24 [4 bytes eZ80]
- `11 xx xx xx` = LD DE,addr24 [4 bytes eZ80]
- `01 xx xx xx` = LD BC,addr24 [4 bytes eZ80]
- `ED B0` = LDIR, `ED B8` = LDDR
- `ED A0` = LDI, `ED A8` = LDD
- `ED B1` = CPIR, `ED A1` = CPI
- `E5` = PUSH HL, `D5` = PUSH DE, `C5` = PUSH BC
- `E1` = POP HL, `D1` = POP DE, `C1` = POP BC
- `77` = LD (HL),A, `7E` = LD A,(HL)
- `23` = INC HL, `2B` = DEC HL
- `13` = INC DE, `1B` = DEC DE
- `03` = INC BC, `0B` = DEC BC
- `3C` = INC A, `3D` = DEC A
- `04` = INC B, `05` = DEC B
- `0C` = INC C, `0D` = DEC C
- `47` = LD B,A, `4F` = LD C,A, `57` = LD D,A, `5F` = LD E,A
- `78` = LD A,B, `79` = LD A,C, `7A` = LD A,D, `7B` = LD A,E
