# Auto-Session 200 — P1: Investigate BIT 5,IY+68 at 0x0584C1 (key dispatch alternate path)

## Context

We're transpiling the TI-84 Plus CE OS ROM (eZ80) into JavaScript. The key dispatch path for digit tokens goes:
0x0584A3 → Copy9 → KeyClassifier → 0x09927F → 0x082C50 → JError → z80-mode RET → HALT

This path ALWAYS crashes because JError's z80-mode RET at 0x03E1B1 pops 0x000000 → boot vector → HALT. The z80-mode mixed-mode unwinding bug prevents ALL JError recovery paths.

**However**, there's a branch at 0x0584C1 that tests `BIT 5,(IY+68)`. If bit 5 is SET (NZ), the `JR Z` at 0x0584C5 is NOT taken, and execution follows a DIFFERENT path that may skip 0x09927F entirely. Similarly, 0x0800B8 has a BIT 5 test.

## Task

Build a probe `TI-84_Plus_CE/probe-phase200-bit5-iy68.mjs` that:

1. **Identify what IY+68 is**: IY is typically 0xD00080 in the OS. So IY+68 = IY+0x44 = 0xD000C4. Read the current value at 0xD000C4 after memInit. Dump all 8 bits.

2. **Experiment A — BIT 5 CLEAR (default)**: Run from 0x0584A3 with TOKEN_STAGING pre-seeded with digit-4 token (type=0x00, token byte 0x34 at offset 1). IY=0xD00080. Don't set bit 5. Trace blocks visited, note where JR Z is taken.

3. **Experiment B — BIT 5 SET**: Same setup but set `mem[0xD000C4] |= 0x20` (bit 5). Run from 0x0584A3. Trace blocks visited. See if execution avoids 0x09927F and reaches BufInsert (0x05E2A0) or any different path.

4. **Experiment C — Trace 0x0800B8 with BIT 5 SET**: If 0x0800B8 also has a BIT 5 check, run from there with bit 5 set. See what path it takes.

5. **ROM static analysis**: Grep the transpiled JS for references to 0xD000C4 or IY+0x44 to find what OTHER blocks read/write this flag byte. List all sites.

## Setup pattern

```javascript
import { createCPU, createMemory, loadROM, createPeripheralBus, memInit } from './cpu-runtime.js';
const fs = await import('fs');
const ROM = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
const { PRELIFTED_BLOCKS } = await import('./ROM.transpiled.js');
const mem = createMemory();
loadROM(mem, ROM);
const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(mem, peripherals);
cpu.mbase = 0xD0;
memInit(cpu, mem);
// IY = 0xD00080
cpu.iy = 0xD00080;
// IX = 0xD1A860 (home-screen convention)
cpu.ix = 0xD1A860;
// SP
cpu.sp = 0xD1A87E;
// Pre-seed TOKEN_STAGING at 0xD0230E
mem[0xD0230E] = 0x00; // type byte
mem[0xD0230F] = 0x34; // digit-4 token
```

Use `cpu.runFrom(addr, PRELIFTED_BLOCKS, maxSteps)` with 500 step limit. Track blocks via `cpu.onBlock` or similar callback. Check for `missing_block` events.
