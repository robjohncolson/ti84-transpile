# Auto-Session 287 — P3: Trace E00900 reader clusters (0x040Fxx, 0x0465xx)

## Context
The TI-84 CE keyboard subsystem uses MMIO address 0xE00900 as the scan result register. Session 285 identified the keyboard MMIO architecture: a hardware scan engine at 0xE00900. Session 286 fully disassembled the foreground scanner at 0x0159C0 which reads from E00900.

Session 285's probe `probe-phase285-mmio-kbd-reader.mjs` did a static disassembly scan and found multiple E00900 reader sites. Two clusters were identified at 0x040Fxx and 0x0465xx but have NOT been traced yet. Understanding what these clusters do with the scan result is critical for connecting the keyboard hardware to the OS event loop.

## Task
Create a probe that traces execution at the E00900 reader clusters to understand their role in the keyboard pipeline.

1. First, do a static scan of ROM.rom to find ALL instructions that reference address 0xE00900 (load from or store to). Use the ez80-decoder to decode instructions around each match. List them all.

2. For the 0x040Fxx cluster: 
   - Identify the exact entry point (likely a function start — look for the nearest RET/JP before it, or a known block boundary)
   - Set up a CPU trace starting at that entry point with:
     - Stack at 0xD1A000, return sentinel at 0x7FFFFE
     - E00900 pre-loaded with a test scan code (e.g., 0x35 = a recognizable value)
     - Timer interrupt disabled: `createPeripheralBus({ timerInterrupt: false })`
   - Run up to 200 steps, logging each block visited, register state at E00900 reads, and any writes to D0058C/D0058E (the GetCSC result bytes)

3. For the 0x0465xx cluster:
   - Same approach as above

4. For any other E00900 reader sites found in step 1 that are NOT 0x0159C0 or the two clusters above, list them with their surrounding instruction context

## Deliverables
Create `TI-84_Plus_CE/probe-phase287-e00900-readers.mjs` that:
- Does a static ROM scan for E00900 references
- Traces the 0x040Fxx cluster dynamically  
- Traces the 0x0465xx cluster dynamically
- Reports: what each cluster does with the scan result, whether it writes to D0058C/D0058E, what other side effects it has
- Summary: role classification for each E00900 reader site
