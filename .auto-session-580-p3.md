# Task: Decode 0x06CFAF — GRAPH Key Handler

## Context
This is the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80).

Session 579 decoded the key dispatch pre-processor at 0x06CE73/0x06CE7F. The inner worker reads the key code from D0146D and when key code == 0x07 (GRAPH key), it dispatches `JP Z,0x06CFAF`. This is the GRAPH key handler — what happens when the user presses GRAPH on the calculator.

The inner worker at 0x06CE7F is 96B. Before dispatching to 0x06CFAF, it has already called 0x06C8B4 (cursor position), 0x06AF6C, and re-read D0146D.

## Deliverable
Create `TI-84_Plus_CE/probe-phase580-decode-06CFAF.mjs` that:

1. Reads ROM.rom from disk (`fs.readFileSync('./TI-84_Plus_CE/ROM.rom')` — returns a Buffer)
2. Disassembles starting at 0x06CFAF for up to 400 bytes
3. Uses the decoder: `import { decodeInstruction } from './ez80-decoder.js';` — call as `decodeInstruction(romBuffer, offset, 'adl')` which returns `{ mnem, op_str, length }` (NOT `.mnemonic`/`.operands` — those don't exist)
4. Identifies all CALL targets, JP targets, RAM references (0xD0xxxx), IY+offset operations
5. Counts callers of 0x06CFAF across the full ROM (scan for CD/C3 bytes with AF CF 06 pattern)
6. Prints structured findings — what does GRAPH do? Mode switch? Screen refresh? RAM writes?

## Important constraints
- The decoder API is `decodeInstruction(buffer, offset, 'adl')` → `{ mnem, op_str, length }`. The third param MUST be the string `'adl'`, not boolean `true`.
- ROM is a Node.js Buffer, NOT a DataView/ArrayBuffer. Read bytes with `rom[offset]` or `rom.readUInt8(offset)`.
- To find 3-byte LE addresses in ROM: `rom[i] | (rom[i+1] << 8) | (rom[i+2] << 16)`.
- For hex formatting: `'0x' + val.toString(16).toUpperCase().padStart(6, '0')`.
- File must be an ES module (`.mjs` extension, use `import` not `require`).
- Do NOT modify any existing files. Only create the new probe file.

## Success criterion
Running `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase580-decode-06CFAF.mjs` exits 0 and prints disassembly + caller count + analysis.
