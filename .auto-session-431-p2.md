# Task: Decode Init Priority 7 Fallback (0x009087)

## Context

The TI-84 Plus CE OS has a sequential priority init chain at 0x009118 (108 bytes, decoded in session 430). It calls 7 initializers in priority order; the first to return A=1 wins. Priority 7 (0x009087) is the UNCONDITIONAL FALLBACK — it runs when all 6 gated priorities (P1-P6) fail. Unlike P1-P6, P7 has no CP 0x01 + JR Z success check; its return value passes through directly.

The init chain at 0x009118 calls:
- P1: 0x0089F8 (USB init, 497 bytes)
- P2: 0x008BE9 (undecoded)
- P3: 0x008DA0 (Link init)
- P4-P6: undecoded
- **P7: 0x009087 — unconditional fallback** ← THIS TASK

P7 starts at 0x009087. The init chain itself starts at 0x009118 (which is 0x91 bytes later), so P7 likely ends before 0x009118. Max possible size: 0x009118 - 0x009087 = 0x91 = 145 bytes.

## What to do

1. Read ROM bytes from 0x009087 to ~0x009120 from `TI-84_Plus_CE/ROM.rom`
2. Disassemble the eZ80 ADL-mode instructions
3. Determine:
   - Exact function size (find the RET)
   - What it does — is it error recovery? Null transport setup? Default mode selection?
   - CALL targets
   - RAM variables accessed
   - Port I/O (if any)
   - Return value: what does A contain on return?

4. Write a probe at `TI-84_Plus_CE/probe-phase431-trace-009087.mjs` that:
   - Reads the ROM
   - Hex-dumps bytes from 0x009087 to the RET
   - Identifies CALL/JP targets
   - Reports findings

5. Write a report at `TI-84_Plus_CE/phase431-009087-report.md`

## eZ80 ADL mode notes

- 24-bit default word size
- CALL nn = CD xx xx xx (4 bytes)
- JP nn = C3 xx xx xx (4 bytes)  
- RET = C9
- LD A,(nn) = 3A xx xx xx, LD (nn),A = 32 xx xx xx
- IN A,(C) = ED 78, OUT (C),A = ED 79
- DD prefix = IX, FD prefix = IY
