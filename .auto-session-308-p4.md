# Task: Trace 0x0855B1 token classifier

## Context
Address 0x0855B1 is called from the complex token descriptor variant at 0x022390. Session 307 found that 0x022390 saves D005F8, calls 0x0855B1 (token classifier), then 0x080D1D (setup), then 0x0846EA (lookup). The question is: what classification does 0x0855B1 perform on the token?

Session 301 mapped the CoorMon token classification system as a 28-entry CP cascade using 0xD0058E as a secondary token byte. The question is whether 0x0855B1 is part of this same cascade or a different classification pathway.

## What to do

2. Key questions to answer:
   - How many bytes/instructions is this function?
   - What input does it expect (A register = token? HL = pointer? Something else?)
   - What classification does it perform? (CP cascade? Table lookup? Bit field check?)
   - What output does it produce? (Return value in A? Flags? Modified memory?)
   - Does it reference the CoorMon secondary token byte at 0xD0058E?
   - Does it use IY+offset modifier checks?
   - What does it write or set up for the subsequent calls to 0x080D1D and 0x0846EA?

3. Check for cross-references: search for `0x0855B1` or `0855B1` in the codebase to find other callers.

4. If the function is short (< 50 instructions), fully disassemble it. If it's long, disassemble the first 30-40 instructions to determine the pattern and document the structure.

5. Create a probe file `TI-84_Plus_CE/probe-phase308-token-classifier.mjs` that:
   - Boots the ROM to the home screen
   - Traces execution at/through 0x0855B1
   - Reports the classification logic, inputs, outputs, and any interaction with CoorMon

## eZ80 instruction reference (quick)
- `CP n` = compare A with immediate, sets flags
- `JR C,offset` / `JR NC,offset` = relative conditional jump (carry/no carry)
- `JR Z,offset` / `JR NZ,offset` = relative conditional jump (zero/non-zero)
- `LD A,(IY+d)` = load from IY-relative address (OS state)
- `BIT n,(IY+d)` = test bit in IY-relative byte
- `SUB n` = subtract immediate from A
- eZ80 is little-endian, 24-bit addresses
