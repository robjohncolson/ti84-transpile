# Auto-Session 493 P3: Search for Indirect Dispatch Tables Containing 0x061000/0x061003

## Context
We are reverse-engineering the TI-84 Plus CE OS ROM (eZ80, little-endian, 24-bit addresses). The function at 0x061000/0x061003 (cursor erase — clear-to-screen-bottom) has ZERO direct CALL/JP references in the entire ROM. It must be called via an indirect dispatch mechanism — a function pointer table somewhere in ROM contains the address 0x061000 or 0x061003 as a 24-bit little-endian value.

If we find the table that contains 0x061003, it likely also contains the cursor DRAW function address nearby. This is our best lead for finding the draw half of cursor blink.

Key addresses (24-bit little-endian encoding):
- 0x061000 → bytes 00 10 06
- 0x061003 → bytes 03 10 06
- 0x06029D → bytes 9D 02 06 (already eliminated as cursor draw, but finding its table entry helps map the dispatch system)

## Task
Create a probe `TI-84_Plus_CE/probe-phase493-dispatch-table-search.mjs` that:

1. **Byte-pattern scan the entire 4MB ROM** for the little-endian encodings:
   - Search for bytes `00 10 06` (0x061000)
   - Search for bytes `03 10 06` (0x061003)
   - Search for bytes `9D 02 06` (0x06029D)
   - For each match, report the ROM address where it was found

2. **Filter results**: For each match location:
   - Skip matches that fall within known code regions (i.e., if the match is part of an instruction encoding like a CALL/JP operand — but we already know there are ZERO direct CALL/JP to 0x061000, so any match IS a table entry)
   - Check if the match is within a 0xFF-erased region (skip these)
   - Check if the surrounding bytes (±16 bytes) contain other 0x06xxxx addresses (suggesting a function pointer table)

3. **Decode surrounding table entries**: For each confirmed match:
   - Read ±64 bytes around the match
   - Look for patterns: consecutive 3-byte entries that are all valid ROM addresses (0x000000-0x3FFFFF)
   - Identify all addresses in the table
   - Highlight any addresses in the 0x060000-0x062000 range — these are cursor/text-editing system function pointers
   - Log the full table with addresses

4. **Cross-reference**: For any NEW addresses found in the table (not 0x061000, 0x061003, or 0x06029D):
   - Check if they fall in the 0x060000-0x062000 range
   - These are strong cursor draw candidates
   - For the most promising candidate, do a quick static disassembly (read first 50 bytes and decode)

function searchPattern(rom, b0, b1, b2) {
    const matches = [];
    for (let i = 0; i < rom.length - 2; i++) {
        if (rom[i] === b0 && rom[i+1] === b1 && rom[i+2] === b2) {
            matches.push(i);
        }

    return matches;
}
