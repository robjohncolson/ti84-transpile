# Task: Trace USB Handler Call Targets (0x00D681, 0x00D9EE, 0x00B8BC, 0x0125EA, 0x012933)

## Context

Session 430 decoded 0x0089F8 (497-byte USB init handler). It dispatches on D177B8 event type via the inline case dispatcher at 0x00211B. Within its 8 case handlers, it calls several functions that are still undecoded:

1. **0x00D681** — called in event 0x45 path (descriptor bootstrap), secondary descriptor stage
2. **0x00D9EE** — called in event 0x41 path (controller/PHY arm), after port 0x3114 SET bit 0
3. **0x00B8BC** — called in event 0x47 path (DI-protected recovery), with arg 3000 (tick count)
4. **0x0125EA** — called in event 0xC0 path (vendor control) with args (0x12, 0xC0), and in 0xC1/0xC2 path with args (0x10, 0xFF) — mode transition function
5. **0x012933** — called in event 0xC0 path after 0x0125EA, success follow-up

## What to do

For each of the 5 functions:

1. Read ROM bytes starting at the address from `TI-84_Plus_CE/ROM.rom`
2. Disassemble eZ80 ADL-mode instructions
3. Determine:
   - Function size (find RET or terminal JP)
   - Purpose: what does it do?
   - CALL targets it invokes
   - RAM variables accessed
   - Port I/O
   - Arguments/return value semantics

4. Write a probe at `TI-84_Plus_CE/probe-phase431-trace-usb-targets.mjs` that:
   - Reads the ROM
   - For each function: hex-dumps bytes, identifies CALL/JP targets
   - Reports size and structure

5. Write a report at `TI-84_Plus_CE/phase431-usb-targets-report.md`

## Known context for each target

- **0x00D681**: Called after 0x00CC71 descriptor bootstrap (event 0x45). Likely a follow-up descriptor processing step.
- **0x00D9EE**: Called in 0x41 PHY arm path after port 0x3114 operations. Likely USB PHY configuration.
- **0x00B8BC**: Called with arg 3000 (ticks) inside DI-protected block (event 0x47 recovery). DI = interrupts disabled. Likely a timed recovery/reset with busy-wait.
- **0x0125EA**: Mode transition function. Called with 2 args: (0x12, 0xC0) for vendor control, (0x10, 0xFF) for C1/C2 shared handler. Likely USB OTG or mode switching.
- **0x012933**: Success follow-up in 0xC0 vendor control path. Called after 0x0125EA succeeds.

## eZ80 ADL mode notes

- 24-bit default word size
- CALL nn = CD xx xx xx (4 bytes), JP nn = C3 xx xx xx (4 bytes)
- RET = C9
- LD A,(nn) = 3A xx xx xx, LD (nn),A = 32 xx xx xx
- IN A,(C) = ED 78, OUT (C),A = ED 79
- DD prefix = IX, FD prefix = IY
- DI = F3, EI = FB
