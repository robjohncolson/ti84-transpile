# Auto-Session 256 P3: Cross-reference D00824 mode constants with handler table entries

## Context
In the TI-84 Plus CE ROM transpilation project, the OS uses two key RAM variables for context/mode:
- **D007E0**: mode/context ID byte (used by 0x08C79F comparator)
- **D00824**: app mode byte (used by 0x02FFAE dispatch chain)

Session 236 mapped D00824 writers and found these constants:
- 0x00 = home (via XOR A at 0x04EF17)
- 0x46 = written at 0x084A26
- 0x48 = written at 0x08773A/0x0877A9
- 0x49 = written at 0x088588
- 0x4A = written at 0x06FF2E/0x088B7F
- 0x01 = STAT (written at 0x09E05E)

Session 255 decoded all 20 handler table entries at 0x08C958:
[0]=0x058241(cxMain), [1]=0x03D755, [2]=0x080CA7, [3]=0x0AB667, [4]=0x06C748, [5]=0x08A653, [6]=0x09C883, [7]=0x09C742, [8]=0x09E30C(A=0x48), [9]=0x05FE17, [10]=0x0B290B, [11]=0x09E3B4, [12]=0x09DC3C, [13]=0x05CBDC, [14]=0x0454A4(multi-way dispatcher), [15]=0x045647, [16]=0x09CC2A, [17]=0x09E370, [18]=0x061ECE, [19]=0x09E2BF(A=0x53='S'=STAT).

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase256-d00824-handler-xref.mjs` that:

1. **For each of the 20 handler table entries**, disassemble the first 48 bytes at each handler address from ROM.rom. Show the raw hex and a manual eZ80 decode. Look for:
   - Any LD A,<constant> or LD (D00824),A or LD (D007E0),A patterns
   - Any CP <constant> instructions
   - Any references to D00824 (bytes `24 08 D0`) or D007E0 (bytes `E0 07 D0`)

2. **Cross-reference D00824 write sites with handler addresses**: For each D00824 writer address (0x04EF17, 0x084A26, 0x08773A, 0x0877A9, 0x088588, 0x06FF2E, 0x088B7F, 0x09E05E), scan 256 bytes BEFORE and AFTER to see if any handler table addresses appear nearby (as CALL/JP targets). This identifies which handler is active when a particular D00824 value is written.

3. **D007E0 write site scan**: Search ROM for `LD (D007E0),A` pattern. The eZ80 instruction is `32 E0 07 D0` (LD (addr),A in ADL mode). For each site found, disassemble 16 bytes before it to see what A value is being stored. Map: which code writes which D007E0 value.

4. **Build the cross-reference table**: Combine findings into a table:
   | Handler Index | Handler Address | D007E0 value | D00824 value | Context name |
   |---|---|---|---|---|
   | 0 | 0x058241 | 0x00 | 0x00 | cxMain (home) |
   | 19 | 0x09E2BF | 0x53 | 0x01 | STAT |
   ...etc
