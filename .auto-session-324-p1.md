# Task: Build a probe to test LCD DMA path (0x010A3C LCD sync function)

## Context
This is the TI-84 Plus CE ROM transpilation project. Session 323 registered all LCD DMA controller ports (0x8000-0x8041) and LCD SPI panel ports (0x31xx) in peripherals.js. The key change: port 0x8040 now returns 0x00 (idle status) and port 0x8041 returns 0x01 (panel ready). Previously 0x8040 was a stub that may have caused LCD sync (0x010A3C) to hang waiting for a status bit.

## Goal
Write a probe `TI-84_Plus_CE/probe-phase324-lcd-dma-sync-test.mjs` that:
1. Boots the OS to post-init state (entry 0x0802B2, stack 0xD1A87E, MBASE=0xD0, IY=0xD00080)
2. Calls 0x010A3C (the central LCD sync function) directly
3. Monitors whether it returns or hangs (use a step limit of ~50,000 cycles)
4. Logs all port I/O during the call (especially reads/writes to 0x8000-0x8041 and 0x31xx ranges)
5. Reports: did it return? How many steps? What ports were accessed and in what order?

## Boilerplate
Copy the probe structure from `TI-84_Plus_CE/probe-phase323-055743-lcd-hw-init.mjs`:
- Same imports (cpu-runtime.js, peripherals.js, ez80-decoder.js)
- Same ensureTranspiledModule() / cleanupTranspiledModule() pattern
- Same hex(), hexByte() helpers
- Use `createPeripheralBus({ timerInterrupt: false })` — always disable timer IRQ for probes
- Use `createExecutor(mem, bus)` then load ROM and transpiled blocks

## Calling 0x010A3C
Set up the CPU state:
- SP = 0xD1A87E (stack top)
- MBASE = 0xD0
- IX = 0xD1A860
- IY = 0xD00080
- Push a fake return address (e.g., 0x7FFFFE) onto the stack, then set PC = 0x010A3C
- Run the executor in a step loop, stopping when PC reaches the fake return address or step count exceeds 50,000

## Port I/O Logging
Hook into the peripheral bus to log all port reads and writes. The bus object from createPeripheralBus() has `read(port)` and `write(port, value)` methods. Wrap them to log before delegating:
```javascript
const originalRead = bus.read.bind(bus);
const originalWrite = bus.write.bind(bus);
const portLog = [];
bus.read = (port) => { const v = originalRead(port); portLog.push({ op: 'read', port, value: v }); return v; };
bus.write = (port, value) => { portLog.push({ op: 'write', port, value }); originalWrite(port, value); };
```

## Output
Print a summary:
- "LCD SYNC TEST: RETURNED after N steps" or "LCD SYNC TEST: HUNG after 50000 steps at PC=0xNNNNNN"
- Port I/O log (grouped by port range: 0x8000-0x8041, 0x31xx, other)
- Total port reads/writes counts
