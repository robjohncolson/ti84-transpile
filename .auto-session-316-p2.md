# Task: Decode 0x0241A3 multi-callback orchestrator

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Function at 0x0241A3 was identified in session 315 as having 5 `_indcall` dispatch sites — more than any other function in the ROM. `_indcall` is the ZDS II C runtime indirect call mechanism: it loads a function pointer into IY (typically via `FD 37 dd` = LD IY,(IX+offset)) and then dispatches via `JP (IY)` at address 0x002288.

This makes 0x0241A3 a "multi-callback orchestrator" — a function that invokes up to 5 different callbacks from its stack frame or a struct pointer.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase316-orchestrator.mjs` and a report `TI-84_Plus_CE/phase316-orchestrator-report.md`.

The probe should:
1. Read `TI-84_Plus_CE/ROM.rom`
2. Disassemble the function at 0x0241A3. Start disassembling from 0x0241A3 and continue until you hit a RET (0xC9) or JP that looks like a tail-call, or ~500 bytes, whichever comes first.
3. Find all 5 _indcall dispatch sites within this function. Look for the pattern:
   - FD 37 dd = LD IY,(IX+offset) where dd is the IX offset byte
   - Followed eventually by CALL 0x002288 (CD 88 22 00) or JP 0x002288
4. For each dispatch site, record:
   - The IX offset used (tells us which struct field holds the callback pointer)
   - Any register setup before the dispatch (what arguments are passed to the callback)
   - Whether there's a null-check before dispatch (CP A,0 / JR Z pattern after loading IY)
5. Find all callers of 0x0241A3. Search the entire ROM for CALL 0x0241A3 (CD A3 41 02) and JP 0x0241A3 (C3 A3 41 02).
6. For each caller, extract 10 bytes before the CALL to see what arguments are pushed.

The report should identify:
- What this function coordinates (display refresh? event dispatch? plugin callbacks?)
- The struct layout it expects (based on IX offsets)
- How many callers and from what subsystem

## Technical details
- eZ80 ADL mode, little-endian
- CALL nn = CD nn_lo nn_mid nn_hi (4 bytes)
- JP nn = C3 nn_lo nn_mid nn_hi (4 bytes)
- RET = C9
- FD 37 dd = LD IY,(IX+dd) — ZDS II specific opcode
- LD IY,(IX+dd) loads a 3-byte pointer from the IX-based stack frame
- _indcall entry point: 0x002288
