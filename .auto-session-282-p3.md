# Auto-Session 282 P3: Map the 4 subroutines called by 0x09ED50

## Context
This is a TI-84 Plus CE ROM transpilation project. We lift eZ80 machine code into JavaScript.

Session 281 found that 0x09ED50 (menu item/text label setup, 91 bytes, 0x09ED50-0x09EDAA) is a C-calling-convention function that takes (string_ptr, y_position, flags) and calls 4 subroutines:
1. 0x055316 — display/text related
2. 0x0552F2 — called with BC=0
3. 0x054DD4 — compares against 0x140 (320 = LCD width)
4. 0x0540D0 — render/placement

These are display primitives used by the TI-OS menu system. We need to understand what each one does.

## Task
Write a probe file `TI-84_Plus_CE/probe-phase282-09ed50-subroutines.mjs` that for EACH of the 4 subroutines:

1. **Static disassembly** — decode 40-60 bytes from ROM.rom starting at each address. Identify:
   - Input registers (what does the function expect?)
   - What RAM/MMIO it reads/writes
   - What sub-subroutines it calls
   - Return convention (what registers are outputs?)
   - Function size (find the RET)

2. **Find all callers** of each — scan ROM.rom for `CD xx xx xx` (ADL CALL) patterns for each address.

3. **Dynamic trace** of each subroutine individually:
   - Set up minimal CPU state (boot if needed, or just load ROM + create CPU)
   - Set appropriate input registers
   - Run 200 steps, log blocks visited and RAM writes
   - Note what display-related RAM regions are touched (D005xx = display state, D006xx = text buffer, D4xxxx = VRAM)

4. **Classify each** as one of: font selector, cursor positioner, text renderer, attribute setter, dimension calculator, or other.
