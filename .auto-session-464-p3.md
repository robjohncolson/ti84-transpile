# Session 464 P3: Bypass 0x0066FF Probe — Force NZ Return in Scheduler

## Context

The TI-84 CE OS scheduler at 0x0015F7 calls function 0x0066FF which searches ROM tables. It ALWAYS returns Z (fail), causing the scheduler to loop back to 0x0015F7 without ever reaching key detection at 0x0015E1.

The scheduler flow:
```
0x0015DF: CALL 0x0066FF
          ; returns Z=fail every time
0x0015DF: JR Z, 0x0015F7   ; jump back to loop start (skips key detect)
0x0015E1: SET 3,(IY+5)     ; D00085 bit 3 = key available
0x0015E5: LD A,0x0A
0x0015E7: LD HL,0x001900
0x0015EA: LD (D00595),HL
0x0015ED: CALL 0x0059C6    ; process key
0x0015F0: RES 3,(IY+5)     ; clear key flag
```

## Task

Create a probe at `TI-84_Plus_CE/probe-phase464-bypass-0066ff.mjs` that:

1. Boots the OS using the standard 3-stage boot (entry 0x000000, then 0x00020C, then 0x00042C)
2. Injects a key scan code (e.g., key "1" = scan code 0x92) into D00587 and sets D00080 bit 3
3. Also sets D14091=1 (key processing enable gate)
4. **PATCHES the transpiled function** for block at 0x0066FF to always return NZ instead of searching ROM tables
5. Enters the scheduler at 0x0015F7 and runs for up to 500,000 steps
6. Traces whether:
   - 0x0015E1 is reached (SET 3,(IY+5))
   - 0x0059C6 is called
   - 0x03FA09 (key processor) is called
   - D141B5 gets the key code
   - Any VRAM changes occur

## How to Patch 0x0066FF

The transpiled code has functions named like `block_0066FF_adl` or similar in `ROM.transpiled.js`. After loading the transpiled module, you can override the function:

```javascript
// After loading transpiled code and creating CPU:
// Find the block that implements 0x0066FF
// Override it to return NZ:

const origBlock = cpu.blocks[0x0066FF];
cpu.blocks[0x0066FF] = function() {
    // Set flags to NZ (clear Z flag)
    cpu.flags.Z = false;
    // Set HL=1 (the function returns HL=1 for "found", HL=0 for "not found")
    cpu.hl = 1;
    // Return to caller (pop PC from stack)
    const retAddr = cpu.pop24();
    cpu.pc = retAddr;
};
```

Or alternatively, just hook the return from 0x0066FF by watching the JR Z at 0x0015DF and forcing the Z flag clear.
