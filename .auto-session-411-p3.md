## eZ80 Encoding Reference
- LD A,(nn) = 0x3A + 3 bytes address (little-endian)
- LD (nn),A = 0x32 + 3 bytes address
- LD HL,(nn) = 0x2A + 3 bytes address
- LD (nn),HL = 0x22 + 3 bytes address
- CALL nn = 0xCD + 3 bytes address
- JP nn = 0xC3 + 3 bytes address
- RET = 0xC9
- IN0 A,(n) = 0xED 0x38 + 1 byte port
- OUT0 (n),A = 0xED 0x39 + 1 byte port
