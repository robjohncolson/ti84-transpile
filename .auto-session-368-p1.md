# Task: Trace 0x00BC31 Indirect Caller — How Does Execution Reach 0x00BC31?

## Context
In the TI-84 Plus CE ROM transpilation project, block 0x00BC31 is the byte-copy loop that triggers the IX linked-list corruption chain (0x00BC47 `LD IX,(IX-30)` → 0x00BC72 `LD SP,IX` → crash when IX points into ROM). Session 367 confirmed ZERO direct `CALL` or `JP` instructions targeting 0x00BC31 or 0x00BC47 in the entire 4MB ROM — the block is reached via indirect dispatch.

## Deliverables
Create a probe file `TI-84_Plus_CE/probe-phase368-bc31-indirect.mjs` that:

### Part 1: Static disassembly of 0x00BC20-0x00BC30
Read ROM bytes from 0x00BC20 to 0x00BC30 (17 bytes) and decode them as eZ80 ADL-mode instructions. This checks whether 0x00BC31 is a fallthrough target from a preceding block. Use the ROM file at `TI-84_Plus_CE/ROM.rom`.

Reference: eZ80 instruction encoding — most instructions are 1-4 bytes. Common patterns:
- `JP nn` = 0xC3 nn nn nn (4 bytes in ADL)
- `CALL nn` = 0xCD nn nn nn (4 bytes in ADL)
- `JR cc,d` = 2 bytes
- `RET` = 0xC9

### Part 2: Jump table scan
Scan the entire 4MB ROM for any 3-byte little-endian sequence that encodes the address 0x00BC31 (bytes: 0x31, 0xBC, 0x00). Report all locations where this appears, as these could be jump table entries. Similarly scan for 0x00BC47 (bytes: 0x47, 0xBC, 0x00).

### Part 3: Dynamic trace — what executes before 0x00BC31
Run a cold boot using the standard 3-phase boot pattern (same as probe-phase367-boot-50k.mjs):
- Phase 1: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
- Then reset: `cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0; cpu.sp = 0xD1A87E - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);`
- Phase 2: `executor.runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })`
- Then: `cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0; cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0; cpu.sp = 0xD1A87E - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);`
- Phase 3: `executor.runFrom(0x0802B2, 'adl', { maxSteps: 100, maxLoopIterations: 32 })`

During Phase 2, use the `onBlock` callback (available in runFrom options) to log the last 10 blocks executed before block 0x00BC31 is first reached. Also log the CPU state (PC, SP, IX, IY, A, F, HL, BC, DE) when 0x00BC31 is entered.

Pattern for onBlock callback:
```js
const history = [];
const r2 = executor.runFrom(0x08C331, 'adl', {
  maxSteps: 100000,
  maxLoopIterations: 10000,
  onBlock: (pc, mode) => {
    history.push(`${pc.toString(16).padStart(6, '0')}:${mode}`);
    if (history.length > 10) history.shift();
    if (pc === 0x00BC31 && !foundBC31) {
      foundBC31 = true;
      console.log('First entry to 0x00BC31:');
      console.log('  Block history:', history.join(' → '));
      console.log(`  CPU: SP=${hex(cpu.sp)} IX=${hex(cpu._ix)} IY=${hex(cpu._iy)}`);
      console.log(`  A=0x${cpu.a.toString(16).padStart(2,'0')} F=0x${cpu.f.toString(16).padStart(2,'0')}`);
      console.log(`  HL=${hex(cpu._hl)} BC=${hex(cpu._bc)} DE=${hex(cpu._de)}`);
    }
  },
});
```

## File structure
```js
#!/usr/bin/env node
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { createExecutor } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const romBytes = fs.readFileSync(path.join(__dirname, 'ROM.rom'));
const romModule = await import(pathToFileURL(path.join(__dirname, 'ROM.transpiled.js')).href);
const BLOCKS = romModule.PRELIFTED_BLOCKS;

function hex(v, w = 6) { return v == null ? 'n/a' : '0x' + (v >>> 0).toString(16).padStart(w, '0'); }

const mem = new Uint8Array(0x1000000);
mem.set(romBytes);
const peripherals = createPeripheralBus({ pllDelay: 2, timerInterrupt: false });
const executor = createExecutor(BLOCKS, mem, { peripherals });
const { cpu } = executor;
```
