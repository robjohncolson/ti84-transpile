# Task: Map D13FED connection table structure — who populates it, full struct fields

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

## What we know

- **D13FED** is a 5-slot connection table used by 0x00ED77 (link handshake, 164 bytes).
- Each entry is 3 bytes (a pointer to a connection structure).
- 0x00ED77 iterates 5 entries: compares slot+9 against D14014 then D141E2, filters bit 7 of slot+8 for busy, returns slot index 0-4 or 0 on no match.
- Known struct fields: +8 = busy flag (bit 7), +9 = session ID byte.
- The table is used during TI-Link protocol session matching.
- Related RAM: D14008/D14005 (block list), D1401A/D1401D (slab pool bounds), D14014 (session ID compare), D141E2 (secondary session ID).

## Your task

1. **Scan the ROM for all references to D13FED** (bytes ED 3F D1 in little-endian). Find every instruction that reads or writes D13FED, D13FEE, D13FEF, D13FF0, ..., D13FF9 (covering all 5 entries × 3 bytes = 15 bytes from D13FED to D13FFB).

2. **For each reference**, determine:
   - Is it a read (LD r,(D13FED)) or write (LD (D13FED),r)?
   - What value is being loaded/stored?
   - What function is the reference in?

3. **Trace the connection structure fields**. Since each 3-byte entry is a pointer, the actual struct is elsewhere. From 0x00ED77 we know:
   - The struct pointer is loaded into a register (likely HL or IY)
   - Fields accessed: +8 (busy, bit 7 tested), +9 (session ID, compared)
   - Find OTHER code that dereferences these pointers and accesses struct fields beyond +8 and +9.
   - Document all struct fields you find (offset, size, purpose).

4. **Write a probe** at `TI-84_Plus_CE/probe-phase423-D13FED-map.mjs` that:
   - Reads the ROM binary
   - Scans for all references to D13FED through D13FFB
   - For each reference, extracts surrounding context (10 bytes before, 10 after)
   - Identifies read vs write
   - Prints a structured report with addresses, instruction types, and contexts

5. **Write a report** at `TI-84_Plus_CE/phase423-D13FED-report.md`.

## Constraints

- Do NOT modify any existing files
- Only create NEW files: the probe and the report
- eZ80 ADL mode: addresses are 3 bytes little-endian
- To search for references to D13FED: look for byte sequence ED 3F D1 (little-endian of 0xD13FED)
- Also search for D13FF0, D13FF3, D13FF6, D13FF9 (the 5 entry start addresses, each 3 bytes apart)

## Success criteria

- Probe runs: `node TI-84_Plus_CE/probe-phase423-D13FED-map.mjs`
- Report lists all ROM references to the connection table
- Report documents which functions populate vs read the table
- Report extends the known struct fields beyond +8 and +9
