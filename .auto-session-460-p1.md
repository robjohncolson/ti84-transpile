# Task: Fix port 0x03 (GPIO) in peripherals.js — clear bit 0

## Context

Port 0x03 is the eZ80 internal GPIO/timer status register. The OS event loop at 0x003A73 calls a guard at 0x001713 → 0x0067F8 which executes `IN0 A,(03h); AND 0x01`. Port 0x03 bit 0 must be CLEAR (Z flag) for the guard to pass. When it passes, execution reaches the full ISR dispatcher at 0x03CF7D which fires KbdScan (0x03F994) and eventually 0x03FA09 (key processing that writes D141B5).

Currently, `peripherals.js` initializes port 0x03 (GPIO) with `readValue: 0xee` at line 277. Bit 0 of 0xee is 0 — wait, let me check: 0xee = 1110 1110. Bit 0 IS 0. But the read handler returns `state.gpio.readValue` which defaults to `normalizeValue(options.gpioValue ?? 0xee)`. 

**IMPORTANT**: Actually 0xEE in binary is 11101110 — bit 0 IS already 0. But something is still blocking. The issue may be that `normalizeValue` is truncating or that the `options.gpioValue` is being overridden somewhere. Check all callers of `createPeripheralBus()` to see if any pass `gpioValue` that has bit 0 set. Also check if the `IN0 A,(03h)` instruction in the transpiled code is actually reading port 0x03 or a different port.
