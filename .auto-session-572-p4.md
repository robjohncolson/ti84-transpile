# Task: MAP 0x0A1FAB SWAP FUNCTION FULLY — interrupt-safe scroll buffer swap

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 571 discovered that 0x0A1FAB is the scroll buffer swap function. It swaps between two scroll double-buffers:
- D031F6 (8,400 bytes = 40 bytes/row × 210 rows) — primary scroll shadow buffer
- D07396 (8,400 bytes) — secondary scroll shadow buffer
- D052C6 — third alternate buffer (also 8,400 bytes suspected)

The function uses DI/EI (disable/enable interrupts) with the eZ80 errata workaround (double LD A,I for interrupt state save). It was discovered via cross-referencing the scroll buffer pointers.

## What to do
1. Create a probe script `TI-84_Plus_CE/probe-phase572-map-0A1FAB.mjs` that:
   a. Reads the ROM at `TI-84_Plus_CE/ROM.rom`
   b. Disassembles starting at 0x0A1FAB using the eZ80 decoder
   c. Traces the full function until its RET/JP exit
   d. Documents:
      - Full disassembly with addresses
      - Which buffer pointers it reads/writes (D031F6, D07396, D052C6, or others)
      - How the swap works (pointer exchange? LDIR copy? index toggle?)
      - The DI/EI errata workaround pattern (double LD A,I)
      - What flags/values it returns
   e. Searches for all callers: CALL 0x0A1FAB (CD AB 1F 0A) and JP 0x0A1FAB (C3 AB 1F 0A)
   f. For each caller, identifies the context (which function calls the swap and when)
   g. Prints: full disassembly, function size, swap mechanism, buffer addresses, callers with context
