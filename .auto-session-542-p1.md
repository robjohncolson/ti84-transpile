## Probe Template
Use this pattern (from working probes in this repo):
```javascript
import { readFileSync } from 'fs';
import { createEz80Decoder } from './ez80-decoder.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const decoder = createEz80Decoder(rom);

const START = 0x03EBA3;
const LENGTH = 200;

console.log(`=== Decoding 0x${START.toString(16).toUpperCase()} ===`);
console.log(`Raw bytes: ${Array.from(rom.slice(START, START + LENGTH)).map(b => b.toString(16).padStart(2, '0')).join(' ')}`);

let pc = START;
const end = START + LENGTH;
while (pc < end) {
    const instr = decoder.decode(pc);
    if (!instr) { console.log(`  0x${pc.toString(16)}: ??? (${rom[pc].toString(16)})`); pc++; continue; }
    console.log(`  0x${pc.toString(16).padStart(6, '0')}: ${instr.asm}`);
    pc += instr.length;
    if (instr.asm === 'RET' || instr.asm.startsWith('JP ') && !instr.asm.includes(',')) break;
}
```

**Adjust `LENGTH` if the function is larger than expected. Look for patterns like LD IY,D00080 (system flags setup), OUT0/IN0 (port I/O), BIT/SET/RES on IY offsets (flag manipulation).**
