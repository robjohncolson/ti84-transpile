# Auto-session 496 P1 — Full BCALL Table Scan for Cursor Position References

## Goal
Scan ALL 2,178 BCALL entries for references to D00595 (cursor row) and D00596 (cursor column) within the first 200 bytes of each entry's target address. This is the brute-force approach to finding the cursor draw function: instead of guessing which cluster, scan everything.

## Context
- The TI-OS has a BCALL jump table at 0x020104-0x02230B with 2,178 entries (each `C3 xx xx xx` = JP addr).
- The full table is at `TI-84_Plus_CE/bcall-table.json` (8714 lines, array of {index, tableAddr, targetAddr} objects).
- We're looking for the cursor DRAW function. The cursor ERASE is entry 832 (target 0x061003). The cursor cluster (entries 826-833) has been fully exhausted — none of them is the cursor draw.
- Cursor position is stored at D00595 (row) and D00596 (column). The cursor draw function MUST read these to know where to draw.
- Byte patterns to search for (little-endian 24-bit addresses in eZ80 machine code):
  - D00595 → bytes [0x95, 0x05, 0xD0]
  - D00596 → bytes [0x96, 0x05, 0xD0]
- Also optionally search for 0x0059C6 (charRenderer) → [0xC6, 0x59, 0x00] and cursor glyph codes 0xE1, 0xE2, 0xE3.

## Deliverable
Create `TI-84_Plus_CE/probe-phase496-bcall-cursor-scan.mjs` that:

1. Loads the ROM file (`TI-84_Plus_CE/ROM.rom`) as a Buffer
2. Loads `TI-84_Plus_CE/bcall-table.json`
3. For each of the 2,178 entries, scans the first 200 bytes starting at `targetAddr` in the ROM for the byte patterns above
4. Outputs a ranked list of entries that reference D00595 and/or D00596, sorted by number of pattern matches
5. For each match, reports: entry index, target address, which patterns found, and the byte offset within the function where the pattern was found
6. Excludes known entries: 832 (cursor erase at 0x061003), entries 826-831, 833 (all eliminated)
7. This is a PURE STATIC SCAN — no CPU execution needed, just ROM byte scanning

Run the probe after creating it:
```
node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase496-bcall-cursor-scan.mjs
```
