# Task: Trace 0x0A22B1 display setup function (jjjj)

## Context

We need to understand what the display setup function at 0x0A22B1 does BEFORE entering the VRAM fill at 0x09EFDE. This is the "screen repaint initialization" — it likely sets up VRAM base address, fill color, rectangle dimensions, etc.
