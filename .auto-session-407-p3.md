## Technical Details
- eZ80 is little-endian, 24-bit addresses
- ROM file: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom')`
- LD A,(nn) = 0x3A + 3 bytes little-endian. So LD A,(0xD177B8) = 3A B8 77 D1 (4 bytes)
- CP n = 0xFE + 1 byte
- JR cc,e = 0x20/0x28/0x30/0x38 + signed offset
- JP cc,nn = 0xC2/0xCA/0xD2/0xDA + 3 bytes
- CALL nn = 0xCD + 3 bytes
- BIT b,(IY+d) = 0xFD 0xCB d 0x46/4E/56/5E/66/6E/76/7E
