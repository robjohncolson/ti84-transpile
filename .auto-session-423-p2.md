# Task: Trace 0x00E583 (sibling list walker) — what list does it walk?

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

## What we know

- **0x00E4E8** (155 bytes, 0x00E4E8-0x00E582) is a header field extractor. Fully decoded in session 422:
  - Computes table index from IY header bytes (IY+0x1B shifted left 8, plus IY+0x1A)
  - Validates type field (AND 0x03 == 0x01 for data transfer)
  - Saves/clears IY+0x18 (protocol state)
  - Scans D141EC+1 for nonzero active-transfer entry
  - Returns: HL=0 if consumed match, else computed index
  - 3 CALL targets: 0x002197 (stack frame), 0x0021C2 (null check), 0x0022F9 (shift left)

- **0x00E583** immediately follows 0x00E4E8. It's a "sibling list walker" that calls 0x00E4E8. The question: what list does it walk, and how does it relate to the 0x00FE10 transfer engine?

- **0x00FE10** (638 bytes) is the main TI-Link transfer engine. It walks a block list (D14008→D14005) and calls both 0x00E1CC (slab free) and 0x00E4E8 (header extractor).

## Your task

1. **Disassemble 0x00E583** through to its RET instruction. Estimate ~100-200 bytes. Read ROM bytes at file offset 0x00E583 and decode eZ80 ADL-mode instructions. Document:
   - Exact byte range (start-end)
   - All CALL targets (especially calls to 0x00E4E8)
   - All RAM reads/writes (0xD00000+ range)
   - Loop structure — how does it iterate? What pointer advances?
   - What list is being walked? (D14008? D141EC? Something else?)
   - Return value and how callers use it

2. **Find all callers of 0x00E583** by scanning the ROM for `CALL 0x00E583` (opcode CD 83 E5 00) and `JP 0x00E583` (opcode C3 83 E5 00). Document each caller's address and context.

3. **Write a probe** at `TI-84_Plus_CE/probe-phase423-trace-00E583.mjs` that:
   - Reads the ROM binary
   - Extracts bytes for 0x00E583
   - Scans for all CALL/JP references to 0x00E583
   - Identifies loop structure, CALL targets, RAM addresses
   - Prints a structured report

4. **Write a report** at `TI-84_Plus_CE/phase423-trace-00E583-report.md` summarizing findings.

## Constraints

- Do NOT modify any existing files
- Only create NEW files: the probe and the report
- eZ80 ADL mode: 24-bit addresses, 3-byte pointers
- CALL opcode = CD xx xx xx (4 bytes), JP = C3 xx xx xx (4 bytes)
- Port I/O: IN A,(C) = ED 78, OUT (C),A = ED 79, BC = port address

## Success criteria

- Probe runs: `node TI-84_Plus_CE/probe-phase423-trace-00E583.mjs`
- Report documents exact byte range, list structure, relationship to 0x00E4E8 and 0x00FE10
