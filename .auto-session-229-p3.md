# Task: Investigate 0x0AF8C4 BCD Formatter — D00604 Key Code Output

## Context
In the TI-84 Plus CE ROM transpilation project, we found that 0x0AF8C4 is a BCD display formatter that clobbers HL. Specifically:
- Called from 0x03FC1C's common tail: `PUSH HL / CALL 0x03FA09 / POP HL / PUSH AF / CALL 0x0AF8C4 / POP AF / RET`
- At 0x0AF8FC, it does `LD HL,0xD00604` and writes BCD digits there via an RLD loop
- Returns with HL=0xD00604

The question: **does 0x0AF8C4 write the key code in BCD format to D00604?** If so, D00604 is an alternate readable key code output that just needs BCD→binary conversion. This could be useful for browser-shell integration.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase229-0af8c4-bcd-output.mjs` that:

1. **Static disassembly**: Disassemble 0x0AF8C0-0x0AF960 (the BCD formatter function and surrounding context). Document the full instruction sequence, especially the RLD loop and what it writes to D00604+.

2. **Dynamic trace with known key codes**: Call 0x03FC1C with several known D0058D values (indices into the 56-entry table at 0x03FC41) and examine what gets written to D00604-D0060D (the BCD output region) after 0x0AF8C4 returns. Test at least 5 different indices:
   - Index 1 (expected key code 0x22 = DOWN arrow)
   - Index 9 (row boundary)
   - Index 34 (expected key code 0x8F = digit '1')
   - Index 40 (expected key code ~0x82 = multiply)
   - Index 55 (last valid entry)

3. **Determine the BCD format**: Document exactly what bytes are written to D00604-D0060D for each test case. Is it:
   - The key code value in BCD (e.g., 0x8F → bytes `08 0F` or `89` in packed BCD)?
   - The table entry value in some display format?
   - Something else entirely (like a display cursor position)?

4. **Check if the BCD output correlates with key codes**: Compare the D00604 output bytes with the known key code values from the 0x03FC41 table. If there's a predictable relationship, document the conversion formula.

5. **Cross-reference D00604**: Scan ROM for reads of D00604 — who consumes this BCD output? Look for `LD A,(0xD00604)`, `LD HL,0xD00604`, etc.

For static ROM scan: search `romData` for byte patterns `3A 04 06 D0` (LD A,(D00604)) and `21 04 06 D0` (LD HL,D00604) etc.
