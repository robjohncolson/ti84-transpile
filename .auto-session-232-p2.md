# Auto-Session 232 — P2: Trace 0x02FE9D SET 0,(IY+29) function boundary and trigger

## Task
Build a probe that fully traces the function containing the SET 0,(IY+29) instruction at 0x02FE9D. Determine the full function boundary, what triggers it, and what controls whether the SET vs the nearby RES at 0x02FEA7 fires.

## Background
Session 231 found that 0x02FE9D is the ONLY site in the entire 4MB ROM that sets bit 0 of IY+29 (the key repeat timer gate). The RES at 0x02FEA7 is only 10 bytes later in the same function. This means the function conditionally arms OR disarms the timer gate.

Known context from session 230:
- 0x02FE84 is a trivial wrapper: clears modifier flags then CALL 0x030300
- 0x030300 does BIT 0,(IY+29) gate → RES 3,(IY+8) → CALL 0x040D11 (key repeat timer)
- 2 callers of 0x02FE84: 0x02FFEE (JP NZ) and 0x030130 (JP)
- The SET at 0x02FE9D is NOT inside 0x02FE84 — it's at a different address nearby

## Deliverables
Create `TI-84_Plus_CE/probe-phase232-02fe9d-function-trace.mjs` that:

1. **Static disassembly**: Read ROM bytes from 0x02FE70 to 0x02FFE0 (a generous window around 0x02FE9D). Disassemble every instruction using the eZ80 decoder. Find function boundaries by looking for RET/JP instructions that terminate blocks, and identify the function containing 0x02FE9D.

2. **Identify the branch condition**: The SET at 0x02FE9D and RES at 0x02FEA7 are 10 bytes apart. There must be a conditional branch (JR Z/JR NZ/JP Z/etc.) between or before them that determines which fires. Decode this branch.

3. **Find callers**: Do a static ROM scan (0x000000-0x0BFFFF) for:
   - `CD XX FE 02` (CALL to anything in 0x02FExx range near 0x02FE9D)
   - `C3 XX FE 02` (JP to same range)
   - `18 XX` / `20 XX` / `28 XX` / `30 XX` / `38 XX` (JR/JR NZ/JR Z/JR NC/JR C within ±127 bytes)
   Focus on finding what calls the function containing 0x02FE9D.

4. **Dynamic trace**: Using cpu-runtime.js, set up a minimal runtime (cold boot, no timer interrupts), then execute starting at the function entry found in step 1. Run for 200 steps. Record:
   - All blocks visited
   - Final value of IY+29 (0xD0009D)
   - Whether SET or RES was reached
   - What registers/flags control the branch

5. Output structured results: function boundary, branch condition, callers, dynamic trace summary.
