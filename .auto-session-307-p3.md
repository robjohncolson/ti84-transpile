# Auto-Session 307 P3: Trace 0x09DDB8 Token Descriptor Table Population

## Context
Session 304 discovered a token descriptor table at RAM address 0xD0227E (3 × 18 bytes, MLT-indexed). The function at 0x09DDB8 populates this table. The mode selector at 0x070165 chooses which of the 3 entries to use. This priority has been carried forward since session 305 — it needs someone to actually trace the code.

From session 304 findings:
- Table at 0xD0227E: 3 entries × 18 bytes each = 54 bytes total
- Indexed via MLT instruction (multiply for table offset)
- 0x09DDB8 = population function
- 0x070165 = mode selector that chooses active entry
- Related to token descriptor system (0x022346 builder, 0x0236F9 writer)

## Task

2. Trace the full control flow. Document:

3. Also disassemble 0x070165 (the mode selector) to understand how the active entry is chosen.
4. Document the 18-byte entry structure: which bytes are what fields.
