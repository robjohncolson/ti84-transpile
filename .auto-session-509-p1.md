## eZ80 Decoding Reference

Use the decoder at `TI-84_Plus_CE/ez80-decoder.js`:
```javascript
import { createDecoder } from './ez80-decoder.js';
const decoder = createDecoder();
// decoder.decode(romBuffer, offset) returns {mnemonic, length, ...}
```

Or read raw bytes and decode manually. Key eZ80 patterns:
- `CD xx xx xx` = CALL addr24
- `C3 xx xx xx` = JP addr24
- `AF` = XOR A
- `32 xx xx xx` = LD (addr24),A
- `3E xx` = LD A,imm8
- `CB xx` = bit operations (SET, RES, BIT)
- `FD CB xx xx` = IY-indexed bit operations
- `ED` prefix = extended instructions
- `40` prefix = .SIS (16-bit operand mode)
