## eZ80 Reference
- eZ80 is a Z80 superset with 24-bit addresses (ADL mode)
- LD A,(addr) = 3A ll mm hh (4 bytes in ADL mode)
- LD (addr),A = 32 ll mm hh
- CALL addr = CD ll mm hh (4 bytes)
- CP n = FE nn
- JR cc,offset = 20/28/30/38 dd (relative jump)
- RET = C9
- LD HL,(addr) = 2A ll mm hh
- IX-relative: DD prefix, e.g., DD 7E dd = LD A,(IX+d)
- IY-relative: FD prefix
- CB prefix = bit operations (BIT/SET/RES)
- 0x40 byte can be .SIS prefix (changes immediate size to 16-bit) — watch for this!
