# Task: Decode 0x09903E — List Setup Helper

## Context
This is a TI-84 Plus CE OS ROM (eZ80 ADL mode) disassembly task. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, little-endian eZ80). All addresses are 24-bit. The CPU runs in ADL mode (24-bit registers, 3-byte addresses) unless `.SIS` prefix (0x40) forces 16-bit operand/address for that instruction.

## Target
Disassemble and document the function at ROM address **0x09903E**. This function is called by 0x097C8A (list/complex setup, ~170B) right before the BC metadata write:
```
; In 0x097C8A (list/complex setup):
CALL 0x09903E          ; <-- THIS FUNCTION
.SIS LD (D00338),BC    ; store BC to edit buffer metadata
LD HL,(D00335)
LD (HL),0x00           ; NUL terminator
DEC HL
LD (HL),0x7D           ; '}' character
```

So 0x09903E runs right before the list terminator ('}' + NUL) is written to the edit buffer.

## How to read the ROM
```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');

function readBytes(addr, len) {
  return Array.from(rom.slice(addr, addr + len))
    .map(b => b.toString(16).padStart(2, '0')).join(' ');
}

// Read 256 bytes starting at the target
console.log(readBytes(0x09903E, 256));
```

## eZ80 Decoding Notes
- Default mode is ADL (24-bit). Immediate addresses are 3 bytes little-endian.
- Prefix 0xDD = IX register variants, 0xFD = IY register variants
- Prefix 0x40 = .SIS (force 16-bit mode for next instruction)
- CALL = 0xCD + 3-byte addr (LE). JP = 0xC3 + 3-byte addr. JR = relative jump (signed byte).
- RET = 0xC9. Conditional RET: C0/C8/D0/D8/E0/E8/F0/F8.
- LD A,(addr) = 0x3A + 3-byte addr. LD (addr),A = 0x32 + 3-byte addr.
- LD HL,(addr) = 0x2A + 3-byte addr. LD (addr),HL = 0x22 + 3-byte addr.
- CP imm8 = 0xFE. OR A = 0xB7. XOR A = 0xAF.
- PUSH/POP: BC=C5/C1, DE=D5/D1, HL=E5/E1, AF=F5/F1.
- LDIR = ED B0 (copy BC bytes from HL to DE). LDDR = ED B8.
- BIT n,(IY+d) = FD CB dd 46+8*n.

## Known Related Addresses
- D00338 = edit buffer BC metadata (written immediately after this call returns)
- D00335 = edit buffer end pointer (written with '}' + NUL after this call)
- D02712 = edit-mode type code (set earlier in 0x097C8A)
- D02695 = list iteration pointer (used after this call)
- D02718 = list iteration metadata
