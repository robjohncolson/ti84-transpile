# Task: Decode the Mode Flag Decision Tree at 0x02FECF — Disassemble 0x02FFF6 and 0x0300CB alternate dispatch paths

## Context
TI-84 Plus CE ROM transpilation project. ROM file at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 395 established that the mode flag decision tree at 0x02FECF works as follows:
- 0x02FECF: BIT 3,(IY+0x12) → JP NZ 0x02FFF6 (key dispatch mode path)
- Then: BIT 4,(IY+0x12) → JP NZ 0x0300CB (graph mode path)
- Then: CP 0x36 → SET 3 + CALL 0x02237E (enter key dispatch mode)

IY+0x12 flags byte is fully mapped (session 394):
- Bit 3 = key dispatch mode (8 ops across ROM)
- Bit 4 = graph mode active (21 ops, 2nd heaviest)

4. For each path, report:
   - What RAM addresses are read/written

5. Cross-reference: do either path reference kbdKey (0xD0058C), kbdToken (0xD0058E), or the translation table (0x09F79B)?

## Technical: eZ80 instruction encoding
- eZ80 is Z80-compatible with 24-bit extensions
- Standard Z80 opcodes apply. Key patterns:
  - CB xx = bit operations (BIT/SET/RES)
  - FD CB dd xx = IY+d bit operations (dd=displacement, xx=operation)
  - ED xx = extended ops (IN/OUT, block moves, etc.)
  - CD xx xx xx = CALL addr24 (3-byte address, little-endian)
  - C3 xx xx xx = JP addr24
  - 18 xx = JR offset (signed 8-bit relative)
  - 20/28/30/38 xx = JR NZ/Z/NC/C offset
  - C2/CA/D2/DA xx xx xx = JP NZ/Z/NC/C addr24
  - C4/CC/D4/DC xx xx xx = CALL NZ/Z/NC/C addr24
  - 3E xx = LD A,imm8
  - 21 xx xx xx = LD HL,imm24
  - 11 xx xx xx = LD DE,imm24
  - 01 xx xx xx = LD BC,imm24
  - DD = IX prefix, FD = IY prefix
  - In ADL mode (default), addresses are 3 bytes
