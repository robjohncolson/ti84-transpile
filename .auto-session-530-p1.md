# Task: Decode 0x07D27B extended (matrix/list FP handler continuation past 100B)

## Context
This is a TI-84 Plus CE ROM transpilation project. We're decoding eZ80 machine code from ROM.rom into documented JavaScript.

Session 529 decoded 0x07D27B to about 0x07D2DE (the first ~100 bytes). The function continues past that point. We need to read 0x07D2DE through at least 0x07D380 (another ~160 bytes) to find the RET and complete the function.

## What to do

1. Create a probe file `TI-84_Plus_CE/probe-phase530-decode-07D27B-extended.mjs` that:
   - Reads ROM bytes from 0x07D2DE through 0x07D380 (160 bytes)
   - Disassembles them instruction-by-instruction using the same pattern as existing probes
   - Identifies CALL/JP/JR targets
   - Finds the RET that ends the function
   - Also dump any sub-functions called that are nearby

2. Use the same probe template as `TI-84_Plus_CE/probe-phase529-decode-07CBB5-fp-normalize-core.mjs` (read it for reference).

3. Run the probe: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase530-decode-07D27B-extended.mjs`

4. Report what you find — all instructions, CALL targets, the RET location, and purpose analysis.

## Key reference
- ROM file: `TI-84_Plus_CE/ROM.rom`
- eZ80 is little-endian, 24-bit addresses
- Common opcodes: C9=RET, CD=CALL nn, C3=JP nn, 18/20/28/30/38=JR cc,d, ED prefix for eZ80 extensions
- Session 529 findings for 0x07D27B-0x07D2DE are in CONTINUATION_PROMPT_CODEX.md lines 17-25
- The function handles matrix/list FP comparison/arithmetic
- Known sub-functions from phase 3: 0x07CAB9, 0x07CA48, 0x07C8B7, 0x07F9D9, 0x07C71D, 0x07C747, 0x07F8FA, 0x07F920

## Constraints
- Do NOT modify any existing files except creating the new probe
- Do NOT modify cpu-runtime.js, peripherals.js, ez80-decoder.js, or browser-shell.html
- Run the probe ONLY via `node scripts/run-probe.mjs --max-time 180 <probe>` — NEVER bare `node <probe>`

## Success criterion
- Probe runs successfully and prints disassembled instructions
- The RET (or final JP) that ends 0x07D27B is identified
- Total function size determined
