## Reference: eZ80 decoder API
Do NOT use `ez80-decoder.js`. Write a self-contained hand-rolled decoder directly in the probe (like `TI-84_Plus_CE/probe-phase591-decode-07F7A8.mjs`). The decoder reads raw bytes from the ROM buffer. Key patterns:
- `u8(addr)`, `u16(addr)`, `u24(addr)` for reading ROM bytes
- ADL mode: all immediate addresses are 3 bytes (LD rr,nn = 4 bytes, CALL nn = 4 bytes, JP nn = 4 bytes)
- ED-prefix opcodes: use mask 0xC7 (not 0xCF) for LD rp,(nn) group
- CB-prefix for bit/rotate ops, DD/FD for IX/IY indexing
- Relative jumps (JR/DJNZ): target = addr + instruction_length + signed_displacement
