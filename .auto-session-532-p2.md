# Task: Decode ROM function at 0x07CFA7 — Type 0x20/0x21 Handler

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). We decode ROM functions by writing probe scripts that disassemble bytes from the ROM and annotate them.

## What we know about 0x07CFA7
- Called from 0x0686A8 (type sub-dispatch, session 531) for types 0x20 and 0x21
- Type 0x20 = equation, Type 0x21 = string (TI-OS type codes)
- The type sub-dispatch at 0x0686A8: `CP 0x20 → JP Z,0x07CFA7. CP 0x21 → JP Z,0x07CFA7.`
- So both equation and string types route to this same handler
- Located in the FP math region near matrix/list handlers

## Nearby decoded functions for reference
- 0x07CF1A: Matrix type 0x1C handler (also called from 0x0686A8 — your sibling, being decoded in parallel)
- 0x07CE79/0x07CE86: Dimension check functions (called from 0x07D27B matrix/list handler)
- 0x07D27B: 519B matrix/list FP statistical computation (session 530)
- 0x0686A8: Type sub-dispatch (session 531) — the caller
- 0x06868A: Type validation dispatcher (session 531) — parent of 0x0686A8

## eZ80 instruction reference (key opcodes)
- ED 67 = RRD, ED 6F = RLD
- 27 = DAA
- FD CB xx yy = IY-indexed bit operations
- ED 44 = NEG
- ED A1 = CPI, ED B1 = CPIR
- Standard Z80: LD, ADD, SUB, AND, OR, XOR, CP, JR, JP, CALL, RET, PUSH, POP, INC, DEC, BIT, SET, RES
