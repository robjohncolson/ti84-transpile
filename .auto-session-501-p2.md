# Task: Decode 0x0264B1 Call Chain — VRAM Address Computation

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 CPU).

**Key finding from session 500**: 0x05E4F2 is a save/restore wrapper that saves D001A8, D008D2, D008D5 to stack, then calls 0x0264B1, then restores them. 0x0264B1 is the cursor row iteration function. It loads from D02440/D0243D, loops calling 0x05E386 while D001A8 < D001F1, then calls 0x025C33. The VRAM address computation happens somewhere in this chain: 0x05E386 → 0x025C33 → 0x0263D5.

**Goal**: Decode the inner functions in the 0x0264B1 call chain to find the row/col → pixel formula that computes VRAM addresses stored in D008D2/D008D5.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase501-decode-0264B1-chain.mjs` that:

1. **Static disassembly of 0x0264B1**: Read ROM bytes, decode eZ80 instructions until RET or 150+ bytes. Print address, hex, mnemonic for each instruction.

2. **Static disassembly of 0x05E386**: Same treatment. This is called in the loop inside 0x0264B1.

3. **Static disassembly of 0x025C33**: Same treatment. Called after the loop.

4. **Static disassembly of 0x0263D5**: Same treatment (if referenced from above functions).

5. **For each function**: identify all CALL/JP targets, and note any references to:
   - D008D2 (VRAM base low), D008D5 (VRAM base high)
   - D00595 (cursor row), D00596 (cursor col)
   - D001A8, D001F1 (loop bounds)
   - D02440, D0243D (loaded by 0x0264B1)
   - Any multiplication or shift patterns (SLA, SRL, ADD HL,HL, etc.) that suggest pixel coordinate computation

6. **Summary**: Which function actually computes the VRAM address? What's the formula?

## Technical details
- ROM file: `TI-84_Plus_CE/ROM.rom` — load with `fs.readFileSync`
- eZ80 is little-endian, 24-bit addresses stored as 3 bytes (low, mid, high)
- Common patterns:
  - `CD xx xx xx` = CALL addr
  - `C3 xx xx xx` = JP addr  
  - `C9` = RET
  - `FD CB xx xx` = IY+offset bit ops
  - `3A xx xx xx` = LD A,(addr)
  - `32 xx xx xx` = LD (addr),A
  - `2A xx xx xx` = LD HL,(addr)
  - `22 xx xx xx` = LD (addr),HL
  - `CB 25` = SLA L (shift left = multiply by 2)
  - `29` = ADD HL,HL (double HL)
  - IY = 0xD00080
