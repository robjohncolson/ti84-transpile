# Task: DECODE 0x07DBC2 — Called by 0x0997E3 before type validation

## Context
You are working on TI-84 Plus CE ROM transpilation. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). We are decoding OS functions by writing probe scripts that disassemble ROM bytes directly from the binary.

## What we know
- 0x07DBC2 is called by 0x0997E3 (which is a sub-function: CALL 0x07DBC2 + CALL 0x08021B + RET NC, 10 bytes)
- 0x0997E3 is called from 0x0997AE (conditional FP save/restore wrapper, ~53B)
- 0x0997AE is in the FP context save chain (saves OP2 D00603 around sub-calls, gates on IY+0x53 bits 7/6)
- 0x08021B (type range validator) follows 0x07DBC2 in the call chain — it checks D005F8 type code
- Key RAM: D005F8 = FP accumulator sign/flags, D00603 = OP2 start, D02B39 = OP2 save buffer

## Your task
1. Create a probe `TI-84_Plus_CE/probe-phase525-decode-07DBC2-fp-sub.mjs` that:
   - Reads the ROM binary from `TI-84_Plus_CE/ROM.rom`
   - Disassembles starting at 0x07DBC2 for up to 0x400 bytes (main function) and 0x80 bytes (sub-calls)
   - Follows eZ80 opcodes: CALL (0xCD xx xx xx = 4B), JP (0xC3 xx xx xx = 4B), JR (0x18/0x20/0x28/0x30/0x38 + rel8 = 2B), RET (0xC9), conditional rets, LD r,imm, LD r,(addr), LD (addr),r, PUSH/POP, BIT/SET/RES, CP, AND/OR/XOR, INC/DEC, ADD/SUB, SBC, ADC
   - For IX/IY prefixes (0xDD/0xFD): handle LD IX/IY, ADD IX/IY, PUSH/POP IX/IY, LD (IX+d)/LD (IY+d), BIT/SET/RES (IX+d)/(IY+d)
   - For .SIS prefix (0x40): next instruction uses 16-bit addressing in ADL mode
   - For ED prefix (0xED): SBC HL,rr, ADC HL,rr, LDIR (0xB0), LDDR (0xB8), CPIR (0xB1), IN/OUT, MLT
   - Tracks: all CALL targets, JP targets, RAM reads (≥0xD00000), RAM writes, carry/zero flag events
   - Prints a disassembly listing with hex bytes + mnemonics
   - Recurses into sub-calls (up to SUB_LIMIT bytes each)
   - Prints summary: CALL targets, RAM addresses, flag usage
2. Use the probe template style from session 524 probes (see `TI-84_Plus_CE/probe-phase524-decode-08021B-type-op.mjs` for reference)

## Deliverable
The file `TI-84_Plus_CE/probe-phase525-decode-07DBC2-fp-sub.mjs` — a standalone Node.js ES module probe.

## Success criterion
Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase525-decode-07DBC2-fp-sub.mjs`
It should print a disassembly listing for the function at 0x07DBC2, showing all instructions, CALL targets, RAM references, and flag operations. The function likely operates on FP accumulators since it's called before type validation.
