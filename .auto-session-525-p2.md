# Task: DECODE 0x09953F — Conditional test after FP save on type-init success

## Context
You are working on TI-84 Plus CE ROM transpilation. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). We decode OS functions by writing probe scripts that disassemble ROM bytes directly.

## What we know
- 0x09953F is called from 0x0987B7 (type-specific initializer) on the SUCCESS path after:
  - 0x0997AE (setup) succeeds
  - 0x08021B (type range validator) succeeds (no carry)
  - 15-byte stack frame allocated (PUSH IX, LD IX,0, ADD IX,SP, etc.)
  - 0x0989E9 (FP save to stack frame: saves OP1 D005F8→IX-9, OP2 D00603→IX-18) completes
- Then CALL 0x09953F is made — if it returns CARRY, the init fails (calls 0x098A13 cleanup, jumps to secondary dispatch)
- If no carry, success path continues: POP AF → CALL 0x099574 → CALL 0x098A13 → cleanup → RET
- Key RAM: D005F8 = OP1/FP sign+flags, D00603 = OP2, IX-9/IX-18 = saved FP values on stack frame
- 0x098A3D = frame offset calculator (13B), 0x07F978 = 11-byte FP copy

## Your task

   - IX/IY prefixes (0xDD/0xFD), .SIS prefix (0x40), ED prefix, CB prefix (bit ops)
   - LD (IX+d),r / LD r,(IX+d), BIT/SET/RES with IX/IY
   - Tracks CALL targets, JP targets, RAM reads/writes (≥0xD00000), carry/zero flag operations
   - Prints disassembly listing + summary
