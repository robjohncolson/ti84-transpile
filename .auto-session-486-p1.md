# Task: Capture All 3 Cursor Glyph Pixel Shapes (0xE1, 0xE2, 0xE3)

## Context

The TI-84 Plus CE ROM transpilation project has decoded the cursor glyph selector at 0x030202 (session 485). The function returns one of three cursor glyph codes based on D00092 bits 3/4/5:

- D00092=0x08 (bit 3 set) → returns 0xE1 (thin cursor)
- D00092=0x10 (bit 4 set) → returns 0xE2 (underline cursor)
- D00092=0x30 (bits 4+5 set) → returns 0xE3 (block cursor)

Session 483 already captured the pixel grid for 0xE1 (14×10 block with hollow interior, 104 pixels).

## Goal

Create a probe that renders the cursor with each of the three D00092 settings to capture the pixel grids for all three cursor styles. For each style:
1. Set D00092 to the correct value
2. Run the idle loop so the cursor blink path (0x030173) fires
3. Capture the VRAM diff (which pixels changed)
4. Print the pixel grid (row/col layout based on VRAM addresses)

## Implementation

Create file: `TI-84_Plus_CE/probe-phase486-cursor-glyph-shapes.mjs`

The probe should:

1. **Use the EXACT same boot and setup as `probe-phase483-cursor-pixels.mjs`**: Load ROM, load transpiled blocks, create executor with `createPeripheralBus({ timerInterrupt: false })`, 3-stage boot (z80 at 0x000000/20K steps, adl at 0x08C331/200K steps, adl at 0x0802B2/200K steps).

2. **Run 3 experiments**, one for each cursor style:
   - Experiment 1: `mem[0xD00092] = 0x08` → expect 0xE1 thin cursor
   - Experiment 2: `mem[0xD00092] = 0x10` → expect 0xE2 underline cursor
   - Experiment 3: `mem[0xD00092] = 0x30` → expect 0xE3 block cursor

3. For each experiment:
   - Reset VRAM to 0xFF (white) between experiments: `mem.fill(0xFF, 0xD40000, 0xD65800)`
   - Set `mem[0xD00000] = 0x00` (idle path)
   - Set `mem[0xD000C6] |= 0x01` (enable display update)
   - Set `mem[0xD00089] |= 0x10` (bit 4)
   - Set cursor position: `mem[0xD00595] = 0x00`, `mem[0xD00596] = 0x00`
   - Set the D00092 value for this experiment
   - Run idle loop at 0x02FDBE for up to 5 iterations (intercept at 0x02FE21, re-enter at 0x02FDBE, reset SP to STACK_RESET_TOP-3 each time, refresh D000C6 bit 0 each iteration)
   - After iterations, collect VRAM diff (changed bytes relative to 0xFF background)

4. **Output per experiment**:
   - D00092 value, expected glyph code
   - Total VRAM bytes changed
   - Pixel grid: compute row = `(addr - 0xD40000) / 640`, col = `((addr - 0xD40000) % 640) / 2` for each changed pixel. Print a visual grid showing which pixels changed.
   - VRAM address range (first/last changed)

5. **Summary**: Print a comparison table of all 3 glyph shapes.
