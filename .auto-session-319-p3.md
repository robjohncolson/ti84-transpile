# Task: Investigate State 0x00 (Switch-to-Screen) in D177B9 Dispatch

## Context

You're working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 24-bit addressing).

Session 318 decoded the D177B9 state map. State 0x00 = "switch-to-screen" has 41 callers (the most of any state), dispatches key codes 0x01-0x05. Critically, state 0x00 does NOT appear in the _seqcase dispatch tables for exit_state or process_key — it's a special state used to initiate screen transitions.

The two key dispatch functions are:
- 0x049CCA (flash ROM copy, 166 callers) 
- 0x00883C (low ROM copy, 78 callers)

Both have the signature: `dispatch_key(key_code, new_state)` where `new_state` is written to D177B9.

## Task

1. **Find all 41 callers that pass state=0x00 to dispatch_key.** Search the ROM for CALL 0x049CCA and CALL 0x00883C instructions where the `new_state` parameter (loaded into a register before the call) is 0x00. The calling convention has the state in `(IX+9)` at the call site — look for `LD (IX+9), 0x00` or equivalent register setup patterns within ~20 bytes before each CALL.

2. **Trace what happens when state=0x00 is active.** Since 0x00 is NOT in the _seqcase tables:
   - What does exit_state do for state 0x00? (falls through to default case)
   - What does process_key do for state 0x00? (falls through to default case)
   - Disassemble the default case handlers for both exit_state and process_key

3. **Determine if state 0x00 is the main event loop entry point.** Does the OS boot into state 0x00? What state is D177B9 initialized to?

4. **Map the key codes 0x01-0x05.** What do these 5 key codes trigger? Do they map to Home/Y=/Window/Zoom/Trace as hypothesized?

## Deliverables

1. Create `TI-84_Plus_CE/probe-phase319-state-0x00-switch.mjs` — a probe that:

   - All assertions pass

2. Create `TI-84_Plus_CE/phase319-state-0x00-switch-report.md` with findings.

## Technical Details

- CALL instruction on eZ80: `CD xx xx xx` (4 bytes: opcode + 3-byte LE target)
- To find CALL 0x049CCA: search ROM for bytes `CD CA 9C 04`
- To find CALL 0x00883C: search ROM for bytes `CD 3C 88 00`
- D177B9 address in ROM bytes (LE): `B9 77 D1`
- The _seqcase format: `[u16 count][u24 base][count×u24 targets][u24 default]`
- exit_state for flash dispatch is at 0x0499CC, for low ROM at 0x0085EF
- process_key for flash dispatch is at 0x049A3A, for low ROM at 0x008651
