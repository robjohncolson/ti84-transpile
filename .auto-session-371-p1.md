# Task: Add Coldboot Runtime Mode to Browser Shell

## Context
The TI-84 Plus CE ROM transpilation project has a browser shell at `TI-84_Plus_CE/browser-shell.html`. It currently supports two runtime modes: RUNTIME_MODE_DIRECT and RUNTIME_MODE_COORMON. Session 370 confirmed that with `timerInterrupt:true` and `iff1=1`, the OS event loop runs continuously without HALT — the timer fires 995 times in 200K steps via RST 38h at 0x000038. The rAF loop should be able to drive this continuously.

## Deliverable
Add a new "Coldboot" runtime mode to `TI-84_Plus_CE/browser-shell.html` that:

1. **Adds a new radio button** in the runtime mode selector (near the existing CoorMon checkbox). Label it "Coldboot" or "OS Event Loop". The user picks this mode before clicking Boot.

2. **Boot sequence** when Coldboot mode is selected:
   - Phase 1: `runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })` — Z80 cold boot
   - Phase 2: `runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })` — Kernel init
   - Phase 3: `runFrom(0x0802B2, 'adl', { maxSteps: 100, maxLoopIterations: 32 })` — Post-init
   - Set up event loop state: `cpu.halted = false; cpu.iff1 = 1; cpu.iff2 = 1; cpu.f = 0x40; cpu._ix = 0xD1A860; cpu._iy = 0xD00080; cpu.sp = STACK_RESET_TOP - 12;` and fill SP region with 0xFF
   - Initialize OS event loop RAM: `mem[0xD02AD7] = 0xBE; mem[0xD02AD8] = 0x19; mem[0xD02AD9] = 0x00; mem[0xD0009B] |= 0x40;`
   - Set `lastPc = 0x003A73; lastMode = 'adl';`

3. **Create peripherals with timerInterrupt:true**: `createPeripheralBus({ pllDelay: 2, timerInterrupt: true })`. This is the KEY difference — the timer fires via RST 38h and keeps the event loop alive.

4. **AutoRun frame loop** for Coldboot mode:
   - Each rAF frame calls `executor.runFrom(lastPc, lastMode, { maxSteps: STEPS_PER_FRAME, maxLoopIterations: 10000 })`
   - Update `lastPc`, `lastMode`, `totalSteps` from result
   - Call `syncLCDState()`, `lcd.renderFrame()`, `updateRegs()`, etc.
   - Do NOT check for HALT termination — timer keeps the loop alive
   - Use a step budget per frame (e.g., 50000 steps per frame)

5. **Keyboard integration**: The existing keyboard manager (`kbd`) should already set the key matrix in peripherals. The event loop reads the keyboard via _GetCSC.

## Key constants (from existing probes)
- `STACK_RESET_TOP = 0xD1A87E` (used in the keypress probe at line 13 of probe-phase370-keypress-event-loop.mjs — but note the actual value: look for `STACK_RESET_TOP` or `0xD1A87E` or `0xD1A87B` in the browser shell)
- Event loop entry: `0x003A73`
- Timer ISR fires through RST 38h at `0x000038`
- IY must be `0xD00080` for the OS
