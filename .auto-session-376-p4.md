# Auto-Session 376 P4: Disassemble 0x0067F8 Key Dispatch Entry

## Context

The function at 0x0067F8 is the key processing entry point reached after both dispatch gates pass at 0x001713. From session 375's trace:
- 0x003A7D → CALL 0x001713
- 0x001713 passes gate 1 (flash test) and gate 2 (system flag)  
- 0x001713 eventually calls 0x0067F8
- 0x0067F8 pushes IX, calls 0x001C4F, then routes through the table scan at 0x001C33

We need a detailed disassembly to understand:
- How the scan code (in A register from _GetCSC) gets passed to the table lookup
- What 0x001C4F does (it seems to be the table scan entry)
- How the scan code maps to table entries
- What happens on a successful match (where does execution go?)
