# Task: Patch GetCSC return value for keyboard input

## Context
This is a TI-84 Plus CE ROM transpilation project. The OS ROM is lifted to JavaScript blocks. We need keyboard input to work in the CoorMon event loop.

**GetCSC** (the OS key-scan function) at address 0x042366 reads a certificate descriptor at ROM address 0x3B0033, which always contains 0x00 (no key). Specifically, at PC=0x04236E it does `LD A,(HL)` where HL=0x3B0033, then `AND 0x3F`.

The ROM write-protect in `cpu-runtime.js` only applies to `cpu.write8()`/`write16()`/`write24()` calls. The underlying `mem` Uint8Array is directly writable: `mem[0x3B0033] = scanCode`.

## Deliverable
Create `TI-84_Plus_CE/probe-phase337-getcsc-patch.mjs` that:

1. Boots the OS using the standard 2-phase boot sequence (same as probe-phase336-cxmain-boot.mjs):
   - Phase 1: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
   - Phase 2: `executor.runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })`
   - After boot: set `cpu.mbase = 0xD0; cpu.iy = 0xD00080; cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;`
   - Reset stack: `cpu.sp = 0xD1A87E; cpu.sp -= 3; write24(mem, cpu.sp, 0xFFFFFF);`

2. Installs the home handler: `write24(mem, 0xD007CA, 0x058241)` (cxMain = home handler)

3. **TEST A — Direct mem write approach**: Before calling CoorMon, write `mem[0x3B0033] = 0x09` (ENTER scan code). Then run CoorMon from 0x08BF22 with max 50000 steps. Use `onBlock` callback to track:
   - Whether PC hits 0x08BF3C (the key-dispatch branch point)
   - The value of `cpu.a` at that point (should be 0x09 if patch worked, 0x00 if not)
   - Whether PC hits 0x08BF68 (the key-present JR NZ target)
   - All unique block PCs visited
   - Termination reason and final PC

4. **TEST B — Intercepted read8 approach**: Boot fresh, install cxMain. Monkey-patch `cpu.read8` to return 0x09 when `addr === 0x3B0033` (otherwise delegate to original). Run CoorMon. Track same metrics as Test A.

5. **TEST C — Post-block A register override**: Boot fresh, install cxMain. Use `onBlock` to detect when PC enters the block containing 0x04236E (the GetCSC LD A,(HL) instruction). On the NEXT block after that, set `cpu.a = 0x09`. Run CoorMon. Track same metrics.

6. Print a summary of all 3 approaches:
   - Which approach(es) made GetCSC "return" a non-zero scan code
   - Whether 0x08BF3C was reached with A != 0
   - Whether 0x08BF68 (key-present branch) was taken
   - How far CoorMon got (unique blocks, last PC, steps)
