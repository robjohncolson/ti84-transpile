# Auto-Session 247 — P1: Trace 0x0003B0 (called by 0x027111, stalls at 0x006202)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript and executed in a custom eZ80 runtime. We trace OS functions by running transpiled blocks step-by-step.

Session 245 traced 0x027111 (screen-redraw routine) which calls 0x0003B0 after clearing D02A86. Execution gets stuck at 0x006202 — a tight delay loop (OR A / SBC HL,DE / JR NZ — ~35K iterations). Session 246 confirmed 0x0270F3 (also called by 0x027111) is a CPU clock speed switcher using port I/O. 0x0003B0 is likely a similar hardware-level routine.

## Task
Write a probe file `TI-84_Plus_CE/probe-phase247-0003b0-trace.mjs` that:

1. Boots the TI-84 runtime (use the pattern from existing probes)
2. Calls the transpiled block at 0x0003B0 with default boot state
3. Traces execution for 200 steps, logging each block PC visited
4. Records any port I/O (IN/OUT instructions), memory writes to key RAM areas
5. Checks if 0x006202 is visited and how many times (this is the stall point)
6. Tries a second run with 5000 steps to see if it eventually completes or truly loops forever
7. Reports: function purpose, port accesses, whether it returns, total unique blocks

## Probe Pattern (use this exact boot sequence)
```javascript
import { readFileSync } from 'fs';
import { gunzipSync } from 'zlib';

// Load ROM
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

// Load transpiled JS
let transpiledSrc;
try { transpiledSrc = readFileSync('TI-84_Plus_CE/ROM.transpiled.js', 'utf-8'); }
catch { transpiledSrc = gunzipSync(readFileSync('TI-84_Plus_CE/ROM.transpiled.js.gz')).toString(); }

// Create runtime
const { createCPU } = await import('./TI-84_Plus_CE/cpu-runtime.js');
const { createPeripheralBus } = await import('./TI-84_Plus_CE/peripherals.js');

const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(peripherals);

// Load ROM into memory
for (let i = 0; i < rom.length; i++) cpu.mem[i] = rom[i];

// Install transpiled blocks
const blockMap = {};
const installBlock = (addr, fn) => { blockMap[addr] = fn; };
const mod = { installBlock };
new Function('installBlock', transpiledSrc)(installBlock);

// MBASE = 0xD0
cpu.mbase = 0xD0;

// IY = 0xD00080 (standard OS IY)
cpu.iy = 0xD00080;
```

Then step through blocks: set cpu.pc, look up blockMap[cpu.pc], call it with cpu, record the visited PC, repeat for N steps. Use a sentinel return address on the stack to detect function return.
