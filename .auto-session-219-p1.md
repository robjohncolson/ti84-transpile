# Session 219 P1: Investigate 0xD003E0 BIT 3 gate — what sets it during normal OS operation

## Context

In the TI-84 Plus CE ROM transpilation project, session 218 decoded parent function 0x04EB3E which is called via a pointer table at 0x04EAED. This function dispatches on the A register to reach enter-edit paths (A=0x02 → 0x04EC1C, A=0x0E → 0x04EC1C). However, there is a **BIT 3 gate** at address (HL=0xD003E0) that causes early RET Z if BIT 3 is CLEAR — blocking ALL enter-edit paths.

Session 218 confirmed that with BIT 3 CLEAR, the function returns immediately for all A values. With Z=1 forced at the JP Z 0x04EB82, enter-edit succeeds.

**We need to find what sets BIT 3 at RAM address 0xD003E0 during normal OS operation**, so we understand the natural arming path.

## Task

Build probe `TI-84_Plus_CE/probe-phase219-d003e0-bit3-setters.mjs` that:

### Part A: Static ROM scan
Scan `ROM.rom` (binary file at `TI-84_Plus_CE/ROM.rom`, 4MB) for all instructions that SET, RES, or BIT test bit 3 at address 0xD003E0. Also scan for direct `LD (0xD003E0),A` or `LD (0xD003E0),r` writes, and for any instruction that writes to 0xD003E0 via pointer (LD (HL),A where HL=0xD003E0 won't show up statically, but LD instructions with absolute addresses will).

The IY base is 0xD00080, so 0xD003E0 = IY + 0x360 (too large for IY-indexed — IY offsets are signed 8-bit, -128 to +127). So 0xD003E0 is NOT IY-indexed. Look for:
- Direct absolute address references: search for bytes `E0 03 D0` (little-endian 0xD003E0) in the ROM
- IX-indexed if IX points near there, but IX is typically 0xD1A860 so no
- HL-indirect won't show statically

For each reference found, classify as READ, WRITE, BIT_TEST, SET, RES, or POINTER, and print the ROM address and surrounding instruction context.

### Part B: Boot trace
After full boot (z80 boot + kernelInit + postInit + memInit), check RAM at 0xD003E0. Report what value it has. Is BIT 3 already set after boot?

### Part C: Homescreen trace  
After boot, run all 4 homescreen stages (same pattern as other probes — stages 1-4 with IX=0xD1A860). Then check 0xD003E0 again. Does the homescreen setup arm BIT 3?

### Part D: Write watchpoint
If BIT 3 is NOT set after boot+homescreen, set up a write watchpoint: instrument the executor to detect when address 0xD003E0 is written during a 5000-step trace from the event loop entry at 0x082BE2. Report which block writes to it and what value.
