## Task
Edit `TI-84_Plus_CE/browser-shell.html` to add the following regression commands as direct-eval template handlers:

### 1. QuadReg — Quadratic Regression [0xBB, 0xF5]
- Input: QuadReg L1, L2 (two lists of equal length, ≥3 elements)
- Output: a, b, c coefficients of y = ax² + bx + c (least-squares fit)
- Also compute R² (coefficient of determination)
- Method: Normal equations (X^T X)^(-1) X^T Y where X = [x², x, 1]

### 2. ExpReg — Exponential Regression [0xBB, 0xF6]
- Input: ExpReg L1, L2
- Output: a, b coefficients of y = a·b^x
- Method: LinReg on (x, ln(y)), then a = exp(intercept), b = exp(slope)
- R² from the linearized fit

### 3. PwrReg — Power Regression [0xBB, 0xF7]
- Input: PwrReg L1, L2
- Output: a, b coefficients of y = a·x^b
- Method: LinReg on (ln(x), ln(y)), then a = exp(intercept), b = slope
- R² from the linearized fit

### 4. LnReg — Logarithmic Regression [0xBB, 0xF8]
- Input: LnReg L1, L2
- Output: a, b coefficients of y = a + b·ln(x)
- Method: LinReg on (ln(x), y)
- R² from the fit

### 5. LogisticReg — Logistic Regression [0xBB, 0xF9] (optional, lower priority)
- Input: LogisticReg L1, L2
- Output: a, b, c coefficients of y = c/(1 + a·e^(-bx))
- Method: Iterative (Newton-Raphson or Levenberg-Marquardt). If too complex, skip this one.

## Implementation pattern
