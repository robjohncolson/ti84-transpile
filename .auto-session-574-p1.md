# Task: SCAN 0x0A1FB5 CALLERS — second entry point of scroll buffer swap

## Context

The scroll buffer swap function at 0x0A1FAB-0x0A1FD0 (38 bytes) has TWO entry points:
- 0x0A1FAB: copies D031F6→D07396 (primary to secondary scroll buffer)
- 0x0A1FB5: copies D07396→D031F6 (secondary to primary scroll buffer)

Session 572 found 1 caller of the combined function (CALL at 0x0A1FE4 which checks IY+0x49 bit 6 and IY+0x28 bit 4 before calling). But that analysis only checked for CALL 0x0A1FAB. The SECOND entry point 0x0A1FB5 may have its own separate callers.

## Deliverable

Create a probe at `TI-84_Plus_CE/probe-phase574-scan-0A1FB5-callers.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom` (4MB, load with `fs.readFileSync`)
2. Scans for all CALL/JP instructions targeting 0x0A1FB5:
   - CALL nn: bytes `CD B5 1F 0A` (little-endian 24-bit address on eZ80)
   - JP nn: bytes `C3 B5 1F 0A`
   - Also check for CALL cc,nn variants: `C4/CC/D4/DC/E4/EC/F4/FC` followed by `B5 1F 0A`
3. For each hit, print the ROM offset where the CALL/JP instruction starts
4. Also scan for 0x0A1FAB callers the same way (bytes `AB 1F 0A`) for completeness
5. Also scan for 0x0A1FE4 callers (the wrapper that session 572 found) — bytes `E4 1F 0A` after CD/C3/C4/CC/D4/DC/E4/EC/F4/FC

Print all results clearly labeled.
