# Auto-Session 197 P2: Trace upstream caller that pushes BC before LDDR subroutine at 0x09224B

## Context

In session 196, we corrected the LDDR BC source at 0x092263. The LDDR block is inside parent block `09224b:adl`. The sequence is:
```
PUSH HL → ADD HL,DE → DEC HL → PUSH HL → ADD HL,BC → EX DE,HL → POP HL → POP BC → JR Z,0x092265 → LDDR
```

BC comes from `POP BC` at 0x092260 — meaning it was pushed by the CALLER of this subroutine before entering block 0x09224B. The LDDR copies BC bytes backward (HL→DE). With seeded L1={1,2,3}, the correct BC should be 27 (3 elements × 9 bytes each). Currently BC=0xEAF5 which is wrong — the caller isn't setting up BC correctly.
