# Task: Extend Boot to 50K Steps With Loop Detection

## Context
The TI-84 Plus CE ROM transpilation project boots from 0x000000 in z80 mode. Session 352 showed 270 unique blocks at 10K steps with zero missing blocks. The boot enters a steady-state loop. We need to confirm the loop is truly stable at 50K steps and measure its exact cycle length.

## What You Must Do
Create a probe `TI-84_Plus_CE/probe-phase353-boot-50k-loop.mjs` that:

1. Boots from 0x000000 in z80 mode with `{ pllDelay: 2, timerInterrupt: false }` for 50,000 steps (MAX_STEPS = 50000)
2. Tracks unique blocks discovered over time: report unique block count at steps 1000, 5000, 10000, 20000, 30000, 40000, 50000
3. Records the LAST step at which a NEW unique block was first discovered (the "plateau step")
4. At steps 9000-9050, records the exact sequence of block PCs visited (51 entries). This captures the loop pattern.
5. Computes the loop cycle length: starting from step 9000, find the smallest N such that `blockSequence[i] === blockSequence[i+N]` for all i in [9000, 9000+N]. That's the cycle length.
6. Lists ALL blocks that participate in the loop cycle (the set of unique PCs in one full cycle)
7. Reports which blocks are "hot" (visited most in 50K steps) — top 10 by visit count
8. For each block in the loop cycle, reports any port I/O that occurs (reads and writes) by wrapping peripherals.read/write

Boot: load ROM into mem (Uint8Array, 0x1000000 bytes, copy ROM at offset 0), `new EZ80CPU(mem)`, `createPeripheralBus({ pllDelay: 2, timerInterrupt: false })`, wire `cpu.portRead = peripherals.read; cpu.portWrite = peripherals.write`, `cpu.pc = 0; cpu.adl = 0`.

Transpiled ROM: `const mod = await import(pathToFileURL(TRANSPILED_PATH).href); const blocks = mod.default || mod.blocks || mod;`

Step loop:
```javascript
const blockSequence = []; // stores PC at each step
const visitCounts = new Map(); // block key -> count
const uniqueByStep = []; // [step, uniqueCount] milestones

for (let step = 0; step < MAX_STEPS; step++) {
  const key = blockKey(cpu.pc, cpu.adl ? 'adl' : 'z80');
  blockSequence.push(cpu.pc);
  visitCounts.set(key, (visitCounts.get(key) || 0) + 1);
  
  // Record milestones
  if ([1000,5000,10000,20000,30000,40000,50000].includes(step)) {
    uniqueByStep.push([step, visitCounts.size]);
  }
  
  const block = blocks[key];
  if (!block) { console.log(`missing_block at step ${step}: ${key}`); break; }
  block(cpu, mem);
}
```

Helper: `function blockKey(pc, mode) { return (pc >>> 0).toString(16).padStart(6, '0') + ':' + mode; }`

**Important**: `blockSequence` at 50K entries is ~400KB of numbers — that's fine for Node.js. But for cycle detection, only analyze the segment from step 9000 onward.
