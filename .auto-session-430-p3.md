## How to read ROM bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Read byte at address addr: rom[addr]
// Read 3-byte LE address: rom[addr] | (rom[addr+1] << 8) | (rom[addr+2] << 16)
// eZ80 CALL nn: 0xCD + 3-byte LE target
// eZ80 IN A,(C): 0xED 0x78 (reads port from BC)
// eZ80 OUT (C),A: 0xED 0x79 (writes port from BC)
// eZ80 LD BC,nn: 0x01 + 3-byte LE immediate (sets port address for IN/OUT)
// eZ80 PUSH nn: various opcodes for pushing immediates/registers
```

- 0xC0-0xC4: Vendor-specific requests with device recipient
