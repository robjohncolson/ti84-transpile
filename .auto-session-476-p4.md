# Task: Find cursor VRAM address variable (D00591 is timer, not address)

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 binary).

## Background
Session 475 CORRECTED session 474: D00591 is a CURSOR BLINK TIMER (set to 0x000049/0x0000F1/0x0001E1 by 0x040D11), NOT a cursor VRAM address. The actual cursor VRAM address must be stored elsewhere. Known cursor-related variables:
- D0058C = cursor column
- D0058E = cursor row
- D00590 = cleared to 0 by 0x040D11 (timer related)
- D00591-D00593 = cursor blink timer (3 bytes, 24-bit value)
- D00595 = display cursor position (507 references, used with 0x0059C6)

The function 0x04E950 (cursor position save/update) is called from 0x03013A when D00092 bit 4 is set. It likely calculates and stores a VRAM address for the cursor. Also, 0x0059C6 is the display output function that actually writes to VRAM.

## Deliverable
Create `TI-84_Plus_CE/probe-phase476-cursor-address-search.mjs` that does TWO things:

### Part 1: ROM binary search for cursor-area writes
Search the ROM for writes to the D00580-D005A0 region (cursor/display state area):
- LD (D0058C),A = `32 8C 05 D0` (cursor column write)
- LD (D0058E),A = `32 8E 05 D0` (cursor row write)
- LD (D00590),A = `32 90 05 D0`
- LD (D00595),A = `32 95 05 D0` (display cursor write)
- Also LD (addr),HL variants: `22 xx 05 D0` for any xx in 0x80-0xA0
- Also IY-relative: D0058C = IY+0x10C from IY=D00080... actually IY offsets are 8-bit signed (-128 to +127), so D0058C (offset 0x50C from D00080) is NOT IY-accessible. Skip IY-relative for these.

Report all matches with ROM address and surrounding context (8 bytes before/after).

### Part 2: Decode 0x04E950
Dump 64 ROM bytes starting at 0x04E950 for manual disassembly. Also dump 32 bytes at 0x04E960, 0x04E970, 0x04E980 (in case the function is long).

### Part 3: Decode 0x0059C6 entry
Dump 64 ROM bytes starting at 0x0059C6 to understand how the display output function uses cursor position to compute VRAM addresses.

### Part 4: Search for VRAM base address references
The TI-84 CE VRAM starts at 0xD40000. Search for ROM instructions that load this base:
- LD HL,0xD40000 = `21 00 00 D4` (in ADL mode, 3-byte immediate)
- LD DE,0xD40000 = `11 00 00 D4`
- LD BC,0xD40000 = `01 00 00 D4`

These reveal functions that compute VRAM addresses from cursor position.
