# Task: Trace 0x04EDD9 BIT 0,(HL) test — D003E0 bit 0 behavior

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript and executed via `cpu-runtime.js`.

Session 239 found a previously unknown BIT test site: 0x04EDD9 does `BIT 0,(HL)` where HL points to D003E0. This is part of the shared handler at 0x04EDD0. The known BIT tests on D003E0 are:
- 0x04EABD: BIT 3 (gate for enter-edit paths)
- 0x04EB66: BIT 3 (gate)
- 0x051CF3: BIT 3
- 0x04EDD9: BIT 0 (NEW — found session 239)
- 0x051B84: BIT 4 (NEW — found session 239)

The shared handler 0x04EDD0 was decoded in session 237: it calls 0x04ECCE → 0x07F984 → 0x08BF22 → 0x09EFDE (VRAM fill), then tests D003E0 bits to decide between 0x0850D1 (display-update) and 0x04E447 (alternate computation).

## Task
Create a probe `TI-84_Plus_CE/probe-phase240-04edd9-bit0-test.mjs` that:

1. **Static analysis**: Read ROM.rom and:
   - Disassemble 0x04EDD0-0x04EE10 (the shared handler region) to see where BIT 0 fits in the instruction flow
   - Identify the exact instruction at 0x04EDD9: is it `BIT 0,(HL)` with HL=D003E0, or `BIT 0,(IY+d)`, or something else?
   - Map the conditional branch: what happens on BIT 0 SET vs CLEAR?
   - Find the JR/JP that follows the BIT test

2. **Dynamic trace — BIT 0 CLEAR (default)**: 
   - Boot CPU, set D003E0=0x00 (all bits clear, the home-screen default)
   - Enter at 0x04EDD0 with proper context (IX=0xD1A860, SP=0xD1A800, push return sentinel)
   - Run for 5000 steps
   - Record the path taken past the BIT 0 test
   - Note which branch is taken (the "normal" home-screen path)

3. **Dynamic trace — BIT 0 SET**:
   - Same setup but seed D003E0 with bit 0 set (value 0x01)
   - Run for 5000 steps
   - Record the DIFFERENT path taken
   - Compare block lists between BIT 0 SET and CLEAR

4. **Report**:
   - Exact disassembly of the BIT 0 test and its conditional branch
   - Path difference between SET and CLEAR
   - What functionality BIT 0 controls (display? computation? mode?)
   - Any new blocks or addresses discovered in the SET path

## eZ80 BIT instruction encoding
- CB 46 = BIT 0,(HL)
- FD CB dd 46 = BIT 0,(IY+d)
- CB 4E = BIT 1,(HL)
- CB 56 = BIT 2,(HL)
- CB 5E = BIT 3,(HL)
