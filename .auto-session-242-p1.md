# Task: Trace post-fill display setup chain 0x0A32F9→0x0A3408→0x0A3404 loop

## Context
In the TI-84 Plus CE ROM transpilation project, session 241 traced the 0x09EFDE VRAM fill lifecycle (102K steps, 429 unique blocks). The post-fill return chain goes:
0x09F001→0x09F736→0x08BFC5→0x0A32F9→0x0A32FF→0x08C308→0x0A331E→0x0A336F→0x0A3383→0x0A338A→0x0A33FB→0x0A3408→0x0A3404

The tail of this chain loops between 0x0A3404 and 0x0A3408 extensively. We need to understand what this display setup loop does after the VRAM fill completes.

## Deliverable
Create a probe file: `TI-84_Plus_CE/probe-phase242-0a32f9-display-chain.mjs`

## What the probe must do
1. Import cpu-runtime, peripherals, ROM loader from the existing codebase (see `TI-84_Plus_CE/probe-phase241-09efde-150k-warm.mjs` for import patterns)
2. Set up warm state: full boot (z80 boot → kernelInit → memInit → homescreen stages 1-4) with IX=0xD1A860, timer interrupts disabled (`createPeripheralBus({ timerInterrupt: false })`)
3. Simulate a key press to get into the 0x04EDD0 handler (digit "1" key code 0x8F at D0058E, trigger the event loop)
4. Run ~5000 steps to get past the VRAM fill, then continue to trace the display setup chain
5. When execution reaches the 0x0A32F9-0x0A3408 range, log:
   - Disassembly of each block (first 8 bytes hex dump + instruction decode)
   - Register state (A, BC, DE, HL, IX, IY, SP) at each block entry
   - Any VRAM writes (addresses 0xD40000-0xD52C00)
   - Any MMIO port reads/writes
   - How many times 0x0A3404↔0x0A3408 loops before exiting
   - What PC value the loop exits to
6. Run up to 150,000 total steps

- Use `mem.fill(val, start, start + length)` NOT `mem.fill(val, start, length)` — the third arg is END not length
- The probe must be runnable with `node TI-84_Plus_CE/probe-phase242-0a32f9-display-chain.mjs`

## Success criterion
The probe runs without errors and produces a report showing:
- What the 0x0A3404↔0x0A3408 loop does (VRAM manipulation? LCD register writes? computation?)
- How many iterations before exit
- The exit PC
- Register state evolution through the loop
