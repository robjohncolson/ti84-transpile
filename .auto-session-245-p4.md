# Task: Investigate D02A86 — pending-display-update counter

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`. The transpiled JS is generated by `node scripts/transpile-ti84-rom.mjs` and lives at `TI-84_Plus_CE/ROM.transpiled.js` (214MB, gitignored).

Session 244 traced 0x08BFCD which reads D02A86 as a pending-display-update counter. The behavior:
- LD A,(D02A86)
- CP 0x00
- Z → JP 0x027111 (counter is zero)
- NZ → DEC A → LD (D02A86),A → JP 0x027123 (counter decremented)

D02A86 acts as a "how many pending display updates remain" counter. We need to know: who writes D02A86? What is the boot value? How does the event loop interact with it?

## Your task
Write a probe `TI-84_Plus_CE/probe-phase245-d02a86-writers.mjs` that:

1. **Static ROM scan for D02A86 references** — search ROM.rom for all references to address 0xD02A86. Look for:
   - `3A 86 2A D0` (LD A,(0xD02A86))
   - `32 86 2A D0` (LD (0xD02A86),A)
   - `21 86 2A D0` (LD HL,0xD02A86)
   - Any 3-byte address references `86 2A D0` in little-endian
   Log all found addresses and classify as READ/WRITE/POINTER.

2. **For each WRITE site found**: disassemble 16 bytes before and 16 bytes after the write instruction. Determine what value is being written (constant? register? computed?).

3. **For each READ site found**: disassemble surrounding context to understand the usage pattern.

4. **Boot value check** — set up a full cold boot:
   - Use createCPU() and createPeripheralBus({ timerInterrupt: false })
   - Load ROM.transpiled.js
   - Run z80 boot (0x000000, 200 steps) → check D02A86
   - Run kernelInit (0x00020C, 200 steps) → check D02A86
   - Run memInit (0x0002B8, 10000 steps) → check D02A86
   Print: D02A86 value after each stage.

5. **Event loop check** — from a warm home-screen state (after full boot stages), run the event loop at 0x02FD99 for 1000 steps. Check if D02A86 is read or written during the idle event loop.

6. Print summary: all D02A86 reference sites, write site analysis (who increments/sets it), boot value, event-loop behavior.
