## eZ80 reference
- eZ80 is little-endian, ADL mode (24-bit addresses)
- CALL nn = 0xCD nn_lo nn_mid nn_hi (4 bytes in ADL mode)
- JP nn = 0xC3 nn_lo nn_mid nn_hi
- LD A,(nn) = 0x3A nn_lo nn_mid nn_hi
- LD (nn),A = 0x32 nn_lo nn_mid nn_hi
- RET = 0xC9
- To find CALL 0x0236F9: search for bytes CD F9 36 02
