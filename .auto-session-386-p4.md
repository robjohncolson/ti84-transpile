# Task: Add Seeds for 0x02FE/0x0303 Functions

## Context
This is a TI-84 Plus CE ROM transpilation project. The transpiler at `scripts/transpile-ti84-rom.mjs` lifts ROM machine code to JavaScript. It uses "seeds" — known entry points — to discover code blocks via recursive disassembly.

Session 385 fully decoded the translation dispatcher (0x02FE00-0x02FF20) and key-processing swap (0x030300-0x030400). Several entry points within these functions may not be reached by existing seeds.

## Entry points to add as seeds
From session 385's disassembly, these are confirmed code entry points:

1. **0x02FE89** — internal entry used by JP from 0x02FDE7 and 0x02FDFE
2. **0x02FEC8** — external caller entry (0x05B24B calls here), modifier-check entry
3. **0x02FEF1** — external caller entry (0x0773ED calls here), post-modifier check
4. **0x02FE73** — JP target from 0x030353, main dispatcher re-entry
5. **0x030300** — key-processing swap function entry
6. **0x030357** — DE=0xFFFF path (zero-init handler)
7. **0x0303BF** — DE=0xFFFE path (menu/app handler)
8. **0x030388** — DE=0xFFFD path (another handler)
9. **0x02FFF6** — 2ND mode path JP target (from session 385's BIT 3,(IY+0x12) check)

## How to add seeds
1. Open `scripts/transpile-ti84-rom.mjs`
2. Find the `seeds` array (search for `const seeds` or `seeds.push` or the seed list)
3. Add each new entry point to the seeds array with a descriptive comment
4. Only add seeds that are NOT already in the list (check first!)

## After adding seeds
1. Run the transpiler: `node scripts/transpile-ti84-rom.mjs`
2. Check the output — it will report total blocks transpiled and any new blocks discovered
3. Run the golden regression: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs`
4. Confirm it still passes (26/26 or 5/5 cells)
5. Report: how many new blocks were discovered by the new seeds?

## Deliverables
- Modified `scripts/transpile-ti84-rom.mjs` with new seeds added
- Transpiler output showing new block count
- Golden regression confirmation (PASS/FAIL)

## Constraints
- Do NOT modify cpu-runtime.js, peripherals.js, browser-shell.html, or any probe files
- Do NOT modify ROM.transpiled.report.json manually (the transpiler updates it)
- Only add seeds — do not change any other transpiler logic
