# Auto-Session 209 P2: Trace 0x080D09 BufInsert Path (FP/Validation Loop)

## Context
In the TI-84 Plus CE ROM transpilation project, BufInsert (0x05E2A0) has 16 call sites. The FP/validation region is the **heaviest user** (7 sites). The most interesting is **0x080D09** which loops over buffer at 0xD0060E (near OP1 at 0xD005F8). This is likely the "display result" path — formatting a computed numeric value into the edit buffer for display.

## Task
Build a probe script `TI-84_Plus_CE/probe-phase209-080d09-bufinsert-loop.mjs` that:

1. **Statically disassembles** 48 bytes BEFORE 0x080D09 from ROM.rom to understand:
   - What sets up the loop (counter, buffer pointer)
   - What HL points to (likely 0xD0060E or edit buffer cursor)
   - What DE contains on each iteration
2. **Statically disassembles** 32 bytes AFTER 0x080D0C (after the CALL) to find the loop structure (JR/DJNZ back to a load+CALL pattern)
3. **Traces execution** starting from the block containing 0x080D09 (or a few blocks before it) with:
   - OP1 seeded with a BCD float value of 5.0 (at 0xD005F8: `00 80 50 00 00 00 00 00 00`)
   - A formatting buffer at 0xD0060E pre-filled with ASCII "5" (0x35) + null terminator
   - Edit buffer at 0xD00A00
   - Run 200 steps
4. **Reports whether BufInsert is reached** and what tokens get inserted
5. **Dumps the edit buffer** (0xD00A00-0xD00A10) after the trace to see if characters were inserted
