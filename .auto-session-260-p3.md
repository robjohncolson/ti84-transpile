## Tokens to ADD
Add the following commonly-used TI-84 tokens that are NOT yet implemented:

### 1. Matrix operations
- `det(` — determinant of a matrix. Token: [0xBB, 0xC4]. Implementation: standard determinant (cofactor expansion or LU for small matrices).
- `Matr>list(` — extract column from matrix to list. Token: [0xBB, 0xCB]. 
- `List>matr(` — combine lists into matrix columns. Token: [0xBB, 0xCA].
- `dim(` for matrices — already handles lists, extend to handle matrix arguments. Return [rows, cols] as a list.
- `T` (transpose) — Token: 0x10 (single byte). Implementation: matrix transpose.
- `rowSwap(` — Token: [0xBB, 0xCC]. Swap two rows of a matrix.
- `row+(` — Token: [0xBB, 0xCD]. Add row to another row.
- `*row(` — Token: [0xBB, 0xCE]. Multiply a row by scalar.
- `*row+(` — Token: [0xBB, 0xCF]. Multiply row by scalar and add to another row.
- `rref(` — Token: [0xBB, 0xD0]. Reduced row echelon form.
- `ref(` — Token: [0xBB, 0xD1]. Row echelon form.

### 2. Number theory / misc
- `isPrime(` — not a real TI-84 token, skip this
- `remainder(` is already implemented, skip
- `expr(` — Token: [0xBB, 0x45]. Evaluates a string as an expression. Implementation: just call the eval engine recursively.

### 3. String operations (low priority, add if time permits)
- `length(` for strings — already done for lists, extend to strings
- `sub(` — Token: [0xBB, 0x46]. Substring. sub(string, start, length)
- `inString(` — Token: [0xBB, 0x47]. Find substring position.

### 4. Probability
- `1-PropZTest(` — Token: [0xBB, 0x56]. One-proportion z-test. Takes p0, x, n. Returns z-stat and p-value.
- `2-PropZTest(` — Token: [0xBB, 0x57]. Two-proportion z-test.
- `1-PropZInt(` — Token: [0xBB, 0x58]. One-proportion z-interval. Takes x, n, C-level. Returns interval.
- `ZInterval(` — Token: [0xBB, 0x54]. Z-interval for mean. Takes sigma, xbar, n, C-level.
- `TInterval(` — Token: [0xBB, 0x55]. T-interval for mean. Takes xbar, Sx, n, C-level.
- `2-SampZTest(` — Token: [0xBB, 0x59]. Two-sample z-test.
- `2-SampTTest(` — Token: [0xBB, 0x5A]. Two-sample t-test.
- `chi2-Test(` — Token: [0xBB, 0x5B]. Chi-square test (observed vs expected matrices).
- `chi2GOF-Test(` — Token: [0xBB, 0x64]. Chi-square goodness of fit.
- `LinRegTTest(` — Token: [0xBB, 0x5C]. Linear regression t-test.
- `ANOVA(` — Token: [0xBB, 0x5D]. One-way ANOVA.

Focus on the **probability/inference** tokens (#4) since these are most useful for AP Statistics. Matrix operations (#1) are second priority. Only add #2/#3 if you have room.
