- ROM occupies 0x000000-0x3FFFFF (4MB).
- `decodeInstruction` returns an object with properties like `mnemonic`, `operands`, `length`, `bytes`.
- Read ROM bytes directly: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom'); const byte = rom[address];`
