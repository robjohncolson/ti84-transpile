# Auto-Session 558 P3: DECODE 0x055191 — Shared BPP Cluster Init Helper

## Context
Sessions 555-557 revealed a large BPP cluster at 0x052Axx-0x0554xx (~56 functions, 11KB). Two key functions (0x055228 switch-to-8bpp, 0x05523D switch-to-16bpp) both call `0x055191` first as a shared init helper. It appears **12 times** across the BPP cluster.

0x055191 is called before any mode-switching logic happens — it's the common setup/teardown that all BPP operations share.

## Task
Create a probe `TI-84_Plus_CE/probe-phase558-decode-055191.mjs` that:
1. Reads ROM.rom and disassembles starting at 0x055191
2. Decodes eZ80 ADL-mode instructions until RET (max scan 0x100 bytes)
3. Tracks: all CALL targets, all RAM references (addr >= 0xD00000), all MMIO refs (addr >= 0xE00000), all IY-relative ops, all JP/JR branches
4. Prints full disassembly with hex bytes, addresses, and mnemonics
5. Reports summary

- LCD registers: E30018 (control), E30028 (status), E30010 (VRAM base), E30020 (ready)
- D000C6 bit 2 = BPP mode flag
