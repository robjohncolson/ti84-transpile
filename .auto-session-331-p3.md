# Task: Trace the Scaling Kernel Dispatch at 0x053573/0x053FF4

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The font system has a descriptor table at 0x05320F containing 16 × 3-byte LE pointers (48 bytes total) organized as 4 records × 4 fields. Each record represents a scaling level:
- Record 0: identity (N=1,1,1,1) — no scaling
- Record 1: small scale (N=3,5,3,5)
- Record 2: medium (N=5,7,5,7)
- Record 3: large (N=7,11,7,11)

Each pointer → variable-length scaling kernel (2N-1 bytes). The font system at 0x053FF4 selects which record using a BC offset (0,3,6,9).

## Key addresses
- **0x05320F** = font descriptor table (48 bytes, 16 pointers)
- **0x05323F** = limit value = 0x000FFF
- **0x053573** = scaling kernel entry point (suspected)
- **0x053FF4** = record/field selection — uses BC offset (0,3,6,9) to pick a field from the current record
- **0x003D6E** = fixed-width font data (28 bytes/char, 12px glyphs)
- **0x0A3AFA** = variable-width font data (25 bytes/char)
- **D005F0** = font translation pointer (set during record selection)

## What to do
1. Open `TI-84_Plus_CE/ROM.transpiled.js.gz` (gunzip it).
2. Disassemble block_0x053573 and block_0x053FF4 fully. Trace the control flow.
3. Determine: how does the OS select which scaling record (0-3)? What variable or register holds the current scale level? Where is it stored in RAM?
4. Trace how the selected scaling kernel is applied to glyph bitmaps. What's the algorithm? (Likely some kind of convolution or pixel replication.)
5. Find all callers of 0x053573 and 0x053FF4.

## Deliverable
Create `TI-84_Plus_CE/probe-phase331-scaling-kernel.mjs` that:
- Statically extracts and analyzes block_0x053573 and block_0x053FF4 from the transpiled JS
- Finds all callers of both functions
- Identifies the RAM variable that holds the current scale level
- Hex-dumps at least one scaling kernel (e.g., record 1 field 0: the 5-byte kernel for N=3) from the ROM
- Boots to home screen and monitors which scaling record is active during normal text rendering
