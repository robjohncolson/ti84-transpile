# Auto-Session 259 — P1: Classify all D007E0 write sites (gated vs. direct)

## Context

Session 256 found **30 D007E0 write sites** in the ROM: values 0x40×8, 0x48×5, 0x49×3, 0x4A×2, 0x44, 0x46, 0x54, 0x5B.

Session 257 found that **0x09E2EC** is a context-registration function that writes D007E0, but it's **gated by BIT 0,(IY+9)** at 0x09E2F8 — RET Z if not set. Session 258 found that **IY+9 bit 0 has ONLY 1 SET site in the entire ROM: 0x09C775** (STAT region). So 0x09E2EC can only complete for STAT contexts.

**Key question**: How do non-STAT contexts (home screen, Y= editor, graph mode) populate D007E0? There must be direct writes that don't go through 0x09E2EC.

## Task

Write a probe `TI-84_Plus_CE/probe-phase259-d007e0-write-sites.mjs` that:

1. **Static scan**: Read `ROM.rom` (4MB binary at `TI-84_Plus_CE/ROM.rom`) and find ALL instructions that write to address D007E0. Look for:
   - `LD (0xD007E0),A` — opcode pattern: `32 E0 07 D0` (little-endian, 4-byte address in ADL mode)
   - `LD (HL),A` or `LD (HL),value` where HL might be 0xD007E0 (harder to find statically — skip these)
   - Just focus on the direct `LD (addr),A` pattern with addr = 0xD007E0

2. **For each write site found**, disassemble 20 bytes BEFORE the write instruction to see what value A holds (look for `LD A,imm8` pattern: `3E xx`). Record the ROM address of the write and the value being written.

3. **Classify each site**: Check if the site is inside 0x09E2EC (range 0x09E2EC-0x09E310 based on session 257's disassembly) or NOT. Sites NOT inside 0x09E2EC are **direct writes** that bypass the IY+9 bit 0 gate.

4. **Print a table** of all sites: ROM address, A value, inside-0x09E2EC (yes/no), surrounding context (nearest CALL or JP target).
