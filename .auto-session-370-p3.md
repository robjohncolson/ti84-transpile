## Disassembly approach
For each target address:
```js
const addr = 0x00620D;
const prefix = addr.toString(16).padStart(6, '0');
const blockKeys = Object.keys(BLOCKS).filter(k => k.startsWith(prefix));
console.log(`Blocks at ${prefix}: ${blockKeys.join(', ') || 'none'}`);

// Raw bytes
const bytes = [];
for (let i = 0; i < 64; i++) bytes.push(mem[addr + i]);
console.log(`Raw bytes: ${bytes.map(b => b.toString(16).padStart(2, '0')).join(' ')}`);
```

Then manually decode the eZ80 opcodes from those bytes (eZ80 ADL mode: 3-byte addresses, standard Z80 opcodes). Key opcodes:
- CD xx xx xx = CALL addr (4 bytes in ADL)
- C3 xx xx xx = JP addr (4 bytes in ADL)
- DB pp = IN A,(port) — but eZ80 uses ED-prefixed IN0/OUT0:
  - ED 38 pp = IN0 A,(port)
  - ED 39 pp = OUT0 (port),A
- C9 = RET
