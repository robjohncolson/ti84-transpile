## Context

**0x03EC5A** is a JUMP TABLE DISPATCHER (12B): takes A=index, HL=table base, returns HL=24-bit pointer from table[A]. When called from 0x03EC8F (error context formatter) with HL=0x03ECAD, it returns a pointer to one of 17 variable type name strings (REAL, LIST, MATRX, EQU, GDB, PIC, PRGM, CPLX, WINDW, ZSTO, TABLE, STRNG, APP, AVAR, UNKN, GROUP, IMAGE) located at 0x03ECFE-0x03ED54.

We need to trace what happens AFTER the CALL 0x03EC5A returns — how does the caller use the HL string pointer? Does it display it, store it, pass it to another function?

The probe must:

4. Print everything with addresses, raw bytes, and mnemonics
5. Specifically look for patterns like:
   - CALL to 0x0A1799 or other text output routines (display the string)
   - LD (addr),HL or PUSH HL (store the pointer)

6. Also search for any direct references to the type string range 0x03ECFE-0x03ED54 (callers that bypass the dispatcher and reference strings directly)
