# Auto-Session 355 — P2: Disassemble RST 38h Handler + 0x0006F3-0x000720 Dispatch Logic

## Context
TI-84 Plus CE ROM transpilation project. The ROM (eZ80 CPU) boots but loops in a 2203-step cycle. The RST 38h handler at 0x000038 does: EX AF,AF'; EXX; PUSH IX; PUSH IY; LD IY,0xD00080; JP 0x0006F3. The code at 0x0006F3 reads flash port 0x06 (BIT 2,A check). RST 38h is called EVERY cycle, and 0x0006F3 always re-enters boot init instead of advancing. We need to understand the full dispatch logic at 0x0006F3-0x000720 to find the condition that would let boot proceed.

## Task
Create a probe that:
1. **Disassembles ROM bytes at 0x000038-0x000060** (the RST 38h handler, ~40 bytes). Print address, hex bytes, mnemonic for each instruction.
2. **Disassembles ROM bytes at 0x0006F3-0x000740** (~77 bytes). This is the boot init dispatch entered via RST 38h. Print each instruction clearly.
3. **Traces execution dynamically** starting at PC=0x000038 (simulating RST 38h entry) with IY=0xD00080 (as the RST handler would set it) for 200 steps. Log: step, PC, instruction mnemonic (from ROM bytes), A register, F register (as hex), and any IN/OUT port operations.
4. **Identifies branch conditions**: For every conditional jump/call in 0x0006F3-0x000740, print: the condition tested, the current flag state, which branch is taken, and what the OTHER branch would lead to (the address of the not-taken path).
5. **Specifically answers**: What register/flag/port value would need to change for 0x0006F3 to take a DIFFERENT path than the LCD init re-entry?

- `cpu.step()` executes one instruction, returns cycles.
- Registers: `cpu.a`, `cpu.f`, `cpu.b`, `cpu.c`, `cpu.d`, `cpu.e`, `cpu.h`, `cpu.l`, `cpu.ix`, `cpu.iy`, `cpu.sp`, `cpu.pc`
- Flags in F register: bit 7=S, bit 6=Z, bit 4=H, bit 2=PV, bit 1=N, bit 0=C
- Port 0x06 (flash): currently returns 0xD4 (bit 2 set) after PLL lock fix from session 349
- eZ80 instruction encoding: some instructions have ED prefix. IN0 A,(port) = ED 38 port. BIT n,A = CB 47+8*n. JR Z = 28 offset. JR NZ = 20 offset.
