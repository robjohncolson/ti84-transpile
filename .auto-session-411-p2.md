You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

Session 409 decoded the notification dispatch table at 0x0120AA with 6 entries. Three of them are USB/Link receive workers:
- Handler 0: 0x013250 — USB receive worker A, reads D1776D buffer

4. For each worker, find all callers in the ROM (search for CALL addr and JP addr patterns).

## eZ80 Encoding Reference
- CALL nn = 0xCD followed by 3 bytes (little-endian 24-bit address)
- JP nn = 0xC3 followed by 3 bytes (little-endian 24-bit address)
- LD A,(nn) = 0x3A followed by 3 bytes (address)
- LD (nn),A = 0x32 followed by 3 bytes (address)
- LD HL,(nn) = 0x2A followed by 3 bytes (address)
- IN A,(n) = 0xDB followed by 1 byte (port)
- IN0 reg,(n) = 0xED followed by register-specific opcode + 1 byte port
- CP n = 0xFE followed by 1 byte
- RET = 0xC9
- Prefix 0x40 = SIS (short mode)
- Prefix 0x49/0x52/0x5B = mixed-mode prefixes
