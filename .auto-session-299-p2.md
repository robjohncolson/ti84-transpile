# Task: Trace 0x040A56 — Single Caller of Keyboard Init Routine 0x040EE0

## Context
Session 298 found that 0x040EE0-0x040F6F is the keyboard controller init/reset routine (144 bytes). It zeroes controller registers, sets row mask, enables interrupts, polls scan status, etc. It runs once during boot.

The single caller is at 0x040A56. We need to trace 0x040A56 to understand:
- What function contains 0x040A56?
- What OS phase does it belong to (boot, APD wake, app init)?
- What does the surrounding code do before and after the keyboard init call?

## What to do
Create a probe at `TI-84_Plus_CE/probe-phase299-040A56-caller-context.mjs` that:

1. **Static disassembly of 0x040A56's containing function**:
   - Read `TI-84_Plus_CE/ROM.rom` binary
   - Starting from 0x040A56, scan backwards to find the function entry point (look for a `RET` or unconditional `JP` before the function start, or a known entry point)
   - Decode instructions from the function entry to past 0x040A56, covering at least 0x0409F0-0x040B00 (wider if the function extends further)
   - For each instruction: print address, hex bytes, mnemonic, operands
   - Identify all CALL targets within this function — these reveal what else this init phase does

2. **Search for callers of the containing function**:
   - Once you identify the entry point of the function containing 0x040A56, search ROM for all CALL/JP to that entry point
   - Pattern: `CD <addr_lo> <addr_mid> <addr_hi>` and `C3 <addr_lo> <addr_mid> <addr_hi>`

3. **Dynamic trace during boot**:
   - Boot the OS through cold boot + kernel init (same as probe-phase99d)
   - Log when PC hits 0x040A56 (the CALL 0x040EE0 site) and 0x040EE0 (the init routine itself)
   - Capture the call stack depth and return addresses at each hit
   - Record how many total steps into boot this occurs

4. **Output**: Full disassembly of the function containing 0x040A56, its callers, and dynamic boot trace showing when keyboard init fires.

## eZ80 instruction reference (key opcodes for decoding)
- `CD xx xx xx` = CALL addr24 (ADL mode)
- `C3 xx xx xx` = JP addr24
- `C9` = RET
- `ED 4D` = RETI
- `18 xx` = JR offset
- `20 xx` = JR NZ,offset
- `28 xx` = JR Z,offset
- `CB xx` = bit operations (BIT, SET, RES, etc.)
- `DD` prefix = IX instructions
- `FD` prefix = IY instructions
- `ED` prefix = extended instructions (LDIR, LDDR, etc.)
