# Session 254 P1: D007E0 Initialization Trace During OS Boot

## Context
The TI-84 Plus CE OS uses RAM address 0xD007E0 as a "current context mode" byte. The CoorMon dispatcher at 0x08C79F reads this byte to decide whether to re-dispatch or skip. Session 253 proved that 0x062055 (a handler) has ZERO static callers — it's registered in a RAM-based dispatch table at runtime. The handler table at 0x08C958 (20 entries, indexed by A register) is a ROM constant, but the MODE SELECTOR at D007E0 determines which handler is used.

We need to know: **When and where does D007E0 first get written during OS boot?**

## Task
Create a probe file `TI-84_Plus_CE/probe-phase254-d007e0-boot-trace.mjs` that:

1. Imports from `./cpu-runtime.js` and `./peripherals.js`
2. Loads the ROM: `fs.readFileSync('./TI-84_Plus_CE/ROM.rom')`
3. Creates the runtime with `createCPU(rom)` and `createPeripheralBus({ timerInterrupt: false })`
4. Boots the OS using the standard boot sequence (see reference below)
5. **Instruments write8** to watch for any write to 0xD007E0. On each write, log:
   - The step number
   - The value being written
   - The current PC (cpu.pc)
   - The current block address if available
6. Runs the full boot sequence: z80 boot (PC=0), kernelInit, memInit, then homescreen stages 1-4
7. After boot completes, also dumps the final value at 0xD007E0

## Boot Sequence Reference
```javascript
const { createCPU } = require('./cpu-runtime.js');
const { createPeripheralBus } = require('./peripherals.js');
const fs = require('fs');

const rom = fs.readFileSync('./TI-84_Plus_CE/ROM.rom');
const cpu = createCPU(rom);
const bus = createPeripheralBus({ timerInterrupt: false });

// Wire peripherals
cpu.connectBus(bus);

// Boot: start at PC=0, run through OS init
cpu.pc = 0;
cpu.sp = 0xD1A87E;
cpu.iy = 0xD00080;
cpu.ix = 0xD1A860;
cpu.mbase = 0xD0;

// Run z80 boot + kernel init
// Execute blocks until HALT or step limit
```

Use `cpu.runBlock()` or whatever the block execution method is. Check `cpu-runtime.js` for the actual API — it might be `cpu.step()`, `cpu.execute()`, or `cpu.run()`.

The key thing is to **patch the write8 function** to intercept writes to 0xD007E0:
```javascript
const origWrite8 = cpu.write8.bind(cpu);
cpu.write8 = function(addr, val) {
  if (addr === 0xD007E0) {
    console.log(`[D007E0 WRITE] step=${stepCount} val=0x${val.toString(16).padStart(2,'0')} PC=0x${cpu.pc.toString(16).padStart(6,'0')}`);
  }
  return origWrite8(addr, val);
};
```
