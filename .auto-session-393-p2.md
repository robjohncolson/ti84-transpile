# Task: Map the 2ND-mode flag lifecycle (bit 5 of IY+0x12 = 0xD00092)

## Context
This is a TI-84 Plus CE ROM transpilation project. We've decoded that bit 5 of (IY+0x12) = address 0xD00092 is the 2ND-mode flag. When set, key translation adds 0xA8 offset (0x70+0x38) to access the 2ND section of the 0x09F79B translation table.

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase393-2nd-flag-lifecycle.mjs` that:

1. **Static ROM search for SET 5,(IY+0x12)**: Search the entire ROM (0x000000-0x3FFFFF) for the byte sequence that encodes SET 5,(IY+0x12). In eZ80:
   - SET 5,(IY+d) = FD CB 12 EE (where d=0x12, SET 5 opcode = 0xC6 + 5*8 = 0xEE)
   - Search for bytes: FD CB 12 EE

2. **Static ROM search for RES 5,(IY+0x12)**: Search for the byte sequence that encodes RES 5,(IY+0x12):
   - RES 5,(IY+d) = FD CB 12 AE (where d=0x12, RES 5 opcode = 0x86 + 5*8 = 0xAE)
   - Search for bytes: FD CB 12 AE

3. **Static ROM search for BIT 5,(IY+0x12)**: Search for test instructions:
   - BIT 5,(IY+d) = FD CB 12 6E (where d=0x12, BIT 5 opcode = 0x46 + 5*8 = 0x6E)
   - Search for bytes: FD CB 12 6E

4. **Context for each match**: For every match found, decode the surrounding ~20 bytes to understand:
   - What function is this in? (look for nearby CALL/RET boundaries)
   - What happens before the SET/RES/BIT? (what triggers it?)
   - What happens after? (what's the consequence?)

5. **Key questions to answer**:
   - Where exactly is the 2ND flag SET? (user presses 2ND key)
   - Where exactly is the 2ND flag CLEARED? (after translation consumes it)
   - How many places test the flag?
   - Is there a 2ND-key handler that receives scan code 0x06 (2ND key) and sets the flag?

## ROM file
Read from: `TI-84_Plus_CE/ROM.rom` (4MB binary, little-endian eZ80)

## Output format
Print structured findings to stdout showing:
- All SET/RES/BIT sites with ROM addresses
- Surrounding instruction context for each
- Summary of the flag lifecycle: SET at X (triggered by Y), tested at Z, CLEARED at W

The probe should be runnable with `node TI-84_Plus_CE/probe-phase393-2nd-flag-lifecycle.mjs`.
