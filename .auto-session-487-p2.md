# Auto-Session 487 P2: Decode Status Bar Indicator at Row 2 Col 289

## Context

This is a TI-84 Plus CE ROM transpilation project. The OS ROM (eZ80 machine code) has been lifted to JavaScript. We run "probes" — Node.js scripts that boot the lifted ROM, step the CPU, and observe memory/VRAM changes.

Session 486 found that the cursor blink function 0x030173 always renders at row=2, col=289 (VRAM 0xD40742). On a real TI-84 CE, this position is in the upper-right status bar area where battery/charging indicators appear. The function 0x030173 calls 0x030202 (glyph selector) which returns 0xE1/0xE2/0xE3 based on D00092 bits 3/4/5, then calls 0x0A23C0 (font glyph selector) and 0x0A239E (pixel writer).

## Task

Create a probe that investigates whether the rendering at row 2, col 289 is the BATTERY INDICATOR or some other status bar element, NOT the text cursor.

### Specific investigations:

1. **Map the status bar layout**: The TI-84 CE status bar occupies the top 37 pixel rows. Row 2, col 289 = 31 pixels from the right edge of a 320-wide display. On a real TI-84, the battery icon is in the upper-right corner. Investigate:
   - What other addresses near 0x030173 are called during idle loop? (Check 0x03013A and nearby functions)
   - Does the code near 0x030173 reference battery-related state variables?

2. **Search for battery/power state variables**: Look in ROM for references to common TI-84 CE battery state addresses. The SDK documents:
   - D00086 bit 0 = charging indicator
   - D00087 = battery level
   Search ROM bytes for LD A,(0xD00086) and LD A,(0xD00087) patterns near the 0x030xxx range.

3. **Trace the full 0x03013A path**: 0x03013A is hit 1228 times in the idle loop (from session 480). Decode what 0x03013A does BEFORE it reaches 0x030173. Does it check battery state? Does it check other status indicators (2nd, Alpha, mode)?

4. **Check for a SEPARATE text cursor blink function**: If 0x030173 is the status bar indicator, then the actual text cursor blink must use a different function. Search for:
   - Other callers of 0x0A23C0 (font glyph selector) or 0x0A239E (pixel writer)
   - Functions that reference D00595/D00596 (text cursor row/col) AND call rendering code
   - Functions in the 0x030xxx or 0x05xxxx range that use the VRAM address formula (row×20+37)×640+(col×12+2)×2
