# Task: Trace 0x03013A — Idle Loop Function Decode

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS idle loop has been fully decoded:
- Loop: 0x02FD99 → 0x02FDB6 → CALL 0x03FA09 → 0x02FDC2 → 0x02FDD8 → 0x02FDE6 → 0x02FDEB → 0x03030E → 0x03034F → 0x02FE73 → JP Z 0x02FD99
- At 0x02FD99, the pre-loop setup does: `PUSH IX; CALL 0x03013A; POP IX`
- 0x03013A is called EVERY idle loop iteration (109 hits in 5000 steps)

## Your Task
Create a probe `TI-84_Plus_CE/probe-phase474-trace-03013A.mjs` that traces 0x03013A to decode what it does.

## Probe Structure

1. **3-stage boot** (standard):
   - Stage 1: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
   - Reset: `cpu.halted=false; cpu.iff1=0; cpu.iff2=0; cpu.sp=0xD1A87E-3; mem.fill(0xFF, cpu.sp, cpu.sp+3);`
   - Stage 2: `cpu.mbase=0xD0; cpu._iy=0xD00080;` then `executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`
   - Reset: `cpu.mbase=0xD0; cpu._iy=0xD00080; cpu._hl=0; cpu.halted=false; cpu.iff1=0; cpu.iff2=0; cpu.sp=0xD1A87E-3; mem.fill(0xFF, cpu.sp, cpu.sp+3);`
   - Stage 3: `executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`

2. **State setup after boot**:
   - NO key injection (we want the idle loop, not key processing)
   - `mem[0xD14091] = 1;`
   - `mem[0xD00824] = 0x48;`
   - `mem[0xD007E0] = 0x48;`
   - `mem[0xD177BA] = 0x7F;`
   - `mem[0xD177B7] = 0x00;`
   - `cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;`
   - Stack: write 0x02FDBE as return address

3. **Run from 0x02FD99** (the pre-loop setup, which calls 0x03013A first):
   - maxSteps: 10000
   - maxLoopIterations: 50000
   - diHaltBypass: true
   - onBlock callback

4. **Tracking — TWO levels**:
   a. Track these high-level PCs (hit counts only):
      - 0x02FD99, 0x02FDB6, 0x03FA09, 0x02FDD8, 0x03030E, 0x02FE73
   
   b. Track EVERYTHING called from within 0x03013A. Use a flag:
      - Set `inside03013A = true` when PC === 0x03013A
      - Set `inside03013A = false` when PC === 0x02FDB6 (the block AFTER the CALL 0x03013A + POP IX returns)
      - While inside03013A is true, log EVERY unique PC visited (store in a Set), and log the first 3 PCs visited in order

5. **Also read ROM bytes** at 0x03013A through 0x03013A+64 (64 bytes) and print as hex dump. This is the raw function body.

6. **Report**:
   - Hex dump of 0x03013A-0x03017A
   - All unique PCs visited while inside 0x03013A (sorted)
   - First 20 PCs visited in order (the call trace)
   - Hit counts for high-level loop PCs
   - Total steps consumed inside 0x03013A vs total steps
