# Task: Add 20 New Transpiler Seeds for Coverage Push

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The transpiler lifts eZ80 machine code from `TI-84_Plus_CE/ROM.rom` into JavaScript. Seeds are entry point addresses that tell the transpiler where executable code begins.

Current state: 144,955 transpiled blocks, 708,707 covered bytes out of ~738,000 non-erased bytes (95.92% coverage).

## Deliverables
1. Find 20 new seed addresses in the ROM that are NOT already seeded
2. Add them to the transpiler at `scripts/transpile-ti84-rom.mjs`
3. Run the transpiler and report new block/byte counts
4. Run the golden regression: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs` — it MUST still pass

## How to Find Seeds
Look for uncovered regions by:
1. Run `node TI-84_Plus_CE/audit-true-uncovered.mjs` to find gaps
2. For each gap, check if the bytes look like valid eZ80 code:
   - Look for common instruction patterns: PUSH/POP (C5/D5/E5/F5 / C1/D1/E1/F1), CALL nn (CD xx xx xx), RET (C9), LD r,r patterns
   - Avoid data tables (long runs of 00, FF, or repetitive patterns)
   - Avoid strings (runs of ASCII 0x20-0x7E)
3. Good seed candidates:
   - Addresses right after a RET (C9) or JP (C3) that start a new function
   - Addresses referenced by CALL/JP from already-transpiled code
   - Addresses in the 0x000000-0x0BFFFF range (OS code region)

## How to Add Seeds
Open `scripts/transpile-ti84-rom.mjs` and find the `seeds` array (or `addSeeds` calls). Add your 20 new addresses. Format: `0xABCDEF`

## How to Run
```bash
node scripts/transpile-ti84-rom.mjs
node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
```

## Validation
- Each seed must decode at least 3 valid eZ80 instructions before hitting an invalid opcode or already-covered region
- The transpiler must complete without errors
- Golden regression must pass (look for "Normal Float Radian" in output and 26/26 cells)
- Report: old block count (144,955), new block count, delta, old bytes (708,707), new bytes, delta

## Constraints
- Do NOT modify any file other than `scripts/transpile-ti84-rom.mjs`
- Do NOT modify `TI-84_Plus_CE/ROM.transpiled.js` manually — the transpiler generates it
- Seeds should be spread across different ROM regions, not all clustered in one area
- Prefer regions 0x008-0x0BC (OS code), avoid 0x0C0000+ (certificate/data region)
