# Task: Decode 0x0A22B1 — Special Character Handler (char == 0xD6)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80). We're decoding OS functions in the text rendering pipeline.

**Call chain**: 0x0A1B5B (per-char dispatch) does `CP 0xD6` — if character matches, it calls **0x0A22B1** (THIS TARGET) before calling 0x0A2032 (line wrap). So 0x0A22B1 handles the "special token 0xD6" case.

In the TI-OS, token 0xD6 likely represents a newline or line-feed character. This function probably handles the newline behavior: reset column, advance row, possibly scroll.

## Known architecture
- 0x0A1B5B flow for 0xD6: CP 0xD6 → JR NZ,normal → CALL 0x0A22B1 → CALL 0x0A2032 → check column → exit
- D00596 = column counter
- D00595 = current column position  
- D008D5 = primary Y coordinate
- D0231A = cursor position
- D0231D = cursor state
- IY base = D00080
- IY+0x4A bit 4 = text output guard (42 refs)
- 0x0A22DA = renderer that selects immediate vs deferred path based on IY+0x4A bit 4
- 0x09EF20 = immediate render path
- 0x09EF44 = deferred render path

## Deliverable
Create `TI-84_Plus_CE/probe-phase559-decode-0A22B1.mjs` that:
1. Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
2. Disassembles starting at 0x0A22B1 for up to 200 bytes (or until RET found)
3. Documents each instruction with comments
4. Identifies: what it does for the newline/special char, whether it resets column, advances Y, calls scroll, or sets flags
5. Prints a structured summary
