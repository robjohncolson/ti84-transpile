# Auto-Session 218 P2: Test 0x04EC1C as BIT 4 arming before ConvKeyToTok digit entry

## Context
Two facts established by prior sessions:
1. **0x04EC1C is "enter edit mode"** (session 217): Function 0x04EC1C-0x04EC38 does RES 0,(IY+14) / CALL 0x05E3AE / CALL 0x0972FE / LD A,(D00596) / CALL 0x0A2CBF / RES 6,(IY+5) / SET 4,(IY+5) / RET. Takes ~2582 steps, sets BIT 4,(IY+5).
2. **Digit entry requires BIT 4,(IY+5) SET** (session 211-212): ConvKeyToTok at 0x05E630 with scan code 0x8F converts to token 0x31. BIT 4,(IY+5) gate at 0x05E63C routes to 0x05E6A4 → BufInsert. Without BIT 4 set, digits take alternate non-insert path.

**Question**: Can we use 0x04EC1C to arm BIT 4, then immediately call ConvKeyToTok to insert a digit — i.e., is 0x04EC1C the natural OS "arm edit mode" call before digit processing?

## Task
Build probe `TI-84_Plus_CE/probe-phase218-04ec1c-arm-then-digit.mjs` that:

### Part A: Call 0x04EC1C then ConvKeyToTok sequentially
1. Full boot (z80 → kernelInit → memInit)
2. Seed gap buffer: editTop(0xD02437)=0xD00A00, editCursor(0xD0243A)=0xD00A00, editTail(0xD0243D)=0xD00B00, editBtm(0xD02440)=0xD00B00
3. Call 0x04EC1C with TRACE_RET_SENTINEL on stack (max 5000 steps)
4. After return, verify IY+5 has BIT 4 set (should be 0x10)
5. Then call ConvKeyToTok at 0x05E630 with A=0x8F (scan code for '1'), max 500 steps
6. Check: did BufInsert fire? Is 0x31 written at 0xD00A00? Did cursor advance to 0xD00A01?

### Part B: Multi-digit sequence
After Part A succeeds (BIT 4 armed by 0x04EC1C):
1. Call ConvKeyToTok with A=0x90 (scan code for '2') — does BIT 4 persist?
2. Call ConvKeyToTok with A=0x80 (scan code for '+')
3. Call ConvKeyToTok with A=0x91 (scan code for '3')
4. Read edit buffer at 0xD00A00-0xD00A03: expect tokens 0x31, 0x32, 0x70, 0x33 ("1", "2", "+", "3")

### Part C: Control — ConvKeyToTok WITHOUT 0x04EC1C arming
1. Fresh boot, same gap buffer seeding, but do NOT call 0x04EC1C
2. Manually clear IY+5 BIT 4 (should already be 0)
3. Call ConvKeyToTok with A=0x8F
4. Confirm BufInsert NOT reached, edit buffer empty
