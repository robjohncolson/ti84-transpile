## Background
0x09BAC9 has been carried as an undecoded priority since session 558. It's described as an "input reader" — likely part of the OS keyboard/input subsystem. The TI-84 CE OS event loop reads scan codes from the keyboard matrix and dispatches them through a chain of handlers.

Related keyboard/input context:
- Keyboard matrix mapped in `TI-84_Plus_CE/keyboard-matrix.md`: `keyMatrix[N] = SDK Group(7-N)`, scan code = `(idx << 4) | bit`
- 0x0AD455 = partial OS input tokenizer/parser (514B+, session 558)
- The OS event loop calls `_GetCSC` (scan code reader) which reads port group registers
- Known port addresses for keyboard: 0xF50000-0xF5001F (keyboard controller)
- D00587 = last scan code, D00080 = key flags (IY+0x00)

## eZ80 Decoder Reference
```javascript
import { createCPU, loadROM } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';
import { decodeInstruction } from './ez80-decoder.js';
const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(peripherals);
loadROM(cpu);
let pc = 0x09BAC9;
for (let i = 0; i < 120; i++) {
  const inst = decodeInstruction(cpu.mem, pc);
  const bytes = Array.from(cpu.mem.slice(pc, pc + inst.length)).map(b => b.toString(16).padStart(2,'0')).join(' ');
  console.log(`0x${pc.toString(16).padStart(6,'0')}: ${bytes.padEnd(20)} ${inst.mnemonic} ${inst.operands || ''}`);
  if (inst.mnemonic === 'RET' && !inst.condition) break;
  pc += inst.length;
}
```
