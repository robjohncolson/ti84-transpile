# Auto-Session 613 — Priority 4: Map D000C4 (IY+0x68) Semantics

## Context

In the TI-84 Plus CE ROM, the outer loop at 0x08F3B8 (decoded in session 612) modifies a byte via IY-relative addressing:
- SET 3,(IY+68) at 0x08F40C
- RES 4,(IY+68) at 0x08F410

IY is set to 0xD0005C. We need to confirm the actual offset (decimal 68 vs hex 0x68) and map ALL references to this byte.

2. **Search ALL IY-relative BIT/SET/RES references** to this byte across the entire ROM:

```js
// temp-scan-iy-refs.mjs
import fs from 'fs';
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
const targetDisp = rom[0x08F40C + 2]; // displacement from the known instruction
const results = [];
for (let i = 0; i < rom.length - 4; i++) {
  if (rom[i] === 0xFD && rom[i+1] === 0xCB && rom[i+2] === targetDisp) {
    const opcode = rom[i+3];
    let op;
    if ((opcode & 0xC7) === 0x46) op = `BIT ${(opcode>>3)&7}`;
    else if ((opcode & 0xC7) === 0xC6) op = `SET ${(opcode>>3)&7}`;
    else if ((opcode & 0xC7) === 0x86) op = `RES ${(opcode>>3)&7}`;
    else continue; // not a BIT/SET/RES
    results.push({ addr: i, op, bit: (opcode>>3)&7 });
  }
}
console.log(`Total IY+0x${targetDisp.toString(16)} refs: ${results.length}`);
results.forEach(r => console.log(`0x${r.addr.toString(16).padStart(6,'0')}: ${r.op},(IY+0x${targetDisp.toString(16)})`));
// Bit usage summary
const bits = {};
results.forEach(r => {
  if (!bits[r.bit]) bits[r.bit] = { BIT: 0, SET: 0, RES: 0 };
  const type = r.op.split(' ')[0];
  bits[r.bit][type]++;
});
console.log('\nBit usage summary:');
for (const [bit, counts] of Object.entries(bits).sort((a,b)=>a[0]-b[0])) {
  console.log(`  Bit ${bit}: ${counts.BIT} BIT tests, ${counts.SET} SETs, ${counts.RES} RESs`);
}
```

const b0 = addr & 0xFF, b1 = (addr >> 8) & 0xFF, b2 = (addr >> 16) & 0xFF;

    count++;
    console.log(`0x${i.toString(16).padStart(6,'0')}: direct ref to 0x${addr.toString(16).toUpperCase()}`);
  }
}
console.log(`Total direct refs: ${count}`);
