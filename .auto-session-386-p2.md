# Task: Trace the Two External Callers of the Translation Dispatcher

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary). Session 385 found exactly 2 external callers of the translation dispatcher (0x02FE00-0x02FF00):

1. **0x05B24B** — `CALL P,0x02FEC8` (conditional: positive sign flag). Targets the modifier-check entry point.
2. **0x0773ED** — `CALL PE,0x02FEF1` (conditional: parity even flag). Targets the post-modifier key-code check.

## Your task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase386-callers-context.mjs` that:

1. Reads ROM.rom
2. For EACH of the two callers (0x05B24B and 0x0773ED):
   a. Disassemble 80 bytes BEFORE the call instruction (to see the setup/context)
   b. Disassemble 40 bytes AFTER the call instruction (to see what happens on return)
   c. Identify the containing function: scan backwards for a plausible function entry (after a RET/RETI, or at a known entry point)
   d. Annotate: what RAM/ports are accessed? What registers are set up before the call? What does this function appear to do?

3. For each caller, determine:
   - Is this in an event loop handler, menu system, editor callback, or something else?
   - Why is the call conditional (P for sign-positive, PE for parity-even)? What flag state triggers it?
   - What scan code or key context is being processed?
