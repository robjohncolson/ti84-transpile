# Task: Investigate APD timer thresholds and subroutines (zzz)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 237 decoded 0x03030E as an APD (Auto Power Down) timer check block. It compares HL (from RAM at 0x000001) against thresholds 0xFFFF, 0xFFFE, 0xFFFD for idle timeout stages. When thresholds match, it calls subroutines:
- **0x07F9FB** — suspected display refresh
- **0x08383D** — suspected display refresh
- **0x03E141** — suspected APD warning
- **0x063051** / **0x061DEF** — suspected editor refresh

We need to trace each subroutine to confirm what fires at each APD stage.

## Task
Create a probe `TI-84_Plus_CE/probe-phase238-apd-timer-subroutines.mjs` that:

1. Sets up a minimal runtime (full boot pattern).
2. For EACH of the 5 subroutines (0x07F9FB, 0x08383D, 0x03E141, 0x063051, 0x061DEF):
   - Enter at the subroutine address with home-screen state (IX=0xD1A860, IY=0xD00080)
   - Run 200-500 steps
   - Log unique blocks visited (with counts)
   - Check VRAM writes (snapshot 0xD40000-0xD40100 before/after)
   - Check IY flag changes
   - Check if it writes to display-related RAM (D005xx, D006xx, D00Axx)
   - Note how many steps to RET
3. Also trace the 0x03030E block itself with HL set to each threshold value (0xFFFF, 0xFFFE, 0xFFFD, and 0x0000 as control) to confirm which subroutine fires at which stage.
4. Classify each: display refresh, cursor blink, APD warning, APD shutdown, editor update?
