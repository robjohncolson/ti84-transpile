# Task: Trace 0x07C8B7 and 0x07C77F (Display Rendering Pair)

## Context

The transpiler is at `scripts/transpile-ti84-rom.mjs`. The runtime is `TI-84_Plus_CE/cpu-runtime.js`. Peripherals are in `TI-84_Plus_CE/peripherals.js`.

## What we know
- 0x07C8B7 and 0x07C77F are a "display rendering pair"
- Both are called by the LCD timing diagnostic display function at 0x05749C
- 0x07C77F is also known as the FPAdd jump-table entry: `SET 6,(IY+89); RES 6,(IY+14); CALL 0x07CC36`
- 0x07C8B7 is likely a display/text rendering helper
- 0x05749C has 12 unique CALL targets and formats BCD numbers for display
- These two functions are likely called by many other display-related functions across the ROM

## Your task
Build a probe script `TI-84_Plus_CE/probe-phase327-display-pair.mjs` that:

1. **Disassembles 0x07C8B7** by reading raw ROM bytes. Trace from 0x07C8B7 until RET or unconditional JP outside. Decode eZ80 instructions manually. Document every instruction.

2. **Disassembles 0x07C77F** similarly. Note: we already know the first few instructions (`SET 6,(IY+89); RES 6,(IY+14); CALL 0x07CC36`), but trace the full function including what happens after the CALL returns.

3. **Counts callers of each**: Search the ROM for CALL/JP references to both addresses. How many callers does each have? This tells us how central they are to the display subsystem.

4. **Runs dynamic traces**:
   - Load the transpiled JS
   - Create CPU + peripherals (timerInterrupt: false)
   - For 0x07C8B7: set PC, run up to 200 steps, log block PCs and any VRAM writes (0xD40000-0xD52BFF range)
   - For 0x07C77F: same treatment
   - What RAM addresses do they read/write? Do they touch display RAM (D17700-D17721)?

5. **Determines**: What does each function actually render? Are they text renderers, pixel plotters, screen clearers, or something else? Do they share subroutines?

## Output format

- Part B: Static disassembly of 0x07C77F
- Part C: Caller counts for each
- Part D: Dynamic trace results for both
- Part E: Functional classification — what each does and how they relate
