# Auto-Session 275 P2: Trace 0x0846EA Caller and Post-Return Dispatch

## Context
In the TI-84 Plus CE OS, 0x0846EA is the dispatch table scanner at D3FFFF. It walks the table top-down looking for a matching entry and returns the handler address in DE. Session 274 confirmed: with an empty table it returns without match; with a populated table it correctly resolves DE=handler.

The critical unknown: WHO calls 0x0846EA and what does the caller do with DE after return? The caller must `JP (DE)` or `CALL DE` or similar to actually dispatch to the handler.

## Task
Create a probe `TI-84_Plus_CE/probe-phase275-0846ea-caller-trace.mjs` that:

1. **Find callers of 0x0846EA statically**: Scan the entire ROM (4MB) for:
   - `CD EA 46 08` (ADL CALL 0x0846EA)
   - `C3 EA 46 08` (ADL JP 0x0846EA)
   - `CC EA 46 08`, `C4 EA 46 08`, etc. (conditional CALL/JP)
   - Also check for z80-mode encodings (3-byte address)
   
2. **For each caller found**: Read 20 bytes AFTER the CALL instruction to see what the caller does with DE on return. Look for:
   - `D5` = PUSH DE (saves handler)
   - `EB` = EX DE,HL then `E9` = JP (HL) — indirect dispatch
   - `ED 53 xx xx xx` = LD (nn),DE (stores handler)
   - Any JP/CALL to the value in DE

3. **Dynamic trace**: Set up a runtime with the dispatch table populated (write a 9-byte entry at D3FFF7-D3FFFF with handler=0x058241), then run from each caller site for 200 steps to see if execution reaches 0x058241.

## Reference files
- `TI-84_Plus_CE/cpu-runtime.js` — createCPU, createPeripheralBus
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary
- `TI-84_Plus_CE/probe-phase274-0846ea-dispatch-scan.mjs` — previous probe

## Probe structure
```javascript
import { readFileSync } from 'fs';
import { createCPU, createPeripheralBus } from './cpu-runtime.js';

const rom = readFileSync(new URL('./ROM.rom', import.meta.url));

// Static scan for CALL/JP 0x0846EA
const patterns = [
    { name: 'CALL', bytes: [0xCD, 0xEA, 0x46, 0x08] },
    { name: 'JP', bytes: [0xC3, 0xEA, 0x46, 0x08] },
];

for (const pat of patterns) {
    for (let i = 0; i < rom.length - 4; i++) {
        if (rom[i] === pat.bytes[0] && rom[i+1] === pat.bytes[1] && rom[i+2] === pat.bytes[2] && rom[i+3] === pat.bytes[3]) {
            const afterCall = i + 4;
            const postBytes = Array.from(rom.slice(afterCall, afterCall + 20));
            console.log(`${pat.name} 0x0846EA at 0x${i.toString(16).padStart(6,'0')}  post-bytes: ${postBytes.map(b=>'0x'+b.toString(16).padStart(2,'0')).join(' ')}`);
        }
    }
}
```
