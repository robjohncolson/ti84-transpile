# Task: DECODE 0x082C50 — Called by 0x0990AB list init, reads element count/metadata

## Context
You are working on TI-84 Plus CE ROM transpilation. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

## What we know
- 0x082C50 is called by 0x0990AB (list init sub, ~40B) which is called by 0x09903E (list element iterator, ~109B)
- 0x0990AB inits D02563 (element counter) and calls 0x082C50 — so 0x082C50 likely reads element count or list metadata
- 0x09903E iterates list elements: CALL 0x069A67 per-element dispatch, LDIR element copy, writes '{'/space to buffer, updates D00335, DJNZ-style loop
- Key RAM from list iteration: D02563 (element counter), D02565 (iteration BC metadata), D00687 (iteration HL pointer copy), D00335 (output buffer pointer)
- The TI-OS uses 11-byte FP entries (9-byte BCD mantissa + 2-byte metadata). Lists are stored as: 2-byte element count + N×9-byte FP entries (or 11-byte with type prefix)
- 0x082C50 may also be a general-purpose "read variable header" function used elsewhere

## Your task

   - Reads ROM from `TI-84_Plus_CE/ROM.rom`
   - Disassembles starting at 0x082C50 for up to 0x400 bytes main, 0x80 bytes per sub-call
   - Full eZ80 decoder (CALL/JP/JR/RET/conditional, IX/IY, ED, CB, .SIS, LD variants, ALU ops, BIT/SET/RES)
   - Tracks CALL targets, JP targets, RAM reads/writes (≥0xD00000), flag operations
   - Prints disassembly listing + summary
