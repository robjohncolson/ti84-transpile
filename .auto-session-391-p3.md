# Task: Trace 0x08C308 (LCD Mode Selector)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js`.

Session 390 discovered that the VRAM rectangle-fill routine at 0x09EF44 calls 0x08C308 to determine 8bpp vs 16bpp LCD mode. The VRAM stride depends on the color depth — 8bpp = 160 bytes/row, 16bpp = 320 bytes/row. Understanding what 0x08C308 reads is needed for correct VRAM rendering in the browser shell.

## Deliverables

Write a probe file `TI-84_Plus_CE/probe-phase391-trace-08C308.mjs` that:

1. **Statically disassembles 0x08C308** using the eZ80 decoder. Start at 0x08C308, decode until RET or 80 instructions. Print each instruction with address, hex, mnemonic.

2. **Identify what port or RAM it reads** — look for IN instructions (port reads) or LD A,(addr) / BIT instructions that test a flag. The function likely reads an LCD control register (port 0xE00018 or 0xF80018) or a RAM flag.

3. **Determine return value meaning** — does it return a flag in A? Set carry/zero? The caller (0x09EF44) uses this to choose between 8bpp and 16bpp paths.

4. **Find all callers** — scan ROM for CALL 0x08C308 (CD 08 C3 08) and JP 0x08C308 (C3 08 C3 08). Report addresses and count.

5. **Dynamic trace** (bonus) — boot the calculator using cpu-runtime.js and trace execution through 0x08C308 to see what value it returns during normal boot. Use this pattern:

```javascript
import { createCPU, createMemory, loadROM } from './TI-84_Plus_CE/cpu-runtime.js';
import { createPeripheralBus } from './TI-84_Plus_CE/peripherals.js';
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const mem = createMemory();
loadROM(mem, rom);
const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(mem, peripherals);
// ... boot and trace
```

Check the actual exports of cpu-runtime.js and peripherals.js before using them — read the first ~30 lines of each file to find the export names.
