# Auto-Session 191 P2: Seed STAT Path Missing Blocks + Retranspile + Probe

## Context
Session 190 probed all 6 STAT context entries. Entry 4 (0x058BA9 = cxErrorEP) reached STAT computation area (0x091Exx, 0x0921AD) but hit MISSING BLOCK at 0x092263. Entry 5 (0x058C01 = cxSizeWind) had NO transpiled block at all. This task seeds those missing addresses and retranspiles to extend the STAT path.

## Task

### Step 1: Add seeds to phase200-seeds.txt
Append these 3 addresses to the END of `TI-84_Plus_CE/phase200-seeds.txt`:

```

0x092263
0x058C01
0x058BA9
```

Note: 0x058BA9 is the entry point for context entry 4 itself (it may already be a seed via another path, but adding it is safe — duplicates are handled). 0x092263 is the missing block that entry 4 hit. 0x058C01 is entry 5 with no block.

### Step 2: Retranspile
Run: `node scripts/transpile-ti84-rom.mjs`

This takes ~2 seconds. Report the new seed count and block count from the output. Previous: 50,062 seeds, 145,846 blocks.

### Step 3: Verify golden regression
Run: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs`

Must pass 26/26 cells, status dots, Normal/Float/Radian. If it FAILS, revert the seed additions immediately:
```bash
git checkout -- TI-84_Plus_CE/phase200-seeds.txt
node scripts/transpile-ti84-rom.mjs
```
And report the failure.

### Step 4: Build extended STAT probe
Create `TI-84_Plus_CE/probe-phase191-stat-extended.mjs` that:

1. Boots (same pattern as `probe-phase190-stat-context-entries.mjs` — boot → kernelInit → postInit → memInit)
2. Enters context entry 4 (0x058BA9) with A=0x31 (STAT key), IX=0xD1A860, tracing up to 1000 steps (increased from 500)
3. Logs every unique block PC visited
4. Reports if 0x092263 is now reached and what happens after it
5. Also tries entry 5 (0x058C01) with same setup, 1000 steps
6. Dumps any RAM writes in range 0xD00000-0xD01000

Use the same boilerplate/structure as `probe-phase190-stat-context-entries.mjs` for the boot sequence, executor creation, and helper functions.

Run the new probe: `node TI-84_Plus_CE/probe-phase191-stat-extended.mjs`
