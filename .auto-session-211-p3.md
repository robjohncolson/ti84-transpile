# Auto-Session 211 — P3: Full STAT probe with late-seed 0xD01508 fix, trace 5000+ steps

## Context
This is the TI-84 Plus CE ROM transpilation project. Session 210 discovered the ROOT CAUSE of STAT crashes: address `0xD01508` (list pointer table base) reads as 0x000000 because it's uninitialized. This causes InsertMem's LDDR at `0x092263` to copy ~3 million bytes, corrupting all RAM.

The fix: seed `0xD01508 = 0xD01600` AFTER the context installer's `CALL 0x091E13` returns (approximately step 82). Session 210 confirmed this allows the STAT pipeline to continue 500+ steps, but only traced briefly.

Key addresses:
- STAT entry (cxErrorEP): `0x058BA9`
- Context installer: `0x091E13`
- InsertMem: `0x092226`
- InsertMem LDDR: `0x092263`
- List pointer table base: `0xD01508`
- List data (L1): `0xD01600` (3-element list: 1.0, 2.0, 3.0)
- STAT struct: `0xD008E6`
- BufInsert: `0x05E2A0`
- Event loop block: `0x082BE2`
- OP1: `0xD005F8` (9 bytes)

## Reference: BCD float format
```
byte 0: flags (0x00 = positive real)
byte 1: exponent (0x80 = 10^0, 0x81 = 10^1, etc.)
bytes 2-8: BCD digits (2 per byte, e.g. 10 = 0x10 0x00...)
```
