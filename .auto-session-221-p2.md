# Auto-Session 221 P2: Find GetKey scan-to-keycode conversion table in ROM

## Context

We are reverse-engineering the TI-84 Plus CE OS ROM (eZ80, 4MB at `TI-84_Plus_CE/ROM.rom`). Session 220 built a complete _GetCSC scan code map: 49 active scan codes (0x00-0x67) across 7 rows. But scan codes ≠ key codes — the OS uses _GetKey (0x04AB5D) to convert scan codes (0x00-0x67) to key codes (0x5A-0xFF range). The ConvKeyToTok primary table at 0x05BF84 is indexed by key code, not scan code.

We need to find the scan-to-keycode conversion table that _GetKey uses internally.

## Task

Build a probe `TI-84_Plus_CE/probe-phase221-getkey-scan-to-keycode.mjs` that:

1. **Disassemble _GetKey (0x04AB5D) and _GetCSC (0x04AB65)**: Disassemble 256 bytes starting at each address. Look for:
   - Table lookup patterns: `LD HL,nnnn` followed by `ADD A,L` or indexed addressing
   - Any reference to a ROM address that could be a 64-entry or 128-entry lookup table
   - CP/JR/JP branches that classify scan codes by range

2. **Dynamic trace of GetKey with known scan codes**: Using the transpiled ROM:
   - Boot the system (z80 boot → kernelInit → postInit → memInit → home screen stages 1-4)
   - Set up the keyboard matrix so that _GetCSC returns a specific scan code (e.g., 0x94 for digit '5')
   - Call _GetKey at 0x04AB5D and trace execution for 500 steps
   - Record what table addresses are loaded (any LD HL,nnnn instructions), what A transformations happen
   - Capture the return value (key code in A register)
   - Repeat for 3-5 different scan codes to see the pattern

3. **Search for conversion tables**: Scan ROM near _GetKey (0x04AB00-0x04AC00) and in the data region after the code for byte sequences that could be a scan-to-keycode mapping table. A table would have 64+ entries where values are in the 0x00-0xFF range, and many entries map to the 0x5A-0xFF key code range.

## Keyboard matrix setup

The keyboard matrix in peripherals.js uses `keyMatrix[N]` where N=0-7. To inject scan code S:
- Row = S >> 4 (upper nibble, 0-6)
- Bit = S & 0x07 (lower 3 bits)
- Matrix index = 7 - row (SDK Group(7-N) convention)
- Set: `peripherals.keyMatrix[7 - row] |= (1 << bit)`
