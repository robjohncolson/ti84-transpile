# Task: Trace Kernel Init Alternative Path

## Context
The TI-84 Plus CE kernel init boot trace (from session 342's probe-phase342-kernel-init-z80-009006.mjs) shows that after adding the z80-mode seed at 0x009006, execution from 0x000000 still does NOT reach 0x009006 within 2M steps. Instead it takes this path:

0x000000 → ... → RST 0x38 → 0x000080 → 0x001768 → 0x000804 → 0x000066 → 0x0008BB → 0x0019B5

Session 340 showed that at some point in kernel init, a RST 0x38 returns to 0x00001A in z80 mode, which was previously a missing block (now has a seed from session 341). But the boot probe from session 342 shows execution goes to 0x001768 instead.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase343-boot-branch-trace.mjs` that:

1. Loads the transpiled ROM: `import ROM from './ROM.transpiled.js'` (gunzip first if needed, or use the uncompressed version)
   - Actually, use the approach from existing probes: `import { createCPU } from './cpu-runtime.js'` and `import { createPeripheralBus } from './peripherals.js'`
2. Creates a CPU with timer interrupts disabled: `createPeripheralBus({ timerInterrupt: false })`
3. Executes from 0x000000 with per-instruction tracing for the first 1000 steps
4. At each step, records: PC, instruction mnemonic, any branch/call targets
5. Specifically identifies:
   - The RST 0x38 instruction and where it returns to
   - Any conditional branch (JR NZ, JR Z, JP NZ, JP Z, CALL NZ, CALL Z, RET NZ, RET Z) and what the condition flag state was
   - The address 0x0006A9 (or nearby) where the PLL path diverges
6. For each conditional branch in the first 200 instructions, prints: address, instruction, condition result (taken/not taken), and what the alternative path would be

## Technical Details
- Use the same probe pattern as `TI-84_Plus_CE/probe-phase340-kernel-halt-trace.mjs` (read that file for the API pattern)
- CPU API: `cpu = createCPU(rom, peripheralBus)`, `cpu.step()` executes one instruction, `cpu.registers.PC` is program counter
- The cpu-runtime exposes: `cpu.registers` (PC, SP, A, F, B, C, D, E, H, L, IX, IY, etc.), `cpu.memory` (Uint8Array)
- Timer interrupts MUST be disabled: `createPeripheralBus({ timerInterrupt: false })`
- ROM file: `TI-84_Plus_CE/ROM.rom`
