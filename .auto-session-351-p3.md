# Task: Check if Block 0x0012CA Exists + Boot Path After RET PO

## Context
The TI-84 CE boot is stuck in a loop. Session 350 identified that block 0x0006A9 ends with `JP 0x0012CA`. If block 0x0012CA does NOT exist in the transpiled output, execution would hit `missing_block` and restart — even if RET PO is fixed.

Additionally, there may be other blocks in the forward path (after the PLL/flash polling loop) that are missing.

## Your Task

1. **Check if block 0x0012CA exists** in `TI-84_Plus_CE/ROM.transpiled.js`. Search for `block_0x0012CA` or equivalent naming.

2. **Check the transpiler seed list** in `scripts/transpile-ti84-rom.mjs` — is 0x0012CA included as a seed? If not, it might still be discovered by CFG analysis.

3. **Check the report** `TI-84_Plus_CE/ROM.transpiled.report.json` — does it list 0x0012CA as a generated block?

4. **If 0x0012CA is missing**: Check what's at ROM address 0x0012CA by reading the raw ROM bytes. Determine if it's valid code that should be transpiled. If so, note that a seed needs to be added.

5. **Also check these related addresses** that appear in the post-PLL boot path (from session 350 disassembly):
   - 0x0019B5 (JP target from 0x000704)
   - 0x0019BE (JP NZ target)
   - 0x02010C (JP target)
   - 0x001713 (CALL target)

6. **Write findings to `TI-84_Plus_CE/probe-phase351-missing-blocks.mjs`** as a Node.js script that:
   - Loads ROM.transpiled.js
   - Checks if each of the above addresses has a corresponding block
   - Reports: EXISTS or MISSING for each
   - If any are missing, reads ROM bytes at that address and does a basic decode of the first few instructions

## Key Files
- `TI-84_Plus_CE/ROM.transpiled.js` — search for block names
- `TI-84_Plus_CE/ROM.transpiled.report.json` — block list
- `scripts/transpile-ti84-rom.mjs` — seed list (look for `seeds` array or similar)
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary
- `TI-84_Plus_CE/ez80-decoder.js` — instruction decoder (can be used to decode raw bytes)

## Constraints
- Do NOT modify any existing files
- Only CREATE `TI-84_Plus_CE/probe-phase351-missing-blocks.mjs`
- Must be runnable with `node TI-84_Plus_CE/probe-phase351-missing-blocks.mjs`

## Success Criteria
- Clear report of which blocks exist and which are missing
- For missing blocks: what ROM bytes are at that address (first 8-16 bytes hex dump + basic decode)
- Actionable: if blocks are missing, state "ADD SEED 0x______ to transpiler" for each
