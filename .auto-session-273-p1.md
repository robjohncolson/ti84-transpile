# Auto-Session 273 P1: Disassemble 0x09F736 (post-VRAM-fill continuation)

## Context
We're investigating the TI-84 Plus CE OS event loop dispatch table initialization. The function at 0x09E2EC enters a VRAM fill loop at 0x09EFDE (DJNZ copy loop, ~960 iterations). After the fill completes, execution does `POP BC / POP DE / POP HL → JP 0x09F736`. We need to know what 0x09F736 does — it's the post-VRAM-fill continuation and may contain the dispatch table registration code.
