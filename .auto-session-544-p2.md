# Task: Decode 0x06B9E8 — Equation Lookup for Type 0x11 Errors

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). You need to decode the function at address 0x06B9E8 which is the "equation lookup" function called from the error display init at 0x03EBB0 specifically for type 0x11 (equation/Y-var) errors.

From session 543: In `0x03EBB0`, when the error context type (from D00813) AND 0x3F equals 0x11:
- POP AF → CALL 0x06B9E8 (equation lookup) → LD A,(HL) — so 0x06B9E8 returns a pointer in HL to the equation variable name

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase544-decode-06B9E8.mjs` that:
1. Reads the ROM binary
2. Uses `decodeInstruction` from `./ez80-decoder.js` to decode instructions starting at 0x06B9E8
3. Decodes up to 50 instructions or until hitting a RET/JP that's clearly a function end
4. Prints each instruction with address, hex bytes, and assembly mnemonic
5. For any CALL targets or memory references, note what they might be (known addresses: D005F8=OP1, D00603=OP2, D0060E=OP3, D00080=IY base, D00813=error context)
6. Searches for xrefs to 0x06B9E8 in the ROM (scan for CD E8 B9 06 pattern)
7. Also check the bytes immediately before 0x06B9E8 (say 16 bytes before) to see if 0x06B9E8 is mid-function or a true entry point

## Technical Details
- Import: `import { decodeInstruction } from './ez80-decoder.js';`
- ROM read: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');`
- Decoder call: `const inst = decodeInstruction(rom, address, 'adl');` — returns object with `.tag`, `.size`, and various fields
- Use `rom.slice(addr, addr + inst.size)` for hex bytes
- Third parameter is the string `'adl'` (NOT an integer)

## Constraints
- Do NOT modify any existing files
- Do NOT import `createEz80Decoder` — use `decodeInstruction` directly
- Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase544-decode-06B9E8.mjs`
- NEVER run the probe bare — always use the watchdog wrapper

## Success Criterion
The probe runs successfully and prints a complete instruction listing showing how 0x06B9E8 looks up an equation variable name and returns a pointer in HL.
