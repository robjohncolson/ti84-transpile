# Task: Full 10-Row Screen Fill (260 Characters)

## Context

The TI-84 Plus CE ROM transpilation project has verified multi-row text rendering through 3 rows (54 characters) in session 485. The character output function at 0x0059C6 renders characters to VRAM with:
- D00595 = cursor row (0-9), D00596 = cursor column (0-25)
- 26 columns per row, 10 rows total
- Line wrap: D00596 wraps at 26, D00595 increments
- Row wrap: D00595 should wrap at 10 (back to 0)
- VRAM formula: `0xD40000 + (row×20+37)×640 + (col×12+2)×2`
- Row VRAM spacing = 12800 bytes (20 pixel rows × 640 bytes/row)

## Goal

Create a probe that renders all 260 characters (10 rows × 26 columns) to verify:
1. D00595 advances 0→1→2→...→9→0 (wraps at 10)
2. D00596 wraps correctly at 26 for every row
3. All 260 characters produce VRAM writes
4. Total VRAM bytes ≈ 25000 (260 chars × ~96 bytes each)
5. The full screen fills correctly
