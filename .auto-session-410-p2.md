## eZ80 Instruction Reference (key opcodes)
- C3 xx xx xx = JP addr24
- CD xx xx xx = CALL addr24  
- C9 = RET
- DD = IX prefix
- FD = IY prefix
- ED = extended prefix
- CB = bit operations prefix
- 3E xx = LD A, imm8
- 21 xx xx xx = LD HL, imm24
- DD 7E xx = LD A, (IX+d)
