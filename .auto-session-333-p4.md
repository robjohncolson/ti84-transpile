## eZ80 reference
- `CALL addr` = 0xCD + 3-byte LE address (in ADL mode)
- To find the CALL 0x053396 instruction: look for bytes `CD 96 33 05` at each caller address
- Subtract the caller address from the CALL instruction location to find how far into the caller's body the call is
