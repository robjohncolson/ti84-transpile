# Task: Add Seeds 0x05D4BB, 0x003CC2, 0x003D5A, 0x003A73 and Retranspile

## Context
The TI-84 CE ROM transpilation project needs new seeds added to `TI-84_Plus_CE/phase200-seeds.txt` and a retranspile to generate blocks for newly discovered code regions.

### Why these seeds matter:
- **0x05D4BB**: The only ROM reference to RAM address 0xD14096. Session 366 found this is a base-address calculation (LD BC,0xD14096; ADD HL,BC; LD (HL),A). Adding this seed may unlock the path that properly initializes the linked-list pointer before 0x00BC47 runs (the SP corruption root cause).
- **0x003CC2**: _GetCSC keyboard scan entry point discovered in session 366. The OS calls this from 0x003A73 → 0x003C63 → 0x003CC2 as part of the main event loop.
- **0x003D5A**: Another _GetCSC keyboard scan address. Part of the scan routine.
- **0x003A73**: The main event loop caller that invokes _GetCSC. This is the OS event loop entry point.

## Your task

Append these 4 lines to the END of `TI-84_Plus_CE/phase200-seeds.txt`:

```
0x05D4BB
0x003CC2
0x003D5A
0x003A73
```
