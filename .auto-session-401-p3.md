# Task: INVESTIGATE 0x05D5C2 TABLE INITIALIZER CALLERS

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

In session 400, we decoded the key action dispatcher at 0x05D58F. Its second entry point at 0x05D5C2 stores a table base pointer to RAM address 0xD1441D and zeros 0xD14084. This is the TABLE INITIALIZER — different application contexts call it to install their own key action tables. Understanding WHO calls 0x05D5C2 reveals WHICH application contexts install WHICH key action tables.

## Task
Write a probe script `TI-84_Plus_CE/probe-phase401-05D5C2-callers.mjs` that:

1. Reads the ROM file at `TI-84_Plus_CE/ROM.rom`
2. First, disassemble 0x05D5C2 itself (~32 bytes) to confirm the table initializer logic. Expected: stores HL (or DE) to 0xD1441D, zeros 0xD14084, RET.
3. Search the entire ROM for ALL callers:
   - CALL 0x05D5C2: search for bytes CD C2 D5 05
   - JP 0x05D5C2: search for bytes C3 C2 D5 05
   Report ALL addresses found.
4. For each caller found (up to 10), read ~32 bytes before the CALL/JP instruction to see what value is being loaded into the register that becomes the table pointer. Look for patterns like:
   - LD HL,nnnnnn (21 xx xx xx) before the CALL — the table address
   - LD DE,nnnnnn (11 xx xx xx) before the CALL
5. For each table address found, read the first 16 bytes (4 entries × 4 bytes each) from that ROM address and report the raw hex. Each 4-byte entry likely contains a 3-byte handler address + 1-byte parameter (or similar).
6. Also search for references to RAM address 0xD1441D (the table pointer variable):
   - Search for bytes 1D 44 D1 in the ROM
   Report all sites — these are reads/writes of the table pointer.
7. Decode eZ80 instructions manually. Key opcodes:
   - 0xCD = CALL nn, 0xC3 = JP nn, 0xC9 = RET
   - 0x21 = LD HL,nn, 0x11 = LD DE,nn
   - 0x22 nn = LD (nn),HL, 0xED 53 nn = LD (nn),DE
   - 0x36 = LD (HL),n, 0x77 = LD (HL),A
   - 0xAF = XOR A (sets A=0)
   - 0x32 nn = LD (nn),A
8. Print all findings clearly.

## Deliverables
