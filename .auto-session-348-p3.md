# Auto-Session 348 — Priority 3: Map Interrupt Controller (Ports 0x5014-0x5016, 0x5008-0x500A)

## Context

After the HALT at 0x0019BD wakes (via NMI), the post-HALT code at 0x0019BE reads interrupt controller status registers and acknowledges pending interrupts. From session 347's disassembly:

```
0x0019BE: LD.SIS BC,0x5015    ; port 0x5015 (interrupt status byte 1)
0x0019C2: IN A,(C)            ; read status
...
; Also reads ports 0x5014, 0x5016
; Acknowledges via writes to ports 0x5009, 0x5008, 0x500A
; Eventually does EI + RETI at 0x001A48
```

These ports are the TI-84 CE interrupt controller:
- 0x5014: interrupt status register 0 (read)
- 0x5015: interrupt status register 1 (read)  
- 0x5016: interrupt status register 2 (read)
- 0x5008: interrupt acknowledge register 0 (write)
- 0x5009: interrupt acknowledge register 1 (write)
- 0x500A: interrupt acknowledge register 2 (write)

There may also be enable/mask registers at 0x5000-0x5002 or similar.

## Task

1. Write a probe `TI-84_Plus_CE/probe-phase348-interrupt-controller.mjs` that:
   - Disassembles ROM bytes from 0x0019BE to 0x001A50 (the full post-HALT interrupt handler)
   - Identifies every port read/write in that range
   - Documents the interrupt controller register map based on what the code accesses
   - Cross-references: search ROM.rom for other IN/OUT instructions using ports 0x5000-0x501F (read 0x000000-0x3FFFFF looking for `ED 78` / `ED 79` with preceding `LD BC,0x50xx` patterns, or `ED 38 xx` / `ED 39 xx` IN0/OUT0 patterns)
   
2. Check `TI-84_Plus_CE/peripherals.js` for existing interrupt controller port handling:
   - If ports 0x5014-0x5016 and 0x5008-0x500A are NOT already modeled, add them
   - Status registers (0x5014-0x5016): return 0x00 by default (no pending interrupts)
   - Acknowledge registers (0x5008-0x500A): accept writes silently (acknowledge = clear bits)
   - If there are enable/mask registers found in the ROM scan, model those too (default 0x00 = all masked)

3. Report: list ALL interrupt controller ports found in the ROM scan, classified as:
   - Status (read): which bits are tested
   - Acknowledge (write): which bits are cleared
   - Enable/Mask (read/write): which bits control interrupt sources
