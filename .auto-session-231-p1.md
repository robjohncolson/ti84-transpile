# Auto-Session 231 — P1: Trace 0x030300 IY+29 Bit 0 Gate

## Context
ROM address 0x030300 is a key repeat timer setup function called by 0x02FE84 (special key path for mode-change tokens 0xE2-0xFB). Session 230 decoded its behavior:
- BIT 0,(IY+29) gate — if SET, returns early WITHOUT timer setup
- If CLEAR: RES 3,(IY+8) → CALL 0x040D11 (key repeat timer: D00591 set to delay values)

## Task
Create a probe `TI-84_Plus_CE/probe-phase231-iy29-bit0-writers.mjs` that:

1. **Static ROM scan**: Search the ROM binary for all references to IY+29 (offset 0x1D from IY base 0xD00080, so RAM address 0xD0009D). Find:
   - All `SET 0,(IY+29)` instructions (opcode: `FD CB 1D C6`)
   - All `RES 0,(IY+29)` instructions (opcode: `FD CB 1D 86`)
   - All `BIT 0,(IY+29)` instructions (opcode: `FD CB 1D 46`)
   - All `LD (IY+29),imm8` instructions (opcode: `FD 36 1D xx`)
   - All direct writes to 0xD0009D: search for `32 9D 00 D0` (LD (0xD0009D),A) and `ED 43 9D 00 D0` patterns

2. **Classify each site**: For each found address, read 16 bytes before and after to determine context (which function it's in, what condition gates it).

3. **Boot value check**: After full boot (z80 boot → kernelInit → memInit → homescreen), read the byte at 0xD0009D and report the value.

4. **Output**: Print a structured summary:
   - Total SET/RES/BIT/LD sites with ROM addresses
   - Boot value of 0xD0009D
   - Classification of each write site (SET vs RES vs LD)
