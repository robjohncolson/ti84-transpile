# Auto-Session 300 P1: Trace the Event Loop Keyboard Path End-to-End

## Context
The TI-84 Plus CE ROM transpilation project has decoded the keyboard scanner invocation chain:
- ISR entry at 0x001401: `CALL NZ,0x015930` conditionally invokes the scanner wrapper
- 0x015930 is a wrapper that eventually does `LD IX,0x0159BD; CALL 0x000D7E`
- 0x000D7E copies 282 bytes of scanner code from ROM to RAM (~0xD18B62) and executes it via `JP (IX)`
- Scanner writes scan code to 0xD00587
- `_GetCSC` at 0x03FA09 reads 0xD00587

## Task
Write a probe `TI-84_Plus_CE/probe-phase300-event-loop-kbd-trace.mjs` that traces the COMPLETE event loop path from ISR entry to application-level key processing. Specifically:

1. **WHO CALLS 0x001401?** — Disassemble the ISR vector and trace how execution reaches 0x001401. The ISR is at the eZ80 interrupt vector (typically 0x000038 or wherever the IM 2 vector points). Check the ROM bytes at the interrupt vector and trace the dispatch chain to 0x001401.

2. **How does _GetCSC output feed into CoorMon/cxMain?** — We know:
   - `_GetCSC` is at 0x03FA09 (OS jump table entry)
   - CoorMon is at 0x058757 (the main event loop coordinator)
   - cxMain is at 0x0589E5 (key dispatch in the main context)
   - The event loop calls _GetCSC, gets a scan code in register A, then dispatches

   Trace: after _GetCSC returns with A = scan code, what happens? Where does CoorMon branch? How does the scan code become a token? Disassemble the path from _GetCSC return → CoorMon decision → cxMain entry.

3. **Document the complete chain** in a comment block at the top of the probe.

## How to disassemble
Read ROM bytes from `TI-84_Plus_CE/ROM.rom` (4MB binary). eZ80 instructions — use the same disassembly approach as existing probes. See `TI-84_Plus_CE/probe-phase299-getCSC-callers.mjs` for reference on how to read ROM bytes and format output.

  - Reads ROM.rom
  - Disassembles the ISR vector chain → 0x001401
  - Disassembles the _GetCSC return → CoorMon → cxMain path
  - Prints the complete chain as structured output
