# Task: Decode 0x08A6F0 Internal Logic (cxMain Handler)

## Context
We're transpiling the TI-84 Plus CE ROM (eZ80) to JavaScript. Session 480 discovered that 0x08A6F0 and 0x08B2AE are cxMain handlers — they have ZERO direct callers and are dispatched via JP (HL) at 0x08C745 using the D007CA context handler table.

0x08A6F0 first calls 0x08A7BE which reads D007E0 (mode variable) and compares to 'W' (0x57). 0x08A7BE has exactly 2 callers: 0x08A6F0 and 0x08B2AE.

We need to fully decode what 0x08A6F0 does AFTER CALL 0x08A7BE — what flag tests, what dispatch branches, what functions it calls for home screen mode ('H', 0x48).

## Deliverable
Create `TI-84_Plus_CE/probe-phase481-decode-08A6F0.mjs` that:

1. Does a ROM hex dump of bytes at:
   - 0x08A6F0 - 0x08A780 (144 bytes) — the main function body
   - 0x08A7BE - 0x08A830 (114 bytes) — the mode comparator subroutine
   - 0x08B2AE - 0x08B340 (146 bytes) — the other cxMain handler for comparison

2. Does 3-stage boot (0x080000, 0x0802B2, 0x08C331, each 150K steps)

3. Installs 0x08A6F0 into the cxMain handler table at D007CA:
   ```javascript
   // D007CA = cxMain handler (3-byte address)
   write24(0xd007ca, 0x08a6f0);
   ```

4. Sets home mode state (D007E0=0x48, D00824=0x48, etc.)

5. Calls the cxMain dispatcher at 0x08C739 (or directly calls 0x08A6F0) with a FAKE_RET sentinel

6. Tracks ALL unique PCs visited during execution (first 200 unique blocks) to map the full dispatch tree

7. Reports: which PCs were hit, in what order, hit counts, and any RAM state changes at D007xx and D008xx

## Template Pattern
```javascript
import { readFileSync } from "node:fs";
import { createExecutor } from "./cpu-runtime.js";
import { createPeripheralBus } from "./peripherals.js";
import { PRELIFTED_BLOCKS } from "./ROM.transpiled.js";

const MEM_SIZE = 0x1000000;
const STACK_RESET_TOP = 0xd1a87e;
const FAKE_RET = 0xfedcba;

const mem = new Uint8Array(MEM_SIZE);
const rom = readFileSync(new URL("./ROM.rom", import.meta.url));
mem.set(rom.subarray(0, MEM_SIZE), 0);
const peripherals = createPeripheralBus();
const executor = createExecutor(PRELIFTED_BLOCKS, mem, { peripherals });

function runFrom(pc, steps, onBlock) {
  return executor.runFrom(pc, "adl", { maxSteps: steps, maxLoopIterations: 200000, onBlock });
}
function hex(v, w = 6) { return "0x" + (v >>> 0).toString(16).toUpperCase().padStart(w, "0"); }
function write24(addr, val) {
  mem[addr & 0xffffff] = val & 0xff;
  mem[(addr + 1) & 0xffffff] = (val >>> 8) & 0xff;
  mem[(addr + 2) & 0xffffff] = (val >>> 16) & 0xff;
}

// 3-stage boot
runFrom(0x080000, 150000);
runFrom(0x0802b2, 150000);
runFrom(0x08c331, 150000);

// Mode state
mem[0xd00824] = 0x48;
mem[0xd007e0] = 0x48;
mem[0xd14091] = 0x01;
executor.cpu.mbase = 0xd0;
executor.cpu._iy = 0xd00080;
```

For hex dump:
```javascript
function hexDump(start, length) {
  console.log(`\nROM dump ${hex(start)} - ${hex(start + length)}:`);
  for (let i = 0; i < length; i += 16) {
    const addr = start + i;
    const bytes = [];
    for (let j = 0; j < 16 && i + j < length; j++) {
      bytes.push(mem[addr + j].toString(16).padStart(2, '0'));
    }
    console.log(`  ${hex(addr)}: ${bytes.join(' ')}`);
  }
}
```

For tracking all visited PCs:
```javascript
const visited = new Map();
let order = 0;
runFrom(0x08a6f0, 100000, (pc) => {
  const blockPc = pc & 0xffffff;
  if (blockPc === FAKE_RET) return "stop";
  if (!visited.has(blockPc)) {
    visited.set(blockPc, { first: order++, hits: 0 });
  }
  visited.get(blockPc).hits++;
});
```

Set up the call with FAKE_RET on the stack so the function returns to our sentinel.
