## Target
Find the **index table** that maps error codes (0x81-0x9D range, stored at D008DF) to the error string addresses discovered in session 541:
- 0x06244E: "DOMAIN"
- 0x06256F: "SYNTAX"
- 0x0626F9: "INVALID DIMENSION"

## What We Know
- Error code dispatch table at 0x061D00-0x061DB0 has 44 entries (LD A,errCode + JR/JP to shared handler at 0x061DB2).
- Error display routine at 0x03EA5E loads D0081C and does type dispatch (AND 0x3F, CP 0x1A/0x15/0x17).
- The display routine has a computed string pointer path: `LD D,0xEF, HL+2, A=0x50+offset → DE=string addr`.
- The error handler at 0x08356A does `SUB 0x0F` — this might be the error code → index conversion.
- SDK error codes: E_OVERFLOW=0x81, E_DIVBY0=0x82, E_SINGULAR_MAT=0x83, E_DOMAIN=0x84, E_INCREMENT=0x85, E_BREAK=0x86, E_NONREAL=0x87, E_SYNTAX=0x88, E_DATATYPE=0x89, E_ARGUMENT=0x8A, E_DIMMISMATCH=0x8B, E_DIMENSION=0x8C, E_UNDEFINED=0x8D, E_MEMORY=0x8E, E_INVALID=0x8F, E_ILLEGALNEST=0x91, E_BOUND=0x92, E_GRAPHRANGE=0x93, E_ZOOM=0x94, E_LABEL=0x96, E_STAT=0x97.

## Approach
1. Search the ROM for a table of 3-byte (24-bit) addresses near the string region (0x062xxx). Look for consecutive 3-byte little-endian pointers that match the known string addresses.
2. Also search for a table near the error display routine (0x03EA5E-0x03ECFE region) that could be an offset table.
3. Check 0x08356A — the `SUB 0x0F` there converts error code to index; decode the surrounding function.
4. Look for the pattern where error code 0x84 (E_DOMAIN) maps to the first string "DOMAIN" at 0x06244E.

## Probe Template
```javascript
import { readFileSync } from 'fs';
import { createEz80Decoder } from './ez80-decoder.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const decoder = createEz80Decoder(rom);

// Known error string addresses (little-endian in ROM)
const knownStrings = [
    { name: 'DOMAIN', addr: 0x06244E },
    { name: 'SYNTAX', addr: 0x06256F },
    { name: 'INVALID DIMENSION', addr: 0x0626F9 },
    { name: 'UNDEFINED', addr: 0x06278D },
    { name: 'MEMORY', addr: 0x0627C2 },
    { name: 'INVALID', addr: 0x06282E },
    { name: 'WINDOW RANGE', addr: 0x062909 },
    { name: 'ZOOM', addr: 0x06296B },
];

// Search for pointer table: look for 3 consecutive known addresses in ROM
console.log('=== Searching for error string pointer table ===');
for (const s of knownStrings) {
    const lo = s.addr & 0xFF, mid = (s.addr >> 8) & 0xFF, hi = (s.addr >> 16) & 0xFF;
    // Search entire ROM for this 3-byte sequence
    for (let i = 0; i < rom.length - 2; i++) {
        if (rom[i] === lo && rom[i+1] === mid && rom[i+2] === hi) {
            // Check if this is outside the string itself
            if (i < 0x060000 || i > 0x065000) {
                console.log(`  Found pointer to ${s.name} (0x${s.addr.toString(16)}) at ROM offset 0x${i.toString(16)}`);
            }
        }
    }
}

// Decode 0x08356A
console.log('\n=== Decoding 0x08356A (error offset calc) ===');
let pc = 0x08356A;
for (let i = 0; i < 30; i++) {
    const instr = decoder.decode(pc);
    if (!instr) { console.log(`  0x${pc.toString(16)}: ???`); pc++; continue; }
    console.log(`  0x${pc.toString(16).padStart(6, '0')}: ${instr.asm}`);
    pc += instr.length;
    if (instr.asm === 'RET') break;
}
```
