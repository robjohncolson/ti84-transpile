# Task: Map _indcall Dispatch Sites (All Callback Slots Using JP (IY) Trampoline)

## Context
The TI-84 Plus CE ROM has an indirect call mechanism: `_indcall` at 0x00015C executes `JP (IY)`. Two wrapper routines at 0x01322D (13 callers) and 0x041E95 (14 callers) use the pattern: `_frameset0` → `_icmpzero` null-check → `LD IY,(slot_addr)` → `_indcall (JP (IY))`. Session 313 found that 0xD14026 is one such callback slot (entry 49, USB/runtime). We need to find ALL callback slots that use this pattern.

## What to do

1. **Gunzip the transpiled ROM**: `gunzip -kf TI-84_Plus_CE/ROM.transpiled.js.gz`

2. **Find all callers of 0x00015C (_indcall)**. Search `ROM.transpiled.js` for references to address `0x00015c` or `0x15c` (the JP (IY) trampoline). Also search the raw ROM for `CALL 0x00015C` patterns (opcode CD 5C 01 00 in eZ80 ADL mode).

3. **For each caller, extract the callback slot address** — the `LD IY,(addr)` instruction immediately before the CALL to _indcall loads a RAM address. That RAM address is the callback slot. List all unique slot addresses.

4. **For each slot address found**, determine:
   - What writes to it (initialization)
   - How many dispatch sites use it
   - What the slot is likely for (USB, timer, display, etc.) based on context

5. **Also check the two known wrappers** (0x01322D and 0x041E95) — do they each serve a SINGLE slot (0xD14026) or do different callers of the wrapper pass different slot addresses?

6. **Write results** to `TI-84_Plus_CE/phase314-indcall-dispatch-report.md`:
   - Complete list of callback slot RAM addresses
   - For each: writer count, dispatch count, purpose hypothesis
   - Architecture summary: how many total callback slots exist in the OS?

7. **Write a probe** at `TI-84_Plus_CE/probe-phase314-indcall.mjs` that:
   - Loads the ROM binary
   - Finds all CALL 0x00015C sites
   - Extracts preceding LD IY,(addr) to identify slot addresses
   - Prints summary

## Key files

- `TI-84_Plus_CE/ROM.transpiled.js.gz` — gunzip before searching
- `TI-84_Plus_CE/phase313-entry49-callback-report.md` — previous session's callback analysis
