## Target
**0x061DD1** — This address is pushed onto the stack by the setjmp function at 0x061DEF as a "recovery handler". When setjmp sets up the error recovery frame, it pushes:
1. Previous jmp_buf SP from D008E0
2. Context from D0258A/D0258D/D02590/D02593 (error handler chain)
3. **0x061DD1** — recovery handler
4. 0x061E27 — cleanup handler

When an error occurs and longjmp (0x061E20) restores the stack, execution flows through 0x061E27 (cleanup) and eventually may reach 0x061DD1. We need to know what 0x061DD1 does — is it the "normal" recovery path? Does it re-enable interrupts? Clear error state?

## What We Know
- setjmp at 0x061DEF: saves SP to D008E0, pushes chain context + handler addresses, returns to caller
- longjmp at 0x061E20: restores SP from D008E0, RET → cleanup at 0x061E27
- cleanup at 0x061E27 (12B): pops context, restores previous jmp_buf, returns
- error dispatch at 0x061E33 (12B): POP HL×2, LD A,L, LD IY,D00080, JP 0x061DB2
- The error dispatch table at 0x061D00-0x061DB0 has 44 entries that JP to 0x061DB2
- D008DF = error code, D008E0 = saved SP, D0258A-D02593 = handler chain

## Probe Template
```javascript
import { readFileSync } from 'fs';
import { createEz80Decoder } from './ez80-decoder.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const decoder = createEz80Decoder(rom);

function disasm(start, maxBytes, label) {
    console.log(`\n=== ${label} at 0x${start.toString(16).toUpperCase()} ===`);
    const bytes = Array.from(rom.slice(start, start + maxBytes));
    console.log(`Raw: ${bytes.map(b => b.toString(16).padStart(2, '0')).join(' ')}`);
    let pc = start;
    const end = start + maxBytes;
    while (pc < end) {
        const instr = decoder.decode(pc);
        if (!instr) { console.log(`  0x${pc.toString(16)}: ??? (0x${rom[pc].toString(16)})`); pc++; continue; }
        const instrBytes = Array.from(rom.slice(pc, pc + instr.length)).map(b => b.toString(16).padStart(2, '0')).join(' ');
        console.log(`  0x${pc.toString(16).padStart(6, '0')}: [${instrBytes}] ${instr.asm}`);
        pc += instr.length;
        if (instr.asm === 'RET' || (instr.asm.startsWith('JP ') && !instr.asm.includes(','))) break;
    }
}

// The shared handler at 0x061DB2 that all error code dispatchers jump to
disasm(0x061DB2, 40, 'Shared Error Handler (jumped to from 0x061D00-0x061DB0)');

// The recovery handler pushed by setjmp
disasm(0x061DD1, 30, 'Recovery Handler (pushed by setjmp at 0x061DEF)');

// For context: gap between recovery handler and setjmp
disasm(0x061DE0, 20, 'Gap between recovery handler and setjmp');

// Reference: setjmp entry
disasm(0x061DEF, 50, 'Setjmp (reference, decoded session 541)');
```
