# Auto-Session 608 P1 — Selective State Zeroing for Multi-Key Dispatch

## Goal
Create a probe `TI-84_Plus_CE/probe-phase608-selective-zero.mjs` that tests SELECTIVE state zeroing between keys instead of full post-wipe zeroing or full post-paint restore. The hypothesis: zero ONLY the edit buffer pointers that cause the runaway loop, while keeping the cxMain context descriptor and IY flags from the post-paint state. This should give keys 2-3 both cxMain dispatch AND correct halt (no runaway).

## Background
- Session 607 proved: full post-wipe snapshot (all zeros) → keys 2-3 halt correctly (~194K steps) but no cxMain dispatch (D007CA=0).
- Session 607 proved: full post-paint snapshot → keys 2-3 run away at 500K steps due to stale D0243A (editCursorB) causing infinite loop in 0x08F3DC↔0x04C973↔0x090927.
- Session 605 proved: full state restore (post-paint) → cxMain dispatches for all 3 keys, but keys 2-3 run away.

## What to zero (edit buffer pointers that cause runaway)
- D0243A (editCursorB, 3 bytes) — the confirmed root cause of the runaway
- D0243D (editBtm, 3 bytes) — adjacent edit state  
- D02317-D0231F (begPC/curPC/endPC, 9 bytes) — cursor positions
- D0231A (editCursorA, 3 bytes) — already in begPC range but explicitly zero it
- D02440-D02448 (editBtm extended, 9 bytes) — from the extended ranges

## What to KEEP from post-paint snapshot
- D007CA (21 bytes, cxMain context descriptor — 0x0585E9 etc.)
- D0008D (1 byte, mode)
- D0009F (1 byte, eventFlags)
- D00080-D000FF (128 bytes, IY flags)
- D02434 (32 bytes, descriptor block)

## Boot sequence (copy EXACTLY from probe-phase607-postwipe-snapshot.mjs)
1. Cold boot: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
2. Reset halted/iff, set sp=0xD1A87E-3, fill 0xFF, `runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 })`
3. Set mbase=0xD0, _iy=0xD00080, _hl=0, reset halted/iff, sp=0xD1A87E-3, fill 0xFF, `runFrom(0x0802B2, 'adl', { maxSteps: 100, maxLoopIterations: 32 })`
4. Set halted=false, iff1/2=1, _iy=0xD00080, mbase=0xD0, sp=0xD1A87E-12, fill 0xFF, `runFrom(0x0019be, 'adl', { maxSteps: 1_500_000, maxLoopIterations: 100000 })`
5. Launch-init: timer off, halted=false, iff1/2=1, sp=0xD1A87E-24, push 0x0019be, write24 D008E0=sp, `runFrom(0x09DD62, 'adl', { maxSteps: 300000, maxLoopIterations: 30000 })`
6. Paint: timer on, halted=false, sp check, push 0x0019b5 (HALT_IDLE!), `runFrom(0x058241, 'adl', { maxSteps: 300000, maxLoopIterations: 30000 })`
7. Snapshot POST-PAINT state (all the ranges above)

## Key dispatch sequence (for each key)
1. Restore from post-paint snapshot
2. THEN zero the edit buffer pointers: D0243A (3B), D0243D (3B), D02317-D0231F (9B), D02440-D02448 (9B)
3. pressKey: D0058C=scanCode, D0058E=scanCode, D00587=scanCode, D0009F|=0x20, D00080|=0x08
4. halted=false, iff1/2=1, _iy=0xD00080, mbase=0xD0, sp check, push HALT_IDLE, write24(D008E0, sp)
5. `runFrom(0x08C331, 'adl', { maxSteps: 500_000, maxLoopIterations: 500_000, onBlock... })`
6. Track: WIPE (0x0018F8), CX_MAIN (0x0585E9), HALT_IDLE (0x0019B5)
