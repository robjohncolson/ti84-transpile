## Key Architecture

- The transpiled ROM is a collection of `blocks` keyed by address. Import from gunzipped ROM.transpiled.js.
- `executeBlock(cpu, mem, blocks, peripheralBus, startPC)` runs one block, returns `{pc, term, steps}`.
- Loop calling executeBlock with returned pc to run multiple blocks.
- Boot: execute from PC=0x000000 for ~30,000 steps.
- VRAM: 0xD40000-0xD65800 (153,600 bytes = 320×240 pixels × 16bpp ÷ 8).
- mem is a Uint8Array. Use `mem.slice()` to snapshot.

## Important Notes

- Use `diHaltBypass: true` in peripheral bus config — this bypasses DI+HALT dead ends.
- Use `timerInterrupt: false` — timer IRQ hijacks execution.
- 5M steps is important — session 469 only ran ~50 steps and saw no VRAM changes. The display update chain through 0x02FDD8 may require thousands of steps.
- If execution enters an infinite loop (same PC repeating), break early and report the loop address.
