## Reference: TI-OS Variable Type Bytes
Known TI-OS type bytes (from TI documentation):
- 0x00 = Real, 0x01 = Real List, 0x02 = Matrix, 0x03 = Y-Var
- 0x04 = String, 0x05 = Program, 0x06 = Protected Program
- 0x08 = Graph Database, 0x0C = Complex, 0x0D = Complex List
- 0x15 = AppVar, 0x17 = Group, 0x18 = Real Fraction
- High-bit variants (0x80, 0x88, etc.) are often "temp" or "archived" flags
