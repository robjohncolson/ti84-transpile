# Task: Find All D14091 Write Sites and Determine When It Becomes Non-Zero

## Context
This is the TI-84 Plus CE ROM transpilation project. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

D14091 is the **master key-processing enable flag**. The key processor at 0x03FA09 checks D14091 at 0x03FBC7: if D14091 is zero, ALL key writes to D141B5 are blocked. After boot, D14091 = 0x00. Session 446 found 10 write sites, primarily in 0x02xxxx/0x04xxxx mode initialization code. We need to know:

1. What value each site writes (0x00 to clear? 0x01 to enable? Other values?)
2. What function each write site is in
3. When during normal OS startup D14091 becomes non-zero
4. What conditions/mode transitions trigger the enable

## What to do
Create a trace report at `TI-84_Plus_CE/phase447-trace-D14091-report.md`.

### Step 1: Find all references to D14091 in the ROM
Search for the byte pattern for address 0xD14091 in little-endian: `91 40 D1`. This appears in:
- `LD A,(0xD14091)` = `3A 91 40 D1`
- `LD (0xD14091),A` = `32 91 40 D1`
- `LD HL,0xD14091` = `21 91 40 D1`
- `LD BC,0xD14091` = `01 91 40 D1`
- Other register/memory operations with absolute addressing

Write a Node.js script to scan the ROM for all occurrences of `91 40 D1` (the 3-byte LE encoding of 0xD14091) and for each occurrence, dump the surrounding bytes (16 before, 16 after) to help identify the instruction context.

### Step 2: Classify each site
For each reference found:
- Is it a READ (LD A,(D14091), OR/AND/CP with D14091)?
- Is it a WRITE (LD (D14091),A, LD (D14091),HL, etc.)?
- What value is being written? (Check preceding instructions for LD A,n / XOR A / etc.)
- What function contains this site? (Find the nearest preceding RET or function prologue)

### Step 3: Identify the enabling write
Among the write sites, which one(s) write a non-zero value? What function is that in? What mode (home screen init? calculator mode init?) triggers it?

Key addresses to check (from session 446): sites in 0x0489E6-0x048C2D are in the mode init area.

- Each reference classified as READ or WRITE

- Report identifies when during OS startup D14091 transitions from 0 to non-zero
