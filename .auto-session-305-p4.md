# Task: Decode soft-menu string tables at 0x029024/0x02903C

## Context
We are reverse-engineering the TI-84 Plus CE OS ROM. During session 303-304 work on menu handling, addresses 0x029024 and 0x02903C were identified as soft-menu string table locations. These tables likely define the menu labels shown on the TI-84 CE's soft-key menu bar (the labels shown above the function keys at the bottom of the screen).

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase305-softmenu-strings.mjs` that:

1. **Read raw ROM bytes** at 0x029024 and 0x02903C:
   - Dump 128 bytes from each address as hex + ASCII
   - Identify string boundaries (look for null terminators 0x00, or length-prefixed strings)
   - Extract all readable ASCII/menu label strings

2. **Search for cross-references**: 
   - Check if the transpiled ROM references these addresses (grep for `029024` or `02903C` patterns in block names)
   - Find what code reads from these table addresses

3. **Decode the table structure**:
   - How many entries?
   - Fixed-length or variable-length?
   - Are entries indexed directly, or via pointer table?
   - What's the entry format? (just a string? string + metadata bytes?)

4. **Map surrounding context**:
   - What's at 0x029000-0x029023 (before first table)?
   - What's at 0x02905C-0x029080 (after second table)?
   - Are there more tables in the 0x029xxx region?

## Technical setup

```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('./TI-84_Plus_CE/ROM.rom');

// Read ROM bytes directly — no CPU needed for static data analysis
function romByte(addr) { return rom[addr]; }
function romString(addr, maxLen) {
  let s = '';
  for (let i = 0; i < maxLen; i++) {
    const b = rom[addr + i];
    if (b === 0) break;
    s += (b >= 0x20 && b <= 0x7E) ? String.fromCharCode(b) : `[${b.toString(16).padStart(2,'0')}]`;
  }
  return s;
}
```

Also check `TI-84_Plus_CE/ROM.transpiled.js.gz` (gunzip first) or use the transpiler output report for block references.
