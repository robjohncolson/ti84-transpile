# Task: Decode Soft-Float Library (_fmul, _fadd, _fcmp)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

In session 312, we mapped the ZDS II C runtime vector table. The top soft-float entries are:
- `_fmul` at vector 0x000288 → target 0x00372B (71 callers, IEEE 754 soft-float multiply)
- `_fadd` at vector 0x000270 → target 0x003569 (56 callers, soft-float add)
- `_fcmp` at vector 0x000274 → target 0x0035C8 (45 callers, soft-float compare)
- Shared unpacker `_fpunpack` at 0x0034A7 (identified in session 312)

## Task
1. **Disassemble _fpunpack at 0x0034A7** (likely 50-100 bytes). Determine the float format:
   - How many bytes per float? (24-bit or 32-bit IEEE 754?)
   - Where is sign, exponent, mantissa?
   - How are floats passed? (registers? stack? memory pointer?)

2. **Disassemble _fadd at 0x003569** (likely 100-200 bytes). Trace the algorithm:
   - How does it align exponents?
   - How does it add mantissas?
   - How does it normalize the result?

3. **Disassemble _fmul at 0x00372B** (likely 100-200 bytes). Trace the multiply algorithm.

4. **Disassemble _fcmp at 0x0035C8** (likely 30-60 bytes). How does it return comparison results?

5. **Search for _fdiv and _fsub**: Check the vector table area (0x000200-0x000400) for additional float vectors. Also search near the _fadd/_fmul code for _fsub (subtract is often fadd with sign flip) and _fdiv.

6. **Write a probe** at `TI-84_Plus_CE/probe-phase313-soft-float.mjs` that:
   - Disassembles each soft-float function
   - Identifies the float format (byte layout)
   - Lists all soft-float entry points found
   - Tests: verify _fpunpack is called by _fadd, _fmul, _fcmp (check for CALL 0x0034A7 in their bodies)

7. **Write a report** at `TI-84_Plus_CE/phase313-soft-float-report.md`.

## Key Files

- Use `import { decodeInstruction } from './ez80-decoder.js'`
- Probe must run with `node TI-84_Plus_CE/probe-phase313-soft-float.mjs`

## Success Criteria
- Float format identified (bits for sign/exponent/mantissa, byte count)
- All soft-float entry points cataloged (fadd, fsub, fmul, fdiv, fcmp, fpunpack, fpack, etc.)
- _fpunpack call confirmed in fadd/fmul/fcmp bodies
- Probe passes, report written
