# Task: Map the 4-section 09F79B table completely (224 entries)

## Context
Session 229 decoded the key lookup formula at 0x03011C: offset = scanCode + (alpha?0x70:0) + (2nd?0x38:0). The table at 0x09F79B has 4 sections of 56 entries each:
- [0x00-0x37]: no modifier (56 entries)
- [0x38-0x6F]: 2nd modifier (56 entries)  
- [0x70-0xA7]: alpha modifier (56 entries)
- [0xA8-0xDF]: alpha+2nd modifier (56 entries)

Total: 224 entries (bytes). Each entry is a TI-OS key code.

Session 220 mapped 49 active scan codes across 7 keyboard rows (probe-phase220-getCSC-scancode-map.mjs).

## Steps

1. Build a probe `TI-84_Plus_CE/probe-phase230-09f79b-full-table.mjs` that:

   a. Reads ROM.rom directly (use `fs.readFileSync` on `TI-84_Plus_CE/ROM.rom`).

   b. Extracts all 224 bytes starting at ROM offset 0x09F79B (the table base).

   c. For each of the 4 sections (no-mod, 2nd, alpha, alpha+2nd), prints a formatted table:
      - scan_code (0x00-0x37 for each section) → key_code (the byte value) → key_name (human-readable)
      
   d. Cross-references with the keyboard matrix from `TI-84_Plus_CE/keyboard-matrix.md`. The keyboard matrix maps physical keys to scan codes via (group, bit) → scan_code = (idx << 4) | bit. Include the physical key name for each scan code.

   e. For key names, use this reference (TI-84 Plus CE key codes from the SDK):
      - 0x00 = none/unused
      - 0x9A-0xB3 = A-Z letters
      - 0x8E-0x97 = digits 0-9
      - 0x80 = + , 0x81 = - , 0x82 = * , 0x83 = / 
      - 0x84 = ^ , 0x85 = ( , 0x86 = ) , 0x87 = .
      - 0x30-0x39 = token values for digits
      - 0x70 = tAdd, 0x71 = tSub
      - 0xE2+ = special/modifier codes
      - 0xFC+ = special codes (handled by 0x02FE84 path)
      
      Don't try to name all 256 — just name the common ones and mark others as hex.

   f. Output a JSON file `TI-84_Plus_CE/phase230-09f79b-full-table.json` with the complete mapping:
      ```json
      {
        "tableBase": "0x09F79B",
        "sections": {
          "noMod": [ { "scanCode": 0, "keyCode": "0xNN", "keyName": "..." }, ... ],
          "second": [ ... ],
          "alpha": [ ... ],
          "alphaSecond": [ ... ]
        },
        "activeEntries": <count of non-zero entries>,
        "totalEntries": 224
      }
      ```

   g. Print summary statistics:
      - How many non-zero entries per section
      - Key codes in 0xE2-0xFB range (special path codes)
      - Key codes ≥ 0xFC (very special codes)
      - Any scan codes that produce different key codes across all 4 modifier states

2. Run the probe:
   ```bash
   node TI-84_Plus_CE/probe-phase230-09f79b-full-table.mjs
   ```
