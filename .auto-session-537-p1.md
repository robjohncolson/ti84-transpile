## eZ80 conventions
- eZ80 in ADL mode: 3-byte addresses, 3-byte register pairs. Instructions like `LD A,(nn)` use 3-byte nn. `CALL nn` is 4 bytes (opcode + 3-byte addr). `JP nn` is 4 bytes. `JR e` is 2 bytes. `LD r,n` is 2 bytes.
- Prefix bytes: CB = bit ops, ED = extended ops, DD = IX prefix, FD = IY prefix.
- Common patterns: `LD A,(D005F8)` = 3A F8 05 D0. `CALL addr` = CD lo mid hi. `JP addr` = C3 lo mid hi.
- OP registers: OP1=D005F8, OP2=D00603, OP3=D0060E, OP4=D00619, OP5=D00624, OP6=D0062F.
