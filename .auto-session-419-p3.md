## What We Know

### 0x010090
- Called by the display callback dispatcher at 0x010220 before dispatching slot 3 (D177C6)
- 0x010220 is a 388-byte consume-then-rearm pipeline (0x010220-0x0103A3) with 5 callback slots
- Slot 3 is gated by D177D6 bit 3. Before calling the slot 3 callback, 0x010220 calls 0x010090
- The call site is approximately at 0x0102D0-0x0102F0 area (inside the slot 3 dispatch block)
- 0x010090 must end before 0x010220 starts (so it's in the range 0x010090-0x01021F)

### D000BF LCD/DMA Control
- Slot 1 of the display callback dispatcher writes SET 5,(IY+63) where IY=D00080h → target is D000BFh
- This is in the LCD/DMA control region (D00080-D000FF is the system flags area)
- No other slot has this kind of hardware side-effect
- We need to know: what other code reads/writes D000BF? What does bit 5 control?

## eZ80 Reference
- eZ80 Z80 superset, 24-bit addresses, ADL mode
- IY-relative: FD prefix. FD CB dd xx = bit op on (IY+dd). BIT=46/4E/56/.., SET=C6/CE/D6/.., RES=86/8E/96/..
- Standard system IY = 0xD00080, so IY+63 = IY+0x3F = D000BF
- CALL = CD ll mm hh, RET = C9
- LD A,(addr) = 3A ll mm hh, LD (addr),A = 32 ll mm hh
- IN/OUT for port I/O: IN A,(C) = ED 78, OUT (C),A = ED 79
