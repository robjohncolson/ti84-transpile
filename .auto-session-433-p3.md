# Task: Decode 0x03xxxx Low-ROM Wrappers

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 machine code).

Session 432 discovered that the function at 0x0391DC (a parallel descriptor builder in the 0x03xxxx ROM bank) calls through **low-ROM wrapper thunks** in the first 512 bytes of ROM instead of calling helpers directly. The wrappers identified are:

- 0x0000A4 → wraps 0x0027E8 (memcpy)
- 0x000124 → wraps 0x00211B (sparse case dispatcher)
- 0x00012C → wraps 0x002197 (__frameset variant)
- 0x000138 → unknown target
- 0x000204 → unknown target
- 0x000210 → unknown target
- 0x000264 → unknown target

## What to do
1. Disassemble each of the 7 wrapper addresses listed above
2. Each should be a tiny thunk (likely just `JP target_address`, which is 4 bytes: 0xC3 + 3-byte LE address)
3. Document what each wrapper points to
4. Explain WHY 0x03xxxx uses wrappers when 0x00xxxx calls helpers directly (likely: eZ80 CALL range limitation, or ROM bank isolation)
5. Search the first 512 bytes of ROM (0x000000-0x000200) for ALL JP instructions to find the complete wrapper table
6. Also check 0x000200-0x000300 for additional wrappers

## eZ80 reference
- JP nn = 0xC3 followed by 3-byte LE address
- CALL nn = 0xCD followed by 3-byte LE address
- RET = 0xC9
- In ADL mode, addresses are 24-bit (3 bytes, little-endian)
- The eZ80 in the TI-84 CE has a flat 24-bit address space — there is no hardware bank switching. Both 0x00xxxx and 0x03xxxx are in the same 4MB ROM address space.

## Deliverables
1. Create `TI-84_Plus_CE/probe-phase433-low-rom-wrappers.mjs` — a probe that:
   - Reads ROM bytes 0x000000-0x000300
   - Finds all JP instructions (0xC3 byte followed by 3-byte target)
   - For each, prints the wrapper address and its target
   - Specifically decodes the 7 addresses listed above
   - Searches for any pattern explaining WHY wrappers exist

2. Create `TI-84_Plus_CE/phase433-low-rom-wrappers-report.md` — a report documenting:
   - Complete list of wrappers found in 0x000000-0x000300
   - Target address for each wrapper
   - Known function names for targets (0x0027E8=memcpy, 0x00211B=sparse case dispatcher, 0x002197=__frameset, 0x00218A=__frameset, 0x00285F=_bzero, 0x002623=_seqcase, 0x002330=right-shift, 0x00230B=left-shift, 0x0022F9=shift-left-variant, 0x00276B=_stoiu)
