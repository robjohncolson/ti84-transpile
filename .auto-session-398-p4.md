## How Seeds Work
The seeds array in `scripts/transpile-ti84-rom.mjs` looks like:
```javascript
const seeds = [
  0x000000,
  0x000100,
  // ... hundreds of entries
];
```

Each seed is a ROM address where the transpiler starts tracing code. The CFG walker follows CALL/JP/JR targets to discover more blocks from each seed.
