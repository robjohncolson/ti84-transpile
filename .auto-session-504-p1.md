## eZ80 Instruction Reference (critical for correct decode)
- Standard Z80 opcodes are 1 byte, but eZ80 adds ADL mode (24-bit addressing by default)
- In ADL mode (which the TI-84 CE uses), LD instructions with immediate addresses use 3-byte addresses (little-endian)
- CALL nn = CD xx xx xx (4 bytes: opcode + 3-byte address)
- JP nn = C3 xx xx xx (4 bytes)
- JP cc,nn = C2/CA/D2/DA/E2/EA/F2/FA xx xx xx (4 bytes)
- JR e = 18 xx (2 bytes, signed offset from NEXT instruction)
- JR cc,e = 20/28/30/38 xx (2 bytes)
- LD r,(IX+d) = DD 46/4E/56/5E/66/6E/7E dd (3 bytes)
- LD (IX+d),r = DD 70-77 dd (3 bytes)
- LD A,(nn) = 3A xx xx xx (4 bytes in ADL mode)
- LD (nn),A = 32 xx xx xx (4 bytes in ADL mode)
- LD HL,(nn) = 2A xx xx xx (4 bytes in ADL mode)
- LD (nn),HL = 22 xx xx xx (4 bytes in ADL mode)
- LD HL,nn = 21 xx xx xx (4 bytes in ADL mode)
- LD A,n = 3E xx (2 bytes)
- RST 28h = E7 (1 byte, followed by 2-byte BCALL index)
- RET = C9 (1 byte)
- RET cc = C0/C8/D0/D8/E0/E8/F0/F8 (1 byte)
- .SIS prefix = 0x40 (makes following instruction use 16-bit operands with MBASE composition)
- .LIS prefix = 0x49
- .SIL prefix = 0x52
- .LIL prefix = 0x5B
- BIT b,(IY+d) = FD CB dd xx (4 bytes)
- SET b,(IY+d) = FD CB dd xx (4 bytes)
- RES b,(IY+d) = FD CB dd xx (4 bytes)
- PUSH/POP rr = C5/D5/E5/F5 / C1/D1/E1/F1 (1 byte)
- INC/DEC r = 04/0C/14/1C/24/2C/3C / 05/0D/15/1D/25/2D/3D (1 byte)
