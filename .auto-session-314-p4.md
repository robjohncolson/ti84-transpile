# Task: Trace SetTextSpan/SetDisplayRegion Callers — Build Caller Taxonomy

## Context
Session 313 decoded two display functions in the TI-84 Plus CE ROM:
- **SetTextSpan** at 0x0152D8 (vector 0x0003F0): 3-arg, 74 callers. Copies bytes from source to dest region via RAM variables D17710/D17719/D1770D.
- **SetDisplayRegion** at 0x015349 (vector 0x0003EC): 6-arg, 85 callers. Extended version with dual source/fill pairs (D1771E/D17721), special 8-row pixel-level bit-rotate via 0x002553.

A RAM map was established: D1771A=display region base (167 refs), D1770A=text buffer base (155 refs), D17713=cursor X (150 refs), D17716=cursor Y (112 refs), D1771D=text attribute/mode (89 refs).

We need to trace 5-10 callers of each function to build a taxonomy of WHO calls them and WHY.

## What to do

1. **Gunzip the transpiled ROM**: `gunzip -kf TI-84_Plus_CE/ROM.transpiled.js.gz`

2. **Find callers of SetTextSpan (0x0152D8 or vector 0x0003F0)**. In the transpiled JS, search for calls to `0x0003f0` or `0x0152d8`. Also search raw ROM for `CD F0 03 00` (CALL 0x0003F0) and `CD D8 52 01` (CALL 0x0152D8).

3. **Pick 10 representative callers** (5 for each function) spread across different ROM regions. For each caller:
   - Note the caller's address
   - Read ~50 bytes of context before the CALL to see what arguments are set up
   - Determine what RAM variables (D1770A, D17713, D17716, D1771A, D1771D) are written before the call
   - Classify the caller as: menu setup, graph rendering, editor/text init, status bar, dialog, error display, or other

4. **Build a taxonomy table** showing the distribution:
   - How many callers are menu-related?
   - How many are graph/plot related?
   - How many are editor/home screen?
   - What argument patterns are most common?

5. **Write results** to `TI-84_Plus_CE/phase314-display-callers-report.md`:
   - 10 detailed caller analyses (5 per function)
   - Taxonomy table with counts
   - Key patterns observed (e.g., "most callers set cursor X/Y before calling")
   - Any callers that do something unexpected

6. **Write a probe** at `TI-84_Plus_CE/probe-phase314-display-callers.mjs` that:
   - Loads ROM, finds all CALL sites for both functions
   - Prints total count and first 20 caller addresses for each
   - Groups callers by ROM region (0x00xxxx, 0x01xxxx, etc.)

- SetTextSpan may be called via vector 0x0003F0 (JP 0x0152D8 at that address) or directly
- SetDisplayRegion may be called via vector 0x0003EC (JP 0x015349) or directly

## Success criterion
Report with 10 detailed caller analyses, a taxonomy table showing caller distribution by purpose, and a probe that counts and groups all caller sites.
