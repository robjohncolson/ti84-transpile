# Task: Disassemble block 0x001B44 branch logic + RETN audit at 0x000DED

## Context
The TI-84 CE NMI handler runs 14 blocks per wake. Block 0x001B44 reads port 0x28 (gets 0x04 = PLL locked) and falls through to 0x001B6B. We need to understand the EXACT branch condition — what opcode tests port 0x28's value, and what value would cause it to take the other branch.

Also, block 0x000DED is the last block before the handler returns to 0x0019B5 (HALT). We need to know if 0x000DED contains RETN (ED 45) or RETI (ED 4D), or if it JPs directly to 0x0019B5.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase357-disasm-nmi-branch.mjs` that:

1. Reads the ROM binary at `TI-84_Plus_CE/ROM.rom` using `fs.readFileSync`
2. Disassembles bytes from these ROM regions (hex dump + manual decode):
   - **0x001B44 to 0x001B6B** (the branch block — ~39 bytes). Look for: IN A,(C) or IN0 A,(0x28), followed by a conditional (JR Z, JR NZ, BIT, CP, AND, OR). Document which condition would cause the alternate branch.
   - **0x001B6B to 0x001B80** (the fallthrough target — ~21 bytes). What happens after the branch falls through?
   - **0x000DED to 0x000E10** (the RETN/RETI block — ~35 bytes). Look for ED 45 (RETN) or ED 4D (RETI) or JP/JR to 0x0019B5.
   - **0x0019B5 to 0x0019E9** (the HALT region + post-HALT code — ~52 bytes). Confirm the disassembly: DI, LD A,0x10, OUT0 (0x00),A, HALT, then what follows.

3. For each region, output:
   - Raw hex bytes
   - eZ80 ADL-mode disassembly (3-byte addresses, 3-byte immediates for LD rr,nn)
   - Analysis of what the code does

## eZ80 ADL-mode decoding notes
- This is eZ80 in ADL (24-bit) mode, NOT Z80 mode
- LD BC,nn is 3 bytes for nn (not 2): opcode 01 + 3-byte immediate
- IN0 A,(n) = ED 38 nn (reads port nn)
- OUT0 (n),A = ED 39 nn (writes port nn)  
- IN A,(C) = ED 78 (reads port from C register)
- RETN = ED 45
- RETI = ED 4D
- HALT = 76
- DI = F3
- EI = FB
- JP nn = C3 + 3-byte address
- JR Z,e = 28 ee (relative jump if zero)
- JR NZ,e = 20 ee
- BIT b,A = CB 47/4F/57/5F/67/6F/77/7F
- AND n = E6 nn
- CP n = FE nn
- Address immediates are 3 bytes in ADL mode (little-endian)
