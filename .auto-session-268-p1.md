# Session 268 P1 — D007E8 Fix: Seed handler address so LDIR preserves D007D0

## Context

Session 267 found the root cause of the D007D0 zeroing bug:
- Block 0x0250FA does LDIR copying 23 bytes from D007E2→D007CA
- D007D0 = D007CA + 6, so it gets the value from D007E8 (which is zero)
- At 0x08C6A3: LD HL,(D007D0) loads 0, then JP(HL) at 0x08C745 → reset vector
- **FIX**: Seed D007E8 with the handler address (0x06C546) so when LDIR copies D007E2→D007CA, D007D0 ends up with 0x06C546 instead of zero.

Additionally, session 262 found that D007D0 write site 0x06C532 sets D007D0=0x06C546 (home-screen context init), and the init at ~0x06C510 saves a handler struct via LDIR D007CD→D00285.

## Task

Create a probe `TI-84_Plus_CE/probe-phase268-d007e8-fix.mjs` that:

1. Does a full cold boot (same pattern as `probe-phase267-08C69E-hl-trace.mjs` — copy its boot sequence exactly)
2. After boot, seeds D007E8 with handler address 0x06C546 (3 bytes, little-endian)
3. ALSO seeds D007D0 with 0x06C546 as before
4. Sets D0230F=0x3F, B=3, D000A5 bit 5 clear, IX=0xD1A860, IY=0xD00080, madl=1, mbase=0xD0
5. Calls 0x062055 (the main entry that goes through 0x080151 gate → 0x08C69E → 0x08C745)
6. Traces up to 5000 steps, logging every block visit
7. At each step, reads D007D0 and D007E8 from memory and prints their values
8. Specifically tracks:
   - Whether 0x08C69E is reached (PutAway entry)
   - Whether 0x08C6A3 is reached (LD HL,(D007D0))
   - What HL value is at 0x08C745 (JP(HL)) — is it now 0x06C546 instead of 0?
   - Whether execution reaches 0x06C546 (the handler itself)
   - Whether execution reaches 0x058241 (cxMain) or 0x0585E9 (cxMain body)
   - Whether execution reaches 0x082BE2 (event loop)
   - How many unique blocks are visited
9. Also run a control experiment WITHOUT the D007E8 seed (only D007D0 seeded) to confirm it still crashes

Print a clear summary at the end comparing both experiments.

## Key constants

- D007D0 = 0xD007D0 (handler pointer, loaded by LD HL,(D007D0) at 0x08C6A3)
- D007E8 = 0xD007E8 (source for D007D0 after LDIR at 0x0250FA)
- D007CA = 0xD007CA (LDIR destination base, D007D0 = D007CA + 6)
- D007E2 = 0xD007E2 (LDIR source base, D007E8 = D007E2 + 6)
- Handler address = 0x06C546
- 0x062055 = main OS function entry
- 0x080151 = gate (B=3 passes)
- 0x08C69E = PutAway entry
- 0x08C6A3 = LD HL,(D007D0)
- 0x08C745 = JP(HL) dispatch
- 0x058241 = cxMain
- 0x0585E9 = cxMain body
- 0x082BE2 = event loop
- D0230F = 0xD0230F (mode selector, set to 0x3F for cxMain path)
- D007FA = 0xD007FA (stack value for LD SP,(D007FA) at 0x06206E)

## Boot sequence (copy from probe-phase267)

```javascript
const BOOT_ENTRY = 0x000000;
const BOOT_MAX_STEPS = 20000;
const BOOT_MAX_LOOP_ITERATIONS = 32;
const STACK_RESET_TOP = 0xD1A87E;
const KERNEL_INIT_ENTRY = 0x08C331;
const POST_INIT_ENTRY = 0x0802B2;
const RETURN_SENTINEL = 0x7FFFFE;

function coldBoot(executor, cpu, mem) {
  executor.runFrom(BOOT_ENTRY, 'z80', {
    maxSteps: BOOT_MAX_STEPS,
    maxLoopIterations: BOOT_MAX_LOOP_ITERATIONS,
  });
  cpu.halted = false;
  cpu.iff1 = 0;
  cpu.iff2 = 0;
  cpu.sp = STACK_RESET_TOP - 3;
  mem.fill(0xFF, cpu.sp, cpu.sp + 3);
  executor.runFrom(KERNEL_INIT_ENTRY, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 });
  cpu.mbase = 0xD0;
  cpu._iy = 0xD00080;
  cpu._hl = 0;
  cpu.halted = false;
  cpu.iff1 = 0;
  cpu.iff2 = 0;
  cpu.sp = STACK_RESET_TOP - 3;
  mem.fill(0xFF, cpu.sp, cpu.sp + 3);
  executor.runFrom(POST_INIT_ENTRY, 'adl', { maxSteps: 100, maxLoopIterations: 32 });
}
```
