# Task: Investigate Port 0x1F Gate at 0x000D82 + RAM 0xD02AD9

## Context
This is a TI-84 Plus CE ROM transpilation project. The OS ROM (eZ80 machine code) is lifted to JavaScript and executed in Node.js. Boot currently reaches 318 unique blocks before HALTing.

The boot path escapes the PLL HALT loop (session 357 fix: port 0x28 returns 0x0C), then hits a SECOND gate at block 0x000D82:
- Block 0x000D82 does: IN0 C,(0x1F) / INC C / CP C / JP NC,0x0019B5
- Port 0x1F currently returns 0xFF -> INC C wraps to 0x00 -> CP C is A-0=A -> JP NC fires when A>=0 -> goes to HALT at 0x0019B5
- Register A is loaded from RAM address 0xD02AD9: LD A,(0xD02AD9)

## Deliverables

Create a probe file `TI-84_Plus_CE/probe-phase358-port1F-gate.mjs` that:

1. Traces the full block 0x000D82 instruction sequence - disassemble from ROM bytes starting at 0x000D82 through the next RET/JP/JR terminator. Show every instruction with hex offsets.

2. Monitors RAM 0xD02AD9 during boot - hook memory writes to track when/if 0xD02AD9 is ever written during the 318-block boot. Log the value written, the PC that wrote it, and the step number.

3. Identifies all ROM locations that read port 0x1F - scan the ROM for all IN0/IN references to port 0x1F. Opcode patterns: ED 00 1F for IN0 B,(0x1F), ED 08 1F for IN0 C,(0x1F), ED 10 1F for IN0 D,(0x1F), ED 18 1F for IN0 E,(0x1F), ED 20 1F for IN0 H,(0x1F), ED 28 1F for IN0 L,(0x1F), ED 38 1F for IN0 A,(0x1F). List all ROM addresses.

4. Checks whether 0xD02AD9 is written during boot and what value it holds when block 0x000D82 reads it.

## How to write the probe

Read these files FIRST to understand the probe structure:
- `TI-84_Plus_CE/probe-phase357-port28-escape.mjs` (recent probe, use as template)
- `TI-84_Plus_CE/cpu-runtime.js` (createCPU function signature)
- `TI-84_Plus_CE/peripherals.js` (createPeripheralBus, port handlers)

The standard probe pattern:
```javascript
import { createCPU } from './cpu-runtime.js';

import fs from 'fs';
```

For monitoring RAM writes, you need to hook the CPU's memory write functions (write8/write16/write24) to watch address 0xD02AD9. Check cpu-runtime.js for how these work.

For static ROM scan, just iterate over rom bytes looking for the ED xx 1F patterns.
