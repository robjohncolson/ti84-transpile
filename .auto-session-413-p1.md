We need a FULL disassembly trace of 0x014E81 — every instruction, every port touched, every RAM read/write, control flow, callers, and how it interacts with the notification lifecycle.

## eZ80 Encoding Reference
- CALL nn = CD nn[2] nn[1] nn[0] (4 bytes, little-endian 24-bit address)
- JP nn = C3 nn[2] nn[1] nn[0] (4 bytes)
- RET = C9
- LD A,(nn) = 3A nn[2] nn[1] nn[0] (4 bytes)
- LD (nn),A = 32 nn[2] nn[1] nn[0] (4 bytes)
- IN A,(n) = DB n (2 bytes) — but eZ80 uses IN0 A,(n) = ED 38 n (3 bytes)
- OUT (n),A = D3 n (2 bytes) — but eZ80 uses OUT0 (n),A = ED 39 n (3 bytes)
- RES b,(HL) = CB 86+b*8 (2 bytes)
- DI = F3, EI = FB
- OR A = B7, AND A = A7, XOR A = AF
- CP n = FE n
- JR Z,d = 28 d, JR NZ,d = 20 d, JR d = 18 d
- JP Z,nn = CA nn, JP NZ,nn = C2 nn
