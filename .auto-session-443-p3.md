# Task: Map D17792 (Read by D1407A Consume Site)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

In session 442, we traced D1407A (deferred-dispatch-pending flag, 13 refs, boolean). Its consume-and-dispatch pattern is different from D14078/D14079: instead of writing D176FB and calling 0x011576, the D1407A consumer loads BC from address D17792 and then calls function 0x0155BC. Specifically:
- D1407A consumer at 0x013767/0x01386B: OR A → JR Z, clear D1407A, load BC from (D17792), call 0x0155BC

D17792 holds some value that parameterizes the dispatch call. We need to map what it is.

## Task
Trace ALL references to RAM address 0xD17792 in the ROM:

1. **Find all reads and writes**: Scan the entire 4MB ROM for bytes that encode address D17792 (little-endian: 0x92 0x77 0xD1). For each hit, determine if it's a read or write by checking surrounding opcodes.

2. **Characterize the value**: Is it a pointer? Counter? Enum? What values are written to it? Is it 1-byte, 2-byte, or 3-byte (since BC is loaded, it's at least 2 bytes — check if D17793/D17794 are also accessed)?

3. **Map co-accesses**: What other RAM addresses are accessed in the same functions? Focus on D177xx and D140xx ranges.

4. **Who writes D17792?**: Identify the functions that store values to D17792. What values do they write? Under what conditions?

5. **Identify the function at 0x0155BC**: This is called with BC loaded from D17792. What does 0x0155BC do? Disassemble its first ~80 bytes.

## Deliverables
- Create `TI-84_Plus_CE/phase443-trace-D17792-report.md` with your findings

  - For each reference, prints: address, read/write classification, context bytes (±10 bytes hex dump)

  - Disassembles bytes at 0x0155BC (first 80 bytes)
