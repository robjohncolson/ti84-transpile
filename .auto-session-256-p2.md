# Auto-Session 256 P2: Find RAM address storing function pointer to 0x062055

## Context
In the TI-84 Plus CE ROM transpilation project, function 0x062055 is the bridge between the OS event loop and cxMain (the home-screen context handler). It has ZERO static callers — no CALL/JP/LD HL to 0x062055 exists in ROM. It MUST be reached via a RAM-based function pointer populated at runtime during boot.

0x062055 calls 0x08C79F (context switch comparator, compares A with D007E0 mode byte). The handler table at 0x08C958 has 20 entries, with entry[0]=0x058241 (cxMain pre-handler). The event loop path is: event loop → [unknown RAM pointer] → 0x062055 → 0x08C79F → handler_table[A] → context handler → 0x08C33D cleanup → event loop.

Session 253 confirmed 0x062055 is not stored as a data pointer in ROM. Session 252 confirmed ZERO static callers.

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase256-062055-ram-pointer.mjs` that:

1. **Instrument write8/write16/write24**: Patch the CPU runtime's memory write functions to detect when the value 0x062055 (or its bytes 0x55, 0x20, 0x06 in sequence) is written to ANY RAM address during boot. Log the RAM address, the value written, the PC at time of write, and the step number.

   Strategy: After each write24 or write8 call, check if the 3-byte sequence at the written address equals [0x55, 0x20, 0x06] (little-endian for 0x062055). Also check after write16 calls.

2. **Extended boot**: Run a full boot sequence from 0x000000 for 100,000 steps with timer interrupts disabled. Collect all matches from step 1.

3. **Also search for 0x058241** (cxMain pre-handler address, which is known to be stored by 0x08C8CF). The bytes are [0x41, 0x82, 0x05]. This serves as a control — we KNOW this gets stored, so if the instrumentation works, we should find it.

4. **Also search for the event loop addresses**: 0x08C79F bytes [0x9F, 0xC7, 0x08] and 0x08C808 bytes [0x08, 0xC8, 0x08]. These might also be stored as function pointers.

5. **RAM pointer table scan**: After boot completes, scan RAM 0xD00000-0xD30000 for any 3-byte sequence matching 0x062055 ([0x55, 0x20, 0x06]). Report all addresses where found.
