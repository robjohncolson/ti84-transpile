## Background
The TI-84 Plus CE SDK (toolchain by CE Programming) defines system call slot numbers. The slot index maps to address: `slot_addr = 0x000080 + (slot_index * 4)`. Each slot contains `JP target` (opcode 0xC3 followed by 3-byte LE address).

Known named slots (from sessions 433-434):
- Slot 9 (0x0000A4) → 0x0027E8 = _memcpy
- 0x000138 → 0x0021C2 = _null_check  
- 0x000204 → 0x0025E8 = _setflag
- 0x000210 → 0x002623 = _seqcase
- 0x000264 → 0x00276B = _stoiu

The TI-84 CE SDK header files define function names with their slot offsets. The canonical source is the CE C toolchain headers.
