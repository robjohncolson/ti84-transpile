# Auto-Session 256 P1: Trace 0x022264 call chain (LCD write-enable path)

## Context
In the TI-84 Plus CE ROM transpilation project, we need to trace the call chain that reaches 0x022264. This address leads to 0x05523D which contains `SET 2,(IY+0x46)` — the SOLE site that sets D000C6 bit 2 (LCD VRAM write-enable). Without this bit set, LCD VRAM writes are gated off (0x02672F drawing functions check BIT 2 D000C6).

Session 255 added a transpiler seed at 0x022264. Session 248 found that 0x05527B is the SET 2 site inside function ~0x05523D, reached via JP from 0x022264, and that 0x055743 (LCD HW init) is called before the SET.

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase256-022264-call-chain.mjs` that:

1. **Static ROM scan**: Search ROM.rom binary for all CALL/JP references to 0x022264. eZ80 ADL CALL = `CD 64 22 02`, ADL JP = `C3 64 22 02`. Also search for `LD HL,0x022264` patterns: `21 64 22 02`. Report all sites found with their ROM addresses.

2. **Static ROM scan for 0x05523D**: Search for CALL/JP to 0x05523D: `CD 3D 52 05`, `C3 3D 52 05`, `21 3D 52 05`. Report all sites.

3. **Disassemble 0x022264**: Read 64 bytes from ROM at 0x022264 and do a manual eZ80 decode (or use the transpiled runtime to trace). Show what instructions are at 0x022264 and whether it's a JP 0x05523D or a CALL chain.

4. **Trace callers**: For each static caller found in step 1, disassemble 32 bytes preceding the call site to understand the context (what function it's in, what conditions gate it).

5. **Boot trace**: Run a boot sequence (z80 boot at 0x000000, 50000 steps) with a hook that logs whenever PC enters the range 0x022260-0x022280 or 0x055230-0x055280. Report whether and when these addresses are hit during boot.
