# Auto-Session 226 — P1: Disassemble 0x051CF3 (D0059F Writer Function)

## Context
In the TI-84 Plus CE ROM transpilation project, we've traced that variable D0059F controls which token table the key classifier (0x05C52C) uses. Magic values: 0xFA=AlphaLock, 0xFB=Alpha, 0xFC=2nd, 0xFE=Fn. Session 225 found the SOLE WRITE SITE at 0x051D4D: `LD A,(HL); LD (D0059F),A` — inside function 0x051CF3. The magic values come from a lookup table pointed to by HL.

## Task
Build a probe `TI-84_Plus_CE/probe-phase226-051cf3-d0059f-writer.mjs` that:

1. **Static disassembly**: Read ROM.rom bytes from 0x051CF3 to 0x051E00 (~269 bytes) and disassemble them using the eZ80 instruction set (ADL mode). Document every instruction. Key things to identify:
   - Where HL is loaded before the `LD A,(HL); LD (D0059F),A` at 0x051D4D
   - What table HL points to (look for `LD HL,<addr>` instructions)
   - The function boundary (look for RET instructions, especially the final RET)
   - Any CP/JR/JP branches

2. **Find callers**: Scan ROM.rom (0x000000-0x0BFFFF) for `CD F3 1C 05` (ADL CALL 0x051CF3) and `C3 F3 1C 05` (ADL JP 0x051CF3). Also check for `CD` patterns to nearby addresses (0x051CF0-0x051D00).

3. **If a table address is found** (e.g., `LD HL,0x05XXXX`), dump the table contents from ROM.rom — read 16-32 bytes starting at that address and print them in hex.

4. **Dynamic trace**: Run from 0x051CF3 with various A values (0x8F, 0x76, 0x00, 0x5B) using the standard boot setup:
   ```javascript
   const cpu = new ez80CPU();
   const mem = new Uint8Array(0x1000000);
   const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
   mem.set(rom);
   const bus = createPeripheralBus({ timerInterrupt: false });
   cpu.bindMemory(mem, bus);
   cpu.iy = 0xD00080;
   cpu.mbase = 0xD0;
   ```
   Set up A register with the test value, set PC to 0x051CF3, and step up to 200 steps. Record all blocks visited, what D0059F ends up as, and what HL pointed to.

5. **Session 225's internal read sites**: The function has BIT 7/6/5 tests at 0x051D63, 0x051D7A, 0x051DC1. Trace which branches these control.
