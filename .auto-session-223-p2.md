# Task: Find what OS code produces magic A values (0xFA-0xFE) for key classifier

## Context
You are working on a TI-84 Plus CE ROM transpilation project. Session 222 decoded the key classifier at 0x05C52C — it uses "magic A values" to select secondary token tables:
- A=0xFE → Fn table
- A=0xFC → 2nd table  
- A=0xFB → Alpha table
- A=0xFA → AlphaLock table
- Other A values → SUB 0x5A → primary table at 0x05BF84

These magic values are NOT scan codes or key codes — they are synthetic values the OS key handler produces when a modifier key (2nd, ALPHA, etc.) is active.

## Deliverable
Create `TI-84_Plus_CE/probe-phase223-magic-a-producers.mjs` that performs a **static ROM binary scan** to find what code writes/produces these magic A values.

### Search strategy:

1. **Search for `LD A,0xFE` / `LD A,0xFC` / `LD A,0xFB` / `LD A,0xFA` instructions near keyboard/key handling code**
   - eZ80 encoding: `3E xx` (LD A,imm8) where xx = FE/FC/FB/FA
   - Also check `LD A,0xFF` → `DEC A` pattern (produces 0xFE)
   - Search in ROM regions: 0x04A000-0x05FFFF (key handling), 0x001000-0x002000 (ISR), 0x000000-0x001000 (vectors)
   - For each hit, disassemble surrounding ~20 bytes for context

2. **Search for code that writes to the A register before calling ConvKeyToTok (0x05E630) or the key classifier (0x05C52C)**
   - Find all CALL 0x05E630 sites: `CD 30 E6 05` (4-byte ADL CALL)
   - Find all CALL 0x05C52C sites: `CD 2C C5 05` (4-byte ADL CALL)
   - For each site, look back 5-10 bytes for the A-register setup

3. **Search for modifier key flag checks near these magic value producers**
   - 2nd key flag: BIT tests on IY-relative addresses
   - ALPHA flag: similar IY-relative checks
   - Look for patterns like: BIT n,(IY+offset) → JR Z/NZ → LD A,0xFE/FC/FB/FA

## Key constraints
- ROM is 4MB, but focus on 0x000000-0x0BFFFF (executable region)
- eZ80 instructions are variable-length (1-6 bytes)
- ADL mode CALL = `CD xx xx xx` (4 bytes after opcode)
- Print each finding with: address, instruction bytes, decoded instruction, surrounding context
- Group findings by which magic value they produce

## Success criteria
- Find at least one site that loads A with 0xFE, 0xFC, 0xFB, or 0xFA before calling ConvKeyToTok or the key classifier
- Identify the modifier key flag check that gates the magic value selection
- Output structured findings showing the producer→consumer chain
