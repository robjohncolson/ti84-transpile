# Task: Trace 0x0850D1 and 0x04E447 branches (yyy)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 237 decoded 0x04EDD0 as a shared post-classification handler. After its initial calls (0x04ECCE, 0x0A21EC), it tests bits in D003E0 to branch to either:
- **0x0850D1** — described as "display update path"
- **0x04E447** — described as "alternate path"

We need to trace both branches to understand what they do.

## Task
Create a probe `TI-84_Plus_CE/probe-phase238-0850d1-04e447-branches.mjs` that:

1. Sets up a minimal runtime (full boot pattern from existing probes).
2. For the **0x0850D1 branch**:
   - Enter at 0x0850D1 with home-screen state (IX=0xD1A860, IY=0xD00080)
   - Run 500 steps, log unique blocks with visit counts
   - Snapshot VRAM region 0xD40000-0xD40100 before and after — does it write display data?
   - Log OP1-OP6 (0xD005F8-0xD00627) before and after
   - Log any calls to known display functions (0x05E2A0 BufInsert, 0x08383D, 0x07F9FB)
3. For the **0x04E447 branch**:
   - Enter at 0x04E447 with same state
   - Run 500 steps, log unique blocks with visit counts
   - Snapshot same RAM regions
   - Does it converge back to the event loop (0x02FD99)?
4. Compare the two branches — which one fires on home screen (D003E0=0x00 at boot)?
