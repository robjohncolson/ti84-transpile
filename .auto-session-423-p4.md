# Task: Map slab pool metadata (D1401A/D1401D/D14020/D1406C) + add 40 seeds

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The transpiler is at `scripts/transpile-ti84-rom.mjs`.

## What we know

- **0x00E1CC** (287 bytes) is a slab free helper with two selector paths:
  - Selector 0: frees 0x20-byte slabs from pool bounded by D1401A (lower) / D1401D (upper), computes slot index, wipes 32 bytes
  - Selector 2: frees 0x400-byte slabs from D14020 pool, updates free bitmap at D1406C (6 entries)
- The slab allocator's `alloc` counterpart is unknown.
- D14008/D14005 = block list head/terminator for the transfer engine (0x00FE10).

## Your task — TWO PARTS

### Part A: Map slab pool metadata

1. **Scan ROM for all references to D1401A, D1401D, D14020, D1406C**. For each:
   - Search for the 3-byte little-endian pattern (e.g., D1401A = 1A 40 D1)
   - Document read vs write, function context, what value
   - Look especially for the ALLOC counterpart — a function that WRITES to these addresses to populate the pool or allocate from it

2. **Write a probe** at `TI-84_Plus_CE/probe-phase423-slab-pool-map.mjs` that:
   - Scans ROM for all references to D1401A, D1401D, D14020, D1406C
   - Also scan D14005, D14008, D1400B, D1400E (block list pointers)
   - Prints address, instruction context, read/write classification

3. **Write a report** at `TI-84_Plus_CE/phase423-slab-pool-report.md`.

### Part B: Add 40 seeds to the transpiler

Open `scripts/transpile-ti84-rom.mjs` and find the `seeds` array. Add 40 new seed addresses:

**20 OS export JP stubs** — pick addresses from the 0x0211xx-0x0212xx range (OS export jump table continuation). Each address should be a JP instruction (byte C3 at that ROM offset). Verify by checking `rom[offset] === 0xC3` before adding.

**20 function prologues** — scan these ROM regions for function entry patterns:
- 0x00DC00-0x00E000 (link I/O region near the drain functions)
- 0x00E600-0x00EA00 (post-header-extractor region)

Function prologues to look for:
- `PUSH IX` = DD E5 (or ED prefix variants)
- `CALL __frameset` = CD 8A 21 00 (CALL 0x00218A)
- `LD IX,0` followed by `ADD IX,SP` = DD 21 00 00 00 / DD 39

For each candidate, verify it's a plausible function entry (not mid-instruction).

After adding seeds, run:
```bash
node scripts/transpile-ti84-rom.mjs
```

Report the new seed count, block count, and covered byte count from the transpiler output.

## Constraints

- For the transpiler, ONLY add to the `seeds` array — do not change any other code
- Create NEW probe and report files only

## Success criteria
