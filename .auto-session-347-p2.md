# Auto-Session 347 — P2: Integrate CoorMon Event Loop into Browser Shell

## Context

The TI-84 Plus CE OS event loop architecture is now fully decoded (sessions 338-346):

- **Full CoorMon** at 0x08C331 is the master OS loop
- On each iteration: setup + status bar -> dispatch to cxMain via 0x08C72F -> JP (HL) -> handler
- **HOME_HANDLER** at 0x058241 is the home screen context
- Scan code loaded from **0xD0058E** (NOT 0xD0058C — handlers only read D0058E)
- Key injection: write scan code to **0xD0058E** before calling CoorMon
- IY must = **0xD00080** (OS system flags base)
- Context table at 0x08C958 (28 entries, 3-byte stride)
- cxMain pointer at 0xD007CA

The browser shell currently uses a direct-eval bypass. We want to replace it with the real CoorMon dispatch loop.

## Task

Create a new file `TI-84_Plus_CE/coormon-loop-design.md` that documents the integration design. Then modify `TI-84_Plus_CE/browser-shell.html` to add a **second execution mode** (toggled by a button/checkbox) that uses the CoorMon event loop instead of the current direct-eval path.

### Design Requirements

1. **requestAnimationFrame loop** that on each frame:
   - Reads the browser keyboard state -> maps to TI-84 scan code
   - Writes scan code to mem[0xD0058E] (single byte)
   - Calls executeBlock starting at 0x08C331 (full CoorMon entry)
   - Lets it run for up to N steps (e.g., 50000) per frame
   - After execution, reads VRAM and renders to canvas

2. **Prerequisites before entering the loop**:
   - IY register = 0xD00080
   - SP set to a safe RAM location (e.g., 0xD1A87E — standard OS stack)
   - mem[0xD007CA..0xD007CC] = 0x058241 (cxMain = HOME_HANDLER, 3-byte LE)
   - Mode = ADL (24-bit, not z80)

3. **Keyboard mapping**: Use the existing keyboard-matrix.md scan code table. The browser shell already has keyboard event handlers — map them to scan codes and write to 0xD0058E. Key reference: scan code = (group_index << 4) | bit. Group index = 7 - SDK_group.

4. **Keep the existing direct-eval mode** as default. The CoorMon mode is experimental — add it as an opt-in toggle.

5. **Do NOT attempt to boot the OS from 0x000000**. Skip boot entirely — just set up the CoorMon prerequisites in RAM and jump straight into the event loop at 0x08C331.
