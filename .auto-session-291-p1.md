# Auto-Session 291 — P1: Classify 27 D0058C Write Sites by Parent Function

## Context
D0058C is the RAM location where the TI-84 Plus CE OS stores the current scan code (the key that was pressed). We've identified all 27 locations in ROM that write to D0058C. Your job is to classify each one by examining the surrounding code context.

## The 27 D0058C Write Sites (all `LD (0xD0058C),A`)
```
0x0238AD, 0x0258C8, 0x02658A, 0x026892, 0x0268A0, 0x026983,
0x02F95D, 0x02FCBA, 0x02FEC9, 0x030330, 0x030345,
0x03D964, 0x03D975, 0x03F0A1, 0x03F4CB,
0x04BA69,
0x05627A, 0x05628A, 0x0562AB,

0x080FB2, 0x080FCF,

0x09D29E
```

## Task
Create a probe file `TI-84_Plus_CE/probe-phase291-d0058c-write-classify.mjs` that:

1. Reads `ROM.rom` and `ez80-decoder.js` from the same directory
2. For each of the 27 write sites above, disassembles the surrounding context:
   - Scan backwards from the write site to find the likely function entry (look for a common prologue pattern or the nearest address that other code CALLs/JPs to)
   - Disassemble 20-30 instructions before and 10-15 after the write site
   - Look for nearby CALL targets, other memory references (especially keyboard MMIO 0xE00900-0xE0090F, other D005xx variables), and RET/JP instructions
3. Classify each write site into one of these categories:
   - `KEYBOARD_SCAN`: directly reads from keyboard MMIO (0xE00900 range) or calls known keyboard scan routines
   - `EVENT_SERVICE`: part of event dispatch/handler chains (0x02FCxx area is known event-service wrapper)
   - `APP_DISPATCH`: application-level dispatch (0x03xxxx range)
   - `EDITOR`: edit-buffer related (0x05xxxx near BufInsert)
   - `EVENT_LOOP`: main event loop housekeeping (0x07xxxx-0x08xxxx)
   - `STAT`: statistics module (0x09xxxx)
   - `UNKNOWN`: can't determine

4. Print a summary table grouping sites by category, with the parent function address range for each
