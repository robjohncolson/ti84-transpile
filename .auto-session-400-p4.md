## How to Add Seeds
In `scripts/transpile-ti84-rom.mjs`, find the `manualSeeds` array (search for `manualSeeds`). Add new hex addresses to the array. The format is just hex numbers like `0x02A336`.

Before adding a seed, verify the address contains plausible eZ80 code by checking the first few bytes at that offset in ROM.rom. Valid code starts typically start with common eZ80 opcodes: PUSH (0xE5, 0xD5, 0xC5, 0xF5), LD (0x21, 0x31, 0x3E, 0x06, etc.), CALL (0xCD), JP (0xC3), etc. Do NOT seed addresses that start with 0xFF (erased flash) or 0x00 runs (padding).
