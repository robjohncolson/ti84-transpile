# Task: Decode D14072 (USB Speed/Mode Flag)

## Context
This is part of the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). We're tracing RAM byte D14072 which is part of a 16-byte USB state block at D14070-D1407F.

From session 437: D14072 has 19 refs and is described as "USB speed/mode". From session 429: D141E6 stores a 2-bit value from port 0x3082 bits 7:6 (USB speed/mode). D14072 may be related or distinct.

## Task
Write a probe script at `TI-84_Plus_CE/probe-phase438-trace-D14072.mjs` AND a report at `TI-84_Plus_CE/phase438-D14072-report.md`.

The probe must:
1. Open `TI-84_Plus_CE/ROM.rom` (raw binary, 4,194,304 bytes)
2. Scan the entire ROM for all references to address 0xD14072:
   - Address in little-endian: 0x72 0x40 0xD1
   - Pattern for LD (addr),A: opcode 0x32 followed by 0x72 0x40 0xD1
   - Pattern for LD A,(addr): opcode 0x3A followed by 0x72 0x40 0xD1
   - Also look for other LD variants and indexed access
3. For each reference found, determine:
   - The ROM address where the reference occurs
   - Whether it's a read or write
   - What value is written (XOR A = 0, LD A,imm = that constant, register transfer, etc.)
   - What the read value is compared against (CP instructions following reads)
   - The containing function context (what's nearby — other D140xx refs, port I/O, CALLs)

## Additional analysis
- Compare D14072 with D141E6 (port 0x3082 bits 7:6 speed/mode from session 429): are they the same data copied, or distinct state?
- Check if D14072 is written by the same functions that write D141E6 (write sites for D141E6: 0x00DD61, 0x00DDF9, 0x03AB82, 0x03AC1A)
- Look for co-references: functions that access both D14072 and D14073/D14074 (the adjacent USB state bytes)
