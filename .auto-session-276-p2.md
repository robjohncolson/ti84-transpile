# Task: Trace 0x082BE2/0x084711 Polling Loop

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We've discovered a dispatch table mechanism:

- **D0259A** is a 24-bit pointer tracking current top of a downward-growing dispatch table from 0xD3FFFF
- Each entry is 9 bytes
- **0x0846EA** is the table lookup function (235 callers)
- **0x08210D** is the sole entry writer
- **0x09DEF4** resets the table to empty (D0259A = 0xD3FFFF)
- When table is empty, D0259A = 0xD3FFFF
- Related pointer cluster: D0258A, D0258D, D0259A, D0259D, D005F8, D1987E

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase276-polling-loop.mjs` that:

1. **Statically disassembles 0x082BD0-0x082C20 and 0x084700-0x084730** by reading ROM bytes from `TI-84_Plus_CE/ROM.rom`. Print each eZ80 ADL-mode instruction with address. Look for:
   - References to D0259A or D3FFFF
   - Loop structures (JR/JP backward, DJNZ)
   - Comparison instructions (CP) that might check for empty table
   - CALL 0x0846EA or references to the dispatch table

2. **Dynamically traces both addresses** using the transpiled runtime:
   - Boot CPU (PC=0x000000) for 50,000 steps
   - **Experiment 1**: Set PC=0x082BE2, D0259A=0xD3FFFF (empty table), run 500 steps. Watch: does it loop? What breaks it? What does it return?
   - **Experiment 2**: Set PC=0x082BE2, D0259A=0xD3FFF6 (1 entry), populate a 9-byte entry at D3FFF6-D3FFFE, run 500 steps. Does behavior change?
   - **Experiment 3**: Same two experiments but starting at PC=0x084711
   - Track: loop iteration count, exit condition, registers at exit, any CALL 0x0846EA invocations

3. **Report**: What condition breaks each polling loop? Is it checking D0259A ≠ D3FFFF (table non-empty)?

## eZ80 ADL instruction reference
- `ED 6B xx xx xx` = LD HL,(xxxx), `ED 63 xx xx xx` = LD (xxxx),HL
- `21 xx xx xx` = LD HL,imm24, `FE xx` = CP imm8
- `CD xx xx xx` = CALL addr24, `C3 xx xx xx` = JP addr24
- `20 xx` = JR NZ,rel8, `28 xx` = JR Z,rel8, `18 xx` = JR rel8
- `C2 xx xx xx` = JP NZ,addr24, `CA xx xx xx` = JP Z,addr24
- `B7` = OR A (sets Z if A=0)
