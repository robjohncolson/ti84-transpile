# Auto-Session 195 P3: Y= Editor 0xD00596 Exploration + Seeded 0x09CB14

## Context
In the TI-84 Plus CE ROM transpilation project, session 194 decoded the Y= editor CALL targets from block 0x09CB14:
- 0x0A2B72 = attribute updater (17 blocks, writes 0xD00596=0x19 and 0xD00595=0xFF)
- 0x05E27E = lightweight flag check (5 blocks, zero writes)
- 0x0A1B59 = screen update (50 blocks, 679 steps)
- 0x09CB1A (skip JR loop) = 58 blocks, calls 0x05E27E then 0x0A1B59, returns cleanly

The block at 0x09CB14 has a structure:
```
0x09CB14: CALL 0x0A2B72    ; attribute updater - writes 0xD00596=0x19
0x09CB18: JR to 0x09CB08
0x09CB08: CALL 0x05E27E    ; flag check
          LD HL,0xD00596
          DEC (HL)          ; decrement counter
          CALL 0x0A1B59    ; screen update
          RET               ; when (HL) reaches 0
```

The JR loop decrements 0xD00596 each iteration. 0x0A2B72 sets it to 0x19 (=25 decimal). This looks like it iterates 25 times (for Y1-Y0 or 25 Y= variable slots?).
