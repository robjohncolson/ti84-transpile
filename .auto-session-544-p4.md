# Task: Complete Mapping of 0x08356A Case-Switch Error Offset Converter

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). You need to fully map the case-switch at address 0x08356A which converts error type codes to table offsets before the error display routine uses them.

From session 543: 0x08356A is called from the error display routine at 0x03EA5E, followed by `SUB 0x0F` to compute the final error string table index. The Sonnet probe got partial coverage:
- Known branches: 0x0D → returns 1, 0x06 → DEC A (returns A-1), 0x0B → returns 3
- Fallthrough: AND 0x3F → multi-CP chain checking 0x18/0x19/0x1B/0x1C/0x20 with various conditional returns; default XOR A (returns 0)

We need EVERY branch with its input value and output value to derive the exact mapping formula.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase544-map-08356A.mjs` that:
1. Reads the ROM binary
2. Uses `decodeInstruction` from `./ez80-decoder.js` to decode EVERY instruction from 0x08356A to the end of the function
3. Decode at least 60 instructions starting at 0x08356A — follow ALL branches (JR/JP conditional and unconditional)
4. For each CP instruction, note what value is being compared and what the branch target does (what value does A end up with if the branch is taken vs not taken)
5. Build a complete mapping table: input_A_value → output_A_value for EVERY case
6. Also decode what happens BEFORE 0x08356A — read 16 bytes before to see how A is loaded before this function is called
7. Search for xrefs (CD 6A 35 08 pattern) to see all callers

## Technical Details
- Import: `import { decodeInstruction } from './ez80-decoder.js';`
- ROM read: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');`
- Decoder call: `const inst = decodeInstruction(rom, address, 'adl');` — returns object with `.tag`, `.size`, and various fields
- Use `rom.slice(addr, addr + inst.size)` for hex bytes
- Third parameter is the string `'adl'` (NOT an integer)
- For branch targets in JR instructions: target = current_address + inst.size + signed_offset. The decoder should provide `.target` field.

## Key approach
This is a case-switch, so the structure will be:
```
CP value1
JR Z, handler1   ; if A == value1, go to handler1
CP value2  
JR Z, handler2   ; if A == value2, go to handler2
...
; fallthrough = default case
```

For each handler, trace what value A has when the function returns (RET). Some handlers may just RET immediately (A unchanged from the CP), others may LD A,constant first.

- NEVER run the probe bare — always use the watchdog wrapper

## Success Criterion
The probe produces a COMPLETE input→output mapping table for every case in the 0x08356A switch, plus the default/fallthrough case. No branches should be unaccounted for.
