# Auto-session 257 P2: Find who indexes into 0x022264 vector table

## Context
This is a TI-84 Plus CE ROM transpilation project. Session 256 confirmed 0x022264 is a vector table with dense `C3 xx xx xx` (ADL JP) entries, reached by computed index. Entry[0] = JP 0x05523D (LCD init). ZERO static callers — only computed dispatch. We need to find what code computes an index into this table.

## Task
Create a probe file `TI-84_Plus_CE/probe-phase257-022264-indexers.mjs` that:

1. **Static ROM scan for address references**: Search the entire ROM (0x000000-0x3FFFFF) for these byte patterns:
   - `64 22 02` (little-endian 0x022264) — any instruction referencing 0x022264
   - `60 22 02` (0x022260) — possible base with offset
   - `00 22 02` through `FF 22 02` (anything in 0x0222xx page)
   For each hit, print the address, the surrounding 8 bytes (4 before, 4 after), and attempt to decode the instruction (LD HL,imm24 = 0x21, LD DE,imm24 = 0x11, LD BC,imm24 = 0x01, CALL imm24 = 0xCD, JP imm24 = 0xC3).

2. **Search for table-stride patterns**: The table has 4-byte entries (each is `C3 xx xx xx`). Search for:
   - Any `ADD HL,HL` + `ADD HL,HL` (×4 shift for 4-byte entries) near references to 0x022264
   - Any `SLA` or shift sequences near 0x0222xx references
   - Byte sequence `29 29` (ADD HL,HL twice) within 20 bytes of any 0x0222xx reference

3. **Dump the table itself**: Read entries at 0x022264 in 4-byte chunks for entries 0-31. Print index, raw bytes, and decoded JP target for each.

4. **Cross-reference JP targets**: For each table entry's JP target, search ROM for any CALL or JP to that target (first 5 entries only to keep output manageable).
