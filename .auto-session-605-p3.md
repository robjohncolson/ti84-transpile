# Auto-Session 605 — P3: Decode 0x0158BC (Intermediate Function Between Guard and Wipe)

## Context

The TI-84 Plus CE OS ROM is transpiled to JavaScript. Session 604 found that the call chain to the bulk wipe goes through 0x0158xx functions:

- 0x0158E0: `BIT 7,(IY+0x42); RET NZ` — guard gate (IY+0x42 = D000C2)
- 0x0158EE: conditional SET 7,(IY+0x42) or return 0
- 0x0158E8: `CALL 0x0158BC` — this intermediate function leads to the actual wipe
- 0x001872: port 0x03 bit 4 guard → bulk wipe at 0x0018F8

**0x0158BC has NOT been decoded yet.** We need to understand what this function does — it's the link between the 0x0158xx guard chain and the actual wipe at 0x001872/0x0018F8.

Also relevant: 0x0013C3 calls both 0x001988 and 0x0158DE, and 0x001988 has the SAME port 0x03 bit 4 guard as 0x001872.
