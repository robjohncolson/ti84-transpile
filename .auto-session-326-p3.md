## eZ80 decoding

Do manual byte-level decoding. Key opcodes:
- 0xCD = CALL nn (3-byte LE address follows, 4 bytes total)
- 0xC9 = RET
- 0xC3 = JP nn (3-byte LE address, 4 bytes total)
- 0xC2/0xCA/0xD2/0xDA/0xE2/0xEA/0xF2/0xFA = JP cc,nn (conditional, 4 bytes)
- 0xC4/0xCC/0xD4/0xDC/0xE4/0xEC/0xF4/0xFC = CALL cc,nn (conditional, 4 bytes)
- 0x18 = JR d (relative jump, 2 bytes)
- 0x20/0x28/0x30/0x38 = JR cc,d (conditional relative, 2 bytes)
- 0x21 = LD HL,nn (4 bytes: opcode + 3-byte LE)
- 0x3E = LD A,n (2 bytes)
- 0xDD prefix = IX instructions
- 0xFD prefix = IY instructions
- 0xED prefix = extended instructions
- 0xCB prefix = bit instructions

For CALL/JP reference scanning, search the entire ROM (0x000000-0x3FFFFF) for byte pattern CD 9C 74 05 (CALL 0x05749C) and C3 9C 74 05 (JP 0x05749C).
