# Session 268 P2 — 0x0582BC Event Loop Deep Trace + Keyboard Scan Reachability

## Context

Session 267 found that entering at 0x0582BC (home body) reaches the event loop (0x082BE2) at step 21, with 96 visits in 500 steps, only 25 unique blocks, NO reset, NO 0x08C69E. This is the cleanest known path to the OS event loop.

The next question: does this event loop contain the keyboard scan path (0x0159C0)? If we can trace deep enough, we should find:
- The event loop polling for keyboard input
- Calls to 0x0159C0 (foreground keyboard scanner) or related functions
- GetCSC (0x081648) or GetKey paths

## Task

Create a probe `TI-84_Plus_CE/probe-phase268-0582BC-deep-trace.mjs` that:

1. Does a full cold boot (same pattern as `probe-phase267-cxmain-bypass.mjs` — copy its boot sequence exactly)
2. After boot, sets up standard state: IX=0xD1A860, IY=0xD00080, madl=1, mbase=0xD0, SP=0xD1A87B with return sentinel
3. Enters at 0x0582BC (home body, NOT 0x062055)
4. Traces 10000 steps (not 500 like session 267)
5. Logs EVERY unique block visited (address + visit count)
6. Specifically tracks these key addresses:
   - 0x082BE2 (event loop) — count visits
   - 0x0159C0 (foreground keyboard scanner)
   - 0x081648 (GetCSC)
   - 0x0159BD (near keyboard scanner)
   - 0x058D54 (token class lookup from cxMain key dispatch)
   - 0x0589E5 (key dispatch cascading CP chain)
   - 0x058BA9 (STAT entry, for reference)
   - 0x058AC9 (BufInsert path)
   - 0x0585E9 (cxMain body)
   - 0x058241 (cxMain)
7. Prints the top 50 most-visited blocks (sorted by visit count)
8. Prints all blocks in the 0x0159xx range (keyboard-related)
9. Prints all blocks in the 0x058xxx range (cxMain-related)
10. Prints a summary: total unique blocks, total steps executed, whether keyboard scan was reached

Also run a second experiment with 50000 steps to see if deeper tracing reveals keyboard scan paths.

## Boot sequence (copy from probe-phase267-cxmain-bypass.mjs)

```javascript
const BOOT_ENTRY = 0x000000;
const BOOT_MODE = 'z80';
const BOOT_MAX_STEPS = 20000;
const BOOT_MAX_LOOP_ITERATIONS = 32;
const STACK_RESET_TOP = 0xD1A87E;
const KERNEL_INIT_ENTRY = 0x08C331;
const POST_INIT_ENTRY = 0x0802B2;
const RETURN_SENTINEL = 0x7FFFFE;

function coldBoot(executor, cpu, mem) {
  executor.runFrom(BOOT_ENTRY, BOOT_MODE, {
    maxSteps: BOOT_MAX_STEPS,
    maxLoopIterations: BOOT_MAX_LOOP_ITERATIONS,
  });
  cpu.halted = false;
  cpu.iff1 = 0;
  cpu.iff2 = 0;
  cpu.sp = STACK_RESET_TOP - 3;
  mem.fill(0xFF, cpu.sp, cpu.sp + 3);
  executor.runFrom(KERNEL_INIT_ENTRY, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 });
  cpu.mbase = 0xD0;
  cpu._iy = 0xD00080;
  cpu._hl = 0;
  cpu.halted = false;
  cpu.iff1 = 0;
  cpu.iff2 = 0;
  cpu.sp = STACK_RESET_TOP - 3;
  mem.fill(0xFF, cpu.sp, cpu.sp + 3);
  executor.runFrom(POST_INIT_ENTRY, 'adl', { maxSteps: 100, maxLoopIterations: 32 });
}
```
