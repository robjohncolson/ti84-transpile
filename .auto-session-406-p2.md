# Task: Trace 0x049DF9 Notification Common Tail

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

Session 405 found that the notification _seqcase table at 0x049D3A has 13 handlers + 1 default, and ALL are identical: each does `LD A,(IX+6)` / `LD (0xD177B8),A` / `JR 0x049DF9`. Every handler stores the payload byte to 0xD177B8 then jumps to a common tail at 0x049DF9.

The notification lifecycle so far:
- Exit Guard (0x0499C0) checks if context can be left
- State Commit (0x049CCA core) does recursive flush + writes new type to 0xD177B9
- Value Store (0x049D3A selector table) stores payload to 0xD177B8
- Common Tail (0x049DF9) — THIS IS UNKNOWN

## Task
Create a probe script `TI-84_Plus_CE/probe-phase406-notification-tail.mjs` that:

1. Reads the ROM binary directly (use `fs.readFileSync('TI-84_Plus_CE/ROM.rom')`)
2. Disassembles 80-120 bytes starting at 0x049DF9 to decode the common tail
3. Specifically look for:
   - Does it write to 0xD177B9 (the type byte)? Or was that already written before the _seqcase dispatch?
   - Does it call back into the recursive flush mechanism?
   - POP AF / JP PO / EI pattern (session 405 mentioned this — interrupt state restore)
   - What value is returned in A? Session 405 says it returns A=(IX-1)
   - Any CALL/JP targets
   - Any RAM reads/writes
4. Also disassemble the code BEFORE 0x049DF9 (go back ~20 bytes to 0x049DE5) to see how the last handler flows into the tail
5. Trace any CALL targets found within the tail (disassemble 30-40 bytes of each)

Also create `TI-84_Plus_CE/phase406-notification-tail-report.md` with findings.

## eZ80 Instruction Reference
- POP AF = 0xF1
- JP PO,nn = 0xE2 lo mid hi (jump if parity odd — used for interrupt state checking)
- EI = 0xFB
- DI = 0xF3
- LD A,(IX+d) = 0xDD 0x7E dd
- LD A,(IX-1) = 0xDD 0x7E 0xFF
- LD (nn),A = 0x32 lo mid hi (ADL mode)
- CALL nn = 0xCD lo mid hi
- JP nn = 0xC3 lo mid hi
- RET = 0xC9
- JR e = 0x18 offset (unconditional relative jump)

eZ80 ADL mode: addresses are 3 bytes (24-bit).
