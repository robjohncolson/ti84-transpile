# Task: Trace 0x08210D — Dispatch Table Entry Registration Writer

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The transpiler lifts eZ80 machine code into JavaScript. We've discovered a dispatch table mechanism:

- **D0259A** is a 24-bit pointer (NOT a count) that tracks the current top of a dispatch table
- The table grows DOWNWARD from 0xD3FFFF
- Each entry is 9 bytes
- **0x09DEF4** resets the table: `LD HL,0xD3FFFF → LD (D0259A),HL`
- **0x08210D** is the SOLE entry registration writer — the ONLY site in the entire ROM that writes to D0259A (besides the reset at 0x09DEF4)
- 0x0846EA is the lookup function called by 235 sites to search the table

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase276-08210d-entry-writer.mjs` that:

1. **Statically disassembles 0x082100-0x082160** by reading ROM bytes from `TI-84_Plus_CE/ROM.rom` and decoding eZ80 ADL-mode instructions. Print each instruction with address. Focus on:
   - Where does it subtract 9 from D0259A (or HL loaded from D0259A)?
   - What 9 bytes does it write? (handler address? flags? context ID?)
   - What register holds the entry data before the write?

2. **Dynamically traces 0x08210D** using the transpiled runtime:
   - Boot the CPU: `import { createCPU } from './cpu-runtime.js'`
   - Load ROM: `fs.readFileSync('./ROM.rom')` into memory
   - Run kernel init (PC=0x000000) for 50,000 steps to initialize OS state
   - Seed D0259A with 0xD3FFFF (empty table)
   - Set PC=0x08210D with reasonable register values (try HL=some handler address like 0x058241, DE=some context, BC=some flags)
   - Run for 500 steps with step-by-step tracing
   - Watch: D0259A value changes, any writes in the D3FFxx range, register changes
   - Try multiple entry scenarios to understand the 9-byte entry format

3. **Report findings**: What are the 9 bytes? How is D0259A decremented? What's the entry format?

## eZ80 ADL instruction reference (key opcodes)
- `ED 4B xx xx xx` = LD BC,(xxxx), `ED 5B xx xx xx` = LD DE,(xxxx), `ED 6B xx xx xx` = LD HL,(xxxx)
- `ED 43 xx xx xx` = LD (xxxx),BC, `ED 53 xx xx xx` = LD (xxxx),DE, `ED 63 xx xx xx` = LD (xxxx),HL
- `21 xx xx xx` = LD HL,imm24, `11 xx xx xx` = LD DE,imm24, `01 xx xx xx` = LD BC,imm24
- `CD xx xx xx` = CALL addr24, `C3 xx xx xx` = JP addr24
- `23` = INC HL, `2B` = DEC HL, `09` = ADD HL,BC, `19` = ADD HL,DE
- `ED B0` = LDIR (copy BC bytes from HL to DE)
- `36 xx` = LD (HL),imm8, `77` = LD (HL),A, `70-75` = LD (HL),r
