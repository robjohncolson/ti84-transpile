# Session 250 P2: Add regression model tokens to browser-shell direct-eval

## Context
This is a TI-84 Plus CE ROM transpilation project with a browser shell at `TI-84_Plus_CE/browser-shell.html`. The shell has a direct-eval system that handles TI-84 token sequences — when the user types an expression, tokens are matched against registered handlers. Session 249 added randNorm, randBin, expr, toString, length, inString, sub, 1-Var Stats, and 2-Var Stats. Session 208 added chi2pdf, tpdf, Fpdf, invχ², invF. Session 204 added normalcdf, invNorm, normalpdf, binompdf, binomcdf, geometpdf, geometcdf, stdDev, variance, not.

## Task
Add the following TI-84 regression/model tokens to the direct-eval system in `TI-84_Plus_CE/browser-shell.html`:

1. **LinReg(ax+b)** [0xBB, 0xF4] — Linear regression. Takes list L1, L2 (from args or default). Computes a, b, r², r using least-squares. Stores to RegEQ if freq list not given. Output: "a=...\nb=...\nr²=...\nr=..."
2. **QuadReg** [0xBB, 0xF5] — Quadratic regression (ax²+bx+c). Least-squares fit. Output: "a=...\nb=...\nc=...\nR²=..."
3. **CubicReg** [0xBB, 0xF6] — Cubic regression (ax³+bx²+cx+d). Output: "a=...\nb=...\nc=...\nd=...\nR²=..."
4. **ExpReg** [0xBB, 0xF9] — Exponential regression (ab^x). Transform: ln(y) = ln(a) + x·ln(b). Output: "a=...\nb=...\nr²=...\nr=..."
5. **LnReg** [0xBB, 0xFA] — Logarithmic regression (a+b·ln(x)). Transform: y = a + b·ln(x). Output: "a=...\nb=...\nr²=...\nr=..."
6. **PwrReg** [0xBB, 0xFB] — Power regression (ax^b). Transform: ln(y) = ln(a) + b·ln(x). Output: "a=...\nb=...\nr²=...\nr=..."
7. **Med-Med** [0xBB, 0xF3] — Wait, 0xF3 is 2-Var Stats. Use **[0xBB, 0xF8]** for Med-Med. Median-median line (resistant line). Split data into thirds, compute median points, fit line. Output: "a=...\nb=..."

## Implementation pattern
Look at how existing tokens are registered in `browser-shell.html`. The pattern is:
- Token registration in the `directEvalTokens` array (around line 1590+) as `['tokenName', [byte1, byte2]]`
- Handler function in the direct-eval switch/dispatch section
- Helper functions for the math (prefix with underscore, e.g., `_linRegFit`)

For regression functions:
- Parse the input to extract two lists (L1 and L2 or explicit `{1,2,3},{4,5,6}` syntax)
- Implement the actual regression math (least-squares for linear, matrix solve or normal equations for polynomial)
- Format output as the TI-84 displays it (each coefficient on its own line)
- For transformed regressions (ExpReg, LnReg, PwrReg), transform data, run linear regression on transformed data, back-transform coefficients

## Helper math needed
- `_linRegCore(xArr, yArr)` — returns {a, b, r2, r, n, sumX, sumY, sumX2, sumXY, sumY2}
- `_polyRegCore(xArr, yArr, degree)` — polynomial regression via normal equations (Gaussian elimination)
- `_medMedLine(xArr, yArr)` — median-median resistant line
