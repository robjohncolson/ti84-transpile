## Context

In session 302, we decoded the token dispatch system at 0x022331. ALL token deposit paths converge on **0x0236F9** — the "TOKEN BUFFER WRITER". This is the final destination for all token paths. It was identified as:

We need the FULL picture: what buffer does it write to? How big is the buffer? How is it consumed? Who reads it?

Also note: **0x0236F1** is a related entry point (string copy path from 0x022470).
