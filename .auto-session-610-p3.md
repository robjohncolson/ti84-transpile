# Auto-Session 610 — P3: Post-Key1 Snapshot + Re-arm D007CA Hybrid

## Context

This is a TI-84 Plus CE ROM transpilation project. The lifted OS processes keypresses but has a structural wipe at 0x0018F8 that zeroes OS state (D007CA, edit cursors, etc.) during processing.

Session 607 proved: using ALL-ZEROS post-wipe snapshot → keys 2-3 halt correctly (~194K steps) but no cxMain dispatch (no display). Session 608-609 proved: using post-paint snapshot with selective zeroing → keys 2-3 get cxMain but run away (stale edit buffer pointers cause infinite walker loop).

The HYPOTHESIS: capture state AFTER key1 fully completes (at halt, step ~276K), then re-arm D007CA from ROM 0x0585D3 (21-byte home context descriptor). The post-key1 state should have a VALID edit buffer (rebuilt by OS during processing) AND no stale pointers (the second wipe at step ~275K zeroes them). Combined with D007CA re-armed = both cxMain dispatch AND valid edit buffer.

## Task

Create a probe `TI-84_Plus_CE/probe-phase610-postkey1-hybrid.mjs` that:

### Step 1: Full boot + init + paint + key1

```javascript
import { readFileSync } from 'fs';
import { createCPU } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(rom, peripherals);

// Standard boot
cpu.sp = 0xD1A87E - 24;
const retAddr = 0x0019b5;
cpu.mem[cpu.sp] = retAddr & 0xFF;
cpu.mem[cpu.sp + 1] = (retAddr >> 8) & 0xFF;
cpu.mem[cpu.sp + 2] = (retAddr >> 16) & 0xFF;
cpu.write24(0xD008E0, cpu.sp);
cpu.adl = 1;

// OS init
cpu.runFrom(0x09DD62, { maxSteps: 300000, maxLoopIterations: 30000 });

// Home repaint
peripherals.setTimerEnabled(true);
cpu.mem[cpu.sp] = 0xb5; cpu.mem[cpu.sp+1] = 0x19; cpu.mem[cpu.sp+2] = 0x00;
cpu.write24(0xD008E0, cpu.sp);
cpu.runFrom(0x058241, { maxSteps: 300000, maxLoopIterations: 30000 });

// Key1: '2' (scan code 0x90)
cpu.mem[0xD0058C] = 0x90;
cpu.mem[0xD0009F] |= 0x20;
cpu.mem[cpu.sp] = 0xb5; cpu.mem[cpu.sp+1] = 0x19; cpu.mem[cpu.sp+2] = 0x00;
cpu.write24(0xD008E0, cpu.sp);
const r1 = cpu.runFrom(0x08C331, { maxSteps: 350000, maxLoopIterations: 30000 });
console.log('Key1 result:', r1.steps, 'steps, halt:', r1.halted, 'lastPC:', r1.lastPC?.toString(16));
```

### Step 3: Re-arm D007CA from ROM descriptor and dispatch key2

```javascript
// Copy 21-byte home context descriptor from ROM 0x0585D3 → D007CA
for (let i = 0; i < 21; i++) {
  cpu.mem[0xD007CA + i] = rom[0x0585D3 + i];
}
// Set mode flag
cpu.mem[0xD0008D] = rom[0x0585D3 + 21]; // byte after descriptor

console.log('Re-armed D007CA:', cpu.read24(0xD007CA).toString(16));

// Seed key2: '3' (scan code 0x91)
cpu.mem[0xD0058C] = 0x91;
cpu.mem[0xD0009F] |= 0x20;
cpu.mem[cpu.sp] = 0xb5; cpu.mem[cpu.sp+1] = 0x19; cpu.mem[cpu.sp+2] = 0x00;
cpu.write24(0xD008E0, cpu.sp);

const r2 = cpu.runFrom(0x08C331, { maxSteps: 350000, maxLoopIterations: 30000 });
console.log('Key2 result:', r2.steps, 'steps, halt:', r2.halted, 'lastPC:', r2.lastPC?.toString(16));
console.log('Key2 D007CA after:', cpu.read24(0xD007CA).toString(16));
console.log('Key2 cxMain reached:', r2.blockLog?.includes(0x0585E9) ?? 'unknown');
```
