# Task: Decode 0x07CF96 — Shared Copy/Conversion Routine

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 ADL mode). We decode ROM subroutines by writing Node.js probes that read raw bytes and disassemble them.

## Target
**0x07CF96** — A shared copy/conversion routine. Two known callers:
- 0x07CF9D (shared setup stub, 10B): `LD HL,D00603 (OP2); LD DE,D02B39; JR 0x07CF96`
- 0x07CF1A (matrix 0x1C handler, 130B) also calls this

The JR from 0x07CF9D targets 0x07CF96, so this routine starts at 0x07CF96 and likely runs until it hits a RET. HL=OP2 address (0xD00603), DE=RAM buffer (0xD02B39) on entry from 0x07CF9D.

## What To Do
1. Create `TI-84_Plus_CE/probe-phase534-decode-07CF96-shared-copy.mjs`
2. Read raw ROM bytes starting at 0x07CF96. Read at least 64 bytes (the routine is likely short — under 30 bytes).
3. Disassemble as **eZ80 ADL mode** (24-bit addresses = 4-byte immediates for LD nn, 3-byte for JR/DJNZ offsets are still 1-byte signed). Use the project's `ez80-decoder.js` if available, or manually decode from the opcode table.
4. Document each instruction with address, raw bytes, mnemonic, and operands.
5. Identify: what does it copy? How many bytes? Does it use LDIR/LDI? What are the CALL targets?
6. Write findings as comments in the probe file.

## eZ80 ADL Opcode Reminders
- `LD rr, nn` uses 4-byte immediates (e.g., `21 xx xx xx` = LD HL, xxxxxxxx where bytes are little-endian 24-bit)
- `.SIL` prefix = `52` (forces short/Z80 mode for next instruction)
- `ED B0` = LDIR, `ED A0` = LDI
- `C9` = RET, `CD xx xx xx` = CALL nn (3-byte address)
- `18 xx` = JR offset (signed byte)

## Key Addresses
- OP1 = 0xD005F8, OP2 = 0xD00603, OP3 = 0xD0060E (11 bytes apart)
- 0xD02B39 = RAM save buffer (used by matrix/type handlers)

## Constraints
- Do NOT modify any existing files except creating the new probe
- Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase534-decode-07CF96-shared-copy.mjs`
- The probe only needs to READ ROM bytes and print disassembly — no CPU execution needed
- Output the full disassembly listing to stdout

## Success Criterion
Probe runs, prints a complete disassembly of the routine at 0x07CF96 from entry to RET, with all instructions annotated.
