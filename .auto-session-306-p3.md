# Auto-Session 306 P3: Trace SDK _GetCSC IY+40 BIT 3 Check at 0x03FBD0

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80).

Session 305 fully traced the _GetCSC key-present path. Within that path, there's a secondary check at 0x03FBD0 that tests `BIT 3,(IY+40)`. If set, it forces A=0x39 as a key override. We need to understand what this flag controls and when IY+40 bit 3 gets set.

The SDK _GetCSC function starts at 0x03FA09. IY is typically 0xD00080 in the OS, so IY+40 = 0xD000A8 (decimal offset 40) or IY+0x28 = 0xD000A8 (hex offset 0x28).

## Task

2. **Find all ROM locations that SET or RES bit 3 of the byte at IY+40**:
   - Search ROM for `SET 3,(IY+40)` and `RES 3,(IY+40)` instructions
   - Also search for direct writes to the absolute address (0xD000A8 if IY=0xD00080, or 0xD000C8 if IY+40 means offset 0x28 hex)
   - Check both interpretations: IY+0x28 (40 decimal) and IY+0x40 (64 decimal)
3. **Determine what scan code 0x39 represents** — check `TI-84_Plus_CE/keyboard-matrix.md`
4. **Trace the context**: when does this flag get set? During key combos? Mode changes? App switches?
