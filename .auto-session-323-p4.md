# Task: Investigate 5 Unreferenced LCD Wrapper Functions

## Context
You are working on a TI-84 Plus CE ROM transpilation project. Session 322 mapped 51 LCD port wrapper functions in `TI-84_Plus_CE/phase322-lcd-port-wrappers-report.md`. 5 of these have ZERO direct callers (CALL/JP references):

1. **0x7B19** — `read_port_8040_8041_16bit` (reads ports 0x8040+0x8041 as 16-bit HL)
2. **0x7B70** — `read_port_800C_800D_16bit` (reads ports 0x800C+0x800D as 16-bit HL)
3. **0x7D89** — `port_8020_clear_bit4` (RMW: AND 0xEF on port 0x8020)
4. **0x7DBB** — `port_8020_read_bit6` (reads port 0x8020 AND 0x40)
5. **0x7DC6** — `read_port_8034` (reads port 0x8034)

## What to do
Write a probe at `TI-84_Plus_CE/probe-phase323-unreferenced-lcd-wrappers.mjs` that:

1. **Scans the ROM binary** for ALL references to each of the 5 addresses. Search for:
   - Direct CALL: `CD xx xx xx` (3-byte address in little-endian ADL mode, so address 0x007B19 = bytes `19 7B 00`)
   - Direct JP: `C3 xx xx xx`
   - Direct CALL with prefix: `49 CD xx xx` or `52 CD xx xx` (.SIS/.LIS prefix)
   - LD instructions that load the address (could be function pointers): `21 xx xx xx` (LD HL), `11 xx xx xx` (LD DE), `01 xx xx xx` (LD BC)
   - Raw 3-byte address patterns anywhere in ROM (potential pointer table entries)

2. For each address, report:
   - How many CALL/JP references found (should be 0 if truly unreferenced)
   - How many LD references found (potential indirect callers)
   - How many raw address patterns found (potential pointer table entries)
   - For each match: the ROM address where the reference was found and what instruction it appears to be

3. **Also check function pointer tables** — scan the ROM for regions that look like dense pointer tables (sequences of 3-byte or 4-byte aligned addresses in the 0x007xxx range). Report any tables that contain these addresses.

### Reference for probe pattern
Look at existing probes in `TI-84_Plus_CE/` for the import pattern. The ROM is available as `cpu.rom` (4MB Uint8Array) or can be loaded directly from `TI-84_Plus_CE/ROM.rom`.

Key: the ROM file is 4MB. Addresses 0x000000-0x3FFFFF. Read it with `fs.readFileSync`.

For scanning: search for the 3-byte little-endian representation of each address. E.g., for 0x007B19, search for bytes `19 7B 00` in the entire ROM.

- Do NOT edit any other files
