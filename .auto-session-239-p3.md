# Task: Find all D003E0 write sites in ROM

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM binary is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 machine code).

D003E0 is a critical mode/context byte in TI-OS RAM. Session 238 confirmed that on the home screen D003E0=0x00, and specific bits must be set to activate alternate code paths from 0x04EDD0 (the shared post-classification handler). Session 219 found:
- Sole writer: 0x04EE3E does `SET 4,A / LD (0xD003E0),A` — does NOT set BIT 3 directly
- 0x051D52 does `RES 2,(HL) / RES 3,(HL)` which CLEARS bits 2+3
- 3 BIT 3 test sites: 0x04EABD, 0x04EB66, 0x051CF3
- Boot=0x00, event loop doesn't write

But session 219 only found 1 write site. There may be more — the search may have been incomplete (only looked for LD (D003E0),A pattern).

## Task
Create a probe `TI-84_Plus_CE/probe-phase239-d003e0-write-sites.mjs` that does a comprehensive static ROM binary scan for ALL instructions that could write to address 0xD003E0. Search for:

1. **LD (0xD003E0),A** — opcode patterns `32 E0 03 D0` (z80 mode) and with ADL prefix
2. **LD (HL),A / LD (HL),value** where HL could be 0xD003E0 — search for `LD HL,0xD003E0` (`21 E0 03 D0`) followed by any store
3. **SET n,(HL)** and **RES n,(HL)** where HL=0xD003E0 — look for `LD HL,0xD003E0` within 20 bytes before SET/RES instructions
4. **LD (IX+d),A** or **LD (IY+d),A** patterns that could target D003E0 (less likely but check)
5. **LDIR/LDDR** bulk copies that could overwrite D003E0 (check for destination ranges)

For each write site found, report:
- ROM address
- Instruction bytes (hex dump of surrounding 8-16 bytes for context)
- Disassembly of the instruction and 2-3 surrounding instructions
- Whether it's a SET/RES (bit manipulation) or full-byte write

Also check for **pointer table references** to 0xD003E0: scan for the byte sequence `E0 03 D0` anywhere in ROM and classify each hit as CODE (instruction operand) or DATA (pointer in table).

Use the ROM binary directly (`fs.readFileSync('ROM.rom')`), NOT the transpiled JS.
