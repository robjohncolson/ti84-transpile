# Task: Trace 0x010220 Display Callback Registration

## Context
The TI-84 Plus CE OS has a display callback system at RAM D177BC-D177E1:
- D177BC: enable flag (1 byte)
- D177BD-D177C9: 5 callback slots, each 3 bytes (24-bit function pointer)
- D177D6: pending-flags bitmask
- Additional fields through D177E1

Session 317 found that 0x010220 is the display callback DISPATCH function (~400 bytes). It's reached via: OS vector entry 0 at 0x000580 → JP 0x010220. Sole caller of 0x000580: 0x03D14F in LCD SPI handler.

Session 315 identified 3 OS API vectors for this subsystem: dispatch, clear, and install. The dispatch vector is now confirmed as entry 0 (0x000580 → 0x010220).

## What To Do

1. Read the ROM file at `TI-84_Plus_CE/ROM.rom` (4MB binary, little-endian eZ80).

2. **Find all writes to D177BD-D177C9** (the 5 callback slots): Search the ROM for byte sequences that reference addresses D177BD through D177C9. Each slot is 3 bytes:
   - Slot 0: D177BD, D177BE, D177BF
   - Slot 1: D177C0, D177C1, D177C2
   - Slot 2: D177C3, D177C4, D177C5
   - Slot 3: D177C6, D177C7, D177C8
   - Slot 4: D177C9 (first byte only if 3-byte slot continues to D177CB)
   
   Actually, 5 slots × 3 bytes = 15 bytes: D177BD through D177CB. Search for write instructions (LD (nn), r patterns) targeting these addresses.

3. **Identify the INSTALL and CLEAR API vectors**: Session 315 mentioned 3 OS API vectors. We know dispatch = entry 0 (0x000580). Look in the JP mega-table at 0x020110 for entries near entry 0 that JP to functions writing to D177BD-D177CB. Check entries 1-10 specifically:
   - Entry 0: 0x020110 → JP 0x000580 (dispatch, confirmed)
   - Entry 1: 0x020114 → read the JP target
   - Entry 2: 0x020118 → read the JP target
   - etc.
   
   Disassemble each target and check if it writes to the D177BD-D177CB range.

4. **Trace who calls the install vector**: Once identified, find all CALL/JP references to the install function. These are the OS subsystems that register display callbacks.

5. **What callbacks get installed?**: For each install call site, what function pointer is being installed? (It's typically in a register like HL before the CALL.)
