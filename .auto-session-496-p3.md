# Auto-session 496 P3 — Search Non-BCALL Cursor Functions (Full ROM Scan)

## Goal
Search the ENTIRE ROM (0x000000-0x3FFFFF) for functions that reference BOTH D00595 (cursor row) AND D00596 (cursor column), focusing on functions NOT in the BCALL table. The cursor draw may be an internal utility never registered as a BCALL entry.

## Context
- Session 491 found 14 functions in 0x060000-0x062000 that read D00595/D00596. This probe expands that search to the FULL ROM.
- Key internal routines NOT in the BCALL table: 0x0059C6 (charRenderer), 0x005A48 (VRAM row calc), 0x0A2400 (pixel renderer). The cursor draw may also be an internal routine.
- The BCALL table targets are in `TI-84_Plus_CE/bcall-table.json`. Any function found that is NOT a target in that table is an "internal" (non-BCALL) function — these are our primary interest.
- Byte patterns (little-endian 24-bit addresses):
  - D00595 → [0x95, 0x05, 0xD0]
  - D00596 → [0x96, 0x05, 0xD0]
  - VRAM base region: any reference to 0xD4xxxx (bytes [xx, xx, 0xD4] where the address is ≥ 0xD40000)
  - Cursor glyphs: single-byte values 0xE1, 0xE2, 0xE3 (less specific, use only as tiebreaker)

## Deliverable
Create `TI-84_Plus_CE/probe-phase496-rom-cursor-scan.mjs` that:

1. Loads ROM.rom (4MB buffer) and bcall-table.json
2. Builds a Set of all BCALL target addresses for quick lookup
3. Scans the ENTIRE ROM for occurrences of the D00595 and D00596 byte patterns
4. For each match, identifies the "function" it belongs to by scanning backward from the match to find a plausible function entry point (look for common eZ80 function prologues: PUSH IX/IY = DD E5 / FD E5, or just report the match address and context)
5. Groups matches by 256-byte windows (i.e., matches within 256 bytes of each other are in the same "function region")
6. For each region that has BOTH D00595 and D00596 references:
   - Reports the address range
   - Reports whether ANY address in that range is a BCALL target (cross-reference with bcall-table.json)
   - Reports additional pattern matches: 0x0059C6 (charRenderer), 0xD4 high-byte references (VRAM), cursor glyph bytes nearby
   - Flags as "NON-BCALL INTERNAL" if no BCALL targets found in the region
7. Outputs two lists:
   - **Primary**: Non-BCALL regions with both D00595+D00596 (these are the cursor draw candidates)
   - **Secondary**: BCALL regions with both D00595+D00596 (for cross-reference with P1's scan)

const romBytes = fs.readFileSync(path.join(__dirname, 'ROM.rom'));
const bcallTable = JSON.parse(
  fs.readFileSync(path.join(__dirname, 'bcall-table.json'), 'utf8')
);

// Build set of BCALL targets
const bcallTargets = new Set(bcallTable.map(e => e.targetAddr));

// Scan entire ROM for D00595 and D00596

    colMatches.push(addr);
