# Auto-Session 312 — Priority 2: Decode Top Low-Address OS API Vectors

## Task
The low-address region 0x000200-0x000400 is a 128-entry OS API jump vector table. The top two vectors — 0x000204 (140 callers) and 0x000264 (140 callers) — are the most-called OS API vectors. Decode the top 10 vectors by caller count.

## What to do

1. **Gunzip the transpiled JS** if not already done:
   ```bash
   gunzip -k TI-84_Plus_CE/ROM.transpiled.js.gz
   ```

2. **Identify the top 10 vectors by caller count.** The vector table is at 0x000200-0x000400. Each entry is a 3-byte JP instruction (JP target). Scan the transpiled JS for CALL references to addresses in this range. Sort by caller count, take top 10.

3. **For each of the top 10 vectors:**
   - Read the JP instruction at the vector address from the ROM (`TI-84_Plus_CE/ROM.rom`)
   - Identify the jump target
   - Disassemble the target function (first 30-50 bytes minimum)
   - Categorize its function: memory management? string operation? math? I/O? flag test?
   - Note the register contract (what goes in, what comes out)

4. **Cross-reference with ti84pceg.inc names** if possible. The file `TI-84_Plus_CE/ti84pceg.inc` or similar SDK header may have symbolic names for these vectors. Search the repo for `.inc` or `.h` files that define OS call addresses.

5. **Write results** to `TI-84_Plus_CE/phase312-top-vectors-report.md` with:
   - Table of top 10 vectors: address, target, caller count, category, name (if known)
   - Brief disassembly of each target
   - Overall characterization of what the vector table provides

6. **Write a probe** at `TI-84_Plus_CE/probe-phase312-top-vectors.mjs` that:
   - Loads the ROM binary
   - Reads JP targets from the top 10 vector addresses
   - Counts callers in the transpiled JS
   - Prints a summary table

## Key addresses
- Vector table: 0x000200-0x000400 (128 entries, 3 bytes each = JP instructions)
- ROM file: `TI-84_Plus_CE/ROM.rom`
- Transpiled JS: `TI-84_Plus_CE/ROM.transpiled.js`
- Previous utility family analysis: `TI-84_Plus_CE/phase311-utility-clusters-report.md`

- Do NOT run `probe-phase99d-home-verify.mjs`
