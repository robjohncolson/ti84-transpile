- 0x03E187 contains ED 39/ED 38/ED 7E opcodes — eZ80 OUT0 instructions for flash unlock/page-select sequences
- It checks port values (CP 0x88, JP NZ 0x000066 = reset vector)
- Falls through to token processing body at 0x03E230 on success
- Session 517 decoded 0x03E1B4's wrapper structure but NOT the internals of 0x03E187

   - ED 39 XX = OUT0 (XX),A (write A to I/O port XX)
