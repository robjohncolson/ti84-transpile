# Task: Add 20 New Transpiler Seeds for Coverage Push

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The transpiler at `scripts/transpile-ti84-rom.mjs` lifts eZ80 machine code from `TI-84_Plus_CE/ROM.rom` into JavaScript. Seeds are entry point addresses that tell the transpiler where executable code begins. Current state: 145,299 blocks, 710,563 covered bytes.

## What to Do
1. Run the coverage analyzer to find gaps:
   ```bash
   node TI-84_Plus_CE/coverage-analyzer.mjs
   ```

2. Read the output — it lists uncovered ROM regions. Pick 20 addresses from uncovered regions that look like valid code entry points. Good heuristics:
   - Addresses that are CALL targets from already-covered code
   - Addresses at the start of uncovered gaps (first byte after a covered region ends)
   - Addresses referenced in the JP table (0x020104-0x02230C range, each entry is 4 bytes: C3 + 3-byte address)
   - AVOID addresses in known data regions (font tables at 0x03B000+, certificate data at 0x3F0000+)

3. Add the 20 seeds to the `seeds` array in `scripts/transpile-ti84-rom.mjs`. Find the array (search for `const seeds` or `seeds =`), and append your 20 new addresses. Keep them sorted if the existing array is sorted, or append at the end with a comment like `// session 413 seeds`.

4. Run the transpiler to verify:
   ```bash
   node scripts/transpile-ti84-rom.mjs
   ```
   Check output for new block/byte counts.

5. Run the golden regression to verify nothing broke:
   ```bash
   node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
   ```
   This MUST pass (26/26 cells, "Normal Float Radian" decoded).

6. Run the true coverage audit:
   ```bash
   node TI-84_Plus_CE/audit-true-uncovered.mjs
   ```

## Constraints
- ONLY modify `scripts/transpile-ti84-rom.mjs` (to add seeds)
- Do NOT modify any other files
- Do NOT add seeds below 0x000100 (reset vectors) or above 0x3E0000 (certificate/erased region)
- Do NOT add seeds that are already in the seeds array
- The golden regression MUST still pass after your changes
- Report the before/after block and byte counts
