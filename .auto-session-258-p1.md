# Task: Find all SET/RES/BIT sites on IY+9 bit 0

## Context
This is a TI-84 Plus CE ROM transpilation project. We disassemble eZ80 machine code from the OS ROM and trace execution paths. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB binary). IY = 0xD00080 (OS flags base). IY+9 = 0xD00089.

## Background
Session 257 disassembled function 0x09E2EC which writes to D007E0 (context mode ID). The critical gate is `BIT 0,(IY+9)` — if bit 0 is CLEAR, the function returns early via `RET Z` before reaching the `LD (D007E0),A` store. After boot, IY+9 bit 0 = 0 (CLEAR). We need to find what SETs this bit to enable context registration.

## Deliverables
Create probe file: `TI-84_Plus_CE/probe-phase258-iy9-bit0-sites.mjs`

The probe should:
1. **Static ROM binary scan** for all SET/RES/BIT instructions on IY+9 bit 0:
   - `SET 0,(IY+9)` = bytes `FD CB 09 C6`
   - `RES 0,(IY+9)` = bytes `FD CB 09 86`
   - `BIT 0,(IY+9)` = bytes `FD CB 09 46`
2. Also scan for direct writes to 0xD00089:
   - `LD (0xD00089),A` in ADL mode = `ED 39 89 00 D0` (note: eZ80 ADL stores are `ED 39 rr ll hh`)
   - Actually the correct encoding for `LD (nn),A` in eZ80 ADL is `32 89 00 D0` (4 bytes)
3. For each site found, read the surrounding 32 bytes of ROM context (16 before, 16 after) and print hex + a brief decode of the neighboring instructions.
4. Classify each site: SET (armer), RES (disarmer), BIT (tester), LD (direct write).
5. Print summary: total sites by type, addresses grouped by ROM region (0x00xxxx, 0x02xxxx, 0x04xxxx, etc.)

## Reference
Look at existing probes for the pattern. Example: `TI-84_Plus_CE/probe-phase232-iy29-bit0-test-sites.mjs` does a similar IY flag site scan.

## Technical Details
- Use `fs.readFileSync('TI-84_Plus_CE/ROM.rom')` to read the ROM
- ROM is 4,194,304 bytes (0x400000)
- IY+9 = offset 9 from IY base (0xD00080), so actual address = 0xD00089
- eZ80 prefix bytes: FD = IY prefix, CB = bit manipulation prefix
- The probe is a Node.js .mjs file, runs with `node TI-84_Plus_CE/probe-phase258-iy9-bit0-sites.mjs`
