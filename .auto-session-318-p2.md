# Task: Map D177B9 State Transitions (OS Context/Screen State)

## Context
The TI-84 Plus CE OS uses RAM address D177B9 as a "context state byte" that determines which screen/mode the calculator is in. Two structurally identical key-dispatch functions read this byte:

- **0x049CCA** (flash copy, 166 callers): handles 13 states: 0x01, 0x02, 0x03, 0x04, 0x10, 0x11, 0x12, 0x13, 0x14, 0x15, 0x16, 0x17, 0x18
- **0x00883C** (low ROM copy, 78 callers): handles 10 states (missing 0x16, 0x17, 0x18)

Both functions: read D177B9, check for state change, run exit_state handler if changed, commit new state, dispatch key via _seqcase. D177B9 has only 2 write sites (one per copy of the dispatch function).
