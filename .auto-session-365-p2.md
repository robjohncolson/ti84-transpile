# Task: Add Seed 0x006900 and Regenerate Transpiled JS

## Context
The TI-84 Plus CE ROM transpilation project lifts ROM machine code to JavaScript. "Seeds" are ROM addresses where the transpiler starts disassembling. The probe from session 364 (Fix B variant) revealed that address 0x006900 is a missing block hit 3 times during boot when the SP clamp is active. Adding it as a seed will let the transpiler generate a block for it.

## What to do

1. **Append seed 0x006900** to `TI-84_Plus_CE/phase200-seeds.txt`. Just add one line at the end:
   ```
   0x006900
   ```

2. **Regenerate the transpiled JS**:
   ```bash
   node scripts/transpile-ti84-rom.mjs
   ```

3. **Check the transpiler report** to confirm the new seed was picked up:
   ```bash
   node -e "const r = require('./TI-84_Plus_CE/ROM.transpiled.report.json'); console.log('Total blocks:', r.totalBlocks); console.log('Seeds:', r.totalSeeds);"
   ```
   Or if that fails, just check the output of the transpile step for block/seed counts.

4. **Run the golden regression**:
   ```bash
   node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
   ```
   Must pass 26/26.

5. **Run the coverage audit**:
   ```bash
   node TI-84_Plus_CE/audit-true-uncovered.mjs
   ```
   Report the new coverage percentage.

## Important constraints
- Only modify `TI-84_Plus_CE/phase200-seeds.txt` (append one line).
- Do NOT modify `scripts/transpile-ti84-rom.mjs`, `cpu-runtime.js`, or any other source file.
- Do NOT commit `TI-84_Plus_CE/ROM.transpiled.js` — it's gitignored (175MB+). Only the `.gz` gets committed.
- After regenerating, compress: `cd TI-84_Plus_CE && gzip -kf -9 ROM.transpiled.js`

## Deliverables
