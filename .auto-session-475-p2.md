## Background
- The idle loop at 0x02FDBE checks D00000: if 0, takes JP Z 0x03030E (idle path, no display update). If nonzero, takes the display update path through CALL 0x03D1BE, CALL 0x030078, LD HL,(D00591), CALL 0x040D11
- D00092 bit 4 controls cursor display: 0x030202 returns Z immediately when bit 4 is clear
- D00591 is the cursor address — 0x040D11 reads it for pixel writes
- Session 474 proved: D00080 bit 4 fix works (0x040D11 reached 4× via key processing), but VRAM still 0 bytes changed
- Three conditions for VRAM changes: (a) D00000 nonzero, (b) D00092 bit 4 set, (c) D00591 pointing to VRAM
