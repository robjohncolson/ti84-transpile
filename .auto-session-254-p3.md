# Session 254 P3: Add Missing Direct-Eval Tokens to browser-shell.html

## Context
The TI-84 Plus CE browser-shell has a direct-eval engine that handles calculator expressions via JavaScript. Most AP Stats distribution and regression functions are done. The following are still missing or could be added:

### Tokens to Add
1. **1-PropZTest** [0xBB, 0x40] — One-proportion z-test. Input: p0, x, n. Output: z-statistic, p-value (two-tailed by default). Formula: z = (x/n - p0) / sqrt(p0*(1-p0)/n), p-value from normalcdf.
2. **2-PropZTest** [0xBB, 0x41] — Two-proportion z-test. Input: x1, n1, x2, n2. Output: z-statistic, p-value. Formula: p-hat = (x1+x2)/(n1+n2), z = (p1-p2)/sqrt(p-hat*(1-p-hat)*(1/n1+1/n2)).
3. **1-PropZInt** [0xBB, 0x42] — One-proportion z-interval. Input: x, n, C-level. Output: (p-hat - E, p-hat + E) where E = z* * sqrt(p-hat*(1-p-hat)/n).
4. **2-PropZInt** [0xBB, 0x43] — Two-proportion z-interval. Input: x1, n1, x2, n2, C-level.
5. **ZTest** [0xBB, 0x44] — One-sample z-test. Input: mu0, sigma, x-bar, n. z = (x-bar - mu0)/(sigma/sqrt(n)).
6. **TTest** [0xBB, 0x45] — One-sample t-test. Input: mu0, x-bar, Sx, n. t = (x-bar - mu0)/(Sx/sqrt(n)), df=n-1.
7. **2-SampZTest** [0xBB, 0x46] — Two-sample z-test.
8. **2-SampTTest** [0xBB, 0x47] — Two-sample t-test with Welch's df.
9. **ZInterval** [0xBB, 0x48] — One-sample z-interval.
10. **TInterval** [0xBB, 0x49] — One-sample t-interval.

Note: The existing codebase already has `_normalCdf`, `_invNorm`, `_tCdf`, and `_invT` helper functions. Reuse them.

## How to Add Tokens

Look at the existing pattern in `TI-84_Plus_CE/browser-shell.html`. Search for `poissonpdf` or `1-PropZTest` to find the pattern. Each token needs:

1. **Token map entry** in the `EVAL_TOKEN_MAP` array (around line 1590+):
   ```javascript
   ['1-PropZTest', [0xBB, 0x40]],
   ```

2. **Template handler** registered in `runDirectEvalTemplate` (search for `evalRunTemplate` or `case '1-PropZTest'`):
   ```javascript
   case '1-PropZTest': {
     // parse args, compute, return result string
   }
   ```

3. **Implementation function** (if complex math, add a helper like `_onePropZTest`).

## Important Implementation Details
- Reuse existing helpers: `_normalCdf(lower, upper, mean, sd)`, `_invNorm(area)`, `_tCdf(lower, upper, df)`, `_invT(area, df)`
- For z-intervals, z* = `_invNorm((1+C)/2)` where C is the confidence level (e.g., 0.95)
- For t-intervals, t* = `_invT((1+C)/2, df)`
- Match the existing code style exactly — look at how normalcdf or tcdf are implemented
- These are the **template handler** style (like binompdf), not the simple alias style
