# Task: Decode the 0x08C958 context handler table

## Context
The TI-84 Plus CE OS uses a context handler table at ROM address `0x08C958`. This table has a 3-byte stride (little-endian 24-bit addresses) and is indexed by a context ID via an `MLT` instruction (context_id × 3 + base). Session 341 identified this table in the context setup routine at 0x08C900.

## Raw bytes at 0x08C958
```
41 82 05 55 d7 03 a7 0c 08 67 b6 0a 48 c7 06 53
a6 08 83 c8 09 42 c7 09 0c e3 09 17 fe 05 0b 29
0b b4 e3 09 3c dc 09 dc cb 05 a4 54 04 47 56 04
2a cc 09 70 e3 09 ce 1e
```

## What to do

1. Write a probe at `TI-84_Plus_CE/probe-phase342-context-table.mjs` that:
   - Reads the ROM file (`TI-84_Plus_CE/ROM.rom`)
   - Starting at offset 0x08C958, reads 3-byte little-endian entries
   - Read at least 20 entries (60 bytes) — the table likely has ~19 entries based on 19 cxMain writers found in session 341
   - For each entry, print: `index N: handler = 0xXXXXXX`
   - Cross-reference: compare against the known cxMain writer registry from session 341:
     - 0x058241 (HOME_HANDLER)
     - 0x05CD71, 0x05FFEF, 0x06B4E8, 0x080FB7, 0x0810E8, 0x08149F
     - 0x09D32D, 0x09D22C, 0x0AB83D, 0x0ABA44, 0x0AC035, 0x0ACCDD
     - 0x0B1D3B, 0x0B4DAE, 0x0B62D8
   - Print which table entries match known handlers and which are new/unknown

2. Also determine the table's end. Look for a sentinel (0x000000 or 0xFFFFFF) or look for when addresses become implausible (outside ROM range 0x000000-0x3FFFFF).

3. Write a summary section in the probe's output that maps context indices to handler names where known:
   - Index 0 → 0x058241 → HOME_HANDLER
   - Index N → 0xXXXXXX → "unknown" or matched handler

- Do NOT modify any existing files

## Success criteria
