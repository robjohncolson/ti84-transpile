## How to find good seeds
Run the audit first. It outputs uncovered address ranges. For each range:
1. Read the ROM bytes at that address: `rom[addr]`, `rom[addr+1]`, etc.
2. Look for function prologues:
   - 0xF5 = PUSH AF
   - 0xDD 0xE5 = PUSH IX  
   - 0xFD 0x21 = LD IY,nn
   - 0xC5 = PUSH BC
   - 0xD5 = PUSH DE
   - 0xE5 = PUSH HL
   - 0x3E = LD A,n
3. Verify it's not data by checking the next few bytes make sense as instructions
4. Cross-reference: search for CALL/JP to this address elsewhere in the ROM
