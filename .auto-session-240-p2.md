# Task: Trace 0x04E404 — the return point from 0x04E447's computation loop

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript and executed via `cpu-runtime.js`.

Session 239 found that the loop at 0x0A1A3B-0x0A1A4E (reached via 0x04E447) terminates at ~1450 steps after ~35 iterations. The exit path is: 0x0A1A30 → 0x0A1B8B → 0x0A1CEB → 0x04E404. SP recovers fully.

0x04E404 is the return address after 0x04E447's computation loop completes. We need to know what happens next — does it continue to display update? Does it return to the event loop? Does it call more OS functions?

## Task
Create a probe `TI-84_Plus_CE/probe-phase240-04e404-post-return.mjs` that:

1. Boots the CPU (import from cpu-runtime.js, createCPU, createPeripheralBus with timerInterrupt:false)
2. Sets up context to reach 0x04E404:
   - Option A: Start at 0x04EDD0 (the shared handler) and let it naturally reach 0x04E447 → 0x04E404 (may take many steps)
   - Option B: Directly set PC=0x04E404 with appropriate stack/register state from what session 239 found
   - Try Option B first for speed, with Option A as validation
3. For Option B: set SP to a reasonable value (0xD1A800), push a return sentinel (0xCAFE) on stack, set IX=0xD1A860
4. From 0x04E404, trace execution for 2000 steps and record:
   - Every unique block visited (PC values)
   - Key function calls (CALL instructions — look for blocks that start new call chains)
   - Any VRAM writes (addresses in 0xD40000-0xD52C00 range)
   - Any IY flag changes
   - RAM writes to key addresses: D003E0, D007E0, D00824, D0058E
   - Where execution ends up (event loop at 0x02FD99? HALT? Return to caller?)
5. Disassemble 0x04E404 and the next 30 bytes from ROM.rom to understand the instruction sequence

## Disassembly helper
To disassemble ROM bytes, read ROM.rom and decode eZ80 instructions manually. Key opcodes:
- 0xCD = CALL nn (3-byte address in ADL mode)
- 0xC3 = JP nn
- 0xC9 = RET
- 0x18 = JR d
- 0x3E = LD A,n
- 0xCB = prefix for BIT/SET/RES
- 0xFD = IY prefix
- 0xDD = IX prefix
