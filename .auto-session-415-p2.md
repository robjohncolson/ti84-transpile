## eZ80 decoding notes

- eZ80 is a superset of Z80 with 24-bit addresses. Most instructions are 1-4 bytes.
- LD r,(addr) uses 3-byte little-endian absolute addresses
- CALL addr and JP addr use 3-byte addresses
- Prefixes: 0xDD=IX, 0xFD=IY, 0xED=extended, 0xCB=bit ops
- 0x40 can be a .SIS prefix (changes immediate size to 16-bit) — check context
- Common stack frame: CALL 0x00218A (allocates frame, sets IX), CALL 0x002197 (variant)
