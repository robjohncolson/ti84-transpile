## How to decode
Use Node.js to read the ROM binary. eZ80 instructions are variable-length. Key opcodes:
- `0xCD` = CALL.LIL (4 bytes: CD + 3-byte LE addr)
- `0xC9` = RET
- `0xC3` = JP.LIL (4 bytes)
- `0x21` = LD HL,imm24 (4 bytes in ADL mode)
- `0x11` = LD DE,imm24 (4 bytes in ADL mode)
- `0x3E` = LD A,imm8 (2 bytes)
- `0xCB` prefix = bit operations
- `0xDD`/`0xFD` = IX/IY prefix (IY+offset for system flags)
- `0xED` prefix = extended ops
- `0x40` prefix (.SIS) = short mode override
- `0xFD 0xCB offset op` = IY bit operations (BIT/SET/RES on (IY+offset))

Read bytes from the ROM buffer at the target offset and walk through the instruction stream. Function boundaries are typically RET (0xC9) or unconditional JP (0xC3).
