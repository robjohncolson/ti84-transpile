# Task: Trace All D177B7 Write Sites in ROM

## Context
In the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, D177B7 is the display-dirty flag. It's set to 0x55 to mean "needs refresh" and cleared to 0x00 after the display refresh path runs. Session 452 confirmed this behavior.

We need to find ALL locations in the ROM that write to address 0xD177B7, to understand:
- Who sets it to 0x55 (arms the display refresh)?
- Who clears it to 0x00 (marks refresh complete)?
- Are there other values written (e.g., 0xAA)?

## Approach
The eZ80 instructions that write to a fixed memory address include:
- `LD (nn), A` — opcode 0x32 followed by 3-byte address (little-endian: B7 77 D1)
- `LD (nn), HL/BC/DE` — ED-prefixed opcodes followed by 3-byte address  
- But the most common pattern for a single-byte flag is `LD (nn), A` = `32 B7 77 D1`
- Also `LD (nn), r` for other registers in the ED prefix group

Search the ROM binary file `TI-84_Plus_CE/ROM.rom` (4MB) for all occurrences of the byte sequence that encodes writes to 0xD177B7.

## Deliverable
Create `TI-84_Plus_CE/probe-phase453-d177b7-write-sites.mjs` — a probe that:

1. **Loads the ROM binary** from `TI-84_Plus_CE/ROM.rom`.

2. **Scans for byte patterns** that encode writes to address 0xD177B7 (little-endian: 0xB7, 0x77, 0xD1):
   - `LD (0xD177B7), A` = `32 B7 77 D1` (most likely)
   - `LD (0xD177B7), HL` = `ED 22 B7 77 D1` (24-bit store, less likely for a flag)
   - `LD (0xD177B7), BC` = `ED 43 B7 77 D1` (24-bit store)
   - `LD (0xD177B7), DE` = `ED 53 B7 77 D1` (24-bit store)
   - Also check for 16-bit Z80-mode stores: the same opcodes without prefix or in Z80 mode would use 2-byte addresses (B7 77), so scan for `32 B7 77 D1` specifically (3-byte address in ADL mode).

3. **For each write site found**, report:
   - The ROM address of the instruction
   - The full instruction encoding (hex bytes)
   - What value is likely being written: look at the preceding 1-3 instructions to find `LD A, imm` or `XOR A` or `LD A, 0x55` etc.
   - The surrounding function context: what's the nearest `RET` or `CALL` before/after?

4. **Also scan for READ sites** of D177B7:
   - `LD A, (0xD177B7)` = `3A B7 77 D1`
   - `CP (HL)` patterns won't directly reference the address, so skip those.
   - Report read sites separately.

5. **Print a summary table**: address | instruction | likely value written | context
