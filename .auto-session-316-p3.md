# Task: Map the 0x00F000-0x00FFFF event dispatch cluster

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 315 identified 8 frame-based `_indcall` sites in the 0x00F000–0x00FFFF region, spread across 6 functions. This region appears to be the OS core event/notification dispatch system.

`_indcall` is the ZDS II C runtime indirect call mechanism. Frame-based _indcall loads a function pointer from the IX-based stack frame via `FD 37 dd` (LD IY,(IX+offset)), then dispatches via JP (IY) at 0x002288.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase316-event-cluster.mjs` and a report `TI-84_Plus_CE/phase316-event-cluster-report.md`.

The probe should:
1. Read `TI-84_Plus_CE/ROM.rom`
2. Scan 0x00F000–0x00FFFF for all _indcall dispatch patterns:
   - Pattern A: FD 37 dd (LD IY,(IX+offset)) ... CD 88 22 00 (CALL 0x002288)
   - Pattern B: FD 37 dd ... C3 88 22 00 (JP 0x002288)
   - Also look for direct JP (IY) = FD E9 as an alternative dispatch
3. For each dispatch site found:
   - Record the exact address
   - Record the IX offset (struct field being dispatched)
   - Disassemble 20 bytes before and 10 bytes after for context
   - Identify the containing function (scan backward for a function prologue: typically PUSH IX / LD IX,0 / ADD IX,SP pattern, or just find the nearest RET/JP before the dispatch)
4. For each containing function:
   - Find all callers in the full ROM (search for CALL addr and JP addr)
   - Disassemble the first 30 bytes to understand what it does
5. Map relationships: which functions call which, and how they connect to the main event loop

The report should:
- List all 8 dispatch sites with their containing functions
- Identify what events/notifications each function dispatches
- Show the call graph connecting these functions to the rest of the OS
- Determine if this is a single event dispatch system or multiple independent mechanisms

## Technical details
- eZ80 ADL mode, little-endian
- Address encoding: 3 bytes, little-endian (e.g., 0x00F123 = 23 F1 00)
- CALL nn = CD nn_lo nn_mid nn_hi
- JP nn = C3 nn_lo nn_mid nn_hi
- FD 37 dd = LD IY,(IX+dd) — ZDS II specific
- PUSH IX = DD E5
- RET = C9
- The 0x002288 address is the _indcall dispatcher (JP (IY))
