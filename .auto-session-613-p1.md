# Auto-Session 613 — Priority 1: Decode Caller 0x000862 (Second VRAM Wipe)

## Context

In the TI-84 Plus CE ROM transpilation project, the OS init routine 0x0018F8 fires TWICE during key1 processing:
- Hit #1 at block ~84,825 returns to **0x0013E8** (VRAM=1466px)
- Hit #2 at block ~274,953 returns to **0x000862** (VRAM=3337px, i.e. after screen rendered)

The second wipe is destructive — it zeroes edit cursors and descriptor buffers AFTER the screen has been painted. We want to understand the calling context at 0x000862 to determine if a conditional skip or interception is feasible.

## Task

1. **Disassemble 0x000840-0x000890** from the ROM to understand the instruction context around the return address 0x000862. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 24-bit ADL mode). Use the decoder in `TI-84_Plus_CE/ez80-decoder.js`. Create a temporary script:

```js
// temp-decode-862.mjs
import { decodeInstruction } from './TI-84_Plus_CE/ez80-decoder.js';
import fs from 'fs';
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
let pc = 0x000840;
const end = 0x000890;
while (pc < end) {
  const insn = decodeInstruction(rom, pc, true);
  const bytes = Array.from(rom.slice(pc, pc + insn.length)).map(b => b.toString(16).padStart(2,'0')).join(' ');
  console.log(`0x${pc.toString(16).padStart(6,'0')}: ${bytes.padEnd(20)} ${insn.mnemonic}  [${insn.length}B]`);
  pc += insn.length;
}
```

2. **Also decode 0x0013D0-0x0013F0** to get the first wipe caller context (return addr 0x0013E8).

3. **Identify what CALL leads to 0x0018F8** from each region. In ADL mode, CALL.L is 4 bytes (CD + 3-byte LE addr). So CALL 0x0018F8 = `CD F8 18 00`. Search backward from each return address to find the CALL.

4. **Widen the disassembly** to get the full function context for the 0x000862 caller. Scan backward to find the function entry. Decode at least 80 bytes surrounding.

5. **Write findings** to `TI-84_Plus_CE/phase613-wipe-caller-decode.md` with:
   - Full disassembly listing of both caller regions
   - What registers/flags are set before each CALL to 0x0018F8
   - Whether there's a conditional branch that could skip the second CALL
   - Whether the two callers are the same function or different
   - Assessment of feasibility of intercepting/skipping the second wipe
