# Auto-Session 209 P1: Trace 0x0568BA BufInsert Path (Editor Region)

## Context
In the TI-84 Plus CE ROM transpilation project, we found 16 call sites for BufInsert (0x05E2A0) in the ROM. One of the most interesting is at **0x0568BA** — in the editor region (outside cxMain), with `LD DE,0x0082` immediately before the CALL. We need to understand what this path does and whether it's the digit insertion path.

## Task
Build a probe script `TI-84_Plus_CE/probe-phase209-0568ba-bufinsert-trace.mjs` that:

1. **Statically disassembles** 32 bytes BEFORE 0x0568BA from ROM.rom to understand the setup (what loads DE=0x0082, what's in A, what's in HL — the BufInsert parameters).
2. **Statically disassembles** 16 bytes AFTER 0x0568BD (the instruction after the CALL) to see what happens post-insert.
3. **Traces execution** starting from ~0x056890 (or the nearest block entry before 0x0568BA) with:
   - Edit buffer at 0xD00A00 (standard location), cursor pointer set
   - A token value in A (try 0x34 = digit "4", and 0x70 = "+")
   - Run 500 steps, log unique blocks visited
4. **Checks whether BufInsert (0x05E2A0) is reached** in the trace
5. **Reports RAM writes** to the edit buffer region (0xD00A00-0xD00A20) after the trace
