For eZ80 ADL-mode reference:
- CALL nn = CD xx xx xx (3-byte address)
- JP cc,nn = C2/CA/D2/DA/E2/EA/F2/FA xx xx xx
- LD A,(nn) = 3A xx xx xx (ADL) or FA xx xx (.SIS prefix)
- BIT n,(IY+d) = FD CB dd (46+8*n)
- SET n,(IY+d) = FD CB dd (C6+8*n)
- RES n,(IY+d) = FD CB dd (86+8*n)
