# Task: DECODE 0x02D267 MACRO REPLAY MECHANISM

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

In session 400, we found that 0x02D267 is one of 2 callers of the key injector function 0x0562C2. At 0x02D267: loads value from IX-3, increments counter at 0xD1770A, pushes key code as 24-bit BC, calls the injector (0x0562C2). Then immediately calls 0x049CCA with params (0x11, 0x03) for notification/event dispatch. This looks like a MACRO REPLAY or programmatic key sequence mechanism.

## Task
Write a probe script `TI-84_Plus_CE/probe-phase401-decode-02D267.mjs` that:

1. Reads the ROM file at `TI-84_Plus_CE/ROM.rom`
2. Disassembles the BROADER function containing 0x02D267. To find the function start, scan backwards from 0x02D267 looking for common function prologues or the end of a previous function (RET = 0xC9, or a JP/JR that doesn't fall through). Read at least 128 bytes before 0x02D267 and 64 bytes after.
3. Decode the eZ80 instructions manually (hex dump + manual decode). Key eZ80 opcodes:
   - 0xC9 = RET, 0xCD = CALL nn (3-byte addr LE), 0xC3 = JP nn
   - 0xC5 = PUSH BC, 0xD5 = PUSH DE, 0xE5 = PUSH HL
   - 0xDD prefix = IX ops (DD 7E dd = LD A,(IX+d), DD 6E dd = LD L,(IX+d))
   - 0xFD prefix = IY ops
   - 0xED prefix = extended (ED 5B nn = LD DE,(nn), ED 4B nn = LD BC,(nn))
   - 0x3A nn = LD A,(nn), 0x32 nn = LD (nn),A
   - 0x21 nn = LD HL,nn, 0x11 nn = LD DE,nn, 0x01 nn = LD BC,nn
   - Prefix 0x40/0x49/0x52/0x5B = SIS/LIS/SIL/LIL mode prefixes
4. Identify:
   - What function contains 0x02D267? Where does it start and end?
   - What calls this function? Search for CALL/JP to the function start address.
   - What is the counter at 0xD1770A counting? (replay step count? macro index?)
   - What does 0x049CCA do when called with params (0x11, 0x03)?
5. Search the ROM for references to 0xD1770A (the counter address): search for bytes `0A 17 D1` in LD/ST instruction contexts. Report all sites.
6. Print all findings clearly.

## Reference
- ROM is little-endian eZ80 (24-bit addresses in ADL mode)
- Key injector 0x0562C2: pushes IX/IY, sets IY=0xD00080, reads key code from IX+6, calls 0x03F9FA (commit), restores, returns
- The calling convention: push 24-bit value (key code in low byte, B=0) before calling 0x0562C2
