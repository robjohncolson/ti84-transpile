# Task: 1.2M Step Budget Probe — Test Polling Loop Exit

## Context
In auto-session 453, a 700K-step budget was NOT enough to exit the _GetCSC polling loop after key processing. The polling loop at 0x003D6B was visited 505,198 times and was still running at step 700,499. We need to try 1.2M post-consume steps to see if the polling loop exits naturally and whether execution returns to 0x003A73 (event loop) and then reaches HALT.

## Deliverable
Create `TI-84_Plus_CE/probe-phase454-1200k-budget.mjs` — a probe that:
1. Boots the OS (same boot sequence as all phase 453 probes)
2. Injects key "1" (scan code 0x12)
3. Runs with 1,200,000 post-consume steps
4. Tracks visits to key addresses: 0x003D6B (polling loop), 0x003A73 (event loop), 0x003D5A (_GetCSC entry), HALT instruction
5. Reports whether the polling loop exited and what happened after

## Implementation
Use `probe-phase453-700k-budget.mjs` as your exact template. The ONLY change needed:
- Increase the step budget from 700,000 to 1,200,000
- Track the same addresses: 0x003D6B, 0x003A73, 0x003D5A, and any HALT

### Boot sequence (copy from existing probes):
1. createExecutor with createPeripheralBus({ timerInterrupt: false })
2. Boot: BOOT_ENTRY (0x000000) for 50 steps, KERNEL_INIT_ENTRY (0x08C331), POST_INIT_ENTRY (0x0802B2), stages [0x0A2B72, 0x0A3301, 0x0A29EC, 0x0A2854]
3. Copy flash self-test: 16 bytes from ROM offset 0x0802C5 to RAM 0xD18C22
4. Set D14091=1, D177B7=0x55

### Key injection:
- Set mem[0xD00587] = 0x12 (key "1")
- Set bit 3 of mem[0xD00080]
- Clear mem[0xD141B5] = 0x00
- Enter event loop at 0x003A73

### Step execution:
Run 1,200,000 steps with address tracking. Use a Map or object to count visits to:
- 0x003D6B (polling loop body)
- 0x003A73 (event loop entry)
- 0x003D5A (_GetCSC entry)
- Any address where HALT is executed

Use HALT bypass: when PC is in HALT range (0x001933-0x001942), skip to 0x003A73.
