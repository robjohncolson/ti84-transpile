# Auto-Session 190 P2: STAT Context Entries 1-5 + 0x080xxx Key→Context Translation Layer

## Context
Session 189 decoded the STAT context table at 0x0585D3:
- 6 entries indexed by context ID 0-5: [0x0585E9, 0x058B19, 0x058B7E, 0x0582BC, 0x058BA9, 0x058C01]
- The handler reads ONLY IY-relative flags (0xD000C9, 0xD000B4, 0xD00089, 0xD000C5, 0xD000D3), NOT RAM key variables
- Key code 0x31 is consumed by a layer BEFORE cxMain
- 0x0802B2 (CoorMon entry) needs full OS event loop — just MemInit isn't enough
- 0x0800A8-0x0800AE was called during the session 189 trace (steps 19-21, 32-34)

## Task
Build `TI-84_Plus_CE/probe-phase190-stat-context-entries.mjs` with two parts:

### Part A: Try context entries 1-5 directly
For each of the 6 context table entries [0x0585E9, 0x058B19, 0x058B7E, 0x0582BC, 0x058BA9, 0x058C01]:
1. Set up a fresh minimal environment (boot + kernelInit + memInit, same as session 189)
2. Set register A = 0x31 (STAT key code)
3. Set IY = 0xD00080 (standard)
4. Set various IY flag combinations:
   - Default (all zeros at IY offsets)
   - (IY+0x49) = 0x08 (context flag from session 189)
5. Push a return sentinel (0x7FFFFE) on the stack
6. Execute from the context entry address, max 500 steps
7. Log: PC trace (every block hit), steps, termination, registers A/HL/DE/BC at exit, any RAM writes to 0xD00000-0xD00FFF range

### Part B: Disassemble the 0x080xxx key→context translation area
Using the ROM bytes directly (no CPU execution needed for this part):
1. Read and disassemble ROM bytes from 0x0800A0 to 0x0800F0 using `ez80-decoder.js`
2. Also disassemble 0x0800EC (known CALL target from home handler — session 182 found it)
3. For each instruction, log: address, hex bytes, decoded mnemonic, any immediate/target values
4. Look for: CP instructions (comparing A against key codes), table lookups (LD from ROM addresses), indirect jumps (JP (HL), JP (IX)), CALL targets

### Key addresses
- Context table: [0x0585E9, 0x058B19, 0x058B7E, 0x0582BC, 0x058BA9, 0x058C01]
