# Auto-Session 273 P2: Test 0x058322 with BIT 2,(IY+21)=1

## Context
We're investigating the TI-84 Plus CE OS event loop. Block 0x058322 is one of the key event loop dispatch targets. Session 272 disassembled it:

```
0x058322: BIT 2,(IY+21) gate
  → if SET: screen region draw (LD BC,0x001E24 + CALL 0x0800A0 + CALL 0x09EF20)
  → if CLEAR: CALL 0x0A2854 (VRAM clearing routine)
```

Session 272 found that 0x058322 was NEVER entered in 15,000 steps from the event loop at PC=0x0582BC. We need to test what happens when BIT 2,(IY+21) is armed (set to 1) before entering 0x058322.

IY in this OS defaults to 0xD00080. So IY+21 = IY+0x15 = 0xD00095. BIT 2 means bit 2 of that byte.

## Task
1. Write a probe at `TI-84_Plus_CE/probe-phase273-058322-bit2-armed.mjs` that:
   - Boots the CPU: load ROM, createCPU, createMemory, createPeripheralBus({ timerInterrupt: false })
   - Runs kernelInit (PC=0x000280, 5000 steps) for basic OS state
   - Sets up event loop context: D007E0=0x49, D007E8 (3 bytes LE) = 0x06C546
   - **Experiment A**: Set PC=0x058322, BIT 2 of mem[0xD00095] CLEAR (default). Run 2000 steps. Log all block PCs, count unique blocks, report which path taken (0x0A2854 expected).
   - **Experiment B**: Set PC=0x058322, SET BIT 2 of mem[0xD00095] (OR with 0x04). Run 2000 steps. Log all block PCs, count unique blocks, report which path taken (screen draw via 0x0800A0 + 0x09EF20 expected).
   - **Experiment C**: Start from event loop entry PC=0x0582BC with BIT 2 armed. Run 5000 steps. Check if 0x058322 is now reached (it wasn't in session 272 with 15,000 steps, but maybe with different IY flags it will be).
   - For each experiment: dump VRAM changes (check D40000-D52BFF for any non-zero bytes written), IY flag changes, RAM watches on D007E0/D007E8/D00824.

2. Reference existing probes for the boot/init pattern:
   - `TI-84_Plus_CE/probe-phase272-event-loop-dispatch-targets.mjs`
