# Task: DECODE 0x08DDBF TABLE SEMANTICS — map the 19 token triplets to TI token names/classes

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 570 discovered a shared 19-entry × 3-byte table at ROM address 0x08DDBF (57 bytes total, 0x08DDBF-0x08DDF7). This table is used by two functions:
- 0x08DD8C (25B): Forward 2-byte token lookup. Takes DE (D=prefix, E=second byte), scans table for match on first 2 bytes of each triplet, returns A=third byte.
- 0x08DDA5 (26B): Reverse 1-byte token lookup. Takes A, scans table for match on third byte of each triplet, returns DE from first 2 bytes.

The table maps between 2-byte token codes and 1-byte internal representations.

## What to do
1. Create a probe script `TI-84_Plus_CE/probe-phase572-decode-08DDBF-table.mjs` that:
   a. Reads the ROM at `TI-84_Plus_CE/ROM.rom`
   b. Dumps all 19 triplets at 0x08DDBF (each triplet = [byte0, byte1, byte2], where byte0+byte1 = 2-byte token code, byte2 = internal 1-byte representation)
   c. For each 2-byte token code (byte0 = prefix, byte1 = second byte), identifies the TI token name. Known prefix meanings:
      - 0x5C = List vars, 0x5D = Matrix vars, 0x5E = Y-vars
      - 0x60 = Pic vars, 0x61 = GDB vars, 0x62 = String vars, 0x63 = Stats vars
      - 0x7E = Window/Table vars, 0xBB = Extended tokens
      - 0xAA = Stats commands, 0xEF = Graph format tokens
      Note: second byte selects which item within the class
   d. For the internal 1-byte representation (byte2), cross-references where it appears in ROM (especially in token classifiers near 0x09BAxx-0x09BCxx and expression evaluators near 0x0593xx-0x05A6xx)
   e. Prints a formatted table: entry# → [prefix, second, internal] → token name → purpose

## Key references
