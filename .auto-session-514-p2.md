The TI-84 CE OS scan code formula is:
```
OS_scancode = (6 - group) * 8 + bit + 1
```

The keyboard matrix (from `TI-84_Plus_CE/keyboard-matrix.md`):
```
keyMatrix[0] = SDK Group 7: DOWN(B0) LEFT(B1) RIGHT(B2) UP(B3)

keyMatrix[3] = SDK Group 4: .(B0) 2(B1) 5(B2) 8(B3) ((B4) COS(B5) PRGM(B6) STAT(B7)
keyMatrix[4] = SDK Group 3: 0(B0) 1(B1) 4(B2) 7(B3) ,(B4) SIN(B5) APPS(B6) X,T,θ,n(B7)
keyMatrix[5] = SDK Group 2: (empty)(B0) STO→(B1) LN(B2) LOG(B3) x²(B4) x⁻¹(B5) MATH(B6) ALPHA(B7)
keyMatrix[6] = SDK Group 1: GRAPH(B0) TRACE(B1) ZOOM(B2) WINDOW(B3) Y=(B4) 2ND(B5) MODE(B6) DEL(B7)
```

Scan code table:
- 0x04 = (6-group)*8+bit+1=4 → group=6,bit=3 → WINDOW... wait no. scancode-1=3, (6-group)*8+bit=3, so group=6,bit=3 → keyMatrix[6] bit 3 = WINDOW. OS scancode 0x04 = WINDOW key.
- 0x07 = scancode-1=6 → group=6,bit=6 → MODE
- 0x08 = scancode-1=7 → group=6,bit=7 → DEL
- 0x09 = scancode-1=8 → group=5,bit=0 → (empty slot!)
- 0x10 = scancode-1=15 → group=5,bit=7 → ALPHA
- 0x11 = scancode-1=16 → group=4,bit=0 → 0
- 0x29 = scancode-1=40 → group=1,bit=0 → ENTER

## Method

Read ROM bytes starting at 0x099921. eZ80 CP instructions are `FE xx` (compare A with immediate). JP Z is `CA xx xx xx` (3-byte address in ADL mode) or `CA xx xx` (2-byte in Z80 mode). JP NZ is `C2 ...`. Document every branch.

For reference, the eZ80 in ADL mode uses 3-byte addresses for JP/CALL. The ROM is mapped at 0x000000 so file offset = address.
