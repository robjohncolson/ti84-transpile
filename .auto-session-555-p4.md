# Task: Map IY+0x4A Fully — All Bits Used

## Context
The TI-84 Plus CE ROM at `TI-84_Plus_CE/ROM.rom` has been partially reverse-engineered. IY points to the OS system flags area (typically 0xD00080). IY+0x4A (= address D000CA) is a rendering attributes byte. Known bits:
- **Bit 3**: Alternate mono buffer select (D031CE vs D0529E) — from 0x0A1B1C
- **Bit 5**: Mono mode (1bpp rendering) — from 0x0A1A9D, 0x0A1B1C
- **Bit 6**: 4bpp mode — from 0x0A1A9D, 0x0A1B1C
- The blit loop at 0x0A24C8-0x0A26C7 also uses IY+0x4A for rendering mode dispatch

Unknown: bits 0, 1, 2, 4, 7. How many total references exist in the ROM?

## Task
1. **Search the entire ROM for IY+0x4A references**. The eZ80 encoding for `(IY+d)` operations uses prefix byte 0xFD followed by an opcode, then displacement byte 0x4A. Common patterns:
   - `FD CB 4A xx` — BIT/SET/RES operations on (IY+0x4A): the xx byte encodes which bit and operation
   - `FD 7E 4A` — LD A,(IY+0x4A)
   - `FD 77 4A` — LD (IY+0x4A),A
   - `FD B6 4A` — OR (IY+0x4A)
   - `FD AE 4A` — XOR (IY+0x4A)
   - `FD A6 4A` — AND (IY+0x4A)
   - `FD BE 4A` — CP (IY+0x4A)
   - `FD 46 4A` — LD B,(IY+0x4A)
   - `FD 4E 4A` — LD C,(IY+0x4A)
   - `FD 56 4A` — LD D,(IY+0x4A)
   - `FD 5E 4A` — LD E,(IY+0x4A)
   - `FD 66 4A` — LD H,(IY+0x4A)
   - `FD 6E 4A` — LD L,(IY+0x4A)
   
   The simplest approach: search for ALL occurrences of bytes `FD` followed by any byte followed by `4A` where the middle byte is a valid IY-displacement opcode, OR `FD CB 4A` for bit operations.

2. **For `FD CB 4A xx` hits**, decode the xx byte to determine which bit (0-7) and which operation (BIT/SET/RES):
   - BIT b,(IY+d): xx = 0x46 + 8*b (b=0→0x46, b=1→0x4E, b=2→0x56, b=3→0x5E, b=4→0x66, b=5→0x6E, b=6→0x76, b=7→0x7E)
   - SET b,(IY+d): xx = 0xC6 + 8*b
   - RES b,(IY+d): xx = 0x86 + 8*b

3. **Build a bit map**: for each bit 0-7, list all ROM addresses that BIT-test, SET, or RES that bit, plus any LD/OR/XOR/AND that touches the whole byte.

4. **Also map D000CA directly** — search for bytes `CA 00 D0` in the ROM for direct memory access to the same address (IY+0x4A = D000CA when IY=D00080).
