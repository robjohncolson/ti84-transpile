# Task: Trace 0x00E1CC (Block Processor) — TI-Link Transfer Engine Inner Loop

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

In session 421, we decoded 0x00FE10 (638 bytes), the main TI-Link data transfer engine. It calls 0x00E1CC to process each data block in a block list. The block list is walked via D14008→D14005. 0x00FE10 validates transfer type (0x01 data or 0x04 request only), reads port 0x3030 bit 0, and produces result codes (0=success, 3=retry, 5=data-ready, 7=limit-exceeded) that feed the D176F8 protocol FSM via IY+27.

0x00E1CC is the INNER TRANSFER LOOP — the function that actually processes individual data blocks. We need to understand: what format are the blocks? How does it handle partial transfers? What ports does it touch? What RAM does it use?
