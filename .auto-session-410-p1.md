# Task: Dump the Key Handler Table at RAM 0xD1441D

## Context
Session 409 decoded the key dispatch mechanism at 0x05D58F. It uses a COMPUTED FUNCTION TABLE — key_code × 4 indexes into a function pointer table whose base address is stored in RAM 0xD1441D. The table installer is at 0x05D5C2, which does `LD (D1441D),BC` to set the table base.

## Deliverables
1. Create `TI-84_Plus_CE/probe-phase410-key-handler-table.mjs` — a probe that:
   - Boots the OS (coldboot, timer IRQ disabled)
   - Runs until the home screen is reached (~4M cycles)
   - Reads the 3-byte pointer at RAM 0xD1441D (little-endian 24-bit address)
   - Dumps the function table entries: for key codes 0x00 through 0x3F (64 entries), read 4 bytes each (3-byte address + 1 byte padding or flag) from base + key_code*4
   - For each non-zero handler address, check if it's in ROM (<0x400000) and print the address
   - Cross-reference handler addresses with known functions (0x05D5D8 = home screen pipeline, 0x07FDC9 = action byte test, 0x07FDD6 = action byte interpreter, 0x07C8AD = table-driven handler)

2. Create `TI-84_Plus_CE/phase410-key-handler-table-report.md` with findings

## Technical Details
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, eZ80)
- Use `scripts/transpile-ti84-rom.mjs` to regenerate `ROM.transpiled.js` if needed
- Runtime: `TI-84_Plus_CE/cpu-runtime.js` — use `createCPU()`, `createPeripheralBus({ timerInterrupt: false })`
- The probe should import from cpu-runtime.js and peripherals.js like existing probes
- Look at `TI-84_Plus_CE/probe-phase409-trace-05D58F.mjs` for probe structure reference
- Also grep for all callers of 0x05D5C2 (the table installer) in the ROM to find which table pointers are installed: `grep -r "05D5C2" TI-84_Plus_CE/` or disassemble the bytes around call sites

## Finding callers of 0x05D5C2
Search the ROM binary for CALL 0x05D5C2 (eZ80 encoding: CD C2 D5 05) and JP 0x05D5C2 (C3 C2 D5 05). Each caller's BC register value at the call site tells you which function table is being installed. This reveals all the different key handler table variants the OS uses.

- At least some handler entries are non-zero (validating the table exists)
- All callers of 0x05D5C2 are found and their BC values identified
