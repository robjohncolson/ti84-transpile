# Task: Trace BC Value at 0x00CB14 (Master Pool Base Address)

## Context
In the TI-84 CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, session 426 found that the initialization block at 0x00CB14 writes 4 pool configuration variables sequentially from the BC register:
- 0x00CB14: LD (D14017),BC
- Then: LD (D1401A),BC
- Then: LD (D1401D),BC
- Then: LD (D14020),BC

These are the master descriptor/slab pool pointers. The value in BC at this point is the master pool base address — likely a malloc result or fixed RAM address. We need to trace where BC comes from.

   - Uses the existing probe infrastructure (see any `probe-phase426*.mjs` for template).

   - Identifies what instructions precede the LD (D14017),BC — how is BC loaded? Is it from a CALL result? A fixed address? A register copy?
   - Traces the full call chain: who calls this function? Read the bytes at the function entry and search for CALL/JP references to that address.
   - If BC comes from a CALL, identify that CALL target (likely a malloc/slab-alloc function).
