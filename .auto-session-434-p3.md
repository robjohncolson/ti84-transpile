# Task: Trace 0x012456 — Controller Re-Arm / OTG Transition

## Context
In the TI-84 Plus CE ROM (eZ80, file `TI-84_Plus_CE/ROM.rom`), address 0x012456 was previously decoded in session 420 as a "host-to-device OTG transition" (186 bytes). It is called by 0x008527 when port 0x3082 bit 3 is set. Session 420 described it as a USB On-The-Go role transition.

The goal is to CONFIRM or CORRECT the session 420 decode by independently re-tracing 0x012456. Specifically:
1. What is the exact function boundary? (0x012456 to where?)
2. What ports does it read/write?
3. What RAM variables does it access?
4. What CALL targets does it have?
5. Does it match "OTG host-to-device transition" or is it something else?

## Deliverables
1. Create `TI-84_Plus_CE/probe-phase434-trace-012456.mjs` — a Node.js probe that:
   - Loads the ROM from `TI-84_Plus_CE/ROM.rom`
   - Disassembles starting at 0x012456 (eZ80 ADL mode, 24-bit addresses)
   - Traces all CALL targets, RAM reads/writes (0xD00000+), port I/O (IN/OUT instructions)
   - Identifies function boundary (RET)
   - Scans ROM for all callers (CALL 0x012456)
   - Outputs: size, instruction count, CALL targets, RAM refs, port I/O, all callers

2. Create `TI-84_Plus_CE/phase434-012456-report.md` — analysis report:
   - Function boundaries and size (confirm or correct "186 bytes")
   - All CALL targets with known names where possible
   - RAM variables accessed
   - Port I/O operations
   - All callers
   - Assessment: does this match OTG transition, or is it a different function?
