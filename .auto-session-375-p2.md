# Task: Disassemble 0x001853 and 0x000721 (normal key dispatch handlers)

## Context
The TI-84 Plus CE OS event loop at 0x003A73 calls _GetCSC, and when a key is detected, dispatches via:
```
0x003A7D: CALL 0x001713  (flash self-test + dispatch)
0x003A85: JP 0x003A89
0x003A89: CALL 0x001853  ← NORMAL key handler (never reached)
0x003A8D: XOR A
0x003A8E: JP 0x000721    ← post-key-process (never reached)
```

We need to understand what 0x001853 and 0x000721 do, since these are the NORMAL key processing path that we've never reached.

## Deliverable
Create `TI-84_Plus_CE/probe-phase375-normal-dispatch-disasm.mjs` that performs STATIC disassembly of:

1. **0x001853** — Disassemble starting at 0x001853, following all branches/calls for up to 200 instructions or until RET. Document what the function does (register state manipulation, memory reads/writes, port I/O, subroutine calls). Follow CALL targets 1 level deep (disassemble the first 20 instructions of each called subroutine).

2. **0x000721** — Disassemble starting at 0x000721, following all branches/calls for up to 200 instructions or until RET/JP to a known address. This is the post-key-process entry point. Document what it does.

3. For each address block, report:
   - Full instruction listing with addresses, hex bytes, and mnemonics
   - Any RAM addresses read/written (LD from/to memory)
   - Any port I/O (IN/OUT instructions)
   - Any CALL/JP targets
   - Branch conditions and targets

## Template
Base your probe on `TI-84_Plus_CE/probe-phase374-dispatch-disasm.mjs`. Reuse:
- `safeDecode(memory, pc, mode)` for instruction decoding
- `decodeInstruction` from `./ez80-decoder.js`
- `hex()`, `hexByte()`, `bytesToHex()` formatting helpers
- The ROM loading pattern (read ROM.rom, create memory image)

The disassembly is STATIC — you only need to read ROM bytes, not boot the CPU. Load ROM.rom into memory and decode instructions starting at the target addresses.

For each instruction, decode it with `decodeInstruction(memory, pc, 'adl')` and print the address, hex bytes, and a human-readable mnemonic. Follow unconditional JP/JR targets. Stop at RET or after the instruction limit.

## Constraints
- Import from `./cpu-runtime.js`, `./peripherals.js`, `./ez80-decoder.js`
- Do NOT modify any existing files. Only create the new probe file.
- Static disassembly only — no need to boot or run the CPU
- Output should be well-formatted text showing the full disassembly

## Success Criterion
The probe runs and produces a complete disassembly of 0x001853 and 0x000721, revealing what the normal key dispatch path does.
