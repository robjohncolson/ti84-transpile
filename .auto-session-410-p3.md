# Task: Map D141B3/D141BA/D14091 Key State Registers

## Context
The key dispatch system uses several RAM addresses in the D14xxx range. Session 409 showed that D141BA is checked by 0x02B373 (IY+7 where IY=D141B3) as a notification-needed flag. Session 399 showed D141B5 is the key buffer. We need to map the full key state structure.

Known RAM addresses in the key system:
- D141B3 = IY base in notification initializer 0x02B373 (IY points here)
- D141B5 = key buffer (session 399: 5 consumers, dispatch via 0x05D58F)
- D141BA = notification flag (IY+7, checked by 0x02B373: if zero → build notification)
- D14091 = referenced by key buffer consumers (needs investigation)
- D1441D = key handler function table base pointer (session 409)

## Deliverables
1. Create `TI-84_Plus_CE/probe-phase410-key-state-regs.mjs` — a probe that:
   - Loads the ROM binary (TI-84_Plus_CE/ROM.rom, 4MB)
   - Searches the ROM for all references to D141B3, D141BA, and D14091
   - For each reference, extracts the surrounding bytes (16 bytes before, 16 after) to identify the instruction context
   - Categorizes references as READ (LD A,(addr), LD r,(addr), BIT n,(addr)) or WRITE (LD (addr),A, LD (addr),r)
   - Counts total readers vs writers for each address
   - Identifies the IY-relative offsets: if IY=D141B3, then IY+0=D141B3, IY+1=D141B4, IY+2=D141B5 (key buffer!), IY+7=D141BA
   - Maps the full structure from D141B3 to at least D141BF (13+ bytes)

2. Create `TI-84_Plus_CE/phase410-key-state-regs-report.md` documenting the structure

## Technical Details
- ROM: 4MB binary at `TI-84_Plus_CE/ROM.rom`
- Search for 3-byte little-endian patterns: B3 41 D1 (for D141B3), BA 41 D1 (for D141BA), 91 40 D1 (for D14091)
- eZ80 addressing: LD A,(D141B3) = 3A B3 41 D1, LD (D141B3),A = 32 B3 41 D1
- IY-relative: FD 7E 07 = LD A,(IY+7), FD 36 07 xx = LD (IY+7),imm8
- Also search for D141B4 (B4 41 D1), D141B6-D141B9, D141BB-D141BF to map the full struct
- Look at `TI-84_Plus_CE/probe-phase408-D141B5-consumers.mjs` or similar for reference probe structure
