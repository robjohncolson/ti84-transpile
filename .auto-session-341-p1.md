# Task: Add z80-mode seed at 0x00001A to transpiler + verify kernel init progresses further

## Context
The TI-84 Plus CE kernel init sequence (starting at 0x000000 in z80 mode) calls RST 0x38. The RST handler at 0x000038 returns to address 0x00001A in z80 mode. No transpiled block exists at 0x00001A:z80, causing a missing_block termination. This was diagnosed in session 340 (probe: probe-phase340-kernel-halt-trace.mjs).

The transpiler already seeds RST vectors at 0x00-0x38 in 8-byte intervals (line 22315-22317 of `scripts/transpile-ti84-rom.mjs`), but 0x00001A is NOT an RST vector — it's a return address mid-block. The transpiler only generates 0x000018:adl (RST 18h vector), not 0x00001A:z80.

## Deliverable 1: Add the z80-mode seed

In `scripts/transpile-ti84-rom.mjs`, add a new seed entry AFTER the RST vector loop (after line 22317, before `seedEntries.push(...knownEntryAnchors);`):

```javascript

  seedEntries.push({ pc: 0x00001A, mode: 'z80' });
```
