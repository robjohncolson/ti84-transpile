# Task: Decode Mode-Specific Dispatch at 0x02FFED through 0x030010

## Context
We're investigating the TI-84 Plus CE OS key dispatch. At 0x02FFAE, the code does:
```
LD A,(D00824)   ; load mode character code
CP 0x00
LD A,(HL)       ; reload something
JR NZ,0x02FFED  ; if D00824 != 0x00, jump to mode-specific dispatch
```

When D00824=0x48 ('H' = home screen mode), the JR NZ jumps to 0x02FFED. We've never decoded what 0x02FFED does. It may compare D00824 against specific mode codes and branch to mode-specific key handlers.

## Task
Create a probe `TI-84_Plus_CE/probe-phase473-mode-dispatch-decode.mjs` that:

1. **Reads and hex-dumps ROM bytes from 0x02FFED through 0x030020** (51 bytes). Print each byte as hex, 16 per line with address prefix.

2. **Manually decodes the eZ80 instructions** in that range. For each instruction, print: address, hex bytes, mnemonic. Key patterns to recognize:
   - CP nn (FE nn) — compare A with immediate
   - JR cc,offset (28/20/30/38 xx) — conditional relative jump
   - JP cc,addr (C2/CA/D2/DA xx xx xx) — conditional absolute jump
   - LD A,(addr) (3A xx xx xx) — load from memory
   - CALL addr (CD xx xx xx) — subroutine call
   - RET (C9) — return
   - BIT n,(IY+d) (FD CB dd xx) — bit test

3. **Traces execution** through 0x02FFED with:
   - Enter at 0x02FFAE (so we see the full dispatch)
   - A register = 0x05 (translated ENTER key code)
   - D00824 = 0x48 (home screen mode)
   - D007E0 = 0x48 (companion mode)
   - IY = 0xD00080
   - MBASE = 0xD0
   - onBlock tracking every PC hit for the first 50 blocks
   - maxSteps: 5000

4. **Reports what happens** when D00824=0x48: which comparisons match, which branches are taken, what function is called

## Boot sequence (copy exactly — needed for ROM.transpiled.js blocks)
```javascript
const MEM_SIZE = 0x1000000;
const STACK_RESET_TOP = 0xD1A87E;
const bootResult = executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 });
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
cpu.mbase = 0xD0; cpu._iy = 0xD00080;
const kernelResult = executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0;
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
const postInitResult = executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
```

After boot, set state:
- D00824 = 0x48
- D007E0 = 0x48
- D14091 = 1
- D00587 = 0x09
- D00080 bit 3 set
- D177BA = 0x7F
- D177B7 = 0x00
- cpu.mbase = 0xD0, cpu._iy = 0xD00080
- Stack: SP = STACK_RESET_TOP - 3, return address = 0xFFFFFF (sentinel)

Enter at 0x02FFAE with mode 'adl'.
