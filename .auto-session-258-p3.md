# Task: Search ROM for runtime construction of 0x022264 vector table base

## Context
This is a TI-84 Plus CE ROM transpilation project. We disassemble eZ80 machine code from the OS ROM and trace execution paths. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB binary).

## Background
Session 257 confirmed that address 0x022264 is a vector table (32 dense JP entries) used for LCD init and context dispatch. However, ZERO static references to 0x022264 or 0x022260 exist in the ROM — the table base must be loaded from RAM or computed at runtime. We need to find how code reaches this table.

## Deliverables
Create probe file: `TI-84_Plus_CE/probe-phase258-022264-runtime-construction.mjs`

The probe should perform multiple search strategies:

### Strategy 1: Search for LD instructions with 0x022264 or nearby addresses
Scan ROM for these byte patterns:
- `21 64 22 02` = LD HL,0x022264 (ADL mode, 24-bit)
- `21 60 22 02` = LD HL,0x022260
- `11 64 22 02` = LD DE,0x022264
- `11 60 22 02` = LD DE,0x022260
- `01 64 22 02` = LD BC,0x022264
- `01 60 22 02` = LD BC,0x022260
Also try z80-mode 2-byte variants (if MADL bit is cleared):
- `21 64 22` = LD HL,0x2264 (z80 mode)
- `11 64 22` = LD DE,0x2264

### Strategy 2: Search for 4-byte stride computation near 0x0222xx
The table has 4-byte entries (JP + 3-byte address). Search for:
- Any `LD xx,0x04` or `ADD A,A / ADD A,A` (multiply by 4) within 20 bytes of a 0x022xxx address load
- Patterns like `SLA A / SLA A` or `ADD HL,HL / ADD HL,HL` (shift left twice = ×4)

### Strategy 3: Search for the first table entry target 0x05523D
Since entry[0] = JP 0x05523D, maybe code references 0x05523D directly and the table is built from those targets:
- `CD 3D 52 05` = CALL 0x05523D
- `C3 3D 52 05` = JP 0x05523D
- `21 3D 52 05` = LD HL,0x05523D
Count all call sites to 0x05523D.

### Strategy 4: Search for nearby vector table references
The handler table at 0x08C958 (20 entries, session 252) is accessed via known code. Search for similar patterns near 0x022264:
- Any 3-byte value in ROM that equals 0x022264 (little-endian: `64 22 02`)
- Scan ALL 3-byte windows in ROM for `64 22 02` regardless of instruction context

### Strategy 5: Examine 0x022200-0x022280 for table header/metadata
Read and dump ROM bytes from 0x022200 to 0x022280 — there may be a table header, entry count, or dispatch code preceding the vector table at 0x022264.

## Technical Details
- Read ROM with `fs.readFileSync('TI-84_Plus_CE/ROM.rom')`
- ROM is 4,194,304 bytes
- All addresses are little-endian in the binary
- Print all matches with surrounding context (8 bytes before, 8 bytes after)
- Classify each match: instruction type, ROM region, likely purpose
