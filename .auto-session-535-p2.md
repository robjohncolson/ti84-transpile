## eZ80 Decoding Rules (CRITICAL)
- Default mode is ADL (24-bit). All LD rr,nn use 3-byte immediates. All CALL/JP use 3-byte addresses.
- Prefix 0x52 = .SIL (force 16-bit operands for next instruction)
- Prefix 0x40 = .SIS
- ED-prefix opcodes: ED B0 = LDIR, ED A0 = LDI, ED A1 = CPI, ED B1 = CPIR, ED A8 = LDD, ED B8 = LDDR
- CB-prefix: BIT/SET/RES instructions
- DD = IX variants, FD = IY variants (FD CB dd nn for BIT/SET/RES (IY+dd))
- 0xCD = CALL nn (3 bytes), 0xC3 = JP nn, 0xC9 = RET, 0x18 = JR d, 0x20/0x28/0x30/0x38 = JR NZ/Z/NC/C
- RST instructions: 0xC7=RST 0, 0xCF=RST 8, 0xD7=RST 10, 0xDF=RST 18, 0xE7=RST 20, 0xEF=RST 28, 0xF7=RST 30, 0xFF=RST 38
- LD A,(nn) = 0x3A + 3-byte address, LD (nn),A = 0x32 + 3-byte address
- LD HL,(nn) = 0x2A + 3-byte address, LD (nn),HL = 0x22 + 3-byte address
