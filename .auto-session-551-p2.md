# Task: Decode 0x06002D — Cursor/Position Management

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decoded 0x061986 (CHARACTER OUTPUT WRAPPER, 45B, 30 callers) and found it calls 0x06002D before calling 0x0A23E5 (the character renderer).

## What we know

- 0x06002D is called BEFORE the character renderer, suggesting it does cursor positioning, display buffer management, or scroll check.
- The 0x060xxx range is in the display/output subsystem of the OS.

2. Determine function boundaries (RET, JP, or fall-through).
3. Document: entry conditions, what registers/RAM it reads and writes, what it calls, and its likely purpose.
4. Find how many callers reference 0x06002D across the ROM.

## eZ80 ADL mode reference
- CALL nn = CD xx xx xx (3-byte LE address)
- JP nn = C3 xx xx xx  
- JP cc,nn = C2/CA/D2/DA/E2/EA/F2/FA xx xx xx
- RET = C9
- LD r,(IX+d) / LD r,(IY+d) = DD/FD prefix + opcode + displacement
- BIT/SET/RES via CB prefix
- ED prefix for extended ops
- SIS prefix (40) = short (16-bit) instruction in ADL mode
- LD HL,nn = 21 xx xx xx (24-bit)
- LD A,(nn) = 3A xx xx xx
- LD (nn),A = 32 xx xx xx
- CP n = FE xx
- JR cc,d = 20/28/30/38 xx (signed offset)
