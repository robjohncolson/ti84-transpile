# Auto-Session 455 P2: Trace What the ~33K Changed VRAM Bytes Represent

## Context
The TI-84 Plus CE ROM transpilation project. Session 454 discovered that each key press triggers exactly 576,000 VRAM write operations (full-screen repaint), but only ~33K bytes actually CHANGE per key:
- Key "1" (first): 39,082 changed + 536,918 idempotent
- Key "+": 32,968 changed + 543,032 idempotent  
- Key "1" (second): 33,008 changed + 542,992 idempotent
- Key "ENTER": 33,000 changed + 543,000 idempotent

VRAM is at 0xD40000, 320×240×2 bytes (153,600 bytes total). 16-bit color, RGB565 format. Each pixel = 2 bytes. Row stride = 640 bytes (320 pixels × 2 bytes).

## Task
Create a probe file `TI-84_Plus_CE/probe-phase455-vram-changed-map.mjs` that:

1. Boots to home screen using the EXACT same boot sequence as `probe-phase454-vram-write-intercept.mjs` (copy the bootToHomeScreen function verbatim)
2. Creates peripheral bus with `timerInterrupt: false`
3. Sets up key processing: `mem[0xD14091] = 1`, `mem[0xD177B7] = 0x55`
4. For EACH key in the sequence [KEY_ONE(0x12), KEY_PLUS(0x2A), KEY_ONE(0x12), KEY_ENTER(0x29)]:
   a. Take a VRAM snapshot BEFORE the key: `const before = mem.slice(0xD40000, 0xD40000 + 153600)`
   b. Inject the key and run 500,000 steps from EVENT_LOOP_ENTRY (0x003A73) with diHaltBypass:true
   c. Take a VRAM snapshot AFTER
   d. Compare byte-by-byte. For each changed byte, record: offset from VRAM_BASE, row (offset / 640), column pixel ((offset % 640) / 2)
   e. After each key, reset for next: clear halted, reset SP, set D177B7=0x55 again
5. For each key, print:
   - Total changed bytes
   - Row range (min row to max row) of changed pixels
   - Column range (min col to max col) of changed pixels  
   - A histogram: for each row that has changes, how many bytes changed in that row
   - Whether the changed region overlaps with the cursor area (bottom rows ~224-239, the input line)
6. After all 4 keys, print a COMPARISON:
   - Which VRAM rows are changed by ALL 4 keys (common region)
   - Which rows are UNIQUE to specific keys
   - Whether key "1" (first) changes different rows than key "1" (second)

## Key constants
- VRAM_BASE = 0xD40000
- VRAM_SIZE = 153600 (320 × 240 × 2)
- ROW_STRIDE = 640 (320 pixels × 2 bytes per pixel)
- EVENT_LOOP_ENTRY = 0x003A73
- Boot sequence: copy from probe-phase454-vram-write-intercept.mjs
