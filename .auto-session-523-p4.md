# Task: Decode 0x098B80 — Program-Specific Editor Setup

## Context
In the TI-84 Plus CE OS ROM (`TI-84_Plus_CE/ROM.rom`), address 0x098B80 is called by the program type (0x1B) handler in the type-dispatch cascade at 0x097AC8 (session 522). Specifically:
- Type 0x1B (program) handler at 0x097B55: `CALL 0x07F7A8` → `JR NZ,0x097B88` → `CALL 0x098B80`

This is the program-specific editor setup function. We need to decode what it does.

## Deliverable
Create `TI-84_Plus_CE/probe-phase523-decode-098B80-prog-setup.mjs` that:
1. Reads ROM bytes starting at 0x098B80 for ~200 bytes
2. Disassembles the eZ80 instructions (ADL mode, 24-bit addresses)
3. Documents what the function does — program editor initialization, RAM writes, sub-calls
4. Identifies all CALLs, JPs, memory reads/writes (especially RAM D0xxxx)
5. Prints a structured analysis

## How to read ROM bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Read byte at address: rom[address]
// Read 24-bit LE value: rom[addr] | (rom[addr+1] << 8) | (rom[addr+2] << 16)
```

## eZ80 ADL mode reference
- All addresses are 24-bit (3 bytes LE) in ADL mode
- CALL nn = 0xCD nn[2:0], JP nn = 0xC3 nn[2:0]
- LD r,(nn) / LD (nn),r use 3-byte addresses
- RET = 0xC9, RET Z = 0xC8, RET NZ = 0xC0
- JR e = 0x18 e (signed offset from PC+2)
- JR Z,e = 0x28 e, JR NZ,e = 0x20 e
- CP n = 0xFE n, LD A,n = 0x3E n
- LD HL,nn = 0x21 nn[2:0], LD DE,nn = 0x11 nn[2:0], LD BC,nn = 0x01 nn[2:0]
- PUSH/POP: AF=0xF5/0xF1, HL=0xE5/0xE1, BC=0xC5/0xC1, DE=0xD5/0xD1
- OR A = 0xB7, XOR A = 0xAF, AND n = 0xE6 n
- BIT b,(IY+d) = 0xFD 0xCB d opcode
- LD A,(HL) = 0x7E, LD (HL),A = 0x77
- RST 0x28 = 0xEF (bcall)
- LDIR = 0xED 0xB0, LDDR = 0xED 0xB8
- SET b,r / RES b,r use CB prefix
- INC/DEC register pairs: INC HL=0x23, DEC HL=0x2B

## Known context
- Called from the program (type 0x1B) handler in 0x097AC8 type-dispatch
- Called AFTER 0x07F7A8 (type normalizer) succeeds (JR NZ skips this call)
- The 0x098xxx region contains type-specific initializers (0x0987B5/0x0987B7 are nearby)
- D02712 = edit-mode type byte (written with type code after dispatch)
