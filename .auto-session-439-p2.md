## Background
Port 0x3082 is a read-only USB status register with 92 I/O sites across the ROM. Session 438 found that bit 3 (AND 0x08) is the MOST FREQUENTLY accessed bit (~25 sites). The access pattern is:

```
IN A,(C)          ; read port 0x3082 (BC = 0x003082)
AND 0x08          ; isolate bit 3
RRA               ; rotate right through carry (bit 0 → carry, carry → bit 7)
SET 2,A           ; force bit 2 = 1
CP 0x30           ; compare against 0x30
```

This pattern extracts bit 3 into a classification value. The question: what are the possible results, and how do they map to USB speed modes (Full Speed / Low Speed / High Speed)?

## eZ80 Encoding Notes
- Port I/O: `IN A,(C)` = `ED 78` (reads port addressed by BC)
- `LD BC,0x003082` = `01 82 30 00` (little-endian)
- `AND imm8` = `E6 xx`
- `RRA` = `1F` (rotate A right through carry)
- `SET 2,A` = `CB D7`
- `CP imm8` = `FE xx`
- `JR C,offset` = `38 xx`, `JR NC,offset` = `30 xx`
- `JR Z,offset` = `28 xx`, `JR NZ,offset` = `20 xx`
- `BIT n,A` = `CB 47/4F/57/5F/67/6F/77/7F` for bits 0-7
