# Task (qqq): Trace D00824 Writers — Which Fire During Normal Operation?

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM (eZ80 machine code) has been lifted to JavaScript.

Address D00824 is a "mode byte" read by the normal key dispatch function at 0x02FFAE. The CP cascade there does:
- D007E0=0x54/0x53 → key code 0x06 remapped to 0x05
- D007E0=0x43/0x49 → key codes 0x07/0x08 subtract 4
- Home screen default: D00824=0x00, D007E0=0x00 → all checks fail, key passes through

Session 223 found **16 D00824 write sites** (3 in 0x04xxxx, 1 in 0x06xxxx, 12 in 0x08xxxx). Session 235 confirmed 0x084EA7 as one writer (hhh from session 224: B→A→(D00824), CP cascade 0x2B/0x4A, reached via JR Z from 0x084E9C, 16 total writers).

## Deliverables
Create `TI-84_Plus_CE/probe-phase236-d00824-writers.mjs` that:

1. Does a static binary scan of ROM.rom for all instructions that write to D00824:
   - `LD (0xD00824),A` = opcode `32 24 08 D0` (3-byte addr in little-endian for ADL mode)
   - Also check `LD (HL),A` patterns where HL=0xD00824 (harder to find statically — skip if too complex)
2. For each write site found, disassemble 16 bytes BEFORE and 16 bytes AFTER the write instruction using ez80-decoder.js
3. Classify each site: what value does it write? Is it a constant (LD A,imm → LD (D00824),A), register-dependent, or computed?
4. Group sites by ROM region (0x04xxxx = OS core, 0x06xxxx = editor, 0x08xxxx = UI/menu, 0x09xxxx = STAT, 0x0Axxxx = apps)
5. For the top 3 most interesting sites, run a dynamic trace (100 steps from 16 bytes before the write instruction) to see what A value arrives

## Reference files
- `TI-84_Plus_CE/probe-phase235-02ffae-normal-dispatch.mjs` — template for boot/stepping
- `TI-84_Plus_CE/cpu-runtime.js` — createExecutor
- `TI-84_Plus_CE/peripherals.js` — createPeripheralBus({timerInterrupt: false})
- `TI-84_Plus_CE/ez80-decoder.js` — decodeInstruction
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary
- `TI-84_Plus_CE/ROM.transpiled.js.gz` — lifted JS (gunzip if .js doesn't exist)

## Constraints
- Do NOT modify any existing files
- Only create the new probe file
- Use `createPeripheralBus({ timerInterrupt: false })`
- MBASE=0xD0, IY=0xD00080
- Output: table of all write sites with classification

## Success criterion
Probe runs, lists all D00824 write sites with surrounding disassembly, classifies each by value source, and groups by ROM region. Dynamic traces for top 3 sites complete without crash.
