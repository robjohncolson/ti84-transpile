# Auto-Session 216 — P1: Trace 0x079A1E caller chain (BIT 7,(IY+0x18) initial arming)

## Context

We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80). The dispatcher at 0x061290 handles edit-mode key processing, but it's gated by `BIT 7,(IY+0x18)` at address 0x060048 — if bit 7 is CLEAR, the dispatcher is never reached.

Session 215 found ONLY 2 `SET 7,(IY+0x18)` sites in the entire ROM:
- **0x06127B** — inside the dispatcher itself (SELF-ARMING, only useful once already entered)
- **0x079A1E** — in OS/UI area, gated by `BIT 7,(IY-2)`

Since the dispatcher self-arms but needs to be entered first, the INITIAL arming must come from 0x079A1E (or from one of the 4 `LD (IY+0x18),0x00` sites in OS core init, though those CLEAR the byte).

## Task

Build a probe `TI-84_Plus_CE/probe-phase216-079a1e-caller-chain.mjs` that:

### Part A: Static disassembly of 0x079A1E region
1. Read `TI-84_Plus_CE/ROM.rom` (4MB binary)
2. Disassemble 0x079A00-0x079A80 (128 bytes around the SET site) using the eZ80 instruction set (ADL mode, 3-byte addresses)
3. Find the function entry point by scanning backwards for a RET/JP/JR instruction that would mark the previous function's end
4. Document what happens at and after 0x079A1E: does it SET 7,(IY+0x18) then continue to other setup? What's the gate `BIT 7,(IY-2)` checking?

### Part B: Static caller scan
1. Scan the entire ROM binary for `CALL 0x079A1E` (CD 1E 9A 07) and `JP 0x079A1E` (C3 1E 9A 07) — but also check for CALL/JP to the FUNCTION ENTRY found in Part A
2. Also check for JR/JR NZ/JR Z instructions that could reach 0x079A1E from nearby code
3. Report all callers found

### Part C: Dynamic trace from 0x079A1E
1. Use the runtime from `TI-84_Plus_CE/cpu-runtime.js` and transpiled blocks from `TI-84_Plus_CE/ROM.transpiled.js`
2. Set up a standard boot environment:
   ```js
   import { createCPU } from './cpu-runtime.js';
   import { installTranspiledBlocks } from './ROM.transpiled.js';
   const cpu = createCPU();
   installTranspiledBlocks(cpu);
   ```
3. Initialize IY = 0xD00080 (standard OS IY base)
4. Set BIT 7,(IY-2) = SET (since 0x079A1E is gated by this)
5. Set PC = 0x079A1E and run up to 200 steps
6. Log: every block visited, IY+0x18 value before and after, any other IY flag changes
7. Check if SET 7,(IY+0x18) actually fires

### Part D: Trace callers of the function entry point
For each caller found in Part B, do a brief 50-step trace to see what context reaches this code.
