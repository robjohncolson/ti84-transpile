# Task: Trace the Full Wake Sequence at 0x0019BE

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS enters sleep mode at 0x0019B5 via DI + HALT. After HALT, if an NMI or wake event occurs, execution continues at 0x0019BE. Session 378 confirmed: 0x0019BE reads port 0x5015 via `IN A,(C)` and dispatches based on which interrupt bit is set.

Session 379 implemented a DI+HALT bypass in `cpu-runtime.js` that restarts the event loop at 0x003A73 when DI+HALT is hit. But we need to understand what the REAL wake path does — does it re-enter 0x003A73? Does it do additional initialization? This is needed for proper sleep/wake emulation.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase380-wake-sequence.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Statically disassembles the wake path starting at 0x0019BE through all branches until it either:
   - Re-enters the event loop (0x003A73 or nearby)
   - Reaches another HALT
   - Reaches an address we've already documented
3. For each branch target from the port 0x5015 dispatch, trace where it leads
4. Report:
   - Full disassembly of 0x0019BE through ~50 instructions or until terminus
   - Which interrupt bits map to which handlers at 0x0019BE (this is the wake-reason decoder, different from the ISR handlers at 0x001A4B+)
   - Whether any path eventually reaches 0x003A73 (event loop entry)
   - What additional initialization the wake path does compared to the DI+HALT bypass (which just jumps straight to 0x003A73)

## Reference files
- `TI-84_Plus_CE/ez80-decoder.js` — use `decodeInstruction(rom, pc)` for disassembly. It returns `{mnemonic, operands, size, prefix}`.
- `TI-84_Plus_CE/cpu-runtime.js` — reference for the DI+HALT bypass implementation (search for `diHaltBypass`)

## Key addresses
- 0x0019B5: DI instruction (sleep entry)
- 0x0019B6: LD A,0x10
- 0x0019B8: OUT0 (0x00),A
- 0x0019BB-BC: NOP
- 0x0019BD: HALT
- 0x0019BE: Wake path entry — reads port 0x5015
- 0x003A73: Event loop entry
- 0x003D5A: _GetCSC
- Port 0x5015: Interrupt status register (FTINTC010)
