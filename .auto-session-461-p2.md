# Task: Map D177BA Write Sites in ROM

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The project lifts eZ80 ROM machine code into runnable JavaScript.

## Background
Address D177BA is a RAM flag that controls the ISR dispatch path. When D177BA is nonzero, the ISR guard at 0x001713 returns NZ, routing to the "reduced handler" at 0x0019BE instead of the "full ISR dispatcher" at 0x03CF7D.

We need to know: who writes to D177BA, what values, and when during the OS lifecycle.

## Task
Write a probe file `TI-84_Plus_CE/probe-phase461-d177ba-writes.mjs` that:

1. Boots the OS using the standard boot pattern (see `probe-phase99d-home-verify.mjs`)
2. Hooks ALL writes to address 0xD177BA during boot by instrumenting the memory write path
3. For each write, log:
   - The step number
   - The PC at time of write
   - The value being written
   - The old value being replaced
4. After boot (500,000 steps), report:
   - Total number of writes to D177BA
   - Final value of D177BA
   - Timeline of all value changes (step, PC, old→new)
5. Also scan the transpiled JavaScript source for any blocks that reference address 0xD177BA:
   - Search the transpiled ROM source (loaded during boot) for string "0xd177ba" (case-insensitive)
   - Report the block addresses (function names) that read or write it

## Reference files
- `TI-84_Plus_CE/probe-phase99d-home-verify.mjs` — boot pattern
- `TI-84_Plus_CE/cpu-runtime.js` — memory write hooks (look for write8, write16, write24 methods)

## Approach for memory write hooking
The CPU's `write8(addr, val)` method is the low-level memory write. You can wrap it before boot:
```javascript
const origWrite8 = cpu.write8.bind(cpu);
cpu.write8 = function(addr, val) {
  if (addr === 0xD177BA) {
    console.log(`D177BA write: step=${stepCount} pc=0x${cpu.pc.toString(16).padStart(6,'0')} old=0x${mem[0xD177BA].toString(16).padStart(2,'0')} new=0x${val.toString(16).padStart(2,'0')}`);
  }
  return origWrite8(addr, val);
};
```
Also hook write16 and write24 since a 16/24-bit write to D177B9 or D177B8 could overlap D177BA.
