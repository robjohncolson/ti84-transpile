## Key addresses

- 0x030173 = cursor render function entry
- 0x030202 = glyph selector (called by 0x030173, reads D00092)
- 0x0A23C0 = font glyph selector (28×charcode for font lookup)
- 0x0A239E = cursor VRAM writer (B=0x0E for 14 rows)
- D00092 = cursor style control (bits select which glyph code 0x030202 returns)
- D00095 = cursor state flags (bit 1 set by 0x030173)
- D000B2 = font mode bits
- D00085 = display control
- D0008D = display state
- D026AC = foreground color (set to 0x0000 by 0x030173)
- D026AA = background color (set to 0xFFFF by 0x030173)
- VRAM base: 0xD40000, stride: 0x280 (640 bytes per row)
