# Auto-Session 379 — P2: Update keyboard-matrix.md with OS Scan Codes

## Context

The TI-84 Plus CE ROM transpilation project has two different key code systems:
1. **Matrix position codes** (documented in `TI-84_Plus_CE/keyboard-matrix.md`): `(group << 4) | bit`, used by the hardware keyboard controller
2. **OS scan codes** (decoded in session 378): computed algorithmically at ROM 0x003D35-0x003D42 via `scancode = (H-1)*8 + bit + 1` where H is a reverse iteration counter

Session 378 decoded the full OS scan code table:
- The scan loop at 0x003D22 iterates keyboard ports in REVERSE ORDER: 0xA01E (keyMatrix[6]) down to 0xA010 (keyMatrix[0])
- H-value mapping: keyMatrix[0]→H=7, keyMatrix[1]→H=6, ..., keyMatrix[6]→H=1
- Example: ENTER at keyMatrix[1] bit 0: H=6, scancode=(6-1)*8+0+1 = 41 = 0x29
- Key mappings found: GRAPH=0x01, DEL=0x08, ENTER=0x29, CLEAR=0x2F, ALPHA=0x10, 2ND=0x06, Y==0x05, 0=0x11, 1=0x12
