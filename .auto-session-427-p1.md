# Task: Decode 0x00DF73 Descriptor Table Initializer

## Context
In the TI-84 CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, session 426 decoded the full descriptor pool initializer at 0x00E2EB-0x00E4E7 (509 bytes). That function calls 0x00DF73 FOUR times — once for each of the 4 descriptor table bases (D13FD8, D13FDB, D13FDE, D13FE1). 0x00DF73 is the per-table setup routine that initializes individual descriptor entries within a table segment.

We need to decode 0x00DF73 to understand how individual descriptor entries are structured within each table segment.

   - Records all instruction mnemonics, operands, RAM address references, and CALL targets.
   - Identifies loops, conditionals, and the function's RET instruction.
   - Specifically looks for: writes to IY-relative offsets (descriptor entry fields), references to D1401A/D1401D/D14017/D14020, any counter or index that determines how many entries are initialized, the entry stride (likely 0x20 = 32 bytes based on slab size).
