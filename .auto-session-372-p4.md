# Task: Investigate Keyboard Interrupt Bit on Ports 0x5015/0x5014/0x500B

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The timer ISR (called via RST 38h every ~200 steps) polls 3 interrupt status ports:
- **0x5015**: tested with RLA for handlers at 0x001A4B, 0x001A77, 0x001A8D, 0x001ABB
- **0x5014**: tested with RRA for handlers at 0x001AA3, 0x001ACF
- **0x500B**: tested with BIT 4 for handler 0x001A5D

Currently all 3 ports return 0 (no pending interrupts), so the ISR falls through all tests and acknowledges. If we could model a keyboard interrupt on one of these ports, the ISR would dispatch to the corresponding handler, which might trigger key processing.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase372-interrupt-ports.mjs` that:

1. **Disassembles ALL the interrupt handlers** referenced by the ISR polling chain:
   - 0x001A4B, 0x001A5D, 0x001A77, 0x001A8D, 0x001AA3, 0x001ABB, 0x001ACF
   Decode at least 40 bytes from each handler to understand what they do.

2. **Disassembles the ISR polling chain** 0x0019BE-0x001A32 in detail with annotations about which RLA/RRA bit maps to which handler.

3. **Tests each bit individually** by:
   - Running the standard 3-phase boot (timerInterrupt:false)
   - Then entering the event loop at 0x003A73 with timerInterrupt:true
   - Hooking the peripheralBus port reads so that when port 0x5015 is read, it returns a specific bit pattern (try bit 0 set, then bit 1 set, etc. — one at a time in separate runs)
   - Running for 10K steps and seeing which handler block gets visited

4. **Identifies the keyboard handler** by looking at what each handler does — a keyboard handler would likely read from the keyboard port (0xA000 range) or access key data in RAM.

## How to hook port reads
Read `TI-84_Plus_CE/peripherals.js` to understand the port I/O mechanism. The peripheralBus likely has `readPort(addr)` and `writePort(addr, val)` methods. You can monkey-patch `readPort` after creation to intercept reads to port 0x5015:
```js
const origRead = peripheralBus.readPort.bind(peripheralBus);
peripheralBus.readPort = (addr) => {
    if (addr === 0x5015) return testBitPattern;
    return origRead(addr);
};
```
