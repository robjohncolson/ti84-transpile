# Task: Map D177BB Transfer Latch — All Writers and Readers

You are working on a TI-84 Plus CE ROM transpilation project. Your job is to find ALL references to RAM address D177BB in the ROM, categorize them as reads vs writes, and determine when D177BB is set (transfer start) and cleared (transfer end).

## Context

- Session 414 discovered that D177BB is the master "transfer in progress" latch.
- D177BB gates D176F8 state transitions: controls entry to state 0x10 (pending ack) and reset to state 0x00 (idle).
- D176F8 is a 17-state protocol FSM with 44 writers across USB and Link port code.
- We need: who writes D177BB? When is it set vs cleared? What values does it take?

## What to do

1. Create a probe file `TI-84_Plus_CE/probe-phase415-D177BB-latch.mjs` that:
   - Reads the ROM binary at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 CPU, little-endian, 24-bit addresses)
   - Scans the entire ROM (0x000000-0x3FFFFF) for all references to D177BB:
     - LD A,(D177BB) — read: opcode 3A BB 77 D1
     - LD (D177BB),A — write: opcode 32 BB 77 D1
     - LD BC,(D177BB) / LD HL,(D177BB) / LD DE,(D177BB) — 24-bit reads
     - LD (D177BB),BC / LD (D177BB),HL / LD (D177BB),DE — 24-bit writes
     - BIT n,(IX+d) / SET n,(IX+d) / RES n,(IX+d) if IX base could be near D177BB
     - Also check for CP comparisons immediately after reads
   - For each reference: report the address, the instruction, the surrounding context (2-3 instructions before and after), and classify as READ or WRITE
   - For WRITE references: determine what value is being written (immediate via XOR A/LD A,n, or computed)
   - Group references by ROM bank: 0x00xxxx-0x01xxxx (USB) vs 0x04xxxx-0x06xxxx (Link port)

2. Create a report `TI-84_Plus_CE/phase415-D177BB-latch-report.md` summarizing:
   - Total readers vs writers
   - What values are written (0x00 for clear, 0x01 for set, or other?)
   - Which functions write D177BB (use surrounding CALL/JP context)
   - The lifecycle: when is D177BB set and when is it cleared?

3. Run the probe: `node TI-84_Plus_CE/probe-phase415-D177BB-latch.mjs`

## Byte patterns to scan for

D177BB in little-endian is BB 77 D1. Common instruction patterns:
- `3A BB 77 D1` = LD A,(0xD177BB) — 8-bit read
- `32 BB 77 D1` = LD (0xD177BB),A — 8-bit write
- `ED 4B BB 77 D1` = LD BC,(0xD177BB) — 24-bit read
- `ED 43 BB 77 D1` = LD (0xD177BB),BC — 24-bit write
- `2A BB 77 D1` = LD HL,(0xD177BB) — 24-bit read
- `22 BB 77 D1` = LD (0xD177BB),HL — 24-bit write

Also check for the 3-byte sequence BB 77 D1 in other contexts (could be immediate operand to LD BC,0xD177BB = 01 BB 77 D1).
