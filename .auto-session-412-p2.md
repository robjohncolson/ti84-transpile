# Task: Decode D176F8 Protocol Type Semantics

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 machine code).

Session 411 decoded USB Worker B at 0x013377, which dispatches on RAM address D176F8 for protocol type values:
- 0x0A = active transfer
- 0x0C = header
- 0x0D = complete

We need to understand WHO WRITES to D176F8 and what other values it can take, to map the full TI Link protocol state machine.

## What to do

1. **Find all writers to D176F8** in the ROM. Search for:
   - `LD (0xD176F8),A` = bytes 32 F8 76 D1 (4 bytes)
   - `LD (0xD176F8),HL` = bytes 22 F8 76 D1 (4 bytes)
   - `LD (0xD176F8),BC` = bytes ED 43 F8 76 D1 (5 bytes)
   - Also search for LD instructions using IX/IY-relative addressing where the base could be near D176F8

2. **Find all readers of D176F8** in the ROM. Search for:
   - `LD A,(0xD176F8)` = bytes 3A F8 76 D1 (4 bytes)
   - `LD HL,(0xD176F8)` = bytes 2A F8 76 D1 (4 bytes)
   - `LD BC,(0xD176F8)` = bytes ED 4B F8 76 D1 (5 bytes)

3. **For each writer**, disassemble the surrounding context (16 bytes before and 16 bytes after) to determine:
   - What value is being written (immediate? register? computed?)
   - What function contains this write
   - What condition gates the write

4. **Cross-reference with known protocol values**: 0x0A, 0x0C, 0x0D. Are there other CP instructions comparing against D176F8?

5. **Check nearby RAM** (D176F0-D17700) for related protocol state variables.

## Deliverables

Create TWO files:
1. `TI-84_Plus_CE/probe-phase412-D176F8-protocol.mjs` — A Node.js probe that reads ROM.rom, finds all refs to D176F8, disassembles context, and prints analysis.
2. `TI-84_Plus_CE/phase412-D176F8-protocol-report.md` — A report listing all writers/readers, the values written, and interpretation of the protocol state machine.

## eZ80 Encoding Reference
- LD A,(nn) = 3A nn24 (4 bytes, nn is 24-bit little-endian)
- LD (nn),A = 32 nn24 (4 bytes)
- LD HL,(nn) = 2A nn24 (4 bytes)
- LD (nn),HL = 22 nn24 (4 bytes)
- LD BC,(nn) = ED 4B nn24 (5 bytes)
- LD (nn),BC = ED 43 nn24 (5 bytes)
- CP n = FE n (2 bytes)
- CALL nn = CD nn24 (4 bytes)
- JP nn = C3 nn24 (4 bytes)
- RET = C9

Search for the byte pattern F8 76 D1 to find all references to D176F8 (the 24-bit address in little-endian).
