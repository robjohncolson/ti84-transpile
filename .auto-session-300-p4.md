# Auto-Session 300 P4: Investigate 0xD00587 Writers

## Context
In the TI-84 Plus CE ROM, address 0xD00587 is the scan code buffer — the keyboard scanner writes the current scan code here, and `_GetCSC` at 0x03FA09 reads it.

Session 299 found 6 ROM references to 0xD00587. Of these, 3 are WRITERS at addresses:
- 0x003D4B
- 0x003D7B  
- 0x028C2D

The keyboard scanner (0x0159C0, which runs from RAM) is the primary writer, but these 3 ROM-resident writers also modify the scan code buffer. We need to understand in what contexts they write and what values they store.

## Task
Write a probe `TI-84_Plus_CE/probe-phase300-scancode-writers.mjs` that:

1. **Disassemble each writer site** — for each of the 3 addresses (0x003D4B, 0x003D7B, 0x028C2D), disassemble ~30 instructions centered on the write instruction. Show the surrounding context to understand what function each is part of.

2. **Identify the containing function** for each writer:
   - Search backwards for the function entry (look for a sequence after a RET/JP that starts a new function)
   - Search forwards for the function exit (RET)
   - What does the containing function do?

3. **Determine WHAT value is written**:
   - Is it writing a specific constant (like 0x00 to clear the buffer)?
   - Is it writing from a register that was loaded from somewhere?
   - Is it a copy from another memory location?

4. **Cross-reference the containing functions**:
   - Search for CALL/JP references to the containing function addresses
   - Who calls these writers? Are they part of key injection, key simulation, or buffer clearing?

5. **Also check the 3 READER sites** — the other 3 references to 0xD00587 that are reads. Briefly document what reads the scan code besides _GetCSC.

## How to find references
For cross-referencing, search the ROM for byte patterns:
- `CALL addr`: CD xx xx xx (where xx xx xx = little-endian 24-bit address)
- `JP addr`: C3 xx xx xx
- `LD (0xD00587),A`: 32 87 05 D0 (in eZ80 ADL mode, LD (imm24),A = 0x32 + 3-byte LE addr)
- `LD A,(0xD00587)`: 3A 87 05 D0

Running the probe prints the disassembly context for all 3 writer sites and all 3 reader sites, with identification of containing functions, what values are written, and who calls each writer.
