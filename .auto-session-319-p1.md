# Task: Map the Contiguous D13FD8-D14040 Callback Region

## Context

You're working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 24-bit addressing). The transpiler is at `scripts/transpile-ti84-rom.mjs`. The cpu-runtime is at `TI-84_Plus_CE/cpu-runtime.js`.

Session 318 established that the 0x00F000 event cluster uses a callback struct at RAM address D13FED. Session 317 found D13FED is a 3-byte callback pointer array with parallel bases at D13FDE and D13FD8, with 13-byte init, all zero after boot.

## Task

Map the full contiguous RAM region D13FD8-D14040 in the ROM. Specifically:

1. **Find every ROM reference to addresses in range D13FD8-D14040.** Search the ROM binary for little-endian 24-bit addresses (e.g., D13FD8 = bytes D8 3F D1). Count reads vs writes for each address.

2. **Determine the struct layout.** How many entries are there? What is the entry size (3 bytes for pointers, or larger structs)? Are there parallel arrays or a single array of structs?

3. **Find what installs non-zero pointers at runtime.** The boot shows all zeros — what code writes non-zero values into this region? These are the registration sites.

4. **Categorize each entry.** For each distinct address in the region that has ROM references, identify: what function reads/writes it, and what the callback is used for (display, USB, event dispatch, etc.).

## Deliverables

1. Create `TI-84_Plus_CE/probe-phase319-d13fd8-callback-region.mjs` — a probe that:
   - Reads the ROM binary
   - Scans for all references to D13FD8-D14040 in the ROM
   - Reports each address, its reference count, and the ROM locations that reference it
   - Disassembles the instruction at each reference site (at minimum: show the 6 bytes before and after)
   - Classifies each reference as read/write/immediate
   - All assertions should pass

2. Create `TI-84_Plus_CE/phase319-d13fd8-callback-region-report.md` with findings.
