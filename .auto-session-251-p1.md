# Auto-Session 251 P1: Find what calls cxMain (0x0585D3 JP (HL) dispatch table)

## Context

We're tracing the TI-84 Plus CE OS event loop to understand how keypresses reach the home-screen handler. The JP (HL) at 0x0585D3 dispatches to cxMain (0x0585E9) via a pointer table. But session 250 confirmed the 0x02FFxx dispatch chain does NOT route to cxMain. We need to find what DOES.

## Task

Create a probe at `TI-84_Plus_CE/probe-phase251-cxmain-callers.mjs` that:

1. **Static ROM scan**: Read `TI-84_Plus_CE/ROM.rom` and search the entire 4MB ROM binary for:
   - All CALL/JP instructions targeting 0x0585D3 (the JP (HL) dispatch site)
   - All CALL/JP instructions targeting 0x058241 (pre-handler entry)
   - All CALL/JP instructions targeting 0x0585E9 (cxMain direct)
   - All CALL/JP instructions targeting 0x0582BC (home body, table entry [3])
   
   eZ80 ADL CALL = `CD xx xx xx` (3-byte target, little-endian)
   eZ80 ADL JP = `C3 xx xx xx` (3-byte target, little-endian)
   eZ80 JP cc = `C2/CA/D2/DA/E2/EA/F2/FA xx xx xx` (conditional JPs)
   
   For each match, print: `address: 0x${hex} — ${opcode} 0x${target}`

2. **Handler pointer table search**: The JP (HL) at 0x0585D3 reads HL from a pointer table. Search RAM region references to find what writes the handler pointer that HL loads from. The table base is at or near 0x0585D4 (6 entries × 3 bytes each). Search ROM for any `LD HL,0x0585D4` or `LD HL,0x0585D3` instructions:
   - `21 D3 85 05` or `21 D4 85 05` (LD HL,imm24)

3. **Broader search**: Also scan for references to the range 0x058240-0x0585FF by searching for any 3-byte address in that range appearing after CALL/JP opcodes.

4. Print a summary of all found sites with their ROM addresses.
