# Task: DECODE 0x0BAB6D — Display Coordinate Setup Entry Function

You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian, ADL mode = 24-bit addresses by default).

## Context

Session 548 decoded 0x0BAB88, a TOKEN TEMPLATE RENDERER. That function is reached by fall-through from 0x0BAB6D, which sets up display coordinates before the rendering loop:
- `SIS LD (0x08D2),HL` — sets x-position (SIS = short instruction suffix, 16-bit operation in ADL mode)
- Reads y-position from D02A76+2 and stores into D008D5

We need to decode the full entry function at 0x0BAB6D and find its callers to understand how the template rendering pipeline is invoked.

## What to do

1. **Read raw bytes** from ROM at 0x0BAB6D for ~40 bytes (up to and including the fall-through to 0x0BAB88). Use Node.js:
```js
import fs from 'fs';
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
const start = 0x0BAB6D;
const bytes = rom.slice(start, start + 40);
console.log('Bytes:', Buffer.from(bytes).toString('hex').match(/../g).join(' '));
```

2. **Disassemble in eZ80 ADL mode** (24-bit default). Key eZ80 opcodes:
   - `CD xx xx xx` = CALL addr (3-byte address)
   - `C3 xx xx xx` = JP addr
   - `C9` = RET
   - `21 xx xx xx` = LD HL,imm24
   - `52 xx xx` with SIS prefix `40` = SIS LD (imm16),HL (short mode store)
   - `3A xx xx xx` = LD A,(addr)
   - `32 xx xx xx` = LD (addr),A
   - `ED 27` = LD HL,(HL) (eZ80-specific)
   - Addresses are 24-bit little-endian
   - SIS prefix (0x40) forces next instruction to use 16-bit operands in ADL mode

3. **Find all CALL/JP xrefs** to 0x0BAB6D across the full ROM:
```js
const target = [0x6D, 0xAB, 0x0B]; // little-endian 0x0BAB6D
// Search for CD 6D AB 0B (CALL) and C3 6D AB 0B (JP)
```

4. **Also check for xrefs to 0x0BAB88** (the template renderer itself) — does anyone jump directly to the renderer, bypassing the coordinate setup?

5. **Determine**: What registers does 0x0BAB6D expect as input? What display state does it configure? Who calls it?
