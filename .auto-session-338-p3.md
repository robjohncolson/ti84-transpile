# Task: Trace Key Dispatch Flow Past 0x08BF68

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS event loop function CoorMon at 0x08BF22 has a key-present branch at 0x08BF68 that is taken when a scan code is injected via `mem[0x3B0033]`. Session 337 confirmed this with scan code 0x09 (ENTER): 9,439 steps, 246 unique blocks when the key-present branch is taken.

The question: what happens AFTER 0x08BF68? Does it reach the cxMain dispatch at 0x08BF82? What blocks does the key handler visit? What's the full key processing pipeline?

## Your Task
Create a probe at `TI-84_Plus_CE/probe-phase338-key-dispatch-trace.mjs` that:

1. Boots the environment using the standard pattern:
   ```javascript
   // Boot phase
   executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 });
   // Reset CPU, then kernel init
   executor.runFrom(0x08C331, 'adl', { maxSteps: 100000, maxLoopIterations: 10000 });
   // Set up: cpu.mbase = 0xD0, cpu.iy = 0xD00080, install cxMain
   write24(mem, 0xD007CA, 0x058241); // Home handler
   ```

2. Injects ENTER key: `mem[0x3B0033] = 0x09`

3. Runs CoorMon from 0x08BF22 in ADL mode with detailed block tracing:
   - Record EVERY block PC visited in order (not just unique)
   - Flag when these key addresses are hit:
     - 0x08BF3C (branch point — AND 0x3F masking)
     - 0x08BF68 (key-present target)
     - 0x08BF82 (cxMain dispatch — `CALL (IY-0x58)` or similar)
     - 0x058241 (Home handler entry — if cxMain dispatch works)
   - Track call depth changes (look for CALL/RET patterns in block metadata)

4. Reports:
   - Full ordered list of block PCs visited (up to first 100, then summarize)
   - Which key milestone addresses were reached
   - If 0x058241 (Home handler) was entered, what happened inside it
   - Any missing blocks encountered
   - The complete flow from 0x08BF68 → ... → wherever execution ends up

5. Also runs a SECOND trace with a DIFFERENT key — use 0x03 (RIGHT arrow) — to compare:
   - Does the flow diverge after 0x08BF68?
   - Different block count? Different endpoints?

## Boot/Setup Pattern
Use the same boot pattern as `TI-84_Plus_CE/probe-phase337-getcsc-patch.mjs`:
- `createPeripheralBus({ timerInterrupt: false })`
- Boot → kernel init → reset CPU → install cxMain → inject key → run CoorMon
- Stack reset: `cpu.sp = 0xD1A87E; cpu.sp -= 3; write24(mem, cpu.sp, 0xFFFFFF);`
- RETURN_SENTINEL = 0xFFFFFF
- maxSteps for CoorMon: 50000 (enough for full key dispatch)
- maxLoopIterations: 50000

- cxMain dispatch area: 0x08BF82
