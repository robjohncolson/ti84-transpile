# Task: Investigate CP 0x36/0x30 key code classification at 0x02FEDF/0x02FEF3 (fff)

## Context
In the TI-84 Plus CE ROM transpilation project, session 232 decoded function 0x02FE89 (the SET 0,(IY+29) key-repeat armer). After the SET/RES logic, the function continues with:
- BIT 3,(IY+87) test
- CP 0x36 classification at ~0x02FEDF (likely CLEAR key code)
- CP 0x30 classification at ~0x02FEF3 (likely MODE key code)
- These set specific IY+18/IY+31 bits and call 0x02237E
- Then falls into 09F79B table lookup at 0x02FF11

We need to understand what the CLEAR (0x36) and MODE (0x30) key code handlers do, and what 0x02237E does.

## Reference
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB binary, addresses = byte offsets)
- IY = 0xD00080, so IY+18 = 0xD00092, IY+31 = 0xD0009F, IY+87 = 0xD000D7
- 09F79B is the key code lookup table (3 subtables of 56 entries each + base section)
- Previous probe: `TI-84_Plus_CE/probe-phase232-02fe9d-function-trace.mjs`
- eZ80 CP n = 0xFE followed by immediate byte
- BIT b,(IY+d) = 0xFD 0xCB d (46+8*b)
- SET b,(IY+d) = 0xFD 0xCB d (C6+8*b)  
- RES b,(IY+d) = 0xFD 0xCB d (86+8*b)
