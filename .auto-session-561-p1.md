# Task: Decode 0x0A1F48 — Actual Y-Advance Helper

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by reading raw bytes, disassembling them as eZ80 instructions, and documenting their behavior.

Session 560 decoded 0x0A2013 as a Y-advance **wrapper** (31B) that calls 0x0A1F48 as the actual Y-advance function. We need to decode 0x0A1F48 now — this is where cursor row incrementing and scroll triggering happens.

## Known call chain
- 0x0A2032 (line wrap) → 0x0A2013 (wrapper with busy-wait) → **0x0A1F48** (actual Y advance)
- 0x0A2013 returns Z flag from 0x0A1F48 and uses it for flow control

## Known context
- IY = 0xD00080 (OS flags base)
- D0231A = cursor column, D0231D = cursor row (from scroll module analysis, session 557)
- D00595 = column limit, D00596 = column counter
- D014FE = cursor Y conversion base (session 556: render_Y = D014FE-1-C+0x2F)
- D008D5 = render Y output
- 0x06CBE5 = cursor Y conversion function (100B, session 556)
- 0x05ADxx = scroll module (session 557)

## What to do

1. Read 200 bytes starting at ROM offset 0x0A1F48 from `TI-84_Plus_CE/ROM.rom`
2. Disassemble as eZ80 ADL-mode instructions (24-bit addresses, 3-byte pointers)
3. Document: what registers are used, what RAM addresses are read/written, what CALLs are made, where the function ends (RET/JP)
4. Pay special attention to: cursor row increment logic, scroll trigger conditions, interaction with D0231A/D0231D
