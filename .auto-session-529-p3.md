# Task: Decode ROM function at 0x07CBB5

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by writing probe scripts that read ROM bytes and trace execution.

## Target
**0x07CBB5** — FP normalization core. Known to contain: CALL 0x07FF38, conditional branching, CP 0x70, CPL+AND 0x0F logic. Called from 0x0685DF (exponent save+normalize helper). This is a critical FP (floating-point) subroutine in the TI-OS BCD math engine.

## What we know
- eZ80 CPU in ADL mode (24-bit addresses, 3-byte pointer loads)
- FP registers: OP1 at D005F8 (9 bytes: type, sign/exp, 7 mantissa), OP2 at D00603
- D005F9 = OP1 exponent, D005FA = OP1 mantissa start
- 0x07FF38 = FP validation/check (unknown details, called from here)
- 0x07FF4E, 0x07FF59 = related FP helpers discovered in session 528
- BCD operations use DAA, RRD (ED 67), RLD (ED 6F) for decimal digit manipulation
- CPL = complement A, AND 0x0F = mask lower nibble — together they likely extract digit count or shift amount

## Deliverable
Create a probe script at `TI-84_Plus_CE/probe-phase529-decode-07CBB5-fp-normalize-core.mjs` that:

1. Reads ROM bytes from 0x07CBB5 for ~120 bytes and disassembles them
2. Identifies all CALL/JP/JR/RET instructions
3. Reads ROM bytes at each sub-target for ~24 bytes
4. Also reads 0x07FF38 for ~40 bytes (it's a known sub-function)
5. Documents the full control flow

### eZ80 ADL-mode decoding reference
- 3-byte addresses for JP/CALL: opcode + addr_low + addr_mid + addr_high
- CALL nn = CD + 3-byte addr, JP nn = C3 + 3-byte addr
- JR e = 18 + signed offset, JR Z = 28, JR NZ = 20, JR C = 38, JR NC = 30
- Conditional CALL: CALL Z = CC, CALL NZ = C4, CALL C = DC, CALL NC = D4
- Conditional JP: JP Z = CA, JP NZ = C2, JP C = DA, JP NC = D2
- RET = C9, RET Z = C8, RET NZ = C0, RET C = D8, RET NC = D0
- LD A,(nn) = 3A + 3-byte addr, LD (nn),A = 32 + 3-byte addr
- CP n = FE + byte, AND n = E6 + byte, OR n = F6 + byte
- CPL = 2F, NEG = ED 44, ADD A,n = C6 + byte, SUB n = D6 + byte
- INC (HL) = 34, DEC (HL) = 35
- PUSH/POP: AF=F5/F1, BC=C5/C1, DE=D5/D1, HL=E5/E1
- IX prefix = DD, IY prefix = FD
- BIT b,(IY+d) = FD CB dd bb (4-byte sequence)
- RRD = ED 67, RLD = ED 6F
- DJNZ = 10 + signed offset, LD B,n = 06 + byte
- SRL A = CB 3F, SRA A = CB 2F, RRA = 1F, RLA = 17

### Template
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function readROM(addr, len) {
  return Array.from(rom.slice(addr, addr + len));
}

function hex(b) { return b.toString(16).padStart(2, '0'); }
function hex6(a) { return '0x' + a.toString(16).padStart(6, '0'); }
function addr24(bytes, off) { return bytes[off] | (bytes[off+1] << 8) | (bytes[off+2] << 16); }

// Read main function (generous window — normalization may be long)
const mainBytes = readROM(0x07CBB5, 120);
console.log('=== 0x07CBB5 ROM bytes (120) ===');
for (let i = 0; i < mainBytes.length; i += 16) {
  const chunk = mainBytes.slice(i, i + 16);
  console.log(hex6(0x07CBB5 + i) + ': ' + chunk.map(hex).join(' '));
}

// Read 0x07FF38 sub-function
const ff38Bytes = readROM(0x07FF38, 40);
console.log('\n=== 0x07FF38 (40 bytes) ===');
for (let i = 0; i < ff38Bytes.length; i += 16) {
  const chunk = ff38Bytes.slice(i, i + 16);
  console.log(hex6(0x07FF38 + i) + ': ' + chunk.map(hex).join(' '));
}

// Find CALL/JP/JR/RET in main function
const targets = [];
let retAddrs = [];
for (let pc = 0; pc < mainBytes.length; pc++) {
  const op = mainBytes[pc];
  
  // CALL nn or conditional CALL nn
  if (op === 0xCD || op === 0xCC || op === 0xC4 || op === 0xDC || op === 0xD4) {
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      const names = { 0xCD: 'CALL', 0xCC: 'CALL Z', 0xC4: 'CALL NZ', 0xDC: 'CALL C', 0xD4: 'CALL NC' };
      targets.push({ from: 0x07CBB5 + pc, target, type: names[op] });
      pc += 3;
    }
  }
  // JP nn or conditional JP nn
  else if (op === 0xC3 || op === 0xCA || op === 0xC2 || op === 0xDA || op === 0xD2) {
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      const names = { 0xC3: 'JP', 0xCA: 'JP Z', 0xC2: 'JP NZ', 0xDA: 'JP C', 0xD2: 'JP NC' };
      targets.push({ from: 0x07CBB5 + pc, target, type: names[op] });
      pc += 3;
    }
  }
  // JR variants
  else if ([0x18, 0x20, 0x28, 0x30, 0x38].includes(op)) {
    const offset = mainBytes[pc + 1];
    const signed = offset > 127 ? offset - 256 : offset;
    const target = 0x07CBB5 + pc + 2 + signed;
    const names = { 0x18: 'JR', 0x20: 'JR NZ', 0x28: 'JR Z', 0x30: 'JR NC', 0x38: 'JR C' };
    targets.push({ from: 0x07CBB5 + pc, target, type: names[op] });
    pc += 1;
  }
  // RET variants
  else if ([0xC9, 0xC8, 0xC0, 0xD8, 0xD0].includes(op)) {
    const names = { 0xC9: 'RET', 0xC8: 'RET Z', 0xC0: 'RET NZ', 0xD8: 'RET C', 0xD0: 'RET NC' };
    retAddrs.push({ addr: 0x07CBB5 + pc, type: names[op] });
    if (op === 0xC9) break; // unconditional RET = end of function
  }
}

console.log('\n=== CALL/JP/JR targets ===');
for (const t of targets) {
  console.log(`${hex6(t.from)}: ${t.type} → ${hex6(t.target)}`);
}

console.log('\n=== RET instructions ===');
for (const r of retAddrs) {
  console.log(`${hex6(r.addr)}: ${r.type}`);
}

// Read sub-targets
const uniqueTargets = [...new Set(targets.map(t => t.target))];
for (const t of uniqueTargets) {
  if (t >= 0 && t < rom.length && t !== 0x07FF38) {
    const bytes = readROM(t, 24);
    console.log(`\n=== ${hex6(t)} (24 bytes) ===`);
    console.log(bytes.map(hex).join(' '));
  }
}
```
