# Task: Map the 0x006EDA USB Error Checker

## Context
You are analyzing the TI-84 Plus CE OS ROM (eZ80, file `TI-84_Plus_CE/ROM.rom`, 4 MB). This is a 24-bit eZ80 CPU in ADL mode.

## Background
Session 320 mapped all 19 crash references to the crash handler at 0x0019B5. Six of those 19 crash sites (32%) are in the Link/USB subsystem, and they share a common helper function at **0x006EDA**. This function appears to be a USB error condition checker — it tests some condition and, if the check fails, jumps/calls 0x0019B5 (crash/halt).

The crash handler 0x0019B5 performs a hardware halt via port 0x00 write. D0301B is an error context pointer cleared before crash.

Related USB infrastructure from session 320:
- D13FFC = USB pipe descriptor heap pointer (74 refs)
- D13FFF, D14002 = related USB pointers
- D14049 = cached port 0x3014 (USB status)
- 0x00CD7B = pipe setup, 0x00E06D = heap alloc, 0x00E1CC = heap free

## Deliverables
Create `TI-84_Plus_CE/phase321-usb-error-checker-report.md` with:

1. **Full disassembly of 0x006EDA** — decode from 0x006EDA until the function returns or crashes. Show hex bytes + mnemonics.
2. **Error condition** — what exactly does this function check? Which RAM addresses or I/O ports does it read? What bit patterns trigger the crash path vs the normal return?
3. **Caller analysis** — find all callers of 0x006EDA (search for CALL 0x006EDA and JP 0x006EDA in the ROM). For each caller, note the address and immediate context (what USB operation was in progress).
4. **Crash path** — how does it reach 0x0019B5? Direct JP? Conditional? Does it set D0301B (error context) before crashing?
5. **Peripheral implications** — what port/RAM values should the emulator provide to ensure this checker always passes (non-crash path)?

## Method
1. Read `TI-84_Plus_CE/ROM.rom` as binary
2. Disassemble from 0x006EDA
3. Search ROM for the 4-byte pattern for CALL 0x006EDA: CD DA 6E 00 (little-endian 24-bit address)
4. Also search for JP 0x006EDA: C3 DA 6E 00
5. Cross-reference with the crash sites listed in `TI-84_Plus_CE/phase320-crash-references-report.md`
