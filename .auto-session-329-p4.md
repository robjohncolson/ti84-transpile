# Task: Trace font translation routines 0x02398E and 0x023A1C

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

## What we know
From session 226: 0x02398E is an HL-preserving flag clearer with 101 call sites. It:
- PUSH IX/AF/HL
- LD HL,0xD02611 → CALL 0x025758 (pointer deref)
- POP HL (restores original HL)
- Clears IY+53 bit 1 (RES 1,(IY+53))
- Stores 0x0109 to D025CF
- Returns with HL unchanged

There are 5 related sub-functions at 0x02398E/0x0239B3/0x0239CD/0x0239E3/0x0239FE, each loading different D025xx pointers and clearing different IY bits.

0x023A1C is in the same region and is called by both font lookup functions (0x07BF3E for fixed-width and 0x0A5424 for variable-width) when IY+53 flags are set.

## Your task
1. **Statically disassemble** 0x02398E through 0x023A50 (or until all related functions end). Map the 5 sub-functions and 0x023A1C.
2. **Decode what 0x023A1C does differently** from 0x02398E — is it the font-specific translation? What IY flags does it check/set?
3. **Trace the D02611/D025E1/D025E4/D025E7/D025EA pointers** — what do they point to? Are they handler tables, font descriptors, or mode state?
4. **Map all callers** of 0x023A1C specifically — which font lookup paths invoke it?
5. **Dynamic trace**: Execute 0x02398E and 0x023A1C from boot state, showing what flags change and what pointer values are loaded.
