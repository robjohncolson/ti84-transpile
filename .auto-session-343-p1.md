## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase343-all-28-handlers.mjs` that:

1. Reads the ROM file at `TI-84_Plus_CE/ROM.rom`
2. Extracts all 28 3-byte LE addresses from 0x08C958 (stride 3, 28 entries = 84 bytes)
3. For each handler address, disassembles the first 30 bytes (using the ez80 decoder at `TI-84_Plus_CE/ez80-decoder.js`)
4. Looks for CP (compare) instructions in the first ~10 instructions — the immediate value is a scan code. Cross-reference scan codes with the keyboard matrix:
   - Scan codes are (group << 4) | bit where group 0-6 maps to keyMatrix[7-group]
   - Key reference: 0x09=ENTER, 0x15=UP, 0x16=RIGHT, 0x17=LEFT, 0x18=DOWN, 0x19=2ND, 0x20=CLEAR, 0x27=GRAPH, etc.
5. Prints a summary table: index, address, first few instructions (mnemonics), and any identified scan code comparisons
