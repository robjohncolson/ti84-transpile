**Key finding from session 500**: 0x09AD2E is a 19-byte orchestrator that calls:
1. 0x09A3D0 (main setup, receives A=(IX+0))
2. 0x08005F (mode/state check)

## Technical details
- ROM file: `TI-84_Plus_CE/ROM.rom` — load with `fs.readFileSync`
- eZ80 is little-endian, 24-bit addresses
- Common patterns:
  - `CD xx xx xx` = CALL addr
  - `C3 xx xx xx` = JP addr
  - `C9` = RET
  - `DD 7E xx` = LD A,(IX+d)
  - `DD 77 xx` = LD (IX+d),A
  - `FD CB xx xx` = IY+offset bit ops
  - `3A xx xx xx` = LD A,(addr)
  - `32 xx xx xx` = LD (addr),A
  - `2A xx xx xx` = LD HL,(addr)
  - `22 xx xx xx` = LD (addr),HL
  - IY = 0xD00080
