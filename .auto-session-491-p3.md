## How to identify real code vs data

Real eZ80 code patterns:
- Starts with common prologues: PUSH AF (F5), PUSH IX (DD E5), LD A,(addr) (3A xx xx xx)
- Contains CALL (CD xx xx xx), RET (C9), JP (C3 xx xx xx), JR (18 xx, 28 xx, etc.)
- Has conditional branches (JR NZ, JR Z, JP NZ, JP Z)
- Register-register operations (LD r,r, ADD, SUB, AND, OR, XOR, CP)

Data masquerading as code:
- Font bitmaps (repetitive byte patterns)
- USB descriptors (ASCII mixed with control bytes)
- String tables (mostly 0x20-0x7E ASCII)
- Pointer/jump tables (sequences of 3-byte addresses)
- Token tables (structured lookup data)
- Runs of 0x00 or 0xFF
