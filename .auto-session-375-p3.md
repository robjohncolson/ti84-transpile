# Task: Add seed addresses 0x003C98 and 0x003C9C to transpiler

## Context
The TI-84 Plus CE keyboard scan routine at 0x003C63 has two paths to store a key:
- 0x003C98: repeat-key JP target (JP 0x003D4B)
- 0x003C9C: new-key CALL target

Block 0x003C98 is MISSING from transpiled blocks — the transpiler never lifted it. This means the repeat-key path can never execute even if the scan routine tries to reach it.

## Deliverable
1. Add `0x003C98` and `0x003C9C` as seed addresses to the appropriate seed file. The most recent seed file used is `TI-84_Plus_CE/phase200-seeds.txt` or another phase file. Check which seed files exist and add to the latest one, OR create a new file `TI-84_Plus_CE/phase375-seeds.txt` with these two addresses (one per line, hex format matching existing seed files).

2. If you create a new seed file, also add the path to `scripts/transpile-ti84-rom.mjs` following the pattern of existing seed file references (around lines 10-18 for path declarations, and the loading section where seed files are read and parsed).

3. Run the transpiler: `node scripts/transpile-ti84-rom.mjs`

4. Verify the new blocks exist by checking the transpiler output for block count increase, or by grepping the generated `ROM.transpiled.js` for the addresses `003c98` and `003c9c`.

5. Run the golden regression to make sure nothing broke: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs`
