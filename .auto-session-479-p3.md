# Task: TRACE 0x08B0CC MODE DISPATCH CHAIN — FIND CALLERS

## Context
Session 478 found that 0x09E30C (Home mode entry: LD A,0x48; CALL 0x09E2EC) has ZERO direct CALL/JP references. Instead it's reached via computed JP Z:
- 0x08B0CC: CP 0x48; JP Z,0x09E30C — dispatches 'H'→home, 'W'→0x08AA67, 'K'→0x09E3B4, 'S'→0x09E2BF
- 0x096E64: CP 0x48; JP Z,0x09E30C — dispatches 'Q'→0x09E370, 'K'→0x09E3B4, 'S'→0x09E2BF

Both chains load A from D007E0 first, then compare against mode letters.

## Task
Create `TI-84_Plus_CE/probe-phase479-mode-dispatch-callers.mjs` that:

1. Uses the same pattern as `probe-phase478-home-mode-callers.mjs` (import createExecutor, load ROM.rom and ROM.transpiled.js).
2. Searches the ROM binary (first 0x400000 bytes) for:
   a. All CALL references to 0x08B0CC: byte pattern CD CC B0 08 (CALL 0x08B0CC)
   b. All JP references to 0x08B0CC: byte pattern C3 CC B0 08 (JP 0x08B0CC)
   c. All CALL references to 0x096E64: byte pattern CD 64 6E 09 (CALL 0x096E64)
   d. All JP references to 0x096E64: byte pattern C3 64 6E 09 (JP 0x096E64)
   e. Also search for references to any address in the range 0x08B0C0-0x08B0D0 (the function might start a few bytes before 0x08B0CC)
   f. Also search for references to 0x096E60-0x096E70
3. For each match, log the ROM address where the reference was found.
4. Then do a BACKWARD DECODE from 0x08B0CC: read bytes at 0x08B0A0-0x08B0CC to find the function entry point. Look for common function prologues: PUSH AF, PUSH HL, PUSH IX, DI, or a RET/JP instruction that ends the previous function.
5. Similarly backward decode from 0x096E64: read 0x096E40-0x096E64.
6. Search for CALL/JP references to any function entry points found in step 4/5.

## ROM byte patterns
- CALL addr = CD LL MM HH (3-byte LE address in eZ80 ADL mode)
- JP addr = C3 LL MM HH
- JP Z,addr = CA LL MM HH  
- JP NZ,addr = C2 LL MM HH

## Output format
Log all found references with their ROM addresses. Example:
```
CALL 0x08B0CC found at ROM address 0x0XXXXX
JP 0x08B0CC found at ROM address 0x0XXXXX
Function entry for 0x08B0CC chain: 0x08B0XX (starts with PUSH AF / LD A,(D007E0))
Callers of function entry: [list]
```

Also do a hex dump of 0x08B0A0-0x08B0E0 and 0x096E40-0x096E80 for manual analysis.

## Constraints
- Do NOT modify any existing file
- This is a ROM analysis probe — no boot or execution needed, just binary search
- Create ONLY the probe file
