# Task: Decode ROM function at 0x07FBCA — BCD Rounding/Carry Propagation

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). We decode ROM functions by writing probe scripts that disassemble bytes from the ROM and annotate them.

## What we know about 0x07FBCA
- Called from 0x07C9E1 (sign normalization) when the guard byte (D00601) overflows after BCD arithmetic
- Called as: `CALL 0x07FBCA` — performs BCD rounding/carry propagation into the mantissa
- If carry propagates through all digits, the caller (0x07C9E1) resets mantissa to 0x10 and increments exponent
- Located in the FP math region 0x07F800-0x080200
- Related functions: 0x07FBE4 (BCD rounding called from 0x07CBB5 normalization core, session 529)

## Nearby decoded functions for reference
- 0x07FB48: 8×RLD shift left chain (BCD shift left on OP1 mantissa D00601 downward)
- 0x07FB33: BCD shift left variant (LD HL,D00600; XOR A; chain of 8×RLD via JR to 0x07FB1A)
- 0x07FB19: 8×RRD shift right chain
- 0x07FC94: 8-byte BCD SUB chain (trial subtraction for restoring division)
- 0x07FC0E: 8-byte BCD ADD chain (restore for division)
- 0x07FBE4: BCD rounding (called from normalization core)
- 0x07C9E1: Sign normalization (the caller)

## eZ80 instruction reference (key opcodes you'll see)
- ED 67 = RRD (rotate right decimal: A and (HL))
- ED 6F = RLD (rotate left decimal: A and (HL))
- 27 = DAA (decimal adjust accumulator)
- FD CB xx yy = IY-indexed bit operations
- ED 44 = NEG
- ED A1 = CPI, ED B1 = CPIR
- Standard Z80: LD, ADD, SUB, AND, OR, XOR, CP, JR, JP, CALL, RET, PUSH, POP, INC, DEC, BIT, SET, RES
