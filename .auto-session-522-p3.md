# Task: Map 0x097AC8 type-dispatch targets (7 type codes)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript blocks. You need to map the type-dispatch targets called by 0x097AC8.

Session 521 decoded 0x097AC8 as the EDIT-BUFFER TYPE DISPATCHER / STATE RESETTER:
- Clears 4 IY flags on entry: RES 2,(IY+73) [D000C9], RES 0,(IY+7) [D00087], RES 7,(IY+83) [D000D3], RES 0,(IY+31) [D0009F]
- Zeroes 3 RAM locations: D02713, D00334, D02506
- Calls 0x07F7BD (type checker), then dispatches on A against 7 type codes: 0x1B, 0x20, 0x21, 0x1C, 0x01, 0x0D, 0x02
- These correspond to: list (0x1B), matrix (0x20), string (0x21), program (0x1C), real (0x01), complex (0x0D), etc.
- 22 nested CALLs to type-specific setup helpers
- Writes D02712 (edit-mode type register), D00332 (state counter)

## Deliverable
Create a probe file at `TI-84_Plus_CE/probe-phase522-decode-097AC8-type-targets.mjs` that:
1. Reads the ROM binary directly
2. Starting at 0x097AC8, disassembles the full function
3. For each of the 7 type codes (0x1B, 0x20, 0x21, 0x1C, 0x01, 0x0D, 0x02), identifies:
   - The JP/CALL target address for that type
   - Disassembles the first ~50 bytes of each target
   - What RAM addresses each target reads/writes
   - What subroutines each target calls
4. Produces a summary table: type_code → target_address → purpose

## Template
Base your probe on existing probes in the `TI-84_Plus_CE/` directory. Key patterns:
- `import fs from 'fs'` and `import path from 'path'`
- Read ROM: `const rom = new Uint8Array(fs.readFileSync(path.join(import.meta.dirname, 'ROM.rom')).buffer)`
- Read 24-bit address: `rom[a] | (rom[a+1] << 8) | (rom[a+2] << 16)`
- The dispatch pattern is typically: `CP imm8; JP Z,addr24` or `CP imm8; JR Z,offset`
- TI-OS type codes: 0x00=real, 0x01=real list, 0x02=matrix, 0x0C=complex, 0x0D=complex list, 0x1B=program, 0x1C=protected program, 0x20=appvar, 0x21=group

## Constraints
- Do NOT modify any existing files
- Do NOT touch cpu-runtime.js, peripherals.js, browser-shell.html, or the transpiler
- Pure static disassembly — no boot needed
- Follow each dispatch target 1 level deep (don't recurse into sub-sub-calls)

## Success criterion
The probe produces a complete type-dispatch table showing all 7 type code targets with their first few instructions and identified purpose (e.g., "list editor setup", "matrix editor setup", etc.).
