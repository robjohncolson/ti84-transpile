# Task: Decode ROM function at 0x07D27A

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by writing probe scripts that read ROM bytes and trace execution.

## Target
**0x07D27A** — Type validator tail call for type 0x1C/0x1D (matrix/list). Called when type validation at 0x07FDD6 detects matrix/list type codes. The calling sequence is: type byte AND 0x3F gives 0x1C or 0x1D → save OP1→OP5 via CALL 0x07F95E → JP 0x07D27A.

## What we know
- eZ80 CPU in ADL mode (24-bit addresses, 3-byte pointer loads)
- FP registers: OP1 at D005F8 (9 bytes: type, sign/exp, 7 mantissa), OP2 at D00603, OP3 at D0060E, OP4 at D00619, OP5 at D00624, OP6 at D0062F
- Type codes: 0x00=real, 0x0C=complex, 0x1C=matrix, 0x1D=list, 0x18/0x19=result types
- 0x07F95E copies OP1→OP5 (9-byte LDI chain via JP 0x07F978)
- 0x07FDD6 = OP1 type validator (AND 0x3F, CP 0x1C/0x1D check)
- 0x07D233 = descriptor filter/router that calls into this area
- Key FP helpers: 0x07F978 (9xLDI copy), 0x07F974 (11-byte copy), 0x07FD0E (copy+swap), 0x07FD30 (OP1↔OP2 swap), 0x07FA07 (FP init table)

## Deliverable
Create a probe script at `TI-84_Plus_CE/probe-phase529-decode-07D27A-type-validator-tail.mjs` that:

1. Reads ROM bytes from 0x07D27A for ~80 bytes and disassembles them as eZ80 ADL-mode instructions
2. Identifies all CALL/JP/JR targets
3. Reads ROM bytes at each sub-target for ~20 bytes
4. Documents the full function with a structured comment block at the top

### eZ80 ADL-mode decoding reference
- 3-byte addresses for JP/CALL: opcode + addr_low + addr_mid + addr_high
- LD r,nn = 2 bytes, LD rr,nnnn = 4 bytes (3-byte immediate)
- CALL nn = CD + 3-byte addr, JP nn = C3 + 3-byte addr, JR e = 18/20/28/30/38 + signed offset
- RET = C9, PUSH rr = C5/D5/E5/F5, POP rr = C1/D1/E1/F1
- CP n = FE + byte, AND n = E6 + byte, OR n = F6 + byte
- IX prefix = DD, IY prefix = FD
- LD A,(HL) = 7E, LD (HL),A = 77, INC HL = 23, DEC HL = 2B
- BIT b,(IY+d) = FD CB dd bb
- LDI = ED A0, LDIR = ED B0

### Template
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function readROM(addr, len) {
  return Array.from(rom.slice(addr, addr + len));
}

function hex(b) { return b.toString(16).padStart(2, '0'); }
function hex6(a) { return '0x' + a.toString(16).padStart(6, '0'); }
function addr24(bytes, off) { return bytes[off] | (bytes[off+1] << 8) | (bytes[off+2] << 16); }

// Read main function
const mainBytes = readROM(0x07D27A, 100);
console.log('=== 0x07D27A ROM bytes (100) ===');
for (let i = 0; i < mainBytes.length; i += 16) {
  const chunk = mainBytes.slice(i, i + 16);
  console.log(hex6(0x07D27A + i) + ': ' + chunk.map(hex).join(' '));
}

// Manual decode - identify instructions, CALL/JP/JR targets
// Look for: CD (CALL), C3 (JP), 18/20/28/30/38 (JR variants), C9 (RET)
const targets = [];
let pc = 0;
while (pc < mainBytes.length) {
  const op = mainBytes[pc];
  if (op === 0xCD || op === 0xC3 || (op >= 0xC2 && op <= 0xFA && ((op & 0x07) === 0x02 || (op & 0x07) === 0x03 || (op & 0x07) === 0x04))) {
    // CALL or JP with 3-byte address
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      targets.push({ from: 0x07D27A + pc, target, op: hex(op) });
    }
  }
  if (op === 0xC9) {
    console.log(`\\nRET found at ${hex6(0x07D27A + pc)}`);
    break;
  }
  pc++;
}

console.log('\\n=== CALL/JP targets ===');
for (const t of targets) {
  console.log(`${hex6(t.from)}: opcode ${t.op} → ${hex6(t.target)}`);
}

// Read bytes at each unique target
const uniqueTargets = [...new Set(targets.map(t => t.target))];
for (const t of uniqueTargets) {
  if (t >= 0x000000 && t < rom.length) {
    const bytes = readROM(t, 24);
    console.log(`\\n=== ${hex6(t)} (24 bytes) ===`);
    console.log(bytes.map(hex).join(' '));
  }
}
```
