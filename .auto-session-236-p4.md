# Task (sss): Map Full Home-Screen Key Event Path End-to-End

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM (eZ80 machine code) has been lifted to JavaScript.

Sessions 230-235 have fully decoded every individual block in the home-screen key event path. The complete chain is:

```
0x02FD8F (key-event dispatcher entry)
  → RES 3,(IY+40), LD A,0xCC→(D00000), BIT 0,(IY+52) gate
  → CALL 0x02390A
  → CALL 0x03013A (09F79B key scan table lookup)
  → CALL 0x05C76C
  → CALL 0x03FA09
  → OR A → JP NZ,0x02FE89 (key present)

0x02FE89 (key classifier)
  → CP 0xFF gate
  → SET 0,(IY+29) for non-0xFF
  → BIT 4,(IY+0) → conditional RES 0,(IY+29)
  → BIT 3,(IY+87) test
  → CP 0x36 (CLEAR key) → special handler
  → CP 0x30 (MODE key) → special handler
  → Other keys: 09F79B table lookup via LD DE,0x09F79B at 0x02FF11

0x0302EB (0x44 key gate)
  → CP 0x44 + BIT 4,(IY+0x4B) → conditional LD A,0x1D

0x02FFAE (normal dispatch / mode-sensitive classifier)
  → reads D00824 (mode byte), D007E0 (context)
  → CP cascade: 0x54/0x53/0x43/0x49/0x40
  → Home screen: all fail, key passes through

0x02FFED (OR A convergence gate)
  → NZ: JP 0x02FE84 → CALL 0x030300 (timer) → RET
  → Z: JP 0x02FD99 (event loop re-entry)
```

## Deliverables
Create `TI-84_Plus_CE/probe-phase236-home-key-e2e.mjs` that:

1. Traces a SINGLE key press (use key code 0x8F = digit "1", scan code mapped via 09F79B) through the COMPLETE pipeline from 0x02FD8F to final RET
2. Uses 1000-step limit to ensure the full path completes
3. At each major waypoint (0x02FD8F, 0x02FE89, 0x02FF11, 0x0302EB, 0x02FFAE, 0x02FFED, 0x02FE84, 0x030300), records:
   - Step number when reached
   - A register value
   - Key IY flags (offsets 0, 5, 8, 18, 29, 40, 87)
   - D0058E value
4. Seeds D0058E=0x8F (as if ISR delivered key code 0x8F) before entry
5. Seeds: SP=0xD1A87E, MBASE=0xD0, IY=0xD00080, timer IRQ disabled
6. Outputs a formatted summary table:
   ```
   Step | Block      | A    | D0058E | IY flags | Note
   -----|------------|------|--------|----------|-----
   0    | 0x02FD8F   | 0x00 | 0x8F   | ...      | dispatcher entry
   ...  | 0x02FE89   | 0x8F | 0x8F   | ...      | key present, classify
   ...  | 0x02FFED   | 0x9C | ...    | ...      | OR A gate (NZ→timer)
   ```
7. Also traces a SECOND scenario with NO key (D0058E=0x00) to show the A=0x00 → JP 0x02FD99 path
8. Reports total block count and full block chain for both scenarios
