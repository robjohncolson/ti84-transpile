# Task: Decode 0x03007C — Shared Key Handler Continuation Target

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 ADL mode).

Session 397 discovered that both 0x04CA87 and 0x04CA94 (key handler lookup stubs) tail-call JP 0x03007C with a translated key code in register A. 0x04CA87 adds +0x14 to the key code, 0x04CA94 subtracts -0x14. Both filter sentinel values first (0xE5 and 0x31 respectively).

**0x03007C is the shared continuation target — where the translated key code gets dispatched to its handler.** This is the final key→action mapping point.

## Your Task
Create a probe file `TI-84_Plus_CE/probe-phase398-decode-03007C.mjs` that:

1. Reads ROM.rom from disk
2. Uses the eZ80 decoder at `TI-84_Plus_CE/ez80-decoder.js` (import `decodeInstruction`)
3. Performs static disassembly starting at 0x03007C in ADL mode
4. Traces forward for up to 256 instructions or until RET/HALT
5. For each instruction, logs: address (hex), raw bytes (hex), mnemonic + operands
6. Identifies:
   - What 0x03007C does with register A (the key code)
   - Any jump tables, comparison cascades (CP nn / JP Z), or indirect jumps
   - CALL/JP targets (annotate known addresses like 0x02237E, 0x0301F6, 0x02FD99)
   - RAM reads/writes (especially 0xD0058C kbdKey, 0xD0058E kbdToken, 0xD007E0 mode byte)
   - IY+offset bit operations (IY base = 0xD00080)
7. Also searches the entire ROM for CALL/JP references TO 0x03007C to find all callers
8. Prints a summary section with findings

## Reference Format
