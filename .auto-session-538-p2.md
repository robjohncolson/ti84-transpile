# Task: DECODE 0x07FE20 (4 bytes before 0x07FE24 type transform wrapper)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary, little-endian). We're manually decoding eZ80 functions by reading raw bytes from the ROM.

**What we know about 0x07FE20:**
- Called from 0x07FF03 (zero-type handler) when exponent ≥ 0xE4: `JP NC,$07FE20`
- Only 4 bytes before 0x07FE24, which is the type transform wrapper (session 536): `LD HL,$D005F8; LD A,(HL); CALL 0x07FE2F; LD (HL),A; RET`
- 0x07FE20 is likely a short preamble or alternate entry to 0x07FE24

**eZ80 encoding reminders (ADL mode, all addresses are 3 bytes):**
- LD A,n = 3E nn (2 bytes)
- LD HL,nn = 21 nn nn nn (4 bytes)
- LD A,(HL) = 7E (1 byte)
- CALL nn = CD nn nn nn (4 bytes)
- JP nn = C3 nn nn nn (4 bytes)
- JR e = 18 ee (2 bytes, signed offset from PC+2)
- XOR A = AF (1 byte)
- AND n = E6 nn (2 bytes)
- OR n = F6 nn (2 bytes)
- RET = C9 (1 byte)
- NOP = 00 (1 byte)
- LD (HL),A = 77 (1 byte)

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase538-decode-07FE20.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a binary buffer
2. Dumps raw bytes from 0x07FE20 to 0x07FE2E (15 bytes — covers 0x07FE20 through the known 0x07FE24 function)
3. Manually decodes the instructions starting at 0x07FE20
4. Determines where 0x07FE20's code ends and 0x07FE24 begins (we know 0x07FE24 starts the type transform wrapper)
5. Prints:
   - Raw hex bytes
   - Decoded instructions with addresses
   - Analysis of what the 0x07FE20 entry does differently from entering at 0x07FE24
