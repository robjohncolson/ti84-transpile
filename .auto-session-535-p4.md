# Auto-Session 535 — P4: Decode 0x07FBD9

## Task
Disassemble and decode the function at ROM address **0x07FBD9** in the TI-84 Plus CE OS ROM. This is an eZ80 CPU in ADL mode (24-bit addresses).

## What we know
- 0x07FBD9 is called from the BCD division loop at 0x07DFA0-0x07E009: `CALL 0x07FBD9 (shift left B positions)`
- Also called from the BCD division/formatting engine at 0x07EAxx: `CALL 0x07FBD9 (B=1 multiply)` and `CALL 0x07FBD9 (B=2)`
- Purpose hypothesis: BCD shift left by B digit positions (multi-nibble left shift)
- Nearby known functions:
  - 0x07FB48 = BCD left-shift (30B, 8× RLD on D005FA-D00601, shifts all digits left one nibble) — this shifts by ONE nibble
  - 0x07FBCA = BCD carry propagation / increment (15B, ADC+DAA backward loop)
  - 0x07FC0E = BCD ADD (restores after subtraction trial)
  - 0x07FC94 = BCD subtraction trial
- So 0x07FBD9 likely shifts left by MULTIPLE nibbles (B iterations of the single-nibble shift at 0x07FB48)

## eZ80 Decoding Rules (CRITICAL)
- Default mode is ADL (24-bit). All LD rr,nn use 3-byte immediates. All CALL/JP use 3-byte addresses.
- Prefix 0x52 = .SIL (force 16-bit operands for next instruction)
- ED-prefix opcodes: ED B0 = LDIR, ED A0 = LDI, ED 6F = RLD, ED 67 = RRD
- CB-prefix: BIT/SET/RES + rotate instructions (CB 06 = RLC (HL), CB 16 = RL (HL), etc.)
- DD = IX, FD = IY
- 0xCD = CALL nn (3B), 0xC3 = JP nn (3B), 0xC9 = RET
- 0x10 = DJNZ d (decrement B, jump if not zero — signed 8-bit displacement)
- 0x18 = JR d, 0x20/0x28/0x30/0x38 = JR NZ/Z/NC/C d
- Known BCD RAM: D005F8=OP1 type, D005F9=OP1 exponent, D005FA-D00601=OP1 mantissa (7 bytes)
- RLD instruction (ED 6F): rotates nibbles between A and (HL) — the core BCD shift mechanism
