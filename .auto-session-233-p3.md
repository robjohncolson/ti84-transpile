### Implementation pattern
Each token handler is registered in the `runDirectEvalTemplate` function's token map. Look for the existing `[0xBB,0x53]` (ZTest) handler as a template. The pattern is:

1. Parse arguments from the expression string (comma-separated)
2. Compute the test statistic and p-value
3. Return the p-value (for tests) or {lower, upper} interval (for intervals)

### Statistical formulas

**2-PropZTest(x1, n1, x2, n2, direction)**:
- p̂1 = x1/n1, p̂2 = x2/n2, p̂ = (x1+x2)/(n1+n2)
- z = (p̂1 - p̂2) / sqrt(p̂(1-p̂)(1/n1 + 1/n2))
- Return p-value via existing `_zPValue(z, direction)`

**2-PropZInt(x1, n1, x2, n2, C-level)**:
- p̂1 = x1/n1, p̂2 = x2/n2
- SE = sqrt(p̂1(1-p̂1)/n1 + p̂2(1-p̂2)/n2)
- z* = invNorm((1+C)/2) — use existing `_invNorm`
- Return (p̂1 - p̂2) ± z* × SE

**χ²-Test(observedList, expectedList)**:
- χ² = Σ((O-E)²/E)
- df = length - 1
- p-value via existing `_chiSquareCdf(chi2, df)` → return 1 - cdf

**LinRegTTest(Xlist, Ylist, direction)**:
- Compute LinReg(ax+b) to get a, b, r, n
- SE(b) = sqrt(Σ(yi - ŷi)² / ((n-2) × Σ(xi - x̄)²))
- t = b / SE(b), df = n-2
- p-value via existing `_tPValue(t, df, direction)`

**ANOVA(list1, list2, ...lists)**:
- SSB = Σ(ni × (x̄i - x̄)²), dfB = k-1
- SSW = Σ(Σ(xij - x̄i)²), dfW = N-k
- F = (SSB/dfB) / (SSW/dfW)
- p-value via existing `_fCdf(F, dfB, dfW)` → return 1 - cdf

**1-SampZInt(σ, x̄, n, C-level)**:
- z* = invNorm((1+C)/2)
- ME = z* × σ/sqrt(n)
- Return {lower: x̄ - ME, upper: x̄ + ME}

**1-SampTInt(x̄, Sx, n, C-level)**:
- Use existing `_invT` for t* at (1+C)/2 with df=n-1
- ME = t* × Sx/sqrt(n)
- Return {lower: x̄ - ME, upper: x̄ + ME}

**2-SampTInt(x̄1, Sx1, n1, x̄2, Sx2, n2, C-level)**:
- Welch df = (Sx1²/n1 + Sx2²/n2)² / ((Sx1²/n1)²/(n1-1) + (Sx2²/n2)²/(n2-1))
- t* via `_invT` at (1+C)/2 with Welch df
- SE = sqrt(Sx1²/n1 + Sx2²/n2)
- Return {lower: (x̄1-x̄2) - t*×SE, upper: (x̄1-x̄2) + t*×SE}
