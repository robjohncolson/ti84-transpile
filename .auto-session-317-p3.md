## Task

1. **Find ROM code that populates D13FED** — search for writes to D13FED region:
   - `LD (0xD13FED),A/HL/DE` patterns

   Search patterns: byte sequence `ED 3F D1` (little-endian for 0xD13FED)

2. **Determine struct layout** — from the 0x00F000 cluster code and 0x0241A3 orchestrator:
   - Offset 0: type tag (0x81 for active handlers)

   - Offset +0x10E: more filter flags
   - What's at offset +1 through +0x10B? Especially the callback pointer (IX+0 = first field = offset 0, or is the callback at a different offset?)

3. **Determine table size** — how many entries? Each struct is at least 0x10F bytes. D13FED is in RAM (0xD00000+ range). How far does the table extend?

4. **Find initialization code** — search for code that zeroes or initializes the D13FED region during boot. Look for LDIR targeting D13xxx.

## How to search ROM
```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');

// Search for references to D13FED (little-endian: ED 3F D1)
// But also nearby addresses D13Fxx, D140xx etc.
const targets = [0xD13FED, 0xD13FF0, 0xD14000, 0xD13FE0];
for (const target of targets) {
  const lo = target & 0xFF, mid = (target >> 8) & 0xFF, hi = (target >> 16) & 0xFF;
  for (let i = 0; i < rom.length; i++) {
    if (rom[i] === lo && rom[i+1] === mid && rom[i+2] === hi) {
      // Check preceding byte for instruction type
      const prev = i > 0 ? rom[i-1] : 0;
      console.log(`Ref to 0x${target.toString(16)} at ROM 0x${i.toString(16).padStart(6,'0')} (prev byte: 0x${prev.toString(16).padStart(2,'0')})`);
    }
  }
}
```
