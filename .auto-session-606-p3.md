# Task: Capture VRAM bitmap at peak during key processing

## Context
In the TI-84 Plus CE ROM transpilation project, we've confirmed that the typed '2' character renders to VRAM during key processing (session 601: glyph at rows 219-232, cols 14-23). VRAM peaks at ~3,349+ non-white pixels around step 270K during the first keypress, then gets cleared by a second bulk wipe. We need to capture the FULL VRAM bitmap at peak to see what the OS actually renders.

The LCD is 320×240 pixels, BGR565 format, at address 0xD40000. Total VRAM size = 320×240×2 = 153,600 bytes (0xD40000-0xD52C00).

## Task
Create a probe at `TI-84_Plus_CE/probe-phase606-vram-capture.mjs` that:

1. **Boots the OS** using the established recipe:
   ```javascript
   import { createCPU } from './cpu-runtime.js';
   import { createPeripheralBus } from './peripherals.js';
   const peripherals = createPeripheralBus({ timerInterrupt: false });
   const cpu = createCPU(peripherals);
   cpu.sp = 0xD1A87E - 24;
   cpu.write24(cpu.sp, 0x0019b5);
   cpu.write24(0xD008E0, cpu.sp);
   cpu.adl = 1;
   ```

2. **Runs init** `cpu.runFrom(0x09DD62, { maxSteps: 300000, maxLoopIterations: 30000 })`

3. **Runs paint** with timer on and pushed return 0x0019b5: `cpu.runFrom(0x058241, { maxSteps: 500000, maxLoopIterations: 50000 })`

4. **Snapshots state**, seeds key '2' (0x90):
   ```javascript
   // Save state for restoration
   const snapshot = {};
   snapshot.d007ca = [];
   for (let i = 0; i < 21; i++) snapshot.d007ca.push(cpu.read8(0xD007CA + i));
   snapshot.d0008d = cpu.read8(0xD0008D);
   snapshot.d0231a = cpu.read24(0xD0231A);
   snapshot.d0243a = cpu.read24(0xD0243A);
   // ... etc
   
   // Seed key
   cpu.write8(0xD0058C, 0x90);
   cpu.write8(0xD0058E, 0x90);
   cpu.write8(0xD00587, 0x90);
   cpu.write8(0xD0009F, cpu.read8(0xD0009F) | 0x20);
   cpu.write8(0xD00080, cpu.read8(0xD00080) | 0x08);
   ```

5. **Runs the outer loop** `cpu.runFrom(0x08C331, { maxSteps: 500000, maxLoopIterations: 50000 })` **with VRAM tracking**:
   - Every 5,000 steps, count non-white VRAM pixels
   - Track the step with the MAXIMUM non-white pixel count
   - At the peak step, capture a FULL VRAM snapshot

6. **After the run completes**, re-run from the same state but STOP at the peak step to capture VRAM:
   - Restore the pre-keypress state
   - Re-seed the key
   - Run with `maxSteps` = peak_step + 100
   - Capture the FULL 320×240 VRAM bitmap

7. **Output the VRAM as a text rendering**:
   - For each row (0-239), scan all 320 columns
   - Output a character representation: ' ' for white (0xFFFF), '#' for black (0x0000), '.' for any other non-white color
   - Also output a summary of unique colors and their pixel counts
   - Focus detailed output on rows with content (skip rows that are all-white)

8. **Also output the glyph region** in high detail:
   - For the entry line area (rows 210-239), output each pixel as a color code
   - For the status bar (rows 0-30), same detailed output
   - Identify any recognizable character shapes

- A text rendering of the full 320×240 display at peak
- Detailed glyph analysis of the entry line and status bar
- Summary of colors and pixel counts
