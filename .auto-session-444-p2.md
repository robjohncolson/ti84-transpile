# Task: Trace the Event Loop Outer Caller (Who Calls 0x003A73?)

## Context
The TI-84 Plus CE OS event loop starts at address 0x003A73. When the CPU hits the HALT barrier at 0x001942 (via the wrapper at 0x001933, entered from event loop tail `JP NZ,0x001933` at 0x003A81), the timer ISR fires, RETI returns to 0x001943, the shared tail RETs at 0x00194C. But where does that RET go? Who is the outer caller that loops back to 0x003A73?

This is critical for understanding whether the OS event loop is called once and loops internally, or whether an outer scheduler repeatedly calls into 0x003A73.

## What To Do
Create a probe file `TI-84_Plus_CE/probe-phase444-trace-event-loop-caller.mjs` that:

1. Boots the OS using the standard boot sequence (see `probe-workflow-arithmetic.mjs` for the pattern: BOOT_ENTRY → KERNEL_INIT → POST_INIT → STAGE_ENTRIES → EVENT_LOOP_ENTRY)

2. Runs from EVENT_LOOP_ENTRY (0x003A73) in ADL mode with a key pressed (use key '1': idx=4, bit=1) for up to 500,000 steps

3. Traces execution to find the call chain. Specifically, use `onBlockEntry` or step-level tracing to capture the PC at key points:
   - When does execution reach 0x003A81 (JP NZ to the HALT wrapper)?
   - What is on the stack when 0x003A73 is first entered? (Read SP and the return address at [SP])
   - After the HALT bypass fires (use `diHaltBypass: true`), does the PC return to 0x003A73 or somewhere else?

4. Disassemble the ROM around 0x003A73 to find:
   - What is at 0x003A73 - 0x003A90? (read raw bytes from ROM.rom)
   - Is there a CALL to 0x003A73 anywhere in the surrounding code?
   - What function contains 0x003A73? Where does it start? Where does it end?

5. Search for all references to 0x003A73 in the ROM. Read bytes from ROM.rom and scan for:
   - `C3 73 3A 00` (JP 0x003A73)
   - `CD 73 3A 00` (CALL 0x003A73)
   - `CA 73 3A 00` / `C2 73 3A 00` / `DA 73 3A 00` / `D2 73 3A 00` / `EA 73 3A 00` / `E2 73 3A 00` / `FA 73 3A 00` / `F2 73 3A 00` (conditional JP/CALL variants)

6. Disassemble the block containing 0x003A73: go backward from 0x003A73 to find the start of the containing function (look for a RET or JP at the end of the previous function), and forward past 0x003A81 to find its end.
