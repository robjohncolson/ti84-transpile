# Auto-Session 271 P1: Disassemble the 5 Polling Blocks

## Goal
Disassemble the 5 blocks that form the event loop polling loop to understand what comparison/exit condition they implement. These blocks are: 0x082BE2, 0x084716, 0x08471B, 0x084723, 0x084711.

## Background
The TI-84 CE OS event loop (entered via 0x0582BC home body) settles into a tight 5-block polling loop: 0x082BE2→0x084716→0x08471B→0x084723→0x084711→back. Session 269 decoded the dispatch table format: 9-byte entries at D3FFFF downward, comparing D005F9/D005FA/D005FB. Session 270 found that manually seeding table entries doesn't exit the loop — either the blocks don't implement the expected comparison, or the table pointers (D0259D, D025A3) need initialization via 0x09E2EC context registration.

## Task
Create a probe file `TI-84_Plus_CE/probe-phase271-polling-block-disasm.mjs` that:

1. Loads the ROM binary from `TI-84_Plus_CE/ROM.rom` (4MB file)
2. For each of the 5 blocks (0x082BE2, 0x084716, 0x08471B, 0x084723, 0x084711):
   - Read raw bytes from ROM at that address (read 64 bytes from each)
   - Use the eZ80 decoder at `TI-84_Plus_CE/ez80-decoder.js` to decode instructions starting at each address
   - Print a full disassembly listing: address, hex bytes, mnemonic
   - Stop decoding when you hit an unconditional jump (JP/JR) or RET, or after 64 bytes
3. Also dump the raw hex bytes for the first 32 bytes of each block for manual verification
4. Identify and report:
   - What memory addresses are read (LD A,(addr), BIT n,(addr), etc.)
   - What comparisons are performed (CP, BIT, AND, OR)
   - What conditional jumps exist and their targets
   - Whether D005F9/D005FA/D005FB are referenced
   - Whether D0259D or D025A3 (table pointers) are referenced

## Reference Files
- `TI-84_Plus_CE/ROM.rom` — raw ROM binary
- `TI-84_Plus_CE/ez80-decoder.js` — eZ80 instruction decoder. Import: `import { decodeInstruction } from './ez80-decoder.js';`
  - Signature: `decodeInstruction(rom, offset, adlMode)` where rom is a Buffer, offset is the byte offset, adlMode is boolean (use true for ADL mode)
  - Returns: `{ mnemonic, length, bytes }` or similar (read the file header to confirm)
- `TI-84_Plus_CE/cpu-runtime.js` — runtime (not needed for this task)

## Constraints
- Do NOT modify any existing files
- Create ONLY the probe file listed above
- Use `import { readFileSync } from 'fs';` to read the ROM
- The ROM file is memory-mapped 1:1 — address 0x082BE2 is byte offset 0x082BE2 in the file
- Use ADL mode (adlMode=true) for all decoding — this is post-boot code

## Success Criteria
- Probe runs with `node TI-84_Plus_CE/probe-phase271-polling-block-disasm.mjs`
- Prints a clear disassembly of all 5 blocks
- Identifies what the exit condition of the polling loop is
- Reports whether D005F9/D005FA/D005FB and D0259D/D025A3 are referenced
