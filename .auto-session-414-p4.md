# Task: Add 20 New Transpiler Seeds for Coverage Push

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The transpiler is at `scripts/transpile-ti84-rom.mjs`. It lifts eZ80 ROM code to JavaScript by walking from seed addresses. Current stats: 145,339 blocks, 710,653 covered bytes.

## What to do
1. Run the coverage analyzer to find gaps: `node TI-84_Plus_CE/coverage-analyzer.mjs`
2. Read the output to identify uncovered ROM regions
3. For each gap, check if the bytes at the gap start look like valid eZ80 code (not data tables, not 0xFF padding, not ASCII strings)
4. Add 20 new seed addresses to `scripts/transpile-ti84-rom.mjs` in the `seeds` array
5. Re-run the transpiler: `node scripts/transpile-ti84-rom.mjs`
6. Verify the golden regression still passes: `node TI-84_Plus_CE/probe-phase99d-home-verify.mjs`

## How to identify valid code vs data
- Valid code: starts with common eZ80 opcodes (PUSH=0xC5/D5/E5/F5, LD=various, CALL=0xCD, JP=0xC3, JR=0x18/0x20/0x28/0x30/0x38, DI=0xF3, EI=0xFB, RET=0xC9)
- Data tables: repeating patterns, ASCII text (0x20-0x7E runs), all 0xFF, all 0x00
- Jump table stubs: 0xC3 followed by 3-byte address (JP instructions) — these ARE valid seeds
- Avoid addresses in the 0x100000-0x3FFFFF range (certificate/app storage, mostly erased)

## Seed format in transpile-ti84-rom.mjs
Seeds are in an array. Add entries like:
```javascript
0x00XXXX,  // brief description of what's at this address
```

Pick addresses spread across different ROM regions for maximum coverage:
- 10 from OS code area (0x000000-0x0FFFFF)
- 10 from app/utility area (0x010000-0x0FFFFF) or jump table stubs

## Important constraints
- ONLY modify `scripts/transpile-ti84-rom.mjs` (to add seeds)
- Do NOT modify any other files
- Do NOT add seeds that are already in the seeds array
- Do NOT add seeds in the 0x100000-0x3FFFFF range (mostly erased flash)
- After adding seeds, run the transpiler and verify golden regression passes
- If golden regression fails after adding seeds, remove the problematic seeds and try different ones

## Success criteria
- 20 new seeds added to transpile-ti84-rom.mjs
- Transpiler runs successfully with increased block/byte counts
- Golden regression (probe-phase99d-home-verify.mjs) still passes (look for "Normal Float Radian" in output)
- Report the new block count and covered byte count
