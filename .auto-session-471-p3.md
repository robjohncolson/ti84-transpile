# Task: Find the Jump Table Dispatcher for Syscall Table at 0x020104

## Goal
Create a probe `TI-84_Plus_CE/probe-phase471-jumptable-dispatcher.mjs` that finds how the 2178-entry JP syscall table starting at 0x020104 is indexed.

## Context
- ROM has a 2178-entry JP table from 0x020104 to 0x02230C (each entry is 4 bytes: C3 xx xx xx = JP addr)
- Table base 0x020104 is preceded by ROM signature 5A A5 FF FF at 0x020100
- Zero direct CALL/JP references to any individual entry — all access is via computed indexing
- Entry #1614 (at 0x021A3C) = JP 0x08BF22 (home screen init)
- Entry #1645 (at 0x021AB8) = JP 0x030078 (key wait loop / mode handler)
- The dispatcher must compute: table_base + (index × 4) and then JP/CALL to the result
- Common patterns: SLA/ADD HL,HL (multiply by 2, twice = ×4), or ADD HL,HL+ADD HL,HL, then LD from table, JP (HL) or CALL (HL)

## What to build
A probe that searches the ROM for the dispatcher using multiple strategies:

### Strategy 1: Search for the table base address 0x020104 in ROM
Search all ROM bytes (0x000000-0x3FFFFF) for the 3-byte sequence 04 01 02 (little-endian 0x020104). Log every occurrence with surrounding context (16 bytes before and after). This finds code that loads the table base into a register.

### Strategy 2: Search for 0x020100 (the signature address)
Search for 00 01 02 (little-endian 0x020100). The dispatcher might load the signature address and add 4.

### Strategy 3: Search for multiply-by-4 + JP (HL) patterns
Search for sequences like:
- ADD HL,HL (29) followed by ADD HL,HL (29) within 8 bytes of JP (HL) (E9)
- SLA L (CB 25) near JP (HL) (E9)

### Strategy 4: Boot trace
Run the full 3-stage cold boot, then continue execution from 0x08BF22 (home screen init) with onBlock logging. Track if any PC lands in the range 0x020104-0x02230C. If so, the preceding block is the dispatcher.

### Strategy 5: Search for LD HL,(addr) where addr is in the table range
The dispatcher might load a pointer from RAM that contains the current mode's table entry address.

## Implementation
```js
#!/usr/bin/env node
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { createExecutor } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const rom = fs.readFileSync(path.join(__dirname, 'ROM.rom'));

// Strategy 1: Find 0x020104 references
console.log('=== Strategy 1: References to table base 0x020104 ===');
for (let i = 0; i < rom.length - 2; i++) {
  if (rom[i] === 0x04 && rom[i+1] === 0x01 && rom[i+2] === 0x02) {
    const addr = i;
    // Show surrounding bytes
    const start = Math.max(0, addr - 16);
    const end = Math.min(rom.length, addr + 19);
    const bytes = [];
    for (let j = start; j < end; j++) {
      bytes.push(rom[j].toString(16).padStart(2, '0'));
    }
    console.log(`  Found at 0x${addr.toString(16).padStart(6,'0')}: ...${bytes.join(' ')}...`);
  }
}
// ... etc for other strategies
```

The probe should:
1. Run all 5 strategies
2. For Strategy 4, use the standard 3-stage boot then enter at 0x08BF22 with maxSteps=100000
3. Report ALL findings with context
4. If a dispatcher is found, decode the surrounding instructions manually (show raw bytes and explain what they do)

## Boot sequence (for Strategy 4)
```js
const STACK_RESET_TOP = 0xD1A87E;
const MEM_SIZE = 0x1000000;
const mem = new Uint8Array(MEM_SIZE);
mem.set(rom);
const peripherals = createPeripheralBus({ timerInterrupt: false });
const executor = createExecutor(BLOCKS, mem, { peripherals });
const cpu = executor.cpu;
// 1a. Boot entry
executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 });
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
// 1b. Kernel init  
cpu.mbase = 0xD0; cpu._iy = 0xD00080;
executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu._hl = 0;
cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;
cpu.sp = STACK_RESET_TOP - 3; mem.fill(0xFF, cpu.sp, cpu.sp + 3);
// 1c. Post-init
executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 });
```
