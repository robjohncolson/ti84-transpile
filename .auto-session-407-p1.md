## Technical Details
- eZ80 is little-endian, 24-bit addresses
- Use the ROM file directly: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom')`
- Read bytes: `rom[addr]`, `rom[addr] | (rom[addr+1] << 8)` for 16-bit, add `| (rom[addr+2] << 16)` for 24-bit
- Key opcodes: CALL nn = 0xCD followed by 3 bytes (24-bit target), JP nn = 0xC3 + 3 bytes, JP cc,nn = 0xC2/CA/D2/DA/E2/EA/F2/FA + 3 bytes, JR e = 0x18 + signed byte, JR cc,e = 0x20/28/30/38 + signed byte
- CP n = 0xFE + 1 byte, CP r: 0xB8-0xBF
- JP (HL) = 0xE9, JP (IX) = 0xDD 0xE9, JP (IY) = 0xFD 0xE9
- RET = 0xC9, RET cc = 0xC0/C8/D0/D8/E0/E8/F0/F8
- LD A,(nn) = 0x3A + 3 bytes, LD (nn),A = 0x32 + 3 bytes
