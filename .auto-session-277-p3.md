# Auto-Session 277 — P3: Trace callers of 0x0820ED (entry writer setup chain)

## Context

You are working on a TI-84 Plus CE ROM transpilation project. The ROM (eZ80 CPU) has been lifted to JavaScript blocks. You write Node.js probe scripts that boot the OS, seed specific state, then trace execution to decode unknown functions.

In session 276, we fully decoded **0x0820ED** — the entry writer function that inserts 9-byte entries into three parallel tables (D02590/D0259A/D0259D). It reads entry data from the D005F8-D005FF buffer. The question: **Who calls 0x0820ED, and what populates D005F8-D005FF before the call?** This traces the setup chain — understanding who prepares entry descriptors reveals what triggers VAT table population.

## Key addresses

- 0x0820ED = entry writer. Reads 8 bytes from D005F8-D005FF, inserts 9-byte entry. D005FE = type byte ($=0x24, r=0x72, :=0x3A).
- D005F8-D005FF = 8-byte entry descriptor buffer (source data for entry writer)
- D02590 = table pointer 1 (always decremented)
- D0259A = table pointer 2 (unless type=="$")
- D0259D = table pointer 3 (conditional on type)
- 0x0846EA = FindSym (VAT lookup)
- 0x023093 = cache multiple VAT entries function
