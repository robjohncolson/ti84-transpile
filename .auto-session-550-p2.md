# Task: Map Token String Tables — dump entries from base table at 0x09F87D

## Context
In the TI-84 Plus CE ROM (eZ80, `TI-84_Plus_CE/ROM.rom`, 4MB), session 549 decoded 0x0A2A68 as the TOKEN PAGE DISPATCHER. It dispatches to 10+ token string tables based on the page byte (D register). The base table for 1-byte tokens (D=0x00) starts at 0x09F87D. Each entry is 3 bytes (24-bit pointer to the token's display string).

The known table bases from session 549 are:
- 0x09F87D — D=0x00, base 1-byte tokens
- 0x09FB7D — D=0x5D
- 0x09FB9B — D=0x5D exact (JR Z target)
- 0x09FBCB, 0x09FBEF, 0x09FC01 — D<0x60 sub-pages
- 0x09FBAD — D=0x60
- 0x09FC0A, 0x09FC28 — D=0x61
- 0x09FC64 — D=0x63
- 0x09FDC6 — D=0x7E
- 0x09FC46, 0x09FDFF, 0x0A00E1 — D=0xBB

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase550-map-token-tables.mjs` that:

1. Reads the ROM binary from `TI-84_Plus_CE/ROM.rom`
2. For the BASE TABLE at 0x09F87D (D=0x00, 1-byte tokens):
   - Read entries as 3-byte LE pointers. Token code L is the index (L×3 + base = entry offset).
   - For each entry (L = 0x00 through at least 0xFE, or until pointers look invalid — e.g., point outside ROM or to 0x000000):
     - Read the 3-byte pointer
     - If pointer is in ROM range (< 0x400000), follow it and read the string at that address
     - TI token strings may be length-prefixed (first byte = length) or null-terminated — check both patterns
     - Print: token code, pointer address, and the ASCII representation of the string (replacing non-printable bytes with '.')
3. Also dump the FIRST 16 ENTRIES of each of the other table bases listed above, in the same format
4. Print summary: total valid entries per table, sample strings

## String format notes
- TI token strings may use the format: first byte = count, followed by count bytes of character data
- Or they may be null-terminated
- Or the 3-byte entry itself may encode something other than a pointer (check if values are reasonable ROM addresses)
- Characters 0x20-0x7E are ASCII-printable; others are TI-specific tokens or control codes

- Run it: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase550-map-token-tables.mjs`
