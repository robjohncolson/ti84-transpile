## How to decode eZ80
Key opcodes:
- `0xCD` = CALL.LIL (4 bytes: CD + 3-byte LE addr)
- `0xC9` = RET
- `0xC3` = JP.LIL (4 bytes)
- `0x21` = LD HL,imm24 (4 bytes ADL mode)
- `0x3E` = LD A,imm8 (2 bytes)
- `0xFD 0xCB offset op` = IY bit ops
- `0x40` prefix (.SIS) = short mode
