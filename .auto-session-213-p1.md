# Auto-Session 213 P1: Trace 0x0612B0 / 0x0612E4 Edit-Mode Entry Points

## Context
Session 212 found that `SET 4,(IY+5)` (the edit-mode flag that gates digit insertion via ConvKeyToTok→BufInsert) has **12 SET sites** in the ROM. Two of them — **0x0612B0** and **0x0612E4** — are in the editor region, 52 bytes apart, and are the prime candidates for arming edit mode on the home screen.

We need to understand:
1. What code CALLS these addresses (static callers in ROM)
2. What the surrounding function does (disassemble the function containing each SET instruction)
3. Whether these are reachable from the home-screen boot path

## Task
Create a probe file `TI-84_Plus_CE/probe-phase213-edit-mode-entry.mjs` that:

### Part A: Static ROM scan for callers
- Read `ROM.rom` (binary, at `TI-84_Plus_CE/ROM.rom`)
- Scan for `CALL 0x0612B0` (ADL CALL = `CD B0 12 06`) and `JP 0x0612B0` (ADL JP = `C3 B0 12 06`)
- Scan for `CALL 0x0612E4` (ADL CALL = `CD E4 12 06`) and `JP 0x0612E4` (ADL JP = `C3 E4 12 06`)
- Also check for `CALL` to the function entry (the SET instruction may not be at the function start — scan backward from each SET site to find the function entry, look for a RET or JP before it)
- Print all call/jump sites found with their addresses and surrounding bytes

### Part B: Static disassembly of both regions
- Import `decodeInstruction` from `./ez80-decoder.js`
- Disassemble from 0x061280 to 0x061320 (covers both SET sites with context)
- For each instruction, print: address, hex bytes, mnemonic
- Identify the function boundaries (look for RET instructions before 0x0612B0 and after 0x0612E4)

### Part C: Dynamic trace
- Use the same boot sequence as `probe-phase212-multi-digit-entry.mjs`: cold boot (0x000000 z80) → kernelInit (0x08C331 adl, 100000 steps) → postInit (0x0802B2 adl) → memInit (0x09DEE0 adl, return sentinel 0x7FFFF6)
- After boot, set up: SP=0xD1A87E, IX=0xD1A860, IY=0xD00080, MBASE=0xD0
- Try calling 0x0612B0 directly (push return sentinel 0x7FFFFE on stack, set PC=0x0612B0, run up to 500 steps)
- Check if BIT 4,(IY+5) becomes SET after the call
- Report: steps taken, blocks visited, final IY+5 value, any other IY flags changed
