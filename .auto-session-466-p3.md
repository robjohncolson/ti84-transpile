The question: **What does 0x003D5A do?** It's called 100 times per event loop iteration. Understanding this function explains the event loop's inner workings.

## ROM Byte Decoding
For manual disassembly: ROM is the `romBytes` buffer. Address 0x003D5A → `romBytes[0x003D5A]`. eZ80 instructions are variable length (1-6 bytes). Key opcode patterns:
- 0xCD = CALL nn (3-byte address follows in little-endian)
- 0xC9 = RET
- 0xC3 = JP nn
- 0x10 = DJNZ (relative offset)
- 0xDB = IN A,(n) / 0xED = extended prefix
- 0x3A = LD A,(nn)
- 0x32 = LD (nn),A

Print raw hex bytes alongside decoded instructions.
