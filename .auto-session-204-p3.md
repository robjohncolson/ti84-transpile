### Statistical distributions (AP Stats relevant — HIGH PRIORITY):
- `normalcdf(lower, upper, μ, σ)`: Use the error function approximation. Default μ=0, σ=1.
- `invNorm(area, μ, σ)`: Newton's method on normalcdf. Default μ=0, σ=1.
- `normalpdf(x, μ, σ)`: `(1/(σ*√(2π))) * e^(-(x-μ)²/(2σ²))`. Default μ=0, σ=1.
- `binompdf(n, p, x)`: `C(n,x) * p^x * (1-p)^(n-x)`. If x omitted, return list for all x.
- `binomcdf(n, p, x)`: Sum of binompdf(n,p,0) through binompdf(n,p,x).
- `geometpdf(p, x)`: `(1-p)^(x-1) * p`
- `geometcdf(p, x)`: `1 - (1-p)^x`
- `stdDev(list)`: Standard deviation (population σ, not sample s)
- `variance(list)`: Variance

### Utility:
- `not(x)`: logical NOT (returns 1 if x==0, else 0)
- `SortA(list)`: ascending sort
- `SortD(list)`: descending sort
