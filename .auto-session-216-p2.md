# Auto-Session 216 — P2: Dispatcher trace with editCursor seeded

## Context

We're reverse-engineering the TI-84 Plus CE OS ROM (eZ80). The edit-mode dispatcher at 0x061290 branches on A register value. When A=0x03, it calls sub-functions (0x06121E, 0x0605A4, 0x06C737) then does `SET 4,(IY+5)` at 0x0612B0.

Session 215 traced from 0x060048 (parent function) with A=0x03 and BIT 7,(IY+0x18) forced SET. The dispatcher was reached at step 2, but **SET 4,(IY+5) was NOT completed** — execution returned to sentinel in 61 steps / 55 blocks. The sub-calls (0x06121E, 0x0605A4, 0x06C737) returned early.

Session 215 also found that **editCursor at 0xD0243A must be initialized to 0xD00A00** for BufInsert to work (the Z-flag root cause). The sub-calls inside the dispatcher may also need this pointer.

## Task

Build a probe `TI-84_Plus_CE/probe-phase216-dispatcher-cursor-seeded.mjs` that:

### Part A: Dispatcher trace with editCursor seeded
1. Set up standard runtime (see below)
2. Initialize:
   - IY = 0xD00080
   - A = 0x03 (triggers the SET 4 branch)
   - BIT 7,(IY+0x18) = SET (arm the gate at 0x060048)
   - **editCursor 0xD0243A = 0xD00A00** (the key finding from session 215)
   - PC = 0x061290 (dispatcher entry directly, skip the parent function)
3. Run up to 500 steps
4. Log: every block visited (with step number), register A at entry
5. After execution: check if IY+5 bit 4 is SET (value should be 0x10 at byte 0xD00085)
6. Report: did SET 4,(IY+5) complete? How many steps? Which sub-calls were visited?

### Part B: Dispatcher with MORE edit context
Same as Part A, but also seed:
- 0xD0243D = 0xD00A00 (second edit pointer — session 215 found setting BOTH breaks BufInsert, but the dispatcher sub-calls may need it differently)
- Edit buffer at 0xD00A00: fill 16 bytes with 0x00 (clean buffer)
- 0xD00085 (IY+5) = 0x00 initially (clear, so we can detect if SET fires)

### Part C: Dispatcher with full edit context
Same as Part B, plus:
- 0xD0008C (IY+12) bit 7 = CLEAR (home-screen mode, not editor)
- 0xD00089 (IY+9) = 0x00
- 0xD00080 + 0x44 = 0xD000C4 (IY+0x44) bit 5 = CLEAR
- Stack pointer at 0xD1A860 (standard home-screen SP)

### Part D: Trace individual sub-calls
For each of the 3 sub-calls (0x06121E, 0x0605A4, 0x06C737), trace them individually with:
- editCursor seeded (0xD0243A = 0xD00A00)
- 200 steps each
- Log: blocks visited, return address, what they read/write
