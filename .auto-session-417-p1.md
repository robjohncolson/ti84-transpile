## Reference
- ROM file: `TI-84_Plus_CE/ROM.rom`
- eZ80 is little-endian, 24-bit addresses. LD (addr),A = 0x32 addr_lo addr_mid addr_hi. LD A,imm = 0x3E imm. XOR A = 0xAF.
- To find LD (D17795),A: search for bytes `32 95 77 D1` in the ROM.
- D17795 = 0xD17795. In ROM byte search: 0x95 0x77 0xD1.
- Read ~50 bytes before and after each writer to understand context.
