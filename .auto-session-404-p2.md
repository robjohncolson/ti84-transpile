# Task: Decode the Action Code CODEC Lookup Tables

## Context
You are working on a TI-84 Plus CE ROM (eZ80) reverse-engineering project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

Session 403 found a bidirectional action code CODEC at 0x07FE2F and 0x07FE65 in the ROM. Key findings:
- These use CPIR-based lookup to map between external and internal action codes
- Known mappings: external (0x21,0x20,0x1C,0x18,0x00,0x19) ↔ internal (0x1F,0x1E,0x1D,0x1B,0x0C,0x1B)
- The CPIR instruction scans a byte table until a match is found, then uses the position to index a parallel output table
- 119 callers of the action byte interpreter at 0x07FDD6

## Task
Create a probe `TI-84_Plus_CE/probe-phase404-action-codec.mjs` that:

1. **Fully disassemble 0x07FE2F** (external→internal encoder):
   - Find the CPIR table start address and length
   - Dump all external code bytes in the lookup table
   - Find the parallel internal code output table
   - Dump all internal code bytes
   - Map each external→internal pair

2. **Fully disassemble 0x07FE65** (internal→external decoder):
   - Same analysis as above but in reverse direction
   - Find both tables, dump all bytes, map each pair

3. **Cross-reference with callers**: 
   - Find all CALL/JP references to 0x07FE2F and 0x07FE65 in the ROM
   - For each caller, show what value they load into A before the CALL (the input code)
   - This reveals which external/internal codes are actually used by the OS

4. **Build the complete action code dictionary**:
   - Combine the lookup tables with caller analysis
   - Output a complete mapping table: external code → internal code → description/context (based on caller location)

## Reference files

## eZ80 instruction reference for this task
- CPIR: Compare A with (HL), increment HL, decrement BC, repeat until match or BC=0. Z flag set on match.
- After CPIR match, HL points one byte PAST the matched entry
- The position in the table tells you the index into the output table
