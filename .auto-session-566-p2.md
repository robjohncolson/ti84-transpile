Session 565 decoded 0x0A2695 (65B post-blit column handler + row closer) which has JP NZ,0x0A2537 as its row loop top. 0x0A2537 is where each scanline row of a glyph begins rendering. It is part of the large glyph rendering pipeline:
- 0x0A23E5 = BLIT LOOP entry (~512B, 3 rendering paths mono/4bit/16bit)
- 0x0A2537 = row loop top (TARGET — decode this)
- 0x0A2548 = column blit routine
- 0x0A2695 = post-blit column handler + row closer (65B, decoded session 565)

The rendering pipeline uses:
- IX = glyph data pointer (28 bytes per glyph from font table at 0x003D6E)
- IY = D00080 (OS flag base)
- D0059C = VRAM scanline pointer
- Stride = 0x280 (640 bytes per 16bpp scanline)
- B register = row count (DJNZ loop)
