# Auto-Session 188 P2: STAT Micro-Trace Extended (2000+ steps)

## Goal
Extend the STAT key dispatch micro-trace from session 187's 500-step limit to 2000+ steps, to find where key code 0x31 (STAT) branches from the shared non-ENTER handler into a STAT-specific menu path.

## Background
- Session 187 built `probe-phase187-stat-key-dispatch.mjs` which traced STAT key dispatch
- STAT key: physical scan 0x37 → _GetCSC index 0x20 → home key code 0x31
- 0x0585D3 is the home-context structure (cxMain=0x0585E9)
- Dispatch is branch-based, not table-indexed
- Micro-trace reached: 0x0585E9 → 0x0585F8 → 0x058602 → 0x05877A (shared non-ENTER handler) → 0x0587A3 → 0x0587E9 → 0x058B73
- Stopped at 500 steps — need to go further to find the STAT-specific branch

## Deliverables

### Create `TI-84_Plus_CE/probe-phase188-stat-extended-trace.mjs`

Build a probe that:
1. Sets up memory for home-screen context (same as probe-phase187-stat-key-dispatch.mjs)
2. Pre-seeds A register = 0x31 (STAT key code) at entry to the home context handler
3. Seeds execution at **0x0585E9** (cxMain — where the key handler starts for the home context)
4. Runs for **3000 steps** (not 500)
5. Logs every unique PC visited (block entry points), with step number
6. Specifically watches for:
   - Any CP (compare) instruction where A is compared against key codes (especially 0x31, 0x09 for ENTER, 0xFC for STAT)
   - Any JR/JP conditional branches that fire based on the comparison
   - Any CALL to addresses in the 0x058xxx or 0x059xxx range (STAT app lives here)
   - Whether execution reaches 0x059xxx range (likely STAT menu handler territory)
7. Reports: ordered list of block PCs visited, key branch decisions (which comparisons matched/didn't), and whether a STAT-specific path was found

**Memory setup needed** (from session 187 probe pattern):
- IX = 0xD1A860 (home-screen stages need this)
- IY = 0xD00080 (flags base)
- Stack at 0xD1A87E
- `createPeripheralBus({ timerInterrupt: false })`
- MBASE = 0xD0 (cpu-runtime.js default handles this)
- Key matrix: set keyMatrix for STAT key if the handler re-reads it (keyMatrix[1] bit 4 for group 6 scan)
- The "current key" variable: write 0x31 to A register AND to any RAM location the handler might read (check session 187 probe for what it used)

**Key reference**: Read `probe-phase187-stat-key-dispatch.mjs` for the exact memory setup pattern. Copy its initialization but increase the step limit to 3000.
