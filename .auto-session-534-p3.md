# Task: Map BCD Constant Table at 0x07F196

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB). Session 533 decoded the BCD constant table loader at 0x07F16C which loads entries from a table starting at 0x07F196.

## Known Facts
- Table starts at 0x07F196
- Each entry is 9 bytes (1 exponent byte + 7 mantissa bytes + 1 sign/type byte... actually the TI BCD format is: byte 0 = sign/flags, byte 1 = biased exponent (0x80 = 10^0), bytes 2-8 = 7 mantissa bytes holding 14 BCD digits)
- Entry 0 (offset 0) = 180/π ≈ 57.29577951 (exponent 0x81)
- Entry 4 (offset 36) = π ≈ 3.14159265 (exponent 0x80)
- The loader at 0x07F16C takes entry index in A, computes offset = A × 9, adds to base 0x07F196

## What To Do
1. Create `TI-84_Plus_CE/probe-phase534-bcd-constant-table.mjs`
2. Read raw ROM bytes starting at 0x07F196. Read at least 180 bytes (enough for ~20 entries).
3. Parse each 9-byte entry as a BCD floating-point number:
   - Byte 0: sign/type (0x00 = positive real, 0x80 = negative real)
   - Byte 1: biased exponent (0x80 = 1.xxx, 0x81 = 1x.xxx, 0x7F = 0.1xxx, etc.)
   - Bytes 2-8: BCD mantissa (each byte = 2 decimal digits, e.g., 0x31 = "31")
   - Value = sign × mantissa × 10^(exponent - 0x80)
4. For each entry, compute and print:
   - Entry index
   - Raw 9 hex bytes
   - Decoded decimal value
   - Possible identification (π, 180/π, e, ln(10), 1/ln(10), 0.5, 1.0, 2.0, 10.0, etc.)
5. Determine where the table ends. Look for:
   - A run of 0x00 bytes (padding)
   - Or the start of executable code (opcodes that make sense as instructions)
   - Or a known function start address

## TI BCD Format Example
Entry for π (3.14159265358979):
- Bytes: `00 80 31 41 59 26 53 58 97` 
- Sign=0x00 (positive), Exp=0x80 (10^0), Mantissa=3.14159265358979

## Constraints
- Do NOT modify any existing files except creating the new probe
- Run the probe via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase534-bcd-constant-table.mjs`
- The probe only needs to READ ROM bytes — no CPU execution needed

## Success Criterion
Probe runs, prints a formatted table of all BCD constants with their decoded values and identifications. Determine total entry count.
