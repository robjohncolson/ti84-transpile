## eZ80 Reference (ADL mode)
- Opcodes are similar to Z80 but addresses are 24-bit (3 bytes, little-endian)
- CP n = 0xFE nn (compare A with immediate)
- LD A,(HL) = 0x7E
- LD A,(nn) = 0x3A nn nn nn (24-bit address)
- INC HL = 0x23, DEC DE = 0x1B
- PUSH DE = 0xD5, POP DE = 0xD1
- RET = 0xC9, RET Z = 0xC8, RET NZ = 0xC0
- CALL nn = 0xCD nn nn nn
- JP nn = 0xC3 nn nn nn
- OR A = 0xB7, XOR A = 0xAF
- SBC HL,DE = 0xED 0x52
- ADC HL,DE = 0xED 0x5A
- LD HL,(nn) = 0x2A nn nn nn
- LD DE,(nn) = 0xED 0x5B nn nn nn
