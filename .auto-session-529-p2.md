# Task: Decode ROM function at 0x0685DF

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by writing probe scripts that read ROM bytes and trace execution.

## Target
**0x0685DF** — Exponent save+normalize helper. Known behavior: saves D005F9 (OP1 exponent) to stack, sets exponent to 0x80, then CALL 0x07CBB5. Called from 0x07FD24 (part of FP copy/swap chain).

## What we know
- eZ80 CPU in ADL mode (24-bit addresses, 3-byte pointer loads)
- FP registers: OP1 at D005F8 (9 bytes: type, sign/exp, 7 mantissa), OP2 at D00603
- D005F9 = OP1 exponent byte
- 0x07CBB5 = FP normalization core (CALL 0x07FF38 + conditional branching, CP 0x70, CPL+AND 0x0F logic)
- 0x07FD24 = part of FP copy/swap chain that calls this
- Key FP helpers: 0x07F978 (9xLDI copy), 0x07FD0E (copy+swap), 0x07FA07 (FP init table)

## Deliverable
Create a probe script at `TI-84_Plus_CE/probe-phase529-decode-0685DF-exp-save-normalize.mjs` that:

1. Reads ROM bytes from 0x0685DF for ~60 bytes and disassembles them as eZ80 ADL-mode instructions
2. Identifies all CALL/JP/JR targets
3. Reads ROM bytes at each sub-target for ~24 bytes
4. Also reads 0x07FD24 for ~20 bytes to confirm calling context
5. Documents findings with structured output

### eZ80 ADL-mode decoding reference
- 3-byte addresses for JP/CALL: opcode + addr_low + addr_mid + addr_high
- LD r,nn = 2 bytes, LD rr,nnnn = 4 bytes (3-byte immediate)
- CALL nn = CD + 3-byte addr, JP nn = C3 + 3-byte addr
- JR e = 18 + signed offset, JR Z = 28, JR NZ = 20, JR C = 38, JR NC = 30
- RET = C9, RET Z = C8, RET NZ = C0, RET C = D8, RET NC = D0
- PUSH AF = F5, POP AF = F1
- LD A,(nn) = 3A + 3-byte addr (ADL mode), LD (nn),A = 32 + 3-byte addr
- LD A,n = 3E + byte
- CP n = FE + byte, AND n = E6 + byte, OR n = F6 + byte, XOR A = AF
- CPL = 2F

### Template
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function readROM(addr, len) {
  return Array.from(rom.slice(addr, addr + len));
}

function hex(b) { return b.toString(16).padStart(2, '0'); }
function hex6(a) { return '0x' + a.toString(16).padStart(6, '0'); }
function addr24(bytes, off) { return bytes[off] | (bytes[off+1] << 8) | (bytes[off+2] << 16); }

// Read main function
const mainBytes = readROM(0x0685DF, 60);
console.log('=== 0x0685DF ROM bytes (60) ===');
for (let i = 0; i < mainBytes.length; i += 16) {
  const chunk = mainBytes.slice(i, i + 16);
  console.log(hex6(0x0685DF + i) + ': ' + chunk.map(hex).join(' '));
}

// Read calling context
const callerBytes = readROM(0x07FD24, 24);
console.log('\n=== 0x07FD24 calling context (24 bytes) ===');
console.log(callerBytes.map(hex).join(' '));

// Find CALL/JP/JR targets
const targets = [];
for (let pc = 0; pc < mainBytes.length; pc++) {
  const op = mainBytes[pc];
  if (op === 0xCD || op === 0xC3) {
    if (pc + 3 < mainBytes.length) {
      const target = addr24(mainBytes, pc + 1);
      targets.push({ from: 0x0685DF + pc, target, type: op === 0xCD ? 'CALL' : 'JP' });
      pc += 3;
    }
  } else if ([0x18, 0x20, 0x28, 0x30, 0x38].includes(op)) {
    const offset = mainBytes[pc + 1];
    const signed = offset > 127 ? offset - 256 : offset;
    const target = 0x0685DF + pc + 2 + signed;
    targets.push({ from: 0x0685DF + pc, target, type: 'JR' });
    pc += 1;
  } else if (op === 0xC9) {
    console.log(`\nRET found at ${hex6(0x0685DF + pc)}`);
    break;
  }
}

console.log('\n=== CALL/JP/JR targets ===');
for (const t of targets) {
  console.log(`${hex6(t.from)}: ${t.type} → ${hex6(t.target)}`);
}

// Read sub-targets
const uniqueTargets = [...new Set(targets.map(t => t.target))];
for (const t of uniqueTargets) {
  if (t >= 0 && t < rom.length) {
    const bytes = readROM(t, 24);
    console.log(`\n=== ${hex6(t)} (24 bytes) ===`);
    console.log(bytes.map(hex).join(' '));
  }
}
```
