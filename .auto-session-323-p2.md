# Task: Register LCD SPI Panel Ports 0x31xx in peripherals.js

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The file `TI-84_Plus_CE/peripherals.js` contains port I/O handlers for the eZ80 CPU. Session 322 mapped 14 LCD SPI panel wrapper functions in `TI-84_Plus_CE/phase322-lcd-port-wrappers-report.md`. These access ports in the 0x31xx range for LCD SPI panel configuration. Currently NONE of these ports are registered — reads return the default 0x00 and writes are silently dropped.

## What to do
Edit `TI-84_Plus_CE/peripherals.js` to add LCD SPI panel port handlers.

### Ports to register (from phase322-lcd-port-wrappers-report.md):

**Port bank 0x3160** — Panel config registers (4 panels × 4-byte stride):
- 0x3161, 0x3165, 0x3169, 0x316D — R/W, 8-bit each. Used via read-modify-write with CB-prefix bit ops (bits 3, 4, 7). Default 0x00.

**Port bank 0x3180** — Panel config registers (4 panels × 4-byte stride):
- 0x3181, 0x3185, 0x3189, 0x318D — R/W, 8-bit each. Used via read-modify-write with CB-prefix bit ops (bits 3, 4). Default 0x00.

**Port bank 0x31A8** — Panel write registers:
- 0x31A8, 0x31A9, 0x31AA, 0x31AB — Write-only (no read wrapper found). Default 0x00.

### Implementation
Create a state object:
```javascript
const lcdSpiState = {
  panel3160: [0, 0, 0, 0],  // indices 0-3 for ports 0x3161/3165/3169/316D
  panel3180: [0, 0, 0, 0],  // indices 0-3 for ports 0x3181/3185/3189/318D  
  panelWrite: [0, 0, 0, 0], // indices 0-3 for ports 0x31A8-0x31AB
};
```

Register 3 separate handlers (one per bank) since the ports are not contiguous:

1. `register({ start: 0x3161, end: 0x316D }, ...)` — map port to panel index via `Math.floor((port - 0x3161) / 4)`, only handle ports where `(port - 0x3161) % 4 === 0`. Read returns stored value, write stores value.

2. `register({ start: 0x3181, end: 0x318D }, ...)` — same pattern.

3. `register({ start: 0x31A8, end: 0x31AB }, ...)` — write stores value, read returns stored value.

For ports in the range that don't match the stride pattern, return 0x00 on read and drop writes.

### Where to place it
Insert after the LCD DMA controller block (or after the existing `register(0x8040, ...)` if the DMA block hasn't been added yet). Before the interrupt controller block.
