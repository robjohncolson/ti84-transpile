# Task: Decode ROM function at 0x0017CE

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by reading raw bytes and disassembling eZ80 instructions.

## What to Decode
Function at address **0x0017CE** in the ROM. This function is called from the OS event handler when the D02658 countdown reaches zero:

From the event handler at 0x001794:
- 0x001783: EI → HALT → wait for timer ISR → check D02658 countdown
- When D02658 reaches zero (Z flag set), 0x001783 returns Z
- JR NZ 0x00179A loops back if still counting
- When NZ fails (countdown done), falls through to CALL 0x0017CE

So 0x0017CE is called AFTER the timer delay completes. It's the actual processing function that runs after the event handler has waited for the timer countdown. Understanding this function tells us what the event handler actually DOES after waiting.

The event handler cleanup after 0x0017CE:
```
CALL 0x0017CE
DJNZ 0x001796 (loop 248 times)
// cleanup:
LD (D00595),0x000000
JP 0x003A0F
```

## How to Decode
1. Read ROM bytes starting at offset 0x0017CE in `TI-84_Plus_CE/ROM.rom`
2. Read 128-256 bytes to capture the function
3. Disassemble the eZ80 instructions

Create a probe file `TI-84_Plus_CE/probe-phase465-decode-0017ce.mjs` that:
1. Loads the ROM file
2. Reads bytes at offset 0x0017CE (read ~256 bytes)
3. Prints them as hex dump
4. Uses the eZ80 decoder (`ez80-decoder.js`) to disassemble
5. Prints the disassembly with addresses

Also decode 0x003A0F (the event handler cleanup JP target, read ~128 bytes) — what function is at this address? Is it the OS event dispatch main loop or an error handler?

Example pattern:
```js
import { readFileSync } from 'fs';
import { decode } from './ez80-decoder.js';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function disassemble(startAddr, maxLen, label) {
    console.log(`\n=== ${label}: 0x${startAddr.toString(16).padStart(6, '0')} ===\n`);
    
    // Hex dump
    let hexLine = '';
    for (let i = 0; i < maxLen; i++) {
        if (i % 16 === 0) {
            if (hexLine) console.log(hexLine);
            hexLine = `0x${(startAddr + i).toString(16).padStart(6, '0')}: `;
        }
        hexLine += rom[startAddr + i].toString(16).padStart(2, '0') + ' ';
    }
    if (hexLine) console.log(hexLine);
    
    // Disassemble
    console.log('\n--- Disassembly ---');
    let offset = 0;
    let retCount = 0;
    while (offset < maxLen) {
        const addr = startAddr + offset;
        try {
            const instr = decode(rom, addr);
            if (!instr || instr.length === 0) {
                console.log(`0x${addr.toString(16).padStart(6, '0')}: DB 0x${rom[addr].toString(16).padStart(2, '0')}`);
                offset++;
            } else {
                const bytes = Array.from(rom.slice(addr, addr + instr.length)).map(b => b.toString(16).padStart(2, '0')).join(' ');
                console.log(`0x${addr.toString(16).padStart(6, '0')}: ${bytes.padEnd(20)} ${instr.mnemonic} ${instr.operands || ''}`);
                offset += instr.length;
                if (instr.mnemonic === 'RET' || instr.mnemonic === 'RETI' || instr.mnemonic === 'RETN') {
                    retCount++;
                    if (retCount >= 2) break;
                }
            }
        } catch (e) {
            console.log(`0x${addr.toString(16).padStart(6, '0')}: DB 0x${rom[addr].toString(16).padStart(2, '0')} (decode error)`);
            offset++;
        }
    }
}

disassemble(0x0017CE, 256, 'Event handler post-countdown processor');
disassemble(0x003A0F, 128, 'Event handler cleanup JP target');
```
