## How to decode ROM bytes

```javascript
import fs from 'fs';
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
// Read bytes at address 0x055B8F:
const start = 0x055B8F;
const bytes = rom.slice(start, start + 128);
console.log('Hex:', Buffer.from(bytes).toString('hex'));
// Then decode manually or use ez80-decoder.js
```

eZ80 ADL mode: 24-bit addresses, 24-bit registers by default. Common patterns:
- `CD xx xx xx` = CALL addr24
- `C3 xx xx xx` = JP addr24
- `C9` = RET
- `DD/FD` prefixes for IX/IY
- `ED` prefix for extended ops (LDIR, etc.)
