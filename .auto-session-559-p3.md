# Task: Decode 0x05519F — The Actual BPP Init Body

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80). We're decoding OS functions in the BPP (bits-per-pixel) cluster.

**Call chain**: 12 callers in BPP cluster → 0x055191 (conditional gate: tests D000C6 bit 1, CALL Z 0x05519F) → **0x05519F** (THIS TARGET — the actual init body).

0x055191 was decoded in session 558 as a 14-byte thin gate that only calls 0x05519F when D000C6 bit 1 is clear. The actual initialization logic is at 0x05519F.

## Known architecture
- D000C6 = BPP-related flags (bit 2 = BPP mode, bit 1 = gate flag for 0x055191)
- BPP cluster spans 0x052Axx-0x0554xx (11KB, ~56 fns)
- 0x055228 = switch to 8bpp (A=0x2D)
- 0x055261 = switch to 16bpp (A=0x27, + 512B palette copy from ROM 0x055777→E30200)
- 0x055280 = LCD register setup (27B: E30018=control, SET 2 E30028, E30010=D40000 VRAM base)
- E30200 = LCD palette registers
- D40000 = VRAM base
- D52C00 = secondary framebuffer (8bpp page-flip target)
- IY base = D00080

## Deliverable
Create `TI-84_Plus_CE/probe-phase559-decode-05519F.mjs` that:
1. Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
2. Disassembles starting at 0x05519F for up to 200 bytes (or until RET found)
3. Documents each instruction with comments
4. Identifies: what LCD registers it configures, what VRAM addresses it initializes, whether it sets BPP mode, what flags it writes
5. Prints a structured summary
