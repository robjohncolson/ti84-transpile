# Task: Decode ROM function at 0x07FEB6

## Context
You are reverse-engineering the TI-84 Plus CE OS ROM (eZ80 machine code). This function is called in path D of 0x09A39F (symbol address resolver, decoded in session 589). The path D sequence is: `PUSH AF → CALL 0x07FEB6 → POP AF → CALL 0x09A3A5 (self re-entry) → EX DE,HL → JP 0x07FA0D`. So 0x07FEB6 is a setup/helper called before the resolver re-enters itself.

Related context:
- 0x09A39F is a multi-path symbol address resolver (~46B, decoded session 589)
- Path D is the alternate path entered when bit 6 of (IY+9) IS set but type != 0x5C
- 0x07FA0D is the tail-call destination after self-re-entry
