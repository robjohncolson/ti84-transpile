- Each char: 96 VRAM bytes changed, 161-164 steps
- Text grid: 10 rows (0-9) × 26 columns (0-25)
- D00595 = cursor row, D00596 = cursor column
- D0059C = computed VRAM pointer (3 bytes)
- VRAM formula: `addr = 0xD40000 + (row*20+37)*640 + (col*12+2)*2`
- Row height = 20 pixel rows, each pixel row = 640 bytes (16bpp, 320px wide)
- Expected VRAM distance between text rows: 20 * 640 = 12800 bytes (0x3200)
- D00596 wraps at 26 (0x1A), D00595 wraps at 10 (0x0A)
