# Task: DECODE 0x06F56F FONT PARAM WRITER — the function that writes D02A65/D02A68

## Context

Session 573 confirmed D02A65/D02A68 are font parameter blocks (3 bytes each) that are RUNTIME-ONLY — both 0x000000 at boot, written only during active glyph rendering. The 4 ROM references are:
- 0x06F56F = LD (D02A65),A (write)
- 0x06F58C = LD DE,D02A65 (load address for block copy)
- 0x06F59C = LD DE,D02A68 (load address for block copy)
- 0x09F238 = LD A,(D02A68) (read by graph plotter)

The function at 0x06F56F is inside a larger routine at 0x06F5xx that sets up font parameters before rendering. We need to decode the full function containing 0x06F56F to understand what font metrics it writes and how.

## Deliverable

Create a probe at `TI-84_Plus_CE/probe-phase574-decode-06F56F.mjs` that:

1. Boots the TI-84 CPU to idle (copy boot pattern from `probe-phase99d-home-verify.mjs` exactly)
2. Disassembles ROM starting BEFORE 0x06F56F to find the function entry point. Strategy:
   - Scan backwards from 0x06F56F looking for a RET/JP unconditional that would end the previous function. Start scanning from 0x06F540.
   - The function entry is likely the first instruction after that RET/JP.
3. Disassemble forward from the entry point through 0x06F5A0+ until hitting RET or ~128 bytes
4. For disassembly use: `import { decodeInstruction } from './ez80-decoder.js'` — `decodeInstruction(cpu, address)` returns `{mnemonic, operands, length}`
5. Print each instruction: address, hex bytes, mnemonic+operands
6. Identify:
   - All RAM addresses read/written (especially D02A65, D02A68, and any others in D02Axx range)
   - All CALL/JP targets
   - The LDIR operations (block copies between D02A65↔D02A68)
   - What values get written to D02A65 (the LD (D02A65),A at 0x06F56F — what's in A?)
7. Find callers of this function: scan ROM for CALL bytes targeting the entry point address

## Boot pattern (copy from golden regression)

```javascript
import { createCPU } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const rom = fs.readFileSync(path.join(__dirname, 'ROM.rom'));
const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(rom, peripherals);

let steps = 0;
while (steps < 500000) {
    cpu.step();
    steps++;
    if (cpu.halted) break;
}
```

Then use `decodeInstruction(cpu, addr)` to disassemble.
