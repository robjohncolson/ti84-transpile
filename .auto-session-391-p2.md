# Task: Disassemble 0x00596E (Font Base Address Loader)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian). The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js`.

Session 390 discovered the character renderer at 0x005A75 calls 0x00596E to get the font bitmap base address in HL. The font table is at 0x004000 in ROM (28 bytes/glyph, 14×16 1bpp). We need to know: does 0x00596E always return 0x004000, or does it select from multiple font tables?

## Deliverables

Write a probe file `TI-84_Plus_CE/probe-phase391-disasm-00596E.mjs` that:

1. **Statically disassembles 0x00596E** using the eZ80 decoder. Decode instructions starting at 0x00596E until you hit a RET (0xC9) or have decoded 100 instructions. Print each instruction with address, hex bytes, and mnemonic.

2. **Identify all LD HL,imm24 instructions** — these load a 24-bit immediate into HL (opcode 0x21 in ADL mode = 4 bytes: 21 LL MM HH). If 0x004000 appears as an immediate, that's the font table pointer.

3. **Check for conditional branches** — does the function test any flag/RAM and select different font tables? Or does it unconditionally return 0x004000?

4. **Find all callers** — scan ROM for `CALL 0x00596E` (CD 6E 59 00) and `JP 0x00596E` (C3 6E 59 00). Report addresses.

## How to use the decoder
```javascript
import { createDecoder } from './TI-84_Plus_CE/ez80-decoder.js';
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
const decoder = createDecoder(rom);

let pc = 0x00596E;
for (let i = 0; i < 100; i++) {
  const instr = decoder.decode(pc);
  console.log(`0x${pc.toString(16).padStart(6,'0')}: ${instr.mnemonic}  (${instr.length} bytes)`);
  if (instr.mnemonic === 'RET' || instr.mnemonic === 'RETI' || instr.mnemonic === 'RETN') break;
  pc += instr.length;
}
```

Note: the decoder is in `TI-84_Plus_CE/ez80-decoder.js`. Import it with the path relative to repo root OR use dynamic import. Check the actual export name — it may be `decode` or `createDecoder` or a default export. Read the first ~50 lines of `ez80-decoder.js` to find the export.
