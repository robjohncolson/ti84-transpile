# Task: Trace 0x030074 Full Context — Find Callers and Disassemble Parent Function

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`. Session 391 discovered that address 0x030074 is the 2ND-key translation path: it does `ADD A,0x38; LD D,0x00; JP 0x02FF0B`. This offsets into the translation table's 2ND section before jumping to the GetCSC lookup routine.

## What to do
1. Write a Node.js probe at `TI-84_Plus_CE/probe-phase392-trace-030074.mjs` that:
   - Reads `TI-84_Plus_CE/ROM.rom` (4MB binary, `fs.readFileSync`)
   - Performs static disassembly around 0x030074 to find the containing function's boundaries (search backward for a RET/RETI/RETN instruction or a known function prologue, search forward for the end)
   - Searches the ENTIRE ROM (0x000000-0x3FFFFF) for all CALL/JP instructions targeting addresses in the range 0x030060-0x030080 (to find callers of the function containing 0x030074)
   - Also searches for 3-byte little-endian address patterns `74 00 03` that could be indirect references
   - Prints: (a) full disassembly of the function containing 0x030074, (b) all callers found, (c) any indirect references

2. For the disassembly, decode eZ80 instructions manually:
   - `C3 xx xx xx` = JP addr (3-byte addr in ADL mode)
   - `CD xx xx xx` = CALL addr (3-byte addr in ADL mode)  
   - `C9` = RET
   - `C0-C8,D0,D8,E0,E8,F0,F8` = conditional RET variants
   - `ED 4D` = RETI, `ED 45` = RETN
   - `CB xx` = bit operations (2 bytes)
   - `DD/FD xx` = IX/IY prefix (varies)
   - `ED xx` = extended instructions
   - `18 xx` = JR offset (2 bytes)
   - `20/28/30/38 xx` = conditional JR (2 bytes)
   - `C6 xx` = ADD A,imm8
   - `FE xx` = CP imm8
   - For simplicity, just identify CALL, JP, JR, RET instructions and print hex for others

3. Run the probe with `node` and print results
