# Task: Identify 0x0003F0/0x0003EC Display Functions (159 Callers)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

In session 312, we mapped the ZDS II C runtime vector table. Two unnamed high-traffic entries stand out:
- Vector at 0x0003F0 → target 0x015349 (85 callers) — "display/cursor setup 6-arg"
- Vector at 0x0003EC → target 0x0152D8 (74 callers) — "display/cursor 3-arg"

These write to RAM addresses 0xD17700-0xD17721 (display/cursor state area). The 3-arg version at 0x0003EC likely calls into or shares code with the 6-arg version at 0x0003F0.

## Task
1. **Disassemble the 3-arg function at 0x0152D8** (likely 30-80 bytes). Determine:
   - What are the 3 arguments? (registers? stack?)
   - Which RAM addresses does it write? (expect D17700-D17721 range)
   - What display state does it set? (cursor position? window bounds? text region?)
   - Does it call 0x015349 (the 6-arg version)?

2. **Disassemble the 6-arg function at 0x015349** (likely 50-120 bytes). Determine:
   - What are the 6 arguments?
   - Full list of RAM writes in D17700-D17721
   - What each RAM byte represents (row, column, window top, window bottom, etc.)

3. **Map the D17700-D17721 RAM region**:
   - Search the ROM for all references to addresses 0xD17700 through 0xD17721
   - Group by address: which bytes are most referenced?
   - Cross-reference with known display routines (LCD refresh at 0x06868A, text output)
   - Determine: is this a cursor state block? A text window descriptor? A viewport?

4. **Check 3-5 callers** of each function. What context do they call from? (menu setup? graph rendering? editor initialization?)

5. **Write a probe** at `TI-84_Plus_CE/probe-phase313-display-functions.mjs` that:
   - Disassembles both functions
   - Maps all D17700-D17721 references in the ROM
   - Identifies argument passing convention
   - Lists top callers with context

6. **Write a report** at `TI-84_Plus_CE/phase313-display-functions-report.md`.

## Key Files

## Success Criteria

- D17700-D17721 RAM map produced (byte-by-byte purpose)
- Relationship between 3-arg and 6-arg versions clarified
- At least 3 callers of each function traced for context
