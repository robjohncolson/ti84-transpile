# Auto-Session 269 P1: Disassemble Event Loop Polling Condition

## Context
The TI-84 CE OS event loop has been traced to a tight 5-block polling loop:
0x082BE2 → 0x084716 → 0x08471B → 0x084723 → 0x084711 → back to 0x082BE2

This loop runs ~2000 iterations in 10000 steps with NO exit in 50000 steps. It polls some condition that's never satisfied without ISR/key input.

Session 268's probe `probe-phase268-0582BC-deep-trace.mjs` traced this loop but didn't disassemble the **exit condition**.

## Task
Create a probe `TI-84_Plus_CE/probe-phase269-event-loop-exit-condition.mjs` that:

1. Reads ROM.rom directly (like other probes) and statically disassembles the 5 polling blocks:
   - 0x082BE2
   - 0x084716
   - 0x08471B
   - 0x084723
   - 0x084711
   Show every instruction (mnemonic + operands) for each block.

2. Identify the conditional branch that would EXIT the loop — what comparison/test/bit instruction gates the exit?

3. Identify what RAM address(es) are read in the loop condition. These are the trigger addresses — changing them should break the loop.

4. Run a dynamic test:
   - Full boot (cold_boot 20 steps, kernel_init 2000, mem_init 500000 with timerInterrupt:false)
   - Seed D007E8=0x06C546 (the fix from session 268)
   - Call 0x062055 with B=3, D0230F=0x3F (the known-good path to event loop)
   - Run 1000 steps
   - Read the RAM address(es) identified in step 3 to show their current value
   - Report: what value would need to change to break the loop?
