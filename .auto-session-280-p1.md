# Auto-Session 280 P1: Investigate D02AD7-D02AD9 Consumers

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM (eZ80) has been lifted to JavaScript. You need to investigate who READS the RAM addresses D02AD7-D02AD9 after FindSym (0x0846EA) stores data there via CALL 0x04C885.

**Background from session 279**: FindSym at 0x0846EA is the most-called function in the ROM (233 CALL + 2 JP sites). It looks up variables in the VAT (Variable Allocation Table). On match, it calls 0x04C885 which stores the variable data pointer. D005F8 stores the variable type byte. The question is: what do callers DO with the data pointer stored at D02AD7?

**0x04C885** (from session 278): Confirmed as a 24-bit pointer store — writes DE to (D02AD7) as a 3-byte value. 10 callers total.

## Task
Write a probe at `TI-84_Plus_CE/probe-phase280-d02ad7-consumers.mjs` that:

1. Searches the ROM binary for ALL references to addresses D02AD7, D02AD8, D02AD9 (read sites — LD from these addresses)
2. For each reference found, decode the instruction context (what opcode loads from D02AD7?)
3. Classify each consumer: is it a LD A,(D02AD7)? LD HL,(D02AD7)? LD DE,(D02AD7)?
4. Count total readers vs writers
5. For the top 3-5 most interesting readers (non-trivial, in different ROM regions), do a short dynamic trace (100-200 steps) to see what they do with the loaded value
