# Task: Find Who Writes D008D2/D008D5 (VRAM Address Registers)

## Context
In the TI-84 Plus CE OS ROM transpilation project, we've mapped the putchar pipeline:
- 0x061434 (mode gate) → 0x06002D (flag setter: SET 1,(IY+2)) → 0x0A23E5 (pixel renderer)
- The pixel renderer at 0x0A23E5 reads PRE-COMPUTED VRAM addresses from RAM at D008D2 (LCD window base) and D008D5 (LCD window high)
- 0x06002D was previously thought to compute these addresses but is actually just `SET 1,(IY+2); RET`
- The cursor position is stored at D00595 (row) and D00596 (column, stored at D02505 too)
- SOMEONE converts cursor row/col → VRAM pixel address and stores it at D008D2/D008D5 BEFORE putchar runs
- Finding this function completes the full rendering pipeline

## Task
Create and run a probe that searches the entire 4MB ROM (0x000000-0x3FFFFF) for all instructions that WRITE to addresses D008D2 and D008D5. 

### Search patterns (eZ80 little-endian):
For stores to D008D2:
- `32 D2 08 D0` = LD (0xD008D2),A
- `22 D2 08 D0` = LD (0xD008D2),HL
- `ED 63 D2 08 D0` = LD (0xD008D2),HL (alternate encoding)

For stores to D008D5:
- `32 D5 08 D0` = LD (0xD008D5),A
- `22 D5 08 D0` = LD (0xD008D5),HL
- `ED 63 D5 08 D0` = LD (0xD008D5),HL (alternate encoding)

Also search for nearby addresses D008D3, D008D4, D008D6 since the store might target the base and write multiple bytes:
- `22 D2 08 D0` would store HL to D008D2 (covering D008D2-D008D4)

### Deliverables
1. Create `TI-84_Plus_CE/probe-phase498-find-d008d2-writers.mjs`
2. Run it via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase498-find-d008d2-writers.mjs`
3. For each match found, report:
   - ROM address of the instruction
   - The full instruction (decoded if possible)
   - Surrounding context (what function it's in — check for nearby CALL/RET/JP patterns)
   - Whether it also references D00595/D00596 (cursor row/col) nearby (within ±100 bytes)

### Implementation approach
- Load the ROM file from `TI-84_Plus_CE/ROM.rom` (4MB binary)
- Do a byte-pattern search across the entire ROM
- For each match, scan ±200 bytes for references to D00595 (`95 05 D0`) and D00596 (`96 05 D0`)
- Group matches by proximity (within 256 bytes = same function)
- Report all groups sorted by number of cursor-position references (most relevant first)
