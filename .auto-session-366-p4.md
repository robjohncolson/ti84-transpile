# Auto-Session 366 — P4: Extend Boot to 50,000 Steps

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS ROM is lifted to JavaScript and executed block-by-block. With the SP clamp (in cpu-runtime.js) and current seeds, boot reaches 539 unique blocks in 10,000 steps. The last PC at 10,000 steps is 0x003D31.

## Task
Create a probe script `TI-84_Plus_CE/probe-phase366-boot-50k.mjs` that runs the OS boot for 50,000 steps and reports:

1. **Total unique blocks visited** (compared to the 539 baseline at 10k steps)
2. **New blocks discovered** (addresses not seen in the first 10,000 steps)
3. **The last PC at 50,000 steps**
4. **Any blocks that failed (missing from transpiled output)**
5. **A timeline**: blocks visited at 10k, 20k, 30k, 40k, 50k steps — is the boot still making progress or has it entered a loop?
6. **Top 10 most-visited blocks** — to identify hot loops

## How to write the probe
Use this proven boot-probe pattern:

```javascript
import { readFileSync } from 'fs';
import { gunzipSync } from 'zlib';

const compressedJs = readFileSync('TI-84_Plus_CE/ROM.transpiled.js.gz');
const transpiledJs = gunzipSync(compressedJs).toString('utf-8');

const { createCPU } = await import('./TI-84_Plus_CE/cpu-runtime.js');
const { createPeripheralBus } = await import('./TI-84_Plus_CE/peripherals.js');

const peripherals = createPeripheralBus({ timerInterrupt: false, trace: false });
const cpu = createCPU(peripherals);

// Load ROM
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
for (let i = 0; i < rom.length; i++) {
  cpu.mem[i] = rom[i];
}

// Load transpiled blocks
const blockFn = new Function('cpu', 'mem', 'peripherals', transpiledJs + '\nreturn blocks;');
const blocks = blockFn(cpu, cpu.mem, peripherals);

// Seed RAM with known required values
// (copy seed pattern from existing probes like probe-phase99d-home-verify.mjs)

// Run boot
const MAX_STEPS = 50000;
const visited = new Set();
const visitCount = new Map();
const missingBlocks = new Set();
const milestones = [10000, 20000, 30000, 40000, 50000];
let milestoneIdx = 0;
let lastPc = 0;

cpu.pc = 0x000000; // Boot vector
cpu.adl = 1;

for (let step = 0; step < MAX_STEPS; step++) {
  const pc = cpu.pc;
  lastPc = pc;
  visited.add(pc);
  visitCount.set(pc, (visitCount.get(pc) || 0) + 1);

  if (milestoneIdx < milestones.length && step + 1 === milestones[milestoneIdx]) {
    console.log(`  ${milestones[milestoneIdx]} steps: ${visited.size} unique blocks, PC=0x${pc.toString(16).padStart(6, '0')}`);
    milestoneIdx++;
  }

  const block = blocks[pc];
  if (!block) {
    missingBlocks.add(pc);
    break; // or skip — depends on how cpu.runFrom handles missing blocks
  }

  // Execute block using cpu.runFrom for 1 step
  // Actually, use the cpu.runFrom method with max_steps=1
}
```
