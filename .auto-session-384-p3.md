# Task: Investigate what reads kbdKey (0xD0058C) in the ROM

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code). The transpiler is at `scripts/transpile-ti84-rom.mjs`.

Session 382 noted that 19 ROM locations read kbdKey at address 0xD0058C. The translation table at 0x03010D is supposed to populate kbdKey, but session 383 confirmed the translation is NEVER REACHED during normal key dispatch. So these 19 consumers always see 0x00. Understanding what reads 0xD0058C reveals what OS functionality is blocked by the missing translation.

## What to do

Write a Node.js probe script at `TI-84_Plus_CE/probe-phase384-kbdKey-readers.mjs` that:

1. Reads the raw ROM at `TI-84_Plus_CE/ROM.rom` (4,194,304 bytes)
2. Scans for all instructions that reference address 0xD0058C in the ROM:
   - **LD A,(0xD0058C)**: opcode `3A 8C 05 D0` (ADL mode, little-endian)
   - **LD r,(0xD0058C)** for other registers: various opcodes followed by `8C 05 D0`
   - **LD (0xD0058C),A**: opcode `32 8C 05 D0`
   - **LD (0xD0058C),r**: various opcodes followed by `8C 05 D0`
   - Also search for the raw 3-byte address pattern `8C 05 D0` anywhere (catches indirect references, table entries)

3. For each match, report:
   - ROM offset
   - Instruction bytes (4-8 bytes for context)
   - Whether it's a READ or WRITE
   - Instruction mnemonic (best effort decode)

4. Also search for nearby addresses that may be part of the same keyboard state block:
   - 0xD00587 (scan code)
   - 0xD00588 (last key)
   - 0xD00589 (previous key)
   - 0xD0058A (repeat counter)
   - 0xD0058B (debounce counter)
   - 0xD0058C (kbdKey — the translated key code)
   - 0xD0058D, 0xD0058E, 0xD0058F (adjacent state)

   Report a summary count for each address.

5. For the top 5 most interesting 0xD0058C readers (those that appear to be in distinct functions), disassemble 16 bytes before and after each reference to show the surrounding code context.

6. Run the script and capture results.

## eZ80 encoding reference
- Little-endian 24-bit addresses
- LD A,(nn) = 3A xx xx xx
- LD (nn),A = 32 xx xx xx
- LD HL,(nn) = ED 6B xx xx xx (ADL) or 2A xx xx xx
- CP (nn) — not a direct eZ80 instruction, would need indirection
