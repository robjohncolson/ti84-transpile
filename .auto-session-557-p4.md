# Task: Decode 0x05AD22-0x05ADE2 Display Module (7 callers of cursor Y conversion)

## Context
This is the TI-84 Plus CE ROM transpilation project. We disassemble eZ80 machine code from `TI-84_Plus_CE/ROM.rom` (4MB).

Session 556 decoded **0x06CBE5** (cursor Y conversion, ~100B). It has 9 callers total, with 7 concentrated in the range **0x05AD22-0x05ADE2** (~192 bytes). This is likely a menu or dialog rendering module. We need to understand what this module does.

## What To Do

1. Create a probe script `TI-84_Plus_CE/probe-phase557-display-module.mjs` that:
   - Loads the ROM from `TI-84_Plus_CE/ROM.rom`
   - Scans the region 0x05AD00-0x05AE00 (256 bytes, padded) for structure:
     - Find all CALL instructions and their targets
     - Find all RET instructions (function boundaries)
     - Find all JR/JP instructions (internal flow)
     - Find all RAM address references (LD to/from D0xxxx)
     - Find all IY-relative operations
   - Determines: is this one large function (192B) or multiple smaller functions?
   - For each CALL target, note whether it's to known functions:
     - 0x06CBE5 = cursor Y conversion
     - 0x04C979 = character width clipping
     - 0x0A23E5 = character renderer
     - 0x061986 = character output wrapper
     - 0x0A1CAC = text output/string rendering

2. Output:
   - Function boundaries within 0x05AD00-0x05AE00
   - All CALL targets (with labels for known functions)
   - RAM addresses accessed
   - The 7 specific CALL 0x06CBE5 locations and what C register value each sets before calling (C = row offset in the Y conversion formula)
   - Assessment: is this menu rendering, dialog layout, status bar drawing, or something else?

## Technical Reference

- ROM file: `TI-84_Plus_CE/ROM.rom` (4,194,304 bytes, flat binary)
- eZ80 Z80-compatible, 24-bit addressing
- 0x06CBE5 cursor Y conversion: formula render_Y = (D014FE - 1 - C) + 0x2F, stores to D008D5
- D008D5 = renderer Y coordinate (265 refs)
- D014FE = cursor Y position
- Key opcodes: CD=CALL, C9=RET, C3=JP, 18=JR, 0E xx=LD C,imm8
