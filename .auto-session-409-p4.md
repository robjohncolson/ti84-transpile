# Task: Add 20 new transpiler seeds for coverage push

## Context

The TI-84 Plus CE ROM transpiler at `scripts/transpile-ti84-rom.mjs` lifts eZ80 machine code from `TI-84_Plus_CE/ROM.rom` into JavaScript. It starts from "seed" addresses and follows control flow to discover reachable blocks.

Current stats: 145,103 blocks, 709,500 covered bytes, 36,045 uncovered bytes.

## Your task

1. Run the coverage analyzer to find gaps:
   ```
   node TI-84_Plus_CE/audit-true-uncovered.mjs
   ```

2. From the output, find 20 uncovered ranges that are likely CODE (verdict "CODE?" or ranges starting with common eZ80 instruction opcodes). Avoid ranges marked "STRINGS", "DATA-SPARSE", or "DATA-MIXED" — those are data, not code.

3. For each candidate, verify it looks like code by checking the first few bytes against common eZ80 instruction patterns:
   - `C3` (JP), `CD` (CALL), `3E` (LD A,n), `21` (LD HL,nn), `ED` (extended), `CB` (bit ops)
   - `F5` (PUSH AF), `C5` (PUSH BC), `D5` (PUSH DE), `E5` (PUSH HL)
   - `C9` (RET), `AF` (XOR A), `B7` (OR A)
   - Avoid sequences of printable ASCII (0x20-0x7E) — those are strings

4. Add the 20 new seed addresses to `scripts/transpile-ti84-rom.mjs` in the `manualSeeds` array (or equivalent seed array). Each seed should be a hex number like `0x0XXXXX`.

5. Run the transpiler to verify the seeds work:
   ```
   node scripts/transpile-ti84-rom.mjs
   ```

6. Run the golden regression to make sure nothing broke:
   ```
   node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
   ```

7. Report the before/after block count and byte count.

## How to find the seed array

In `scripts/transpile-ti84-rom.mjs`, search for existing seed addresses (hex numbers like `0x0XXXXX` in an array). Recent sessions added seeds to a `manualSeeds` or similar array. Add your 20 seeds to the SAME array, appending at the end.

## Constraints
- ONLY modify `scripts/transpile-ti84-rom.mjs` (to add seeds)
- Do NOT modify any probe files, cpu-runtime.js, peripherals.js, browser-shell.html, or any other file
- Do NOT remove or change existing seeds
- The transpiler must still produce valid output after your changes
- Golden regression (`probe-phase99d-home-verify.mjs`) must still pass

## Success criteria
- 20 new seeds added to the transpiler
- Transpiler runs successfully with new seeds
- Golden regression passes (26/26 cells, "Normal Float Radian")
- Net positive block/byte gain reported
