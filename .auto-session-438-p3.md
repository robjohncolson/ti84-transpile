# Task: Map Port 0x3082 Complete Bit Assignments

## Context
This is part of the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

Port 0x3082 is a USB controller status/configuration register referenced throughout the USB code. Known bits from prior sessions:
- Bits 7:6 — USB speed/mode (2-bit value stored to D141E6, session 429)
- Bit 4 — device-connected status (mirrored to D14073 dynamically, session 437)
- Bit 3 — referenced by 0x008527 (session 432, triggers OTG transition via 0x012456)
- Bit 1 — checked by 0x0125EA and 0x01253F (port-ready gates, session 433)

Session 437 completed a full bitfield map for port 0x3080 (8 bits, 106 I/O sites). Now do the same for port 0x3082.

## Task
Write a probe script at `TI-84_Plus_CE/probe-phase438-map-port3082.mjs` AND a report at `TI-84_Plus_CE/phase438-port3082-report.md`.

The probe must:
1. Open `TI-84_Plus_CE/ROM.rom` (raw binary, 4,194,304 bytes)
2. Find ALL I/O operations on port 0x3082:
   - eZ80 port I/O uses `IN A,(C)` / `OUT (C),A` with BC holding the port address
   - Port 0x3082 in little-endian for LD BC,imm24: 0x82 0x30 0x00 (port addresses are 16-bit but loaded into 24-bit BC)
   - Look for: LD BC,0x003082 (opcode: 0x01 0x82 0x30 0x00) followed by IN/OUT within ~20 bytes
   - Also: LD C,0x82 + LD B,0x30 sequences, or BC already holding nearby port and adjusted
3. For each I/O site found:
   - Determine if it's a READ (IN) or WRITE (OUT)
   - For reads: what bit(s) are tested after the IN? (look for BIT, AND, RRA/RLCA shifts, CP)
   - For writes: what bit manipulation precedes the OUT? (SET, RES, OR, AND masks)
   - The containing function address
4. Build a complete bitfield map showing what each bit (0-7) is used for

## eZ80 I/O instruction reference
- `IN A,(C)` = 0xED 0x78 (reads port in BC into A)
- `OUT (C),A` = 0xED 0x79 (writes A to port in BC)  
- `IN r,(C)` for other registers: 0xED 0x40/0x48/0x50/0x58/0x60/0x68/0x78
- `OUT (C),r`: 0xED 0x41/0x49/0x51/0x59/0x61/0x69/0x79

The port address 0x3082 will be loaded into BC before the IN/OUT. Common patterns:
- `LD BC,0x003082` then `IN A,(C)` — direct port read
- `LD BC,0x003080` then `INC C; INC C` to reach 0x3082 — sequential port access
