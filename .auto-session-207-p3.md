### 1. χ²cdf (chi-square CDF)
- Token: `[0xBB, 0x06]` (tChi2cdf)
- Syntax: `χ²cdf(lowerBound, upperBound, df)`
- Implementation: Use the regularized incomplete gamma function. χ²cdf(a,b,df) = P(b/2, df/2) - P(a/2, df/2) where P is the regularized lower incomplete gamma function.
- Algorithm for regularized gamma P(x,a): Use series expansion for x < a+1, continued fraction for x >= a+1.

### 2. tcdf (Student's t CDF)
- Token: `[0xBB, 0x08]` (tTcdf)
- Syntax: `tcdf(lowerBound, upperBound, df)`
- Implementation: Use the regularized incomplete beta function. tcdf(a,b,df) = I(df/(df+b²), df/2, 1/2) - I(df/(df+a²), df/2, 1/2) where I is the regularized incomplete beta function. Or use numerical integration of the t-distribution PDF.
- Simpler approach: numerical integration of t-PDF = Γ((df+1)/2)/(√(df·π)·Γ(df/2)) · (1+x²/df)^(-(df+1)/2)

### 3. Fcdf (F-distribution CDF)
- Token: `[0xBB, 0x09]` (tFcdf)
- Syntax: `Fcdf(lowerBound, upperBound, dfNumerator, dfDenominator)`
- Implementation: Use regularized incomplete beta function. Fcdf(a,b,d1,d2) = I_x2(d1/2, d2/2) - I_x1(d1/2, d2/2) where x = d1·F/(d1·F + d2)

### 4. invT (inverse t-distribution)
- Token: `[0xBB, 0x03]` (tInvT)
- Syntax: `invT(area, df)`
- Implementation: Use Newton's method on tcdf, starting from a normal approximation.

### 5. LinReg(ax+b)
- Token: `[0xBB, 0x07]` (tLinRegAxPlusB) — verify this token byte
- Syntax: `LinReg(ax+b) L1, L2` or `LinReg(ax+b) list1, list2`
- Implementation: Compute slope a = (nΣxy - ΣxΣy)/(nΣx² - (Σx)²), intercept b = ȳ - a·x̄, correlation r, r².
- Store results: return object or display "a=..., b=..., r²=..., r=..."

### 6. ClrList
- Token: `[0xBB, 0x38]` or `0x72` (check existing token map)
- Syntax: `ClrList L1` or `ClrList L1, L2, ...`
- Implementation: Clear the specified list variables (set to empty `{}`)
