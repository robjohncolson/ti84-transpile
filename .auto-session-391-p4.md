# Task: Coverage Push — Audit + Add Seeds

## Context
This is a TI-84 Plus CE ROM transpilation project. The transpiler is at `scripts/transpile-ti84-rom.mjs`. It lifts eZ80 ROM machine code to JavaScript. Seeds are entry points that the transpiler uses to discover reachable code blocks via control flow analysis.

Current state: 95.92% true coverage, 144,230 transpiled blocks, ~49,973 seeds.

## Deliverables

### Part 1: Run the coverage audit
```bash
node TI-84_Plus_CE/audit-true-uncovered.mjs
```
Capture the output. It lists uncovered ROM regions.

### Part 2: Analyze gaps and add seeds
Look at the audit output for the LARGEST uncovered regions. For each gap:
1. Read the ROM bytes at the gap start address
2. Check if it looks like valid eZ80 code (starts with a known opcode, not 0xFF fill)
3. If valid, add the address as a seed in `scripts/transpile-ti84-rom.mjs`

Seeds are added in the `seeds` array in the transpiler. Search for `seeds` or `0x` in the file to find where seeds are declared. Add new seeds at the end of the array.

### Part 3: Re-run transpiler and verify
```bash
node scripts/transpile-ti84-rom.mjs
node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
```
The transpiler should report a higher block count. The golden regression must still pass 26/26 (or 5/5 in the summary).

## How to find the seeds array
```bash
# In scripts/transpile-ti84-rom.mjs, search for the seed declarations
grep -n "seeds\|0x0" scripts/transpile-ti84-rom.mjs | head -50
```

The transpiler file is large. The seeds are typically in an array near the top or in a dedicated section. Read the relevant section, add new addresses, save.

## Constraints
- Only modify `scripts/transpile-ti84-rom.mjs` (to add seeds)
- Do NOT modify cpu-runtime.js, peripherals.js, browser-shell.html, or any probe files
- Do NOT remove existing seeds
- Run the golden regression after re-transpiling to confirm no breakage
- Report: number of seeds added, new block count, golden regression result

## Success Criterion
- Coverage audit runs successfully
- At least 5 new valid seeds identified and added
- Transpiler re-run succeeds with increased block count
- Golden regression passes (26/26 or 5/5 summary)
