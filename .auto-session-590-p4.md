## Context
You are reverse-engineering the TI-84 Plus CE OS ROM (eZ80 machine code). This address is the type-0x2A special case jump target in 0x09A3D0 (table-driven subfield resolver, decoded in session 589). The path is: `CP 0x2A → JR Z,0x09A40A`. Type 0x2A is `CplxObj` (complex number object) in the TI-OS type system — this is likely a special handler for complex number subfields.

Related context:
- 0x09A3D0 is a table-driven subfield resolver (58B, decoded session 589)
- It uses ROM lookup tables at 0x09A415 (3-byte entries) and 0x09A4D5 (1-byte offsets)
- Base address for subfield storage is D1983D
- The normal path does bit-field merge (AND 0xC0 from source, AND 0xBF on dest, OR merge)
