3. Run the probe: `node TI-84_Plus_CE/probe-phase437-port-3080-map.mjs`

## Port I/O encoding in eZ80

Port access in eZ80 uses:
```
LD BC, <port>    ; 01 xx xx 00 (4 bytes, 24-bit immediate but port is 16-bit so high byte=00)
IN A,(C)         ; ED 78
OUT (C),A        ; ED 79
```

Sometimes with SIL prefix (0x40) before the LD BC: `40 01 80 30` (3-byte immediate in SIL mode).

Also look for direct port byte patterns: bytes `80 30` preceded by `01` for the LD BC instruction.
