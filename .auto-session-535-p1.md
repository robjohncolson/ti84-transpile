## eZ80 Decoding Rules (CRITICAL)
- Default mode is ADL (24-bit). All LD rr,nn use 3-byte immediates. All CALL/JP use 3-byte addresses.
- Prefix 0x52 = .SIL (force 16-bit operands for next instruction)
- Prefix 0x40 = .SIS (force 16-bit operands + short stack)
- Prefix 0x49 = .LIL (force 24-bit, usually no-op in ADL)
- ED-prefix opcodes: ED B0 = LDIR, ED A0 = LDI, ED A1 = CPI, ED B1 = CPIR, ED A8 = LDD, ED B8 = LDDR
- CB-prefix opcodes: BIT/SET/RES instructions (CB 46+8*n = BIT n,(HL), CB C6+8*n = SET n,(HL), CB 86+8*n = RES n,(HL))
- DD prefix = IX variants, FD prefix = IY variants (FD CB dd nn for BIT/SET/RES (IY+dd))
- Common patterns: 0xCD = CALL nn (3 bytes), 0xC3 = JP nn, 0xC9 = RET, 0x18 = JR d, 0x20 = JR NZ, 0x28 = JR Z, 0x38 = JR C, 0x30 = JR NC
- 0xE5 = PUSH HL, 0xD5 = PUSH DE, 0xC5 = PUSH BC, 0xF5 = PUSH AF
- 0xE1 = POP HL, 0xD1 = POP DE, 0xC1 = POP BC, 0xF1 = POP AF
