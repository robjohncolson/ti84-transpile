# Task: Decode 0x0801B9 — Font Size Detection

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decoded 0x0A23E5 (the character renderer) and found it calls 0x0801B9 for "font size detection" — the result influences whether character width is set to 0xBD (189, large font) or 0x61 (97, small font).

## What we know
- 0x0A23E5 calls 0x0801B9 after testing BIT 4,(IY+20).
- After 0x0801B9 returns, 0x0A23E5 uses BIT 3,(IY+17) to select between large (0xBD) and small (0x61) character widths.
- 0x0801B9 likely reads font configuration flags or computes the active font metrics.
- The 0x080xxx range contains display/font-related code in the TI OS.

## Your task
1. Read the ROM binary at offset 0x0801B9 and disassemble the function (eZ80 ADL mode, 24-bit addresses).
2. Determine function boundaries (find the RET).
3. Document: entry conditions, what registers/RAM it reads and writes, what it calls, return values.
4. Find how many callers reference 0x0801B9 across the ROM.
5. Determine: does this function SET flags that the caller then tests? Or does it return a value in A/HL?

## eZ80 ADL mode reference
- CALL nn = CD xx xx xx (3-byte LE address)
- JP nn = C3 xx xx xx
- JP cc,nn = C2/CA/D2/DA/E2/EA/F2/FA xx xx xx
- RET = C9, RET cc = C0/C8/D0/D8/E0/E8/F0/F8
- LD r,(IX+d) / LD r,(IY+d) = DD/FD prefix + opcode + displacement
- BIT/SET/RES via CB prefix (FD CB d op for IY-indexed)
- ED prefix for extended ops
- SIS prefix (40) = short (16-bit) instruction in ADL mode
- LD HL,nn = 21 xx xx xx, LD DE,nn = 11 xx xx xx, LD BC,nn = 01 xx xx xx
- LD A,(nn) = 3A xx xx xx
- LD (nn),A = 32 xx xx xx
- CP n = FE xx
- OR A = B7, AND A = A7, XOR A = AF
- JR cc,d = 20/28/30/38 xx
