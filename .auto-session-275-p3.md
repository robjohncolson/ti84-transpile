# Auto-Session 275 P3: Investigate D0259A Dispatch Table Entry Count

## Context
In the TI-84 Plus CE OS, the dispatch table lives at D3FFFF growing downward with 9-byte entries. Session 274 found that 0x09DEF4 loads HL=0xD3FFFF and also references D0259A, suggesting D0259A holds the dispatch table entry count. Understanding who reads/writes D0259A tells us how entries get registered and how many the OS expects.

## Task
Create a probe `TI-84_Plus_CE/probe-phase275-d0259a-count.mjs` that:

1. **Static ROM scan for all D0259A references**:
   - Search for `9A 25 D0` (little-endian address bytes) in the ROM
   - For each match, read surrounding bytes to determine the instruction type:
     - LD A,(D0259A) / LD (D0259A),A — direct read/write
     - LD HL,D0259A — pointer load
     - INC (HL) after LD HL,D0259A — counter increment
     - DEC (HL) — counter decrement
   - Classify each reference as: READ, WRITE, INCREMENT, DECREMENT, POINTER

2. **Disassemble 0x09DEF4 context**: Read 32 bytes before and 32 bytes after 0x09DEF4 to understand the function it's in. What does it do with HL=0xD3FFFF + D0259A?

3. **Dynamic trace of 0x09DEF4**: Run from 0x09DEF4 (or the function entry ~16 bytes before) for 100 steps to see:
   - Does it zero D0259A (table reset)?
   - Does it increment D0259A (registration)?
   - Does it read D0259A and use it as a loop counter (iteration)?

4. **Boot value**: After cold boot, what is mem[0xD0259A]? (Should be 0x00 = empty table)

## Probe template

```javascript
import { readFileSync } from 'fs';
import { createCPU, createPeripheralBus } from './cpu-runtime.js';

const rom = readFileSync(new URL('./ROM.rom', import.meta.url));

// Scan for D0259A references (little-endian: 9A 25 D0)
const target = [0x9A, 0x25, 0xD0];
console.log('=== Static scan for D0259A references ===');
for (let i = 0; i < rom.length - 3; i++) {
    if (rom[i] === target[0] && rom[i+1] === target[1] && rom[i+2] === target[2]) {
        // Check preceding opcode to determine instruction type
        const prevBytes = Array.from(rom.slice(Math.max(0, i-4), i));
        const postBytes = Array.from(rom.slice(i+3, i+8));
        console.log(`  ref at ROM offset 0x${i.toString(16).padStart(6,'0')}: prev=${prevBytes.map(b=>'0x'+b.toString(16).padStart(2,'0')).join(' ')} [9A 25 D0] post=${postBytes.map(b=>'0x'+b.toString(16).padStart(2,'0')).join(' ')}`);
    }
}

// Disassemble around 0x09DEF4
console.log('\n=== Bytes around 0x09DEF4 ===');
const start = 0x09DEE0;
const bytes = Array.from(rom.slice(start, start + 48));
console.log(`0x${start.toString(16)}: ${bytes.map(b=>b.toString(16).padStart(2,'0')).join(' ')}`);
```
