# Task: Trace 0x051B84 BIT 4,(HL) test on D003E0 (llll)

## Context
Session 239 identified 0x051B84 as a BIT 4 test site on D003E0 that was previously unknown. D003E0 is a critical OS flags byte with multiple bit tests scattered across the ROM:
- BIT 0 at 0x04EDDD (controls 0x04E447 vs 0x0850D1)
- BIT 3 at 0x04EABD, 0x04EB66, 0x051CF3 (gates enter-edit paths)
- BIT 4 at 0x051B84 (NEW — untraced)
- SET 2 at 0x051D89, RES 2+3 at 0x051D52, sole direct writer at 0x04EE3E

We need to understand what 0x051B84's BIT 4 test controls.

## What to do
Create a new probe file `TI-84_Plus_CE/probe-phase241-051b84-bit4-trace.mjs` that:

1. **Static disassembly**: Read ROM bytes and disassemble from 0x051B60 to 0x051BA0 (40+ bytes around 0x051B84) to see the full instruction context — what's before and after the BIT 4 test.

2. **Find the parent function**: Scan backwards from 0x051B84 for a RET instruction to identify the function boundary. Also scan forwards to find the function's RET.

3. **Find callers**: Scan the ROM binary for `CALL 0x051B??` patterns (CD xx 1B 05 for ADL CALL) that target the function containing 0x051B84. Also check for JP patterns (C3 xx 1B 05).

4. **Dynamic trace with BIT 4 SET vs CLEAR**:
   - **Scenario A**: Seed D003E0=0x00 (BIT 4 CLEAR), enter at the function containing 0x051B84, run 500 steps
   - **Scenario B**: Seed D003E0=0x10 (BIT 4 SET), same entry, run 500 steps
   - Compare: what path does each take? Which blocks differ?

5. Track:
   - What the BIT 4 test gates (JR Z? JR NZ? JP Z? JP NZ?)
   - What code runs on each branch
   - Any RAM writes or IY flag changes
   - Other D003E0 bits referenced nearby
