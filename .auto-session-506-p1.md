# Task: Decode 0x0A1799 — Real Character Output Function

## Context
You are working on a TI-84 Plus CE ROM (eZ80) transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 ADL mode, little-endian).

Session 505 discovered that 0x0A1B5B (51-byte text cursor advance wrapper) delegates to 0x0A1799 as the **actual character output function**. 0x0A1B5B just tracks column position (wraps at column 26) and handles special char 0xD6. The real rendering happens at 0x0A1799.

The status bar rendering pipeline calls: 0x0979E4 → 0x0A1B5B (column tracking) → **0x0A1799** (actual output).

## What to do

1. Create a probe file `TI-84_Plus_CE/probe-phase506-decode-0A1799.mjs` that:
   - Reads the ROM file from `TI-84_Plus_CE/ROM.rom` (use `fs.readFileSync`)
   - Statically disassembles starting at 0x0A1799 for ~200 bytes
   - For each instruction: read the opcode bytes, decode the eZ80 instruction, print address + hex bytes + mnemonic
   - Look for: CALL targets, RAM addresses (D0xxxx), VRAM writes, port I/O, RST 28h (0xE7 = BCALL)
   - The eZ80 is in ADL mode (24-bit addresses). Key opcodes:
     - 0xCD = CALL nn (3-byte address, little-endian)
     - 0xC3 = JP nn
     - 0xC9 = RET
     - 0x3A = LD A,(nn) — 3-byte address
     - 0x32 = LD (nn),A
     - 0x2A = LD HL,(nn)
     - 0x22 = LD (nn),HL
     - 0xFD prefix = IY operations
     - 0xDD prefix = IX operations
     - 0xED prefix = extended ops
     - 0xCB prefix = bit ops
     - 0x40 prefix = .SIS (force 16-bit operands in ADL mode)
     - 0x52 prefix = .LIS
     - 0x49 prefix = .SIL
     - 0xE7 = RST 28h (BCALL, followed by 2-byte table index)
   - Print a summary of what the function does

2. Run the probe: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase506-decode-0A1799.mjs`
