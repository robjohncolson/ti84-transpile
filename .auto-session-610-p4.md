# Auto-Session 610 — P4: Investigate 0x0907D6 SET 3 Conditional

## Context

This is a TI-84 Plus CE ROM transpilation project. We're investigating the D000A3 flag byte (IY+0x23) which controls the edit buffer walker's termination.

Session 609 mapped D000A3 bit 3 semantics:
- **SET 3 at 0x0907D6**: conditional — first does RES 3 at 0x0907BF, then re-SETs bit 3 ONLY IF D00081 bit 2 is SET AND D11146 == D11104
- **RES 3 at 0x0907BF**: unconditional clear before conditional re-SET
- **RES 3 at 0x0A8EA2**: app context manager clear

D000A3 bit 3 = "edit buffer active" flag. When SET, the walker at 0x090917 continues walking. When CLEAR, the walker exits via RET Z.

### Part B: Decode D00081 (IY+0x01) and D11146/D11104

These are the addresses that control whether SET 3 fires:
- **D00081 bit 2**: What is this flag? (IY+0x01 bit 2). Search the ROM for BIT 2,(IY+1) / SET 2,(IY+1) / RES 2,(IY+1) patterns to understand its purpose.
- **D11146 and D11104**: What are these? Are they edit buffer pointers, display coordinates, or something else?

To search for IY+1 references:
```javascript
// IY+d instructions use prefix FD CB d opcode
// BIT 2,(IY+d) = FD CB 01 56 (d=0x01, opcode=0x56 for BIT 2)
// SET 2,(IY+d) = FD CB 01 D6
// RES 2,(IY+d) = FD CB 01 96
// Also: LD A,(IY+d) = FD 7E 01, then AND/OR/BIT on A

const patterns = [
  { name: 'BIT 2,(IY+1)', bytes: [0xFD, 0xCB, 0x01, 0x56] },
  { name: 'SET 2,(IY+1)', bytes: [0xFD, 0xCB, 0x01, 0xD6] },
  { name: 'RES 2,(IY+1)', bytes: [0xFD, 0xCB, 0x01, 0x96] },
];

for (const pat of patterns) {
  const hits = [];
  for (let addr = 0; addr < rom.length - pat.bytes.length; addr++) {
    let match = true;
    for (let j = 0; j < pat.bytes.length; j++) {
      if (rom[addr + j] !== pat.bytes[j]) { match = false; break; }
    }
    if (match) hits.push('0x' + addr.toString(16).padStart(6, '0'));
  }
  console.log(`${pat.name}: ${hits.length} hits — ${hits.slice(0, 20).join(', ')}`);
}
```
