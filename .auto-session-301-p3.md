Session 300 discovered that the keyboard scanner wrapper at 0x015930 performs a **stack bounds check** before calling the scanner. If the stack pointer is out of range (bounds: 0xD1987E to 0xD1A87E), it executes `JP 0x000066` — the eZ80 NMI vector address. The scanner wrapper also JPs to 0x000066 if a post-scan port check fails.

On the eZ80 CPU, address 0x000066 is the **Non-Maskable Interrupt (NMI) handler** vector. The TI-84 CE OS repurposes this as a crash/recovery handler.

   - Clear interrupt state
   - Jump to an error display routine or reset routine

2. **Follows any JP/CALL targets** within the first 2 levels of indirection. If the NMI handler does `JP 0xNNNNNN`, disassemble that target too (up to 64 bytes).

4. **Identifies what the OS does on stack overflow**: Does it display an error? Reset? Reboot? Look for references to error message strings or LCD write routines.

5. **Print a summary**: What happens when the NMI fires, how many callers use it as an explicit JP target (vs. hardware NMI trigger), and what the recovery behavior is.
