# Task: Decode the OS API Helpers at 0x006E6D-0x006E8D (edit mode syscalls)

## Context
TI-84 Plus CE ROM transpilation project. ROM file at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 395 identified three tiny OS API helpers at 0x006E6D-0x006E8D that manage edit mode (bit 2 of IY+0x12):
- 0x006E6D region: test edit mode (BIT 2,(IY+0x12))
- 0x006E73 region: one of the three (test/set/clear)
- 0x006E7F region: another of the three
- These are the OS-level syscalls for edit/input mode management

IY+0x12 bit 2 has 24 total operations across ROM (the heaviest bit). Understanding who calls these helpers reveals which OS subsystems manage edit mode.

## Deliverable
Create `TI-84_Plus_CE/probe-phase396-editmode-helpers.mjs` — a Node.js probe that:
1. Reads ROM.rom directly with `readFileSync`
2. Disassembles from 0x006E6D through 0x006E8D (~32 bytes) — should contain 3 tiny functions (each ~6-8 bytes: BIT/SET/RES 2,(IY+0x12) + RET)
3. Identify the exact boundaries and purposes of each function
4. For each function, search the ENTIRE ROM (0x000000-0x3FFFFF) for CALL references:
   - CALL addr24 = CD xx xx xx where xx xx xx = function address (little-endian)
   - JP addr24 = C3 xx xx xx (same pattern)
5. Report all callers with their addresses and which function they call (test/set/clear)
6. Group callers by ROM region to identify which OS subsystems use edit mode

## Technical: eZ80 instruction encoding
- FD CB 12 46 = BIT 0,(IY+0x12) ... FD CB 12 56 = BIT 2,(IY+0x12)
- FD CB 12 D6 = SET 2,(IY+0x12)
- FD CB 12 96 = RES 2,(IY+0x12)
- C9 = RET
- CD xx xx xx = CALL addr24 (little-endian: low, mid, high)
- C3 xx xx xx = JP addr24

For searching: CALL 0x006E6D = CD 6D 6E 00, CALL 0x006E73 = CD 73 6E 00, etc.
