## Background
Session 475 found two critical issues:
1. The display update path's final XOR A + RET spans bytes 0x02FE21-0x02FE22. Probes using `RET_POINTS={0x02FE22}` miss the block because `onBlock` fires at 0x02FE21 (the block start). FIX: use 0x02FE21 in RET_POINTS.
2. D00089 bit 4 gates 0x03D1BE (BIT 4,(IY+0x09)). After boot, D00089=0x00 so 0x03D1BE always returns Z immediately. Setting D00089 bit 4 allows 0x03D1BE to proceed to 0x030078 display setup.
