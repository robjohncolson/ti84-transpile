# Auto-Session 208 P2: STAT entry from FULL BOOT + CoorMon path

## Context
Sessions 204-207 established that STAT menu dispatch (entry at 0x058BA9 = cxErrorEP) reaches an "Error" state after <100 steps when entered from a cold boot with just list/VAT seeding. PushErrorHandler before STAT has NO EFFECT (crashes into RST vectors at 107 steps). The hypothesis is that STAT requires OS state that only exists after a full boot + CoorMon traversal — specifically the error handler stack (errSP), the OS event loop context, and possibly the display/menu state.

## Task
Build a probe `TI-84_Plus_CE/probe-phase208-stat-full-boot.mjs` that:

1. **Uses the FULL BOOT path** from the golden regression probe as a starting point. Reference `TI-84_Plus_CE/probe-phase99d-home-verify.mjs` for the boot sequence (kernelInit → memInit → homescreen stages 1-4).

2. **After full boot completes** (home screen rendered), seed list data L1={1.0,2.0,3.0} at a NEAR address (0xD01600, per session 202's fix):
   - List header: count=3 (LE: 03 00), then 3 BCD reals (9 bytes each): 1.0=`00 80 10 00 00 00 00 00 00`, 2.0=`00 80 20 00 00 00 00 00 00`, 3.0=`00 80 30 00 00 00 00 00 00`
   - VAT entry at 0xD1A800: type=0x01, data pointer to 0xD01600 (LE: 00 16 D0), name length 2, name bytes 0x5D 0x00 (L1)
   - Set allocator: opBase=0xD1A800, ops/pTemp=0xD1A808, newDataPtr=0xD0161D

3. **Enter STAT via context table entry [4]** (0x058BA9 = cxErrorEP). This is how session 191 entered STAT and got 87 blocks + 264 blocks.

4. **Run for 50000 steps** and report:
   - Total unique blocks visited
   - Whether the 5-block error loop (0x082BE2/0x084716/0x08471B/0x084723/0x084711) appears
   - Whether OP1 contains "Error" string (0x032D pattern)
   - Whether any FP/math blocks (0x07Bxxx-0x07Dxxx) are reached
   - RAM state at 0xD008E6 (STAT structure)
   - Compare block count to cold-boot entry (264 blocks from sessions 204-207)

5. **Also try entry via the FULL CoorMon path**: After boot, instead of jumping directly to 0x058BA9, set up the context table pointer at 0x0585D4 to select entry [4] and enter via 0x0585D3 (JP (HL)). This more closely mimics how the OS enters STAT through the menu system.
