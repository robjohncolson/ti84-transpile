## eZ80 opcode reference for decoding
- 0xDD prefix = IX instructions, 0xFD prefix = IY instructions, 0xED prefix = extended
- 0xCB prefix = bit operations (BIT/SET/RES)
- FD CB dd bb = IY+dd bit operation (bb determines BIT/SET/RES and bit number)
- 0x3A = LD A,(addr) [3-byte addr in ADL mode]
- 0xFE = CP n (compare A with immediate)
- 0xC8 = RET Z, 0xC0 = RET NZ, 0xC9 = RET
- 0xCA = JP Z, 0xC2 = JP NZ
- 0x28 = JR Z, 0x20 = JR NZ
- 0xCD = CALL addr
