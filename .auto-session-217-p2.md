# Auto-Session 217 P2: Trace 0x04EC34 (OS core SET 4,(IY+5) site)

## Context
Session 212 identified 12 SET 4,(IY+5) sites in the ROM. Most are in STAT/apps region (0x09xxxx). Two are in the editor region (0x0612B0, 0x0612E4 — inside the dispatcher at 0x061290). One is in OS core: **0x04EC34**.

0x04EC34 may be the general "enter edit mode" helper that the OS calls during home-screen setup or before accepting keyboard input. Understanding this site is critical for determining how BIT 4,(IY+5) gets armed during normal OS operation.

## Task
Build a probe `TI-84_Plus_CE/probe-phase217-04ec34-trace.mjs` that:

### Part A: Static analysis around 0x04EC34
1. Read ROM.rom binary directly
2. Disassemble ~64 bytes before and ~64 bytes after 0x04EC34 to find function boundaries (look for RET instructions)
3. Identify the function that contains 0x04EC34
4. Report surrounding instructions

### Part B: Caller search
1. Scan the entire ROM (0x000000-0x3FFFFF) for CALL/JP instructions targeting the function containing 0x04EC34
2. Search patterns: `CD xx xx 04` (ADL CALL), `C3 xx xx 04` (ADL JP), `CD xx xx` (z80 CALL with 2-byte addr if applicable)
3. Report all call sites found

### Part C: Dynamic trace
1. Full boot (z80 boot → kernelInit → memInit)
2. Call the function containing 0x04EC34 directly
3. Run up to 200 steps
4. Check IY+5 (0xD00085) before and after
5. Record all unique blocks visited
6. Record any RAM writes to IY-indexed addresses (especially IY+5, IY+12, IY+0x18, IY+0x44)

### Part D: Context experiment
1. Same as Part C but with edit buffer pointers seeded:
   - editCursor 0xD0243A = 0xD00A00
   - editTail 0xD0243D = 0xD00B00
   - editTop 0xD02437 = 0xD00A00
   - editBtm 0xD02440 = 0xD00B00
2. Compare: does seeding edit pointers change the function's behavior?

## eZ80 instruction encoding reference
- SET 4,(IY+d) = `FD CB dd E6` where dd is the displacement byte
- RES 4,(IY+d) = `FD CB dd A6`
- BIT 4,(IY+d) = `FD CB dd 66`
- CALL nn (ADL) = `CD ll mm hh` (3-byte address, little-endian)
- JP nn (ADL) = `C3 ll mm hh`
- RET = `C9`
