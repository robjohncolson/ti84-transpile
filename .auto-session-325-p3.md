# Task: Trace 0x05F7D9 — Sole Caller of Vector 0x0005CC (→0x007B70)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM binary is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

Session 324 found:
- 0x0005CC = vector #19 in the BCALL table at 0x000580-0x0005FC (32 JP instructions, 4 bytes each)
- 0x0005CC → JP 0x007B70 (reads ports 0x800C and 0x800D as 16-bit composite)
- Only 1 caller: CALL 0x0005CC at address 0x05F7D9
- 0x007B70 reads LCD DMA timing registers — why would runtime code need these?

## What to do
Create a probe `TI-84_Plus_CE/probe-phase325-trace-05F7D9.mjs` that:

### Part 1: Disassemble the function containing 0x05F7D9
Find the function prologue before 0x05F7D9 and disassemble forward. eZ80 function prologues typically start with:
- `PUSH IX` (0xDD 0xE5) followed by `LD IX, 0` + `ADD IX, SP` (frame setup)
- Or just `PUSH` of callee-saved registers

Scan backwards from 0x05F7D9 looking for a prologue (up to 200 bytes back). Then disassemble forward from the prologue through the RET.

### Part 2: Find all callers of this function
Once you identify the function start address, search the entire ROM for CALL instructions targeting it:
- CALL encoding: 0xCD + 3-byte LE address
- JP encoding: 0xC3 + 3-byte LE address

### Part 3: Analyze what 0x05F7D9 does with the result
After the `CALL 0x0005CC` at 0x05F7D9, the return value is in HL (16-bit composite of ports 0x800C and 0x800D). Disassemble the bytes after 0x05F7D9 + 4 (the CALL is 4 bytes: CD CC 05 00) to see what the function does with HL.

### Part 4: Cross-reference with known LCD functions
Check if this function also calls any of these known LCD-related addresses:
- 0x010A3C (LCD sync)
- 0x055280 (LCD DMA transfer)
- 0x055191 (config table copier)
- Any address in the 0x0550xx-0x0558xx range

Search for CALL instructions to these targets within the function body.

### eZ80 instruction reference (key opcodes for disassembly)
- 0xCD = CALL nn (4 bytes total: CD + 3-byte addr)
- 0xC3 = JP nn (4 bytes total)
- 0xC9 = RET (1 byte)
- 0xDD 0xE5 = PUSH IX (2 bytes)
- 0xDD 0xE1 = POP IX (2 bytes)
- 0x21 = LD HL, nn (4 bytes)
- 0x3E = LD A, n (2 bytes)
- 0xED = prefix for block/port ops
- 0xDD = IX prefix
- 0xFD = IY prefix
