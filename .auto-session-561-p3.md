# Task: Decode 0x0800B8 — Low-ROM Syscall

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We decode ROM functions by reading raw bytes, disassembling them as eZ80 instructions, and documenting their behavior.

Session 560 decoded 0x0A2013 (Y-advance wrapper, 31B) which calls 0x0800B8 as a final syscall after busy-waiting on D00824 and gating on IY+0x15 bit 6. The call chain is:
- 0x0A2032 (line wrap) → 0x0A2013 (wrapper) → 0x0A1F48 (Y advance) + **0x0800B8** (syscall)
- 0x0800B8 is in low ROM (page 0x08xxxx) suggesting it's a system-level function
- Called AFTER Y-advance and busy-wait — likely LCD sync, display update, or similar system service

## Known context
- IY = 0xD00080 (OS flags base)
- D00824 = busy-wait state byte (polled by 0x0A2013 until zero)
- IY+0x15 bit 6 = gate flag checked before calling 0x0800B8
- The 0x08xxxx range contains OS system calls (we've seen 0x08DBE1 = cursor-back in session 558)

## What to do

1. Read 200 bytes starting at ROM offset 0x0800B8 from `TI-84_Plus_CE/ROM.rom`
2. Disassemble as eZ80 ADL-mode instructions (24-bit addresses, 3-byte pointers)
3. Document: registers used, RAM addresses read/written, CALL targets, I/O ports accessed, function boundary
4. Pay special attention to: LCD-related I/O (port 0x10-0x1F in E300xx range), DMA triggers, interrupt enable/disable

## Deliverable
Create a probe file: `TI-84_Plus_CE/probe-phase561-decode-0800B8.mjs`

Use this template structure:
```javascript
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

const startAddr = 0x0800B8;
const bytes = rom.slice(startAddr, startAddr + 200);

console.log(`=== Decoding 0x0800B8: Low-ROM Syscall ===`);
console.log(`Bytes at 0x${startAddr.toString(16)}:`);

for (let i = 0; i < bytes.length; i += 16) {
    const addr = startAddr + i;
    const hex = Array.from(bytes.slice(i, Math.min(i + 16, bytes.length)))
        .map(b => b.toString(16).padStart(2, '0')).join(' ');
    console.log(`  ${addr.toString(16).padStart(6, '0')}: ${hex}`);
}

console.log(`\n=== Disassembly ===`);
// Full eZ80 ADL-mode disassembly, instruction by instruction
// Cover all standard eZ80 instruction groups
// Pay attention to OUT (C),r / IN r,(C) for I/O port access
// Watch for E3xxxx addresses (LCD controller registers)

console.log(`\n=== Summary ===`);
// RAM addresses, I/O ports, CALL targets, function size, architectural interpretation
```

Implement a FULL eZ80 disassembly. Cover at minimum:
- LD r,r / LD r,n / LD r,(addr) / LD (addr),r
- PUSH/POP, CALL nn (3-byte ADL), RET/RET cc
- JP nn / JR e / JR cc,e
- CP / OR / AND / XOR / ADD / SUB / INC / DEC
- BIT/SET/RES (CB prefix), IX/IY (DD/FD prefix)
- ED prefix: IN/OUT, LDIR/LDI, block I/O
- DI/EI, HALT, NOP
- .SIS prefix (0x40) for 16-bit mode

Stop at clear function boundary.
