# Task: Map D000C6 Fully — BPP Mode Flag Byte

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We map RAM addresses by searching the ROM for all references to them.

Session 553 discovered that RAM address D000C6 contains a BPP mode flag. Specifically:
- 0x08C308 does `BIT 2,(D000C6)` to test between 16bpp (Z) and 8bpp (NZ) rendering
- D000C6 bit 2 selects the framebuffer rendering mode

We need to map ALL references to D000C6 in the ROM to understand what all the bits do and who reads/writes them.

## Your task
1. Search the entire ROM for all references to address D000C6 (bytes C6 00 D0 in little-endian)
2. For each reference found, read surrounding bytes to determine the instruction (is it a read, write, BIT test, SET, RES?)
3. Categorize each reference: which bit is being tested/set/reset, and what the surrounding context suggests
4. Count total references and summarize what each bit appears to control

## How to search ROM
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

// Search for D000C6 in little-endian (C6 00 D0)
// But be careful — D000C6 appears as part of 24-bit address loads
// Pattern: look for C6 00 D0 anywhere in ROM
const target = [0xC6, 0x00, 0xD0];
const refs = [];
for (let i = 0; i < rom.length - 2; i++) {
  if (rom[i] === target[0] && rom[i+1] === target[1] && rom[i+2] === target[2]) {
    refs.push(i);
  }
}
```

For each reference, look at preceding bytes to identify the instruction. Common patterns:
- `LD HL,D000C6` = 0x21 C6 00 D0 (loads address into HL for indirect access)
- `LD A,(D000C6)` = 0x3A C6 00 D0 (direct read)
- `LD (D000C6),A` = 0x32 C6 00 D0 (direct write)
- BIT/SET/RES via HL indirect: instruction loads HL with D000C6, then does CB prefix operations

Also search for references to nearby addresses D000C5, D000C7, D000C8 — they may be part of the same flag block.

## eZ80 notes
- ADL mode: 24-bit addresses, 24-bit registers by default
- `SIS` prefix (0x40) forces 16-bit mode — in SIS mode, LD HL,imm16 loads only 16 bits
- For BIT n,(HL): HL must be loaded with the address first, then CB prefix + BIT opcode
