# Auto-Session 196 P3: Y= editor row label investigation — what controls Y1=, Y2=, etc.

## Context
Session 195 fully decoded the Y= editor display loop at 0x09CB14. Counter 0xD00596 counts down from 25 (0x19), each iteration renders one LCD row with 384 VRAM writes. The loop calls:
- 0x0A2B72: attribute updater (sets counter, initializes when 0/0xFF)
- 0x05E27E: lightweight flag check
- 0x0A1B59: screen update (50 blocks, 679 steps, writes VRAM)

What's NOT known: how does each row know which function label to display (Y1=, Y2=, Y3=, etc.)? There must be a label index or Y-variable number that maps to the row being rendered.
