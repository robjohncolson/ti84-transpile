# Task: Map the CPIR Table at 0x09AF6F (15-byte Fast-Match Table)

## Context
This is a TI-84 Plus CE ROM transpilation project. In session 515, we decoded the token/alpha range dispatcher at 0x09AF4E (301B, 147 instructions, 32 CP checks). It contains a CPIR TABLE LOOKUP at 0x09AF5A:
- BC = count (number of entries)
- HL = 0x09AF6F (pointer to 15-byte table in ROM)
- The CPIR instruction searches for register A in the table at (HL)
- Matched codes take a fast path, others fall through the full cascade

The CPIR instruction (ED B1) repeats: compare A with (HL), increment HL, decrement BC, repeat until match or BC=0.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase516-cpir-table.mjs` that:

1. Reads the ROM file (`TI-84_Plus_CE/ROM.rom` via readFileSync)
2. Extracts the 15 bytes at ROM offset 0x09AF6F
3. Prints each byte as hex with its meaning:
   - Cross-reference each value against the keyboard matrix in `TI-84_Plus_CE/keyboard-matrix.md`
   - The values are scan codes (key codes) — format: `(idx << 4) | bit` where idx=SDK Group(7-N)
   - Common codes: 0x09=ENTER, 0x04=*, 0x07=CLEAR, 0x11=., etc.
4. Also extract the surrounding context:
   - Read the instruction at 0x09AF5A to confirm the CPIR setup (should see LD BC,count / LD HL,0x09AF6F / CPIR or ED B1)
   - Read what happens AFTER the CPIR: what branch is taken on match (Z flag set) vs no match (BC=0, Z clear)
   - Decode ~30 bytes before 0x09AF6F (the CPIR setup) and ~30 bytes after 0x09AF6F+15 (the post-match handler)

## Import pattern
Use readFileSync to read ROM.rom. Do NOT use `import { createDecoder } from './ez80-decoder.js'` — that export doesn't exist. Simple approach:
```js
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Direct byte access: rom[0x09AF6F], rom[0x09AF70], etc.
```

## eZ80 reference for CPIR
- CPIR = ED B1: Compare A with (HL), HL++, BC--, repeat until A=(HL) or BC=0
- After CPIR: Z flag set if match found, BC = remaining count (0 if exhausted)
- The 15-byte table is at ROM offset 0x09AF6F through 0x09AF7D (inclusive)

## Constraints
- File: `TI-84_Plus_CE/probe-phase516-cpir-table.mjs`
- Do NOT modify any other files
- The probe must be runnable via: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase516-cpir-table.mjs`
- Print clear output: table contents, cross-references, surrounding instruction context

## Success criterion
All 15 bytes extracted, identified as key/token codes, cross-referenced with keyboard matrix where possible. Surrounding CPIR setup and post-match handling decoded.
