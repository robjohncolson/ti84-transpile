## eZ80 ADL mode reference
- CALL nn = CD xx xx xx (3-byte LE address)
- JP nn = C3 xx xx xx
- RET = C9, RET cc = C0/C8/D0/D8/E0/E8/F0/F8
- JR d = 18 xx, JR cc,d = 20/28/30/38 xx (signed byte offset from NEXT instruction)
- LD r,(IX+d) / LD r,(IY+d) = DD/FD prefix
- BIT/SET/RES = CB prefix (+ DD CB d op for IX, FD CB d op for IY)
- ED prefix for extended ops
- SIS prefix (40) for 16-bit ops in ADL mode
- PUSH/POP: C5/D5/E5/F5 (push BC/DE/HL/AF), C1/D1/E1/F1 (pop)
- LD A,(HL) = 7E, LD (HL),A = 77
- INC/DEC: 04/05 B, 0C/0D C, 14/15 D, 1C/1D E, 24/25 H, 2C/2D L, 3C/3D A
