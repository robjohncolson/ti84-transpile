# Task: Decode 0x030173-0x0301F0 instruction-by-instruction (cursor rendering function)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at TI-84_Plus_CE/ROM.rom (4MB eZ80 binary).

Session 481 decoded the cursor rendering function at 0x030173-0x0301F0 from a hex dump. The function:
- Calls 0x030202 (glyph select)
- Saves display state (D00085, D0008D, D00082, D000B2, D026AC, D026AA, D02AC0)
- Sets LCD window registers
- Calls 0x0A23C0 (cursor character render) and 0x0A239E with B=0x0E

But this was decoded from a hex dump printout — we need a proper instruction-by-instruction disassembly with exact byte boundaries.

2. Load ROM.rom
3. Read bytes from 0x030173 to 0x030250 (covering the full function + 0x030202 handler)

   - PUSH/POP: C5/D5/E5/F5/DD E5/FD E5 and C1/D1/E1/F1/DD E1/FD E1

   - Bit ops: CB prefix, FD CB for (IY+d)
   - .SIL prefix (DD 49 before instructions), .SIS prefix (40 before instructions)

5. Output each instruction: address, hex bytes, mnemonic
6. Also hex-dump 0x030202-0x030250 for the cursor glyph selector and nearby code

The output should look like:
```

```

## eZ80 key differences from Z80
- ADL mode: 3-byte addresses (CALL/JP/LD), 3-byte register pairs
- .SIL prefix (0x52 after 0xDD, or 0x49 after 0xDD in some encodings) forces suffix in ADL mode
- MLT rr (ED 4C/5C/6C/7C) multiplies H×L→HL, etc.
- MBASE register provides upper byte for non-ADL mode addresses
