## eZ80 Disassembly Notes
- eZ80 is little-endian, variable-length instructions
- LD A,(addr24): 3A + 3-byte LE address
- LD (addr24),A: 32 + 3-byte LE address  
- CALL addr24: CD + 3-byte LE address
- JP addr24: C3 + 3-byte LE address
- BIT n,A: CB + (0x47 + n*8)
- RES n,A: CB + (0x87 + n*8)
- SET n,A: CB + (0xC7 + n*8)
- RET: C9
- PUSH/POP AF: F5/F1, BC: C5/C1, DE: D5/D1, HL: E5/E1
- LD IY,(addr24): FD 2A + 3-byte LE address
- JR cc,offset: 20/28/30/38 + signed byte offset
- JP cc,addr24: C2/CA/D2/DA + 3-byte LE address
