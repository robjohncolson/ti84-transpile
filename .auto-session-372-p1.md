# Task: Disassemble the 0x003D6B Hot Loop and Surrounding Blocks

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The OS event loop idle spin sits at address 0x003D6B — this address received 494,176 visits in 500K steps, making it the dominant hot loop. It's also the timer interrupt return point (RST 38h returns here). Understanding what this loop does and what condition would cause it to exit is critical for making keypresses work.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase372-hotloop-disasm.mjs` that:

1. **Disassembles blocks around 0x003D6B**: At minimum decode addresses 0x003D28, 0x003D2E, 0x003D5A, 0x003D5C, 0x003D62, 0x003D67, 0x003D6B, 0x003D70, 0x003D73 and any other addresses reachable from these blocks.
2. **Runs the event loop** starting at 0x003A73 with timerInterrupt:false, maxSteps=100000, maxLoopIterations=100000, and traces which blocks around 0x003D6B are visited and in what order.
3. **Logs the instruction bytes** at 0x003D6B and surrounding addresses (decode at least 20 bytes starting from each address using the decodeInstruction function from ez80-decoder.js).
4. **Identifies the loop exit condition**: What branch instruction keeps the loop spinning? What register/flag/memory value would need to change to break out?

## Reference files
- `TI-84_Plus_CE/probe-phase371-rst38-disasm.mjs` — use this as a template for the probe structure (imports, ROM loading, executor creation, multi-phase boot, disassembly formatting)

Run phases 1-3 first (with timerInterrupt:false, maxLoopIterations:32 for phase 1, 10000 for phase 2, 32 for phase 3), then enter the event loop at 0x003A73 with SP=EVENT_RESET_SP.
