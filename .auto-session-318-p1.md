# Task: Correlate 0x0241A3 and 0x00F000 Event/Callback Systems

## Context
The TI-84 Plus CE OS has two event/callback dispatcher systems discovered in recent sessions:

1. **0x0241A3 orchestrator** (session 316): 311-byte linked-list handler dispatcher with 5 _indcall sites, 9 wrappers at 0x0242E6-0x024327, command-byte bit-fields. Part of OS event/notification system.

2. **0x00F000 event cluster** (session 316): 8 sites, 4 functions = OS jump table entries 168/169/173/174. Unified callback framework at D13FED, D177B8 control word.

Both are event/callback dispatchers. The question: does 0x0241A3 dispatch INTO the 0x00F000 cluster, or are they independent systems?

## What To Do

1. Read the ROM file at `TI-84_Plus_CE/ROM.rom` (4MB binary, little-endian eZ80).

2. **Disassemble 0x0241A3** (311 bytes, through ~0x0242D8) and identify all CALL/JP targets. Check if any target falls in the 0x00F000 range or calls jump table entries 168/169/173/174.

3. **Disassemble 0x00F000 cluster** — the 4 functions at jump table entries 168, 169, 173, 174. Entry addresses: look up entries in the JP mega-table at 0x020110 (each entry is 4 bytes: JP opcode 0xC3 + 3-byte address). Entry 168 = 0x020110 + 168*4 = 0x0203B0. Entry 169 = 0x0203B4. Entry 173 = 0x0203C4. Entry 174 = 0x0203C8. Read the JP targets from those locations. Disassemble those target functions and check if they reference 0x0241A3 or its wrappers.

4. **Cross-reference check**: Search the ROM for:
   - Any CALL/JP from the 0x0241A3 function body (0x0241A3-0x0242D8) to addresses in 0x00F000-0x00F100
   - Any CALL/JP from the 0x00F000 cluster functions to 0x0241A3 or 0x0242E6-0x024327
   - Shared RAM addresses: both use D13FED area and D177B8. Check if both read/write the SAME bytes or different offsets.

5. **Determine the relationship**: Are they (a) hierarchical (one calls the other), (b) siblings (both called by a common parent), or (c) independent parallel systems for different subsystems?
