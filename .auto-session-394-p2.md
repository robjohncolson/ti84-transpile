# Auto-Session 394 P2: Decode the IY+0x12 Flags Byte Fully (All 8 Bits)

## Context
IY = 0xD00080 on the TI-84 Plus CE. IY+0x12 = 0xD00092. This is a critical OS flags byte with 74 total bit operations across all 8 bits. Session 393 fully mapped bit 5 (2ND mode flag). Now we need to map all other 7 bits.

Known from session 393:
- Bit 5 = 2ND mode flag: SET at 0x0300DB, RES at 0x02FEFF and 0x03FC17, BIT at 0x0300D5 and 0x03010F
- Bit 3 = SET at 0x02FEE3 (in the key dispatch decision tree at 0x02FECF)
- Bit 4 = SET at 0x02FEFB/0x05C89E, tested at 0x02FED7/0x030103/0x073235/0x07990D etc

Other bits referenced (from session 393 notes):
- Bit 0: SET at 0x0A27FA, RES at 0x0A34A2
- Bit 1: RES at 0x04E966/0x05C659/0x0ACC07
- Bit 2: SET at 0x04A2AC/0x06B90B, RES at 0x059A9D/0x061DBE/0x06B4D7/0x06B6D2/0x09D0F4
- Bit 6: unknown
- Bit 7: unknown

## Task
Write a Node.js probe at `TI-84_Plus_CE/probe-phase394-iy12-flags.mjs` that:

1. Reads the ROM file at `TI-84_Plus_CE/ROM.rom` (4MB binary)
2. Searches the ENTIRE ROM (0x000000-0x3FFFFF) for ALL bit operations on (IY+0x12):
   
   The eZ80 encoding for IY-indexed bit operations:
   - `BIT n,(IY+d)` = FD CB d (40+n*8+6) — where d=0x12
   - `SET n,(IY+d)` = FD CB d (C0+n*8+6) — where d=0x12
   - `RES n,(IY+d)` = FD CB d (80+n*8+6) — where d=0x12
   
   So search for byte pattern: FD CB 12 xx where xx determines the operation:
   - xx & 0xC0 == 0x40 → BIT, bit number = (xx >> 3) & 7
   - xx & 0xC0 == 0xC0 → SET, bit number = (xx >> 3) & 7
   - xx & 0xC0 == 0x80 → RES, bit number = (xx >> 3) & 7
   
   Also check for (IY-0x12) won't apply here but be aware.

3. For EACH bit (0-7), list:
   - All SET sites (address + surrounding context)
   - All RES sites (address + surrounding context)  
   - All BIT test sites (address + surrounding context)
   - A proposed name/purpose based on what subsystem the addresses are in

4. Categorize each address by ROM region:
   - 0x000000-0x010000 = boot/core
   - 0x020000-0x030000 = key dispatch / event handling
   - 0x030000-0x040000 = key translation / menu
   - 0x040000-0x060000 = screen / cursor / display
   - 0x060000-0x080000 = graph / editor
   - 0x080000-0x0A0000 = misc OS services
   - 0x0A0000-0x0C0000 = math / catalog
   - 0x0C0000+ = apps / other
