# Task: Map D176C9/D176CA Channel 3 Notification

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The instruction decoder is at `TI-84_Plus_CE/ez80-decoder.js`.

Session 413 discovered that the teardown function at 0x014E81 disarms THREE notification channels:
- Channel 1: D1440E/D1440F (primary USB notification lock/status)
- Channel 2: D17779/D1777A (Link protocol staging)
- Channel 3: D176C9/D176CA (secondary protocol channel — newly discovered, unknown purpose)

We need to map all readers and writers of D176C9 and D176CA to understand what Channel 3 does.

## What to do
1. Create a probe script `TI-84_Plus_CE/probe-phase414-channel3-D176C9.mjs` that:
   - Loads the ROM binary
   - Scans the entire ROM (0x000000-0x3FFFFF) for all references to D176C9 and D176CA
   - For each reference, determine if it's a read or write
   - Decode 5-10 surrounding instructions for context
   - Print a summary: address → read/write → D176C9 or D176CA → context

   Search patterns in eZ80 ADL mode:
   - `LD A,(D176C9)` = 3A C9 76 D1 (read)
   - `LD (D176C9),A` = 32 C9 76 D1 (write)
   - `LD A,(D176CA)` = 3A CA 76 D1 (read)
   - `LD (D176CA),A` = 32 CA 76 D1 (write)
   - Also check LD (nn),BC (ED 43), LD (nn),HL (22), LD BC,(nn) (ED 4B), LD HL,(nn) (2A)
   - Also check BIT/SET/RES instructions if used with indirect addressing

2. Create a report `TI-84_Plus_CE/phase414-channel3-D176C9-report.md` documenting:
   - Total reader and writer counts for each address
   - Which functions contain the references (find function boundaries via RET/JP)
   - What protocol Channel 3 serves (USB? Link? Something else?)
   - How Channel 3 relates to Channels 1 and 2
   - Whether D176C9/D176CA follow the same flag/status pattern as the other channels

## Known context about the channel pattern
The teardown at 0x014E81 uses this pattern for each channel:
```
read flag → if nonzero: clear flag to 0, set partner to 1
```
- Channel 1: D1440E (flag) → if ≠0: D1440E=0, D1440F=1
- Channel 2: D17779 (flag) → if ≠0: D17779=0, D1777A=1
- Channel 3: D176C9 (flag) → if ≠0: D176C9=0, D176CA=1

So D176C9 is the "active/armed" flag and D176CA is the "completed/status" byte.
