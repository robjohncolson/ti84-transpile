# Task: Map all 19 cxMain (0xD007CA) write sites — classify each by handler installed

## Context
From session 340: A full ROM scan found 47 references to 0xD007CA. Of these, 19 are STORE operations (writes). Each STORE site installs a different context handler address into cxMain, telling the OS event loop which screen/app to dispatch to next.

Mapping all 19 write sites gives us the complete context registry — every screen and app mode the OS supports.

## Deliverable: Classification probe

Create `TI-84_Plus_CE/probe-phase341-cxmain-writers.mjs` that:

1. Scans the entire ROM for all instructions that write to 0xD007CA
2. For each write site:
   a. Read the surrounding bytes (32 bytes before the write instruction) to find what value is being stored
   b. The typical pattern is: `LD HL, <handler_addr>` followed by `LD (0xD007CA), HL`
   c. Extract the handler address from the LD HL instruction
   d. Print: `write_site_addr → handler_addr (hex) — nearby_label_if_known`
3. Cross-reference handler addresses against known handlers:
   - 0x058241 = HOME_HANDLER (home screen)
   - Other handlers discovered in this scan should be noted as "UNKNOWN_<addr>"
4. Also check for indirect writes — `LD (0xD007CA), HL` where HL was computed, not loaded from immediate
5. Produce a summary table:
   ```
   CXMAIN WRITE SITE REGISTRY
   ===========================
   Address    | Handler Installed | Notes
   -----------|-------------------|------
   0x0XXXXX   | 0x058241          | HOME_HANDLER
   0x0XXXXX   | 0x0YYYYY          | UNKNOWN
   ...
   ```

## How to find write sites

The instruction `LD (0xD007CA),HL` in eZ80 ADL mode encodes as: `ED 07 CA 07 D0` (wait — let me be precise).

Actually, the eZ80 encoding for `LD (imm24),HL` in ADL mode is: `22 CA 07 D0` (opcode 0x22 + 24-bit address in little-endian = CA 07 D0).

There may also be `LD (imm24),IX` = `DD 22 CA 07 D0` or `LD (imm24),IY` = `FD 22 CA 07 D0`.

And for the `ED` prefix group: `ED 23` = `LD (imm24),HL` (alternate encoding in some eZ80 variants).

Search for ALL these patterns:
```javascript
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Pattern 1: LD (0xD007CA),HL = 22 CA 07 D0
// Pattern 2: LD (0xD007CA),IX = DD 22 CA 07 D0  
// Pattern 3: LD (0xD007CA),IY = FD 22 CA 07 D0
// Also check: ED-prefix stores if applicable
```

For each match, walk backward up to 32 bytes looking for `LD HL,imm24` = `21 xx yy zz` to find the handler value.
