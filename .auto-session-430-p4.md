# Task: Trace D141BE Data Source Buffer

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

Session 429 identified **D141BE** as a new RAM variable — a "data source buffer" referenced 9 times by the descriptor builder at 0x00CD7B (a 1394-byte function at 0x00CD7B-0x00D2EC). The descriptor builder parses incoming USB setup packets, and D141BE likely points to the incoming packet data.

## Deliverables

1. **Create `TI-84_Plus_CE/probe-phase430-trace-D141BE.mjs`**: A probe that:
   - Scans the entire 4MB ROM for ALL references to address 0xD141BE
   - For each reference, identify:
     - The ROM address where D141BE is referenced
     - Whether it's a read (LD r,(D141BE) or LD r,D141BE) or write (LD (D141BE),r)
     - The containing function (find the nearest function prologue or known function boundary)
   - Search patterns for D141BE (little-endian: BE 41 D1):
     - LD A,(nn): 0x3A BE 41 D1
     - LD (nn),A: 0x32 BE 41 D1
     - LD HL,(nn): 0x2A BE 41 D1 (or with ED prefix for other registers)
     - LD (nn),HL: 0x22 BE 41 D1
     - LD BC/DE/HL/IX/IY,nn (loading address): 0x01/0x11/0x21 BE 41 D1 (loading the address, not dereferencing)
   - Also check for references to D141BF and D141C0 (adjacent bytes — if D141BE is a 3-byte pointer, D141BF and D141C0 are the high bytes)

2. **Create `TI-84_Plus_CE/phase430-D141BE-report.md`**: A structured report with:
   - Total reference count (reads vs writes)
   - Who writes D141BE (what functions store values there?)
   - Who reads D141BE (what functions consume the value?)
   - Is it a 1-byte value, 2-byte, or 3-byte pointer?
   - What is the data flow: who sets it up → who consumes it?
   - Relationship to the descriptor builder at 0x00CD7B

## How to scan for references
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

// D141BE in little-endian = 0xBE, 0x41, 0xD1
const target = [0xBE, 0x41, 0xD1];

for (let i = 0; i < rom.length - 2; i++) {
  if (rom[i] === target[0] && rom[i+1] === target[1] && rom[i+2] === target[2]) {
    const opcode = rom[i-1]; // byte before the address
    const addr = i - 1; // likely instruction start
    console.log(`Reference at 0x${addr.toString(16).padStart(6,'0')}: opcode 0x${opcode.toString(16).padStart(2,'0')}`);
  }
}
```

- D141C0 (BE+2): might be highest byte of a 3-byte pointer
- D141BD (BE-1): adjacent below, context
