# Task: DECODE 0x005A75 VRAM ADDRESS COMPUTATION (instruction-by-instruction)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We've proven that calling the character renderer at 0x0059C6 produces real VRAM writes, but the renderer breaks after 2 characters because D0059C (at RAM address 0xD0059C) is used as a RELATIVE column pixel offset, not an absolute VRAM pointer.

The function at 0x005A75 is the actual character pixel renderer. It computes the VRAM write address INTERNALLY — it does NOT use D0059C as an absolute VRAM address. We need to decode exactly how it computes the VRAM position.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase480-decode-005A75.mjs` that:

1. Reads the ROM binary and does an instruction-by-instruction hex dump + manual decode of bytes from 0x005A75 to 0x005AC0 (75 bytes).
2. For each instruction, print the address, raw hex bytes, and a human-readable mnemonic.
3. Specifically look for:
   - Any `LD HL,(Dxxxxx)` instructions (opcode pattern: ED 27 xx xx xx in ADL mode, or 2A xx xx xx in Z80 mode) — these load from RAM variables
   - Any references to 0xD40000 (VRAM base) — bytes D4 00 00 or 00 00 D4
   - Any `LD HL,(D0059C)` — pattern would include bytes 9C 05 D0 or 9C 05 00
   - Any `LD HL,(D00595)` — bytes 95 05 D0 or 95 05 00
   - Any CALL instructions (CD xx xx xx) or JP instructions (C3 xx xx xx)
   - The MLT instruction (ED 6C) already known at 0x005A85

4. Also dump and decode the subroutine at 0x00596E (called from 0x005A85, the font base address adder) — decode 0x00596E through 0x005990 (~35 bytes).

## eZ80 instruction reference (key opcodes)
- 2A xx xx xx = LD HL,(xxxx) [ADL mode, 3-byte address little-endian]
- 22 xx xx xx = LD (xxxx),HL
- ED 27 xx xx xx = LD HL,(xxxx) [mixed mode .LIL prefix]
- ED 6C = MLT HL (multiply H*L → HL)
- CD xx xx xx = CALL addr
- C3 xx xx xx = JP addr
- C9 = RET
- 06 xx = LD B,xx
- 1E xx = LD E,xx
- DD prefix = IX instructions
- FD prefix = IY instructions
- 49 prefix = .SIS mode prefix
- 52 prefix = .LIS mode prefix
- 5B prefix = .LIL mode prefix
- 40 prefix = .SIL mode prefix
