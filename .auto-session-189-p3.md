## Context

- Digits 0-9, operators +-*/^, decimal point, parens, brackets, braces

## Missing tokens to add

Add these commonly-used TI-84 tokens that students would want in a calculator:

### 1. iPart( and fPart( (integer/fractional part)
- iPart(: token 0xB4 (tIPart) — single byte function token
- fPart(: token 0xB5 (tFPart) — single byte function token

### 2. sum( and prod(  
- sum(: two-byte token [0xBB, 0x30] (tSum)
- prod(: two-byte token [0xBB, 0x2F] (tProd)

### 3. dim( (dimension/length of list)
- dim(: two-byte token [0xBB, 0x04] (tDim)

### 4. Σ (summation notation alias for sum)
- Map Unicode Σ (U+03A3) to the same sum token

### 5. ᴇ (small-caps E for EE/scientific notation display)
- Already handled via 'E' → 0x3B, just ensure 'EE' doesn't double-match

### 6. ≤, ≥, ≠ (comparison operators)
- ≤: token 0x6C (tLE)
- ≥: token 0x6E (tGE)  
- ≠: token 0x6F (tNE)
- Also map textual aliases: "<=", ">=", "!=" or "<>"

### 7. → (STO arrow)
- →: token 0x04 (tStore)
- Also map "->" text alias
