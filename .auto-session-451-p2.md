# Task: Headless Coldboot End-to-End Test (Phase 451)

Create `TI-84_Plus_CE/probe-phase451-coldboot-e2e.mjs` — a headless test that exercises the full boot path from address 0x000000 through to the home screen, then injects a single keypress, to verify the trampoline fix (session 450) and SIL/LIS prefix fix (session 449) work together in a clean cold boot.

## Context

Session 449 fixed a critical SIL/LIS prefix word-size swap bug in the transpiler. Session 450 fixed a critical RAM trampoline bug (`cpu.mem[sp]` → `memory[sp]`). Together, these should make the browser-shell cold boot work much better. This probe tests that path headlessly (no browser needed).

## What to build

A probe that:

1. **Loads ROM and transpiled blocks** (same pattern as all other probes — see `probe-phase449-per-iteration-inject.mjs` for the import pattern)

2. **Runs a full cold boot** from 0x000000 through:
   - BOOT_ENTRY (0x000000) — 20k steps
   - KERNEL_INIT_ENTRY (0x08C331) — 100k steps  
   - POST_INIT_ENTRY (0x0802B2) — 100 steps
   - Stage entries: [0x0A2B72, 0x0A3301, 0x0A29EC, 0x0A2854] — 50k steps each
   - Reset CPU state between stages (same as probe-phase449 does)

3. **Pre-copies ROM 0x000EBB→0xD18C22** (90 bytes) after stages complete

4. **Sets OS flags**: D14091=1, D177B7=0x55, D177BA=0

5. **Runs event loop** from 0x003A73 for 100k steps with `diHaltBypass: true`

6. **Injects key "1"** (scan code 0x12):
   - Set D00587=0x12
   - Set IY bit 3: mem[0xD00080] |= 0x08
   - Clear D177BA=0
   - Run from 0x003A73 for 500k steps with diHaltBypass: true

7. **Reports**:
   - Boot completion status for each stage
   - VRAM hash before and after event loop (baseline)
   - VRAM hash before and after key injection
   - Whether key was consumed (D00587 cleared, IY bit 3 cleared)
   - Final PC and termination reason
   - Total unique blocks executed (track via onBlock callback)
   - Any errors/crashes encountered

8. **Assertions** (print PASS/FAIL for each):
   - Boot completes without throw
   - Event loop runs >1000 steps
   - Key "1" is consumed (D00587=0 and IY bit 3 cleared after processing)
   - VRAM changes after key injection
   - No unhandled errors

## Constraints

- Do NOT modify any existing files. Create only `TI-84_Plus_CE/probe-phase451-coldboot-e2e.mjs`.
- Use `createPeripheralBus({ pllDelay: 2, timerInterrupt: false })` — timer IRQ causes infinite loop.
- The probe must be runnable with: `node TI-84_Plus_CE/probe-phase451-coldboot-e2e.mjs`
- Use the `onMissingBlock` option to log missing blocks but continue (don't crash).

## Success criteria

The probe runs to completion without crashing and prints clear PASS/FAIL assertions.
