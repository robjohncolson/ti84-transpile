# Task: Find Home Screen Mode Table Installer (who writes D1441D)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

Session 445 discovered that D1441D is the **mode-specific handler table pointer**. The key dispatch path uses it: 0x05D58F reads D1441D to find the handler table for the current mode (home screen, graph, program editor, etc.). The function 0x05D5C2 is believed to be the installer that writes to D1441D.

**Critical need**: The workflow probe must know what value the home screen mode stores at D1441D so it can populate this pointer for key processing to work.

## Task
Find all code that writes to RAM address D1441D and identify which write installs the home screen handler table.

### How to search
1. Search the ROM for the byte pattern that writes to D1441D:
   - `LD (D1441D),A` = 0x32 0x1D 0x44 0xD1 (4 bytes)
   - `LD (D1441D),HL` = 0x22 0x1D 0x44 0xD1 (4 bytes)
   - Also check for indexed writes via IX/IY

```javascript
const fs = require('fs');
const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
// Search for 0x32 0x1D 0x44 0xD1 (LD (D1441D),A)
// Search for 0x22 0x1D 0x44 0xD1 (LD (D1441D),HL)
// Search for 0xED 0x63 0x1D 0x44 0xD1 (LD (D1441D),HL with ED prefix in eZ80)
for (let i = 0; i < rom.length - 4; i++) {
  if (rom[i] === 0x32 && rom[i+1] === 0x1D && rom[i+2] === 0x44 && rom[i+3] === 0xD1) {
    console.log(`LD (D1441D),A at 0x${i.toString(16).padStart(6,'0')}`);
  }
  if (rom[i] === 0x22 && rom[i+1] === 0x1D && rom[i+2] === 0x44 && rom[i+3] === 0xD1) {
    console.log(`LD (D1441D),HL at 0x${i.toString(16).padStart(6,'0')}`);
  }
}
```

2. Also search for references to 0x05D5C2 (the suspected installer function):
   - `CALL 0x05D5C2` = 0xCD 0xC2 0xD5 0x05

3. For each write site, disassemble the surrounding context to determine what value is being written and what mode is being installed.
