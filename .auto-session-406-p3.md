# Task: Map 0xD177B8 and 0xD177B9 Consumers

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB eZ80 binary).

The notification system writes two output registers:
- **0xD177B8** — payload byte (written by the _seqcase handlers at 0x049D3A)
- **0xD177B9** — type byte (written by the notification state commit at 0x049CCA)

These are the notification system's OUTPUT. We need to find who READS them — which OS subsystems consume the stored type and payload after a notification fires.

## Task
Create a probe script `TI-84_Plus_CE/probe-phase406-notification-consumers.mjs` that:

1. Reads the ROM binary directly (use `fs.readFileSync('TI-84_Plus_CE/ROM.rom')`)
2. Scans the ENTIRE 4MB ROM for ALL references to addresses 0xD177B8 and 0xD177B9
3. For each reference found, determine:
   - The instruction type (LD A,(nn), LD (nn),A, LD HL,nn, etc.)
   - Whether it's a READ or WRITE
   - The ROM address where the reference occurs
   - The surrounding context (disassemble 5 instructions before and after)
4. Categorize references by:
   - WRITERS (stores TO these addresses) — these are the notification system internals
   - READERS (loads FROM these addresses) — these are the CONSUMERS we want to find
5. For each READER, identify what function/region it belongs to (group by ROM region)

Search patterns for 0xD177B8 (little-endian: B8 77 D1):
- LD A,(0xD177B8) = 0x3A 0xB8 0x77 0xD1
- LD (0xD177B8),A = 0x32 0xB8 0x77 0xD1
- LD HL,0xD177B8 = 0x21 0xB8 0x77 0xD1
- LD DE,0xD177B8 = 0x11 0xB8 0x77 0xD1
- LD BC,0xD177B8 = 0x01 0xB8 0x77 0xD1

Search patterns for 0xD177B9 (little-endian: B9 77 D1):
- Same instruction prefixes but with B9 77 D1

Also check for HL-indirect access patterns where HL is loaded with nearby addresses and then indexed.

Also create `TI-84_Plus_CE/phase406-notification-consumers-report.md` with findings.

## eZ80 Notes
- eZ80 ADL mode uses 3-byte addresses
- LD A,(nn) = 0x3A lo mid hi
- LD (nn),A = 0x32 lo mid hi  
- LD HL,nn = 0x21 lo mid hi
- LD DE,nn = 0x11 lo mid hi
- LD BC,nn = 0x01 lo mid hi
- Also check for IX/IY-relative access if a register is loaded with a base address near 0xD177B8
