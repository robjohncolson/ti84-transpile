## Background
- 0x003A0F is the OS error handler entry point (confirmed by ROM text "ERROR!" at 0x003A92)
- At 0x003A70: `LD B,0x64` (100 iterations), then loop: `PUSH BC → CALL 0x003D5A → POP BC → OR A → JR NZ 0x003A7D → DJNZ 0x003A72`
- 0x003D5A is _GetCSC — reads scan code from D00587 (returns in A, 0 = no key)
- At 0x003A7D: `CALL 0x001713` (ISR guard, checks D177BA) → `JP NZ 0x001933` (sleep-until-IRQ)
- D177BA = 0x7F after boot → always NZ → always goes to sleep
- The key-found path (OR A → JR NZ) AND the timeout path (DJNZ fall-through) BOTH converge at 0x003A7D
- Key scan code in A is LOST after CALL 0x001713 because 0x001713 doesn't use A
- D00587 holds the scan code (0x92 = key "9" from keyboard matrix)
