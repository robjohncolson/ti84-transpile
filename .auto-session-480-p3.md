# Task: TRACE 0x08A7BE AND 0x08A6F0 — HIGHER-LEVEL MODE DISPATCH

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary).

Session 479 found the mode dispatch chain:
- 0x08B0A2/0x08B0A6 → dispatches modes (H→0x09E30C, W→0x08AA67, K→0x09E3B4, S→0x09E2BF)
- 0x08B0A2 has 6 callers including 0x08A809
- 0x08A809 is inside function 0x08A7BE
- 0x08A7BE is called from 0x08A6F0 and 0x08B2AE

We need to decode 0x08A6F0 — this may be the TOP-LEVEL function that the OS scheduler calls to enter a mode. Finding this reveals the complete boot→scheduler→mode dispatch→home screen chain.

## What to do
Create `TI-84_Plus_CE/probe-phase480-higher-mode-dispatch.mjs` that:

1. Reads the ROM binary directly (no cpu-runtime needed)
2. Hex-dumps and manually decodes these ROM regions:
   - 0x08A6F0 through 0x08A780 (~144 bytes) — the higher-level mode dispatch entry
   - 0x08A7BE through 0x08A830 (~114 bytes) — contains 0x08A809 which calls 0x08B0A2
   - 0x08B2AE through 0x08B310 (~98 bytes) — second caller of 0x08A7BE
3. For each region, print: address, raw hex, and best-effort mnemonic
4. Search the ENTIRE ROM (0x000000-0x3FFFFF) for CALL/JP references to:
   - 0x08A6F0 (CALL = CD F0 A6 08, JP = C3 F0 A6 08)
   - 0x08A7BE (CALL = CD BE A7 08, JP = C3 BE A7 08)
   - 0x08B2AE (CALL = CD AE B2 08, JP = C3 AE B2 08)
5. Print all found callers with their addresses

## eZ80 reference
- CD xx xx xx = CALL addr (little-endian, 3-byte address in ADL mode)
- C3 xx xx xx = JP addr
- C9 = RET
- CB = bit/rotate prefix
- DD = IX prefix
- FD = IY prefix (FD CB xx = IY bit ops)
- ED = extended prefix
- 49/40/52/5B = mode prefixes (.SIS/.SIL/.LIS/.LIL)

Note: eZ80 ADL mode addresses are 3 bytes little-endian. CALL 0x08A6F0 = CD F0 A6 08.

## Template (MUST follow)
```javascript
import { readFileSync } from "node:fs";

const rom = readFileSync(new URL("./ROM.rom", import.meta.url));
const hex = (v, w=6) => `0x${(v>>>0).toString(16).toUpperCase().padStart(w,'0')}`;

function dumpRange(start, end, label) {
  console.log(`\n=== ${label} (${hex(start)}-${hex(end)}) ===`);
  for (let i = start; i < end; ) {
    const byte = rom[i];
    // Print address and raw bytes
    let line = `${hex(i)}: `;
    // Print up to 4 raw hex bytes
    const rawBytes = [];
    for (let j = 0; j < 4 && i + j < end; j++) {
      rawBytes.push(rom[i + j].toString(16).padStart(2, '0'));
    }
    line += rawBytes.join(' ');
    console.log(line);
    i++; // advance by 1 for raw dump (let human decode)
  }
}

function searchForCallsTo(targetAddr, label) {
  const lo = targetAddr & 0xff;
  const mid = (targetAddr >> 8) & 0xff;
  const hi = (targetAddr >> 16) & 0xff;
  console.log(`\n=== Searching for CALL/JP to ${label} (${hex(targetAddr)}) ===`);
  for (let i = 0; i < 0x400000 - 3; i++) {
    if ((rom[i] === 0xCD || rom[i] === 0xC3) && rom[i+1] === lo && rom[i+2] === mid && rom[i+3] === hi) {
      const op = rom[i] === 0xCD ? 'CALL' : 'JP';
      console.log(`  ${hex(i)}: ${op} ${hex(targetAddr)}`);
    }
  }
}

// Dump regions
dumpRange(0x08A6F0, 0x08A780, "0x08A6F0 HIGHER-LEVEL MODE DISPATCH");
dumpRange(0x08A7BE, 0x08A830, "0x08A7BE CONTAINS 0x08A809 CALLER");
dumpRange(0x08B2AE, 0x08B310, "0x08B2AE SECOND CALLER OF 0x08A7BE");

// Search for callers
searchForCallsTo(0x08A6F0, "08A6F0");
searchForCallsTo(0x08A7BE, "08A7BE");
searchForCallsTo(0x08B2AE, "08B2AE");
```
