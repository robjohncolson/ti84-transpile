# Task: Decode 0x092F35 (InsertMem-based content scroll)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript blocks. You need to decode the function at ROM address 0x092F35.

Session 521 identified that 0x092F35 is called by 0x0A2032 (line wrap/scroll) in "scroll mode A". It's described as an InsertMem-based content scroll — the only remaining unknown in the scroll mechanism.

Related decoded functions:
- 0x0A2032 = line wrap/scroll (session 520): zeroes curCol, IY+13 bit 2 gates scroll, two scroll modes, LDIR row shift
- 0x0A3126 = display scroll (session 521): dual-layer pixel LDIR/LDDR at D40000 + text LDIR at D006BF
- 0x0A321D = edit-buffer scroll: 26-col LDDR + space fill

## Deliverable
Create a probe file at `TI-84_Plus_CE/probe-phase522-decode-092F35-insertmem-scroll.mjs` that:
1. Boots the OS to the home screen (use the standard boot sequence from existing probes like `probe-phase521-decode-composite-refresh.mjs` as a template)
2. Disassembles the function at 0x092F35 by reading ROM bytes and decoding eZ80 instructions
3. Traces all CALLs, JPs, JRs from the function
4. Reports:
   - Full instruction listing with addresses
   - All RAM addresses read/written
   - All subroutine calls
   - Register usage pattern
   - How InsertMem is used (look for LDIR/LDDR patterns, HL/DE/BC setup for block moves)

## Template
Base your probe on existing probes in the `TI-84_Plus_CE/` directory. Key patterns:
- Import from `./cpu-runtime.js` and `./peripherals.js`
- Use `createPeripheralBus({ timerInterrupt: false })` 
- The ROM is at `./ROM.rom` (read with fs.readFileSync)
- Use `rom[addr]` to read ROM bytes, `rom[addr] | (rom[addr+1] << 8)` for 16-bit, etc.
- Decode eZ80 instructions manually by reading opcode bytes
- Report findings via console.log

## Constraints
- Do NOT modify any existing files
- Do NOT touch cpu-runtime.js, peripherals.js, browser-shell.html, or the transpiler
- The probe should be self-contained and runnable via `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase522-decode-092F35-insertmem-scroll.mjs`
- Focus on static disassembly of 0x092F35 and nearby code (follow CALLs 1 level deep)

## Success criterion
The probe runs without error and produces a clear disassembly of 0x092F35 showing:
- The function's purpose (InsertMem wrapper, scroll helper, etc.)
- Block move operations (LDIR/LDDR) with source/dest/length
- All subroutine calls with their purpose if identifiable
- RAM addresses accessed
