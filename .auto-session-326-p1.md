If the decoder is not easily importable, do manual byte-level decoding. Key opcodes:
- 0xCD = CALL nn (3-byte LE address follows)
- 0xC9 = RET
- 0xC3 = JP nn
- 0x18 = JR d (signed offset)
- 0x21 = LD HL,nn (3-byte)
- 0xED 0xB0 = LDIR
- 0x3E = LD A,n
