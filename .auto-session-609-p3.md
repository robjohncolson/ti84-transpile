## VRAM layout
- Base address: 0xD40000
- 320×240 pixels, 16-bit RGB565 (little-endian)
- Row stride: 640 bytes
- Pixel at (row, col) = D40000 + row*640 + col*2
- White = 0xFFFF (both bytes 0xFF)
