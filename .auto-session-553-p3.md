## What we know
- 0x08C308 is called by the 16-bit color rendering path in the character blit loop (0x0A2618-0x0A2694).
- The blit loop has three rendering paths based on IY+0x4A flags:
  - Path 1 (BIT 5): monochrome
  - Path 2 (BIT 6): 4-bit color/bold
  - Path 3 (default): 16-bit color — this is where 0x08C308 is called
- After the call, the code writes pixel pairs as E/D (foreground) or C/B (background) — 16-bit color values.
- The TI-84 Plus CE uses RGB565 format (5 bits red, 6 bits green, 5 bits blue packed into 16 bits).
- The function likely converts a color index/code into actual RGB565 foreground and background pixel values.

## eZ80 reference
- LD DE,(nn) = ED 1B nn nn nn (load 24-bit from memory to DE)
- LD BC,(nn) = ED 0B nn nn nn (load 24-bit from memory to BC)
- LD A,(nn) = 3A nn nn nn (load byte from memory)
- For 16-bit loads in SIS mode (short): LD DE,(nn) = ED 1B nn nn (2-byte address)
- Known color-related RAM: D02688 (display pointer), D008D5 (y-coord), D0059C (framebuffer ptr)
