## Background
D1407C is a RAM byte in the D14070-D1407F USB state block. Session 438 discovered that D1407E (the pipe-active flag) is co-written with D1407C at the pipe-activation sites (0x00C7CD + mirror 0x02B633). At those sites, D1407C is CLEARED simultaneously when D1407E is set to 1, and port 0x3100 is read. D1407C is adjacent to D1407E in the pipe state group (D1407C/D1407E/D1407F/D14080/D140B2).

Also create a report file `TI-84_Plus_CE/phase439-trace-D1407C-report.md` with your findings.

## eZ80 Encoding Notes
- eZ80 is little-endian, 24-bit addresses
- `LD A,(D1407C)` = `3A 7C 40 D1` (opcode 3A + 3-byte LE address)
- `LD (D1407C),A` = `32 7C 40 D1` (opcode 32 + 3-byte LE address)
- `LD HL,(D1407C)` = `2A 7C 40 D1` (opcode 2A + 3-byte LE address)
- `LD (D1407C),HL` = `22 7C 40 D1` (opcode 22 + 3-byte LE address)
- The ROM banks mirror: 0x00xxxx, 0x02xxxx, 0x04xxxx often contain duplicated code. Count unique logical sites by deduplicating across banks.
- `XOR A` (opcode AF) before a store means writing 0x00
- `OR A` (opcode B7) after a load is a zero-test (sets Z flag if A==0)
