# Task: Find who calls the jump table at 0x021AB8

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We've identified a computed jump table at ROM address 0x021AB8 containing 16 JP instructions (each 4 bytes: C3 + 3-byte little-endian address). The first two entries both jump to 0x030078 (the key wait loop). Finding WHO dispatches through this table reveals how the OS enters different mode handlers (home screen, graph, etc.).

The table has ZERO direct references — no instruction in the ROM does `JP 0x021AB8` or `CALL 0x021AB8`. It must be accessed via computed indexing: some code loads a base address near 0x021AB8, multiplies a mode index by 4, and does `JP (HL)` or similar indirect jump.

## Deliverable
Create a probe file at `TI-84_Plus_CE/probe-phase469-jump-table-dispatcher.mjs` that:

1. Searches the ROM binary for any instruction that references address 0x021AB8 or nearby (0x021AB0-0x021B00 range). Look for:
   - 3-byte address patterns: bytes `B8 1A 02` (little-endian 0x021AB8) anywhere in ROM
   - Nearby base addresses like `B0 1A 02`, `A8 1A 02`, `A0 1A 02` that could be table base
   - Also search for `21 B8 1A 02` (LD HL, 0x021AB8) and variants with IX/IY

2. For each match found, print the ROM address of the match and the surrounding 32 bytes (16 before, 16 after) in hex.

3. Also search for "JP (HL)" instruction (opcode 0xE9) within 64 bytes of any reference to the table base address. In eZ80, JP (HL) = E9. Also check for JP (IX) = DD E9 and JP (IY) = FD E9.

4. Search for references to address 0x021A00 - 0x021AFF range more broadly (the table might be part of a larger structure). Look for the byte pattern `1A 02` (the high two bytes of any address in the 0x021Axx page) preceded by any low byte and an opcode that loads an address (21=LD HL, DD 21=LD IX, FD 21=LD IY, 01=LD BC, 11=LD DE, CD=CALL, C3=JP).

5. Print a summary of all findings.
