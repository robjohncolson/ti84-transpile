# Task: Decode 0x07C8B7 — FP normalize phase 3

## Context
This is a TI-84 Plus CE ROM transpilation project. We're decoding eZ80 machine code from ROM.rom.

Session 529 identified 0x07C8B7 as the third stage of the multi-phase normalization pipeline in the matrix/list FP handler (0x07D27B). It was described as: "RES 6,(IY+14); reversed OP order check". We need a full decode.

## What to do

1. Create a probe file `TI-84_Plus_CE/probe-phase530-decode-07C8B7-fp-norm-phase3.mjs` that:
   - Reads ROM bytes from 0x07C8B7 through 0x07C950 (153 bytes — generous window)
   - Disassembles them instruction-by-instruction
   - Identifies all CALL/JP/JR targets
   - Finds the RET/JP that ends this function
   - Also dump bytes for any sub-functions called (especially anything related to OP1/OP2 comparison or swapping)

2. Use the same probe template as `TI-84_Plus_CE/probe-phase529-decode-07CBB5-fp-normalize-core.mjs` (read it for reference).

3. Run the probe: `node scripts/run-probe.mjs --max-time 180 TI-84_Plus_CE/probe-phase530-decode-07C8B7-fp-norm-phase3.mjs`

4. Report: all instructions, CALL targets, function boundary, and purpose analysis.

## Key reference
- ROM file: `TI-84_Plus_CE/ROM.rom`
- eZ80 little-endian, 24-bit addresses
- IY typically points to D00080 (flags base), so IY+14 = D0008E
- RES 6,(IY+14) = clear bit 6 of D0008E
- OP1 at D005F8, OP2 at D00603, OP3 at D0060E
- Known related functions: 0x07CAB9 (phase 1), 0x07CA48 (phase 2), 0x07F9D9 (copy OP2→OP3)
- "Reversed OP order" suggests it checks/swaps OP1 vs OP2 ordering
