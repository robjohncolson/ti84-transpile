# Task: Test with D000C6 Refresh + Character Output Setup

## Context
You are working on a TI-84 Plus CE ROM transpiler project. The ROM is lifted to JavaScript.

In session 477, we got 280 VRAM bytes changed — but ALL were from screen fill (`0x09EF44`), not character output (`0x0059C6` had 0 hits). The screen fill clears white to black (0xFF→0x00). We want actual TEXT RENDERING.

The character output function at `0x0059C6` needs:
- A = character code to print (e.g., 0x48 = 'H', 0x30 = '0', 0x20 = space)
- D0059C = valid VRAM address (session 477 computed it to 0xD42A42)
- D0058C = cursor column position
- D0058E = cursor row position
- D00596 = current column counter (compared to 0x1A = 26 chars per line)

The character renderer at `0x005A75` uses font table at `0x1C00 + charcode` and writes 16 pixel rows to VRAM.

## What to do

Create: `TI-84_Plus_CE/probe-phase478-char-output-test.mjs`

This probe should directly call `0x0059C6` with a character to see if it writes to VRAM.

### Setup
Use the standard 3-stage boot from `TI-84_Plus_CE/probe-phase477-full-mode-setup.mjs`:
1. z80 boot: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
2. Kernel init: `executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`
3. Post-init: `executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`

After boot, set up display state:
```javascript
// Set VRAM address pointer (D0059C = 0xD40000, the VRAM start)
mem[0xD0059C] = 0x00;
mem[0xD0059D] = 0x00;
mem[0xD0059E] = 0xD4;

// Cursor position
mem[0xD0058C] = 0x00;  // col 0
mem[0xD0058E] = 0x00;  // row 0
mem[0xD00596] = 0x00;  // column counter = 0

// D0058B (set by 0x08BF22 to 0x70 in session 475)
mem[0xD0058B] = 0x70;

// IY setup
cpu.mbase = 0xD0;
cpu._iy = 0xD00080;
cpu.halted = false;
cpu.iff1 = 0;
cpu.iff2 = 0;
```

### Test 1: Direct CALL to 0x0059C6 with A='H' (0x48)
Set A register to 0x48, set up SP with sentinel, run from 0x0059C6:
```javascript
cpu._a = 0x48 << 24;  // A register in high byte
cpu.sp = STACK_RESET_TOP - 3;
mem[cpu.sp] = 0xFF; mem[cpu.sp + 1] = 0xFF; mem[cpu.sp + 2] = 0xFF;
```
Run: `executor.runFrom(0x0059C6, 'adl', { maxSteps: 5000, maxLoopIterations: 100 })`

After: check VRAM for changes. Snapshot VRAM before and diff after.

### Test 2: Multiple characters
After Test 1, reset A to 0x49 ('I'), run 0x0059C6 again. Then 0x20 (space). Check VRAM after each.

### Test 3: Track what 0x005A75 (font renderer) does
Add the PC `0x005A75` to tracked PCs. Log its hit count. Also log `0x005A20` (padding) and `0x005A02` (column tracking).

### Output
- VRAM bytes changed after each character
- Hit counts for 0x0059C6, 0x005A75, 0x005A20, 0x005A02
- Hex dump of first 64 VRAM bytes that changed (show address + before + after)
- Post-run D0059C value (should advance after each character)
- Post-run D00596 value (column counter)

### Template
Use `createExecutor` and `createPeripheralBus` from `cpu-runtime.js` and `peripherals.js`. Use `timerInterrupt: false` for this probe since we're calling functions directly, not running the event loop.

```javascript
#!/usr/bin/env node
import fs from 'fs';
import path from 'path';
import { fileURLToPath, pathToFileURL } from 'url';
import { createExecutor } from './cpu-runtime.js';
import { createPeripheralBus } from './peripherals.js';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const MEM_SIZE = 0x1000000;
const STACK_RESET_TOP = 0xD1A87E;
const VRAM_START = 0xD40000;
const VRAM_END = 0xD65800;

const mem = new Uint8Array(MEM_SIZE);
const rom = fs.readFileSync(path.join(__dirname, 'ROM.rom'));
mem.set(rom.subarray(0, MEM_SIZE), 0);

const romModule = await import(pathToFileURL(path.join(__dirname, 'ROM.transpiled.js')).href);
const BLOCKS = romModule.PRELIFTED_BLOCKS;
const peripherals = createPeripheralBus({ timerInterrupt: false });
const executor = createExecutor(BLOCKS, mem, { peripherals });
const cpu = executor.cpu;

function hex(v, w = 2) { return '0x' + (v >>> 0).toString(16).toUpperCase().padStart(w, '0'); }
```
