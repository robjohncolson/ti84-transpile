# Task: Map the 0x007B00+ LCD Port Wrapper Family

## Context
The TI-84 Plus CE ROM transpilation project lifts eZ80 ROM machine code into runnable JavaScript. This is a pure investigation/disassembly task — produce a report, do NOT modify any source files.

## Background
Session 321 found that the LCD sync function 0x010A3C calls port 0x8040 via wrapper function 0x007B05. This wrapper is part of a family of 10+ small functions at 0x007B00+ that wrap LCD DMA controller port I/O. The family covers:
- **Read ports**: 0x8000, 0x8004, 0x8008, 0x800C, 0x8040
- **Write ports**: 0x8024, 0x8028, 0x802C, 0x8030

Session 321 also noted that 0x007B05 has a paranoid BC-corruption check (RST 0x08 trap).

## What to Investigate

### 1. Map all functions in the 0x007B00-0x007C00 region
- Read `TI-84_Plus_CE/ROM.rom` (4MB binary, little-endian eZ80)
- Start at offset 0x007B00 and disassemble forward
- Each wrapper is likely very short (5-15 bytes): load port address, do IN/OUT, RET
- Document each function's:
  - Start address
  - Which port it accesses (read or write)
  - Parameters (if any — value to write, etc.)
  - Return value (for reads)
  - Any special checks (like the BC-corruption RST 0x08 trap in 0x007B05)

### 2. Identify what the write ports control
Session 321 identified read ports but the write ports' functions are unknown:
- 0x8024: ?
- 0x8028: ?
- 0x802C: ?
- 0x8030: ?

For each write port wrapper, look at its callers to determine what values are written and in what context. This tells us what the ports control (DMA base address? Transfer length? LCD configuration?).

### 3. Find all callers of each wrapper
For each wrapper function found, search for its CALL opcode in the ROM:
- `CD xx 7B 00` pattern for functions in 0x007Bxx range
- List caller addresses and group by subsystem

### 4. LCD DMA controller register map
Based on the wrappers, construct a register map for the LCD DMA controller at 0x8000-0x80FF:
- Which offsets are read registers vs write registers?
- What does each register likely control?
- Cross-reference with TI-84 CE hardware documentation if patterns match known DMA controller designs

## Tools Available
- ROM file: `TI-84_Plus_CE/ROM.rom` (read as binary)
- Use `node -e` with `fs.readFileSync` to read ROM bytes
- eZ80 opcodes for port I/O:
  - `DB xx` = IN A,(port8) — only for ports 0x00-0xFF
  - `ED 78` = IN A,(C) — port address in BC
  - `ED 79` = OUT (C),A — port address in BC
  - `01 xx xx xx` = LD BC,imm24
  - `C9` = RET
  - `CF` = RST 0x08
