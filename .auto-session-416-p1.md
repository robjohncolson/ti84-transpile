# Task: MAP D177BD 5-ENTRY FUNCTION POINTER TABLE

## Context
You are working on a TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

Session 415 discovered that 5 callers at ROM addresses 0x010269, 0x0102A4, 0x0102C9, 0x0102F2, 0x010389 each load IY from addresses D177BD, D177C0, D177C3, D177C6, D177C9 respectively before calling 0x002288 (a JP (IY) trampoline). This is a 5-entry function pointer table at D177BD, 3 bytes per entry, for per-channel notification dispatch.

## Task
Create a probe script `TI-84_Plus_CE/probe-phase416-D177BD-table.mjs` that:

1. **Disassembles each of the 5 caller sites** (0x010269, 0x0102A4, 0x0102C9, 0x0102F2, 0x010389) — read ~20 bytes before and after each to understand the full context. What sets up the call? What arguments are passed?

2. **Searches the ROM for ALL references to D177BD, D177C0, D177C3, D177C6, D177C9** — both reads (LD IY,(addr), LD BC,(addr), LD HL,(addr)) and writes (LD (addr),BC, LD (addr),HL, LD (addr),IY). Count readers vs writers for each slot.

3. **For each write site**, disassemble ~30 bytes of context to determine WHAT value is being written (a hardcoded ROM address? A register loaded from elsewhere?).

4. **Cross-reference** the 5 caller addresses with the notification dispatch table at 0x0120AA (session 409) and the notification channel system (Channels 1-3 at D1440E/D17779/D176C9).

## Deliverables

## Technical Details
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, little-endian eZ80)
- eZ80 addressing: 24-bit addresses, little-endian (low byte first)
- LD IY,(addr) encoding: FD 2A <addr-low> <addr-mid> <addr-high> (5 bytes in .LIL mode)
- LD (addr),IY encoding: FD 22 <addr-low> <addr-mid> <addr-high>
- LD BC,(addr): ED 4B <3-byte addr>
- LD (addr),BC: ED 43 <3-byte addr>
- 3-byte pointer slots: each D177BD+N*3 entry holds a 24-bit function pointer
