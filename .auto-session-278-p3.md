# Task: Trace 0x09DD62 — single caller of 0x09DEE0 (dispatch table reset)

## Context
In the TI-84 Plus CE ROM, 0x09DEE0 is the dispatch table reset function that:
- Resets ALL THREE table pointers to sentinel 0xD3FFFF: D02590, D0259A, D0259D
- Also resets D02587/D0258A/D0258D/D025A0 to 0xD1A881
- Does NOT wipe D3Fxxx table data — just resets pointers
- After reset: calls 0x08A98F, 0x000600 (free RAM query), bounds check vs 0x0B0000, calls 0x04C9EA

Session 277 discovered that 0x09DEE0 has ONLY 1 CALLER in the entire ROM: **0x09DD62** (in the STAT region). That caller writes 0xFF to D0250F before calling 0x09DEE0.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase278-09dd62-stat-init.mjs` that:

1. **Static disassembly of 0x09DD62**: Read ROM bytes starting at 0x09DD62 and decode eZ80 ADL instructions for ~150 bytes (until RET or JP out of the local region). This is a STAT initialization function. Log each instruction. Key things to look for:
   - What does it do BEFORE calling 0x09DEE0 (the table reset)?
   - What does it do AFTER 0x09DEE0 returns?
   - Does it write to other D025xx addresses?
   - Does it call other known functions (0x0846EA FindSym, 0x08267D VAT cache builder, 0x091E13 context installer)?
   - What is the function entry point? (scan backwards from 0x09DD62 for RET/JP that ends previous function)

2. **Find callers of 0x09DD62's parent function**: Once you identify the entry point of the function containing 0x09DD62, scan the ROM for CALL/JP to that entry point. This tells us what OS path triggers the dispatch table reset.

3. **Dynamic trace**: Cold boot (timer IRQ disabled), set PC = entry point of the function containing 0x09DD62. Trace 300 steps, logging:
   - Each block visited
   - All writes to D025xx range (the dispatch table pointer cluster)
   - All writes to D0250F (the flag that gets set to 0xFF)
   - Any CALL targets to known functions

4. **D0250F investigation**: Search the ROM for ALL writes to address D0250F:
   - Pattern: `LD (0xD0250F),A` = opcode `32 0F 25 D0` (4 bytes, ADL)
   - Also check for `LD (HL),value` patterns where HL=D0250F
   - Report all write sites and what value they store
