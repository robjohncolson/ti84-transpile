## eZ80 Disassembly Notes
- eZ80 is little-endian, variable-length instructions
- CALL addr24: CD + 3-byte LE address (so CALL 0x007CAD = CD AD 7C 00)
- LD A,(addr24): 3A + 3-byte LE address
- LD (addr24),A: 32 + 3-byte LE address
- LD BC,(addr24): ED 4B + 3-byte LE address
- LD (addr24),BC: ED 43 + 3-byte LE address
- BIT/SET/RES n,A: CB + opcode byte
- IX-relative: DD prefix. LD A,(IX+d): DD 7E d
- RET: C9
- Search for callers by scanning ROM for bytes CD AD 7C 00
