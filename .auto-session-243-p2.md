# Task: Trace 0x0A33DA — last block in display chain before exit

## Context
Session 242 traced the display chain in the 0x0A3200-0x0A3500 range (23 unique blocks). The chain enters at step 4980 and exits at step 102296 to 0x04EE00 (handler return). The LAST block PC before exit was 0x0A33DA. We need to understand what this block does — it's the display chain termination point.

## What to do

1. Create a probe `TI-84_Plus_CE/probe-phase243-0a33da-display-chain-exit.mjs` that:
   - Uses the same boilerplate as `probe-phase242-0a32f9-display-chain.mjs` (reference probe from session 242)
   - Cold boots, kernel init, seeds edit buffer and gap buffer for home screen
   - Arms the key processing path to reach the display chain (use the same setup as session 241/242 probes — enter via 0x04EDD0 or 0x04ECCE with D003E0=0x00)
   - Runs enough steps to reach the display chain (~5000+ steps to get past VRAM fill)
   - When PC reaches 0x0A33DA region, captures:
     - Full register state (A, F, BC, DE, HL, IX, IY, SP)
     - Next 20 bytes of ROM at 0x0A33DA (raw hex dump for manual disassembly)
     - What address execution goes to AFTER 0x0A33DA (the exit target)
     - Any RAM writes in the 0x0A33DA block
     - VRAM changes (check 0xD40000-0xD52C00 region for writes)
   - Also traces the 3 blocks immediately before 0x0A33DA in the execution trace to show the approach path
   - Reports: block address, disassembly bytes, successor block, register state, RAM writes

2. Run the probe:
   ```bash
   node TI-84_Plus_CE/probe-phase243-0a33da-display-chain-exit.mjs
   ```
