# Task: Map the Full 0x000120-0x000198 Vector Table

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 324 identified that 0x000138 is vector #6 in a vector table starting around 0x000120, with 545 callers — it's a generic OS utility vector. We need to map ALL entries in this table to understand the full boot/dispatch architecture.

## Target
ROM region **0x000120 through 0x000198** — this appears to be an early vector table (possibly the eZ80 hardware vector table or an OS-defined jump table). Each entry is likely a 3-byte or 4-byte address (eZ80 uses 24-bit addresses).

## Deliverables
Create a probe file `TI-84_Plus_CE/probe-phase328-vector-table.mjs` that:

1. Reads the raw ROM bytes from 0x000120 to 0x000198 (120 bytes)
2. Dumps them in hex with annotations
3. Tries multiple interpretations:
   - As 3-byte little-endian addresses (eZ80 native, 40 entries in 120 bytes)
   - As 4-byte little-endian addresses (32 entries in 128 bytes — may extend slightly)
   - As JP instructions (0xC3 xx xx xx pattern — each JP is 4 bytes on eZ80)
4. For each valid-looking target address (in ROM range 0x000000-0x3FFFFF):
   - Disassemble the first 3-5 instructions at the target
   - Count how many callers reference this vector (grep the transpiled ROM or use the decoder)
   - Classify the vector: boot, ISR, BCALL, utility, LCD, keyboard, etc.
5. Cross-references with known vectors:
   - 0x000138 = vector #6 (545 callers, generic OS utility — session 324)
   - 0x0005CC = runtime BCALL vector #19 (session 324)
   - 0x000000 = reset vector
   - 0x000038 = RST 38h (mode 1 interrupt)
   - 0x000066 = NMI vector

6. Produces a summary table:
   ```
   Offset  | Address  | Target   | First Instructions | Callers | Classification
   0x000120| ...      | ...      | ...                | ...     | ...
   ```
