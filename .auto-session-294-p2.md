# Auto-session 294 P2: Disassemble 0x0AF408 (follow-on token dispatcher)

## Context
The TI-84 Plus CE OS token dispatch pipeline has been traced:
- Key scan codes are stored in D0058C
- Dispatchers like 0x088657 and 0x08C4E9 normalize scan codes into D0058E (keyExtend) values
- Both dispatchers route to 0x0AF408 as the follow-on token dispatcher
- The calling convention is: A=0xFE, D0058E contains the normalized keyExtend value
- 0x0AF408 is where scan codes become actual OS token actions — this is the next major piece of the token pipeline

## Task
Create a probe file `TI-84_Plus_CE/probe-phase294-0af408-token-dispatch.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` directly (raw binary, 4MB)
2. Uses `TI-84_Plus_CE/ez80-decoder.js` to decode instructions starting at 0x0AF408
3. Follows the linear instruction stream (stop at RET/JP unconditional, note but continue through CALL and conditional branches)
4. For EACH instruction, check:
   - Does it read D0058E (keyExtend input)?
   - Does it use CP (compare) instructions? Log the comparison value — these likely form a dispatch table
   - Is it a CALL? Log the target address
   - Does it reference any D005xx or D007xx addresses (OS state)?
   - Is it a conditional JP/JR? Log condition and target
5. At conditional branches, follow the fall-through path but log the branch target
6. Build a "CP cascade map" — for each CP instruction, record: address, compared value, branch-if-equal target, fall-through address
7. Report: total instruction count, byte range, all CP values found, all CALL targets, the CP cascade map, all D005xx/D007xx references

## Reference
Use `TI-84_Plus_CE/probe-phase293-token-dispatcher-trace.mjs` as a template — it traces similar dispatcher structures at 0x088657 and 0x08C4E9.

## Key technical details
- ROM file is raw binary, byte at file offset N = ROM address N
- ez80-decoder.js: `decodeInstruction(romBuffer, address)` returns instruction object
- Instruction object has: `.tag`, `.length`, various operand fields depending on tag
- eZ80 addresses are 24-bit. ROM = 0x000000-0x3FFFFF
- CP instruction tag is typically 'alu-imm' with operation='cp' or 'alu-reg' with operation='cp'
- D0058E = keyExtend (input), D0058C = raw scan code
