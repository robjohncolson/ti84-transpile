# Task: Trace 0x05527B and 0x05522C — the LCD mode setters

## Context
This is a TI-84 Plus CE ROM transpilation project. We've decoded that 0xD000C6 bit 2 is the system-wide LCD color depth flag (0=16bpp, 1=8bpp). Session 392 found that only 2 ROM sites can change bit 2:
- SET 2 at 0x05527B (switches to 8bpp)
- RES 2 at 0x05522C (switches to 16bpp)

We need to understand what functions contain these instructions and when they trigger.

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase393-lcd-mode-setters.mjs` that:

1. **Disassemble function containing 0x05527B**: Scan backward from 0x05527B to find the function entry point. Scan forward to find the end. Decode all instructions. Identify what this function does — is it a "set 8bpp mode" routine? What else does it configure?

2. **Disassemble function containing 0x05522C**: Same treatment. Scan backward/forward for function boundaries, decode all instructions.

3. **Find all callers of both functions**: Search the ROM for CALL/JP instructions targeting each function's entry point.

4. **Key questions to answer**:
   - What function contains 0x05527B? (entry address, size, purpose)
   - What function contains 0x05522C? (entry address, size, purpose)
   - Are they the same function (with two paths) or different functions?
   - How many callers does each have?
   - Do these functions also configure LCD hardware (write to ports in 0xE000-0xE0FF range or similar)?
   - When would the OS switch between 8bpp and 16bpp? (graph mode? app mode?)

5. **Additional context**: Also decode what other bits of 0xD000C6 are modified near these sites. Session 392 found:
   - SET/RES 0 at 0x03007C/0x03009C/0x0300C6/0x0409A1
   - SET/RES 1 at 0x0551A4
   - SET/RES 7 at 0x0AE5AA/0x058C97
   Check if 0x0551A4 is in the same function as 0x05522C/0x05527B.

## eZ80 instruction reference
- SET 2,(IY+d) when IY points to 0xD00080, d=0x46 → address 0xD000C6
- But could also be SET 2,(HL) if HL=0xD000C6: CB D6
- Or direct memory: need to check the actual encoding at those addresses

## ROM file
Read from: `TI-84_Plus_CE/ROM.rom` (4MB binary, little-endian eZ80)

## Output format
Print structured findings to stdout. The probe should be runnable with `node TI-84_Plus_CE/probe-phase393-lcd-mode-setters.mjs`.
