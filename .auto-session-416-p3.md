# Task: MAP D176BD/D176F2/D176FB/D176FC/D1772D (0x0150C2 STATE VARIABLES)

## Context
You are working on a TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM is a 4MB eZ80 binary at `TI-84_Plus_CE/ROM.rom`.

Session 415 decoded 0x0150C2 (generic completion dispatcher, 103 bytes at 0x0150C2-0x015128). It uses 5 RAM addresses:
- D176BD — callback pointer (3-byte, read by 0x0150C2 to load dispatch target)
- D176F2 — state value (written conditionally with caller's argument)
- D176FB — cleared flag (unconditionally cleared by 0x0150C2)
- D176FC — gate flag (checked in Channel 3 special case: if D176FC==0 AND D1772D!=0)
- D1772D — secondary gate (checked with D176FC for Channel 3 path)

## Task
Create a probe script `TI-84_Plus_CE/probe-phase416-0150C2-state.mjs` that for EACH of the 5 RAM addresses:

1. **Searches for ALL references** in the 4MB ROM using these byte patterns:
   - Direct byte read: `3A <low> <mid> <high>` (LD A,(nn))
   - Direct byte write: `32 <low> <mid> <high>` (LD (nn),A)
   - 24-bit read: `ED 4B <3-byte addr>` (LD BC,(nn)), `2A <3-byte addr>` (LD HL,(nn)), `ED 5B` (LD DE,(nn))
   - 24-bit write: `ED 43 <3-byte addr>` (LD (nn),BC), `22 <3-byte addr>` (LD (nn),HL), `ED 53` (LD (nn),DE)
   - IY read/write: `FD 2A` / `FD 22` (LD IY,(nn) / LD (nn),IY)
   - Address load: `21 <low> <mid> <high>` (LD HL,nn — loading the address itself)

2. **Counts** readers vs writers for each address.

3. **For the top 5 most interesting write sites** of each address, disassembles ~20 bytes of surrounding context to determine WHAT value is being written and WHY.

4. **Determines lifecycle**: When is each variable initialized? When is it cleared? What values does it take?
