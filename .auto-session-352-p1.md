## How to Intercept I/O
The peripheral bus in `peripherals.js` has `read(port)` and `write(port, value)` methods. To intercept I/O, you need to wrap these methods on the returned peripheral object:

```javascript
const peripherals = createPeripheralBus({ timerInterrupt: false, pllDelay: 2 });
const ioLog = [];
const origRead = peripherals.read.bind(peripherals);
const origWrite = peripherals.write.bind(peripherals);
let currentStep = 0;

peripherals.read = (port) => {
  const val = origRead(port);
  ioLog.push({ dir: 'IN', port, value: val, step: currentStep });
  return val;
};
peripherals.write = (port, value) => {
  ioLog.push({ dir: 'OUT', port, value, step: currentStep });
  return origWrite(port, value);
};
```

Update `currentStep` in the `onBlock` callback.
