## Approach

1. **Binary search**: Read the ROM file (`TI-84_Plus_CE/ROM.rom`, 4MB) and scan for all `CALL` and `JP` instructions that target 0x03FA09.

   In eZ80 ADL mode:
   - `CALL nn` = opcode `0xCD` followed by 3-byte little-endian address (4 bytes total)
   - `JP nn` = opcode `0xC3` followed by 3-byte little-endian address (4 bytes total)
   - Conditional variants: `CALL cc,nn` opcodes are `0xC4, 0xCC, 0xD4, 0xDC, 0xE4, 0xEC, 0xF4, 0xFC`
   - Conditional `JP cc,nn` opcodes are `0xC2, 0xCA, 0xD2, 0xDA, 0xE2, 0xEA, 0xF2, 0xFA`

   Target address in little-endian: 0x03FA09 → bytes `09 FA 03`

2. **For each caller found**: Report the ROM address, the opcode (CALL/JP/conditional variant), and the bytes around it (±8 bytes hex dump for context).

3. **Cross-reference with transpiled blocks**: For each caller address, check if a transpiled block exists starting at or containing that address. 4. **Also search for indirect references**: Search for the 3-byte pattern `09 FA 03` anywhere in ROM (not just after CALL/JP opcodes) to find potential function pointer tables or jump tables that reference 0x03FA09.
