# Session 383 P4: Trace the scan code conversion step from _GetCSC to translation table

## Context
Session 382 found that:
- _GetCSC stores the REVERSED scan code (e.g., ENTER=0x29) at 0xD00587
- The translation table at 0x09F79B uses FORWARD formula indices (group*8+bit+1): ENTER would be index 0x09
- 0xD0058C (kbdKey, the TI-BASIC key code) is always 0x00 after key dispatch — the conversion never runs
- Only ONE location reads 0xD00587: the _GetCSC key-available path at 0x003D75
- The translation table lookup at 0x03010D has 0 CALL sites — it's reached by fall-through

The question: WHERE in the dispatch path does the reversed scan code (0x29) get converted to a forward index (0x09) for the translation table? The full dispatch path is:
```
0x003A73 (event loop) → 0x003D5A (_GetCSC returns 0x29 in A)
→ 0x003A77 (OR A, NZ) → 0x003A7D (CALL 0x001713)
→ 0x001853 (key handler) → 0x0158DE (post-key dispatcher)
→ ... eventually reaches 0x03010D (translation table lookup)
```

## Task
1. Write a probe `TI-84_Plus_CE/probe-phase383-scancode-trace.mjs` that:
   a. Boots the OS through phases 1-3 (standard coldboot, ~200K steps)
   b. Injects ENTER key (mem[0xD00587]=0x29, mem[0xD00080]|=0x08)
   c. Runs the event loop at 0x003A73 with DI+HALT bypass enabled
   d. Instruments reads of 0xD00587 AND writes to 0xD0058C
   e. At each step, checks register A and logs it when:
      - PC enters key dispatch blocks: 0x003A7D, 0x001713, 0x001853, 0x0158DE
      - PC is in the 0x030000-0x031000 range (near the translation table lookup)
   f. Tracks when/if the value in A changes from 0x29 to something else
   g. Reports the full trace of A through the dispatch path

2. Use `cpu-runtime.js` for execution. Example pattern:
   ```js
   import { createCPU } from './cpu-runtime.js';
   import { createPeripheralBus } from './peripherals.js';
   const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom');
   const transpiled = fs.readFileSync('TI-84_Plus_CE/ROM.transpiled.js', 'utf-8');
   const cpu = createCPU(rom, transpiled);
   const peripherals = createPeripheralBus({ timerInterrupt: false, gpioValue: 0xEE });
   cpu.peripherals = peripherals;
   ```

3. Key runtime methods:
   - `cpu.runFrom(addr, maxSteps, opts)` — opts can include `{ diHaltBypass: true, diHaltBypassEntry: 0x003A73 }`
   - `cpu.registers` — { A, F, B, C, D, E, H, L, IX, IY, SP, PC }
   - `cpu.memory` — Uint8Array, can read/write directly
