# Task: Decode 0xD141B5 Consumers — Who Reads the Final Key Output Buffer?

## Context
You are working on `C:/Users/rober/Downloads/Projects/school/ti84-transpile`, a TI-84 Plus CE ROM transpilation project.

0xD141B5 is the FINAL key output buffer in the TI-84 CE OS. After a key is fully processed by 0x03FB9A, the final key code is stored here (written only when currently zero — single-slot buffer). We need to find WHO READS 0xD141B5 to understand what happens after a key is fully processed (display update, cursor move, token insert, etc.).

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase399-D141B5-consumers.mjs` that:

1. Loads the ROM from `TI-84_Plus_CE/ROM.rom` (4MB file, raw binary)
2. Searches the ENTIRE ROM (0x000000–0x3FFFFF) for all instructions that reference 0xD141B5:
   - LD A,(0xD141B5): 3A B5 41 D1 (3-byte address, little-endian: B5 41 D1)
   - LD (0xD141B5),A: 32 B5 41 D1
   - LD HL,0xD141B5: 21 B5 41 D1
   - LD DE,0xD141B5: 11 B5 41 D1
   - LD BC,0xD141B5: 01 B5 41 D1
   - Also search for the raw 3-byte pattern B5 41 D1 to catch any other addressing modes
3. For each reference found, disassemble 32 bytes BEFORE and 16 bytes AFTER the reference to understand the context
4. Classify each reference as READER (loads from the address), WRITER (stores to the address), or POINTER (loads the address into a register)
5. Also search for references to adjacent addresses 0xD141B4 and 0xD141B6 (the OS may access these as part of a wider struct)
6. Print all findings organized by type (readers, writers, pointers)
