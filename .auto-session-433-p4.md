# Task: Trace 0x01253F (Short Status-Submit Gate)

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 machine code).

**0x01253F** is a sibling of **0x0125EA** (port-ready gate, 191 bytes, decoded in session 431). Both are called by the USB follow-up helper at 0x008527. Specifically:
- 0x0125EA is called in the normal path
- 0x01253F is called in the special 0x98 re-enumeration branch of 0x008527

We need to understand how 0x01253F differs from 0x0125EA.

## Reference: 0x0125EA (from session 431)
0x0125EA is a 191-byte port-ready gate at 0x0125EA-0x0126A8. It:
- Checks port 0x3082 for USB controller readiness
- Uses notification system (0x014E3F) with timeout
- Polls D1440F/D177B7 for abort conditions
- Returns success/failure status

## What to do
1. Disassemble ROM bytes starting at 0x01253F
2. Decode the full function until RET
3. Compare with 0x0125EA — what's different?
4. Document all CALL targets, RAM variables, port I/O
5. Search ROM for all callers (search for bytes encoding CALL 0x01253F = 0xCD 0x3F 0x25 0x01)

## eZ80 reference
- CALL nn = 0xCD followed by 3-byte LE address
- JP nn = 0xC3 followed by 3-byte LE address
- RET = 0xC9
- LD A,(nn) = 0x3A + 3-byte LE address
- LD (nn),A = 0x32 + 3-byte LE address
- IN A,(C) = 0xED 0x78
- OUT (C),A = 0xED 0x79
- RST 08h = 0xCF (BC assertion)
- __frameset at 0x00218A, notification installer at 0x014E3F
