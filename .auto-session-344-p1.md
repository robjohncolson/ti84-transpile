## Task

1. Loads the ROM and transpiled blocks

3. Traces execution step-by-step (per-block) up to 2000 blocks
4. For each block visited, log: PC, mode (adl/z80), block step count, and any OUT instructions (port, value)
5. Specifically track:
   - When/if execution reaches 0x0006F3 (RST 0x38 handler target)

   - What block/PC precedes each of those (the branch that led there)
   - All IN0/OUT0 port accesses (from the peripheral bus events)
6. Stop at: missing_block, halt at 0x0019B5, or 2000 blocks reached

Also do a STATIC disassembly of ROM bytes 0x000658-0x000750 (the boot entry code) — read the raw ROM bytes and decode eZ80 instructions manually (or via the decoder). Output: hex dump + instruction mnemonics for this ~248 byte region.
