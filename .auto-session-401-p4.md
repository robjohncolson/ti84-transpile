# Task: ADD 10 NEW TRANSPILER SEEDS

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The transpiler at `scripts/transpile-ti84-rom.mjs` lifts eZ80 machine code from `TI-84_Plus_CE/ROM.rom` into JavaScript. It uses a set of "seed" addresses — known function entry points — to start control-flow-guided disassembly.

Current state: 144,631 transpiled blocks, 707,098 covered bytes, ~95.92% true coverage.

## Task
1. Run the coverage gap analyzer to find uncovered regions:
```bash
node TI-84_Plus_CE/audit-true-uncovered.mjs
```

2. From the output, identify 10 uncovered ROM addresses that are likely function entry points. Good candidates:
   - Addresses that appear right after a RET (0xC9) or JP (0xC3) instruction in the ROM
   - Addresses referenced by CALL instructions from already-transpiled code
   - Addresses in the 0x000000-0x0BFFFF range (OS code region)
   - Avoid addresses in 0x0C0000+ (certificate/data region)

3. Read the ROM bytes at each candidate address to verify they look like valid code (not 0xFF padding or data tables).

4. Add the 10 new seed addresses to the `knownEntryPoints` array in `scripts/transpile-ti84-rom.mjs`. The array is near the top of the file. Add them in sorted order with a comment `// auto-session 401`.

5. Re-run the transpiler and verify:
```bash
node scripts/transpile-ti84-rom.mjs
```
Check that the block count increased and no errors occurred.

6. Run the golden regression to verify nothing broke:
```bash
node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
```
Confirm "26/26" or "PASS" in output.

7. Print a summary: which 10 addresses were added, new block count, new covered byte count.

## Constraints
- ONLY modify `scripts/transpile-ti84-rom.mjs` (adding seeds to knownEntryPoints)
- Do NOT modify any other files
- Do NOT add addresses >= 0x0C0000
- Do NOT add addresses that are already in knownEntryPoints
- If golden regression fails after adding seeds, remove the problematic seeds and retry

## Deliverables
- Modified `scripts/transpile-ti84-rom.mjs` with 10 new seeds
- Summary of results printed to stdout
