## Background
Session 507 traced D01EB1 write sites and found the PRIMARY descriptor populator chain:
- **0x07D583** = primary populator — checks D02032 bits 0/1/2 per cursor type, conditionally calls 0x07D577 → 0x07D83B which writes through HL pointer
- **0x07D577** = per-type writer called from 0x07D583
- **0x07D83B** = does the actual write through HL pointer into D01EB1/D01EBA/D01EDE descriptor blocks
- **D02032** = master gate — its bits 0/1/2 control which cursor types get descriptors populated

The descriptor blocks:
- D01EB1/D01ECC = cursor type 0 descriptor pair (HL/DE)
- D01EBA/D01ED5 = cursor type 1 descriptor pair
- D01EDE/D01EF9 = cursor type ≥2 descriptor pair

## Task

1. Read the raw bytes from ROM.rom starting at the function address
2. Decode each eZ80 instruction (the ROM uses eZ80 ADL mode — 24-bit addresses, 3-byte pointer loads)
3. Document the complete instruction flow
4. Identify all RAM reads/writes (especially to D01EB1-D01EF9 and D02032)
5. Identify all CALL/JP targets
6. Determine what values get written to the descriptor blocks and how they're computed

Key eZ80 opcodes to watch for:
- `ED 27` = LD HL,(HL) — eZ80-specific indirect load
- `40` prefix = .SIS (16-bit MBASE-composed addressing)
- `DD`/`FD` prefixes = IX/IY register operations
- `ED 4C` = MLT BC, `ED 5C` = MLT DE, `ED 6C` = MLT HL (eZ80 multiply)
