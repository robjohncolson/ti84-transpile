# Auto-Session 503 — P1: Search for RST 28h (BCALL) in 0x096B00-0x096E00

## Task
Search the TI-84 Plus CE ROM for RST 28h (BCALL) opcodes in the cursor blink region 0x096B00-0x096E00. The BCALL mechanism uses opcode 0xE7 followed by a 2-byte little-endian index into the BCALL jump table at 0x020104 (2,178 entries, each 4 bytes: C3 xx xx xx).

Session 502 found ZERO direct CALL/JP instructions to cursor draw functions (0x061061, 0x061003, 0x061980) in the entire 0x096000-0x09A000 range. The hypothesis is that the blink code may invoke draw/erase through BCALL instead.

Key BCALL entries for cursor:
- Entry 832 at table offset 0x020E04 → JP 0x061003 (cursor erase)
- Entry 0x020DF8 → 0x060EF5 (orchestrator)

## Deliverables
Create a probe file `TI-84_Plus_CE/probe-phase503-rst28h-search.mjs` that:

1. Loads the ROM from `TI-84_Plus_CE/ROM.rom` (4,194,304 bytes)
2. Scans bytes 0x096B00 through 0x096E00 for opcode 0xE7 (RST 28h)
3. For each 0xE7 found:
   - Read the 2-byte LE index that follows (bytes at offset+1, offset+2)
   - Compute the BCALL table address: 0x020104 + (index * 4)
   - Read the JP target from the table (bytes at tableAddr+1, tableAddr+2, tableAddr+3 as LE 24-bit)
   - Print: address of E7, raw index, table address, JP target
   - Flag if the target is 0x061003, 0x061061, 0x061980, or any address in 0x060000-0x062000
4. Also scan for opcode 0xE7 in the broader 0x096000-0x09A000 range
5. Print summary: total E7 bytes found, how many resolve to cursor-related functions
