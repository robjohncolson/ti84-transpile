# Auto-Session 280 P2: Trace 0x040BE4-0x040C89 Full STAT Dispatcher

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM (eZ80) has been lifted to JavaScript.

**Background from session 279**: The STAT dispatcher was partially traced. Key findings:
- 0x040C00-0x040C16 reads flag byte from D1A880 (the STAT mode selector byte)
- bit 0 → JP Z 0x09E0D9 (menu with HL=0x09E140, A=0x42)
- bit 1 → JP Z 0x09E0A1 (SET 0@IY+26, menu with HL=0x09E1F1, DE=0x000608)
- fallthrough → inline D025CF setup + CALL 0x09DD1C (partial init)
- Caller chain: 0x040B28 JP 0x040BE4 → bit-test dispatch → 0x09E0A1/0x09E0D9

The question: What is the FULL function at 0x040Be4-0x040C89? How does it select between STAT Edit, STAT Calc, and STAT Tests?

## Task
Write a probe at `TI-84_Plus_CE/probe-phase280-040be4-stat-dispatch.mjs` that:

1. Disassembles the ROM region 0x040Be4 through 0x040C89 (or until a clear function boundary — RET or unconditional JP to outside the function)
2. For each branch/conditional in the function, document what it tests and where it goes
3. Run dynamic traces with different D1A880 values (0x00, 0x01, 0x02, 0x04, etc.) to see which STAT sub-modes each bit selects
4. Map the complete dispatch table: which D1A880 bit value → which STAT sub-mode (Edit, Calc, Tests, etc.)
5. Trace any additional RAM reads the function makes (D025CF, D007E0, etc.)
