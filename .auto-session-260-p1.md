# Task: Static disassembly of 0x062055 function region (D007E0 writes + cxMain call)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). We're investigating the OS event loop → context handler dispatch chain.

**Key finding from prior sessions**: The function at 0x062055 is the ONLY path to cxMain (the home-screen key handler). Specifically:
- 0x0620C4 contains `CALL 0x058241` — the sole call site to cxMain's pre-handler in the entire ROM
- 0x0620AE writes D007E0 with A=0x49
- 0x0620C0 writes D007E0 with A=0x40
- 0x062055 has ZERO static callers — reached via RAM function pointer only
- 0x062077 and 0x0620D6 SET bit 7 of IY+12 ("editor active" flag)

## Deliverable
Create `TI-84_Plus_CE/probe-phase260-062055-disasm.mjs` that:

1. Reads `TI-84_Plus_CE/ROM.rom` as a Buffer
2. Starting at offset 0x062055, decode eZ80 instructions in ADL mode (24-bit addresses) up to at least 0x0620E0
3. For each instruction, print: `0x{addr}: {hex bytes} → {mnemonic}`
4. Flag any LD (0xD007E0),A instructions (byte pattern: `32 E0 07 D0` in ADL mode)
5. Flag any CALL instructions (0xCD) and their targets
6. Flag any SET/RES/BIT instructions on IY+offset
7. Flag any JP/JR/RET instructions (control flow boundaries)

## eZ80 Encoding Reference (ADL mode)
- `CALL nn` = CD nn_lo nn_mid nn_hi (4 bytes in ADL)
- `LD (nn),A` = 32 nn_lo nn_mid nn_hi (4 bytes in ADL)
- `LD A,(nn)` = 3A nn_lo nn_mid nn_hi (4 bytes in ADL)
- `LD A,n` = 3E n (2 bytes)
- `JP nn` = C3 nn_lo nn_mid nn_hi (4 bytes in ADL)
- `JR d` = 18 d (2 bytes, signed displacement)
- `JR cc,d` = 20/28/30/38 d (2 bytes)
- `RET` = C9 (1 byte)
- `RET cc` = C0/C8/D0/D8/E0/E8/F0/F8 (1 byte)
- `SET b,(IY+d)` = FD CB d (C0 + bit*8 + 6) — 4 bytes
- `RES b,(IY+d)` = FD CB d (80 + bit*8 + 6) — 4 bytes  
- `BIT b,(IY+d)` = FD CB d (40 + bit*8 + 6) — 4 bytes
- `PUSH rr` = C5/D5/E5/F5 (1 byte for BC/DE/HL/AF)
- `POP rr` = C1/D1/E1/F1
- `LD HL,nn` = 21 nn_lo nn_mid nn_hi (4 bytes in ADL)
- `LD DE,nn` = 11 nn_lo nn_mid nn_hi
- `LD BC,nn` = 01 nn_lo nn_mid nn_hi
- `CP n` = FE n (2 bytes)
- `AND n` = E6 n (2 bytes)
- `OR n` = F6 n (2 bytes)
- `XOR n` = EE n (2 bytes)
- Prefix 0xDD = IX prefix, 0xFD = IY prefix
- Prefix 0xED = extended instructions
- `NOP` = 00

The decoder doesn't need to be perfect — just good enough to identify the key instructions (LD (D007E0),A, CALL targets, SET/RES/BIT on IY, control flow).
