# Task: Trace D01EB1 Write Sites — Who Populates the Cursor Descriptor Blocks?

## Context
You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 machine code).

Session 505 decoded 0x096C03 — a cursor-type-indexed table selector that returns pointers to three pairs of descriptor blocks in RAM:
- Type 0: HL=D01EB1, DE=D01ECC
- Type 1: HL=D01EBA, DE=D01ED5
- Type ≥2: HL=D01EDE, DE=D01EF9

Session 506 confirmed D01EB1-D01EF9 are ALL ZEROS after boot. The caller at 0x096BD3 does `LD A,(HL); CP 0x0E` — reads first byte as token type, checks against 0x0E.

**Question**: What code in the ROM writes to these descriptor blocks? Finding the write sites reveals what values are written and when, which tells us what token type 0x0E represents.

## Deliverable
Create a probe file `TI-84_Plus_CE/probe-phase507-trace-D01EB1-writes.mjs` that:

1. **Byte-pattern search for writes to D01EB1**: Search the ENTIRE ROM (0x000000-0x3FFFFF) for these byte patterns:
   - `32 B1 1E D0` = LD (D01EB1),A
   - `22 B1 1E D0` = LD (D01EB1),HL (24-bit store)
   - `ED 53 B1 1E D0` = LD (D01EB1),DE (some eZ80 extended stores)
   - Also search with .SIS prefix: `40 22 B1 1E` = .SIS LD (xx1EB1),HL (MBASE=D0 composes the high byte)
   - `40 32 B1 1E` = .SIS LD (xx1EB1),A

2. **Also search for D01EBA, D01ECC, D01ED5, D01EDE, D01EF9** — the other descriptor block addresses. Use the same patterns with the appropriate low bytes.

3. **Also search for LDIR/LDDR near these addresses**: Look for sequences that load HL or DE with values in the D01EB0-D01F00 range followed by LDIR (ED B0) or LDDR (ED B8) within ~20 bytes. These block-copy instructions could populate the descriptors.

4. **Context decode**: For each match found, print the 20 bytes before and 10 bytes after the match address, with a basic disassembly of the surrounding instructions.
