# Task: Disassemble 0x080151 — the entry gate for 0x062055

## Context
The function at 0x062055 is the bridge between the OS event loop and cxMain (home screen context handler). At entry, it does `LD A,B` then `CALL 0x080151` then `JR NZ,0x0620CC` (alternate path). When 0x080151 returns Z, execution continues to the main cxMain path. When it returns NZ, it takes the alternate path that crashes.

Session 260 found that after boot with B=0, 0x080151 returns NZ. We need to understand what 0x080151 checks.

## Deliverable
Create probe file `TI-84_Plus_CE/probe-phase261-080151-disasm.mjs` that:

1. **Static decode**: Read ROM.rom bytes starting at 0x080151 and manually decode the eZ80 instructions for at least 60 bytes (until you hit a RET or unconditional JP). Document each instruction with address, hex bytes, and mnemonic.

2. **Dynamic trace**: Run the transpiled block at 0x080151 with different A values (0x00, 0x01, 0x3F, 0x40, 0x5E) and record:
   - How many steps to RET
   - Z flag on return
   - Any RAM reads (especially D007xx, D023xx, D0230F)
   - Any CP instructions (what value is compared)

## Technical details
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 binary)
- Transpiled JS: `TI-84_Plus_CE/ROM.transpiled.js` (gunzip from .gz if needed)
- Runtime: `TI-84_Plus_CE/cpu-runtime.js`
- Use `createCPU` and `createPeripheralBus({ timerInterrupt: false })` from cpu-runtime.js
- eZ80 is little-endian, ADL mode (24-bit addresses by default)
- Common instruction patterns:
  - `CP n` = `FE n` (compare A with immediate)
  - `LD A,(nn)` = `3A ll hh` (z80) or `ED 3A ll mm hh` (ADL 24-bit)
  - `RET` = `C9`, `RET Z` = `C8`, `RET NZ` = `C0`
  - `JR NZ,offset` = `20 offset`
  - `JR Z,offset` = `28 offset`
  - `BIT b,(IY+d)` = `FD CB d 46+8*b`
  - `CALL nn` = `CD ll hh` (z80) or `CD ll mm hh` (ADL)

```javascript
const bus = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(bus);

// Load ROM
for (let i = 0; i < rom.length; i++) cpu.mem[i] = rom[i];

// Load transpiled code

for (const testA of [0x00, 0x01, 0x3F, 0x40, 0x5E]) {
  // Reset CPU state
  cpu.pc = 0x080151;
  cpu.sp = 0xD1A860;
  cpu.a = testA;
  cpu.iy = 0xD00080;
  cpu.madl = 1;
  
  // Push return sentinel
  const sentinel = 0x7FFFFE;
  cpu.sp -= 4;
  cpu.mem[cpu.sp] = sentinel & 0xFF;
  cpu.mem[cpu.sp+1] = (sentinel >> 8) & 0xFF;
  cpu.mem[cpu.sp+2] = (sentinel >> 16) & 0xFF;
  cpu.mem[cpu.sp+3] = cpu.madl ? 0x80 : 0x00;
  
  const blocks = new Set();
  let steps = 0;
  while (steps < 200 && cpu.pc !== sentinel) {
    blocks.add(cpu.pc);
    const block = cpu.blocks[cpu.pc];
    if (!block) { console.log(`  MISSING BLOCK at 0x${cpu.pc.toString(16).padStart(6,'0')}`); break; }
    block(cpu, cpu.mem, bus);
    steps++;
  }
  
  const z = cpu.flags.z ? 'Z' : 'NZ';
  console.log(`A=0x${testA.toString(16).padStart(2,'0')}: ${steps} steps, ${blocks.size} blocks, flags=${z}, A_out=0x${cpu.a.toString(16).padStart(2,'0')}`);
}
```
