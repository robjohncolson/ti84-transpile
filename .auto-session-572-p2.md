# Task: DUMP 0x080075 TABLE CROSS-REF — map all 11 multi-byte prefix bytes to TI token class names

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 570 discovered function 0x080064 (CPIR multi-byte token prefix check, 17B) which references a table at ROM address 0x080075 containing 11 bytes: `5C 5D 5E 60 61 62 63 7E BB AA EF`. These are the multi-byte token prefix bytes for the TI-84 CE token system.

## What to do
1. Create a probe script `TI-84_Plus_CE/probe-phase572-dump-080075-table.mjs` that:
   a. Reads the ROM at `TI-84_Plus_CE/ROM.rom`
   b. Dumps the 11 bytes at 0x080075 and identifies each
   c. For each prefix byte, searches the ROM for a token name table. The TI-84 CE stores token names as null-terminated strings in ROM — look near 0x09F79B (the key-to-scan-code translation table area) or in the 0x0Axxxx-0x0Bxxxx region. Common TI token prefix mappings:
      - 0x5C = List prefix (L1-L6, other list vars)
      - 0x5D = Matrix prefix ([A]-[J])
      - 0x5E = Y-var prefix (Y1-Y0, parametric, polar)
      - 0x60 = Pic prefix (Pic1-Pic0)
      - 0x61 = GDB prefix (GDB1-GDB0)
      - 0x62 = String prefix (Str1-Str0)
      - 0x63 = Statistics prefix (RegEQ, etc)
      - 0x7E = Window/Table prefix (Xmin, Xmax, etc)
      - 0xBB = Extended tokens (randInt, etc)
      - 0xAA = Statistics commands (1-Var Stats, etc)
      - 0xEF = Graph format tokens (ZXmin, etc)
   d. Cross-references: for each prefix byte, find which ROM functions reference it (scan for CP instructions comparing against each value, or LD instructions loading it)
   e. Prints a formatted table: prefix byte → token class name → number of ROM references

2. The probe should also dump any token name string tables it finds near these references.
