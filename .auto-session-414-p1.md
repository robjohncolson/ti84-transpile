# Task: Trace 0x015185 Notification Completion Callback

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). The instruction decoder is at `TI-84_Plus_CE/ez80-decoder.js`.

Session 413 decoded `0x0151FE` (pre-delivery staging), which installs `0x015185` as the callback vector at RAM address `D17770`. This callback is invoked when a USB/Link notification completes. We need to trace what `0x015185` actually does.

## What to do
1. Create a probe script `TI-84_Plus_CE/probe-phase414-trace-015185.mjs` that:
   - Loads the ROM binary
   - Uses `ez80-decoder.js` to decode instructions starting at `0x015185`
   - Follows the linear instruction flow (stop at RET, JP to known address, or after 200 bytes max)
   - Annotates RAM addresses with known labels (see below)
   - Prints a clean disassembly listing

2. Create a report `TI-84_Plus_CE/phase414-trace-015185-report.md` documenting:
   - The full decoded instruction sequence with addresses and hex bytes
   - What RAM addresses are read/written
   - What subroutines are called
   - What the function does in plain English
   - How many bytes the function spans
