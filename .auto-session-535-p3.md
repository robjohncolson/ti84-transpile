## eZ80 Decoding Rules (CRITICAL)
- Default mode is ADL (24-bit). All LD rr,nn use 3-byte immediates. All CALL/JP use 3-byte addresses.
- Prefix 0x52 = .SIL (force 16-bit operands for next instruction)
- ED-prefix opcodes: ED B0 = LDIR, ED A0 = LDI, ED A1 = CPI, ED B1 = CPIR
- CB-prefix: BIT/SET/RES instructions
- DD = IX, FD = IY (FD CB dd nn for BIT/SET/RES (IY+dd))
- 0xCD = CALL nn (3B), 0xC3 = JP nn (3B), 0xC9 = RET, 0x18 = JR d
- 0x20/0x28/0x30/0x38 = JR NZ/Z/NC/C d (signed 8-bit displacement)
- Common LD: 0x21 = LD HL,nn, 0x11 = LD DE,nn, 0x01 = LD BC,nn, 0x3E = LD A,n
- 0xE6 = AND n, 0xFE = CP n, 0xEE = XOR n, 0xF6 = OR n
- Known RAM: D005F8=OP1, D00603=OP2, D0060E=OP3, D00619=OP4, D00624=OP5, D0062F=OP6
