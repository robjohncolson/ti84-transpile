In auto-session 301, the key class lookup function at 0x058D54 was decoded. It contains a two-byte token dispatcher at 0x058E02 that uses a CP cascade:
- `0xFE` → table at **0x058E57** (14 entries)
- `0xFC` → table at **0x058E65** (2 entries)
- `0xFB` → table at **0x058E67** (3 entries)
- `0xFA` → same table as 0xFB

These tables contain two-byte token codes that the TI-84 OS uses to identify calculator functions (like sin, cos, Disp, etc.).

## Task
Create a probe script `TI-84_Plus_CE/probe-phase302-token-tables.mjs` that:

1. **Dumps raw bytes at each table address**:
   - 0x058E57: dump 28 bytes (14 entries × 2 bytes each, or adjust if entries are different size)
   - 0x058E65: dump 4 bytes (2 entries)
   - 0x058E67: dump 6 bytes (3 entries)
   - 0x058E6A: dump 18 bytes (9 entries)
   Also dump extra bytes beyond each table to catch any adjacent data.

2. **Determines entry format**: Are entries 2-byte token codes? 3-byte (token + handler address)? Or something else? Look at how the dispatcher at 0x058E02 indexes into these tables — disassemble 0x058E02 through 0x058E70 to understand the table format.

3. **Maps token bytes to TI-84 function names** where possible. Known TI-84 two-byte token prefixes:
   - 0x5C = matrix tokens
   - 0x5D = list tokens  
   - 0x5E = equation tokens

   - 0x61 = GDB tokens
   - 0x62 = string tokens
   - 0x63 = system variable tokens

   - 0xBB = extended function tokens

4. **Prints a formatted summary** showing each table's contents with hex values and any identified token names.
