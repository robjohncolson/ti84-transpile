# Task: IDENTIFY 4 UNIDENTIFIED OS API TARGETS

You are working on the TI-84 Plus CE ROM transpilation project at `C:/Users/rober/Downloads/Projects/school/ti84-transpile`.

## Objective

Decode and identify the 4 remaining unidentified OS API jump table targets:
- 0x001768
- 0x00380D
- 0x0060FA
- 0x015151

These are the only 4 of 364 unique targets in the OS API jump table (374 JP thunks at 0x000080-0x000654) that have NOT been identified. All other targets have been matched to SDK names or C runtime functions.

## Known context

- The OS API jump table has 374 JP thunks starting at 0x000080, each 4 bytes (JP opcode 0xC3 + 3-byte address)
- 360 of 364 unique targets are already named (98.9%)
- The "non-standard prologues" means these 4 targets don't begin with the typical `PUSH IX` / `CALL __frameset` (0xCD 0x97 0x21 or 0xCD 0x8A 0x21) pattern
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB)

## What to do

1. Create a probe file `TI-84_Plus_CE/probe-phase437-decode-4-targets.mjs` that for EACH of the 4 addresses:
   - Reads the ROM bytes starting at that address (first 64 bytes)
   - Disassembles the first ~20 instructions (basic eZ80 disassembly)
   - Counts how many callers reference this address in the ROM (search for LE-encoded address after CALL/JP opcodes: CD/C3 + 3 LE bytes)
   - Identifies any RAM addresses referenced (pattern: bytes in 0xD0xxxx-0xD4xxxx range)
   - Identifies any port I/O (LD BC,<port> + IN/OUT patterns)
   - Reports the function size (distance to first RET = 0xC9)
   - Attempts classification: is it a C runtime helper? A hardware function? A stub?

2. Key eZ80 opcodes for disassembly:
   - 0xC9 = RET
   - 0xCD = CALL addr (4 bytes total)
   - 0xC3 = JP addr (4 bytes total)
   - 0x3A = LD A,(addr) (4 bytes)
   - 0x32 = LD (addr),A (4 bytes)
   - 0x21 = LD HL,addr (4 bytes)
   - 0xDD = IX prefix
   - 0xFD = IY prefix
   - 0xED = extended prefix
   - 0xCB = bit operation prefix
   - 0xE5 = PUSH HL
   - 0xDD 0xE5 = PUSH IX
   - 0xB7 = OR A (flag set)
   - 0xC8 = RET Z, 0xC0 = RET NZ
   - 0xAF = XOR A (clear A)
   - 0x18 = JR offset
   - 0x20 = JR NZ offset
   - 0x28 = JR Z offset

3. Create a report file `TI-84_Plus_CE/phase437-4-targets-report.md` with:
   - Hex dump and disassembly for each target
   - Caller count and caller addresses
   - Proposed function name/purpose for each
   - Confidence level (high/medium/low)

4. Run the probe: `node TI-84_Plus_CE/probe-phase437-decode-4-targets.mjs`
