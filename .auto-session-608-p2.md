# Auto-Session 608 P2 — Decode 0x08F3DC (Cursor-Advance Function)

## Goal
Create a probe `TI-84_Plus_CE/probe-phase608-decode-08f3dc.mjs` that statically decodes the function at 0x08F3DC and its immediate vicinity (0x08F3B0-0x08F420). This is the cursor-advance function that forms the inner loop of the key2 runaway (0x08F3DC↔0x04C973↔0x090927). Understanding its termination condition will reveal what the edit buffer needs to contain for the loop to exit.

## Background
- Session 607: key2 ('3') with post-paint snapshot gets stuck in a tight loop: 0x08F3DC (16,632 hits), 0x04C973 (compare helper, 150 hits/2000 tail blocks), 0x090927 (POP DE, 11,088 hits).
- 0x090917-0x090928 is the walker: INC HL → CALL 0x08F3DC → RET Z → LD DE,(D0243A) → CALL 0x04C973 (compare) → POP DE → RET NZ.
- The loop walks forward through the edit buffer, comparing HL against D0243A (editCursorB). It exits when either 0x08F3DC returns Z (something found), or 0x04C973 returns NZ (HL passed D0243A).
- Since D0243A is stale (points to already-freed memory), the comparison never succeeds and the loop runs forever.

## What to decode
1. **0x08F3DC**: Read ROM bytes from 0x08F3DC to 0x08F420 (68 bytes). Disassemble as eZ80 ADL-mode instructions. This is an eZ80 CPU — opcodes include standard Z80 + eZ80 extensions (24-bit addresses, `.SIS`/`.LIS`/`.SIL`/`.LIL` prefixes at 0x40/0x49/0x52/0x5B).
2. **0x04C973**: Read ROM bytes from 0x04C973 to 0x04C990 (29 bytes). Disassemble. This is the compare helper called from the walker loop.
3. **0x090917-0x090930**: Read ROM bytes (25 bytes). Confirm the walker loop structure.
4. **Cross-reference 0x08F3DC callers**: Search the ROM for `CALL 0x08F3DC` (opcode CD DC F3 08 in ADL mode — 4-byte CALL). Count callers and list their addresses.
