# Task: Test Event Loop with Timer Interrupt + Keypress Combined

## Context
You are working on the TI-84 Plus CE ROM transpilation project. Session 371 tested keypresses with timerInterrupt:false and found that the 0x003D6B hot loop dominates with 494K visits in 500K steps. Session 371 also fully disassembled the RST 38h to timer ISR chain. The timer ISR polls ports 0x5015, 0x5014, 0x500B for pending hardware interrupts. With timerInterrupt:true, the timer fires every ~200 steps.

We need to test whether enabling the timer interrupt CHANGES the event loop behavior when a key is pressed.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase372-timer-keypress.mjs` that runs 4 scenarios and compares them:

1. **Scenario A**: Event loop, timerInterrupt:false, NO keypress, 100K steps
2. **Scenario B**: Event loop, timerInterrupt:false, WITH ENTER keypress, 100K steps
3. **Scenario C**: Event loop, timerInterrupt:true, NO keypress, 100K steps
4. **Scenario D**: Event loop, timerInterrupt:true, WITH ENTER keypress, 100K steps

For each scenario:
- Track all unique blocks visited and their visit counts
- Track total steps executed
- Track the final PC, SP, and key registers (A, BC, DE, HL, IX, IY)
- Note if execution HALTed and at what step

Then compare:
- Unique blocks in D but not in C (timer+key vs timer-only)
- Unique blocks in D but not in B (timer+key vs key-only)
- Any blocks unique to D (only appear when BOTH timer AND key are active)
