# Task: Decode 0x07FACF — FP-Related Context Setup

## Context
In the TI-84 Plus CE OS ROM (`TI-84_Plus_CE/ROM.rom`), address 0x07FACF is called after PUSH AF in the token classifier at 0x09BB35 (noted in session 522 priorities). This is believed to be a floating-point or context setup function. We need to decode what it does.

## Deliverable
Create `TI-84_Plus_CE/probe-phase523-decode-07FACF-fp-context.mjs` that:
1. Reads ROM bytes starting at 0x07FACF for ~200 bytes
2. Disassembles the eZ80 instructions (ADL mode, 24-bit addresses)
3. Documents what the function does — what context it sets up, what RAM it touches
4. Identifies all CALLs, JPs, memory reads/writes (especially RAM D0xxxx, FP stack D025xx)
5. Prints a structured analysis

## How to read ROM bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
// Read byte at address: rom[address]
// Read 24-bit LE value: rom[addr] | (rom[addr+1] << 8) | (rom[addr+2] << 16)
```

## eZ80 ADL mode reference
- All addresses are 24-bit (3 bytes LE) in ADL mode
- CALL nn = 0xCD nn[2:0], JP nn = 0xC3 nn[2:0]
- LD r,(nn) / LD (nn),r use 3-byte addresses
- RET = 0xC9, RET Z = 0xC8, RET NZ = 0xC0, RET C = 0xD8, RET NC = 0xD0
- JR e = 0x18 e (signed offset from PC+2)
- JR Z,e = 0x28 e, JR NZ,e = 0x20 e, JR C,e = 0x38 e, JR NC,e = 0x30 e
- CP n = 0xFE n, LD A,n = 0x3E n
- LD HL,nn = 0x21 nn[2:0], LD DE,nn = 0x11 nn[2:0], LD BC,nn = 0x01 nn[2:0]
- PUSH AF = 0xF5, POP AF = 0xF1, PUSH HL = 0xE5, POP HL = 0xE1
- OR A = 0xB7, XOR A = 0xAF, AND n = 0xE6 n
- BIT b,r uses CB prefix (0xCB then opcode)
- LD A,(HL) = 0x7E, LD (HL),A = 0x77
- RST 0x28 = 0xEF (bcall)
- ADD HL,DE = 0x19, ADD HL,BC = 0x09
- SBC HL,DE = 0xED 0x52, SBC HL,BC = 0xED 0x42
- EX DE,HL = 0xEB
- LDIR = 0xED 0xB0, LDDR = 0xED 0xB8

## Known context

- Likely FP or arithmetic context — the 0x07Fxxx region contains BCD normalizer (0x07EFF0), type normalizer (0x07F7FA), type rewriter (0x07FE9C)
