## Context

## Target
**0x07C9E1** — Sign normalization + exponent adjustment. This is the epilogue of the BCD multiplication function at 0x07C8B7 (246B, 0x07C8B7-0x07C9AD). The multiplication epilogue at 0x07C98E does `BIT 6,(IY+14) → RET NZ`, else `JR 0x07C9E1`. So 0x07C9E1 is the sign normalization path taken when operands were NOT in reversed order.

## Known Context
- 0x07C8B7 is the BCD multiplication core (session 530). It multiplies OP1 × OP2 mantissas.
- The epilogue checks BIT 6,(IY+14) — if set (reversed order), returns directly. If clear, jumps to 0x07C9E1.
- 0x07C9AF is another function called from the division epilogue (session 528: `CALL 0x07C9AF` — "BIT 3,(IY+72); RET NZ" then continues).
- OP1 is at D005F8 (type), D005F9 (exponent), D005FA (mantissa start).
- OP2 is at D00603 (type), D00604 (exponent), D00605 (mantissa start).
- IY is typically 0xD00080.

## eZ80 Decoding Reference
- Standard Z80 opcodes apply, but addresses are 24-bit (3 bytes for JP/CALL targets)
- `ED` prefix: extended instructions. `CB` prefix: bit operations. `DD`/`FD` prefix: IX/IY operations.
- `FD CB dd xx` = IY+dd bit operation (dd=displacement, xx=opcode)
- Common patterns in this ROM:
  - `3A xx xx xx` = LD A,(addr24)  [4 bytes]
  - `32 xx xx xx` = LD (addr24),A  [4 bytes]
  - `CD xx xx xx` = CALL addr24    [4 bytes]
  - `C3 xx xx xx` = JP addr24      [4 bytes]
  - `C9` = RET
  - `18 dd` = JR dd (signed relative)
  - `20 dd` = JR NZ,dd
  - `28 dd` = JR Z,dd
  - `38 dd` = JR C,dd
  - `30 dd` = JR NC,dd
  - `FE xx` = CP xx
  - `E6 xx` = AND xx
  - `F6 xx` = OR xx
  - `EE xx` = XOR xx
  - `CB xx` = bit ops (BIT/SET/RES on registers)
  - `FD CB dd xx` = bit ops on (IY+dd)
  - `ED 6F` = RLD, `ED 67` = RRD
