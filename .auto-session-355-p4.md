# Auto-Session 355 — P4: Test RST 38h Bypass

## Context
TI-84 Plus CE ROM transpilation project. Boot loops in a 2203-step cycle through 270 blocks. The cycle ends when execution reaches 0x00D33B which triggers RST 38h (0x000038), which re-enters boot init at 0x0006F3 via a chain: 0x000038 → 0x000080 → 0x001768 → 0x000000 (reset vector).

The hypothesis: if RST 38h is the SOLE mechanism causing the cycle, bypassing it should let boot proceed to new territory (new blocks beyond the current 270).

## Task
Create a probe that:
1. **Baseline run**: Boot from PC=0 for 10000 steps, record all unique block addresses visited. This is the control.
2. **RST 38h NOP bypass**: Hook execution so that when PC reaches 0x000038 (RST 38h entry), instead of executing the handler, set PC to the return address (pop 3 bytes from stack into PC, since eZ80 ADL mode pushes 3-byte PC). This simulates RST 38h doing nothing — execution continues at the instruction after the RST 38h call. Run for 10000 steps and record unique blocks.
3. **RST 38h skip at source**: Instead of NOPping the handler, find the exact instruction at 0x00D33B (or wherever RST 38h is triggered). If it's opcode 0xFF (RST 38h), hook execution to skip it (advance PC past it without executing). Run 10000 steps and record unique blocks.
4. **Compare results**: Print a table showing:
   - Baseline: total blocks, highest PC
   - NOP bypass: total blocks, highest PC, NEW blocks not in baseline
   - Source skip: total blocks, highest PC, NEW blocks not in baseline
5. **For any new blocks discovered**, print the first 8 bytes of ROM at that address (hex dump) to help identify what code was reached.

## Deliverables

## Technical Details
- ROM file: `TI-84_Plus_CE/ROM.rom` (4MB)
- Runtime:
```js
const { createCPU } = await import('./cpu-runtime.js');
const { createPeripheralBus } = await import('./peripherals.js');
import fs from 'fs';
const rom = new Uint8Array(fs.readFileSync('TI-84_Plus_CE/ROM.rom'));
```
- For each test, create a fresh CPU+mem+bus:
```js
const mem = new Uint8Array(0x1000000);
mem.set(rom);
const bus = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(mem, bus);
const transpiled = await import('./ROM.transpiled.js');
```
- `cpu.step()` executes one instruction. Check `cpu.pc` before each step.
- To implement the RST 38h NOP bypass: before each `cpu.step()`, check if `cpu.pc === 0x000038`. If so, pop the return address from stack: `const ret = mem[cpu.sp] | (mem[cpu.sp+1] << 8) | (mem[cpu.sp+2] << 16); cpu.sp += 3; cpu.pc = ret;` and skip the step.
- To implement source skip: before each `cpu.step()`, check if `cpu.pc === 0x00D33B` (or wherever the RST 38h instruction is). If `mem[cpu.pc] === 0xFF` (RST 38h opcode), then `cpu.pc += 1;` to skip it.
- **IMPORTANT**: The transpiled ROM uses pre-compiled block functions. Execution may hit `missing_block` for new addresses — that's expected and is a POSITIVE signal (we reached new code). Count missing_block terminations and report the address.
- eZ80 ADL mode: RST pushes 3-byte PC. Stack grows downward. SP points to the lowest byte of the pushed value.
- `cpu.halted` or a missing_block error may terminate execution early. Catch errors and report them.
