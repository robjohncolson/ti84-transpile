The walker loop at 0x090917 (forward) and 0x09092E (backward) is the inner loop that runs away when D000A3 bit 3 is SET. 0x08F3DC is called from this loop (BIT 3,(IY+35); RET). Session 608 found 14 callers of 0x08F3DC, all in the 0x08Fxxx-0x090xxx range (edit buffer subsystem).

## Task

Create `TI-84_Plus_CE/probe-phase609-walker-callers.mjs` that:

1. **Find all CALL/JP targets to 0x090917 and 0x09092E** in the ROM binary:

     - `CALL 0x090917` = CD 17 09 09 (eZ80 24-bit address, little-endian)

3. **Decode the immediate callers of 0x090917**: For each CALL site found in step 1, decode 64 bytes starting 16 bytes before the CALL instruction. Use the eZ80 decoder from `TI-84_Plus_CE/ez80-decoder.js` if available (import { decodeInstruction } from './ez80-decoder.js'), or manually decode the most common instructions.

4. **Trace upward one more level**: For the callers found in step 3, search for CALL/JP to THOSE addresses to find the second-level callers. This builds a 2-level call tree above the walker loop.

5. **Output summary**:

   - For each walker caller: is D000A3 bit 3 cleared (RES 3,(IY+0x23)) anywhere in the 64-byte decode window before the CALL? This tells us whether the OS normally clears the flag before invoking the walker.
