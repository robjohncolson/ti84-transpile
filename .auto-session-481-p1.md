# Task: Render Multi-Char String "HOME" Using Correct VRAM Formula

## Context
We're transpiling the TI-84 Plus CE ROM (eZ80) to JavaScript. Session 478 proved that calling `0x0059C6` with A=character code renders real glyph pixels to VRAM. Session 480 fully decoded the VRAM address computation at `0x005A75`:

```
vram_addr = 0xD40000 + (D00595 * 20 + 37) * 640 + (D00596 * 12 + 2) * 2
```

- D00595 = cursor row (read by renderer at 0x005A8E)
- D00596 = cursor column (read at 0x005A9A, auto-incremented by 0x0059C6)
- D0059C = computed column pixel offset (2 bytes, .SIL mode at 0x005AB0)
- D005A0 = computed pixel row scratch byte
- Status bar = 37 pixels, text row = 20 pixels, left margin = 2 pixels, char width = 12px

Session 478 found that with D00595 at its boot value (not 0), chars rendered at VRAM row 119. Setting D00595=0 should render at the top of the screen.

## Deliverable
Create `TI-84_Plus_CE/probe-phase481-multi-char-render.mjs` that:

1. Does 3-stage boot (0x080000, 0x0802B2, 0x08C331, each 150K steps)
2. Sets up home mode state (see template below)
3. Sets D00595=0 (row 0), D00596=0 (col 0), D0058B=0x70
4. Captures VRAM snapshot before rendering
5. Renders "HOME" by calling 0x0059C6 four times (A=0x48, 0x4F, 0x4D, 0x45) with a FAKE_RET sentinel between each call
6. After EACH character call, logs: D00596 value, D0059C value (3 bytes), VRAM bytes changed so far
7. After all 4 characters, reports total VRAM bytes changed and their address range
8. Verifies the VRAM addresses match the formula: row 0 should be at pixel row 37, so VRAM offset = 37 * 640 = 23,680 = 0x5C80

## Template Pattern (MUST follow exactly)
```javascript
import { readFileSync } from "node:fs";
import { createExecutor } from "./cpu-runtime.js";
import { createPeripheralBus } from "./peripherals.js";
import { PRELIFTED_BLOCKS } from "./ROM.transpiled.js";

const MEM_SIZE = 0x1000000;
const VRAM_BASE = 0xd40000;
const VRAM_SIZE = 320 * 240 * 2;
const STACK_RESET_TOP = 0xd1a87e;
const FAKE_RET = 0xfedcba;

const mem = new Uint8Array(MEM_SIZE);
const rom = readFileSync(new URL("./ROM.rom", import.meta.url));
mem.set(rom.subarray(0, MEM_SIZE), 0);
const peripherals = createPeripheralBus();
const executor = createExecutor(PRELIFTED_BLOCKS, mem, { peripherals });

function runFrom(pc, steps, onBlock) {
  return executor.runFrom(pc, "adl", { maxSteps: steps, maxLoopIterations: 200000, onBlock });
}
function hex(v, w = 6) { return "0x" + (v >>> 0).toString(16).toUpperCase().padStart(w, "0"); }
function write24(addr, val) {
  mem[addr & 0xffffff] = val & 0xff;
  mem[(addr + 1) & 0xffffff] = (val >>> 8) & 0xff;
  mem[(addr + 2) & 0xffffff] = (val >>> 16) & 0xff;
}
function read24(addr) {
  return mem[addr & 0xffffff] | (mem[(addr + 1) & 0xffffff] << 8) | (mem[(addr + 2) & 0xffffff] << 16);
}

// 3-stage boot
runFrom(0x080000, 150000);
runFrom(0x0802b2, 150000);
runFrom(0x08c331, 150000);

// Home mode state
mem[0xd00824] = 0x48;
mem[0xd007e0] = 0x48;
mem[0xd14091] = 0x01;
mem[0xd00092] = 0x16;
mem[0xd00089] |= 0x10;
mem[0xd000c6] = 0x01;
mem[0xd000b4] = 0x01;
mem[0xd00080] |= 0x18;
mem[0xd00595] = 0x00;  // Row 0
mem[0xd00596] = 0x00;  // Col 0
mem[0xd0058b] = 0x70;
executor.cpu.mbase = 0xd0;
executor.cpu._iy = 0xd00080;
```
