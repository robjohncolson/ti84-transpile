# Auto-Session 395 P4: Coverage Push — Add Seeds

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The transpiler at `scripts/transpile-ti84-rom.mjs` lifts eZ80 machine code from `TI-84_Plus_CE/ROM.rom` into JavaScript. "Seeds" are entry point addresses that tell the transpiler where to start disassembling blocks.

Current stats: 144,355 blocks, 705,495 covered bytes.

## Task

1. Run the coverage gap analysis to find uncovered regions:
```bash
node TI-84_Plus_CE/audit-true-uncovered.mjs 2>&1 | head -80
```

2. From the output, identify 10-15 uncovered address ranges that are likely code (not data tables, not erased flash 0xFF regions).

Heuristics for identifying code vs data:
- Code regions often start with common eZ80 prologues: PUSH AF (0xF5), PUSH IX (0xDD 0xE5), PUSH HL (0xE5), DI (0xF3)
- Data tables often contain repeating patterns, ASCII text, or 0x00/0xFF runs
- Addresses in the 0x000000-0x010000 range are OS core
- Addresses in the 0x020000-0x0B0000 range are OS subsystems
- Addresses above 0x0C0000 are often flash apps or data

3. Read the ROM bytes at each candidate address to verify they look like code (check first 4-8 bytes).

4. Open `scripts/transpile-ti84-rom.mjs` and find the `seeds` array (search for `const seeds` or `seeds =`). Add the new seed addresses to the array. Keep them sorted by address.

5. Re-run the transpiler:
```bash
node scripts/transpile-ti84-rom.mjs
```

6. Run the golden regression to verify no breakage:
```bash
node TI-84_Plus_CE/probe-phase99d-home-verify.mjs
```

7. Report: how many new blocks were added, how many new bytes covered.

## Constraints
- ONLY modify `scripts/transpile-ti84-rom.mjs` (to add seeds)
- Do NOT modify peripherals.js, cpu-runtime.js, browser-shell.html, or any probe files
- Do NOT add seeds that point to obvious data (ASCII strings, 0xFF runs, lookup tables)
- The golden regression MUST still pass after adding seeds
- If the golden regression fails, revert your seed additions and report which seeds caused the failure

## Success Criteria
- 10+ new seeds added
- Net positive block count increase
- Golden regression passes
