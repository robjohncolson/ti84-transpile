# Task: Map All 13 Non-Crash References to 0x0019B5

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB, eZ80 binary). Session 319 identified 0x0019B5 as the crash/halt handler: `DI; LD A,0x10; OUT0(0x00),A; NOP; NOP; HALT`. It found 13 ROM sites that reference 0x0019B5 — 4 via JP and 9 via CALL.

## What to do
1. Search the ROM for all references to 0x0019B5. The little-endian byte pattern is `B5 19 00`. Look for:
   - `JP 0x0019B5` = C3 B5 19 00 (unconditional)
   - `JP cc,0x0019B5` = C2/CA/D2/DA/E2/EA/F2/FA B5 19 00 (conditional)
   - `CALL 0x0019B5` = CD B5 19 00
   - `CALL cc,0x0019B5` = C4/CC/D4/DC/E4/EC/F4/FC B5 19 00
2. For each reference site, read ~64 bytes before and ~32 bytes after the reference. Disassemble as eZ80 ADL-mode code.
3. For each site, determine:
   - What function it's inside (look for function prologue/epilogue patterns)
   - What condition triggers the crash — what test fails to reach the JP/CALL?
   - Whether it's a boot-time check, runtime integrity check, or error handler
4. Categorize the 13 sites into groups (boot, runtime, error handling, etc.)

## Deliverables
Create `TI-84_Plus_CE/phase320-crash-references-report.md` with:
- Table of all 13 sites: address, instruction type (JP/CALL/conditional), containing function, trigger condition
- Disassembly snippets for each site (the relevant comparison + branch)
- Categorization into functional groups
- Any insights about what runtime conditions the OS considers fatal
