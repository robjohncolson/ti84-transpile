# Task: Enhanced Persistent Loop with D00824=0x48 + D007E0=0x48 + Multiple Keys

## Context
We're investigating the TI-84 Plus CE OS event loop at 0x02FDBE. Session 472 discovered:
- D00824 is a MODE CHARACTER CODE: 0x48='H' = home screen mode
- D007E0 is a companion mode variable: 0x48='H' = home mode
- With D00824=0x48, the mode-specific dispatch at 0x02FFED is reached for the FIRST TIME
- D14091=1 is required for the key processor gate at 0x03FBC7
- After first iteration, a tight loop forms between 0x03FA09 and 0x02FDD8

The key dispatch at 0x02FFAE does: LD A,(D00824); CP 0x00; when D00824!=0x00 → JR NZ to 0x02FFED for mode-specific handling.

## Task
Create a probe `TI-84_Plus_CE/probe-phase473-enhanced-persistent.mjs` that:

1. Boots the OS (3-stage boot, see below)
2. Sets up state:
   - D00587=0x09 (ENTER key scan code)
   - D00080 bit 3 set (key available flag)
   - D14091=1 (key processing enable gate)
   - D00824=0x48 (home screen mode 'H')
   - D007E0=0x48 (companion mode = home 'H')
   - D000B4 bit 0 set (enables display path)
   - D000C6 bit 0 set (enables CALL NZ 0x030078)
   - D177BA=0x7F, D177B7=0x00
3. Uses onBlock at 0x02FE88 to restore the return address 0x02FDBE onto the stack EVERY iteration
4. Uses onBlock at 0x03FA09 to inject a SECOND key after the first is consumed:
   - On iteration 2+, if D00587==0x00, set D00587=0x31 (key "1" scan code) and D00080 bit 3
5. Runs for 500K steps with maxLoopIterations: 50000
6. Tracks hit counts for: 0x02FDBE, 0x02FE88, 0x03FA09, 0x02FDD8, 0x02FE89, 0x02FFAE, 0x02FFED, 0x030078, 0x030300, 0x040D11, 0x0059C6
7. Reports: final D00824, D007E0, D141B5, D00587, VRAM changes (bytes changed count + checksum before/after)
