# Task: Find Home Mode Entry Callers (Who Calls 0x09E30C?)

## Context
You are working on a TI-84 Plus CE ROM transpiler project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary, little-endian).

In session 477, we discovered that `0x09E30C` is the HOME MODE ENTRY function:
- At 0x09E30C: `LD A,0x48` ('H')
- At 0x09E30E: `CALL 0x09E2EC` (common mode change function)

The function `0x09E2EC` stores A to `D007E0` as the mode identifier.

## What to do

Create a probe file: `TI-84_Plus_CE/probe-phase478-home-mode-callers.mjs`

This probe should search the ROM binary for all references to `0x09E30C` (callers). Specifically:

### Search 1: Find CALL 0x09E30C in ROM
The eZ80 ADL-mode CALL instruction is `CD 0C E3 09` (opcode CD, followed by 24-bit little-endian address: 0x0C, 0xE3, 0x09).

Search the entire ROM (0x000000-0x3FFFFF) for this byte sequence. Print the address of each match.

### Search 2: Find JP 0x09E30C in ROM
The eZ80 ADL-mode JP instruction is `C3 0C E3 09`.

Search for this byte sequence too.

### Search 3: Find references to 0x09E309 (possible function entry 3 bytes before)
Also search for `CD 09 E3 09` (CALL 0x09E309) and `C3 09 E3 09` (JP 0x09E309). The actual function entry might be at 0x09E309, with 0x09E30C being 3 bytes in.

### Search 4: Find references to 0x09E2EC (common mode change)
Search for `CD EC E2 09` (CALL 0x09E2EC). Session 477 found two callers: at 0x09E2C9 (with A='S') and at 0x09E30E (with A='H'). Confirm these and find any additional callers.

### Search 5: Hex dump context around each caller
For each caller found, hex dump 32 bytes BEFORE the CALL/JP instruction (to see what A register value is loaded before the call — look for `3E xx` = `LD A,xx` or `FD 7E xx` = `LD A,(IY+xx)`).

### Template
Use this pattern (NOT the full boot + executor pattern — this is a ROM search, not an execution probe):

```javascript
#!/usr/bin/env node
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const rom = fs.readFileSync(path.join(__dirname, 'ROM.rom'));

function hex(v, w = 2) { return '0x' + (v >>> 0).toString(16).toUpperCase().padStart(w, '0'); }

function searchROM(pattern, label) {
  const results = [];
  for (let i = 0; i <= rom.length - pattern.length; i++) {
    let match = true;
    for (let j = 0; j < pattern.length; j++) {
      if (rom[i + j] !== pattern[j]) { match = false; break; }
    }
    if (match) results.push(i);
  }
  console.log(`\n=== ${label} (${results.length} matches) ===`);
  for (const addr of results) {
    console.log(`  Found at ${hex(addr, 6)}`);
    // Dump 32 bytes before for context
    const start = Math.max(0, addr - 32);
    const bytes = [];
    for (let j = start; j < addr + pattern.length + 4; j++) {
      bytes.push(rom[j].toString(16).padStart(2, '0'));
    }
    console.log(`    Context (${hex(start, 6)}-${hex(addr + pattern.length + 3, 6)}): ${bytes.join(' ')}`);
  }
  return results;
}

// ... searches here ...
```
