```

POP HL

LD (D008D5),A    ; store VRAM high byte
```

The CALLER of 0x05E50C computes the actual row/col → pixel VRAM address and pushes it on the stack before calling 0x05E50C. Finding that caller reveals the cursor-to-pixel mapping formula.

## What to do

The eZ80 CALL instruction is `CD` followed by 3 bytes little-endian. For CALL 0x05E50C:
- Address 0x05E50C in little-endian = 0C E5 05
- Full pattern: CD 0C E5 05

Read the ROM file at `TI-84_Plus_CE/ROM.rom` (binary, 4MB). Search for all occurrences of bytes `CD 0C E5 05` in the entire 4MB ROM. Report:
- The offset of each match

## Key eZ80 opcodes
- CD xx xx xx = CALL addr (4 bytes)
- ED 5B xx xx xx = LD DE,(addr)
- 2A xx xx xx = LD HL,(addr)
- 3A xx xx xx = LD A,(addr)
- E5 = PUSH HL
- D5 = PUSH DE
- C5 = PUSH BC
- 19 = ADD HL,DE
- 09 = ADD HL,BC
- 29 = ADD HL,HL (HL *= 2)
- C9 = RET
