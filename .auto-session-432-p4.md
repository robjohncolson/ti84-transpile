# Task: Trace 0x0079E5 (Endpoint Configurator)

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 machine code).

0x0079E5 is called by 0x00D9EE (USB PHY link-speed negotiation, 158 bytes). The 0x00D9EE function:
- Reads ports 0x3014 + 0x3015, combines them into a 6-bit speed value
- Feeds this 6-bit value to 0x0079E5 as the endpoint configuration parameter
- Branches on IX+6 for minimal reset vs 3-stage full init

So 0x0079E5 configures USB endpoints based on the negotiated link speed (Full Speed, High Speed, etc.).

## Your Task
1. Create a probe script at `TI-84_Plus_CE/probe-phase432-trace-0079E5.mjs` that:
   - Reads the ROM binary at `TI-84_Plus_CE/ROM.rom`
   - Disassembles from 0x0079E5 forward until a clear RET boundary
   - Lists all CALL targets
   - Lists all port I/O operations (USB endpoint ports are 0x31xx range)
   - Lists all absolute RAM references (0xD0xxxx range)
   - Identifies what endpoint registers it programs

2. Create a report at `TI-84_Plus_CE/phase432-0079E5-report.md` documenting:
   - Total size in bytes
   - How the 6-bit speed value maps to endpoint configuration
   - Which USB endpoint registers are written (port 0x31xx range)
   - Whether it configures multiple endpoints or just one
   - What packet size / FIFO settings it applies based on speed
   - RAM variables accessed
   - CALL targets and their roles

## Technical Notes
- eZ80 instructions are variable-length (1-6 bytes)
- CALL nn = 0xCD followed by 3-byte LE address (eZ80 ADL mode)
- RET = 0xC9
- USB endpoint ports on TI-84 CE (0x31xx range):
  - 0x3100 = USB control
  - 0x3108-0x310F = endpoint 0 registers
  - 0x3110-0x3117 = endpoint 1 registers
  - 0x3118-0x311F = endpoint 2 registers
  - etc.
  - 0x3138 = interrupt flags
  - 0x313A = interrupt enable
- Port 0x3014/0x3015 = USB line state / speed detection
- The eZ80 decoder is at `TI-84_Plus_CE/ez80-decoder.js`
- Look at existing probes for patterns (e.g., `probe-phase431-*.mjs`)

## Constraints
- Do NOT modify `scripts/transpile-ti84-rom.mjs`, `cpu-runtime.js`, `peripherals.js`, or `browser-shell.html`
- Do NOT add seeds to the transpiler
- Output files: `TI-84_Plus_CE/probe-phase432-trace-0079E5.mjs` and `TI-84_Plus_CE/phase432-0079E5-report.md`
- The probe must be runnable with `node TI-84_Plus_CE/probe-phase432-trace-0079E5.mjs`

## Success Criteria
