# Task: Read ROM at 0x0008E6 and decode the STAT LDDR byte count source

## Context
In the TI-84 Plus CE ROM transpilation, the STAT handler's LDDR at 0x092263 copies list data. Session 197 traced the byte count to `LD DE,(0x0008E6)` at block 0x092226. The value loaded is DE=0x000019 (25 decimal). Question: is 0x0008E6 a ROM literal, a pointer to a RAM variable, or part of a jump table?

If it's a 3-byte value stored literally at ROM address 0x0008E6, that's the LDDR count directly. If it's a pointer to RAM, then the runtime would dereference it. The instruction `LD DE,(0x0008E6)` loads DE from memory at address 0x0008E6 — on the eZ80 in ADL mode, this reads 3 bytes from that address.

Additionally: 3 elements × 9 bytes/element = 27 bytes. But DE=25 (0x19). Hypothesis: 25 = 27 - 2 (excludes 2-byte list dimension header). Verify by checking what HL (source) and DE (dest) point to when LDDR executes.

## Goal

2. Identify what's at ROM address range 0x000800-0x000900 — is this the jump table area, interrupt vectors, or something else?
3. Cross-reference: the OS jump table starts at 0x020000. What's at 0x0008E6 in the ROM? Check surrounding context.
4. Build a probe that traces the LDDR at 0x092263 with properly seeded list data and reports: (a) BC value at LDDR entry, (b) HL (source address), (c) DE (destination address), (d) whether 25 = elements×9 - 2 (header excluded)
