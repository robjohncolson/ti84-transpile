# Auto-Session 247 — P3: Trace 0x0885EA (D02661 latch armer caller)

## Context
This is a TI-84 Plus CE ROM transpilation project. The ROM is lifted to JavaScript and executed in a custom eZ80 runtime.

Session 245 mapped the D02661 latch: 12 refs, 1 armer at 0x0AF1DC (SET bit 7, copies 0xB4 bytes to D02E13), 1 disarmer at 0x0AF76E (RES bit 7). The sole CALL to 0x0AF1DC is at 0x0885EA. We need to trace 0x0885EA to understand: what context triggers the latch arm, what A value it passes, and what function 0x0885EA is part of.

## Task
Write a probe file `TI-84_Plus_CE/probe-phase247-0885ea-latch-armer.mjs` that:

1. Boots the TI-84 runtime (standard probe boot pattern)
2. **Static analysis first**: Disassemble bytes around 0x0885EA (±32 bytes) by reading ROM.rom directly. Find the function boundary (look for RET before), identify the CALL 0x0AF1DC instruction, and decode surrounding instructions.
3. **Find callers**: Scan ROM.rom for `CD EA 85 08` (CALL 0x0885EA) and `C3 EA 85 08` (JP 0x0885EA) to find who calls this address. Also scan for calls to the parent function entry.
4. **Dynamic trace**: Execute from 0x0885EA with:
   - Standard boot state (MBASE=0xD0, IY=0xD00080)
   - SP = 0xD1A878
   - Try A = 0x00, 0x01, 0x83 (various contexts)
   - Trace 200 steps each
   - Record: blocks visited, D02661 value before/after, D02E13 area changes, whether 0x0AF1DC is reached
5. Report: function purpose, what A value triggers the latch SET, what the 0xB4-byte copy at 0x0AF1DC contains

## Probe Pattern
```javascript
import { readFileSync } from 'fs';
import { gunzipSync } from 'zlib';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');
let transpiledSrc;
try { transpiledSrc = readFileSync('TI-84_Plus_CE/ROM.transpiled.js', 'utf-8'); }
catch { transpiledSrc = gunzipSync(readFileSync('TI-84_Plus_CE/ROM.transpiled.js.gz')).toString(); }

const { createCPU } = await import('./TI-84_Plus_CE/cpu-runtime.js');
const { createPeripheralBus } = await import('./TI-84_Plus_CE/peripherals.js');

const peripherals = createPeripheralBus({ timerInterrupt: false });
const cpu = createCPU(peripherals);

for (let i = 0; i < rom.length; i++) cpu.mem[i] = rom[i];

const blockMap = {};
const installBlock = (addr, fn) => { blockMap[addr] = fn; };
new Function('installBlock', transpiledSrc)(installBlock);

cpu.mbase = 0xD0;
cpu.iy = 0xD00080;
```

Step through blocks by setting cpu.pc, looking up blockMap[cpu.pc], calling it. Use sentinel return address on stack.
