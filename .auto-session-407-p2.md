## Technical Details
- eZ80 is little-endian, 24-bit addresses
- ROM file: `const rom = fs.readFileSync('TI-84_Plus_CE/ROM.rom')`
- LD (nn),A = 0x32 + 3 bytes (little-endian address)
- LD A,(nn) = 0x3A + 3 bytes
- CALL nn = 0xCD + 3 bytes, JP nn = 0xC3 + 3 bytes
- _seqcase pattern: look for ADD A,A (0x87) followed by LD HL,nn (0x21 + 3 bytes) and JP (HL) (0xE9)
- To find callers: scan entire ROM for bytes CD xx 88 00 (CALL 0x0088xx) and C3 xx 88 00 (JP 0x0088xx)
