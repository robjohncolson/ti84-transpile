# Task: Trace 0x04C979 — Cursor Management Function

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The OS idle loop calls 0x03030E when no key is pressed (A=0, D00000=0 path). From session 473:
- 0x03030E calls 0x04C979 THREE TIMES with different DE values
- 0x04C979 is described as a "string/buffer processing function used in cursor management"
- 0x03030E body: BIT 0,(IY+0x1D); RET NZ → RES 3,(IY+0x08) → CALL 0x040D11 → RET (14 bytes)

Wait — session 473 says 0x030300 is 14 bytes, but 0x03030E is DIFFERENT. 0x03030E is the cursor management block that calls 0x04C979 three times. Let me clarify:
- 0x030300 = cursor/display prep (14 bytes: BIT test + RES + CALL 0x040D11 + RET)
- 0x03030E = cursor management (separate block, calls 0x04C979 three times)

## Your Task
Create a probe `TI-84_Plus_CE/probe-phase474-trace-04C979.mjs` that:
1. Hex-dumps ROM bytes at 0x03030E through 0x03030E+128 (to see the full cursor management block and its three CALL 0x04C979 instructions)
2. Hex-dumps ROM bytes at 0x04C979 through 0x04C979+96 (the function body)
3. Runs the idle loop and traces all PCs visited within 0x04C979

## Probe Structure

1. **3-stage boot** (standard):
   - Stage 1: `executor.runFrom(0x000000, 'z80', { maxSteps: 20000, maxLoopIterations: 32 })`
   - Reset: `cpu.halted=false; cpu.iff1=0; cpu.iff2=0; cpu.sp=0xD1A87E-3; mem.fill(0xFF, cpu.sp, cpu.sp+3);`
   - Stage 2: `cpu.mbase=0xD0; cpu._iy=0xD00080;` then `executor.runFrom(0x08C331, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`
   - Reset: `cpu.mbase=0xD0; cpu._iy=0xD00080; cpu._hl=0; cpu.halted=false; cpu.iff1=0; cpu.iff2=0; cpu.sp=0xD1A87E-3; mem.fill(0xFF, cpu.sp, cpu.sp+3);`
   - Stage 3: `executor.runFrom(0x0802B2, 'adl', { maxSteps: 200000, maxLoopIterations: 500 })`

2. **State setup after boot** (idle loop, no key):
   - `mem[0xD14091] = 1;`
   - `mem[0xD00824] = 0x48;`
   - `mem[0xD007E0] = 0x48;`
   - `mem[0xD177BA] = 0x7F;`
   - `mem[0xD177B7] = 0x00;`
   - `mem[0xD0009D] = 0x00;` (clear display gate so 0x030300 doesn't exit early)
   - `cpu.mbase = 0xD0; cpu._iy = 0xD00080; cpu.halted = false; cpu.iff1 = 0; cpu.iff2 = 0;`
   - Stack: write 0x02FDBE as return address

3. **FIRST: Print hex dumps BEFORE execution**:
   - Print ROM bytes 0x03030E to 0x03030E+128 as hex (16 bytes per line with address prefix)
   - Print ROM bytes 0x04C979 to 0x04C979+96 as hex

4. **Run from 0x02FD99** with:
   - maxSteps: 5000
   - maxLoopIterations: 50000
   - diHaltBypass: true

5. **Track**:
   - Hit counts for: 0x03030E, 0x04C979, 0x040D11, 0x030300, 0x02FD99, 0x03FA09
   - When PC === 0x04C979: log cpu.de (the DE parameter), cpu.hl, cpu.a for the first 10 hits
   - All unique PCs visited while inside 0x04C979 (set flag true at 0x04C979, false when returning to 0x03030E or nearby)

6. **Report**:
   - Hex dumps
   - DE values passed to 0x04C979 on each call
   - Unique PCs visited inside 0x04C979
   - Hit counts
