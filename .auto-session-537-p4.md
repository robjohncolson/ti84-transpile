## eZ80 conventions
- eZ80 in ADL mode: 3-byte addresses. `LD A,(nn)` = 3A + 3 bytes. `CALL nn` = CD + 3 bytes. `JP nn` = C3 + 3 bytes.
- OP registers: OP1=D005F8, OP2=D00603.
