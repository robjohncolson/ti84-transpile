# Auto-Session 376 P1: Investigate Key Dispatch Table Format at 0x020000+

## Context

The TI-84 Plus CE OS has a key dispatch table scan at 0x001C33-0x001CE5. When a key is pressed and dispatched through 0x0067F8, it enters a table scan loop that tries to match the key against table entries. The parser at 0x001CA6 compares tokens against 0x0E and 0x0F. The table pointer is loaded via BC=0x020000 before the loop.

In session 375, ENTER (scan code 0x09) was injected and reached the dispatch loop, but the loop scanned the table without finding a match and fell through to the error path (0x001933 → DI+HALT).

## Task

Write a probe at `TI-84_Plus_CE/probe-phase376-table-format.mjs` that:

1. **Dumps ROM bytes at 0x020000-0x020200** (512 bytes) in hex with annotations showing any structure (look for repeating patterns, token bytes 0x0E/0x0F, pointers)

2. **Disassembles the table scan loop 0x001C33-0x001CE5** instruction by instruction using the eZ80 decoder (ADL mode). Show every instruction with address and hex bytes. Pay special attention to:
   - How BC is used (table pointer? counter?)
   - What register holds the scan code being compared
   - How 0x001CA6 parses entries (what does the 0x0E/0x0F comparison mean?)
   - What constitutes a "match" vs "no match"

3. **Trace the dispatch path dynamically** with ENTER injected (scan code 0x09):
   - Boot phases 1-3 (same as probe-phase375-both-seeds-test.mjs)
   - Seed mem[0x020100] = [0x5A, 0xA5, 0x00] (flash self-test pass)
   - Seed mem[0xD177BA] = 0x00 (system flag clear)
   - Inject ENTER: mem[0xD00587] = 0x09, mem[0xD00080] |= 0x08
   - Run event loop from 0x003A73 for up to 50,000 steps
   - Log every visit to blocks in range 0x001C00-0x001D00 with full CPU state (A, BC, DE, HL, IX, IY, SP, PC, F)
   - When block 0x001CA6 is visited, dump the memory bytes being compared (pointed to by whatever register holds the table pointer at that point)

4. **Determine**: Is this a scan-code table or a token table? What format are the entries? Why doesn't ENTER (0x09) match anything?
