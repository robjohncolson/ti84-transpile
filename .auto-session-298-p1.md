# Auto-Session 298 — Priority 1: Disassemble Primary Keyboard Scanner 0x0159C0-0x015AD2

## Task
Produce a full annotated disassembly of the primary keyboard scanner (GetCSC raw scan) at ROM addresses 0x0159C0 through 0x015AD2 (274 bytes). This is the heart of keyboard input on the TI-84 Plus CE.

## Context
Session 297 confirmed the TI-84 CE uses MEMORY-MAPPED I/O (not Z80 IN/OUT ports) for keyboard access:
- 0xE00800-0xE0082F = keyboard controller registers (mode, config, status)
- 0xE00900 = keyboard data register (read key state / write group select)
- 0xE00810-0xE00817 = per-group key data (8 groups, 8 bytes)
- 0xE00824 = ready flag (bit 0 = keyboard result available)
- 0xE00818 = scan status (bit 1 = scan complete)

The scanner at 0x0159C0:
- Sets IY = 0xE00800 as controller base
- Uses `FD 77 offset` (LD (IY+d),A) for controller config writes
- Uses `FD CB offset 46` (BIT 0,(IY+d)) to poll status bits
- Reads 0xE00900 at ROM addresses 0x0159EE and 0x015A0E
- Writes group select to 0xE00900 at ROM addresses 0x015A4E, 0x015A7D, 0x015AC3

## Deliverable
Create file `TI-84_Plus_CE/probe-phase298-primary-scanner-disasm.mjs` that:

1. Reads `ROM.rom` from disk
2. Decodes every eZ80 instruction from 0x0159C0 to 0x015AD2
3. For each instruction, prints: `0xADDRESS: HEX_BYTES    MNEMONIC    ; annotation`
4. Annotations should identify:
   - IY-relative accesses and what keyboard register they target
   - Direct 0xE009xx memory accesses (reads vs writes)
   - Branch targets (JR/JP/CALL/RET)
   - Status bit polling loops
   - How the scan code is computed and returned
5. At the end, prints a summary: what group select values are written, the polling algorithm, and how the final scan code is assembled

## eZ80 Decoder Reference
- The project has `TI-84_Plus_CE/ez80-decoder.js` — you can import and use it if helpful
- eZ80 is in ADL mode (24-bit addresses, 3-byte immediates for LD rr,nn and JP/CALL)
- IY-prefixed: FD prefix. FD 77 dd = LD (IY+d),A. FD 7E dd = LD A,(IY+d). FD CB dd 46 = BIT 0,(IY+d)
- LD A,(imm24) = 3A lo mid hi. LD (imm24),A = 32 lo mid hi
