# Auto-Session 264 P1: D007D0 Boot Write-Site Tracing

## Context
D007D0 is a critical mode/context byte in the TI-84 Plus CE OS. Session 261 found a crash at 0x08C69E because D007D0 was uninitialized (0x00). Session 262 (probe `probe-phase262-d007d0-write-sites.mjs`) mapped 12 ROM sites that write to D007D0:

The question: **Which of these 12 write sites fires FIRST during normal OS boot, and what value does it write?**

## Task
Create a probe `TI-84_Plus_CE/probe-phase264-d007d0-boot-writer.mjs` that:

1. Performs a full boot sequence (same pattern as other probes — load ROM, create executor, run from z80 boot entry through kernelInit + memInit)
2. Instruments ALL writes to address 0xD007D0 by hooking cpu `write8` or by checking after each step
3. Runs up to 500,000 steps (with timer IRQ disabled via `createPeripheralBus({ timerInterrupt: false })`)
4. For EACH write to D007D0, logs:
   - Step number
   - PC at time of write
   - Value written
   - The block that contains the writing PC (if available)
5. Also check D007D0 at steps 10000, 50000, 100000, 200000, 500000 to see if it ever gets set

## Reference Code Pattern
Use the same probe structure as `TI-84_Plus_CE/probe-phase262-d007d0-write-sites.mjs` — read that file first to understand how the codebase creates executors and runs probes.

Key patterns:
- `import { createPeripheralBus } from './peripherals.js';`
- `const cpuRuntime = await import('./cpu-runtime.js');`
- `const { createExecutor } = cpuRuntime;`
- Transpiled blocks: `await import(pathToFileURL(TRANSPILED_PATH))` — but the file is ~214MB, so use `const blocks = (await import(pathToFileURL(TRANSPILED_PATH))).default;`
- Timer IRQ disabled: `createPeripheralBus({ timerInterrupt: false })`
- Boot entry: set `cpu.pc = 0x000000` with `cpu.adl = 1` and `cpu.mbase = 0xD0`
- Run via `executor.run(maxSteps)` or step-by-step with `executor.step()`

The simplest approach: snapshot D007D0 before each step, run the step, compare after. Log any change.

## Deliverables
- `TI-84_Plus_CE/probe-phase264-d007d0-boot-writer.mjs` — the probe
- Run it and include stdout output showing which sites write D007D0 and when
