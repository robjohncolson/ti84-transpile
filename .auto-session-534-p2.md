# Task: Decode 0x07DF66 — Conditional Path Helper

## Context
You are working on a TI-84 Plus CE ROM transpilation project. The ROM is at `TI-84_Plus_CE/ROM.rom` (4MB, eZ80 ADL mode). We decode ROM subroutines by writing Node.js probes that read raw bytes and disassemble them.

## Target
**0x07DF66** — A conditional path helper in the FP engine. Known callers:
- 0x07CF1A (matrix 0x1C handler) calls this in Phase 1 (rows) conditional path
- Carried from sessions 531, 532, 533 as undecoded

This function is in the FP engine region (0x07xxxx). It likely performs some conditional computation or flag check related to matrix dimension processing.

## What To Do
1. Create `TI-84_Plus_CE/probe-phase534-decode-07DF66-conditional-helper.mjs`
2. Read raw ROM bytes starting at 0x07DF66. Read at least 80 bytes.
3. Disassemble as **eZ80 ADL mode** (24-bit addresses = 4-byte immediates). 
4. Document each instruction with address, raw bytes, mnemonic, and operands.
5. Identify: what condition is checked? What are the CALL targets? Where does it return?
6. Look for patterns: IY-offset flag checks (FD CB xx xx), CP comparisons, conditional JR/JP.
7. Write findings as comments in the probe file.

## eZ80 ADL Opcode Reminders
- `LD rr, nn` uses 4-byte immediates (e.g., `21 xx xx xx` = LD HL, xxxxxxxx)
- `FD CB xx xx` = BIT/SET/RES on (IY+offset)
- `CD xx xx xx` = CALL nn, `C9` = RET, `C0`=RET NZ, `C8`=RET Z, `D0`=RET NC, `D8`=RET C
- `18 xx` = JR, `20 xx` = JR NZ, `28 xx` = JR Z, `30 xx` = JR NC, `38 xx` = JR C
- `FE xx` = CP n

## Key Addresses
- OP1 = 0xD005F8, OP2 = 0xD00603
- IY = 0xD00080 (system flags base)
- Known FP engine calls: 0x07C8B7 (BCD multiply), 0x07CAB9 (BCD divide), 0x07FB48 (BCD shift left)
