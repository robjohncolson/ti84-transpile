- 0x096CCF calls 0x096CC8 **after** adjusting cursor row (INC D00595) and IX (+4)
- The call sequence inside 0x096CCF is:
  1. CALL 0x096F67, JP NZ → early exit
  2. LD A=0x15, CALL 0x0994DC
  3. LD HL=D0060E, CALL 0x0A1EAD

  5. Check D007E0 against 0x53, RET NZ if not

  11. CALL 0x0A1F12
  12. SUB IX-4

- 0x096CCF manipulates cursor row ±1 and IX ±4 → this is multi-line cursor (equation editor / split-screen)

Since 0x096CC8 starts at 0x096CC8 and 0x096CCF starts at 0x096CCF, there are exactly 7 bytes (0x096CC8-0x096CCE).
This MUST be a very short function — likely 2-4 instructions.
