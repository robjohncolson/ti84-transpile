# Auto-Session 345 — Priority 4: Investigate 0xD0058E vs 0xD0058C Scan Code Locations

## Context

In the TI-84 Plus CE OS, the primary _GetCSC result is stored at address 0xD0058C. However, session 344 found that OS context handlers read from a DIFFERENT address: 0xD0058E.

Specifically:
- Handler[14] at 0x0454A4 reads from 0xD0058E for arrow key dispatch
- Handler[22] at 0x0ADB41 reads from 0xD0058E for scan code remapping
- Handler[13] at 0x05CBDC reads from 0xD0058E to check for 0x0A (+)

The question: What writes to 0xD0058E? Is it a secondary/remapped scan code? Who copies from 0xD0058C to 0xD0058E?

## Task

Create a probe at `TI-84_Plus_CE/probe-phase345-scancode-d0058e.mjs` that does a ROM-wide scan for references to address 0xD0058E.

### Approach

The ROM is at `TI-84_Plus_CE/ROM.rom` (4 MB). Scan all 4MB for the byte pattern corresponding to address 0xD0058E in little-endian: `0x8E 0x05 0xD0`.

For each match:
1. Print the ROM offset where the pattern was found
2. Print the surrounding context (5 bytes before and 10 bytes after)
3. Try to identify if it's a LD instruction writing TO 0xD0058E vs reading FROM it:
   - `LD (0xD0058E), A` = opcode 0x32 followed by 0x8E 0x05 0xD0 (this is a WRITE)
   - `LD A, (0xD0058E)` = opcode 0x3A followed by 0x8E 0x05 0xD0 (this is a READ)
   - Other patterns: LD HL,0xD0058E (0x21 8E 05 D0) = address load

Also scan for 0xD0058C (`0x8C 0x05 0xD0`) and 0xD0058D (`0x8D 0x05 0xD0`) to build a complete picture of the scan code RAM area.

### Implementation

```js
#!/usr/bin/env node
import { readFileSync } from 'fs';

const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

function scanForAddress(targetAddr, label) {
  const lo = targetAddr & 0xFF;
  const mid = (targetAddr >> 8) & 0xFF;
  const hi = (targetAddr >> 16) & 0xFF;
  const matches = [];
  for (let i = 0; i < rom.length - 2; i++) {
    if (rom[i] === lo && rom[i + 1] === mid && rom[i + 2] === hi) {
      const prevByte = i > 0 ? rom[i - 1] : null;
      let type = 'UNKNOWN';
      if (prevByte === 0x32) type = 'WRITE (LD (nn),A)';
      else if (prevByte === 0x3A) type = 'READ (LD A,(nn))';
      else if (prevByte === 0x21) type = 'ADDR_LOAD (LD HL,nn)';
      // ... add more opcode patterns as needed
      matches.push({ offset: i, prevByte, type });
    }
  }
  console.log(`\n=== ${label} (0x${targetAddr.toString(16).toUpperCase()}) — ${matches.length} references ===`);
  for (const m of matches) {
    const context = Array.from(rom.slice(Math.max(0, m.offset - 5), m.offset + 10))
      .map(b => b.toString(16).padStart(2, '0')).join(' ');
    console.log(`  0x${(m.offset - 1).toString(16).padStart(6, '0')}: ${m.type}  [${context}]`);
  }
  return matches;
}

scanForAddress(0xD0058C, 'D0058C (_GetCSC primary)');
scanForAddress(0xD0058D, 'D0058D');
scanForAddress(0xD0058E, 'D0058E (handler reads)');
```
