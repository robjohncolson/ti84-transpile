# Auto-Session 197 P3: Trace 0x0A1799 renderer to decode Y= label selection

## Context

In session 196, we decoded the Y= row structure:
- Screen update at 0x0A1B59: loads A=0x3A (colon), compares 0xD00595 vs 0xD02505, calls renderer 0x0A1799, increments counter 0xD00596, checks ≥26
- Row index: `C = 0x19 - [0xD00596]` computed at 0x0A29D6
- VRAM cursor at 0xD0059C (3-byte pointer)
- Y-variable tokens (0x5E 0x10-0x19) found at 0x09FE9B, 0x09D48D

The next step is to trace what 0x0A1799 actually does — it's the renderer called from the screen update loop. We need to understand how it uses the row index to select Y1=/Y2=/Y3= labels and render them.
