# Task: Trace D14079 and D1407A — Last 2 Unmapped Bytes in USB State Block D14070-D1407F

## Context
The TI-84 Plus CE ROM transpilation project has fully characterized 14 of 16 bytes in the USB state block D14070-D1407F. The last 2 bytes, D14079 and D1407A, are known to be bulk-cleared alongside D14078 (endpoint-configured flag) on disconnect at addresses 0x00FD04 and 0x02C22E. We need to trace ALL references to determine what they individually track.

## What to do

1. **Create a probe script** `TI-84_Plus_CE/probe-phase442-trace-D14079.mjs` that:
   - Loads the ROM from `TI-84_Plus_CE/ROM.rom` (4MB, raw binary)
   - Scans ALL 4MB for any instruction that reads or writes addresses D14079 or D1407A
   - For eZ80 memory access patterns, search for these byte sequences:
     - `LD A,(D14079)` = `3A 79 40 D1` (3-byte address little-endian: 79 40 D1)
     - `LD (D14079),A` = `32 79 40 D1`
     - `LD A,(D1407A)` = `3A 7A 40 D1`
     - `LD (D1407A),A` = `32 7A 40 D1`
     - Also search for the address bytes `79 40 D1` and `7A 40 D1` in any context (LD r,(addr), LD (addr),r, etc.)
   - For each reference found, extract:
     - ROM address of the instruction
     - The containing function (scan backward for common function prologues: `CALL __frameset` = `CD 97 21 00` or `PUSH IX` = `DD E5`)
     - The instruction type (read/write)
     - Surrounding context (5 bytes before and after)
     - What other D140xx addresses are accessed within ±30 bytes (co-access pattern)

2. **Create a report** `TI-84_Plus_CE/phase442-trace-D14079-report.md` with:
   - Total reference counts for D14079 and D1407A separately
   - Read vs write breakdown
   - Whether each is boolean (only 0x00/0x01 values) or multi-value
   - Co-access patterns (which other USB state bytes appear nearby)
   - Containing functions
   - Assessment: what does each byte track? Endpoint address? Endpoint type? Direction?

## Known facts about D14079 and D1407A
- Bulk-cleared alongside D14078 at disconnect sites 0x00FD04 and 0x02C22E
- Part of the endpoint state sub-block (D14078/D14079/D1407A)
- D14078 is the "lead flag" (endpoint-configured, 11 refs)
- Adjacent D1407B (SOF-received, 19 refs) is already characterized
