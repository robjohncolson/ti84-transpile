# Task: Decode Text Cursor Candidate at 0x05E400

## Context
We are reverse-engineering the TI-84 Plus CE OS ROM (eZ80) to find the TEXT CURSOR BLINK function. The ROM is lifted to JavaScript in `TI-84_Plus_CE/ROM.transpiled.js` (regenerate via `node scripts/transpile-ti84-rom.mjs`). The CPU runtime is in `TI-84_Plus_CE/cpu-runtime.js`, peripherals in `TI-84_Plus_CE/peripherals.js`.

Session 487 identified 6 candidates that reference BOTH cursor position variables (D00595=row, D00596=column) AND the rendering pipeline (0x0A23C0/0x0A239E). The top 2 (0x05C780 and 0x0817C0) were eliminated in session 488. The third strongest candidate is:

**0x05E400-0x05E55F**: References D00595 ×4, D00596 ×1, calls 0x0A23C0.

## What to do

Create a probe file `TI-84_Plus_CE/probe-phase489-decode-05E400.mjs` that:

1. **Disassembles 0x05E400-0x05E55F** instruction by instruction using the ROM bytes directly (read from `TI-84_Plus_CE/ROM.rom`). Show each instruction's address, hex bytes, and mnemonic. Pay special attention to:
   - How it reads D00595 (row) and D00596 (column)
   - How it calls 0x0A23C0 (the pixel rendering function)
   - Whether it computes a VRAM address from cursor position
   - Whether it reads/writes D008D2 or D008D5 (LCD window registers)
   - Whether it reads D0059C (column scratch variable)
   - What glyph code it passes to the renderer

2. **Dynamic test**: Boot the CPU to idle state (use the pattern from existing probes like `probe-phase488-decode-05C780.mjs` — read it for reference), then:
   - Set D00595=0 (row 0), D00596=0 (col 0), D00092=0x16 (cursor enabled)
   - Call 0x05E400 directly and record all VRAM writes
   - Reset and repeat with D00595=5, D00596=13 (middle of screen)
   - Compare VRAM write positions — do they change with cursor position?

3. **Report**: Print whether this function is the text cursor blink or something else. Key question: does it produce VRAM writes at DIFFERENT positions when D00595/D00596 change? (The status bar indicator at 0x030173 always renders at fixed row=2, col=289 regardless of inputs — the text cursor should render at variable positions.)
