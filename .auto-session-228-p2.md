# Task: Trace the jump table dispatcher at 0x0213C0 — find callers and HL values

## Context
Session 227 found that 0x023B67 is a mode-registration stub: `LD (D02611),HL / SET 1,(IY+53) / RET`. It's entry [12] in a jump table at 0x0213C0 (dispatched via address 0x0213F0). There are ~20 similar stubs at 0x023B31-0x023BCE, each storing HL to a D025xx/D026xx address.

The jump table at 0x0213C0 is the "mode registration" API — callers pass HL=pointer-to-handler-table, and the table index selects which handler slot to register. We need to find:
1. What code calls THROUGH this jump table (not just references to the table)
2. Specifically for entry [12]: what HL value does the caller pass?
3. How many total entries the table has and their target addresses

## Deliverables

Create a probe file `TI-84_Plus_CE/probe-phase228-0213c0-jump-table.mjs` that:

1. **Dump the jump table at 0x0213C0**: Read ROM.rom bytes starting at 0x0213C0. Each entry is a 3-byte ADL address (little-endian). Read entries until you hit an obviously non-code address or reach ~30 entries. Entry [12] should point to 0x023B67. List all entries with their index and target address.

2. **Find callers of the jump table**: The dispatch mechanism is typically `CALL (IX+offset)` or `JP (HL)` or a computed `CALL` using the table base 0x0213C0. Search the ROM binary for:
   - References to 0x0213C0 (bytes C0 13 02 in little-endian, with ADL prefix consideration)
   - References to nearby addresses (0x0213C3, 0x0213C6, ..., 0x0213F0 for entry [12])
   - The pattern `CALL` followed by any table entry address

3. **For any callers found**: Disassemble the ~20 bytes preceding the call to identify how HL is loaded. HL should contain a pointer-to-handler-table that the stub stores to D02611.

4. **Cross-reference D02611**: Search for all ROM references to D02611 (bytes 11 26 D0 in little-endian). Classify as READ/WRITE/POINTER. This tells us where the mode handler pointer is consumed.

## Pattern for reading ROM bytes
```javascript
import { readFileSync } from 'fs';
const rom = readFileSync('TI-84_Plus_CE/ROM.rom');

// Read 3-byte little-endian address at offset
function read24(offset) {
  return rom[offset] | (rom[offset+1] << 8) | (rom[offset+2] << 16);
}

// Search for 3-byte pattern in ROM
function findPattern(b0, b1, b2) {
  const results = [];
  for (let i = 0; i < rom.length - 2; i++) {
    if (rom[i] === b0 && rom[i+1] === b1 && rom[i+2] === b2) {
      results.push(i);
    }
  }
  return results;
}
```
