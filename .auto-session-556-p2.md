# Task: Decode IY+0x4A Bit 4 Context — The 42-Reference Flag

## Context
You are working on the TI-84 Plus CE ROM transpilation project. The ROM file is at `TI-84_Plus_CE/ROM.rom` (4MB eZ80 binary). Session 555 fully mapped IY+0x4A and found bit 4 is the MOST ACTIVE flag with 42 references (3 BIT tests, 17 SETs, 22 RESes). Heavy concentration in the 0x045xxx-0x046xxx range (10 SETs, 14 RESes) with a "bracket pattern" where SET is followed by RES. The hypothesis is this is an expression parser/evaluator flag.

## Target
Decode the **context** around the IY+0x4A bit 4 references to determine what this flag controls. Specifically:

### Part A: Decode the 0x045xxx-0x046xxx cluster
1. Find all SET 4,(IY+0x4A) and RES 4,(IY+0x4A) instructions in the range 0x045000-0x046FFF. The encoding is:
   - SET 4,(IY+0x4A) = FD CB 4A E6
   - RES 4,(IY+0x4A) = FD CB 4A A6
   - BIT 4,(IY+0x4A) = FD CB 4A 66
2. For each match, hex-dump 32 bytes before and 32 bytes after to see what functions bracket them.
3. Look for CALL instructions (CD xx xx xx) near the SET/RES pairs — what functions are called between SET and RES?

### Part B: Decode 0x0A22DA (the tester)
Session 555 noted a BIT 4 test at or near the renderer. Search for BIT 4,(IY+0x4A) in the 0x0A2000-0x0A2FFF range. For each hit:
1. Hex-dump 48 bytes before and after
2. Identify what conditional jump follows the BIT test (JR Z/NZ, JP Z/NZ)
3. Determine what the function does when bit 4 is set vs clear

## Deliverables
Create a probe file `TI-84_Plus_CE/probe-phase556-iy4a-bit4.mjs` that:

1. Scans the full ROM (0x000000-0x3FFFFF) for all three encodings of bit 4 operations on IY+0x4A
2. For each match, prints:
   - Address
   - Instruction type (BIT/SET/RES)
   - 32 bytes context before and after (hex)
3. For the 0x045000-0x046FFF cluster specifically:
   - Groups SET/RES pairs by proximity (within 64 bytes of each other = same bracket)
   - Identifies CALL targets between each SET/RES pair
4. For the 0x0A2000-0x0A2FFF range:
   - Full disassembly context (48B before/after each BIT 4 hit)
   - The conditional branch direction and target
