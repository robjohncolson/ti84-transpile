### Ports to register (from phase322-lcd-port-wrappers-report.md):

**Read-only timing registers** (return reasonable defaults):
- 0x8000: LCD timing reg 0 (default 0x00)
- 0x8004: LCD timing reg 1 (default 0x00)  
- 0x8008: LCD timing reg 2 (default 0x00)
- 0x800C: LCD timing reg 3 low (default 0x00)

**Read/Write timing registers** (store and recall):
- 0x8010: LCD timing reg 4 (default 0x00)
- 0x8014: LCD timing reg 5 (default 0x00)
- 0x8018: LCD timing reg 6 (default 0x00)

**LCD DMA control register** (read/write, 8-bit, bitfield):
- 0x8020: DMA control register (default 0x00). Bit 5 = DMA enable (most important). Bit 0-4 = config bits. Bit 6-7 = state/control.

**DMA window coordinate registers** (write-only, store for reads):
- 0x8024: H-start (default 0x00)
- 0x8028: H-end (default 0x00)
- 0x802C: V-start (default 0x00)
- 0x8030: V-end (default 0x00)

**DMA misc register**:
- 0x8034: R/W, default 0x00

**DMA status registers** (read-only):
- 0x8040: Status (always return 0x00 = idle/DMA complete — this is what was already registered)
- 0x8041: Status high, bit 0 = panel ready (return 0x01)

```javascript

  timing: [0, 0, 0, 0, 0, 0, 0],  // regs 0x8000,0x8004,0x8008,0x800C,0x800D,0x8010,0x8014,0x8018
```

Use a switch or if-chain on `(port & 0xFFFF)` to dispatch reads and writes. For unhandled ports in the range, return 0x00 on read and silently drop writes.
