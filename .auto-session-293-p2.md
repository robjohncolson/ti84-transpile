# Task: Trace 0x088657 and 0x08C4E9 Token Dispatchers Deeper

## Context
Session 292 mapped 14 KEY_DISPATCH CP cascades that read scan codes from D0058C (0xD0058C). The two richest dispatchers are:
- **0x088657** — 14 CP values: 0xFF, 0xFE, 0xFC, 0xFB, 0xFA, 0xEF, 0x69, 0xF9, 0xF3 (token/function key router)
- **0x08C4E9** — 14 CP values: 0xEF, 0xF9, 0xF3, 0x69, 0x5B, 0x28, 0x29, 0xBC, 0xBD, 0xC0 (similar token dispatcher)

Session 292 identified the CP values and their branch targets, but NOT what the handlers actually DO.

## What to do
Create a probe file `TI-84_Plus_CE/probe-phase293-token-dispatcher-trace.mjs` that:

1. For dispatcher **0x088657**:
   - Read the probe `TI-84_Plus_CE/probe-phase292-key-dispatch-cp-values.mjs` to find the exact CP values and branch targets
   - For each CP value's branch target, disassemble the first 10-20 instructions at that target
   - Identify what the handler does: does it write a token byte somewhere? Call a specific OS function? Set a mode flag? Jump to another dispatcher?
   - Flag any writes to D0058C, D0058E, or known display/token RAM addresses

2. For dispatcher **0x08C4E9**:
   - Same analysis as above

3. Print a summary table mapping: `scan_code_value → dispatcher → handler_address → action_summary`
