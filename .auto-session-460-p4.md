# Task: Trace 0x009B35 — handler called from reduced ISR dispatcher

## Context

The reduced ISR dispatcher at 0x0019BE handles interrupts when the full dispatcher (0x03CF7D) is blocked by the port 0x03 gate. Session 459 mapped 0x0019BE fully and found it calls only two functions:
- 0x010220 (port 0x5015 bit 4 handler)
- 0x009B35 (port 0x5015 bit 5 handler, called from 0x001A77)
- 0x014DAB (port 0x5008 bit 3 handler — increments D14038 SOF counter)

0x009B35 is the most interesting because it handles port 0x5015 bit 5 interrupts, which may be related to display refresh or other periodic events. It has NOT been traced yet.

## Deliverables

Write a probe `TI-84_Plus_CE/probe-phase460-trace-009B35.mjs` that:

1. **Disassembles** the ROM bytes starting at 0x009B35 for 256 bytes (or until RET/RETI is found)
2. **Identifies**:
   - What ports does the function read/write?
   - What RAM addresses does it access?
   - Does it call any sub-functions? If so, list their addresses
   - Does it interact with any known state (IY flags, D00080+, keyboard, LCD, timers)?
   - Is there any relationship to display refresh, keyboard, or other subsystems?
3. **Also trace 0x010220** (the other CALL target from 0x0019BE) in the same probe — same questions
4. **Report**: For each function, a summary of purpose, size, ports/RAM touched, and sub-calls
